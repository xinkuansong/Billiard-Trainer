## ⚠️ 问题项（非阻塞 — 开发时修正）

### P1: 厚薄球概念数值标注错误

- **期望**: 全球(0°/偏移0%)、半球(30°/偏移50%)、3/4球(48.6°/偏移75%)、极薄球(90°/偏移100%)
- **当前**: "3/4 球" 显示 "14.5° | 0.25R"（角度应为 48.6°，偏移应为 75%），其他项格式为 R-based 而非百分比
- **处理**: **开发时以 tasks.md 验收标准中的正确数值为准**。Stitch 对具体数值的准确性有限，此处视觉布局正确，数值由开发填充

### P2: 厚薄球排列顺序与规格不同

- **期望**: 左上全球 → 右上半球 → 左下3/4球 → 右下极薄球（按角度递增）
- **当前**: 左上全球 → 右上3/4球 → 左下半球 → 右下极薄球
- **处理**: 开发时按角度递增排列（0° → 30° → 48.6° → 90°）

### P3: 假想球法步骤标签为英文

- **期望**: "步骤 1"/"步骤 2"/"步骤 3"（中文）
- **当前**: "STEP 1"/"STEP 2"/"STEP 3"（英文）
- **处理**: 开发时改为中文标签，或保留英文（对教学内容无本质影响）

### P4: 假想球法步骤布局差异

- **期望**: 每步为全宽卡片（Canvas 占上方 + 文字占下方）
- **当前**: 左侧小 Canvas 缩略图 + 右侧文字说明的横排布局
- **处理**: 当前横排布局更紧凑，可读性亦可。开发时可根据内容量选择垂直或横排
