瞄准原理

什么是切入角

切入角是指母球击球方向与目标球进球方向之间的夹角。范围：0° 到 90°

核心公式

偏移量 = sin(α) × R
sin(30°) = 0.5 (半球厚度)

假想球法（Ghost Ball）

Step 1

确定进球线路

连接目标球中心与袋口中心点。

Step 2

放置假想球

在进球线反方向放置一个与母球等大的圆。

Step 3

瞄准球心 C

母球只需向假想球的圆心方向击出即可。
