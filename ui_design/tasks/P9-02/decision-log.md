# 设计决策日志 — P9-02

## 决策 1: 教学页面采用白色卡片分 Section 滚动布局
- **上下文**: 瞄准原理为纯教学长页面，需要组织 4 个知识 Section
- **决策**: 沿用 P1-05 ContactPointTableView 的白色卡片 + #F2F2F7 背景 ScrollView 模式
- **理由**: 保持工具子页面系列的视觉一致性，卡片式分段便于阅读理解
- **日期**: 2026-04-14

## 决策 2: Canvas 球台示意图为布局参考，精确数值由开发实现
- **上下文**: Stitch 生成的 Canvas 中球位/线条/角度为近似示意，部分数值标注有误（如 3/4 球角度显示 14.5° 应为 48.6°）
- **决策**: Stitch 截图作为布局和视觉风格参考，所有数值/坐标/几何关系由开发代码精确计算
- **理由**: Stitch 无法精确计算三角函数和球台几何，开发时使用 AngleCalculator 等工具类确保数值正确
- **日期**: 2026-04-14

## 决策 3: 假想球法步骤横排布局可接受
- **上下文**: 规格要求每步为全宽垂直布局（Canvas 上 + 文字下），Stitch 渲染为左 Canvas + 右文字横排
- **决策**: 横排布局更紧凑且可读性良好，开发时可根据内容量灵活选择
- **理由**: 教学内容核心是信息传达清晰，横排和竖排都能达到目标
- **日期**: 2026-04-14

## 决策 4: Dark Mode 跳过，参考 Phase E 规范
- **上下文**: P9-02 原计划 Light + Dark 两帧
- **决策**: 仅保留 Light Mode Stitch 截图，Dark Mode 参考 E-01 ~ E-04 规范
- **理由**: 教学页面结构为标准卡片列表，SwiftUI Dark Mode 自动适配，Token 表已齐备
- **日期**: 2026-04-14
