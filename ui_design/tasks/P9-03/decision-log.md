# 设计决策日志 — P9-03

## 决策 1: 球台使用真实照片/USDZ 渲染替代 Canvas 绘制
- **上下文**: P0-07 AngleTestView 使用 Canvas 绘制简化球台，P9-03 需要更沉浸的视觉
- **决策**: 使用真实球台俯拍照片（开发时为 USDZ 模型渲染）作为底图，标注线/球/角度弧作为矢量叠加层
- **理由**: 用户拥有精准尺寸的 USDZ 台球桌模型，真实感更强，且可复用 3D 资源
- **日期**: 2026-04-14

## 决策 2: 球台竖屏显示（长轴竖直）
- **上下文**: P0-07 使用横版 2:1 球台（P0-07 决策 1），P9-03 需要在手机竖屏中展示更多球台细节
- **决策**: 球台长轴竖直显示，旋转 90° 适配手机竖屏
- **理由**: 竖屏最大化利用手机屏幕空间，且更接近站在球台一端俯视的真实视角
- **日期**: 2026-04-14

## 决策 3: 数值面板布局开发时灵活选择
- **上下文**: 规格要求 5 项水平排列，Stitch 渲染为垂直列表
- **决策**: 两种布局均可接受，开发时根据实际空间和可读性选择
- **理由**: 水平排列更紧凑但数值较小，垂直列表可读性更好。核心是 5 项数据完整呈现
- **日期**: 2026-04-14

## 决策 4: 移除"开始实练模式"按钮
- **上下文**: Stitch 自行添加了底部 CTA 按钮
- **决策**: 开发时移除，此页面为纯探索工具
- **理由**: 角度动态关系页定位为教学/探索工具，不含练习入口。练习入口在 AngleHomeView 的训练区 Section
- **日期**: 2026-04-14
