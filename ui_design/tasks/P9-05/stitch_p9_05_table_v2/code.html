原理说明 (Principle)

切入角 α 与球心偏移距离 d 的关系遵循公式：d = 2R · sin(α)。 在中八规格中，球体直径 57.15mm，半径 R = 28.575mm。 当偏移量 d 等于半径 R 时，即为“二分之一”球位，此时切入角 α 为 30°。
