### 帧 1 — 偏差 1：通称文字不准确
- **期望**：全球(0°) / ≈1/3球(10°) / 半球(30°) / 极薄球(90°)
- **实际**：全中(0°) / 厚球(10°) / 1/2(30°) / 薄球(45°) / 1/4(60°) / 微边(90°)
- **处理**：开发时以规格定义的通称为准（全球 / ≈1/3球 / 半球 / 极薄球）

### 帧 1 — 偏差 2：偏移% 数值公式错误
- **期望**：偏移% = sin(α) × 100%（30° → 50%，45° → 70.7%）
- **实际**：Stitch 似乎使用了 d/R × 100%（30° → 100%，45° → 141%），导致出现 >100% 的值
- **处理**：开发时偏移% = sin(α) × 100%，数值不可能超过 100%
