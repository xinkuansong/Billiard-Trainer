# 设计决策日志 — P9-05

## 决策 1: 移除球种切换 Tab，仅保留中八
- **上下文**: 原设计包含 BTSegmentedTab（斯诺克/中八/美式）三球种切换，Stitch 帧 1 已渲染
- **决策**: 移除 BTSegmentedTab，页面固定显示中八数据（R=28.575mm，球径 57.15mm）
- **理由**: 用户判断球种切换在当前阶段不必要；中八和美式球径相同（R=28.575mm），斯诺克差异较小（R=26.25mm），单球种简化页面复杂度
- **影响**: 帧 1 顶部 Tab 区域移除，导航栏直接接滑块 Section；帧 2 顶部 Tab 同样移除
- **日期**: 2026-04-14

## 决策 2: 帧 2 Stitch 偏差以帧 1 为基准修正
- **上下文**: 帧 2 存在 7 处 Stitch 渲染偏差（导航样式、英文 Tab、底部 Tab 栏、额外卡片等）
- **决策**: 开发时全部以帧 1 为基准修正
- **理由**: 帧 1 渲染质量更高，两帧为同一页面不同滚动位置，必须保持一致
- **日期**: 2026-04-14

## 决策 3: X/Y 轴刻度开发时补齐
- **决策**: X 轴补齐 15°/45°/75° 三个刻度，Y 轴补齐 0.5 刻度
- **理由**: Stitch 渲染空间有限导致刻度省略，开发时 Canvas 可精确控制
- **日期**: 2026-04-14

## 决策 4: Dark Mode 跳过
- **决策**: 仅 Light Mode 两帧，Dark Mode 参考 Phase E 规范
- **理由**: 延续 P9-01~P9-04 决策
- **日期**: 2026-04-14
