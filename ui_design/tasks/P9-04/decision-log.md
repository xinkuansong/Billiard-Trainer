# 设计决策日志 — P9-04

## 决策 1: 几何坐标系使用 btTableFelt 绿色背景
- **上下文**: 纯几何角度练习需要一个 Canvas 背景
- **决策**: 使用 btTableFelt #1B6B3A 绿色，与其他角度训练 Canvas 一致
- **理由**: 保持角度模块视觉统一性，绿色背景也便于白色线条清晰显示
- **日期**: 2026-04-14

## 决策 2: 答题+反馈布局沿用 P0-07 模式
- **决策**: Canvas → 输入 → 确认 → 反馈 → 统计 的垂直布局，与 P0-07 AngleTestView 一致
- **理由**: 用户对 P0-07 的答题交互模式已有认知，保持一致降低学习成本
- **日期**: 2026-04-14

## 决策 3: 帧 2 导航栏以帧 1 为准
- **上下文**: Stitch 帧 2 渲染为大标题导航，与帧 1 标准子页面导航不一致
- **决策**: 开发时统一使用帧 1 的子页面导航（返回箭头 + 居中标题"角度预测"）
- **理由**: 同一页面不同状态导航必须一致
- **日期**: 2026-04-14

## 决策 4: 保留"下一题"按钮
- **上下文**: Stitch 帧 2 自行添加了"下一题"和"查看解析"按钮
- **决策**: 保留"下一题"（合理交互需求），移除"查看解析"
- **理由**: 答题完成后自然需要进入下一题，但该页面无独立解析功能
- **日期**: 2026-04-14
