# 设计决策日志 — P9-06

## 决策 1: 教学页面沿用 P9-02 白色卡片分 Section 滚动布局
- **上下文**: P9-06 与 P9-02 同为教学类长页面，需保持风格统一
- **决策**: 完全沿用 P9-02 确立的布局模式（白色卡片 + #F2F2F7 背景 + ScrollView）
- **理由**: 教学类页面系列应保持视觉一致性，用户在两个页面间切换无割裂感
- **日期**: 2026-04-14

## 决策 2: 视觉锚点使用球重叠方式表达厚薄球
- **上下文**: Section 2 需要展示全球/半球/3/4球/薄球从母球视角的视觉印象
- **决策**: 采用 Stitch 生成的球重叠偏移方式（白色母球 + 橙色目标球的横向偏移量渐变），而非俯视球台图
- **理由**: 球重叠方式更直观地传达了"从母球看过去"的第一人称视觉体验，比俯视图更贴合教学目标
- **日期**: 2026-04-14

## 决策 3: Canvas 为布局参考，精确数值由开发实现
- **上下文**: 与 P9-02 决策 2 一致，Stitch 生成的 Canvas 中球位/线条/角度为近似示意
- **决策**: Stitch 截图作为布局和视觉风格参考，所有角度/偏移/球位关系由开发代码精确计算
- **理由**: Stitch 无法精确计算三角函数和球台几何
- **日期**: 2026-04-14

## 决策 4: Dark Mode 跳过，参考 Phase E 规范
- **上下文**: P9-06 仅要求 Light 一帧，与 Phase F 全部任务策略一致
- **决策**: 不生成 Dark Mode 截图，开发时参考 E-01~E-04 规范
- **理由**: 教学页面结构为标准卡片列表，SwiftUI Dark Mode 自动适配，Token 表已齐备
- **日期**: 2026-04-14
