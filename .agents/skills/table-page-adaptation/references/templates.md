# 按需模板

这些字段用于约束遗漏，不要求每次机械填满。普通局部修订可只更新受影响章节。没有证据的字段写未采集；示例不能作为真实反馈或验收。

## 页面实施卡

```markdown
# P编号 · 页面名
版本／日期：
设计状态：提案／方向已确认／需调整／本版已确认
工程状态：未实施／实施中／检查失败／定向检查通过
体验状态：未交付／待评审／待真机／已评审（版本及范围）
唯一下一步：

## 任务与现状
正常入口、业务任务、源码锚点、实际截图与采集身份。
区分已证实问题与待验证假设。

## 目标与保留
顶部／球桌／两侧／辅助面板的具体安排。
控件能力映射、业务不变量、与共用方案的差异。
参考页完整设置对照：适用／差异／不适用理由；状态与禁用、偏好作用域、接线缺口、逐项验收。
用户已确认范围；尚需判断的实质取舍。

## 适配与依赖
宽度不足、高度不足、字号、大屏与窗口恢复策略。
依赖批次、共享消费者、当前在途工作与隔离方式。

## 批次与验证
设计规范版本、适用DC编号及保留差异；每项登记“具体判断→原图/操作/测试→通过/失败/未验”，不只列编号。
每批范围、进入条件、完成证据、受影响状态／设备。
真实可用测试入口；实施时填写实际命令和输出。

## 交接
最新轮次、反馈索引、DoD已完成/未完成及唯一下一动作。
相关源码/构建身份、证据适用范围、在途命令/日志/所属会话与状态；无在途写无，未知先核实。
恢复按 references/session-continuity.md；该节已作活动入口时不另设平行CURRENT。
```

## 每轮评审包

```markdown
# P编号 / r编号 评审
产物类型：原生页面／概念提案（明确选择）
源与构建身份：commit、未提交差异指纹、配置、采集时间
设备／OS／实际窗口／安全区／字号／球形／模式／状态：
用户已认可的参考版本及范围：

## 看这一版
原图、同条件前后对照、必要录屏或可运行入口。
概念图及标注图单独标记；不替换原始证据。

## 本轮变化
目标、实际变化、上轮每条反馈的处理／延期原因。

## 检查与限制
真实命令、exit、日志／xcresult和视觉审查证据。
通过／失败／未验；真机、安装、提交和发布分别列状态。

## 需要用户判断
通常 1–3 个与可见产物直接对应的具体问题；没有则省略。

## 下一步
反馈状态和依赖；只写一个当前执行入口。
```

## 反馈条目

```markdown
- ID：F编号
- 来源：用户原话、日期
- 对象：页面／轮次／设备／状态；未知但影响判断时澄清
- 目标：能观察到的变化，保留用户意图
- 范围：本页／同类候选／全局候选
- 处理：实现、需取舍、缺陷修复或延期及理由
- 证据：变更版本、对照图、交互／测试记录
- 状态：待澄清／待处理／已实现待验证／已验证待体验／已确认／延期
- 裁定：用户认可的版本和范围，或客观缺陷的验证关闭依据
```
