# ADR · 分离角练习双模式与轨迹评分记录

日期：2026-10-22。状态：用户批准范围，实施与验证记录见[活动方案](../tasks/table-page-adaptation/SEPARATION-PRACTICE-PLAN-20261022.md)。

## 问题与决定

在“打”区新增2D、3D分离角练习，用户根据完整母球碰后目标轨迹选择打点和杆速，系统补偿瞄准。2D/3D共用物理与出题器，分别持有轮次、显示偏好、布局模板和本地草稿；旧“分离角与走位”保留。用户于同日追加批准DTW 70%＋Fréchet 30%轨迹评分，排名不纳入。

球形来自当前准度题库与条件筛选。先用中心打点按0.01 m/s全范围升序找首个进袋样本，再以0.0025 m/s复查前邻区间（0.05粗扫在密集对照中漏检，已替换）；下限称数值最低样本，不声称全局精确最小。以(0,0,2.5)为中心，σ=(0.18,0.18,0.75)拒绝采样，速度上限4.5，双轴默认允许。每个精确输入重新补偿、检验球杆可达域、完整模拟及指定袋事件；标准答案复用直进判定排除母球落袋和间接路线。预算耗尽只在所选条件内换题，不抬杆代替中心基准，不调整输入使样本“通过”。

## 数据和状态边界

`SeparationPracticeViewModel`负责页面状态，`SeparationQuestionGenerator`负责纯出题/求解，`SeparationPracticeRepository`隔离持久化。复用现有SwiftData `TrainingSession` 与同步DTO，无新Schema或SPM依赖。载荷使用SP01标识及LZFSE无损压缩，保留完整浮点物理数据，24题样本传输载荷约1.27 MB；历史和恢复走同一解码器。显式访客数据迁移事务同步迁移载荷owner，失败恢复原载荷。自由练习每10题或压缩载荷达到512 KB后，在下一题边界原子归档上一段并创建续段，连续题号/总结累计、物理记录/时长按段入历史；不限制总题数。段切换失败保留原结果，未答续段不上传；单条压缩载荷1.45 MB安全上限在计题前检查，避免反复向2 MiB接口提交超大请求。

新增`kind=separationPractice`，载荷版本1、物理版本`separation-planar-v1`；无DrillEntry/AngleTestResult，不计准确率与周目标。载荷冻结题面、标准答案、原始物理帧、真实事件/声音/捕获事实、首次有效尝试、最新一次试打、打点杆速、球姿态和3D观察机位。回放与恢复读取同一记录，不重新求解。未来默认物理模型改变必须迁移该记录格式；当前拒绝非平面格式，不能丢失空间段后伪装完整回放。

点击前只保存草稿输入，不发布预测或计算提示。点击冻结输入→完整求解→记录成功保存→幂等计首答/额度→显示实际整线→渲染首帧回执→1.5秒→标准出杆/运杆/真实播放。保存失败保留待保存的同一结果，重试保存不重算、不先扣题；求解失败无有效尝试。退出/后台取消代次及首帧回执，前台不补击球；播放中断按已冻结终态恢复。

目标与实际轨迹均以母球首次接触指定球为零时刻，保存时间与XZ米制位置。原始事件帧间按解析运动补曲线，保留事件端点；捕获后收球动画不进入轨迹。显示采用白色短虚线与橙色长线，2D/3D均贴同一实际台面。

## 权益

免费2D每天独立20题，3D和自由练习需要Pro。每题首次完整试打成功落盘计一次，失败进袋也算尝试；重打/回放/恢复不重复。额度耗尽仍允许最后一题重打与回放。3D不消耗2D额度。沿用既有商品、登录、购买恢复与订阅组件；不改价格。购买返回恢复原入口或待操作，已开始一杆在安全边界结束后再限制权益。

## 验证与限制

模拟器、单测、物理抽样及TP01–TP36证据独立登记，不能代替真机读屏、触感、声音与真实StoreKit交易。当前外部协议问题沿HUMAN-REQUIRED处理，不接受或提交协议。实现不以评分测试或生成图替代真实球桌截图。

## 评分追加决定

**2026-10-24 当前决定：用户审阅200组后批准 p=2 替换下述旧公式，2D/3D同步。** 新提交对首次接触指定目标球后的完整母球轨迹使用弧长加权、保序匹配的均方根距离：`D=sqrt(min∫||P(s)-Q(t)||²(ds+dt)/(Lp+Lq))`，分数仍为`100×2^(-D/20cm)`。采用已审阅的1cm物理弧长中点网格近似，内层直接计算坐标差平方；不增加尾段、库数或参数接近特例。版本为`arc1cm-rms-p2-t20-potgate-v3`，保存`rmsDistanceCM`和两条路径的网格数，新评分不伪填DTW/Fréchet字段。

母球落袋/目标球未进指定袋仍直接0分；只切换通过进球条件后的几何评分。两条均静止使用起点距离，一条静止仍计入另一条完整路径。后台计算支持取消。旧v1/v2冻结分数按旧字段解码，旧题可继续用新方法作答；回放、重进和历史不重算已存分数。SP01载荷版本/物理记录、首杆与本题均分聚合方式保持。验证见[接入记录](../tasks/ui-reviews/UR-20261024-separation-p2-score.md)。

以下为2026-10-22/23原决定的历史记录：

采用`d=0.7×平均DTW+0.3×离散Fréchet`（cm），`100×2^(-d/20)`。碰后路线按512等弧长点与碰撞锚点并集采样；版本、原始距离及样本数固化在可选score中。旧载荷兼容，旧杆不补算；新提交未碰球时，按未进指定袋计0分。结果展示本杆，汇总/历史使用首杆均分；自由续段累计和/数量延续，历史段不重复累计。2026-10-23用户追加：母球落袋或目标球未进指定袋直接0分（包括未接触），作为有效分数参与本题及首杆均分；通过进球条件后按轨迹相似度计算，不增加库序扣分。详见活动方案§10。

2026-10-23显示与重打统计追加：当前题轻量可选QuestionScores按shotID保存有效分数，用于本杆均分；回放/重复接受不重复计数，不改首杆历史/续段口径。旧载荷只恢复留存首杆/末杆，不伪造中间尝试；玩家速度0.5–8与出题至4.5分开。详情见活动方案§13。
