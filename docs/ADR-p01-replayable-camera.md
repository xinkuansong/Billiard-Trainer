# ADR：P01 可重放运镜试点

日期：2026-11-17—18。状态：已实施，本轮原生定向验证完成；未获用户体验认可，未推广。

依据：`问题集合_v67.md`、`tasks/camera-v67/B0-BASELINE.md`。用户授权在正式“分离角与走位”完成试点，其他页面保持现状。

## 问题与决定

旧凹面把高度与距离绑定，且 P01 方向尺改变杆向后机位没有同步跟随。新增纯值 `P01CameraMotion`，由既有 `CameraRig` 适配实际场景、输入及节点输出。`ShotCameraPolicy` 默认 `legacy`，在 PositionPlay 宿主内，MainTab 的两条正式 P01 路由显式传入 `p01Replayable`。空间练习独立使用同一基础内核。v67.8 由 PositionPlay 再显式开启锚定切镜，空间练习继续使用 v67.7 路径。

三种构图共用真实 cue/strike/aim/elevation。第三人称距离 1.65m、高度 0.65m 独立控制，杆轴水平居中、母球约位于视窗顶部以下 67%；横滑绕过母球的竖直轴，以固定半径、眼高、俯仰与视野转动。第一人称沿杆后退 0.90m，基础轴上眼高 0.13m，母球约 70%。进袋模式横拖时眼点固定，松手后朝向回正。自由瞄准横拖时眼点随真实杆向移动。全桌观察绕过桌心的竖轴，初始圆半径由房间短边净空决定，按台面近远端确定俯仰。进入时保持请求高度，按当前 HUD 和视窗为完整一周选定镜头。只有旧录制回放使用超椭圆半径和原输入增益。

一、三人称进袋横滑只观察，自由横滑和方向尺共用业务杆向；方向尺改向可进入手动自由。全桌横滑持续观察。连续改向更新同一回瞄准过渡的终点，不重启计时或锁住方向尺；多圈方向保持展开角度。业务模式、物理、成绩和球位仍由原宿主管理。

## 安全、时间和恢复

相机求值检查房间边界、台面最低高度和天花板；第三人称按绕母球完整一圈的可用净空限制实际半径，并保留请求距离。第一人称使用实际桌体网格检查母球轮廓，最多额外抬高 0.20m，修正量单独记录。无法求得合法机位时保留可见姿态并报告诊断，不 silently 改杆向。

模式切换采用五次平滑时间曲线、母球屏幕锚点与桌心之间的连续交接，按平移/转角/FOV 安排时长。一、三人称切换按母球起止投影逐帧求俯仰。手势接管从可见姿态重建参数。第一人称在切换途中被接管后，回正仍保持接管眼点，不返回尚未到达的旧目标。

快照与业务盘面代次绑定。临时俯视和 2D 纯查看恢复原姿态；编辑后旧锚点失效，使用当前有效引用。原杆重打/回放通过显式恢复盘面路径恢复其相机快照。出杆冻结站位引用，既有击球事件负责转观察。后台/离页取消所属过渡，保留当前可见姿态；不新增永久相机存档需求。

重放记录包含 schema、策略、几何标识、初态、视口/HUD、相机活动时钟、输入、实际遮挡修正及轨迹采样。30/60/120Hz 使用同一生产求值器比较 eye/forward/FOV。记录限定场景内存容量，DEBUG 可导出；这不是物理重算或 GPU 逐像素重放承诺。

## 隔离与验证

旧 CameraSurface/TwoViewCamera 保留。三条既有教学测试按既有同袋重选保留机位合同修订为严格完整姿态/模式比较；失效前提及旧宿主无diff证据见实施账本，不以新策略差异放宽旧页要求。Composer、FreePlay、VM、Rig 的省略策略参数均为 legacy。共享 Rig 的锚定切镜须由正式 P01 PositionPlay 配置显式启用。页面规范只在 P01 卡记录例外，TP17 不全局改写。

最终执行结果和源码身份以 `tasks/camera-v67/IMPLEMENTATION.md`、`tasks/table-page-adaptation/CAMERA-V67-STATUS.md` 为准。模拟器功能与视觉、真机手感、用户认可分别记账；用户优化完毕后仍需另行指令才制定推广。
