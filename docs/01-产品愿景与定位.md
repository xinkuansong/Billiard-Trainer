# 产品愿景与定位

## 1. 背景与问题

### 1.1 市场背景

中国国内台球热度持续上升，中式台球与斯诺克在业余爱好者中普及率快速提高。但「严肃训练 / 系统涨球」这一层在 C 端几乎是空白：现金流集中在 To B 的 AI 投影硬件（门店加盟，详见 `docs/research/20260617-AI台球投影系统-硬件竞品.md`），C 端只有碎片化短视频与娱乐游戏。

### 1.2 现有替代品的核心缺口

| 现有替代品 | 满足的需求 | 核心缺陷 |
|---|---|---|
| 专业培训机构 / 私教 | 系统课程 + 实体场地 + 个性化指导 | 门槛高（时间/费用/约课），普通爱好者难持续 |
| 短视频平台（抖音/B站） | 海量免费教学内容 | 碎片化、看完就忘、形不成体系；干扰严重 |
| 台球游戏 App | 娱乐对局、模拟练球 | 训练属性弱，娱乐导向，不训练真实「球脑」 |
| AI 投影硬件（小铁/客满台等） | 门店内瞄准线/走位可视化 | 重资产、绑场地、To B；多为「理想无塞线」、关掉就不会打 |

**核心痛点**：大量爱好者卡在瓶颈期（「老是清不了台 / 走位走死」），但**说不清自己缺的是「线路/走位/战术的思路」**；短视频拼不出体系，私教又没时间/条件。市场缺一个**低门槛、系统化、能练「球脑」**的训练工具。

## 2. 产品愿景

打造一款面向台球爱好者的 **「练脑型」系统化训练 App**：把系统教学、交互式练习与训练记录整合为「学练记」闭环，帮助瓶颈期爱好者在不依赖私教、不被短视频干扰的前提下，建立线路 / 走位 / 战术的系统化思路并持续提升。

中长期愿景：成为中文台球爱好者认可的首选「涨球」训练工具；远期可选向培训机构与硬件/内容生态延伸（见 §6）。

## 3. 目标用户与定位

### 3.1 主力用户（v1.0 聚焦）— 中间层「瓶颈期爱好者」

- **画像**：常打（每周 1–3 次）、有提升意愿、卡在瓶颈期；靠刷短视频拼不出体系、又没时间/条件请私教。
- **关键特征（也是最大获客难点）**：需求是**潜在而非显性**——他们能感到「赢不了/走死」，但不会主动搜「走位思路训练」。
- **结论**：这是基数最大、真实痛点存在、却被现有替代品忽略的一层；用户教育（创造需求）是触达他们的关键（见 §5）。

### 3.2 次级用户 — 进阶玩家 / 业余联赛参赛者

- 已知道自己需要思路与数据训练，付费意愿高，但**人数小**，作为高客单补充而非主力。

### 3.3 远期用户 — 培训机构教练（v2.0）

- B 端逻辑（多角色/机构账号），v1.0 不覆盖。

### 3.4 与现有替代品的区隔

- vs 短视频：系统化、可练（交互式）、可记录复盘，减少干扰。
- vs 私教：线上化、低门槛、自主节奏。
- vs 游戏：训练真实「球脑」（线路/走位/战术决策），非娱乐模拟。
- vs AI 投影硬件：零硬件门槛、随身可用；**诚实区分「理想薄厚点」与「带塞修正」**，讲清「为什么这么瞄」，而非一条会让人依赖的投影线。

## 4. 价值主张

**「看得懂、练得到的台球训练 App」** —— 学练记闭环：

- **系统教学（学）**：动作库 + 官方分级计划 + 角度/解球原理，把零散知识变成体系。
- **交互式练习（练）— 护城河**：物理引擎驱动的「练脑」工具（分离角与走位、走位反解、斯诺克做杆、球形生成、拍照建球形、角度训练）。
  - **关键原则**：手机练不了真实出杆手感，只练 **线路判断 / 几何角度直觉 / 战术决策**；定位为真实球台练习的「课前预习 + 课后复盘」，**不替代真实击球**。
- **训练记录（记）**：日志 + 历史日历 + 统计，作为习惯黏合与复盘。

> 三者的价值不在各自，而在**连成环 + 数据驱动个性化**（练习结果回灌记录、记录驱动教学推荐）——这是短视频与硬件都做不到的，也是后续产品重点。

## 5. 增长策略：用户教育 = 创造需求

- 目标用户需求潜在，**用户教育的真正作用是「把模糊挫败感命名成具体可解决的问题」，产品再作为答案**——故教育是本产品最优且几乎唯一可行的获客方式。
- **独特优势**：产品的物理引擎 + 教学素材渲染管线能**近零成本量产**别人做不出的可视化讲解内容，天然适合内容驱动获客。
- **硬前提**：需补一个**有台球可信度的真人 IP / 面孔**（纯引擎动画立不住权威，台球是强 KOL 领域）。
- **产品侧配合**：新用户前几分钟需有「啊哈时刻」（如：拍照建球形 → 让用户先决策 → 引擎正解对比揭示盲区 → 第一个小胜），否则会被当成「画线工具」流失。

## 6. 成功指标（待真实数据校准）

> ⚠️ **最高优先级待验证假设**：目标爱好者是否愿意为训练工具付费。建议尽早用最小成本验证（落地页/问卷/课程预售）后再定量化目标。

候选北极星与过程指标（草案）：
- 激活：新用户首日完成 ≥1 次交互式练习并经历「啊哈时刻」的比例。
- 留存：周活跃练习用户的次周留存。
- 转化：免费→付费转化率（订阅/买断），及内容渠道→下载的转化。

## 7. 明确不做什么

- 不做在线实时对战 / 娱乐对局。
- 不做通用社交平台（关注/动态/广场）。
- v1.0 不做培训机构 B 端管理。
- 不自建视频直播。
- **不再扩物理引擎新功能**（2D 物理已够教学用；跳球/扎杆腾空等投入大、回报不确定——工程纪律，2026-06-18）。

## 8. 商业价值与可选上行（诚实判断）

- 作为**独立 C 端订阅 App**，天花板偏低（付费意愿是命门、台球训练 C 端盘子小）；定位收敛与教育驱动可改善获客与留存，但不改变盘面。
- **真正值钱的是「物理/几何引擎 + 内容渲染管线」本身**，构成被掩盖的价值岔路（远期可选，不影响把 App 做好）：① 反向供给硬件/门店赛道当「算+教」软件层；② 当内容生产工厂；③ 绑可信教练 IP 转化为内容权威；④ 诚实几何教学做差异化。
