## 1. 问题与做法

要回答的不是再画一张分离角图，而是：

- 切角、力度、母球旋转，怎样改变**母球路程**和**目标球路程**；
- 两者的比 \(\rho = L_\text{母}/L_\text{目}\) 有没有简洁规律；
- 职业球员台上如何把「该用多大力」做出来。

路程由四段因果串起来，不宜一上来三维网格盲扫：

```
击杆 (V0, 打点)  →  碰前台呢改 (v,ω)  →  球-球碰撞分光  →  碰后滑/滚停
                                                              ↘ 吃库则 Han2005 改写后再滑/滚
```

本引擎对应真源：

| 段 | 代码 | 对路程的含义 |
|---|---|---|
| 击杆 | `CueBallStrike` | 打点 ≠ 碰时旋转；近距和远距同一打点，碰时状态不同 |
| 台呢 | `AnalyticalMotion`（μ_s=0.2，μ_r=0.01） | 滚动停距 \(s=v^2/(2\mu_r g)\)；滑动段可转弯 |
| 球-球 | `CollisionResolver.resolveBallBallPure`（e=0.95，Alciatore \(u_b\)） | 定杆近似 90° 分光；跟 / 缩不是 |
| 吃库 | `Han2005CushionModel`（e_c=0.94，正撞有效法向速约 80%） | 因 \(L\propto v^2\)，正撞后剩余路程大约 ×0.64 |

无库时整条链是闭式的，应用公式推，引擎只对拍。吃库没有同样简洁的闭式，做成「公式 + 入射角表」。

### 1.1 坐标与度量（必须先钉死）

- 坐标系：SceneKit，台面 XZ，+Y 朝上，单位米。
- 切角 φ：瞄准线与连心线夹角，0°=直球，90°=无限薄。
- **V = 碰时母球线速度**，不是杆头速度 V0。近距、水平、中心击：\(V \approx 1.54\,V_0\)（`CueBallStrike`：\(v=2V_0/(1+m/M)\)，\(m=0.170,\ M=0.567\)）。满高 / 满低杆线速度更小，约 \(V\approx 1.04\,V_0\)。
- 路程 = **碰后弧长**。母球不含碰前那段。不用起终点位移（缩 / 跟会转弯）。
- 「旋转」以**碰时 (v, ω)** 为准。近距可贴上把打点当成碰时状态；远距中杆会滚起来。

## 2. 无库停距：两球共用 \(L=C|v'|^2\)

### 2.1 假设（定杆主律）

1. 等质量，目标球碰前静止。
2. 近距定杆：碰时母球 ω≈0，目标球 ω=0。
3. 先忽略球-球切向摩擦（只要法向 e）。Alciatore \(u_b\) 是后面对拍修正。
4. 碰后两球都是「无初旋、沿自己速度滑，再滚到停」。无库。

第 4 条保证两球走同一个 \(L=C|v'|^2\)，C 在相除时消掉。

### 2.2 碰撞分光

碰前母球：\(v_n=V\cos\phi\)，\(v_t=V\sin\phi\)。

\[
v'_{\text{母},n}=\frac{1-e}{2}V\cos\phi
\qquad
v'_{\text{目},n}=\frac{1+e}{2}V\cos\phi
\]

无切向摩擦时切向不换：\(v'_{\text{母},t}=V\sin\phi\)，\(v'_{\text{目},t}=0\)。

\[
|v'_\text{目}|=\frac{1+e}{2}V\cos\phi
\qquad
|v'_\text{母}|=\sqrt{\Bigl(\frac{1-e}{2}V\cos\phi\Bigr)^2+(V\sin\phi)^2}
\]

e=1 时母球只剩切向，两球速度垂直（90° 分离）。本引擎 e=0.95：\((1+e)/2=0.975\)，\((1-e)/2=0.025\)。

### 2.3 无初旋滑→滚停距

碰后无旋，底面滑移就是线速度。滑动既减速，也把角速度往滚动攒：

\[
\frac{dv}{dt}=-\mu_s g,\qquad
\frac{d\omega}{dt}=\frac{5}{2R}\mu_s g
\]

滚动条件 \(v=\omega R\)，\(\omega_0=0\)：

\[
t_{sr}=\frac{2|v'|}{7\mu_s g},\qquad v_\text{roll}=\frac57|v'|
\]

\[
L_\text{滑}=\frac{12}{49}\frac{|v'|^2}{\mu_s g}
\qquad
L_\text{滚}=\frac{25}{98}\frac{|v'|^2}{\mu_r g}
\]

\[
L=C\,|v'|^2,\qquad
C=\frac{12}{49\mu_s g}+\frac{25}{98\mu_r g}\approx 2.73\ \mathrm{s^2/m}
\]

（μ_s=0.2，μ_r=0.01，g=9.81。）  
若误当成「碰后立刻在滚」，C 会变成 \(1/(2\mu_r g)\approx 5.10\)，绝对路程虚高约一倍，**比值仍然一样**——只要两球都用错同一套。

跟 / 缩时 \(\hat u\) 不沿 v，路径弯曲，不能再用这个 C；停距仍有闭式（常加速段积分 \(|v_0+at|\)），只是不漂亮。

### 2.4 相除：C 和 V 一起消掉

\[
\rho=\frac{L_\text{母}}{L_\text{目}}
=\frac{|v'_\text{母}|^2}{|v'_\text{目}|^2}
=\frac{\sin^2\phi+\bigl(\frac{1-e}{2}\bigr)^2\cos^2\phi}
{\bigl(\frac{1+e}{2}\bigr)^2\cos^2\phi}
\]

力度 V 不出现：两边都 ∝ V²。

- **e=1**：\(\rho=\tan^2\phi=\sin^2\phi/\cos^2\phi\)
- **e=0.95 完整式**：\(\rho=(\sin^2\phi+0.000625\cos^2\phi)/(0.950625\cos^2\phi)\)
- **e=0.95 口诀**（φ≳15°）：\(\rho\approx 1.05\tan^2\phi\)

直球必须用完整式：φ=0 时 ρ≈0.00066，不是 \(\tan^2 0=0\)——母球还有 \((1-e)/2\) 的法向反弹。

三条主律（定杆、无塞、无库）：

1. **目标球只看厚度和碰时速度**：\(L_\text{目}\approx C(0.975\,V\cos\phi)^2\)
2. **路程比只看切角，与力度无关**
3. **要改这个比，靠切角和杆法，不靠加力**

绝对米数是「无限台呢等效」。μ_r=0.01 很滑，中力直球目标球等效可走数十米；真台 2.54 m，无库只能走到库边。**有用的是比例。**

## 4. 加上母球旋转

旋转一加，就不能再用一条 \(\tan^2\phi\)。**目标球路程几乎不动**（各杆法只差几个百分点，仍 ∝ cos²φ）；变的是母球，所以 ρ 按碰时杆法族分列。

### 4.1 杆法族 \(k=\omega/\omega_\text{滚}\)

碰时线速度相同。近距水平杆与打点 b 的关系（计算）：

| 打点 b | k | 名称 |
|---|---|---|
| 0 | 0 | 定杆 |
| +0.40 | +1.00 | 自然滚 |
| +0.50 | +1.25 | 满跟（打滑极限） |
| −0.40 | −1.00 | 缩 |
| −0.50 | −1.25 | 满缩 |

远距中杆应按「自然滚」查，不能按「定杆」。查表用碰时状态，不是出杆打点。

### 4.2 各族简化式

| 杆法 | 简化式 | 直球 ρ | 薄球 |
|---|---|---|---|
| 定杆 k=0 | \(\rho\approx\tan^2\phi\) | ≈0 | 就是 tan² |
| 自然滚 k=1 | \(\rho\approx 2\tan^2\phi+0.18\cos^2\phi\)（拟合） | ≈0.18 | 约 **2 tan²** |
| 满跟 k=1.25 | \(\rho\approx 2.4\tan^2\phi+0.29\cos^2\phi\)（拟合） | ≈0.28 | 约 **2.3 tan²** |
| 满缩 k=−1.25 | 母球路程几乎不随切角变；\(\rho\approx 0.22/\cos^2\phi\)（粗） | ≈0.22（往回走） | 升得比定杆慢 |

交叉：大约 **30° 以前** 缩杆 ρ 大于定杆（直球也能拉回）；**30° 以后** 定杆超过缩杆（缩把切向剩余吃掉）。跟 / 滚在所有切角都比定杆大。

口诀：

- 目标球看厚度，几乎不看杆法。
- 定杆：比值 = (sin/cos)²。
- 跟 / 自然滚：厚球有一块「底」（直球也能跟出去），薄球大约是定杆的 2～2.4 倍。
- 缩：厚球母球有固定一截回拉；越薄，缩越压低比值。

力度在同一族里仍大致消掉（计算：φ=30°，V 从 1.6 到 5.8，自然滚 / 满跟的 ρ 几乎平底；定杆 / 缩因 \(u_b(s)\) 略漂）。

## 5. 吃库（未做，只留接口）

无库层完成后再叠。不要一上来摆真实走位局。

- **一库**：隔离单次吃库。η(α, 侧旋) = 吃库后路程 / 若无库还能走的路程。正撞、无塞预期 η≈0.64（法向速约剩 80%，\(L\propto v^2\)）。越贴库 η→1。目标球与母球用同一张 η 表（Han 只看 (v,ω)）。
- **两库**：先验证 \(L\approx L_\text{开桌}\cdot\eta_1\cdot\eta_2\)。第一库会改 ω，第二库不能拿无旋表硬查。袋口圆角恢复系数更低，规律层先用直库中段。

## 6. 职业球员如何精准控力

台上没有人把切角代进公式。Mosconi 把速度控制看成拉开档次的核心技能；职业判断是：

1. 先选路线和落位区（倒推：下一颗怎么打，母球该停哪一带）；
2. 从记忆里调出 **Speed Picture**（母球、目标球、目标区）；
3. 用**出杆长短**把档位做出来，试杆校准；
4. 能用几何容错就不用把力度拧到毫米级。

公式解释**为什么**某厚度 + 某杆法会走到某距离；职业把同一件事压成「见过的画面 + 出杆长度」。

### 6.1 先让力度不必那么准

Matt Poland（经 Dr. Dave 站点）：**「先做到不需要精确控力，再追求精确控力。」**

| 做法 | 作用 |
|---|---|
| 顺着落位区进，不横穿 | 力度偏一点仍停在区里 |
| 走位区做长、靠近台心 | 下一杆容错大 |
| 母球少走 | 只练口袋速度附近一小段 |
| 贴库停改成「稍重一档撞库再停」 | 库吃能，容差大约放大一倍（T04） |
| 能中杆高低杆解决，就少加塞 | 侧塞吃库会突然加速或刹死 |

「精准」常常是选了一条不要求精准的路。

### 6.2 认知：连续力度收成档

Phil Capelle《Play Your Best Pool》**Spectrum of Speeds（1–9）**：

- 轻 1–3、中 4–6、重 7–9。整数是锚点，熟了用 4.8、5.3 微调。
- **蹲下去之后不再想数字**；数字只用于学习和排除。

挑档用排除法（高尔夫选杆同构，已落地 T04）：

1. 看清速度画面（三位置）
2. 「这一档过了吗？」定上界
3. 「这一档够吗？」定下界
4. 窗口里只剩 1–2 档，选定
5. 按出杆长度执行，不靠「再加把劲」

能低档完成绝不用高档。训练优先打熟中段 4–6。本 App 五档杆头速度：

| 档 | 杆头速度 | 典型用途 |
|---|---|---|
| 轻 | 1.6 m/s | 近距走位 / 防守 |
| 中轻 | 2.4 m/s | 轻走位 |
| 中 | 3.3 m/s | 走位主力区 |
| 中重 | 4.4 m/s | 中长台分离 |
| 大力 | 5.8 m/s | 长台 / 强分离 |

### 6.3 动作：调出杆长度，不调「用力」

Dr. Dave（2020 *Speed Control*）：

> 要慢就缩短后拉，要快就加长后拉；全程匀加速送完，不要在触球前减速。

同一套加速曲线，只改变行程。配套：

- **轻力**：短架桥，限制手腕，短行程仍要加速送透（长杆匀速去「推」最难控）。
- **大力（7–9）**：加长架桥、试杆更平滑、触球时放杆、完整送杆。
- **握杆松**：死捏会切掉力度梯度。

斯诺克圈常把奥沙利文说成「杆速变加速」、希金斯 / 丁俊晖说成「拉杆长度匀加速」。共同点是可重复的加速曲线。此条中文归纳证据弱于 Alciatore / Capelle。

### 6.4 试杆是在编程这杆的感觉

Capelle：大量职业选手在有难度的走位上会走到下一杆站位、杆头指向母球要去的地方（如 Justin Bergman），站着空挥，蹲下后试杆的长度和节奏就是正式出杆的预演。运动系统不听「中力」口头指令，要想象母球滚多久才停。

### 6.5 记忆库是参照球

职业存的是「见过的同类杆」，不是公式表。校准（Alciatore）：

- 母球打到台面不同目标距离，击点约高 20%（跟杆更好控）；
- 落在目标左右各一颗钻石内算合格；
- 吃库后要明显加力；
- 每天开打先用口袋速度 / 半台 / 一库摸清这张台。

同一停点往往有多解：「软一点多缩」或「硬一点少缩」。远距停球必须带一点低杆（超过约 1 钻石，中杆路上已经滚起来）。他们选自己最稳的那组（打点 × 档位）。

### 6.6 和路程比怎么接

| 公式层 | 职业层 |
|---|---|
| \(L_\text{目}\propto(V\cos\phi)^2\) | 越薄，同样出杆目标球越没劲，要进袋或走位得加档 |
| 定杆 \(\rho\approx\tan^2\phi\) | 厚球母球少走、薄球母球多走——Speed Picture 自带 |
| 跟 / 滚 ρ 更大 | 同一档跟杆比定杆多走一截，用打点换距离，常常比加力更稳 |
| 缩杆厚球有「底」 | 直球也能拉回固定一截，轻档 + 低杆代替中档中杆 |
| 力度消掉、比只看切角和杆法 | 先定厚度和杆法，再在很小的档位窗口里挑 V |

职业很少先想「45° 该 1:1」，但长期训练后已经在肌肉里。

### 6.7 可练的压缩版

1. 路线先于力度：落位区顺着进；能借库刹车就借。
2. 只养 5 档出杆长度（对应 App 轻到大力），中档打到能重复。
3. 每天开台三杆校准：口袋速度、半台跟停、一库回头。
4. 试杆 = 正式杆的预演。
5. 先中杆高低杆，再加塞；加塞只当微调出库方向。

若接进球迹，产品落点不是让用户心算 ρ，而是：**选落位区 → 推荐档位 + 出杆长短示意 → 用试打校准这张台的快慢**。
