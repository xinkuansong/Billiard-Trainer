# 球迹｜中国商标注册：逐步操作手册

> 调研 / 成文：2026-08-26  
> 适用：中国大陆普通商品 / 服务商标（非集体、证明、地理标志），申请人已是公司。  
> 本次候选名：**球同学**、**球小练**（也适用于「球迹」或其他二字 / 三字中文文字标）。  
> 法律总论：[`20260820-中国商标注册入行与风险判断.md`](./20260820-中国商标注册入行与风险判断.md)  
> 检索作业：[`20260826-球迹候选名检索与风险判断.md`](./20260826-球迹候选名检索与风险判断.md)  
> 类似群与项目：[`20260826-球迹商标类似群选择.md`](./20260826-球迹商标类似群选择.md)  
> **本文是公开法规与官方文件的整理，不构成法律意见。** 花钱申请前必须做官方检索，并由有备案的代理或律师核对。

## 0. 先对齐

### 0.1 我理解的需求

把「从现在到拿到注册证」拆成每一步该做什么、交什么、看什么通知、错过会怎样。候选名按「球同学 / 球小练」写；类群沿用已定的第一批 9 / 41 / 42。

### 0.2 假设（任一条不成立，步骤会变）

| # | 假设 | 若不成立 |
|---|---|---|
| A1 | 申请人是**已领执照的公司**，不是个人 | 自然人须另附个体户执照，且囤标口径更严 |
| A2 | 只报**普通文字标**（黑白），Logo 另件 | 图文组合、指定颜色、声音标，材料与说明栏不同 |
| A3 | 第一批只报 **9 + 41 + 42**，每类 ≤10 个标准名 | 超项加钱；第二批 28 / 35 另走一遍 |
| A4 | 走**网上申请 + 接受电子发文** | 纸质每类 300 元，且补正 / 收文更慢 |
| A5 | 2026 年内提交 | 审查仍按 2019 年《商标法》；2027-01-01 后新案按 2026 年法（异议期从 3 个月改为 2 个月） |

### 0.3 事实 / 推测 / 未验证

| 类型 | 内容 |
|---|---|
| 事实 | 中国是申请在先。先用未注册，对抗力弱。 |
| 事实 | 专用权钉在「核准的标志 × 核定的项目」上，不钉在类似群号上。 |
| 事实 | 网上注册费每类 270 元（含 10 项），超项 +27 元。驳回不退官费。 |
| 事实 | 法定实质审查上限：收到申请文件之日起 **9 个月**。公告期现行 **3 个月**。 |
| 事实 | 2025-10-20 起新网上申请系统已上线，走统一身份认证，不再用软硬数字证书。 |
| 推测 | 「球同学」显著性优于「球小练」；二者都未做 TOAS，不能写低风险。 |
| 未验证 | 未打开 TOAS 检索任一候选名；未在官方商品项目查询核标准名。 |

### 0.4 整条时间线（一次通过、无异议）

```
定名 + 官方检索     1–3 天（你 / 姐姐本机做）
开账号 + 核项目     半天–2 天
提交 + 缴费         当天（验签 + 收到缴费通知后缴）
形式审查 → 受理     通常数周（补正则 +30 日窗口）
实质审查            法定 ≤9 个月（近年实务常见 4–7 个月）
初审公告            3 个月（2027 年起新案 2 个月）
发证                公告期满后数周
────────────────
合计经验值          约 9–12 个月拿到证
```

提交当天起就可以用 ™。**只有核准注册后**才能用 ®。受理通知 ≠ 专用权。

## 1. 提交前必须做完的事（不要跳）

这一段不做，后面填表等于盲打。

### 第 1 步：定主名，不要两个一起当主品牌

| 决策 | 建议 |
|---|---|
| 主品牌只留 **一个** 中文文字标 | App 名、备案名、应用商店、对外话术、商标主申请，用同一个词 |
| 另一个当备选 | 检索后更干净的那个升主名；另一个可以不报，或只报 9 类占位 |
| 文字与 Logo 拆开 | 第一批先报黑白文字。Logo 另件，不要只报图文组合 |
| 英文 / 拼音另件 | 要用 QiuTongXue / QiuXiaoLian 对外，再另报；不是中文的自动保护 |

两个名字都报 9+41+42 = 6 件，官费 1620 元，还要付两套代理费。**先检索，再决定报几个。**

### 第 2 步：第零关（名字本身能不能注册）

对照 [`20260820-商标起名规范.md`](./20260820-商标起名规范.md)。两个候选的初判见本文 §8。未过第零关就换名，不要检索。

### 第 3 步：官方商品项目查询核名

入口：中国商标网 / TOAS「商品/服务项目」。

对每一条候选标准名核三件事：**官方现在怎么写、落在哪个类似群、有没有「注」**。核不到就换该群里另一条标准名，**禁止自拟**「台球训练 App」「智能走位软件」。

第一批建议勾的方向（待核名，真源见类似群专文）：

| 类 | 群（只用于检索，申请书不填） | 优先勾的标准名方向 |
|---|---|---|
| 9 | 0901 | 可下载的手机应用软件、可下载的计算机应用软件、计算机程序（可下载软件）、计算机软件（已录制）、电子出版物（可下载）、可下载的影像文件；查询仍在则加「用于虚拟环境的可下载应用软件」 |
| 41 | 4101 + 4105（三） | 教育、培训、教学、体育教育、**通过模拟装置进行的培训服务**、辅导（培训）；4105（三）至少 `健身指导课程`、`私人健身教练服务` |
| 42 | 4220 | 软件即服务（SaaS）、提供在线不可下载的计算机软件、手机应用软件的设计和开发、云计算、**计算机模拟模型的设计** |

**不要勾：** 0901 里的鼠标 / 键盘 / 电脑；0910 训练器械 / 电子运动训练模拟器；4105（二）在线游戏；4220 的 AIaaS（无使用意图）。

检索必须整群 + 「注」里的交叉群（0901 兼查 0908）。申报只报真实生意，每类尽量用满 10 个贴生意的标准名。

### 第 4 步：TOAS 官方近似检索

入口：<https://toas.sbj.cnipa.gov.cn>  
作业模板：[`20260826-球迹候选名检索与风险判断.md`](./20260826-球迹候选名检索与风险判断.md) 附录 C。

**不要把商标网账号密码发给任何人（含 AI）。** 检索在你本机做。

对每个候选名，第一批 9 / 41 / 42 各跑：

1. 完全相同  
2. 汉字（字形）  
3. 拼音 / 读音  
4. 包含在其它商标中  
5. 空群复核（该群已注册但查询类型没命中的，扫一眼文字部分）

再补库外：国家企业信用信息公示系统字号、App Store / 安卓、常用域名。

打档：任一高风险项成立，禁止用「整体还行」平均掉。第 9 类干净、第 41 类被占，必须分开写。

**未完成官方检索，不得写「低风险」，也不得交钱。**

### 第 5 步：决定谁提交

| 选项 | 何时选 | 你要准备什么 |
|---|---|---|
| **公司自行网上申请** | 姐姐或你愿意跟系统、能盯补正 / 缴费期限 | 执照 + 法人 / 经办人身份证 + 对公或个人缴官费 |
| **委托备案代理** | 要人盯驳回、异议、部分驳回分割 | 执照扫描件、公章、委托书、图样、项目清单；代理费另计 |

两种途径**审查速度一样**。代理的价值是检索报告、项目核名、收到驳回后 15 日内复审，不是「更快拿证」。

代理必须能在国知局「商标代理」名录查到。不要找只给「包过」承诺的中介。

## 2. 材料清单（按主体）

### 2.1 公司自行网上申请（你们的主路径）

| # | 材料 | 规格 / 注意 |
|---|---|---|
| 1 | 营业执照 | 与申请名义**一字不差**。网上申请通常上传清晰彩色扫描件 / 照片；执照上的名称、住所、统一社会信用代码后面都要填对 |
| 2 | 法定代表人身份证 | 开通法人用户、关联经办人时核验 |
| 3 | 经办人身份证 | 姐姐代办：在统一身份认证里把她加成经办人。每日 8:00–18:00 用居民身份证可按原流程注册；其他时段或其他证件要下「国家网络身份认证」App |
| 4 | 商标图样 | 见 §2.3 |
| 5 | 商品 / 服务项目清单 | 只填官方标准名，每类 ≤10 个免超项费 |
| 6 | 对公账户或缴费人信息 | 收到《缴费通知书》后再缴。网上申请接受电子发文：270 元 / 类 |
| 7 | 联系邮箱 + 能收件的地址 | 「国内申请人联系地址」用来收后续法律文件；填错会导致公告送达、错过期限 |
| 8 | 公司公章 | 网上申请多数步骤电子验签即可；若窗口 / 纸质补件、委托书，要盖章 |

网上申请**不必**再交一份纸质申请书。提交后也不用把纸质件补寄到商标局。

### 2.2 委托代理另加

| # | 材料 |
|---|---|
| 1 | 《商标代理委托书》（代理出模板），公司盖公章 |
| 2 | 营业执照复印件，盖公章 |
| 3 | 商标图样电子文件 |
| 4 | 拟申报类别 + 已核名的标准项目清单 |
| 5 | 申请人名义、地址、信用代码、联系人、电话、邮箱（与执照一致） |

### 2.3 文字标图样怎么做（第一批就用这个）

目标：一件**不指定颜色的纯文字标**。保护最宽，以后换字体、换颜色，仍落在这件文字权里。

| 项 | 要求（官方 FAQ + 实施条例口径） |
|---|---|
| 内容 | 只写「球同学」或「球小练」三个字，不要 Logo、不要英文、不要 slogan |
| 颜色 | **黑字白底**。不要指定颜色，不要渐变、描边、投影 |
| 字体 | 用常规黑体 / 思源黑体即可，不要手写花体（花体以后实际使用对不上，还可能被要出处） |
| 清晰 | 网上上传常见 JPG / PNG；纸质要求长宽 **5–10 cm**。电子件建议正方形、边长约 800–1500 px，四周留白 |
| 说明栏 | 纯中文常用字一般写「商标图样为标准汉字『球同学』，不指定颜色」即可。生僻字才需要出处 |

**不要做的事：**

- 把 Logo + 三个字做成一件「组合标」当唯一申请（别人单用这三个字，维权变难）
- 上传彩色 App 图标当文字标图样
- 提交后改字。图样错了只能重新申请，补正只能「更清晰、不改图」

Logo 图形标：另做一件，图样只放图形、不要字。等文字标检索过了再报，不挡第一批。

## 3. 开通账号（新系统，2025-10-20 后）

旧系统已不再接受新申请。入口会变，以当天中国商标网首页为准。

### 第 6 步：注册统一身份认证

1. 打开 <https://ggfw.cnipa.gov.cn/> 或 <https://sso.cnipa.gov.cn/am/#/login>  
2. 「立即注册」→ 先注册**个人**（你或姐姐，居民身份证，尽量在 8:00–18:00）  
3. 再开通 / 关联**法人用户**：填执照上的名称、信用代码、住所，上传执照  
4. 法人用户下「关联经办人」：把实际点鼠标的人加进去  
5. 手机下微信或支付宝小程序 **「国家知识产权局商标局网上服务」**  
6. 经办人在小程序里申请**手机证书**，自己设 PIN

官方说明：<https://sbj.cnipa.gov.cn/sbj/cjwtjd/202510/t20251011_36420.html>  
注册规则调整（2026-07-01）：<https://sbj.cnipa.gov.cn/sbj/tzgg/202606/t20260629_39605.html>

客服：公共服务平台 010-61073410；商标业务 010-63218500。

### 第 7 步：进入新网上申请系统

1. 中国商标网 <https://sbj.cnipa.gov.cn> → 「商标网上申请」→ **新网上申请系统**  
   备用登录：<https://toas.sbj.cnipa.gov.cn/toas-extra-prod/login>  
2. 用统一身份认证登录，确认当前身份是**公司**，不是个人  
3. 先点检索 / 商品项目查询，把第 3–4 步的结果截图存档（日期 + 查询式）

## 4. 填申请、提交、缴费

### 第 8 步：新建「商标注册申请」

系统字段按这个填（普通文字标、一标三类）：

| 栏 | 怎么填 |
|---|---|
| 申请人名称 | 执照上的全称，一个字都不能差 |
| 统一社会信用代码 | 执照 18 位 |
| 申请人地址 | 执照住所；若未写省市区，前面补上 |
| 国内申请人联系地址 | 能稳定收快递 / 理解文件的地址（可与住所不同） |
| 联系人 / 电话 / 邮箱 | 姐姐或你；邮箱要能收到电子文书 |
| 共同申请 | 否 |
| 商标申请声明 | 普通商标**不要**勾集体 / 证明 / 三维 / 颜色组合 / 声音 |
| 商标类型 | 文字商标 |
| 是否指定颜色 | 否 |
| 商标图样 | 上传黑白三字图 |
| 商标说明 | 见 §2.3 |
| 优先权 | 无，则不选 |
| 类别 | 9、41、42（一标多类；官费仍按 3 类计） |
| 商品 / 服务项目 | **只从系统标准库勾选**，不要手打广告词 |

可先「暂存」。三类都勾完再统一提交。新系统支持勾选多件暂存后**一次验签批量提交**。

提交前核对三遍：名义、图样、三类项目。交出去改不了字、改不了图。

### 第 9 步：手机扫码验签

页面弹出二维码 → 经办人用已装证书的小程序扫 → 输入 PIN。  
扫码的人必须是当前业务的经办人，换个人的小程序会失败。

### 第 10 步：等缴费通知，再付钱

2019-12-30 之后的申请：**先审形式，再发缴费通知，期限内缴清才受理。** 拿证时不再收费。

1. 在系统「待办 / 缴费」或小程序看《缴费通知书》  
2. 按通知金额缴：网上、接受电子发文 = **270 元 × 3 类 = 810 元**（每类 ≤10 项）  
3. 超项：每项 +27 元  
4. 保存电子票据

官费标准页：<https://sbj.cnipa.gov.cn/sbj/sbsq/sfbz/>  
缴费指南：中国商标网「商标业务缴费指南」（2025-11-03）。

**逾期不缴 = 视为未缴纳 = 不予受理。** 官费缴了以后，驳回也不退。

## 5. 交出去之后，每一步你要做什么

下面每张通知都有法定期限。自己办就设日历提醒；代理办也要自己看一眼系统，不要默认「代理一定会盯」。

### 第 11 步：形式审查 → 受理或补正

商标局先看：手续齐不齐、图样清不清、项目名称规不规范、钱缴了没有。

| 结果 | 你做什么 | 期限 |
|---|---|---|
| 《受理通知书》 | 记下申请号。此后用申请号查状态。可以继续用 ™ | — |
| 《补正通知书》 | **只改通知点名的那一项**。回复补正不收费。图样不清晰可以换更清晰的同一张，不能换字 | 收到之日起 **30 日**；逾期或不按要求 = 不予受理，申请日丢掉 |
| 《不予受理通知书》 | 已缴费的按通知看是否退费或如何处理。常见原因：名义与执照不一致、未缴费、项目无法划分类别 | — |
| 《缴费通知书》 | 见第 10 步 | 通知载明的期限 |

申请日 = 商标局**收到**申请文件之日（数据电文 = 进入电子系统之日）。补正合格的，保留原申请日。

网上申请后，中国商标网状态查询有时要 **1–2 周**才看得到记录，不是没交上。

### 第 12 步：实质审查（法定 ≤9 个月）

审查员查两块：

1. **绝对理由**：禁用（第 10 / 15–16 条）、无显著特征（第 11 / 17 条）  
2. **相对理由**：同一种或类似商品上，与在先申请 / 注册标相同或近似（第 30–31 / 20、35 条）

| 结果 | 你做什么 | 期限 |
|---|---|---|
| 全部通过 → 初审公告 | 进入第 13 步 | — |
| **全部驳回** | 决定：换名重报，或驳回复审 | 收到通知之日起 **15 日**内申请复审；评审费网上 675 元 |
| **部分驳回**（某几项或某一类挂了） | 可申请**分割**：过的部分先拿去公告，保住申请日；挂掉的部分再决定复审或放弃 | 收到部分驳回之日起 **15 日**内。新系统可在待回文里「商品/服务分割」在线提交 |

15 日极短。自己办的，受理之后每周登录一次系统 + 小程序打开临期提醒。

复审不是「再交一次申请」。要写理由、比近似、必要时补使用证据。这一步建议代理或律师写，不要 DIY 一段话应付。

### 第 13 步：初步审定公告（现行 3 个月）

任何人可提异议（在先权利人、利害关系人、任何人，理由不同）。

| 情况 | 你做什么 |
|---|---|
| 无人异议 | 等期满核准 |
| 被异议 | 收到答辩通知后 **30 日内**答辩；声明后 3 个月内可补证据。异议费由异议人缴（网上 450 元） |

2027-01-01 起新案公告期改为 **2 个月**。2026 年内提交的，仍按 3 个月准备。

### 第 14 步：核准注册、领证

公告期满无异议，或异议不成立 → 核准注册，发《商标注册证》，再公告。

- 有效期 **10 年**，自核准注册日起算  
- 专用权范围 = 核准的标志 × 核定的项目  
- 这时才有权用 ® 或「注册商标」  
- 电子证 / 纸质证以当时送达方式为准；补发网上 450 元

被异议后才准予注册的，专用权起算点为初审公告期满之日。

## 8. 「球同学」和「球小练」怎么选

**本节不是核准结论。** 公开网页检索 ≠ TOAS。没跑完第 4 步，两个都不能标低风险。

### 8.1 第零关（显著性）

| | 球同学 | 球小练 |
|---|---|---|
| 结构 | 「球」+「同学」 | 「球」+「小练」 |
| 类型（初判） | **暗示**：像一个陪你打球的同学，没有直接说「训练软件」 | **偏描述**：「练」就是训练；「小练」像「小小练习」 |
| 第 11 / 17 条 | 通常过得去；「同学」不是本商品通用名 | 审查员有空间主张「仅直接表示用途 / 内容」。至少记 **M2**，是否升 H2 等代理看审查实践 |
| 作主品牌 | 更好记、更像品牌 | 更像功能名或栏目名，长期弱 |

「球」单字在台球商品 / 训练服务上显著性弱，两个名字都靠后两字拉开。后两字里，**「同学」优于「小练」。**

### 8.2 公开渠道（2026-08-26，仅网页，未验证）

| 对象 | 网页上看到的 | 含义 |
|---|---|---|
| 球同学 | 未见同名台球 App | **不能**据此认为商标库也空 |
| 球小练 | 未见同名 App | 同上 |
| 邻近品牌 | **球小二**（台球用品 / 馆维电商）、球友汇、球客网、球遇 | 「球小练」与「球小二」同行业、「球小 X」结构接近，**TOAS 必须把「球小二」「球小*」查进报告** |
| 「XX同学」 | 教育培训里很常见 | 「球同学」在 **41 类**必须把「同学」被包含、汉字、拼音跑完，不要只查三字完全相同 |

### 8.3 每个名字 TOAS 至少查这些要素

**球同学**

- 中文：球同学、同学、球同  
- 加缀：球同学科技、球同学体育、球同学官方、球同学 Pro  
- 拼音：QIUTONGXUE、QIU TONG XUE、QTX  
- 同音 / 近音：球童学、球同雪、球铜学  
- 库外：公示系统字号「球同学」「同学」+ 台球 / 软件 / 教育；App Store「球同学」

**球小练**

- 中文：球小练、小练、球练  
- 必须加查：球小二、球小、小练  
- 加缀：球小练科技、球小练 Pro  
- 拼音：QIUXIAOLIAN、QIU XIAO LIAN、QXL  
- 同音：球小连、球小莲  
- 库外：字号 + 应用商店「球小练」「小练」

两类都按检索文第一批五格打：0901（兼 0908）、4101、4105（三）、4220，外加空群。

### 8.4 决策规则（检索之后用）

1. 第零关或任一第一批类出现 **H** → 这个名字不作主品牌。  
2. 两个都没有 H、只有一个有 M → 选 M 更少、41 类更干净的那个。  
3. 两个都干净 → **优先球同学**（品牌像品牌，描述性更弱）。  
4. 不要用「球同学练」「球小练同学」拼接降风险，完整包含规则会把你拖回被包含的那个标。  
5. 「球迹」若仍作产品名，必须单独跑完附录 C。**产品名、备案名、商标名必须同一套**；商标报「球同学」、商店还叫「球迹」，两头都弱。
