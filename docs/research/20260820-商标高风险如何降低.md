# 商标高风险如何降低（中英文）

> 配套：[`20260820-中国商标注册入行与风险判断.md`](./20260820-中国商标注册入行与风险判断.md) §7  
> 检索作业与报告：[`20260826-球迹候选名检索与风险判断.md`](./20260826-球迹候选名检索与风险判断.md)  
> 先对号入座 H1–H9，再选动作。 **换缀、换类、加 Pro，通常降不了高风险。**

核心：绝对理由只能换标；相对理由要么把标志改到「读音 / 字形 / 含义」都不像，要么先清掉在先权。中文改了，对应英文 / 拼音一并改。

---

## 1. 按类型处理

| 编号 | 高风险 | 有效降风险 | 无效或很弱 |
|---|---|---|---|
| H1 | 禁用：国名地名、官方、欺骗、不良影响 | **整词换掉** | 改字体、加®、改一个字留词根 |
| H2 | 仅通用 / 仅直接描述 | 换臆造主名；描述词降为副标 | 加「牌 / 科技 / App / Pro」 |
| H3 | 同类同群 **相同** 在先标 | 换全新主名；或受让 / 等其注销后再报 | 加空格、大小写、横竖排 |
| H4 | 读音 / 字形 / 含义高度接近 | 三项都拉开；中英拼音一起改 | 只改形近字；中文改英文音译留下 |
| H5 | 完整包含或摹仿知名标 | 去掉被包含的名牌，另起炉灶 | 球迹Pro、QiuJi Official、名牌+中国 |
| H6 | 他人作品 / 字号 / 姓名 | 原创；或拿书面授权再申请 | 「我改了颜色」 |
| H7 | 代理商 / 前员工 / 合作方抢注关系 | 停用；协商转让；对方同意你注 | 换主体自己再报同一标 |
| H8 | 类别远超经营、像囤积 | 只报真实业务 +  Tight 延伸类 | 再多报几类「防御」 |
| H9 | 摹仿驰名、跨类也危险 | 放弃该方向 | 躲到不相近类别继续傍 |

依据：2019 第 4、10–11、13、15、30–32 条 / 2026 第 15–17、19–22、24 条；指南「完整包含或摹仿」。

---

## 2. 改名：怎样才算拉开（中英文一起做）

须 **同时** 满足，否则仍可能判近似：

1. **读音不同**：中文声调韵母都变；英文不是原中文拼音 / 旧英文谐音。  
   反例：球迹 → 球记 / QiuJi / QIUEE。
2. **字形不同**：不是多一笔、换形近字、拆字重组。
3. **含义不同**：不是同义、反义成对、中英互译。  
   反例：快球 → FastCue；球迹 → Ball Trace（若审查认为对应）。
4. **不完整包含**旧标或他人知名标。
5. 新中文、新英文、新拼音 **三套再检索**，不是只查新中文。

改完仍像同一家族（系列商标），按指南仍可驳。

---

## 3. 不换名时的路（贵、慢、不保证）

只在「这个字必须留」时才走。成功前 **不要对外锁死品牌**。

| 手段 | 适用 | 注意 |
|---|---|---|
| 缩商品 / 换类似群 | 引证只占部分群 | 保护变窄；诉讼仍可能突破区分表 |
| 分割 | 部分商品被驳 | 收到部分驳回后 **15 日** 内申请 |
| 撤三 | 引证满 3 年无使用 | 须证据；成功前路未清。2019 年法撤三后还有 **一年隔离**；2027 年起隔离主要针对主动注销 |
| 无效 | 引证违反绝对 / 相对理由 | 相对理由一般须注册日起 5 年内；驰名恶意除外 |
| 异议 | 对方在公告期 | 2019：3 个月；2027 起：2 个月 |
| 购买 / 受让 | 对方肯卖 | 近似标须一并转；易混淆转让可不核准 |
| 共存协议 | 审查个案 | 实质审查阶段常不采；不能救禁用、傍名牌 |
| 在先使用抗辩 | 你先用且有一定影响 | 只能在原范围继续用，不是去注册的通行证 |

---

## 4. 已对外用了高风险名

1. 立刻停用 ®，未注册不要冒充注册。  
2. 评估：继续用是否侵权（2019 第 57 条 / 2026 第 72 条）。同类相同 = 最高危。  
3. 能换则换，应用商店、域名、主体名一起改。  
4. 必须留旧名：谈受让，或准备撤三 / 无效，同时启用新主品牌过渡。  
5. 从合作关系里拿来的标：先处理权属，再谈注册。

---

## 5. 最低成本顺序

```
H1/H2/H5/H9 → 直接换主名（中+英+拼音）
H3/H4       → 优先换名；非留不可再撤三/买/无效
H6/H7       → 停用或拿授权/转让
H8          → 砍类别，只留能解释经营需要的
改完         → 三语检索 → 低风险再提交
```

英文不是「中文被占后的逃生口」。中文高风险，其拼音和意译通常也高风险。
