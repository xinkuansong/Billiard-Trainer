## 0. 一句话结论（最诚实的版本）

> 球迹**「活下来」可信**；但「**1–2 年营收做到千万级**」在当前「1 人/小团队 + 专注 C 端 App」假设下**没有被证据支持的可达路径**，需用户在「放宽时间 / 引入 B 端 BD·融资 / 降低目标」间拍板；「**千万下载**」是更长线（数年）、低概率、需跨端 + 真人 IP + 内容机器的**独立目标，不是 1–2 年千万营收的必要条件**。当前最该做的不是再想一个增长回路，而是**把训练内核内容补到位（Drill 现状 1/72 COMPLETE）+ 做出可信的口袋教练 + 跑正单位经济**。

## 1. 定位（簇 0，已回溯定稿）

- **品类**：台球**决策反馈引擎 / 口袋教练**（练脑型），在不可动资产（物理引擎 / 训练 Tab / 动作库）之上生长。
- **承重墙修订**：原「双产品 = 楔子病毒玩具 + 深水训练器，同一机制同时解决千万下载与千万营收」**作废**。新表述为**分阶段路线**：

| 阶段 | 形态 | 主要验证 |
|---|---|---|
| **阶段 1（先活下来）** | 单产品：训练内核 + 口袋教练 + 首启啊哈 + 埋点 | 单位经济（KT-G1/G2/G3、KT7-B、KT6） |
| **阶段 2（找增长回路）** | 决策向楔子「每日球局」+ 球商段位 | 转化桥/传播（KT4/KT5） |
| **阶段 3（破圈/上行，全 evidence-gated）** | 娱乐楔子(判官/鹰眼) / 外置小程序·H5 / 跨端 / B 端授权 / AR | 各自闸门（KT-BD、版号、KT-U/M） |

- **关键纪律**：千万下载与千万营收**解耦为两条独立路径、不同时间尺度**（见 §6）。

## 2. 引擎红线 + 可信度分层（簇 0，KT1/KT7-A 已用代码证据钉死）

读 `QiuJi/Core/PositionPlay/*`、`BTPhysicsConstants.swift`、`Homography.swift` 后定稿：

- **KT1**：单杆反解可行（秒级）；**整局自动规划清台顺序不可行**。所有「清台/对决/Wordle」只能是**单杆 或 人用编排台 authored 的有限步序列 + 引擎逐杆验证**。文案**禁用**「清台最优/精确胜率/精确力度塞/绝对停点」。
- **KT7 可信度分层**（决定什么能作付费核心）：

| 反馈层 | A 类可信度 | 能否作付费核心 |
|---|---|---|
| 方向/拓扑/几何（进袋方向、分离角方向、翻袋瞄点、有无解、袋口选择、单杆建议方向/排序） | 有真实几何底座（对摩擦不敏感） | **候选可以，但须过 KT7-B 盲测 ≥80%** |
| 走位停点/落区（restRegion 反解） | 摩擦未拟合，绝对精度不可信 | 只给「大致落区/相对排序」 |
| 力度/塞绝对数值 | 不可信 | **永不作精确卖点** |

- 付费卖点定调：**「不会教你打错方向」**，而非「给你最优解」。球桌差异沿用 F19 思路交用户校准（缩小因子滑块），不假装 universal 答案。

## 3. 产品形态与功能（簇 2，已收口）

- **不新增 Tab**，复用现有 5 Tab（训练/动作库/角度/历史/我的）：
  - 口袋教练（答案之书）= 角度 Tab 工具区 6 个反解器（F14/F15/F18/F19/分离角/球形）**后端化收敛**为一个「方向答案」入口。
  - 决策向楔子（每日球局）= 训练 Tab 顶部可配置卡片（**不得挤掉「今日训练」默认首位**）。

- **首启啊哈（Predict-before-Reveal）**：预置经典球形 →「你觉得母球往哪走位/打哪袋更稳」用户先选 → 引擎揭晓建议方向 + 对比 → 第一个「原来如此」。
- **功能优先级（串行，1 人/小团队不可并行）**：
  - **P0a 口袋教练**（复用最多、风险最低、一身三角：转化桥+内核增值+付费核心；即使楔子被砍也不浪费 = 安全退路）
  - **P0b 首启啊哈**
  - **P1 每日球局楔子**（与 Drill 录制抢编排台产能，须错峰；阶段 2）
  - **P1 留存实验：口袋教练「今日一题」**（最小高频钩子，复用题型+Predict→Reveal，不做全网同题/排行榜/战绩格/题库运营）
  - **P2/砍**：娱乐楔子（判官/鹰眼）、外置端、B 端 SDK 完整化、AR（现做不了，北极星）
- **资源保护线**：每 2 周迭代周期 ≥2 条 Drill 四件套至 COMPLETE，楔子冲突时**砍楔子不砍 Drill**（数字须挂钩 `curriculum-map §6` 三参数待用户拍板）。
- **回写任务**：`docs/05` 角度 Tab 定义滞后于 `docs/04` 实际实现，须同步（KT-IA1）。

## 4. 商业 / 增长 / 留存（簇 3，已收口）

- **付费墙**：口袋教练高级/统计（gated KT7-B）+ 现有 Pro 边界；执行层永不收钱；**免费内容不可撤回**（docs/08 §4.3），免费/付费边界须一开始设计死。
- **定价**：先用现价（年¥88）验付费意愿（KT6 试用→付费 ≥10%），**证明「愿付费」再上探**（年¥128–198，仅对新功能/新用户）。LTV 停用 ¥0.48/下载·年，待真实 cohort 重算。
- **阶段 1 获客（无楔子病毒回路）**：内容引擎（主）+ **B2B2C 把口袋教练做成腰部博主「出片外挂」**（最现实杠杆，但依赖 KT7-B 可信度）+ 场馆桌边码（拍照看建议方向，本地 3 家试点）+ ASO + 私域。北极星 = **周新增激活**。
- **阶段 1 诚实定位 = 验证单位经济，非冲量增长期**：现实落点 20–60 万下载 / 年营收 ¥12 万–¥76 万；乐观 180 万（¥421 万）阶段 1 撑不起。
- **阶段 1 留存**：复用打卡 streak、角度测试每日挑战、训练计划连续性、今日一题；**G2（7日留存≥15%、MAU/下载≥8%）是最可能挂的 gate**，若不过则测「今日一题」是否提升 D7，否则下修预期。

## 5. 合规 + 护城河（簇 4，已收口）

- **合规**：阶段化天然把重风险（版号/UGC/年龄分级）压到阶段 2。阶段 1 训练工具合规风险低。阶段 2 上每日球局/分享/外置端前**必须过版号闸门**（大陆 App Store 游戏类+IAP 需 NPPA 版号/审批号，安卓更严）+ UGC 审核+肖像声明+年龄分级复评。段位避赌（基于决策质量、不引入真金/虚拟货币对赌）。
- **护城河强度 = 中等偏弱**：
  - **唯一结构性真壁垒 = 物理反解引擎**（娱乐物理算不出、CV 路线补不快），但**深而窄**——被 KT7（对外只能表达方向层、易被低配模仿）+ 标定缺失（绝对值不可信）双重削薄。
  - 内容产能（中等·经营性）、训练体系（**当前 1/72 是负债不是壁垒**）、中式本土化（弱，DrillRoom 已中文）、品牌词心智（远期）。
  - B 端短期是收入岔路**不是护城河**；唯「创作者基建平台」（远期、低概率）才有网络效应。
  - **结论**：能防住被新玩家快速从零完全复制，**防不住娱乐巨头用低配提示外壳分走增量流量**。真正拉开差距靠「反解引擎 × 内容体系补齐 × 长期经营」叠加 → **取决于团队能否长期经营，而非产品天生护城河有多宽**。

### 9.3 最便宜验证次序（Critic 修订）

1. **KT6-pre**：落地页/问卷/预售 —— 测「表述 + 价格锚点」（≈¥0、数天、零前提）。**负结果不枪毙产品（只能描述不能体验）；正结果只证明值得继续做 core。**
2. **KT7-B**：用现有反解器跑 20–30 个球形 → 专家盲评「方向/排序合理」≥80%。**与落地页并列本周最高优先**（不过则口袋教练付费核心垮台、工程返工）。
3. **KT6-real**：口袋教练 core 上线后基于真实体验测试用→付费 ≥10%。
4. **G2 留存**：TestFlight 看 D7≥15%/MAU·下载≥8%，「今日一题」作轻钩子实验。
5. **G1 获客 / KT-LTV**：博主外挂 + 场馆码 + ASO（慢，依赖 KT7-B）；真实 cohort 重算 LTV。

### 9.4 本周第一动作（双线，1 人则别三线开花）

- **验证线**：上线付费意愿落地页/预售（KT6-pre）+ 启动 KT7-B 盲测筹备（现有反解器导方向建议 + 招专家）。
- **工程线**：c042 内容竖切（内核根基，不卡前提）。
- 口袋教练 core 作下一步工程主线，**paywall 等 KT7-B + KT6-real 后再上**。

### 9.5 硬卡点（看似能做、实则卡前提，诚实标注）

- **专家招募**（KT7-B 前提）：须含教练 / 高水平业余 / 内容创作者三类，否则盲评偏差大。
- **球形样本质量**：20–30 题须覆盖进袋方向/走位方向/翻袋反射/斯诺克安全/常见误判，不能只挑引擎擅长的。
- **内容补债是人力瓶颈非工程**：批量示范素材依赖创始人本人录台球示范（curriculum §7 已「⏸ 暂停等录制」）；每周期 ≥2 条 COMPLETE 需真实日历容量。
- **绝对值/停点可信**：需真实俯拍视频拟合常量，现无素材（阶段 1 付费核心已锁方向层规避）。
- **免费/付费边界先定稿**：docs/08 免费内容不可撤回，口袋教练 core 免费给什么、Pro 解锁什么须一开始谨慎。

### 9.6 ADR 边界

阶段 1 属产品层收敛 + UI/内容工程，不触发 ADR。但：schema 加字段若涉持久化/OTA 内容兼容，须按数据流程做迁移检查；后续 B 端 SDK/多租户/外置小程序/同步策略变化，另行触发 ADR。
