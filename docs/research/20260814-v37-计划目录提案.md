## 4. 衰减曲线（默认，W4 可按课时档微调）

适用于主计划内第 2 次及以后出现，以及跨计划咬合条目。必须标 `PlanDrillDose.decay: true`。首次引入禁止 decay（契约 §6.6）。

| 第几次出现（同一 drill，时间序） | rounds | 说明 |
|---|---|---|
| 1 | = 该球形 `defaultRounds` | 完整剂量、focused 优先 |
| 2 | ≈ 70%（四舍五入，≥1） | 同计划内第二次，可 focused 或 warmup |
| ≥3 | ≈ 50%（≥1） | 同计划巩固或跨计划热身 |

特殊球：第 1、2 次都完整，第 3 次起才 70%（罕见技术需要两次全量手感）。

走位链：按链的 `defaultRounds` 打折，**不砍球形/不砍杆**（D-v37-2 只放宽 rounds 下限，位置仍全覆盖）。
