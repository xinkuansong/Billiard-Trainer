## 3. 三类 tutorialKind 流程差异

| | `multiShot` 应用课 | `singleShot` 单杆技术课 | `ruleset` 规则流程课 |
|---|---|---|---|
| 技能 | **tutorial-authoring** 全流程 | **tutorial-migration** A 模板 | **tutorial-migration** C 模板 |
| digest | ✅ 每条序列必跑 | ⏭ 无序列跳过 | ⏭ 无序列跳过 |
| 读图 | ✅ 逐张 Read PNG（证伪，不取值） | 常无图：注明「无图」 | 常无图：有图才填 image |
| 意图卡问 3 | 本杆打法意图 / 角色 | **关键控制点**（可证伪动作） | **规则为何这样设计**（逼练什么） |
| 骨架标题 | 技术原理 → 开局与击球顺序 → 第N杆 → 常见错误 → 进阶练习 | 技术原理 → 动作要领 → 常见错误 → 进阶练习 | 技术原理 → 怎么摆 → 怎么计分 → 失败判定 → 常见错误 → 进阶变体 |
| params | 从 digest「params」行原样抄 | 默认不写 | 默认不写 |
| image | `<id>_sNN`；多球形用现行 token（`manual0N`）；禁 `_fN_` | 无手型素材则不填 | 有开局示意才填 |
| 胜负手 | ✅ 全组指认一个 | 动作关键控制点即「胜负点」 | 规则压力点（如「一次失误丢整局」） |
| 自查清单 | authoring **15** 条 | migration **0–12**（含 0/0b/0c） | 同 migration |
| C4 期望 | 逐杆节数 == 序列杆数（多球形按 formation 顺序） | 无序列 → C4 **warn「无序列」**（非 fail） | 同左 |

### 3.1 多球形 / 递进型额外约束（`multiShot`）

- `formations[]` 顺序与序列 `manual01, manual02, …` 一致；每套完整骨架。  
- 首档写透原理 + 阶梯变量；后续档只写「变了什么 / 难在哪 / 怎么调」，**差异自带参照档位名**。  
- 各档「技术原理」互不可替换。  
- profile 已 `retired`：问 2 **降级**，禁止假装矩阵仍有效；用序列实测对比各球形。  
- §8.15：image 只指向现行 `<drillId>_<token>_sNN`；完成后从 `i5_legacy_token_exempt` 删条目并下调 `c3_dead_refs_baseline`。

### 3.2 红灯（命中即停该条）

digest 报 **scratch / 目标球未进袋 / 文件缺失** → 上报，不硬圆。  
若批完成标准仍要求结构对齐：允许写结构占位，但正文必须标明缺陷与待重录，禁止把瑕疵写成成功示范（W1：`c053` manual02 第11杆先例）。

## 4. 每条 drill 必须回显的块

### 4.1 意图卡四问

1. 训练主题  
2. 球形设计意图（无 profile / retired → 声明降级 + 用序列能支撑的差异）  
3. 按模板换问法（见上表）  
4. 达标含义 / 失败常卡在哪  

### 4.2 胜负手

一句话 + 客观依据（容差 / 最大切角 / 关键控制点 / 规则压力点）。

### 4.3 元数据 diff 表（`nameZh` 除外）

| 字段 | 改前 | 改后 | 序列/依据 |
|---|---|---|---|

`nameZh`：**不写回**；若建议改名，单独成表，并跑跨 drill 引用扫描：

```bash
python3 -c "
import json,glob
names={json.load(open(f))['nameZh'] for f in glob.glob('QiuJi/Resources/Drills/*/drill_*.json')}
for n in ['建议旧名','建议新名']:  # 换成实际
    print(('✅' if n in names else '❌'), n)
# 正文引用扫描
old='旧 nameZh'
for f in glob.glob('QiuJi/Resources/Drills/*/drill_*.json'):
    d=json.load(open(f))
    if old in json.dumps(d,ensure_ascii=False) and d['id']!='本条id':
        print('引用方', d['id'])
"
```

### 4.4 读图健康检查

球数 / 跨图连贯 / 图注可兑现 / HUD 与文字同语言（档位语言，不抄百分比）。坏图如实列，不硬写。

### 4.5 自查清单

applicable 的每条 ✅/❌；❌ 先修再交付。
