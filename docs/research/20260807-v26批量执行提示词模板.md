## 3. 三类 tutorialKind × 形态差异

| | `multiShot` 应用课 | `singleShot` | `ruleset` |
|---|---|---|---|
| 技能 | **tutorial-authoring** | **tutorial-migration** A | **tutorial-migration** C |
| digest | ✅ 每条序列必跑 | ⏭ | ⏭ |
| **形态判定** | ✅ 写逐杆前必判（DR-062） | n/a | n/a |
| 读图 | ✅ 逐张 Read PNG（证伪） | 常无图 | 常无图 |
| 骨架标题 | 技术原理 → 开局与击球顺序 → 第N杆 → 常见错误 → 进阶练习 | 技术原理 → 动作要领 → 常见错误 → 进阶练习 | 技术原理 → 怎么摆 → 怎么计分 → 失败判定 → 常见错误 → 进阶变体 |
| params / image | digest 原样抄；多球形现行 token | 默认不写 | 默认不写 |
| **重点分配** | **走位链**：指认一个胜负手；**独立阶梯**：2–4 个锚点档全文，中间档仅一条自检 | 关键控制点 | 规则压力点 |
| 自查 | authoring 15（含 12/12b/13） | migration 0–12 | 同左 |
| C4 | 逐杆节数 == 序列杆数 | 无序列 → warn | 同左 |

### 3.1 独立阶梯 · 混合式结构（必遵，DR-062）

1. **`技术原理`**：讲透**唯一变量**（切角/距离/塞量/力度），一次讲完。  
2. **`开局与击球顺序`**：摆位 + **阶梯总表**（数值抄 digest）。  
3. **逐杆节保留**：锚点档全文三条目；中间档只留一条 `自检`。  
4. **多球形**：第 2 形起技术原理首段先答关系三问。  
5. ⛔ 禁用「胜负手/关键档」措辞。

### 3.2 走位链写法（默认）

- 每杆全文三条目；全组指认**一个胜负手**。  
- 「为下一杆」必须有实义。

### 3.3 语域规则（全字段，DR-062 + DR-063）

面向用户字段 ⛔ 禁止：

- 仓库工作流词：退役/retired、profile、序列文件、manual01、digest、出片、录制、待重录、W 批次号  
- 验收自证话术  
- 「轻力 2.1 档」式标签+数值堆叠  
- 旧横版袋口名：左上袋/右上袋/左下袋/右下袋/上中袋/下中袋  

**力度/杆法/塞 — 定性词汇表（DR-063，取代 v2 纯数值口径）**：

#### 打点读数单位契约（T1）

| 量 | 值 | 依据 |
|---|---|---|
| `spinX`/`spinY` 单位 | 接触点偏移 / R（无量纲） | `ShotIntent.Spin` |
| spin = 1.0 | 1.0·R = **28.575 mm** | `BallPhysics.radius` |
| 满塞 `MISCUE_LIMIT` | 0.5 → **14.2875 mm** | `CuePhysics.miscueLimitFraction` |
| 百分比读数 100% | spin / 0.5 × 100 | `SpinDisplay` |
| 定性皮头宽 | **≈12 mm**（任务口径；代码 tipDiameter=11 mm） | DR-063 |
| 半颗皮头 | 6 mm → spin ≈ **0.210** → 读数 ≈ **42%** | 6/28.575 |
| 一颗皮头 | 12 mm → spin ≈ **0.420** → 读数 ≈ **84%** | 12/28.575 |

#### 力度（阈值 = `PowerDisplay.name`）

| 条件 (m/s) | 定性词 | 正文示例 |
|---|---|---|
| < 1.2 | 轻推 | 轻推（0.9 m/s） |
| < 2.2 | 小力（轻力） | 小力（1.6 m/s） |
| < 3.6 | 中力 | 中力（3.3 m/s） |
| < 4.8 | 中大力 | 中大力（4.2 m/s） |
| ≥ 4.8 | 大力 | 大力（5.8 m/s） |

首次出现或关键档写「定性词（数值 m/s）」；其余档可只写定性词。数值始终可进 `params`。

#### 竖向杆法（阈值按 |spinY|，中点切分）

| \|spinY\| | 词 |
|---|---|
| < 0.105（半颗皮头/2） | 中杆 |
| < 0.315 | 中高杆 / 中低杆 |
| < 0.460 | 高杆 / 低杆 |
| ≥ 0.460 | 纯高杆 / 纯低杆 |

#### 横向塞（取最近档：0 / 0.210 / 0.420）

无塞 · 半颗皮头的左塞/右塞 · 一颗皮头的左塞/右塞  

组合：「中高杆加一颗皮头的右塞」「小力纯低杆」。

### 3.4 屏幕系方位规范（DR-063，废除参照物绕行）

digest 已输出 portrait 屏幕系（与精讲竖图同向）。**方位词与袋口名照抄事实清单**，禁止写作者自行旋转。

| schema ID | portrait 用户可见名 |
|---|---|
| `topLeft` | 左下角袋 |
| `topRight` | 左上角袋 |
| `bottomLeft` | 右下角袋 |
| `bottomRight` | 右上角袋 |
| `topCenter` | 左侧中袋 |
| `bottomCenter` | 右侧中袋 |

- 逐杆节标题：`第N杆：X号球 · 右侧中袋`（照抄 digest）  
- ⛔ 废除 v25 E9「参照物绕行」作为方位主策略（参照物描述仍推荐，但是增强可执行性，不是用来躲开错方位）  
- ⚠️ 事实清单与配图袋口位置不符 → 红灯上报，禁止手工「转正」
