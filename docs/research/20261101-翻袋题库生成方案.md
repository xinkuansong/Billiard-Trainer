## 1. 范围与当前证据

目标是构建有训练价值的目标球翻袋球形，区分翻中袋与翻底袋；母球直接碰目标球，目标球按指定库数/库序进指定袋。不是解球或K球。

已有研究小样及其原始证据保留：[中远台12题](../../tasks/BANK-DISTANCE12-20261101.md)。该批通过旧合同下的24杆事件/评分精确重放，但未应用本次中袋末段≥35°条件，不能当作新方案验收。用户截图中的M-45-2、M-55-2末段与长库夹角约19.72°、17.40°，按新条件应排除。

当前App初步48题与这些离线研究样例的接入状态以各自页面卡为准；本文不授权替换App资源。文档中的数量均不代表已生成库存。

## 2. 一库路线与目标球采样

1. 基础袋口只选一个中袋、一个底袋；先生成基础球形，再通过上下/左右镜像变化。不把镜像重复计入基础题数量，不在矩形桌上使用90°旋转。
2. 中袋从对面长库及两侧短库反弹进入；底袋从对面长库及另一端短库反弹进入。
3. 每条长库的有效部分分48区，每条短库分24区。分区只覆盖有效库段，剔除袋口开口及不合法端部；每区先随机取1个碰库点。长库的两个有效段合计48区，不是每段48区。
4. 从袋口向碰库点反向发射，按几何反射得到台内射线。反射须按实际球半径和球心碰库位置处理；几何只提供搜索种子，不能代替正向物理验证。
5. 每条反射线先取约12个目标球位置，靠近预定首碰库处采样密、远处采样疏；保留台内其他位置，不再使用中央50%区域框或目标球距库10cm硬限制。
6. 无合法母球候选的目标球位置可以为空，不强制保留。无合格末段的路线可提前排除，不能为补配额放松条件。

坐标沿生产X–Z米制、Y向上；横桌图右为+X、下为+Z。袋口/库线/圆角以BTPhysicsConstants、TableGeometry与AngleSceneCalculator当前代码为准，旧文档屏幕方位词不能替代实际映射。

## 3. 母球条件与直打比较

依据目标球首段方向构造假想球，再采样母球来向与距离；不能仅用两球球心连线的粗角度代替实际瞄准/碰撞切角。

| 项目 | 本轮方案 |
|---|---|
| 两球距离 | 球心间距≥0.40m；远台不因距离分低被淘汰，最大距离由合法桌面决定 |
| 出杆空间 | 完整评分中的空间分≥85，并核实际出杆可行性 |
| 翻袋切角 | 实际母球碰撞来向与目标球碰后首段去向的夹角≤35° |
| 直打困难 | 六袋合法直打候选中的最小几何切角≥45°；不得只比较指定目标袋 |
| 直打中袋 | 沿用MiddlePocketRegion和合法进球通道检查；无合法直打候选的球形当前单独排除，不虚记90° |
| 完整评分 | 保留距离/空间/角度/综合分及六袋最高合法直打综合分；距离分和综合分不作远台准入门槛，分数不是成功率 |
| 目标球位置 | 不强制限定区域；球间不重叠、摆位和路线均须合法 |

0.40m、空间85、最小直打45°与翻袋切角35°沿用当前研究参数，尚非实台成功率标定。直打45–55°、55–65°、≥65°用于覆盖统计/审图，不要求每个目标球位置同时填满三档。

## 4. 新确认：翻中袋末段入袋角≥35°

所有库数的翻中袋候选，最后一次指定主库碰撞之后的目标球入袋段，与中袋所在长库的锐角必须≥35°；90°为正面入袋。此角与第3节“翻袋切角≤35°”不同，不可混用。

生成时检查理想末段，正向模拟后再次检查实际末段。在实际末段存在弯曲或袋角接触时，应保存最后主库反弹后的方向及进入袋嘴前的方向，不能用袋角反弹后的方向或进袋动画制造达标；具体测量实现须在统一试跑前核定并用反例验证。末段几何区域也以最后碰库处的球心作为直进起点检查，而不是拿最初目标球位置代替。

35°是用户认可的翻中袋训练余量，不是替换物理引擎的绝对可进边界。直打中袋沿用原筛选；翻底袋暂不套此阈值。此前研究边界方向与长库约16.69°，还含位置偏移，表示当前模型下的存在性外沿，不保证训练容错。

来源：[中袋可行区域研究](../../tasks/MIDDLE-POCKET-ANGLE-20261026.md)、[现行区域实现](../../QiuJi/Core/PositionPlay/MiddlePocketRegion.swift)。

## 5. 母球尝试数量与保留配额

以下是首轮试跑参数，不是已证明的最佳采样密度：

- 每个目标球位置分批尝试母球候选，每批32个，最多128个。使用固定随机种子，记录实际尝试数与拒绝原因；不能把128个候选都记为物理模拟次数。
- 按距离及左右切分层抽样，最终每个目标球位置最多保留6题：中距离[0.40,1.00)m最多2题、远距离[1.00,1.60)m最多2题、更远距离[1.60,桌内合法上限]最多2题。
- 各档尽量覆盖左右切；零切角单独标记，不伪造左右对称配额。物理/空间不允许时留空，不跨档硬凑六题。
- 先收集合格候选，再按球位、瞄准方向、实际路线差异去重择代表，不能简单保留最先通过的6个。具体相似阈值待小样比较后定，不在此凭空固定。
- 最终0–6题均合法。零通过只表示有限预算内未找到，不等同于物理无解。候选不足、几何拒绝、规则排除、物理未找到、模拟未完成分别计数。

| 底袋 | 48+24=72 | 864 | 5,184 |
| 合计 | 168 | 2,016 | 12,096 |

母球候选预算最多2,016×128=258,048个；几何预筛后才需物理求解，每个球形又可能尝试多个击打参数，不能把此数当成总模拟杆数。35°筛选、非法位置与去重会减少有效库存。

含零保留位置的平均保留数若为1/2/3/4，则分别约2,016/4,032/6,048/8,064题。4,000–8,000题只是平均保留2–4题的情景估算，未经试跑，不是产量承诺。镜像变化不乘入基础题数；当前12题每行3题只是审图配额。

## 7. 统一物理验证与交付要求

候选必须经生产正向模拟确认母球首碰目标球、目标球实际主库次数/顺序及指定进袋、无母球落袋及二次球碰撞、模拟完整结束；袋嘴接触须独立记录并按最终合同审核，不能借最终进袋掩盖额外路线。几何与实际角度分开保存。

保存可复现的球位、库区/反射线/目标点来源、随机种子、库序、参考击打参数、实际碰撞事件、路线与完整评分。重放和独立审核分开；历史精确重放只能证明同输入可复现，不代替新增35°条件或瞄准/力度扰动容错验证。

统一试跑先报告各袋型/库数/库序的候选和拒绝漏斗、目标点0–6题分布、两球距离/左右切/角度覆盖、去重前后数量，再提供每行3题图册。新增硬门槛不得靠放宽阈值凑题。

## 8. 二库、三库讨论草案（尚未定稿）

### 已有方向

沿用从袋口逆推，不选择两个平行库之间的反复往返来凑库数；相邻两次指定主库要求垂直相邻。中袋末段≥35°、母球远台保留、直打困难等条件继续沿用。

### 建议生成方法

- 二库：从合格的“末库→袋口”段向前继续反射，找到前一库；目标球放在前一库反射后继续向台内延伸的射线上。正向顺序是目标球→第一库→第二库→袋口。
- 三库：再向前延伸一次，正向顺序是目标球→第一库→第二库→第三库→袋口。首轮建议使用三个不同主库、长短交替的路线；具体可用库序须经过几何遍历和正向模拟，不把排列数量当作可行路线数量。
- 反向路线必须实际先到达指定库，途中遇袋口/其他库或越界即拒绝；不能独立任选多个碰库点再拼成折线。
- 多库路线从几何种子延伸，不要求同一位置的一库母球方案先成功；改变首段后要重新放目标球、重新选择母球。
- 暂建议沿用每条有效路线约12个目标点、每目标点最多128候选/保留6题，并按库序记录数量；是否按路线族限额，等有效库序明确后决定。

### 下一步需共同确定

1. 三库是否限定三个不同主库；哪些路线族作为首轮核心。
2. 少库替代判据：建议同一母球/目标球布局若存在同样满足空间、切角、中袋入袋角且物理可行的更少库路线，多库题降级或剔除；但“存在一条少库解”不自动等于明显更容易，需要确定比较口径。有限搜索未找到不能记为不存在。
3. 二库/三库是否要求与直打一致的阈值，是否设置额外路线长度、力量或容错条件；尚未指定的阈值不暗中加入。
4. 各库序的采样预算及去重粒度。此前4库仅属初始探索，本次用户明确先定1–3库，不自动纳入统一生成。

待以上确定后，整理统一参数表和审计合同，再执行一次新的1–3库试跑。本轮仅记录与讨论。
