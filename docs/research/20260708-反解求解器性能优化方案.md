## 2. 核心设计（第一性原理）

**最大浪费：用完整多球事件模拟去回答本可解析回答的问题。** 在 elevation=0 恒成立的约束下，一杆球四段中前两段可解析：

1. 母球接近段：无 swerve，直线路径 + 分段常加速度闭式解；
2. 碰撞瞬间：squirt（`CueBallStrike` 已是解析模型）+ collision throw（引擎碰撞解算器内已是解析模型）；
3. 目标球段 / 4. 母球走位段：需要 rollout，但可用**单球 + 静态障碍**的轻量模拟替代全场多球模拟。

### 分层求解管线（目标架构）

```
第 0 层  纯几何（ns 级）：切角闸门、母球挡线、障碍挡直线路径（线段-圆测试）
第 1 层  解析（µs 级）：瞄准偏移牛顿反解（补偿 squirt+throw）→ 碰后双球状态
第 2 层  单球 rollout（ms 级）：母球走位段 / 目标球段各自单球+静态障碍模拟；
         走位段撞上障碍球 ⇒ 该候选升级为全模拟（少数）
第 3 层  全保真终验（仅每桶代表解）：现有 buildPrediction 完整多球模拟 = 唯一真相；
         不通过则局部修复或降级
```

对 D-D2「双景观错位」的回应：搜索允许近似，**呈现给用户的解必须通过第 3 层真实全保真终验**——比现状（搜索解无独立二次校验）更严格。

### 搜索策略换代：网格 → 连续曲线求根

固定 spin 组合时，母球停点随 velocity 是台面上一条连续曲线（拓扑变化处断开）。情形 A = 曲线与落区**求交**（自适应采样 + 变号处二分），同时取代 19 档力度网格与 Hooke-Jeeves 精修；情形 B 的速度分段 = 同一条曲线上「经过 P」的参数区间。

### 优化空间估算（推测，B0 校准）

| 路径 | 现状 | 目标落点 | 倍数 |
|---|---|---|---|
| 情形 A | ~2.3s | ~100–250ms | 10–20× |
| 情形 B | ~1.6s | ~100–200ms | ~10× |
| 斯诺克 | ~2.5–5s（推算） | ~0.3–0.5s | 8–15× |

方差最大项：解析层与引擎物理模型的对齐难度（若滑动摩擦细节无法闭式表达，瞄准层收益从 ~4× 降至 ~2×，见 B2 的对拍验证）。
