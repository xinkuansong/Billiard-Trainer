## 0. 给写手的用法（W1+ 必守）

| 角色 | `技术原理` | 逐杆自检 |
|------|------------|----------|
| **引入** | 把该概念的机制卡五问写成自然段（可合并，抽查时五问都能指认）。不要把「状态/这节只改/…」标题暴露给学员 | 盯本卡「观察」那一对征兆，不要写成别的分类的进袋套话 |

| **合成** | 默认会切角 / 杆法 / 走位。一句前置可点名先决课，然后只写本玩法新层。⛔ 禁止改回阶梯腔 | 盯本玩法（停位 / 叫位 / 翻袋 / 安全 / 清台链），不要重写切角定义 |

- 所有权管到**这一杆自检盯什么**，不能只改开篇。
- 前置句落在该形 `技术原理` 首句（D-v40-1=A），不改 schema / UI。
- SOP-A（把定理译成一句教练话）仍要做，但**不够当引入课**。

## 3. 机制卡（每个引入概念一张；五问必须可勾）

> 适用：该知识点在动作库里**第一次**被当作训练主题。后续课禁止再写五问全文。
> 五问标题：状态 / 这节只改 / 因为所以 / 观察 / 本课只练。禁止：「提升球感」、无机制口号、「本组只练一个变量」写完就结束。
> 过目样张单独放在最前，必须填满：切角→c013、定杆→c010。

### 3.0 过目样张 A — 切角 → c013

**来源**：§四B 切角样张（旧用词勿照抄）；定理改写：目标球沿连心线离开，吃得越薄，连心线越偏离袋口，稍偏就越不容易进；digest 切角约 3°–39°（球形1）与「直线球没有切角可用」。common_errors 改写：不要把半球当成定杆；不要把母球瞬间方向当成最终方向（本课锁中杆，先把接触点打熟）。

1. **状态**：目标球沿着两球连心线离开；吃得越薄，连心线越偏离袋口方向，稍偏就越不容易进。
2. **这节只改**：母球相对目标球的左右位置（切角 / 厚薄）、接触点瞄准。
3. **因为所以**：打厚，接触面大、能进的余地大、稍偏还能进；打薄，接触面小，同样的瞄准误差会被放大，容易切薄滑开或擦袋口。因为吃得越薄越难进，所以近距先把接触点打熟，再拉远——远了以后，同样的瞄偏更容易进不去。
4. **观察**：切薄滑开 / 擦过去没碰到目标球 = 太薄。贴着袋口慢进或碰袋唇弹出 = 太厚。进袋且路线贴预判连心线 ≈ 对。
5. **本课只练**：杆法锁中杆、力度锁小力、袋口锁死，只扫切角。先在近距把接触点打熟，再拉远。两形袋距不同，各形自己完整，不靠「跟球形 1 比」才能看懂。

### 3.0 过目样张 B — 定杆 → c010

**来源**：§四B 定杆样张（引入改归 c010，D-v40-7=B）；定理 common_errors：「关键是碰到目标球那一瞬间前后旋接近零，不是杆头离开母球时无旋」；远距中杆会先转成向前滚。digest：「直线球没有切角可用：母球只能沿击球线前后走（跟进/定/缩）」；「母球先走切线，随后被回旋拉弯，距离越短切线段占比越大」。description：停在 8 号原位附近约 1 颗球（母球到 8 号约 11→28 颗球）。

1. **状态**：母球碰到目标球的那一瞬间，如果前后旋接近零，碰撞后不会跟进也不会缩——直线球就停在碰撞点附近；有切角则沿切线横滑。要的是**碰到时**的旋转状态，不是杆头离开母球时的状态。
2. **这节只改**：打点高低（出发时给底旋 / 无旋 / 前旋）、力度（走多远、底旋被台呢磨掉多少）、两球距离（同样打点，走得越远越容易先转成滚动）。
3. **因为所以**：打点略低，母球出发带一点底旋；台呢一路把底旋磨掉。定杆就是让底旋在**碰到目标球时刚好磨完**。距离拉长，同样打点会提前转成向前滚，碰到时变成跟进——所以要再压低打点，或略加力让底旋多撑一段。打点过低或力过大，碰到时底旋还在，就会往后缩。打点给出发旋、台呢磨旋、力度/距离决定能不能撑到碰撞。
4. **观察**：直线球吃完，母球粘在原目标球附近约 5 公分 ≈ 对。往前溜 = 碰到时已经在向前滚（打点高了，或底旋不够撑到碰撞）。明显往后缩 / 往回跑了一大截 = 碰到时底旋还在（打点过低或力过大）。
5. **本课只练**：用定杆当基本功检验：袋口和瞄准线钉死，距离从约 0.6 米拉到约 1.6 米，停在 8 号原位附近约 5 公分。练的是用打点 + 力度把「碰到时无前后旋」守住。距离再往远拉（约 0.6→1.8 米）放到后续课 c014，本课不重写五问之外的距离阶梯。

### 3.1 近台直线 → c011

**来源**：description「专练近台仍认真锁线、控制母球别跟进袋」；digest「直线球没有切角可用：母球只能沿击球线前后走」。

1. **状态**：目标球和母球都走在同一条瞄准线上；直线没有切角可借，母球只能沿这条线跟进、停住或缩。
2. **这节只改**：瞄准线（杆、下巴、视线是否共线）、出杆直度、力度（跟进会不会进袋）。
3. **因为所以**：近台误差绝对值小，但瞄准线一偏，目标球就沿偏掉的线走；力稍大，母球会沿同一条线跟进袋。因为没有切角把母球带开，所以近台也要把线和力都守住。
4. **观察**：8 号进左下角袋且母球留台 ≈ 对。目标球偏出袋口 = 线偏了。母球跟着进袋 = 力大了或打点偏高。
5. **本课只练**：8 号距袋约 7–8 颗球，锁中杆中力，只换五个近台起点。只练近台锁线，不练切角、不加塞。

### 3.2 打点停点 → c016

**来源**：description「间距约 10 颗球…只改打点高低…练的是停点对打点的灵敏度，不是切角」；定杆卡的「碰到时前后旋」；定理 common_errors：直球停住 与 非直球沿切线横开 不是同一件事（本课是直线）。

1. **状态**：和定杆课一样，要的是碰到目标球时前后旋接近零——直线球就停在原位附近。本课把距离钉死，让你看清：这一点旋有多怕打点。
2. **这节只改**：打点高低（中低杆短停 → 中杆微跟进 → 更深中低杆回退）。力度锁中力，间距锁约 10 颗球。
3. **因为所以**：打点抬高，出发前旋变多，碰到时还没磨完就会跟进；打点压低，底旋在碰到时还在就会缩。因为距离不再变，所以停点的每一寸变化都来自打点，不是来自走得更远。
4. **观察**：短停在 8 号原位附近 ≈ 中低杆对上了。微跟进 = 打点偏高。回退拉长 = 打点更深。不要用切角解释这些前后差。
5. **本课只练**：几何不变，只扫打点。前置可点 c010：已经会「碰到时无前后旋」；这里只练灵敏度。

### 3.3 高杆跟进 → c003

**来源**：description 两形（拉远看跟进量 / 钉死间距爬打点）；定理：母球先沿切线走，随后被前旋拉向目标球方向；短距离时前旋还来不及把母球拉离切线（common_errors：短距高杆以为会立刻向前）。digest：直线无切角，母球只能沿击球线向前。

1. **状态**：碰到之后母球要沿击球线向前跟。出发时打点偏高，给的是前旋；碰到时如果前旋已经在，碰撞后会继续向前滚。
2. **这节只改**：打点高低（中杆 → 中高杆 → 纯高杆）、两球距离、力度。
3. **因为所以**：打点越高，出发前旋越多，碰到后跟进越长。距离拉长，台呢会把一部分前旋磨成滚动——同样打点，远了跟进手感会变钝。距离很短时，前旋还来不及把路线拉离切线，分离会更贴切线，这是正常现象，不是杆打滑了。
4. **观察**：8 号进袋且母球沿击球线向前、留台 ≈ 对。跟进不够 = 打点不够高或力不够。母球也进袋 = 跟进过量（示范里常见，练习以留台为合格）。
5. **本课只练**：直线进左下角袋。球形1 锁中高杆小力、把距离从约 7 拉到约 19 颗球；球形2 钉死约 10 颗球、打点从中杆爬到纯高杆。只练跟进，不加塞。

### 3.4 低杆缩杆 → c004

**来源**：description 两形（爬力度看回退 / 拉远目标距袋仍打出缩量）；定理：母球先沿切线走，随后被回旋向后拉弯；距离越短，切线段占比越大。digest 同左。

1. **状态**：碰到之后母球要沿击球线回退。出发时打点偏低，给的是底旋；碰到时如果底旋还在，碰撞后会被拉回来。
2. **这节只改**：打点深浅、力度、目标球距袋（同样低杆，目标越远越难把缩量打出来）。
3. **因为所以**：打点越低、力越大，底旋越能撑到碰撞，回退越长。距离短时，碰到前底旋几乎没被磨掉，回退会很「脆」；目标球距袋拉长，同样杆法要想缩回来，得把力或打点再送透。母球总是先沿切线走一小段，再被底旋拉回——短距时这一段更明显。
4. **观察**：目标球进袋且母球沿击球线回退、留台 ≈ 对。缩不回来 = 打点不够低或力不够。回退过量/进袋 = 力过大（球形2 第1杆示范有此现象，练习以留台为合格）。
5. **本课只练**：直线进左下角袋。球形1 锁低杆、力度从小力爬到中大力；球形2 锁低杆中力、目标距袋约 9→24 颗球。只练缩，不加塞。

### 3.5 挤偏 → c073

**来源**：description「先建立塞侧→让点方向」；定理：加塞会同时带出挤偏、路线弯曲、碰撞挤推三层误差；左右打点偏移决定出发时的侧旋，不是某种特殊手腕。common_errors：以为加塞就能任意控母球。

1. **状态**：杆头打在母球左侧或右侧时，母球出发方向会相对瞄准线偏向塞的**对侧**（挤偏）。这是出发瞬间就有的，不是吃球之后才出现。
2. **这节只改**：左右塞量（中杆 / 半颗 / 一颗皮头）、力度（球形2 才叠力度）。
3. **因为所以**：塞量越大，出发偏得越多；线路越长（到 c074 再练），同样的偏角在袋口处横向偏差越大。因为瞄准线还指着袋，而母球已经从另一条线出发，所以要先承认「会偏」，再谈让点。
4. **观察**：母球（或带着 8 号）落到塞的对侧 ≈ 挤偏方向对了。仍沿原瞄准线走 = 塞量没打上或打点仍在中心。偏向塞的同侧 = 让点方向反了。
5. **本课只练**：近台直线。球形1 只扫塞量；球形2 再叠力度。先感知方向，不练一库走位。

### 3.6 塞量让点 → c075

**来源**：description「唯一主变量是塞量（及与高低杆的组合），切角近直线钉死」；定理：能用中杆走到的位置不要加塞；必须加塞时，用让点抵消挤偏，塞量以能完成任务的最小量为准。common_errors：把加塞当成玄学控球。

1. **状态**：侧旋在出发时造成挤偏，一路上还可能把路线掰弯，碰到目标球时还会轻微挤推。近直线进袋时，你要先让开这几层，目标球才会仍走袋口。
2. **这节只改**：左右塞量（无塞 → 半颗 → 一颗 → 近满）、打点高低（三套：中杆 / 中高杆 / 中低杆）。
3. **因为所以**：塞量上去，挤偏和掰弯都变大，所以瞄准要向塞的同侧让一点，目标球才回得中袋。高低杆叠塞，是在侧旋之外再叠前旋或底旋，落点和让点会一起变——不是「多加一点塞就更好控」。
4. **观察**：目标球进右侧中袋 ≈ 让点对上了。擦对侧袋唇 = 让点不够。擦同侧袋唇 = 让多了。空杆或明显侧向飞出 = 塞量与让点完全反了。
5. **本课只练**：切角近直线钉死，袋口锁右侧中袋，只扫塞量及与高低杆的组合。走位变线放到后续课。

### 3.7 分离方向随切角 → c024

**来源**：description「体会分离方向随切角变化」；定理：碰到时若前后旋接近零，母球沿切线离开，和目标球的分离接近直角（直球会停住，是唯一例外）；母球瞬间方向总是切线，之后才被旋转拉弯。common_errors：把直球停住和非直球沿切线横开混成一件事；远了用中杆会先转成滚动，分离就不再按「碰到时无旋」算。

1. **状态**：吃球瞬间母球先沿切线（垂直于两球连心线）离开；目标球沿连心线走。切角变了，这两条线一起转，分离方向就变。
2. **这节只改**：厚薄 / 切角（本课约 12°→46°）。杆法锁中低杆，接近「碰到时前后旋很少」。
3. **因为所以**：切角打开，连心线转开，切线也转开，母球横滑的方向跟着变。因为本课接近定杆，母球不会马上被前旋拉向目标球、也不会马上被底旋拉回，所以你看到的主要是切线方向本身。
4. **观察**：母球离开的方向随切角转 ≈ 对。母球仍沿出杆方向冲 = 打太薄或碰到时已经在向前滚。母球几乎停住 = 打成了直球定杆（切角太小）。⛔ 不要只用「进袋即过」当自检。
5. **本课只练**：中低杆、独立重置，只扫切角看分离方向。不练走位落点、不加塞。

### 3.8 厚球分离 → c026

**来源**：description「厚球接触面大，母球易大角度横滑或双落」；定理：自然滚动、中等厚度时母球偏开大约一个固定的小角度带；common_errors：把半球击球当成定杆。

1. **状态**：打得厚时，接触面大，目标球吃到的速度多，母球剩下的横向速度也大，容易大角度横滑；太厚时两球可能一起走（双落）。
2. **这节只改**：近直线区的切角（球形1）、力度（球形2）、高低杆（球形3）。先控方向，再叠另外两维。
3. **因为所以**：厚 → 连心线更靠近出杆方向，目标球更「正」，母球切线更横。力越大或带前旋，母球越容易在横滑之后被拉向目标球，双落风险上升。因为接触面大，稍厚一点，分离方向就会从「可控横滑」变成「两球抢一条线」。
4. **观察**：目标球进右侧中袋、母球按预判横开且不碰目标球第二次 ≈ 对。双落 = 太厚或力太大。母球几乎不横滑 = 打薄了，已经不是厚球该有的走向。
5. **本课只练**：袋口锁右侧中袋。三形分别扫近直线切角、力度、高低杆。自检盯分离方向与双落，不盯准度课的进袋套话。

### 3.9 薄球分离 → c025

**来源**：description「薄球时母球偏转很小，几乎沿出杆方向继续」；定理：母球瞬间仍走切线，但切得很薄时连心线已经转开很多，切线几乎贴着出杆方向。

1. **状态**：打得薄时，目标球只吃到一点点速度，母球几乎还沿着出杆方向走，偏转很小。
2. **这节只改**：切角（球形1 约 71°→43° 中袋；球形2 约 44°→64° 角袋）、接触点瞄准。杆法锁中杆、力度锁小力。
3. **因为所以**：切角越大，连心线越离开出杆方向，目标球稍偏就越不容易进，母球切线越靠近出杆方向——所以母球「好像没被带走」。若按厚球那样预判母球会大角度横开，走位会完全落空。
4. **观察**：目标球进袋、母球几乎沿出杆方向继续 ≈ 对。母球大角度横开 = 打厚了。切薄滑开 / 擦过去没碰到目标球 = 太薄（这是准度征兆，本课只用来排除，主自检仍是母球走向）。
5. **本课只练**：全程中杆小力，两形只扫薄切角。先感知「母球几乎不偏」，再谈走位。

### 3.10 三档力度标尺 → c045

**来源**：description「无目标球…建立力度 → 行程的身体尺度」；定理：力度用出杆长度来调，不是用「用力大小」；先用少档把身体尺度立住，档位堆太多只会把误差放大。common_errors：用用力思维；为了「够」去选过高档。

1. **状态**：母球被推出后，在台呢上走一段再停住。行程主要由出发速度决定。
2. **这节只改**：出杆长度（本课三档：小力 1.2 / 小力 2.0 / 中力 3.0 m/s）。打点锁中心，无目标球。
3. **因为所以**：出杆越长，母球出发越快，台呢要磨更久才停，停点越远。因为没有目标球，停点上的每一寸都来自力，不是来自碰撞或旋转花样。
4. **观察**：三档停点能拉开、且可重复 ≈ 对。三档停在差不多的地方 = 出杆长度没分开。越打越远却说「我没加力」= 还在用用力大小，而不是看出杆长短。
5. **本课只练**：同一起点、直线、无目标球，只推三档。五档加密、轻推进袋、强弱杆都放到后续课。

### 3.11 握杆 → c006

**来源**：description「评判标准是握杆是否复原，不是进球花样」。无对应定理条目——只写可观察的手，不写自造物理。

1. **状态**：击球前后，握点、虎口、手腕应回到同一副样子。
2. **这节只改**：握点前后、手指松紧、手腕是否内扣或外翻。
3. **因为所以**：握点前移或后移，杆头不再走你刚才瞄准的那条线；手腕内扣/外翻，杆头会在出杆末段被带偏。因为直线球只是检验载体，对了看的是手有没有复原，不是球进得漂不漂亮。
4. **观察**：打完定格，握点没挪、手腕没翻 ≈ 对。握点滑动、虎口离开、手腕明显内扣外翻 = 错。
5. **本课只练**：简单直线当载体，只评握杆复原。

### 3.12 站位对齐 → c007

**来源**：description「脚步、下巴、瞄准线要在同一条线上，不靠改打点高低来补站位」。无对应定理条目。

1. **状态**：身体中线、下巴、球杆、瞄准线叠在同一条线上。
2. **这节只改**：脚的落点、身体朝向、下巴是否压在杆上。打点与力度本课锁死。
3. **因为所以**：脚或身体偏了，杆即使「看起来」对着球，实际出杆也会偏到线外。用打点高低去补站位，只会把下一次的线补得更乱——因为你改的不是站位这一项。
4. **观察**：四次同一摆位，8 号进袋且杆、下巴、脚仍共线 ≈ 对。球进了但身体明显拧着 = 用结果掩盖站位。球不进且身体已歪 = 先摆脚，不先改打点。
5. **本课只练**：直线、中杆、中力锁死，只留站位。

### 3.13 手架 → c008

**来源**：description「架杆稳、球杆在导槽/指环里滑动顺畅、击球瞬间无明显侧偏」。无对应定理条目。

1. **状态**：手架是一条不动的导轨；杆在导轨里走，而不是手跟着杆晃。
2. **这节只改**：开放架 / 封闭架的形状、底座是否塌、导槽或指环松紧。
3. **因为所以**：底座一塌，导轨指向就变；导槽太松，杆会在击球瞬间侧偏。进球只是载体——手架歪了偶尔也能进，但下一杆导轨已经不在原处。
4. **观察**：杆走完仍在导槽里、底座没塌、没有明显侧偏 ≈ 对。击球瞬间手架跳开或杆磕出导槽 = 错。
5. **本课只练**：可用直线或小角度作载体，只评手架质量。

### 3.14 直线出杆 → c009

**来源**：description「把击打距离一档档拉长，专门放大出杆是否走直线」。无对应定理条目。

1. **状态**：杆头沿瞄准线进出，母球沿同一条线走。
2. **这节只改**：出杆路径（是否画弧、是否甩腕）。打点锁中杆，力度锁小力。
3. **因为所以**：距离拉长，出杆时一点点侧向会被放大成袋口处的明显偏差。因为袋口和杆法都钉死，偏了只能是出杆不直，不是切角或加塞。
4. **观察**：母球沿直线进右下角袋 ≈ 对。越远越偏到一侧 = 出杆画弧或甩腕。
5. **本课只练**：上路七个起点，只把距离拉长。标记球不入袋。

### 3.15 五分点瞄准线 → c023

**来源**：description「变量只留力度，专门练同一条瞄准线在不同力度下是否还成立」。无对应定理条目。

1. **状态**：瞄准线（母球—8 号—袋口）在加力前后应仍是同一条。
2. **这节只改**：力度。摆位、瞄准线、中杆锁死。
3. **因为所以**：加力时如果身体抬起来或杆头甩开，瞄准线就不再指向袋。因为几何钉死，进不进袋直接反映「这条线还在不在」，不是切角变了。
4. **观察**：八次都沿同一条线进左下角袋 ≈ 对。小力进、大力偏 = 加力时线散了。
5. **本课只练**：8 号在台面中点附近，只扫力度。不练切角、不加塞。
