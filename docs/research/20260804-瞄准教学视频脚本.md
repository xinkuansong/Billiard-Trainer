## 〇、制作总规范（全片统一，逐拍不再重复）

### 0.1 视觉语言（与 App 内线语言 v2 同源，`TrajectoryStyle` / `FigureLine`）

| 元素 | 规格 | 语义 |
|---|---|---|
| 瞄准线 / 母球碰前路径 | 白实线；碰后白虚线 | 母球 |
| 进球线 / 目标球路径 | 目标球本色虚线（黑 8 亮灰） | 目标球 |
| 假想球 | 绿虚线圆圈（`BTGhostCircle`） | 几何解 |
| 接触点 Q / Pt / Pc | 绿点（`BTContactDot`）；Pc 白点 | 碰撞几何 |
| 作图参考量（平行线/间距 δ/刻度） | 金色（`Color.btAccent`） | 「作图工具」而非物理量 |
| 误导线 / 错误示范 | 灰虚线 | 「不要这样瞄」 |
| 幽灵变体轨迹 | 同色 40% 透明度 + 变体标签角标 | 对比组 |
| 修正量 Δ / 偏差读数 | 金色等宽数字，HUD 条底部（与导出 HUD 同款玻璃语法） | 实测值 |

### 0.2 公式卡范式

- 公式卡 = 深色半屏侧栏推入，LaTeX 排版，**变量出现时对应画面元素同步高亮闪一次**（如公式中 R 亮起时，画面里球半径标尺亮起）。
- 每张卡右下角小字标注代码出处（如 `CueBallStrike.squirtAngle`）——这是「全网最专业」的信任状：公式不是抄书，是引擎里真实在跑的代码。
- 公式卡停留期间旁白**逐项读公式**（不念符号名，说物理含义）。

### 0.3 单位与换算约定

- 全片角度用度，长度用毫米；每个角度数字**必须**跟一句 mm 换算。换算基准卡（第一次出现时上屏，此后复用）：**1° 偏角 ≈ 17.5 mm/米球距**（tan1°×1000）。
- 球径 57.15mm（中式八球），R = 28.6mm——「半颗球 ≈ 28mm」作为口语锚。

### 0.4 慢放与时间 ramp 语义

| 档位 | 倍率 | 用途 |
|---|---|---|
| 正常 | 1× | 完整击球叙事 |
| 慢放 | 1/8× | 轨迹形状观察（swerve 弯折、分离角） |
| 超慢 | 1/50×–1/200× | 碰撞瞬间机理（接触面拖拽、旋转搓动） |
| ramp | 1× → 碰撞前 0.2s 内降至超慢 → 碰后回 1× | 击球实演默认节奏 |

### 0.5 对比范式（三种，各拍标注用哪种）

- **C1 幽灵叠加**：同一盘面跑两次模拟（确定性保证可复现），变体以 40% 透明球+虚线同屏；**时间对齐以「碰撞事件」为锚**（两杆到达碰撞时刻对齐，碰前按各自真实时间压缩），保证观众比较的是碰后差异。
- **C2 并排分屏**：参数差异大、轨迹重叠看不清时用；左右画面物理时间严格同步。
- **C3 定格叠印**：终局静帧叠加，标注两个停点间距 mm 读数。

### 0.6 标注时序语法

每拍图规格里用 `@t` 标记标注元素出现时刻（相对本拍起点秒）；未标 = 随拍首帧出现。原则：**一次只出现一个新元素，旁白说到才出现**。

## 三、第一章：瞄准有唯一正确答案（L0，7 拍，≈4.5 min）

**拍 5**　B0（隐去母球）　[S1 静帧]
- 画面：只有目标球与袋口。@3s 进球线出现。
- 旁白：「先退回原点，忘掉母球。目标球要进袋，它被撞后只能走这一条线——进球线。整个瞄准问题，就是想办法让它上这条线。」

**拍 6**　B0　[S2 推导动画 + 公式卡]
- 画面：目标球球面 @0s；@2s 超慢碰撞示意（半透明母球从任意方向靠近）：接触瞬间画出**两球心连线**，力沿连线的箭头从母球心穿到目标球心；@8s 换三个来球方向重复，目标球离开方向始终 = 连线方向。
- 旁白：「球是圆的、表面光滑（先假设光滑，这个假设第三章会被打破）。碰撞瞬间，力只能沿一个方向传递——两颗球球心的连线。母球从哪来不重要，**连线指向哪，目标球就往哪走**。」
- 公式卡（G1，`ghostBallPosition`）：
  \[ \text{ghost} = \text{OB} - 2R \cdot \hat{d}_{pot} \]
- 画面（公式期间）：@0s 进球线上反向长度标尺「2R = 57mm」拉出；假想球绿圈落位。
- 旁白：「所以：要让目标球沿进球线走，碰撞那一刻母球球心必须站在这个位置——沿进球线反方向退两个球半径，五十七毫米。这就是假想球。」

**拍 7**　B6　[S4 三母球位对比，C2 三分屏→合屏]
- 画面：三分屏各摆一个母球位，同一目标球+袋口；三屏同时画瞄准线，@4s 合成一屏——三条白线从三个方向汇入**同一个绿圈**。
- 旁白：「换三个母球位。假想球一动不动，动的只是你走向它的方向。**进球线固定，假想球就唯一固定**——瞄准问题在几何层面有唯一正确答案。这句话是全片的地基。」
- 锚：(A1)

**拍 8**　B0　[S2 切角定义 + 公式卡]
- 画面：@0s 瞄准线与进球线的夹角弧亮起，标 θ；@4s 目标球上横移标尺 d 拉出。
- 公式卡（G2，`AngleSceneCalculator.lateralDisplacement`）：
  \[ d = 2R\sin\theta \]
- 旁白：「给『打多厚』一个数：瞄准线和进球线的夹角叫切角 θ。假想球心偏离目标球心的横向距离 d 等于两倍半径乘 sin θ。三十度切角——d 就是一个球半径，28 毫米。这个公式第二章会变成你手里的刻度尺。」

**拍 9**　B2　[S2 贴库球标注]
- 画面：贴库目标球；@0s 灰虚线（瞄袋心）——@2s 该线与近端 jaw 相交处红闪；@4s 真进球线（本色虚线）终点从袋心**外移**到管道安全入口，目标球本色管道（两条平行边线）显现。
- 旁白：「一个精化。贴库球直瞄袋心，会先撞上近端袋角——所以真正的进球线，终点不是袋心，是袋口让得开的那个入口。引擎用纯几何把它算出来：能空心进就瞄袋心；不能，就自动外移、只允许擦远端袋角。」
- 旁白（收）：「终点变了，铁律不变：**进球线定了，假想球就定了**。」
- 锚：(A2，`effectivePocketAimPoint` far-jaw-only 三情况)

**拍 10**　B0 变体　[S2 可行性边界]
- 画面：目标球+袋口不动，母球绕目标球扫一圈动画：切角弧实时变化，@扫过 ~72° 时画面示警「切角过大 · 不可进」；@6s 第二种失败：母球恰好压在进球线上，示警「母球占位」。
- 旁白：「几何也会说『无解』：切角大到接近九十度，假想球退到你根本碰不着的一侧；或者母球自己堵在进球线上。承认无解也是瞄准的一部分——这时候该想的是防守，不是硬打。」
- 锚：(§1.3 可行性闸门 `maxCutAngle` / `isCueBallBlocking`)

**拍 11**　[章节小结卡]
- 画面：三行字卡逐行出现：「① 进球线唯一 → 假想球唯一（G1）」「② 厚薄有精确数：d = 2R·sinθ（G2）」「③ 贴库球终点外移，铁律不变」。
- 旁白：「第一章三句话。接下来的问题是：假想球在空中又没有画出来——怎么『看到』它？」

## 四、第二章：四种瞄准法，一个终点（L1，8 拍，≈5 min）

> 本章图规格与学区 `AimingMethodsView` 作图**同源**（管道 / 接触点 Pt·Pc / 平行线 / 厚薄），几何以该页 `AimingMethodsGeometry` 为准；恒等式 Pc→Pt ≡ G−C 有数值草稿（`build/y1-evidence/`）。

**拍 12**　[S1 静帧 + 弹幕感引入]
- 画面：四个流派名以「争论帖」样式漂过：假想球法 / 管道法 / 接触点法 / 平行线法。
- 旁白：「网上吵了几十年：哪种瞄准法最准？第一章的地基直接给出答案——**它们瞄的是同一个点**。四种方法，是定位同一个假想球的四种测量工具。逐一拆开看。」

**拍 13**　B0　[S2 管道法动画，交互感]
- 画面：@0s 进球线扩成半径 R 的圆管（目标球本色半透明管道，管宽恰好一个球径）；@4s 瞄准线也扩成白色管道；@7s 试瞄角 φ 从偏厚扫到偏薄：两管**相交（太厚）→ 外切（正确）→ 相离（太薄）**，外切瞬间切点 Q 绿点亮起。
- 旁白：「管道法：把两条线各加粗成一个球宽的管子。瞄太厚，两管相交；太薄，相离；**恰好外切——切点就是接触点 Q，此刻母球心正好走到假想球心**。它把『打厚打薄』从抽象角度变成看得见的相交与相离。适合：中等切角、喜欢面积感的人。」
- 锚：（管道外切 ⇔ 球心距 2R，与 G1 等价；作图同 `AimingMethodsView` §1）

**拍 14**　B0　[S2 接触点法碰合动画 + 误导线警告]
- 画面：@0s Pt 绿点（目标球背袋点：球心沿进球方向后退 R）；@3s Pc 白点（母球心沿**同一进球方向**前进 R）；@6s 母球沿瞄准线平移动画——Pc 与 Pt 在 Q 点碰合、母球心恰落绿圈；@10s **灰虚线**出现：球心直指 Pt 的错误瞄法，与真瞄准线的夹角弧标出。
- 旁白：「接触点法：目标球上找背对袋口的点 Pt，母球上找对应点 Pc，出杆让两点碰到一起。注意陷阱——很多人直接**球心瞄向 Pt**，灰线这样：必打厚。正确的是点对点碰合，两点连线和进球线平行等长。适合：薄球、点感强的人。」
- 锚：（Pc→Pt ≡ G−C 恒等式，y1 草稿；误导线 = `AimingMethodsView` §2 原生教学点）

**拍 15**　B0　[S2 平行线法 + Mosconi 变体]
- 画面：@0s 金线连 Pc→Pt；@3s 过母球心作金线的**白色平行线** = 瞄准方向；@6s 碰撞定格：两球心关于 Q 点对称高亮。@9s 右下角小图 Mosconi 变体：过目标球心作进球线、过母球心作平行线、量间距 δ、平移收拢。
- 旁白：「平行线法：连两个接触点，过母球心画平行线，就是瞄准方向。它和接触点法是同一个几何的两种画法。变体是 Mosconi 平行线——用间距 δ 做量具。适合：喜欢用杆比划作图的人。」

**拍 16**　B5　[S2 厚薄刻度尺 + 公式卡]
- 画面：目标球放大居中，母球轮廓从正后方视角叠上：@0s 全球（完全重叠）；@3s 依次滑到 3/4、1/2、1/4、极薄，每档目标球被母球轮廓**遮住的比例**高亮 + 对应切角数字弹出。
- 公式卡（G3，`NamedBallThickness`，sin 恒等式）：
  \[ \sin\theta = 1 - \text{overlap} \]
- 五档表（上屏，数据 = 代码派生值）：全球 0°｜3/4 球 14.5°｜半球 30°｜1/4 球 48.6°｜极薄 →90°。
- 旁白：「最后是用得最广的厚薄法：沿瞄准方向看过去，母球盖住目标球几分之几。盖住的比例和切角有精确关系——sin θ 等于一减厚度。全球正碰零度；四分之三球十四度半；**半球正好三十度**；四分之一球四十八度半。注意这五档不是均匀的——越薄，每差一档角度跳得越多，所以薄球最考验眼睛。」
- 锚：（G3 为几何恒等式，档位值 = `NamedBallThickness.classic` 派生；⟨**D2**：各档在教学袋口的容错窗（±几度仍进袋）需引擎扫描，供「薄球更难」量化⟩）

**拍 17**　B0　[S4 四法同屏收敛，C1]

## 五、第三章：看不见的小偷——不加塞也会偏（L2，7 拍，≈5 min）

## 六、第四章：加塞——三重效应，方向可能和你想的相反（L3，9 拍，≈7 min）
