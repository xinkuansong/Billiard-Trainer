## 0. 坐标契约回显（geometry-spatial-reasoning）

- **内容/烘焙系**：归一化 Canvas（`AngleSceneCalculator`）——X∈[0,1] 左→右；Y∈[0,0.5] 上→下；`sceneZ = y·2·innerWidth − innerWidth/2`。

- **满塞**：`CuePhysics.miscueLimitFraction = 0.5`（不是球边缘）。

## 1. 数值核验三件事（摘要）

完整 stdout / 表见 `build/v21-evidence/`。脚本入口：`QiuJiTests/V21W1EvidenceTests.swift`。

### 1.1 S1 让点方向 → `s1-squirt.md`

**[事实]** 左塞(`spinX>0`)母球出射偏向**右**（`squirtDeg<0`，满塞 ≈ −1.887°）；瞄准补偿应向**左**让。右塞对称。

对照 `drill_c018.json:17`「加左塞时瞄准点需略向右补偿」→ **与引擎矛盾 → 旧文案需修正**（见 §4 W4 待改清单）。

### 1.2 挤偏 × 力度 → `squirt-vs-power.md`

**[事实]** 挤偏与力度无关：YES（复现 v12 Z3）。`squirtAngle(a:)` 无速度参数；多档 v 与 `executeStrike` 0.8/4.0 同值。

文案红线维持：⛔ 不得写「大力挤偏更大」。

### 1.3 直球 + 三档塞洗袋 → `straight-scratch-scan.md`

引擎路径：`ShotBaker.bake` → `ShotPredictor.predict`；局面 = bottomCenter 直球、`spinY=0`、`d_cue_ghost=0.22`、三档塞（轻 0.15 / 中 0.30 / 满 0.5）× dtp × 力度网格。

**[事实]** W2 可用摆位区间（三档塞交集）**dtp∈[0.12, 0.25]**（归一化）；交集内力度上界轻/中/满均可至 **5.0 m/s**（本网格）。近袋更易洗袋（dtp≤0.12 洗袋率 77% vs ≥0.22 的 22%）；满塞 dtp=0.10 仅 v≤1.0，中塞 dtp=0.10 无 ok。dtp=0.30 本扫描无 ok（摆位越界/不可行）。W2 仍须逐球形核 `feasible ∧ objectPocketed ∧ ¬cuePocketed`。

## 3. 6 条变量档案骨架（B2 六要素；⛔ 不落坐标）

### c073 挤偏认知·直球近台

| 要素 | 取值 |
|---|---|
| **固定** | 切角=0°（直球）；袋口=bottomCenter（或角袋二选一，W2 脚本定，须全档案一致）；spinY=0；塞量=中(0.30)；判定=仅进袋 |
| **目标** | `side` ∈ {L, R}（全覆盖） |
| **条件** | 母-目距离近段 2 档散布；力度 轻/中散布（上界受洗袋扫描约束） |
| **约束结构** | 袋口 P + dtp → T 在进球线上 → G=T−2R·v̂ → C 在过 G 的进球线反向射线上（θ=0）；加塞后行进含挤偏，烘焙走 `predict` 求解补偿 |
| **最小覆盖** | N≥2（L/R）× 条件散布 → 预算 4；矩阵弱化版 |
| **难度递进** | 主序：距离升；同距内 L→R（或惯用手镜像） |

### c074 挤偏放大·直球长台

| 要素 | 取值 |
|---|---|
| **固定** | 切角=0°；spinY=0；判定=仅进袋；袋口同 c073 族 |
| **目标** | `side` ∈ {L,R} × 距离档（中/长，2 档）→ 4 组合全覆盖 |
| **条件** | 力度散布（≤洗袋上界）；塞量固定中档 |
| **约束结构** | 同 c073；长距放大横向误差（挤偏角×杠杆臂） |
| **最小覆盖** | N=2×2=4 |
| **难度递进** | 主序距离；次序侧别 |

### c075 塞量阶梯

| 要素 | 取值 |
|---|---|
| **固定** | 切角=0°；spinY=0；判定=仅进袋 |
| **目标** | `spinLevel` ∈ {轻, 中, 满} × `side` ∈ {L,R} → 6 档全覆盖 |
| **条件** | 距离散布（须落在洗袋可用 dtp）；力度随塞量递减（满塞更严上界） |
| **约束结构** | 同直球链；`spin.x` = ±{0.15,0.30,0.50} 写入 profile |
| **最小覆盖** | N=3×2=6 |
| **难度递进** | 主序塞量升；同档 L→R |

### c076 小角度带塞进袋

| 要素 | 取值 |
|---|---|
| **固定** | spinY=0；塞量=中；判定=仅进袋；袋口（W3 定，建议角袋或中袋一致） |
| **目标** | 切角 ∈ {15°,30°} × 顺塞/反塞 → 4；预算 6 = 目标全覆盖 + 条件加样 |
| **条件** | 距离；可加一侧别绝对 L/R 散布（标签仍保留，真变量是顺/反） |
| **约束结构** | P+T → 进球线；G；θ+侧 → 白球射线；顺/反 = spin 相对切向同侧/异侧（投掷厚薄） |
| **最小覆盖** | N_min=4，预算 6（条件 pairwise 摊） |
| **难度递进** | 主序 θ；次序顺→反（反塞通常更难，待 W3 实测确认后可调） |

### c077 中大角度带塞进袋

| 要素 | 取值 |
|---|---|
| **固定** | θ=45°；spinY=0；塞量=中（无塞对照档 spin=0）；判定=仅进袋 |
| **目标** | 顺塞 / 反塞 / 无塞对照（3）× 条件铺开 → 预算 6 |
| **条件** | 距离、目标球距袋 dtp |
| **约束结构** | 同角度球链（c053 范式）+ spin；无塞对照用于隔离投掷/挤偏感知 |
| **最小覆盖** | 目标 3 档全覆盖；条件散布凑满 6 |
| **难度递进** | 无塞→顺→反；同档距升 |

### c078 远台带塞准度

| 要素 | 取值 |
|---|---|
| **固定** | spinY=0；判定=仅进袋；中等切角或直球偏远（W3 选一钉死，推荐小切角远距以免洗袋） |
| **目标** | 距离档 × 塞侧 → 4 |
| **条件** | 塞量、入袋角散布 |
| **约束结构** | 远距杠杆放大挤偏+投掷；入袋角控制避免与切角难度混淆 |
| **最小覆盖** | N=4 |
| **难度递进** | 主序距离；次序塞侧 |
