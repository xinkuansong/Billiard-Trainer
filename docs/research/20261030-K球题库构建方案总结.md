# K球题库构建方案总结

记录日期：2026-10-30。本文汇总本轮已经确定的构建方案，作为后续扩库、复建与修改规则的入口；历史试验保留原条件和结果。

核心流程：从两球走位题库取得母球、第一目标球A及其指定袋和存档路线，筛选自然的靠库路线，在合适片段的管道内生成第二目标球B，进行真实三球验证、模拟容错和去重，最终每个原球形的每条合适轨迹只保留一个B位置。

## 一 训练目标

练习目标是打进A，同时让母球随后碰到B。这里的“随后”指母球先碰A、再碰B，不要求A已经落袋才能碰B。

- A必须进指定袋。
- 母球落袋不作为失败条件。
- 不控制B碰后的方向、位移、停点、是否进袋或下一杆位置。
- 不要求证明“这杆K球比直接走到B更容易”。实战中还可能借其他球走位，首版不做整局球序比较。
- 靠库、远离袋口的B是首版选择的训练场景；不把“靠库”直接等同于所有情况下都值得K。

## 二 两层筛选条件

|层次|现行条件|口径|
|---|---|---|
|初始球形|原库生成角度5–50°，含端点|使用原库`board.angle`，不另加小角度配额|
|路线片段|相对当前观察库切线的角度≤45°|平行库边为0°，垂直为90°；入库前、出库后分别计算|
|B位置|球心到观察的有限直库段≤10cm|按球心，不按球面；同时保证球体不侵库|
|覆盖|第一、第二、第三观察库；A进角袋和中袋|每个观察库独立检查，前面的过渡库不必也满足≤45°|
|最终配额|每个原球形的每条合适存档轨迹最多一题|所有观察库、入库前和出库后的候选合并择一，质量不足不补数|

须区分三个角度：`board.angle`是原库生成字段；图册“球形夹角”是母球→A球心与A→物理袋心两线的夹角；路线角是母球路线与库边切线的夹角。它们不混用，也不把存档折线角当成碰B时的瞬时速度角。

第一库仅作过渡、第二库适合K的路线可以保留；前两库自然、第三库适合K的路线也可以保留。不能因为前面某一库接近垂直，就淘汰整条路线。

## 三 自然路线与B候选生成

目前生成器采用以下工程筛选值，用于排除过于复杂、末段行程不足的路线；这些值是首版实现参数，不是真人难度标定。

|项目|当前值|
|---|---|
|保存打法|杆速≤3m/s，左右打点绝对值≤0.15R，上下打点绝对值≤0.5R|
|从碰A到观察库的路程|第一、第二库≤2.5m；第三库≤3.5m|
|进入观察库的路段及前序各段|长度至少0.4m|
|前序碰库点|距袋口参考点至少0.18m|
|出库后候选的额外条件|出库段至少0.4m，出库后总剩余路程至少0.6m|

R为球半径，杆速与打点使用App模型参数。入库前和出库后使用各自的局部角度；出库后的行程条件不强加给入库前候选。

B位置由“母球轨迹管道”与靠库10cm区域的交集产生：

1. 沿合格入库前或出库后片段建立管道，总宽为球直径的0.9倍，即中心线两侧各0.45个球直径。
2. 用固定种子随机采样，沿片段长度分配候选，再施加横向偏移，保证可复现。筛选后优先管道中心附近且位置有间隔的点，所以最终题集并非区域内均匀随机分布。
3. B球心须落在有限库段范围内、距该段≤10cm；球体不侵库、不与初始母球/A重叠，到各袋口沿的最近距离至少30cm，并避开母球到A的初始进球线路。
4. 沿原路线检查母球首次可能碰B的位置，排除在目标片段之前就先碰B的候选。
5. 每次模拟只放一颗B。每片段最多保留6个随机备选；每条路线、每种时机轮换观察库，最多取4个备选做物理验证。没有采到合格点不等于已证明无解。

管道只负责提出候选，不负责证明K球成功，也不代表碰撞后的轨迹。具体距离与采样细节以[候选生成器](../../research/k-ball-full-20261029/candidates.py)和[路线扫描器](../../research/k-ball-full-20261029/scan.py)为准。

## 四 存档复用与真实物理验证

两球库已经保存的2mm轨迹可直接用于角度、路程、靠库片段和B位置初筛，省去原两球路线的重复计算。复用前核对分片SHA、球位、目标袋、方向、力度打点及库序，避免串用不同版本。

新增B之后必须运行生产三球物理；瞄准、杆速或打点发生扰动时也必须重新模拟。原两球轨迹没有包含与B的碰撞，不能据此证明新题成功。

名义打法检查完整模拟、先碰A、A进指定袋、母球随后碰B，并核对实际K前库序与候选观察片段。保存真实事件、轨迹、输入和失败原因，供独立审计。母球落袋仅记录。

## 五 容错与模拟难度

每个候选围绕名义打法测试三档偏差：

|档位|瞄准方向|杆速相对偏差|左右、上下打点各自偏差|
|---|---|---|---|
|小|±0.05°|±1.5%|±0.01R|
|中|±0.10°|±3%|±0.02R|
|大|±0.20°|±6%|±0.04R|

每档8个单轴端点，加32个四项共同变化的组合点；组合使用16个四维Halton点及其反向配对。完整方案每题120次扰动，另加名义基线。输入不做夹取，无法出杆计失败。

一档通过要求：8个单轴端点全部成功、32个组合至少26个成功，且所有更小档也通过。最大通过档为小、中、大时，分别记“敏感、常规、宽容”；小档未通过的不收入首版。

批量执行可在首个失败单轴，或第7个失败组合出现时停止该档及更高档，因为已确定无法过关；保留停止原因。某路线某时机找到常规及以上候选后停止继续搜索备选，否则从已经通过小档的候选中选优。这是有限预算筛选，不声称找到全局最优位置。

**现有等级的证据边界：**生成时的扰动成功只要求进A、按顺序K到B，库序变化单独记录，不额外判失败。因此这些等级尚未按2026-10-30新增的App观察库次要求做整库重分级，也不是真人成功率。离散探针通过不保证整个连续误差区间都能成功。

## 六 去重与每路线选一题

来源身份采用“原球形ID＋存档路线ID”。不同球形的路线编号可能相同，不能只用路线编号作为全局身份。

首轮先选每路线入库前、出库后各一题，再跨路线合并近似重复：初始母球/A位置、目标袋、时机、观察库及实际K前库序相同，B位置相距小于一个球直径，且K前母球整段路径的双向距离小于一个球直径时才合并。路径加密到≤1cm，并保留5mm距离余量；不只比较终点或吃库数量。

用户随后确认入库前与出库后的重复感较强，最终改为每路线仅一题。对已经验证、去重后的候选排序：

1. 优先较高模拟容错等级。
2. 同档优先保存的管道横向偏移绝对值较小者。
3. 再按稳定题目ID确定顺序。

管道偏移不是实测碰撞余量。最后这次收敛只选取原记录的未修改子集，不移动B、不改杆法，因此复用原物理证据，无须再跑一次模拟。被合并的来源映射与旧题集保留，不能把代表题的新B位置视为已在所有被合并路线中验证。

## 八 App判题与后续复建

App侧沿用观察库口径：第一、第二、第三库的入库前和出库后都算该库。例如第三库入库前K，碰B前实际吃了两库；第三库出库后K，碰B前实际吃了三库。

2026-10-30已将这个要求接入正式提交判题：从真实第一碰A到第一碰B之间统计母球主库事件，再用碰B前方向与B所在库墙判断观察库次；朝库为已吃库数＋1，离库为已吃库数并检查上一主库属于该库墙。库次不符不能成功，事实不足提示无法确认。母球落袋仍不影响结果，旧成绩不回算。

保存打法用于复建和核验；页面默认参考线则是当前三球局面的中杆无塞、2m/s基准，并不是保存答案。用户提交的实际输入仍走生产物理。

复建时按以下顺序执行：冻结源库和规则 → 扫描路线 → 生成B候选 → 名义三球验证 → 容错分级 → 跨路线去重 → 每路线择一 → 独立审计 → 参数打包 → App读取与代表打法回归。改变球位、输入、成功规则或物理版本后，重新确定需要复验的阶段；不能只刷新指纹沿用旧证明。

当前已完成全库生成与审计、参数包及App接入。最新库次修复的13项逻辑测试和3项UI测试通过，其中覆盖一至三库、入库前/后六类代表打法；这不是11,458题的新一轮全库物理复验。下一轮如需让容错等级与当前App库次判题完全一致，应单独开展重分级；实台难度仍需真人标定。
