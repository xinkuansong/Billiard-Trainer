# 台球训练精讲内容规范

> 真源：用户 2026-08-18 过目后定稿；同日二审通过试点重写后补七条细则（v2，见各节「⛔」与新增第十二节）。写作时**语义上遵守**，禁止按模块用脚本填空生成正文。  
> 现网 JSON 节标题仍用 `技术原理` / `开局与击球顺序` / `第N杆` / `常见错误与纠正` / `进阶练习`（C4 / 配图依赖杆节，不改标题）。下表是信息落点，不是另起一套 schema。

| 规范模块 | 现网节 | 是否必写 |
|---|---|---|
| 训练目的 + 原理 / 要点 | `技术原理` | 推荐。无新原理可只留目的一句 |
| 训练设置 | `开局与击球顺序` | 核心 |
| 动作讲解 | `第N杆`（可合并写、锚点详 / 中间档一句或留空） | 核心。⛔ 不删节、不改「第N杆」前缀 |
| 判断 / 常见错误 | `常见错误与纠正` | 有诊断价值才写 |
| 进阶 / 降阶 | `进阶练习` | 有具体路径才写 |

模型约束：`TutorialSection` 只有 `title` 必填——中间档整档留空（只剩标题 + params + 图 + caption）是**合法且推荐**的形态，不必凑句。

---

## 一、核心定位

精讲不是把一个球形「讲完整」，而是让用户：

> **看懂这个球形 → 理解为什么这样练 → 知道怎么打 → 打完知道哪里出了问题 → 能够马上调整并继续练习。**

- **图负责「看见」**
- **文字负责「理解和行动」**
- **击球结果负责「验证和反馈」**

文字不重复图里已经清楚的信息，不为完整而堆理论。

---

## 二、软模板

统一的是信息结构，不是句式和篇幅。某个模块对当前动作没有价值，直接删除。

**模板保证不漏关键维度，不限制表达方式。**

---

## 三、训练目的

一句话说清：这一组到底在练什么能力。指向一个明确训练能力。

推荐：练习不同切角下的接触点控制。 / 在更远距离下重新建立厚薄感觉。 / 练习中袋窄袋口下的瞄准精度。 / 练习进球后母球停位，为下一杆创造可打角度。

避免：帮助提升台球水平。 / 提高进球能力。

---

## 四、原理 / 要点

回答：为什么这样练？只讲当前需要理解的一层。已经在前置课讲过的，不展开。

目标不是把台球物理讲明白，而是让用户知道这个球为什么这样打。

后续课不要反复写「厚薄已经在××里练过」。直接写当前新难点（「这一组把相同的厚薄带到中台」）。前置课名交给 UI 更好，正文不承担点名任务。

---

## 五、训练设置

结构化列出，参数不要散落在后文反复解释。图里已有的摆位叙述删掉。

例：

- **目标球**：8 号
- **目标袋**：左下角袋
- **球袋距离**：约 0.6 米
- **杆法**：中杆
- **力度**：小力
- **训练档位**：8 档
- **切角**：从约 39° 逐档收到约 3°，再打开到约 26°（每档见配图）

距离单位仍走 D-v40-9（≤50 公分用 5 的倍数公分，更远用约 X.X 米）。

⛔ **切角阶梯写走势，不倒数字**：不要把每档度数排成一串（「39° → 27° → 15° → …」）。设置节只描述阶梯形状（从多少收到多少、再开到多少），每档的具体角度归 caption（见第六节）。

---

## 六、动作讲解

围绕：这一杆怎么打，以及这一杆最应该关注什么。

1. **可以逐杆讲**——档位有明显递进时。
2. **可以合并**——连续几档目的相同，写成「第1–3杆｜由厚到薄」。现网仍保留对应 `第N杆` 节（C4），合并发生在**正文**：锚点档写清，中间档只留一句判断**或整档留空**。
3. **关键杆单独强调**——如走位链第 1 杆。

不要求每杆同等篇幅。动作不同，讲解粒度就不同。

`params` 照抄 digest。杆法/力度已在训练设置里写过的，逐杆不再重复。

### 逐杆三个 label 的定义（⛔ 硬约束）

- **为什么**：回答**这一档在整组里的作用**（校线锚点 / 基准档 / 关键停位杆 / 最薄收尾）。⛔ 禁止用参数复读顶位（「约 58°，这一组最薄」不算为什么）。答不出作用就删掉这个 item。
- **怎么打**：只写这一杆区别于设置节的动作要点。
- **自检**：必须是**条件诊断句**——看到 X = 偏 Y，往 Z 调。⛔ 禁止状态描述句（「薄度在加」「站位已换」）、预测句（「常碰袋唇弹出」）、期望复述（「8 号干净进袋」）、鼓励句。

**中间档纪律**：没有该档特有的新判断，就整档留空（标题 + params + 图 + caption），⛔ 禁止为「每档非空」凑一句。档特有指的是只在这一档成立的信号（如「刚从直线打开的第一档最容易仍按直线打厚」「切角和第 2 杆相同但距离更远」）。

### caption 的职责（固定）

caption = **档位标识 + 本档角度**：「第N杆：约 X°」。开局图 caption 可加一短句说明摆位含义。

- ⛔ 逐杆正文（为什么/怎么打/自检）一律不再报度数——角度只出现在 caption。正文要引用别的档位时，用「第 2 杆」「半颗球厚那一档」这类说法，不用度数。
- ⛔ caption 不重复设置节已有的杆法/力度（「中杆、小力」删），也不写正文已说的话（正文说了「最薄收尾」，caption 就只留「第10杆：约 38°」）。
- 球厚语言（半颗球厚、三分之一颗）不受此限，正文可用——它是瞄准语言，不是计量播报。

## 七、判断 / 常见错误

尽量：看到什么 → 说明什么 → 怎么调整。

- 擦袋外侧 → 打薄了 → 多吃一点
- 碰袋唇弹出 → 打厚了 → 少吃一点
- 完全擦过目标球 → 明显打薄
- 母球停位过近 → 打厚了
- 母球停位过远 → 打薄了

一句话能说清就一句话。没有明确诊断就删这个模块。

⛔ **通用诊断全篇只落一处**：「擦外侧 = 薄 / 弹唇 = 厚」这对基础判读只写在本节，逐杆自检不再复述——逐杆只写档特有信号。跨课同理：本节写出来若和前置课一字不差，就换成本课特有的错法（中台课写「近距能进、中台进不去」，中袋课写「撞库弹开」），基础判读交给前置课。

---

## 八、进阶 / 降阶

必须是具体、可执行的动作。没有路径就删。

避免：「如果觉得困难，可以适当降低难度。」

---

## 九、语言

像优秀教练在旁边指导。一句话一个动作或判断。多用瞄准、观察、判断、调整、移动、保持、击打、回到、确认、检查。少用注意、需要、应该、尽量、从而、因此、可以有效地。

「不要」适量。优先正向：先改接触点，再调力度。 / 身体固定，只调整瞄准点。

语域仍走 D-v40-8（类型规则，不是词表）。

### 厚薄 / 力度调整的标准话术（⛔ 硬约束）

| 意图 | 用 | ⛔ 禁 |
|---|---|---|
| 往厚调 | 打厚一点 / 多吃一点 | 接触点向厚侧调整 |
| 往薄调 | 打薄一点 / 少吃一点 | 接触点向薄侧调整 |
| 力度调整 | 力度加一点 / 收一点 | 降半档力度 |
| 幅度 | 一点 / 明显 | 半档、0.5 档（「档」在课里指切角档位，借来量厚薄力度是生造计量） |

「接触点向 X 侧调整」是机械腔且极易复读成模板——试点里曾出现十几次同一句。同一意图在一篇里连用同一句式超过两次，换说法或合并进常见错误节。

## 十、图与文怎么交叉

图资产不动。交叉发生在**同一节里各管一层**，不是另做一套图，也不是让正文给图配解说词。

App 里这一节的顺序是：文字 → 打点/力度 → 图。所以：

> **文先告诉用户看什么、打完怎么判；图随后出示这一档的台面。**

### 同一节的分工

| 节 | 图已经给出 | 文只补图给不出的 |
|---|---|---|
| 开局 | 摆位、标记、袋口在哪一侧 | 训练设置（锁什么、几档、切角阶梯）+ 这一组练哪一维 |
| 第 N 杆 | 这一档有多开、路线、母球大概停哪 | 这一杆盯什么；打完看到什么结果该怎么改 |
| 原理 / 错误 / 进阶 | 通常无图 | 不补几何描写来「代替图」 |

### 允许交叉的三种写法

1. **指认，不描写。** 「看母球停得远还是近。」可以。「母球停在 8 号右上方约 30–35 公分一带。」不行——那是把静帧写成了字。⛔ 可检查形态：**停位诊断只许用相对词**（停太近 / 停太远 / 横开到上路 / 漂到中路），凡「方位词 + 公分数」的停位句一律违规——不管它戴的是「自检」还是别的 label。
2. **用结果说话，不用坐标说话。** 「贴着袋口慢进 = 打厚了。」可以，用户对照自己打完的台面。把示范图上的落点方位抄进自检，不行。
3. **只在诊断需要时写「错位」。** 「停到中路左侧，第 2 杆会更别扭。」可以——这是失败区，图上的正确停位不会标出这块。把正确停位再叙述一遍，不行。

### 禁止的交叉

- 开局文再写「1–7 号沿右侧、8 号在下路」——开局图已经是这样。
- 逐杆文再报一遍袋口、中杆小力、约 39°——节标题、训练设置、`params` 已经有。
- 为了「和图对得上」而补方位词、区域名、颗球/公分停点。需要对齐时，让用户看图，不要让文字代替图。
- 中间档没有新判断时，不要为了配图再写一句摆位。

自测：把图遮住，剩下的句子是否仍能指导击打和修正。若遮住图就不知道球在哪，但这句话离开图也没有动作——删掉这句。

## 十一、防新八股

「不统一句式」不仅指别抄旧模板，也指别让新写法固化成新模板：

- `技术原理` 不强制「目的一句 + 空行 + 原理两句」双段式——一段说得清就一段。
- `进阶练习` 不强制「降阶：…\n\n升阶：…」两行式——有时一句话给条路径更自然。
- 升降阶内容跨课不许雷同复制（「略打厚半档」「再移远约 5 公分」连课出现即返工）。
- **检查方式**：连看三课，若某节的句式结构完全相同，视为模板腔，返工。

---

## 十二、写完自检

- 用户知道这一组在练什么、为什么、怎么打、最该盯什么
- 打错后知道如何判断、往哪调
- 不重复前置课、不描写图上已有的球位/路线/正确停点、不强行凑模块、无教材腔 / AI 腔
- 中间档没凑句（没有档特有判断的档是空的）；正文没出现度数；「接触点向 X 侧调整」「半档」零出现；停位句全是相对词
- 读完可以马上执行

一句话：

> **统一结构，不统一句式；保留信息，不堆砌文字；图负责展示，文字负责指导，结果负责反馈。**
