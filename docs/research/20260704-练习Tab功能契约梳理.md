## 1. 设计语言：「球迹 · 教练仪表盘」

### 1.1 品牌概念

**一句话**：台面是世界，其余皆仪表。

个性三关键词：**精密**（仪器感：刻度、等宽数字、细线）、**教练**（战术板：标注与解，非游戏特效）、**专注**（夜场聚光：黑场、无噪音元素）。场景页 = 教练手里的测量仪表盘；任何元素先问「它是仪表盘上的哪件仪器」，说不清就不该存在。

### 1.2 签名元素一：轨迹与标注语言（App 就叫「球迹」，线即 logo）

**适用范围 = App 内 8 场景页 + 渲染管线全部产物**（`SequenceVideoExporter` 的静帧/cover/preview/gif/视频、缩略图）——用户在抖音看到的线和 App 里的线必须是同一套。

**两条正交规则（实现时发现「球迹线金」与「进球线绑球色」在翻袋/反射页冲突，收敛为身份色系统）**：
- **线色 = 球的身份**：白 = 母球的路径（瞄准线、母球走位、反射绕库路线）；目标球本色 = 该球的路径（进球线、联动球轨迹；黑 8 等深色取亮灰变体）。
- **线型 = 信息性质**：实线 = 真实模拟/解路线；虚线 = 理想/自动解对照；短虚线 = 理论释义（90° 分离角、进球垂线）。

| 线/标注 | 含义 | 颜色 | 线型/粗细 |
|---|---|---|---|
| 瞄准线 / 母球路径 | 母球即将走的（含反射解路线） | **白，固定** | 实线，`lineMain` |
| 进球线 / 目标球路径 | 该球即将走的（含翻袋解路线） | **绑定目标球本色** | 实线，`lineMain` |
| 对照线 | 理想/自动解参考 | 白 | 虚线，`lineHint`（弃蓝） |
| **90° 分离角释义线** | 过**假想球球心**、垂直于撞击线的切线（母球碰后走向） | **品牌绿**（DR-021 弃白：定杆时与母球白轨迹共线重合） | **短虚线**，`lineHint`，约 2–3 颗球长 |
| 假想球 + 接触点 | 瞄准落点 | 品牌绿圈 + 绿点 | `lineHint` |
| 角度弧 | 切角/分离角 | 品牌绿弧 + 白读数 | — |
| 方案标记 | 反弹点、解高亮 | 金（btAccent）——金退出轨迹，专属「方案/量值」 | 点/pill |

粗细两档 token：`lineMain`（母球/目标球路径同粗）、`lineHint`（释义层细一档）。现状违例：瞄准线与进球线粗细不一、对照线蓝、90° 线暖黄/青两套、翻袋反射解路线黄——全部收编。

### 1.3 签名元素二：重叠标注（全局默认的「角度→打点」教学层）

用户在**每个有瞄准的页面**都应潜移默化看到「这个角度要打哪里」。定义三档重叠标注，逐页按档配置（取代 SPEC §8.2 的裸开关矩阵，每页给**理由**）：

- **L0 基础档（默认，所有瞄准场景常驻）**：假想球虚线圈 + 接触点绿点——重叠关系由圈与目标球的交叠直接呈现，零文字零占位。
- **L1 读数档**：L0 + 切角小数值（贴弧）。用于练/解类需要读数的页。
- **L2 全指标档**：L0 + 顶部完整指标条（切角/厚度图示/d/R/横移/偏移）。**仅「角度与打点」一页**——它是教学页，指标条就是内容本体；其他页嫌占空间的根因是错用了 L2，降档即解。

各页何时显示瞄准线/进球线也必须有理由，写入逐页节（§3）：原则=**「用户此刻的任务需要哪条线」**——瞄准任务显示瞄准线，进球判断任务加进球线，走位任务加球迹线；不为装饰画线。

### 1.4 签名元素三：读数胶囊（`BTReadout` 仪表窗）

所有数值读数统一：小号灰白 label + 等宽圆体大 value，暗色半透明胶囊。**金=可调量值，白=测量结果，红=失误**。抽 `BTReadout` 组件换装 8 页 + 导出 HUD 条同款式样。数字一律 `.rounded + monospacedDigit`。

### 1.5 签名元素四：交互语言（瞄准与力度，本轮重做）

**自由瞄准（现状不好用，重做）**：
- **粗调 = 手指跟随**：台面空白处拖动，瞄准方向实时指向手指（指哪打哪）；球上起手仍是移球（命中判定球优先）。
- **细调 = 贴缘刻度轮**：只画刻度（1°/5°/10° 三级刻度线），**不显示角度数值**（打点要精确到毫米级，看的是台面效果不是数字）；越整度轻触感保留。
- **砍**：瞄准线上的手柄圆环（完全去掉）；现刻度轮的数值胶囊。

**力度控制（现状简陋，重做）**：
- 竖直贴缘**力度柱**：离散档位（步进 detent），填充色随力度低→高渐变（克制暗调：暗绿→暗金→暗橙，禁高饱和）；端头 `BTReadout` 读数（金）。
- **打点盘迷你图示置于力度柱上方**（点开 Z7 打点盘 sheet），构成一列「打点+力度」仪表柱。
- 与瞄准刻度轮**分居两侧**（默认左=瞄准轮、右=打点力度柱；真机手感后可对调）。
- 底部条随之简化：击球主按钮 + 球库（+解类的求解/试打）。`ShotControlBar` 升 v2。

### 1.6 签名元素五：大字海报卡 + 暗场仪表感

入口卡「渐变底+单字水印」固化为品牌元素（单字即页面图腾）。场景页恒黑底 + 暗材质胶囊 + 绿标题；**一切浮出层（设置 sheet/打点盘/原理页）统一暗材质**（实拍瞄准训练设置 sheet 浅色违例）。绿金信号四通道之外不引入新色。

### 1.7 HUD 视觉风格：「仪表玻璃」（骨架与零件之上的皮肤）

> 七分区是骨架、读数胶囊/仪表柱是零件，本节定皮肤——所有 HUD 元素的统一外观配方。目标：任何一页截图裁掉台面，剩下的 HUD 也能认出是球迹。

**材质配方（`hudGlass`，唯一真源）**：
- 底：黑 60% 半透明 + 背景模糊（暗玻璃）——收编现状混用的 ultraThinMaterial / 纯黑 / 灰三种底。
- 描边：0.5pt 白 12% 发丝线（仪器边框感，黑场上代替阴影做分层）。
- 阴影：无。黑场上光效一律禁止——克制是仪器感的来源；全 App 唯一允许的"光"是球迹线端点渐隐（§1.2）。

**形状语法（只有三种）**：胶囊（chip / pill / 读数 / 按钮）、正圆（FAB / 打点盘 / 假想球圈）、圆角矩形（面板 / sheet，radius 用现有 token）。出现第四种形状即违例。

**HUD 文字层级（三级）**：
| 级 | 用途 | 式样 |
|---|---|---|
| label | 读数名 / chip 文字 | 11pt semibold，白 55% |
| value | 数值 | 15pt bold rounded mono，白（测量）/ 金（可调）/ 红（失误） |
| title | 页内小标题 / sheet 标题 | 14pt semibold，品牌绿 |

**状态语法（chip / 按钮统一）**：未选 = 仪表玻璃底 + 白 75% 文字；选中 = 品牌绿实底 + 白字；禁用 = 文字 30%（治实拍确认钮禁用态难辨）；量值永远用金色的是**数字本身**而非容器——绿管选择、金管数值，容器不抢色。

**刻度语法（瞄准轮与力度柱同一视觉家族——左右两根「尺子」）**：三级刻度线（长/中/短 = 白 40% / 25% / 15%），无数值；当前位置指示 = 金色短线（力度柱为金色填充水位）；越档轻触感。两根尺子式样完全一致，只是一根管方向、一根管力度。

**图标**：仅 SF Symbols monochrome（`Image.btSymbol` 已封装），两档尺寸；禁多色/层级渲染模式。

## 2. 场景页骨架：HUD 七分区

| 区 | 位置 | 仪表盘角色 | 允许内容 | 禁止内容 | 组件 |

| Z3a 贴缘仪表柱 | 左右缘 | 精调旋钮 | 左：瞄准刻度轮；右：打点+力度柱 | 其他 | `BTAimWheel` / 力度柱 |
| Z4 方案 pill | 左下浮层 | 表盘：解/结果摘要（只读） | 方案 pill、失误 pill | 交互控件、与 Z1 重复状态 | `BTReadout` |
| Z5 FAB 列 | 右下 | 快捷键 ≤3 | 重置/下一解/辅助/答题 | 主执行动作 | `BTSceneFAB` |

铁律：① 顶定义问题、底执行动作（判据：改它是否重新定义问题）；② 状态只出现一次（Z1 副标题 vs Z4 pill 不重复）；③ 新控件先归区再选组件。

## 3. 逐页应用

### 3.1 学（四页全部真台化：插图/交互图一律用真实 2D 球桌渲染，风格与场景页同源）

**① 瞄准原理** — 讲切角/假想球/厚度+公式。
改：**示意图卡全部换真实 2D 台渲染**（离屏渲一次缓存成图，含 §1.2 线语言）；术语（切球角→切角、幽灵球→假想球）。增：页末 CTA「去练一练→角度预测」。

**② 角度与打点** — 拖两球实时看联动，L2 全指标档唯一持有页。
改：台面重叠标注按 §1.3 L0 升级常驻（假想球圈+接触点醒目化）；蓝色角度标注收编白/绿；90° 分离角短虚线加入（本页最该有）。增：首次「可拖动」提示。

**③ 浅谈球感** — 方法论+四档厚度锚点。
改：**四档锚点卡换真实 2D 渲染**（从母球视角的两球重叠，真台材质）。增：CTA「用真台验证→2D 瞄准训练」。

**④ 进球点对照表** — 速查工具。
改（重设计）：抽象圆盘 → **俯视图真台渲染**：目标球+假想球+袋口方向，拖滑条时假想球绕目标球转动，**同时看见瞄准点（母球方向）与接触点**；对照表保留。幽灵球→假想球。

### 3.2 练

**⑤ 角度预测**（卡改名与页内一致）— 抽象估角第 1 步。
改：**题面换真实 2D 球桌与球**；参考线补 90°、修 75° 标签裁切（现 [15,30,45,60,75] 无 90，实拍 75° 文字被裁）；辅助线用 §1.2 语言；确认钮禁用态对比度。增：答错「回看原理」、结束「去真台练」。

**⑥⑦ 2D / 3D 瞄准训练（拆两卡）** — 俯视练几何判断 / 站位练临场球感。
拆法：单 View + 两 route 传 `initialCameraMode`，隐藏页内 toggle，成绩分记。
改：**入口流程重做**——点卡先弹训练设置（模式/类型完整选项）再开始，训练中齿轮可换；辅助瞄准线/进球线/90° 分离角短虚线全部走 §1.2 统一语言（与其他页同色同粗细）；重叠标注 L1 档；统计 chip 加单字前缀（题/袋/力/剩）；设置 sheet 暗材质。

### 3.3 打

**⑧ 自由击球** — 编排台 `.free` 入口卡，保留；开球能力见 ⑨。

**⑨ 走位编排台（旗舰）** — 逐杆编排推演。
改：**自由瞄准重做**（§1.5：手指跟随+无数值刻度轮+删手柄圆环）；**ShotControlBar v2**（右缘打点+力度柱，底部条简化）；**内置「开球」**（吸收球形生成器）：球库行加「开球」入口 → Z7 弹玩法选择（中八/9球 4/5/6/9）→ 台面摆架+白球开球区可拖 → 主按钮「开球」真实物理散局就地落座；失误态去重（保红 pill，Z1 副标题回中性）；重叠标注 L0 常驻。

**⑩ 分离角与走位** — 教学演示碰后走向。
改：分离角弧+90° 短虚线升级常驻主角（L1 档）；交互与力度同 ⑨ 新语言。v1.x：预设案例库。

**⑪ 球形生成器 — 下线（页面级砍除）**。
职责已无独立闭环：开球功能内置进编排台/思路/三杆（复用 `RackLayout`/`BreakSimulator`/开球区拖白球交互，core 零浪费），入口卡移除。「打」分类剩四卡（自由击球/分离角/编排台/拍照）。

**⑫ 拍照建球形（供给页）** — 照片→球形。
增：送入扩三目的地（编排台/思路/三杆）；步骤指示（1 选图·2 标定·3 标球·4 确认）。

### 3.4 解

**⑬ 思路训练器** — 单杆走位反解。
改：求解三态（就绪「设好约束点求解」→求解中→有解读数 n/N / 尚无解+降级）；**内置「开球」**（同 ⑨）；重叠标注 L1；解读数走 `BTReadout`。

**⑭ 打一走二想三** — 三杆规划。
改：**角色选择从右侧竖排移到底部**——Z6 内球库行上方加一行横排角色 chip（球1→袋→球2→袋→球3），台面恢复全宽（治实拍压窄）；余同 ⑬（三态、开球、L1）。

**⑮ 做斯诺克** — 安全球反解。同 ⑬ 三态；遮挡可视化保留；无开球（斯诺克不需散局，维持摆球）。

**⑯ 翻袋解球器** — 目标球翻库进袋。
改：**袋口选择改台面直点**（点袋口高亮圈），顶部重排 行1=库数、行2=理想/真实+力度（治滑条截断）；进球线按 §1.2 绑目标球色、对照线白虚线弃蓝；发力→力度；页内标题补「器」；多解则补「下一解」FAB 对齐反射页。

**⑰ 反射解球器** — 母球绕库碰球。顶部结构即目标形态；改：发力→力度、线语言收编。

## 4. 全局统一项

1. **页名 = 入口卡名**（违例：角度预测、翻袋解球器）。
2. **术语词表**（落 SPEC）：切角/假想球/力度/厚度/横移 mm/偏移 %/塞/打点/库/分离角。
3. **渲染管线同语言**：`SequenceVideoExporter` 线色/线宽/打点指示/力度 HUD/读数式样与 App 内同 token 同源（改 token 两边同时生效）。
4. **求解三态**（思路/三杆/斯诺克）。
5. **Z7 浮出层一律暗材质**。
6. **埋点骨架**（B5 接线）：`practice_enter / practice_core_action / practice_result / practice_handoff`。

## 5. 结论清单（默认按此执行，可逐条否决）

1. 线语言 7 项 token：瞄准线白固定、**进球线绑定目标球本色**（深色球高明度变体）、球迹线金、对照线白虚线、90° 分离角白短虚线、假想球绿圈、两档线宽——App+渲染管线同源。
2. 重叠标注三档 L0/L1/L2：L0 全瞄准场景常驻（潜移默化教「什么角度打哪里」）、L2 仅角度与打点页；辅助线显隐逐页给理由。
3. 自由瞄准重做：手指跟随粗调 + 无数值刻度轮细调 + 删手柄圆环。
4. 力度控制重做：右缘竖直力度柱（离散档+克制渐变色+BTReadout 读数）+ 打点盘置顶成仪表柱；ShotControlBar v2。
5. 学练四页真台化：原理插图/球感锚点/对照表俯视交互图/角度预测题面全部换真实 2D 渲染；角度预测补 90° 参考线、修 75° 裁切。
