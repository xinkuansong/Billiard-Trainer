# 摄像机截图与观察范围：独立反方

2026-10-02。只制定文档标准，未截图采集、测试、构建或设备负载。读取现方案/验收契约、10-01覆盖审查与通用观察方法，参考项目截图审查规则的原图与用户视觉否决原则；本文件不是实际UI截图审查结果，所有新观察能力均UNVERIFIED。

**关键异议：C05安全/远端全桌与C06诚实受限，不足以证明常规观察可用。** 它们保证“不穿实体、不误报”，却允许每个难球都返回limited或建议2D。用户要求的观察范围必须另有必须达到的任务与场景；2D作为读盘能力保留，但不能替代常规3D观察验收。

## 1. 观察任务与状态分层

先冻结ObservationDomain：场景/主体角色、普通球距/切角/球数/遮挡/HUD范围、允许轨道与镜头、默认entry含义和完成操作预算。不能仅把profile能输出的域定义为常规域，从而排除所有失败盘面。

| 状态/任务 | 必须达到的观看结果 | 不应强加的结果 |
|---|---|---|
| TP标准进入/显式归位 | 在声明常规域内辨认母球、当前目标、真实目标袋口与必要路线；有上下文和足够屏幕尺寸 | 不是任意盘面所有球/全部复杂路线同框无遮挡 |
| TP整盘阅读端 | 可辨桌界、六袋空间关系及在桌球分布，HUD不吞掉关键边界 | 不要求此档所有球号都朝向相机或近景大小 |
| TP主动细看/近端裁桌 | 所选细看区域可达且能辨；进退/绕桌连续、可逆并能回到声明标准态 | 不因用户主动裁桌而要求全盘仍入框 |
| FP杆轴基准/headYaw=0 | 母球、真实杆尖/杆轴方向可读；近裁剪/HUD不破坏本模式任务 | 真实瞄准透视下不无条件要求目标袋与所有球路同时可见 |
| FP主动转头 | 视线能按允许角域观察对应区域，眼位/击球参数/owner保持；可明确回杆轴 | 任意headYaw都看得到母球/目标/袋不作为通过条件 |
| 击球过程/杆末TP | 本阶段必需运动主体与事件结果可读，旧离台目标不继续当必需主体 | 不偷继承未裁定capture时机，也不要求球/袋始终无重叠 |

主体列表由本阶段真实业务状态给出，不能沿用旧杆/旧目标。自由瞄准、开球和无指定袋沿相同角色规则表达，不虚构目标；球号码只能按真实可见方向/角色辨识，不强求每一颗球的号码同时朝向观察者。

建议区分：**adequate**当前姿态完成任务；**reachable**当前不足但允许轨道中有已知可达姿态及清楚操作；**limited**有具体不能兼顾的原因。常规任务的必须通过项只能以adequate或冻结操作预算内达到adequate通过；limited、搜索未找到和“可切2D”不是成功等级。

默认标准entry与保留手动姿态分开验：标准entry承担其构图承诺；手动记忆/中断恢复只需保实际状态与可恢复能力，不得为了标准构图夺回owner。手动绕到桌背/转头看别处不算自动相机失败。

## 2. 固定轨道与主体舒适构图的矛盾必须显露

台心固定、眼高/FOV固定可以让控制简单，却未必让角袋、薄球、远距离球与HUD同时可读。第三球不占击球通道也能遮住目标；同眼位扩大FOV不能解除遮挡。球很小、袋嘴被库/皮革挡住、路线低对比，都不是“中心入框”能通过的项目。

常规域需要分别记：整球/真实开口入框余量、真实几何遮挡比例、HUD交叠、屏幕尺寸、可见区域宽度与角色可辨性。裁切/HUD不减少可见比例分母，不能只露一点仍报100%；高可见面积也不保证号码或开口可读。

独立已知可用角必须附相同资产/球/HUD下实际姿态与图像。若允许轨道内存在adequate姿态，常规路径须能在冻结操作预算内到达；若轨道全部不可读，但允许安全眼位域内有adequate姿态，则是固定profile/语言与任务冲突，须修profile或明确产品取舍，不能用2D把3D项改PASS。不为每球形搜索仍可采用轻量可读性判定和统一可达操作，不需要退回任意自动相机搜索。

真实几何确实不可兼顾时保留构造性受限证据；“有限样本没找到”不等于全域无解。固定中心/高度是待裁定推荐，不是发生观察失败后不得调整的用户铁律。

屏幕大小、visibleFraction、HUD margin及完成动作数的阈值都须版本化冻结。建议先用非验收集的原尺寸辨识任务校准，再冻结保留集；不能用裁剪放大图替代实际页面可辨。不给任意新像素数或65%中央矩形冒充已批准通用标准。

| 场景轴 | 必须包含的族/边界 | 观察判定关注点 |
|---|---|---|

四个构造反例必须保留：①中心入框但真实主体被球/库挡；②远端全桌但目标小到不可辨；③默认机位不足、邻近合法轨道角adequate却无明确可达操作；④所有声明轨道姿态不足、另一个合法安全眼位adequate，揭露profile与观察任务冲突。每例的可用姿态需独立证明；采样最佳不称全局最优。

覆盖报告按独立布局数、状态序列数、设备/aspect重复数、角域/分支命中与失败分别计数。10-01报告已指出“3072”只是1024布局×3比例，63图只覆盖14球形；不能复制这一数量口径证明一般盘面。生成/调参集与冻结保留集分开；有限截图补视觉证据，不替代连续安全或全域可达证明。
