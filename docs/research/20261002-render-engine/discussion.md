# 交叉讨论与主控裁决

2026-10-02。第一轮三角色独立研究，第二轮互读并回应，独立评审逐项质疑。参与角色继承本会话模型；相同结论不是统计独立实验或性能证据。主控直接核对生产 profile、调用入口、资产结构、历史失败指标及决定性的 SDK/官方能力。

## 讨论如何改变建议

| 争点 | 首轮意见/风险 | 实质挑战 | 收口 |
|---|---|---|---|
| 活动状态 | 部分共享入口可能持续工作 | 每日已显式接入，不能解释每日动态发热；代码条件不等于实际 present | 管线接受拆成非每日覆盖、每日 idle、每日动态三条；不预设根因 |
| 专用 Metal 的价值 | 显式控制看起来适合受控台球场景 | SCNProgram 已能替换完整对象 shader/buffer，SCNRenderer 已能受控提交；为何必须重写？ | 引擎和管线撤回自动进入 Metal 的顺序；先证明窄路径仍不能消除的实际限制 |
| 同公式是否节能 | 相同积分迁入新宿主 | 控制更多不自动更省电；编译成本也未必相同 | 分宿主与算法两轴，必须说明消失的工作和新增成本，完整页配对 |
| 资产数字 | 桌体几何与纹理容量很大 | 源面不等于 GPU draws/tiler，RGBA8 模型不等于驻留；可能 fragment 限速 | 资产路线按具体 counters 决定，冷准备与持续负载分账；不把大资源定为发热根因 |
| 反射缓存依赖 | 首轮建议广泛纳入主题/曝光键 | 缓存应看实际捕获输入，不能由最终输出设置无条件触发重烘 | 资产撤回宽泛键：先规范捕获scene/材料；保留桌fragment高光映射是实际输入例外，首次访问状态风险待测 |
| 基线 A/R | 首轮原型描述使用“原 A” | 每日当前是 R；历史实验 A1 又是另一命名 | 当前每日 R 对 R，共享 A 另池；不能再计旧 64 次球面反射消融收益 |
| Filament 次序 | 专用 Metal 后的备选 | 成熟材质/透明/工具链可减少维护成本 | 次序仅是研究投入建议，非性能排名；实际维护成本可让 Filament 提前 |
| RealityKit | 新系统能力丰富 | 公共正交/受控 renderer 最低 18，17 的 ARView 不等价；不可泛称其不能 3D | 按当前统一出口需求不推荐完整替换；系统/出口边界改变后重新评估 |
| 迁移是否必做 | 研究容易持续扩张 | 如果资产或中间 SceneKit 路径达标，为什么再写引擎？ | 各角色接受明确停止：目标达成则撤销当下节能驱动的全面迁移 |
| 验收门槛 | 可以给一套通用目标 | 每日 09-27 与共享 v62 的范围/严度不同；旧呈现统计有反例 | 两套原线分列保留，不用新百分比放宽，也不恢复旧失败帧率/优化幅度结论 |

管线完整回应见 [pipeline.md §8](pipeline.md)，引擎回应见 [engines.md §9](engines.md)，资产追加回应见 [assets.md](assets.md)，评审质疑与回应状态见 [review.md §3](review.md)。引擎报告已直接更正 §6 P1 的 A/R 基线，并注明首轮 Metal 建议受交叉审计条件约束。具体代码/API证据保留在各自报告，不以本表代替。

## 独立事实复核与时点

主控复算了桌体 PNG 像素量与 USD 面扇复杂度，与资产角色结果一致；实际驻留和 GPU 瓶颈仍未知。SDK 精确方法标注确认 SCNProgram buffer binding 为 iOS 9；RealityRenderer、OrthographicCameraComponent 为 iOS 18。Filament 官方版本与接口核验固定 v1.77.2，而非漂移主分支。[复核证据](host-evidence.md)

资产附录现已真实落盘并经主控全文复核：反射捕获使用替代相机，但原桌材质曝光派生的高光fragment映射仍参与；首次捕获与后续style miss的主题/动态uniform状态可能不同。主控直接检查对应shader和setup调用顺序后认可该风险描述；它尚无像素反例，不列为已证缺陷。未来版本键先规范捕获依赖，再决定哪些变化真正失效，不能把“扩大缓存键”本身视作优化结果。

并发房间任务在研究期间形成用户选定的 8×6 m 试用集成。开始时源码快照、资产 08:17 读取及随后 PROGRESS 状态分别保存；房间任务报告的构建/测试不是本轮验证。首轮“尚未选定”措辞应纠正为当前已选定试用，原测量 SHA/时间不回写成新版本证据。后续 S0 重新冻结完整获批包。

## 主控决定

采纳 SceneKit 优先、按 limiter 逐步缩小改动的近期路线；保留 Metal 和 Filament 的反例竞争。没有采纳任何“已经最低能耗”的结论，没有启动引擎迁移或变更最低系统。

最低成本的可执行起点是当前 R 的可信全页测量及一项已证热点优化。完整要求、未来晋级及停止条件见 [最终建议](RECOMMENDATION.md)。未决项只由实验关闭：真实呈现、当前动态 limiter、资源驻留、同画质跨宿主差异和长时能耗。讨论收口不代表这些门槛已通过。
