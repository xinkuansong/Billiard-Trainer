## 二 页头结构（编号 + 名称 + 一句话陈述卡）

顺序固定：**编号 chip → 页名（由 `navigationTitle` 承担，正文不重复大标题）→ 一句话陈述卡**。

- **编号 chip**：`Text("T03")` + `.font(.btMicro.weight(.semibold))` + `.monospacedDigit()` +
  `.btTextTertiary` + `Color.btBGTertiary` 胶囊。安静、次级，只作**页面标识**。
  ⛔ 编号不得进正文句子（红线 3：不出现「根据定理 T03」「T03 告诉我们」）。
- **一句话陈述卡（r1 改）**：就是一张普通 `LearnDocSectionCard`——**结论主句当卡标题**
  （`.btTitle`，与现有学页首卡同层级），结论后半句走 `LearnDocText.body`，
  适用边界走 `LearnDocText.footnote`。API：
  `TheoryPageHeader(pageID:headline:detail:caption:)`。⛔ 不再另立 `.btHeadline` 题眼字号。
  取材：`theorem-tags.json.statement_one_liner`；**允许口语化微调**（`statement_one_liner` 含
  `OB` / `cut` / `stun` 等术语，正文页应改成人话），但**不得引入原文没有的断言**，
  微调后在该篇的取舍对照表（W1 产出）注明「改写：原文 → App 版」。
- 陈述卡下可紧跟一行 `LearnDocText.footnote` 作适用边界的一句话预告（可选）。

> 与索引页副标题的区别（**W1 按 X-v30-2 更新**）：索引页副标题原为「只准截断」，现放宽为
> **允许语义等价的限定改写**——可换中文人话，但不得新增断言、不得改变适用条件、不得改动
> 数值 / 单位 / 关键限定词，且每条须在转写模板 §六 留取舍记录。约束由 `TheoryCatalogTests`
> 的四道断言（数值单位守恒 / 语义锚词 / 无拉丁字母 / 逐字与改写条目集合固定）固化，
> 原「连续子串」断言已被替代（不是删除）。详情页正文口径不变（允许口语化转写，禁造新断言）。

## 四 配图（硬性要求）

> **来源**：W1 人工验收未通过（用户原话「没有说明图，很不满意」）。自 r1 起，
> **配图不是可选项**：⛔ 深链现有学页**不能**代替页内说明图，深链只作「看更多」。

### 4.1 硬性下限

- **每篇理论页至少一张页内说明图**，放在**对应正文节的 `LearnDocSectionCard` 内**（图文同卡，
  同现有学页），⛔ 不单独堆成「插图节」。
- 图框统一：主图 `.frame(height: 250)` + `.clipShape(RoundedRectangle(cornerRadius: BTRadius.md))`；
  配文小图 80–90pt + `BTRadius.sm`（范式 `AimingPrincipleView.thicknessCanvas`）。
- 图必须给 `accessibilityIdentifier`（UI 测试断言「图在页面上」）；抽象图示另加
  `.accessibilityElement(children: .ignore)` + `.accessibilityLabel(<一句话说明>)`。
- 交付时 UI 测试须断言每张图存在（范式 `V30W1TheoryPageUITests.capturePage(figureIdentifiers:)`）。

### 4.2 图类型决策（先判类，再动手）

| 这篇讲什么 | 用哪种图 | 组件栈 | 红线 5 |
|---|---|---|---|
| 两球碰撞 / 瞄准 / 分离角 / 走位方向等**物理几何** | 真台标注图 | `BTTableFigure` + `FigureLine` + `BTFigureBall` / `BTGhostCircle` / `BTContactDot` / `BTAimPointDot` / `BTFigureTag` | 不命中（几何由真源函数算，不是编排局面） |
| 决策 / 流程 / 分级 / 权衡等**战术抽象** | 非球形抽象图示 | `GeometryReader`（或 `Canvas`）+ `Path` / `RoundedRectangle` + **仅** token 色 | 不命中（图里没有球） |
| **具体战术局面**（哪颗球在哪、怎么被挡死） | ⛔ **不画** | — | **命中**：登记文字描述（球形要点，不含坐标）交人工编排台录制 |

### 4.3 真台标注图骨架（照抄）

```swift
private struct XxxFigure: View {
    let cutAngleDeg: CGFloat            // 需要 θ 联动时才要
    var body: some View {
        let scene = SpinAndEnglishGeometry.scene(cutAngleDeg: cutAngleDeg)   // 几何真源
        let n = scene.potDir
        let t = SpinAndEnglishGeometry.tangentDir(scene: scene)
        return BTTableFigure(orientation: .landscape,
                             closeup: (center: CGPoint(x: 0.40, y: -0.16), halfHeight: 0.36)) { proj in
            let d = proj.ballDiameter
            let target = proj.point(x: scene.target.x, z: scene.target.y)
            // …真源点 → proj.point(x:z:) → Path 描线 / .position 摆球…
        }
    }
}
```

约束：

1. **几何一律取真源函数**：`SpinAndEnglishGeometry`（切线 / 三路径）、`AimingMethodsGeometry`
   （切角 / 假想球 / 接触点 / 管道）、`AimPointGeometry`、`AngleSceneCalculator`（球径 / 袋口）。
   ⛔ 页内禁止手填球位坐标常量凑图；只有「线段画多长、标记画多大」这类**纯视觉长度**
   可以是本页常量，且须集中成 `private enum Metrics` 并注明「不参与几何断言」。
2. **动手前回显坐标契约**（技能 `geometry-spatial-reasoning` §1）写进视图文档注释：
   SceneKit 世界台面米坐标，水平面 X–Z（`CGPoint.x` = X、`.y` = Z），Y 朝上，原点台心；
   `.landscape` ⇒ 屏幕右 = +X、屏幕上 = −Z。世界 → 视图为**均匀缩放**线性映射
   （`Backdrop.imagePoint` 与 `TableFigureProjection.point` 的 x/z 系数同为 `H/(2·orthoScale)`）
   ⇒ 世界直角在屏上仍是直角，可以放心画直角标记。
3. **线语言只走 `FigureLine`**：`aim` 白实线（瞄准线 / 母球路径）、`pot(number:)` 进球线、
   `hint` 白虚线（对照 / 连心线）、`separation` 品牌绿（90° 分离角 / 切线，DR-021）、
   `contact` 假想球圈与接触点、`aimPoint` 红点。线宽用 `proj.lineMainWidth` / `lineHintWidth`。
4. **图要出不变量断言，不许「看着像」**：新增图须在 `QiuJiTests` 落一条几何不变量用例
   （范式 `TheoryFigureGeometryTests`：垂直 / 长度 = 2R / 端点不出取景框），并在汇报里给出
   「图元 ↔ 真源函数」映射表。
5. **能复用就别新造**：现成图先查 `SeparationPathsFigure`（碰后三路径，`emphasizeAll: true`
   三条同显）、`AimingFigure`（切角全景）、`thicknessCanvas`（两球厚薄特写）。
6. θ 联动可选：需要时加 `LearnControlStrip.Theta`（位置：页头卡之后、首张图之前），
   并在 caption 里写清「教学折线示意 / 非精确物理角」。⛔ 别为了加控件而加。

### 4.4 抽象图示骨架（战术类）

- 范式真源：`SpinAndEnglishView` 打点盘、`ContactPointTableView` 正弦曲线。
- 只用 token 色：`.btPrimary` / `.btWarning` / `.btAccent` / `.btBGSecondary` / `.btBGTertiary` /
  `.btSeparator` / `.btText*`，⛔ 无字面色值。
- 布局按 `geo.size` 比例算，⛔ 不写绝对 pt 常量堆坐标。
- **只画正文已有的断言**：轴不标正文没给的连续标度（定性「低 / 高」即可），
  节点文字取正文原句短语，⛔ 不新增概率 / 分档数字。
- W1 已落地样板：`ThreeQuestionFlowFigure`（三问 → 开打 / 安全球流程 + 硬性项虚线支路）、
  `RiskRewardZoneFigure`（把握 × 代价四区，分界线 = 及格线）。

## 五 误区卡样式

每篇**必有**一张「常见误区」卡，放在正文末、页尾互链区之前。

- 组件：`TheoryMistakeCard(mistakes:)`（W1 落地，内含下述样式；不要手写重复实现）。
- 容器：`LearnDocSectionCard(title: "常见误区")`。
- 每条（**r1 改为现有学页旁注范式**）：`HStack(alignment: .top)`，左侧
  `Image(systemName: "exclamationmark.triangle.fill")` `.font(.system(size: 13))`
  `.foregroundStyle(.btAccent)`，右侧两行——**误区说法**（`.btSubheadlineMedium` + `.btText`）+
  **为什么错 / 正确说法**（`.learnDocFootnoteStyle()`）；整条 `.padding(Spacing.md)` +
  `Color.btAccent.opacity(0.10)` 底 + `BTRadius.sm`。真源：`AimingPrincipleView` 名词系统卡旁注。
- 取材：`theorem-tags.json.<T>.common_errors`（原文是速记短语，需展开成人话）；
  ⛔ 不得新增 contracts / 16 原文里没有的误区。
- 条数 2–4 条；`common_errors` 多于 4 条时取业余高频的前 3–4 条，其余在取舍对照表记「剔除」。

> 参考既有实现风格：`AimingPrincipleView` 名词系统卡末的金底误区提示（P18 B3.7 P1.3）。
