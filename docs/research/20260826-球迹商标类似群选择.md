## 1. 类似群是什么（三层，不要混）

```
第 9 类（尼斯大类：计算机软件等商品）
  └── 类似群 0901（中国《区分表》再分组）
        └── 具体项目：可下载的手机应用软件、计算机软件（已录制）…
```

| 层 | 是什么 | 申请书填不填 |
|---|---|---|
| 国际分类（1–45） | 尼斯大类。官费按类计 | 填类别 |
| 类似群（四位，如 0901） | 商标局把「容易误认」的项目编成一组，作类似关系的**主要参考** | **不填**。申报指南：不可填写类似群号、类似群名称 |
| 商品 / 服务项目（六位编号，标准名在编号前） | 专用权真正钉死的对象（2019 第 56 条 / 2026 第 71 条） | **只填名称**，不填编号 |

分类指引原文结构（事实）：

1. 大多数情况下，**同一类似群内构成类似，不同群原则上不构成类似**。
2. 有些群再分成（一）（二）（三）……**同一部分内原则上类似；不同部分是否类似，看该群后面的「注」**。4104、4105 属于这种。
3. 有些项目与**其他群**构成类似或交叉检索，也写在「注」里。漏看「注」，检索和保护都会有洞。
4. 区分表未列的新业态：按相关公众认知综合判断。

申报指南还规定：既可以报标准名，也可以报未列入区分表但符合分类原则的名称；优先标准名。含混、过宽、广告性修饰（「智能走位软件」「台球训练 App」）容易被补正或不予受理。

## 2. 类似关系在不同程序里不是同一把尺子

| 程序 | 区分表的地位 | 对球迹的含义 |
|---|---|---|
| 注册审查、驳回复审 | **原则上以区分表为依据** | 核心群被占 → 几乎必驳（H3/H4） |
| 异议、不予注册复审、无效 | **参照**区分表，结合指南个案判断 | 不同群、甚至跨类（软件商品 vs 培训服务）仍可能被拉成类似 |
| 侵权诉讼 | 法释第 11–12 条：功能 / 渠道 / 用户综合判断；区分表是参考 | 只报了 0901 软件，挡不住别人在诉讼里主张「训练服务也类似」——所以 41 要自己报，不能赌跨类保护 |

两对概念必须同时成立才依 2019 第 30 条驳回：**标志相同或近似** × **商品同一种或类似**。只选对群、名字撞车，照样驳；名字干净、群落错，注册了也护不住。

## 3. 选群方法（先映射生意，再对表）

国知局指引第五节的选类原则，收成四步：

```
1. 写下真实在卖、以及可书面说明的合理延伸
2. 到《区分表》/ 官方商品项目查询找标准名（不要自拟）
3. 看这些名称落在哪个类似群、哪一段、有没有「注」
4. 检索：整群 + 「注」里的交叉群 + 空群复核
   申报：只报真实或合理延伸的项目，不报群号，不占无关硬件
```

三条硬约束：

1. **检索范围 ≥ 申报范围。** 0901 里既有「可下载的手机应用软件」，也有计算机、鼠标。同群原则上类似，别人在「计算机」上的在先标，审查时可以挡你的 App。所以检索必须整群；申报却不应去勾鼠标、键盘——那是无使用意图（2019 第 4 条 / 2026 第 19 条）。
2. **专用权钉在项目上，不钉在群上。** 报了「可下载的手机应用软件」，对同群其他项目有类似商品层面的排斥力，但维权、撤三、使用证据都要对着**核定项目**。核心生意对应的标准名必须写上。
3. **官费含 10 项。** 核心群里用满 10 个贴生意的标准名是合理的；为了「占满群」去勾无关项，既费钱，也触囤积条款。

### 4.1 物理引擎改的是项目，不是类

**事实（产品）**：球迹端上跑自研事件驱动物理引擎（`QiuJi/Core/Physics/`，pooltool 移植），反解、走位、球形生成、示范出片都靠它。这是产品核心能力，不是装饰。

**事实（分类）**：引擎嵌在 App 里卖给用户，法律上仍是「可下载软件商品 + 用模拟手段做培训 + 在线软件服务」。**不因此多开一个大类，也不改第一批 9 / 41 / 42。**

它改变的是这三类里**哪几条标准名必须点上**：

| 层 | 因引擎应优先勾的标准名（待官方核名） | 群 |
|---|---|---|
| 培训怎么交付 | **通过模拟装置进行的培训服务**（WIPO 对应 training services provided via simulators） | 4101 |
| 软件商品 | 可下载的手机 / 计算机应用软件；若查询仍有，加 **用于虚拟环境的可下载应用软件** | 0901 |
| 软件服务 | SaaS / 提供在线不可下载的计算机软件；加 **计算机模拟模型的设计**（转载编号 420267） | 4220 |

**不要报成 0910。** 第 9 类标题里的「训练器械和模拟器」在区分表里落到 **0910**（急救人体模型、驾驶训练模拟器、航空器飞行模拟器、电子运动训练模拟器、模拟万用表等）。那是**器械 / 仪器**，不是手机里的物理库。球迹不卖台球模拟器硬件。勾 0910 = 项目名与真实商品不符，还把检索拖进科学仪器堆，增加第 4 / 19 条风险。

同样不要勾：数字模拟转换器、模拟万用表、教学用模型标本（16 类）、训练模拟器出租（4105 里若存在，按出租器械理解）。3D 台面不是 VR 的，也不要只因为有 SceneKit 就勾「虚拟现实软件」全套，除非官方查询里有更贴的「虚拟环境」软件项。

若将来把引擎拆成 **SDK / 授权给他人的仿真服务**，仍在 0901 + 4220 里加「计算机软件出租 / 设计」，不必新开 0910。

| 教学 | 总括 |

**4105 文娱、体育活动的服务 —— 只点第（三）部分**

- 4102：`安排和组织培训班`、`组织体育比赛`——有办营、办赛的书面计划再报。
- 4104 第（一）部分：`电子书籍和杂志的在线出版`、`提供在线电子出版物（非下载）`。转载表注：4104 **各部分之间不类似**。精讲若只在 App 内阅读，4101 已覆盖教学；4104 是「出版」口径的补强，不是第一批硬条件。

同一件 41 类申请里可以同时指定 4101 与 4105（三）的项目，官费仍按 1 类计（10 项内 270 元）。

### 5.3 第 42 类 · 4220（必报）

群的常见标题（转载）：计算机编程及相关服务。

**建议申报：**

| 候选标准名 | 为何贴球迹 |
|---|---|
| 软件即服务（SaaS） / 软件运营服务（SaaS） | 账号、在线能力（以官方查询显示的规范写法为准） |
| 平台即服务（PaaS） | 若提供平台层 |
| 提供在线不可下载的计算机软件 | OTA / 在线功能，与 9 类可下载对偶 |
| 计算机软件设计 | 开发服务 |
| 手机应用软件的设计和开发 | 移动端 |
| 计算机软件咨询 / 计算机技术咨询 | 技术咨询 |
| 云计算 | 云端 |
| 计算机软件维护 / 更新 | 持续运营 |
| **计算机模拟模型的设计** | **因物理引擎应点**（转载 420267）。指模拟模型的设计服务，不是 0910 硬件模拟器 |
| 电子数据存储 / 远程数据备份 | 用户数据（若确有）。10 项满了可让给上一条 |

**不要只因为 2026 新增就勾：** `人工智能即服务（AIaaS）420315`。官方修订 PDF 确认此项已进 4220；球迹目前没有对外提供 AIaaS，勾了会增加「超出经营需要」和撤三风险。

### 6.1 第 28 类 · 2804（台球器材）

**更正：不是 2806。** 2806 在转载表中是射箭（箭弓、靶、泥鸽）。

2804 常见标题：球类及器材。候选名（转载，待核）：

- 台球杆  
- 台球桌

- 台球球杆头 / 台球杆皮头  
- 台球记分器  
- 台球桌垫  

手套、护腕若做周边，转载表多在 **2809 运动防护器具**，与 2804 不同群。要卖再核，不要默认算进 2804。

第二批被占 → 记 M6 或该类高风险，**不单独触发换产品名**。

### 6.2 第 35 类 · 3501 / 3503（只在「为他人」时必要）

分类指引原文示例（事实）：

> 类似群「3503 为他人推销」指的是帮助**他人**提升其商品或服务在市场上的销量或需求。普通从事零售或以批发方式直接向消费者出售**自己的**商品或服务的经营主体，**不需要**在此类申请注册商标。

因此：

| 实际在做 | 要不要报 35 |
|---|---|
| 只在 App Store 卖自己的会员、自己的课 | **不必**为了「能卖自己的东西」去报 3503 |
| 接广告、给球房 / 器材商做推广 | 报 **3501**（如计算机网络上的在线广告、广告） |
| 做第三方器材商城、替别人卖货 | 报 **3503**（替他人推销；为商品和服务的买卖双方提供在线市场） |
| 纯防御、怕别人抢 35 类 | 可以报，但要能说明合理延伸；被占不换产品名 |

3509 是药品零售，与球迹无关。
