## `week/day` 剩余命中分类

对生产代码、测试、脚本、规格和两份研究表执行了定向 `rg`。剩余命中按以下边界保留或后续处理：

1. **批准的 bundle/OTA 兼容层**：`PlanContentService` 的 legacy decoding、`PlanWeek/PlanSession` 兼容视图，以及 I10/fixture 中的旧格式负例。它们只读旧数据，不允许新内容写旧结构。
2. **W4 必须消费的持久化迁移输入**：`UserActivePlan.currentWeek/currentDay/isCustom` 和 V3/V4 schema 历史类型。它们在下一 schema 映射成 `currentLessonId/status` 后仅保留在历史 schema。
3. **自然周统计与用户节奏目标**：`weeklyGoalDays`、自然周训练日统计、模版的 `sessionsPerWeek` 旧字段。这类“周”是统计/用户偏好，不是官方课程结构；W4/W5 会继续拆清命名与职责。
4. **历史生成器与研究证据**：`v31_*`、`v37_*` 脚本以及研究表中的 `Wn/Dn` 记录旧版生成过程，不再是生产写入路径。研究表已加 v54 语义覆盖，I13 §5 改读“最早阶段”。
5. **待 W5–W9 改造的现行业务/UI/测试**：`PlanProgressService`、`TrainingHomeViewModel`、`PlanDetailView` 及旧计划测试仍通过兼容视图使用 week/day；这些不是内容迁移遗漏，而是后续批次的明确改造面。
