# Drill 缩略图 / 详情首帧静帧契约

> 日期：2026-07-29 · 状态：已落地（v24 修订显示槽 + 列表球放大）  
> 代码真源：`QiuJi/Core/Scene/DrillStaticPreview.swift`

## 契约（5 条）

1. **选源**：代表性球形 = `A1` → 旧式无 token 单文件 → 最低编号 `A*` → 否则才 `manual*` / 其它。禁止在有 `A*`/legacy 时扫目录误选 Snipaste。
2. **静帧内容**：全桌真实球键 + 瞄准位球杆（`pullBack=0`，走 elevation/穿模守卫）+ 线语言 v2（`TrajectoryRenderer`）+ 假想球/接触点。母球姿态钉死 identity。
3. **详情首帧（live）**：`DrillSceneView` / `DrillSceneController` 与缩略图同走 `DrillStaticPreview` 选源与线语言；取景 ortho=0.77；**`ballScale=1.0` 真尺寸**。详情顶栏是 live 场景，**不**消费列表 PNG，也**不**另烘第二套详情 PNG。
4. **列表 PNG**：一 drill 一图（`Resources/DrillThumbnails/<id>.png`）；烘焙用 `Options.thumbnail`（**`ballScale=1.8`**，ortho=0.86）；多球形不拆多图。
5. **显示槽**：
   - 动作库网格卡 / 骨架封面 = **2:1**（与烘焙像素同比，`.fill` 不裁左右库边）。
   - 计划详情行缩略图已是 40×20（2:1）。
   - 方槽行卡（64²/56²/48²/40²）维持 `BTBakedDrillTable` 默认 **`.fill` 中心裁**（v24 D-v24-1=C；不假装完整桌）。可选 `contentMode: .fit` 供日后 letterbox。
   - **不改**练习首页 `AngleGridCard` 的 4:3（海报封面，非球桌缩略图）。

## 多序列语义

- **多球形**（A1…An）与 **多杆**（`shots[]` / sequence steps）正交。
- 缩略图 / 详情门面 = 代表性球形的**首杆预备态**。
- `initial-only` 序列：摆球取 board，击打意图回退 `shotIntent` / `animation`。
