## 〇、坐标契约回显（geometry-spatial-reasoning 强制）

## 一、公理层：进球线固定 ⇒ 假想球唯一

### 1.1 推导链（纯几何，无物理假设）

1. 目标球（OB）要进袋 ⇒ OB 被撞后的**离开方向**必须沿进球线 `d_pot = unit(aimPoint − OB)`。
2. 理想碰撞（无摩擦、等质量、弹性）中，静止 OB 的离开方向 = 碰撞瞬间**两球心连线**方向。
3. ⇒ 碰撞瞬间母球（CB）球心必须位于 `ghost = OB − 2R·d_pot`（沿进球线反向退两个球半径）。
4. ⇒ **假想球位置由进球线唯一确定**，与母球在哪、用什么杆法无关。

代码锚点：

```222:225:QiuJi/Core/Physics/ShotPredictor.swift
        let ghost = AngleSceneCalculator.ghostBallPosition(
            targetBall: input.targetBall, pocket: aimPoint, ballRadius: r
        )
        let aimDir = unitXZ(from: input.cueBall, to: ghost)
```

### 1.2 「进球线」本身的精化：管道法（pipe method）

「瞄袋心」是近似。真实进球线的终点 `aimPoint` 由 `AngleSceneCalculator.effectivePocketAimPoint` 按**纯几何管道法（far-jaw-only）**给出，三种情况：

- **空心穿喉**：OB 能不擦 jaw 直穿袋喉 ⇒ aimPoint = 袋心；
- **远端 jaw 反弹**：贴库/强切角不可空心进 ⇒ aimPoint 自动外移，避开近端 jaw、只允许擦远端 jaw；
- **不可行**：几何上无管道 ⇒ 无解。

关键性质：**aimPoint 与力度、加塞无关，纯由三球位几何决定**——这保证了「进球线固定」这个公理在贴库球上依然成立，只是进球线不再指向袋心。落袋判定始终以真实袋口捕获窗（球心入孔圈，ADR-P10-09）为准，管道只定瞄准几何。

### 1.3 可行性闸门

- 切角上限：`cutAngle ≥ AngleSceneCalculator.maxCutAngle` ⇒ 判不可进（`ShotPredictor.prepareAim`）；
- 母球占位：母球坐在进球线段上 ⇒ 判不可进（`isCueBallBlocking`）。

### 1.4 教学含义（L0/L1 层的全部内容）

- 一切瞄准法（假想球法、接触点法、管道法、平行线法、分数/厚薄法）都是**定位同一个 ghost 的不同测量仪器**，不是不同理论。厚薄档位几何真源：`AngleSceneCalculator.NamedBallThickness`（全球/3/4/半球/1/4/极薄）。
- 教学基准局面：`AimingMethodsGeometry.scene(cutAngleDeg:)`，θ≈30°（实测构造切角 29.54°）→ 右上角袋（pocketIndex=1）——Z1–Z3 全部实测数据基于此局面。

## 二、正演链：一杆球的物理效应管线

理想假设逐个破缺的顺序 = 效应发生的时间顺序 = 教学的认知阶梯顺序：

```
杆头撞击 → [squirt 即刻偏向] → 飞行(滑动段 swerve → 滚动) → 球-球碰撞[throw] → OB 离开 → (库边 Han2005) → 落袋
```

### 2.1 杆-球碰撞：打点如何变成初速与初旋

**代码真源**：`CueBallStrike.executeStrike` / `cueStrikePT`（忠实移植 pooltool `cue_strike`，Alciatore TP A-30/31 口径）。

**模型**：瞬时点接触刚体冲量。打点 (a, b) ∈ 单位圆（a 正 = 左塞，b 正 = 高杆），球杆仰角 θ。接触点 Q = R·[ball_a, ball_c, ball_b]（经杆系→球系变换）。母球获得速度：

\[ v = \frac{2 V_0}{1 + m/M + \frac{a_Q^2 + (b_Q\cosθ)^2 + (c_Q\sinθ)^2 - 2 b_Q c_Q \cosθ\sinθ}{I_m}} , \quad I_m = \tfrac{2}{5}R^2 \]

角速度 ω = (v/I_m)·vec(Q)。**教学要点**：打点越偏，同样杆速下母球线速度越小（能量进了旋转）——「加塞会吃力度」有闭式来源。

**常量**（`BTPhysicsConstants`）：球 m=0.170kg、杆 M=0.567kg、皮头有效质量 endMass=0.00567kg、皮头 φ11mm、曲率半径 10.5mm。

**打滑极限**：√(a²+b²) ≤ `CuePhysics.miscueLimitFraction` = 0.5（满塞 = 半个半径）。打点盘 UI 与引擎同源钳制（`AimingCorrectionMath.clampSpinX`）。

**皮头曲率换算**：用户摆的是皮头中心，真实接触点 = 中心偏移 × R/(R+ρ) ≈ 0.731（`tipContactPullFactor`）——教学可讲「你以为打了满塞，实际接触点更靠中心」。

### 2.2 Squirt（挤偏/让点）：母球不沿你出杆的方向走

**代码真源**：`CueBallStrike.squirtAngle(a:)`（pooltool `get_squirt_angle`，杆头有效质量模型）：

\[ α_{squirt} = -\arctan\frac{2.5\,a\sqrt{1-a^2}}{1 + m/m_{end} + 2.5(1-a^2)} \]

m/m_end = 0.170/0.00567 ≈ **30.0**（分母主导项 ⇒ squirt 角小而稳定）。

**实测量值**（Z1，教学局面）：

| spinX | squirt |
|---|---|
| +0.3（左塞） | **−1.2324°（向右）** |
| +0.35 | −1.4153° |
| −0.3（右塞） | +1.2324°（向左） |

**已核验性质**：
- 符号：**左塞 → 母球出发方向向右偏**（Z1 ALL_PASS）。实施在 `executeStrike` 内：实际方向 = aim.rotatedY(−squirt)。
- **与力度无关**：`squirtAngle` 签名无速度参数；v=0.8 与 v=4.0 实测同值（Z3）。教学红线：不得说「大力挤偏更多」。
- 与距离的关系：角度恒定 ⇒ **横向错位随球距线性放大**（1° ≈ 17.5mm/m）——这是「长台加塞难」的第一因子。

### 2.3 飞行段：三态运动与 swerve（弧线）

**代码真源**：`AnalyticalMotion`（滑动/滚动/自旋三态闭式演进）+ `EventDrivenEngine`（事件驱动调度）。

**运动状态机**：滑动（接触点相对速度非零，减速 μ_s·g=0.2g，方向沿接触点相对速度 û）→ 滚动（μ_r·g=0.01g）→ 自旋/静止。滑动→滚动时刻 t = 2|v_rel|/(7 μ_s g)。竖轴自旋独立衰减（u_sp = 0.444R）。

**swerve 的机理**：滑动段摩擦力方向由接触点相对速度决定；当自转轴倾斜（侧旋 + 高低杆合成）时摩擦横向分量使轨迹弯折。**滚动段不弯**——弧线只在滑动段累积。

**已核验性质（Z3，含一次首跑证伪）**：
- ⛔ **平杆纯侧旋（spinY=0）弧线 ≈ 0**（实测 <0.001mm）。物理归因：平杆纯侧旋 ⇒ 自转轴竖直 ⇒ ω×r 在接触点无水平分量 ⇒ 摩擦不弯折。**教学红线：不得写「加了左塞轨迹必弯」**。
- 侧旋 + 低杆组合（+0.3/−0.4, v=0.8）：横向漂移 +4.6mm（0.42m 行程），可教学量级；
- **越慢越弯**：同组合 v=0.8→4.6mm、v=2.0→0.54mm、v=4.0→0.11mm（快球滑动段占比小）；
- **仰角出杆放大弧线**：纯左塞 v=0.8，仰角 0°→0mm、5°→−8.9mm。教学口径：「弧线主要来自抬杆 + 塞，平杆几乎不弯」。

### 2.4 球-球碰撞：throw（投掷）

**代码真源**：`CollisionResolver.resolveBallBallPure`（pooltool `frictional_inelastic` 忠实移植）。

**模型**：法向用恢复系数 e=0.95 交换动量；切向按接触面相对速度分**滑移/无滑移**两分支：
- 滑移：Δv_t = −u_b·|Δv_n|·v̂₁₂c（摩擦冲量沿接触面相对速度反向）；
- 无滑移（咬合）：Δv_t = −(1/7)(v₁−v₂+(ω₁+ω₂)×n̂·R)（经典 1/7 律）。

摩擦系数为 **Alciatore 速度依赖拟合**：

\[ u_b = 0.009951 + 0.108\,e^{-1.088\,v_{rel,surf}} \]

**throw 不是独立 API，是这条摩擦碰撞的涌现结果**。接触面相对速度 v_rel 有两个来源，对应两类投掷：
- **CIT**（切角致投掷）：切角本身给出切向相对速度——不加塞也偏；
- **SIT**（旋转致投掷）：母球侧旋在接触点附加切向速度——可增可减可反转 CIT。

**已核验性质（Z1/Z2，含两次首跑证伪）**：
- **慢速投掷更大**：u_b 随 v_rel 指数衰减 ⇒ v=0.8 时 CIT 1.454°、v=4.0 时 0.793°（Z1）。「轻推最容易被投掷偷走进球」。
- ⛔ **CIT 非全程单调**：15°→30° 递增，**半球（30°）附近见顶**，45° 不再更高（Z2 证伪「切角越大投掷越大」）。教学口径：「小切角越薄越明显，半球附近最明显」。
- **左塞的 SIT 分量把 OB 向右带**（cut=0 + squirt 补偿隔离实测：+SIT ≈ 1°量级）。
- ⛔ **SIT 会被 squirt 淹没**：不补偿 squirt、几何瞄准照打左塞时，squirt 造成的偏心碰撞几何效应约 −9.6°，**方向与 SIT 相反且大一个量级**（Z2 证伪）。**教学红线：只可说「左塞的投掷分量向右」，绝不可说「加左塞球就往右跑」**——这是市面口诀最大的谬误点，也是本教学最强的差异化断言。
- **高低杆改变有效厚度**（Z1 厚薄偏向，符号经 ±1.5° 扰动标定「正=偏薄」）：同一几何瞄准下，高杆(+0.4) bias −0.73°、中杆 −1.55°、低杆(−0.4) −3.00° ⇒ **高杆相对偏薄、低杆相对偏厚**。教学口径：「低杆要瞄薄一点补回来」。

### 2.5 库边与袋口（教学延伸，非直击瞄准主链）

- 库边：`Han2005CushionModel`（闭式解），库鼻高于球心（h/R≈1.29，接触角≈17°）⇒ 部分法向冲量转为旋转；e_c=0.94 时**有效法向速度保留率仅 ~80%**——「吃库吃掉两成速度」有实测出处（`CushionDiagnosticsTests`）。加塞对反弹角的改变由同一模型涌现（`CushionEnglishAtlasView` 图谱已消费）。
- 袋口：落袋 = 球心水平投影入孔圈，无速度特判；jaw 圆弧恢复 0.70（实测标定：低中力沿库进、≥2.4 m/s 冲袋被鼻尖拒绝）——「大力怼袋会 rattle」有标定出处。

## 三、反解链：「进球线固定、瞄准点可变」的数学本体

### 3.1 问题定义

给定（母球位、目标球位、袋口、力度 v、打点 (a,b)），求瞄准方向，使 OB 碰后**实际**沿管道方向 `d_pipe` 离开。由于 squirt/swerve/throw 都是 (v, a, b) 的函数，解不再是几何 ghost 方向，而是：

\[ \text{aim} = \text{aimDir}_{geo}\ .rotatedY(Δ), \quad Δ = Δ(v, a, b, \text{三球几何}) \]

**Δ 就是「瞄准修正量」的全部**——squirt、swerve、CIT、SIT、偏心碰撞几何效应的总合成，一个数。

### 3.2 求解器结构（`ShotPredictor`）

1. **几何基线**：`prepareAim` → 管道 aimPoint → ghost → `aimDir_geo` + 可行性闸门（§1.3）。
2. **一维补偿搜索**：`positionAimOffset` / `solveAimOffset`——评分 = OB 碰后方向与 `d_pipe` 的夹角 + 1e-3·|Δ| 正则（同分取小偏移，解唯一稳定）。**没有进袋奖励、没有分支特判**：进不进是力度的下游结果；碰前吃库 = 无效候选（管道法是直击）；未碰到 OB 时用 cueGhostMinDist 作梯度拉回。搜索为三级网格（±12°/0.5° → ±0.6°/0.1° → ±0.12°/0.02°）或黄金分割（容差 0.05°）。
3. **解析加速层**：`AnalyticAim.outcome`（B2）——不进事件循环，直接串「executeStrike → 至多滑动+滚动两个常加速度段（引擎同款 CCD 求根）→ makeBallBallKiss → resolveBallBallPure」。**忠实性契约：全部复用引擎组件、零重写**，对拍测试（`AnalyticAimParityTests`）守护与整程模拟的一致性。`useAnalyticPositionAim = true` 为线上路径。
4. **全保真终验**：候选 Δ 用完整事件驱动模拟验证真实进袋（squirt/throw/传旋/衰减全由引擎裁决），「宁可少解，不出几何假解」。

### 3.3 Δ 的实测量级（Z1 扫描表，教学局面 cut≈29.5°）

来源：`build/z1-evidence/delta-scan-table.tsv`（36 行全量见原表）。代表行：

| v (m/s) | spinY | spinX | Δ | 解读 |
|---|---|---|---|---|
| 1.5 | 0 | 0 | **+0.18°** | 纯 CIT 补偿：小但非零——「几何瞄准永远差一点」 |
| 0.8 | 0 | 0 | +0.18° | 轻推 CIT 补偿同量级 |
| 1.5 | 0 | +0.3 | **−1.13°** | 左塞：补偿主要在抵消 squirt+偏心几何 |
| 1.5 | 0 | −0.3 | +1.08° | 右塞：镜像 |
| 0.8 | −0.4 | +0.3 | **−1.43°** | 低杆轻推+左塞：全效应叠加，修正最大档 |
| 5.0 | +0.4 | 0 | +0.03° | 大力高杆无塞：几乎不用修 |

**教学转译**：1° ≈ 17.5mm/m 球距。1 米球距上「低杆轻推加左塞」要比几何假想球多修 **约 25mm——接近一颗球半径**。这是「为什么口诀不够用、为什么职业选手每杆都在做修正」的定量证据。

### 3.4 反解范式的推广（同一思想的三个应用）

- 直击：Δ 补偿反解（本节）；
- 翻袋（`prepareBankAim`）：镜像展开给种子方向 → ghost → 同一 Δ 搜索 → 引擎实测终验（含贴库预反射门控）；
- 反射/kick（`prepareKickAim`）：母球侧镜像展开 → 真实滑动/滚动过渡下的吃库反解。

教学叙事价值：**「先几何近似、再物理精化、最后实测裁决」是通用解题范式**——这也正是人类瞄准学习的路径（先学假想球，再学修正，最后靠球感闭环）。

## 五、边界与假设声明（诚实交付：能讲什么、不能讲什么）

| 边界 | 含义 | 对教学的约束 |
|---|---|---|
| 2D 平面物理 | 无跳球、无扎杆腾空（docs/04 明示不做） | 不讲 jump/massé 实演；弧线只讲滑动段 swerve（小仰角近似） |
| 仰角的渲染-物理不自洽 | 大仰角渲染 ≠ 引擎平杆物理（DR-027 已知项） | 仰角相关断言限 ≤5° 对照组（A7），不做大仰角实演 |
| 球杆参数固定 | endMass 等为单一常量，无杆型矩阵 | 不能实测对比「低偏移杆 vs 普通杆」；只能讲 endMass 机理定性 |
| Alciatore u_b 为拟合式 | 台呢/球况差异未参数化 | 量值标注「本引擎标准台况」，教用户方向与相对大小，不背绝对度数 |
| 恢复系数为常数 | e=0.95（球-球）不随速度变 | 极端力度下的量值外推需谨慎 |
| Z1–Z3 实测基于单一教学局面 | cut≈29.5° 固定三球位 | 跨切角/跨距离断言需 §8 扫描矩阵补证后才可量化上屏（A9 已有 3 点切角扫描） |
| 教学层符号约定为标定产物 | 「正=偏薄」「正=右侧」经数值标定非先验 | 引用符号必须连同标定出处（`thicknessBiasDegrees` 注释 / Z2 手性锚定） |
