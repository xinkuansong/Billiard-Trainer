## 判断

- **不是已上架竞品。** 国内 C 端「严肃训练工具空白」的结论暂不改。
- 像抖音常见的创业故事号：履历 + 行数 + 全国首创 + 邀达人。8 粉邀 98 达人，叙事大于产品。
- 有信息量的只有一句：**「台球训练软件」已被别人当成短视频钩子。** 类别故事会被讲出来，不等于对方能做成可练的产品。
- 与球迹无品牌词冲突（截图范围内）。商标紧迫来自中国「申请在先」+ 已有多家「球迹」字号（见 `20260810` 方案 §5），**不是**因为这个号。

## 应对（有效直到升级）

1. 关注、不评论、不转发、不对线。
2. 每周看一次：有无上架、有无腰部以上达人带、有无使用「球迹」或抄画面。
3. 不因此改功能、定价、内容排期，也不跟「代码行数 / 全国首创」对外话术。

## 升级条件（满足任一条再单独立项）

- 上架了能用的 App / 小程序 / 安卓包  
- 腰部以上台球账号帮带  
- 使用「球迹」名称，或明显抄 UI / 球形 / 精讲 / 渲染画面  

到了再谈平台投诉或侵权；现在不到。
