商标起名规范（中英文）

配套：20260820-中国商标注册入行与风险判断.md
依据：2019年《商标法》第8–11、13、30、32条；2026年法（2027-01-01）第14–17、20–21、24条；《审查审理指南》近似规则。
简洁清单，不是法律意见。定名后必须官方检索。

原则：能区别来源，且不撞别人。中文、英文、拼音分开想、分开查、分开注。


1. 先选类型（显著性从高到低）

类型    中文                    English                         注册难度
臆造    无字典义的自造词        coined: Kodak式                 最低
任意    与商品无关的常用词      arbitrary: Apple之于手机        较低
暗示    不直接说功能            suggestive: 点到即止            中
描述    快、纯棉、智能、健身    Fast, Smart, Fitness, Pro       高，勿作主名
通用    台球、软件、App         Billiards, App, Software        不可作主名

主名用臆造或任意。描述词、行业词只能当副标，且注册后别人仍可正当使用（2019第59条 / 2026第73条）。


2. 绝对不能当主名

禁                  中文                                          English / 其他
国家/政党/官方      中国、国旗、中央机关、党旗党徽、重大理论或历史事件名    China, Chinese, official, national；外国国名国旗
地名                县级以上行政区、公众知晓外国地名              Beijing, Shanghai, Paris（无其他含义时）
欺骗                暗示功效、原料、产地不实                      organic / medical / 产地词，实际对不上
不良影响            低俗、歧视、蹭政治热点                        脏话、歧视性词
直接描述本商品      台球训练、智能软件                            Billiard Trainer, Smart App
傍名牌              完整包含或加缀                                名牌+Pro / Official / China；音译抄国际品牌

法条：2019第10–11、13条 / 2026第15–17、21条。


3. 中文规则

1）2–4字为宜；过长短语像口号，显著性弱。
2）读音、字形、含义三项都要和在先标拉开。只改一个形近字不够。
3）勿在他人商标前后加「中国 / 官方 / 科技 / 网络 / Pro」。指南：完整包含或摹仿知名标，可判近似。
4）谐音、繁简、拆字、同音字都算近似检索范围。
5）勿用他人字号、姓名、作品名、角色名。
6）公司能核名 ≠ 商标能过。两套系统。


4. 英文 / 拼音规则

1）外文申请须说明中文含义（实施条例第13条）。含义若直接描述商品，按描述性驳。
2）意译、音译、拼音，与对应中文可判近似。
   例：球迹 ↔ QiuJi / Qiu Ji / QIuji；Nike ↔ 耐克。
3）大小写、空格、连字符、字体通常视为相同或细微差别（指南：文字构成与顺序相同即可同标）。
4）避免行业词典词单独做主名：App, Play, Cue, Pool, Shot, Trainer, Lab, AI。
5）自造英文优先：非常见拼写、无行业直译。仍须查：该拼写、近似拼写、对应中文。
6）中文主品牌与英文主品牌不是自动保护关系。要用英文对外，须另注英文文字标。


5. 中英怎么配

做法                              结论
中文臆造 + 英文臆造，读音含义都无对应    最好；两件文字标分开申请
中文 + 其拼音 / 英文意译          检索时当作同一组；一件被占，另一件也危险
只注中文，App对外用英文           英文不受该中文注册保护
图文组合一件搞定                  弱。文字、图形、中文、英文应拆开

建议四件骨架（按类别计费）：中文文字、英文文字、图形、（可选）中英组合。黑白文字保护最宽。


6. 定名自检（全过再检索）

[ ] 主名不是通用名、不是直接描述功能 / 原料 / 质量
[ ] 不含国名、地名、官方、政党、欺骗性词
[ ] 中文：读音、字形、含义均不靠近竞品或知名标
[ ] 英文：不是行业词；不是他人中文的拼音 / 意译
[ ] 没有「名牌+Pro / 官方 / 中国」
[ ] 不是合作方、明星、知名作品名
[ ] 已准备中文、英文、拼音三套检索式

检索入口：https://toas.sbj.cnipa.gov.cn
