### 0.4 三条红线

1. **未完成官方检索，不得写「低风险」。** 结论栏写「未验证」。
2. **任一高风险项成立，禁止用「整体还行」平均掉。** 第 9 类干净、第 41 类被占，必须分开打档。
3. **不要把商标网账号密码发给任何人（含 AI）。** 政务站点有验证码与访问阻断；检索由你在本机完成，本文只规定查什么、怎么判。

## 2. 把名字拆成可检索要素

中文、拼音、英文**分开想、分开查、分开评**。意译、音译、拼音与对应中文，审查实践中可判近似（指南「形、音、义」；法释〔2020〕19 号第 9 条第 2 款）。

### 2.1 四个槽

| 槽 | 怎么取 | 例（现用名） |
|---|---|---|
| 中文主名 | 去掉「科技 / 网络 / 官方 / 中国 / Pro / App / 软件」等后缀，只留识别部分 | 球迹 |
| 拼音 | 全拼无空格、全拼有空格、首字母；大小写、连字符视为细微差别 | QIUJI、QIU JI、QJ |
| 英文 | **已有**才查。没有则写「未提供」，禁止为了凑检索发明一个当主品牌 | （现用名未锁定英文主品牌） |
| 变体 | 按附录 A 生成：同音、形近、换序、减字、加字、繁简 | 球记、球际、迹球 |

加缀名（「球迹 Pro」「球迹科技」）的**主检索要素仍是「球迹」**。加缀降不了「完整包含」风险（指南下编第五章；见 H5）。加缀本身再作为第二条检索要素跑「完全相同」。

### 2.2 提交检索前的自检（未过则先改名）

完整清单见起名规范。本作业最低限度：

- [ ] 主名不是「台球 / 中式八球 / 训练 / 走位 / 瞄准 / 软件 / App / 智能」单独成标
- [ ] 不含国名、县级以上地名、官方、政党、欺骗性词
- [ ] 不是「他人名牌 + Pro / 官方 / 中国」
- [ ] 已准备中文、拼音两套；有英文则三套

## 3. 第零关：标志本身能不能用

绝对理由由商标局依职权审查，**换类别救不了**。命中即高风险（H1 / H2），停止近似检索。

### 3.1 禁止使用（连未注册商标都不能用）

**现行法 第 10 条 / 2026 年法 第 15、16 条**，包括但不限于：

- 同国家名称、国旗、国徽、国歌及中央国家机关名称、标志性建筑物名称等相同或近似
- **2026 年法新增**：同中国共产党的名称、党旗、党徽、勋章或重要理论成就、历史事件相关标志性要素相同或近似
- 外国国名国旗、政府间国际组织徽记、官方标志、红十字 / 红新月
- 民族歧视、欺骗性（对质量、工艺、原料、产地误认）、不良影响（2026 年法表述为违背公序良俗或其他不良影响）
- 县级以上行政区划地名、公众知晓的外国地名（有其他含义或集体 / 证明商标组成部分的除外）

未注册而使用禁用标志，可被查处（2019 第 52 条 / 2026 第 62 条）。

### 3.2 可以当未注册商标用，但不能注册

**现行法 第 11 条 / 2026 年法 第 17 条**：

1. 仅有本商品的通用名称、图形、型号；
2. **仅直接表示**商品的质量、主要原料、功能、用途、重量、数量及其他特点；
3. 其他缺乏显著特征。

例外：经过使用取得显著特征（第 2 款）。举证极重，申请前不要赌这一条。

显著性光谱（便于初判，不是法条原文）：

| 类型 | 球迹场景的例子 | 注册难度 |
|---|---|---|
| 臆造 | 无字典义的自造词 | 最低（仍可能撞在先标） |
| 任意 | 与台球训练无关的常用词 | 较低 |
| 暗示 | 点到即止、不直接说「训练软件」 | 中 |
| 描述 | 台球训练、智能瞄准、走位软件 | 高，第 11 / 17 条 |
| 通用 | 台球、App、软件 | 极高，通常不可作主名 |

描述词即使侥幸注册，他人仍可正当使用该描述部分（2019 第 59 条 / 2026 第 73 条）。

### 3.3 「球迹」本身：交界地带（推测）

**事实**：「球迹」不是「台球」「软件」这种商品通用名称。

**推测**：产品签名元素就是球迹线，相关公众看到「球迹」+ 训练 App，可能把它理解成「球的轨迹」。审查员有空间主张第 11 条第 1 款第 2 项「仅直接表示功能、用途」。反方主张是两字组合的暗示标，并非「仅」直接表示。

**作业要求**：以「球迹」为候选时，第零关不得标「无绝对理由风险」。至少记 **M2（描述性成分）**，并在报告里单独写一句。是否升格为 H2，等代理结合审查实践表态，本文不替你拍板。

「台球训练」「Billiard Trainer」「智能走位」单独作主名 → 按 H2 淘汰。

## 4. 球迹必须覆盖的类别与类似群

法律依据：2019 第 22、23、56 条 / 2026 第 26、27、71 条——专用权**以核准标志和核定商品为限**；选错类等于注册了也保护不到真实生意。

类似关系：国知局《关于正确理解商标注册用商品和服务分类的指引》——同一类似群内多数构成类似，不同群原则上不构成类似。法释〔2020〕19 号第 12 条：区分表是**参考**；异议、无效、诉讼可以突破。

### 4.1 第一批（不过这三类，结论无效）

| 类 | 类似群 | 规范项目方向（填申请书时用区分表标准名） | 覆盖球迹的哪一块 |
|---|---|---|---|
| **9** | **0901** | 可下载的计算机软件；可下载的计算机应用软件；可下载的手机应用软件；已录制的计算机程序 | App 安装包，核心商品 |
| **41** | **4101** | 教育；培训；教学；体育教育；通过模拟装置进行的培训服务；提供教育信息 | 精讲、训练课、体育教育 |
| **41** | **4105** | 文娱、体育活动的服务（健身课程、体育训练服务等，以当期表为准） | 体育活动 / 训练服务交叉 |
| **42** | **4220** | 计算机软件设计；计算机软件开发；软件即服务（SaaS）；平台即服务（PaaS）；计算机技术咨询 | 账号、OTA、云端、SaaS |

说明：

- 第 9 类与第 42 类**互补不替代**。9 保护「可下载的软件商品」，42 保护「提供软件服务」。只注一类，另一类可被他人合法占用。
- 第 41 类 4101 与 4105 都要查。球迹同时像「体育教育 / 培训」和「体育活动服务」。
- 可选加查 **4102**（组织和安排教育、文化、娱乐等活动），若未来做线下课 / 赛事策划。
- 第 9 类若提供可下载教学视频，可按区分表核是否落入 **0908**；不作为第一批硬条件，但报告可备注。

每类检索时：**先填类似群跑一轮，再空着类似群在该类再跑一轮**（防漏交叉注释与归类争议项目）。

### 4.2 第二批（布局与防抢注）

| 类 | 方向 | 风险含义 |
|---|---|---|
| **28** | 体育活动器械、台球杆、台球桌等（群号以区分表检索「台球」所在群为准） | 实物周边；被占不自动挡 App 上架 |
| **35** | 广告、替他人推销、为零售目的在通讯媒体上展示商品 | 电商 / 招商高频抢注类 |

第二批被占 → 记 M6 或该类高风险，**不单独触发换产品名**。

### 4.3 默认不报（防囤积条款）

25（服装）、38（电信）、16（印刷品）等，除非能书面说明真实使用意图。

**现行法 第 4 条**：不以使用为目的的恶意申请应驳回。  
**2026 年法 第 19 条**：不以使用为目的，**且明显超出正常生产经营需要**的，不予注册。  
《规范商标申请注册行为若干规定》第 8 条：申请数量、类别跨度、经营状况等是判断因素。

第一批 9 + 41 + 42，外加紧密相关的 28 / 35，一般可解释为正常经营需要。无经营关联的十几个类，按 H8。

### 4.4 跨类突破（初判怎么写）

9 / 41 / 42 在区分表上通常不属同一类似群，实质审查常不跨类驳回。但法释第 11 条第 3 款承认「商品与服务类似」（功能、渠道、用户有特定联系）。初判：

- 三类**分开打档**；
- 一类有强引证、另两类干净 → 干净的两类不升格为高风险；
- 报告单列「跨类突破」为**中风险备注**，不把三类都写成低。

## 5. 中国商标网选择查询：必跑矩阵

### 5.1 入口与模式

- 中国商标网：<https://sbj.cnipa.gov.cn>
- 综合查询（新系统）：<https://toas.sbj.cnipa.gov.cn>
- 使用**选择查询**（按分类 + 查询方式 + 查询类型）。综合查询可作复核，不能替代本矩阵。

国际分类为必填。类似群能填则填 §4 核心群，再空群复核。

### 5.2 查询方式

| 方式 | 何时必跑 |
|---|---|
| **汉字** | 有中文主名时，每个第一批类别都跑 |
| **拼音** | 每个第一批类别都跑（全拼无空格为主；有空格、首字母各至少「完全相同」一次） |
| **英文** | 已锁定英文主品牌时，每个第一批类别都跑 |
| 数字 | 名称含数字时 |
| 字头 | 英文 / 拼音有 3 个以上字母时，作补充，不替代全拼 |
| 图形编码 | 有 Logo、准备单独报图形标时；纯文字作业可暂缓 |

字体、大小写、空格、横竖排、连字符，指南视为细微差别，**不能当成新商标**。

### 5.3 查询类型（汉字主名，每个第一批类别）

选择查询的类型与审查「形、音、义、排列」对齐。二字中文名按下表，缺一项则该类别的近似结论无效。

| 查询类型 | 二字中文 | 三字及以上 | 法律 / 审查对应 |
|---|---|---|---|
| **完全相同** | 必跑 | 必跑 | 法释第 9 条第 1 款：视觉上基本无差别。H3 |
| **读音相同** | 必跑 | 必跑 | 法释第 9 条第 2 款「读音」 |
| **部分相同** | 必跑 | 必跑 | 共享主要识别部分 |
| **包含在其它商标中** | **特别必跑** | 必跑 | 「球迹」被「球迹科技 / 球迹体育」完整包含 |
| **内含其它商标** | 必跑 | 必跑 | 你的名字是否吃进他人显著部分 |
| **加汉字** | 必跑 | 必跑 | 指南完整包含 / 加缀 |
| **任意位置加汉字** | 必跑 | 必跑 | 同上，位置不限 |
| **减汉字** | 建议跑 | 必跑 | 去掉「科技」后是否撞剩余部分 |
| **换序** | 必跑 | 必跑 | 排列顺序 |
| **逆序** | 必跑 | 必跑 | 迹球 vs 球迹 |

拼音 / 英文：至少跑 **完全相同、读音相同（或拼写极度接近的部分相同）、换序**。英文无「加汉字」，改为关注加减字母、连字符变体。

### 5.4 状态必须覆盖

对每一条命中记录，抄下并判断：

| 状态 | 是否构成在先障碍 |
|---|---|
| 已注册 | 是（2019 第 30 条 / 2026 第 20 条） |
| 初步审定 / 公告中 | 是 |
| 申请中（已受理未审定） | 是（2026 年法明文含「在先申请」） |
| 驳回复审中 / 异议中 | 是，视为未死；跟踪结果 |
| 无效宣告中 | 是，成功前路未清 |
| 已驳回确定、已无效确定、已撤销确定 | 一般不再挡；注意一年隔离 |
| 期满未续展、主动注销 | 2019 第 50 条：撤销 / 无效 / 不续展后 **一年内** 对相同近似申请不予核准。2026 第 49 条：一年隔离**主要适用于注册人主动注销**（2027-01-01 起） |

「没搜到」只说明当前库无命中，不说明没有未入库的新申请（公告滞后）。

### 5.5 一条命中要抄的字段

商标号、商标图样 / 文字、申请人、申请日 / 注册日、国际分类、类似群或核定商品、法律状态。缺商标号或核定商品的截图，不能用来打「低风险」。

### 5.6 作业量（第一批汉字 + 拼音）

以二字中文为例，粗算：

- 3 个国际分类 ×（填群 + 空群）× 汉字约 9 种查询类型  
- 3 个分类 × 拼音「完全相同 / 读音或拼写接近」  

先保证 **9 / 41 / 42 × 汉字：完全相同、读音相同、包含在其它商标中、内含其它商标、换序** 这五格跑完，再补其余类型。五格未完，禁止给该类下低风险。

## 6. 商标库以外必须查的

相对理由不会全部出现在商标库。只查库就写低风险，结论无效。

法律：2019 第 32 条 / 2026 第 24 条（在先合法权益、故意抢先注册他人已经使用并有一定影响的商标）；《反不正当竞争法》第 6 条（有一定影响的商品名称、企业字号、姓名等混淆）。

| 库 | 入口或方法 | 查什么 | 命中意味着什么 |
|---|---|---|---|
| 国家企业信用信息公示系统 | <https://www.gsxt.gov.cn> | 字号是否已被他人使用，优先看软件、体育、教育、文化 | 字号有一定影响时可阻注册或构成仿冒混淆。**不会出现在只查商标库的结果里** |
| App Store / 国内安卓商店 | 商店搜索中文名、拼音、英文 | 同名或近名的台球 / 体育训练 App | 在先使用 + 一定影响；上架名称冲突 |
| 域名 | 注册商查询 `.cn` / `.com` | 主品牌能否与对外名称一致 | 不是驳回依据，是使用与仿冒风险 |
| 微信公众号 / 小程序 | 微信搜索 | 同名账号 | 同上 |
| 著作权 / 公开发表 | 公开网页、著作登记（如有） | Logo、插画、角色是否像他人作品 | 第 32 / 24 条 + 著作权法 |
| 行业知名品牌 | 台球器材、赛事、海外训练 App | 是否被完整包含或摹仿 | 指南完整包含；驰名可跨类（第 13 / 21 条） |

方案文档已记录：宁波、上海、长沙等地存在「球迹」字号。**任何仍以「球迹」为候选的报告，必须单列字号检索**，并写清检索日与命中主体所属行业。未做字号检索 = 第 32 / 24 条未验证。

## 7. 怎么读结果：相同 / 近似 × 同一种 / 类似

两对概念**同时**满足，才依 2019 第 30 条 / 2026 第 20 条驳回。

```
                商标相同              商标近似
商品同一种      直接驳回                驳回（混淆）
商品类似        驳回（混淆）            驳回（混淆）
商品既不同也不类似  通常不驳            （驰名可跨类，H9）
```

### 7.1 商标相同

法释〔2020〕19 号第 9 条第 1 款：二者在**视觉上基本无差别**。

指南口径：语种相同，文字构成、排列顺序完全相同；仅字体、大小写、横竖排、间距、颜色细微差别，仍可认定为相同。混淆是相同的**结果**，不是认定相同的前提。

### 7.2 商标近似

法释第 9 条第 2 款：字形、读音、含义，或图形构图颜色，或整体结构相似，**易使相关公众对来源产生误认，或认为有特定联系**。

法释第 10 条三原则：

1. 以**相关公众的一般注意力**为标准；
2. **整体比对 + 主要部分比对**，且在**隔离观察**下分别进行（不要并排「找不同」）；
3. 考虑在先商标的**显著性和知名度**。

指南：实质审查主要看标志本身；异议 / 无效还综合知名度、注意程度、主观意图。文字商标**完整包含或摹仿**他人在先具有较高知名度或较强显著性的文字，易被认为系列商标的，判定近似。

初判检查项：

| 检查 | 高风险方向（示意，不是个案结论） |
|---|---|
| 读音相同或极度接近 | 球迹 / 球记 / 球际；QiuJi / 球迹 |
| 字形接近 | 多一笔少一笔、形近字 |
| 含义相同 | 同义中英文、意译（球迹 ↔ Ball Trace，若审查认为对应） |
| 完整包含 | 在先标前后加「中国 / 官方 / Pro / 科技」 |
| 换序 / 逆序 | 迹球 |
| 系列化摹仿 | 改一个字仍像同一家族 |

### 7.3 同一种 / 类似商品或服务

法释第 11 条：

- **类似商品**：功能、用途、生产部门、销售渠道、消费对象相同，或相关公众认为有特定联系、容易混淆；
- **类似服务**：目的、内容、方式、对象相同或有特定联系；
- **商品与服务类似**：二者存在特定联系，容易混淆。

初判顺序：

1. 核定项目是否在同一类似群（区分表）；
2. 功能、渠道、用户是否实际上接近（即使不同群）；
3. 在先标若已在台球培训或体育软件上使用，类似范围会被拉宽。

### 7.4 混淆可能性

法释〔2017〕2 号第 12、13 条的结构：

```
混淆可能性 ≈ f(标志近似, 商品类似, 在先显著性, 在先知名度, 相关公众注意程度, 主观意图)
```

落到球迹：相关公众是业余台球爱好者，在应用商店里扫一眼做选择，**注意力偏低**，近似门槛偏严。这不是新法条，是第 10 条「一般注意力」在本产品上的适用。

### 7.5 读一条引证的操作顺序

1. 记下商标号、状态、申请日（是否在先）。
2. 核定商品落在哪个类似群，是否与 §4 核心群重合。
3. 隔离观察：音、形、义是否高度接近或完整包含。
4. 申请人是谁：是否行业内、是否可能构成字号冲突或业务关系人（H6 / H7）。
5. 套入 §8 的 H / M，**一类一档**。

## 8. 风险档位

与 20260820 手册 §7 **同一套编号**。不要另发明分数。

### 8.1 高风险（换标或先清障碍；不交代理费去赌核准）

满足**任一项**即高：

| # | 情形 | 法律依据 |
|---|---|---|
| H1 | 命中禁用条款 | 2019 第 10 条 / 2026 第 15、16 条 |
| H2 | 仅通用名称，或仅直接表示质量 / 原料 / 功能 / 用途 | 2019 第 11 条 / 2026 第 17 条 |
| H3 | 拟指定**同一类似群**上已有他人注册、初审或在先申请的**相同**商标 | 2019 第 30、31 条 / 2026 第 20、35 条 |
| H4 | 同一或类似商品上读音 / 字形 / 含义高度接近，尤其在先标显著或已使用 | 2019 第 30 条；指南；法释第 9–10 条 |
| H5 | 完整包含或明显摹仿他人较高知名度 / 较强显著性的文字或图形 | 指南下编第五章；2019 第 13 条 / 2026 第 21 条 |
| H6 | 他人著作权 Logo / 角色、有知名度的字号或姓名 | 2019 第 32 条 / 2026 第 24 条；法释〔2017〕2 号第 18–22 条 |
| H7 | 与对方有代理、经销、合作、劳动关系，对方先用该标 | 2019 第 15 条 / 2026 第 22 条 |
| H8 | 申请量、类别明显超出经营需要，或以转让为主要目的 | 2019 第 4 条 / 2026 第 19 条；若干规定第 8 条 |
| H9 | 复制、摹仿、翻译驰名商标（即使跨类） | 2019 第 13 条 / 2026 第 21 条 |

对球迹的常用误判：

- 「改成球迹 Pro / QiuJi Official」——通常仍是 H5，不是降风险。
- 「中文被占，改用拼音对外」——拼音与中文可判近似，通常仍是 H4。
- 「公司已经核名了」——与商标无关（M5）。

### 8.2 中风险（可谈改要素 / 缩群 / 预案，不能当绿灯）

| # | 情形 | 处理方向 |
|---|---|---|
| M1 | 同一类别、**不同类似群**上有相同或近似在先标 | 审查常不驳；异议 / 诉讼可能突破区分表 |
| M2 | 有描述性成分，但整体另有显著部分 | 可能放弃专用权；「球迹」默认至少记本档 |
| M3 | 谐音、简繁、加缀变体，在先标知名度一般 | 审查不稳定；拉开音形义再报 |
| M4 | 在先标满三年无使用，考虑撤三 | 成功前路未清；2019 年法撤三后还有一年隔离 |
| M5 | 公司名称能核下，商标检索有冲突 | 两套系统 |
| M6 | 只报文核心类，35 / 28 等空白 | 他人可在空白类注册 |
| M7 | 只报图文组合、商品项目过窄或非规范名称 | 保护范围有洞 |

### 8.3 低风险（五条同时满足，且检索做完）

1. 不触 H1 / H2；
2. 拟指定类似群内，官方库无相同商标，无读音字形含义接近的在先商标（含申请中、初审中）；
3. 未完整包含他人知名品牌，未使用他人作品 / 姓名 / 字号；
4. 申请类别与真实经营或可说明的合理延伸对应（第 4 / 19 条）；
5. 创作与使用历史干净（不是从合作方拿来的）。

低风险 **不等于** 一定核准：检索日到申请日之间可能出现新的在先申请；公告期仍可能被异议。

### 8.4 决策树

```
标志本身能否用？ ──否──► H1/H2，换主名
        │是
        ▼
第 9 或 41 类核心类似群有无相同 / 高度近似在先标？
        │有──► H3/H4，停，定产品名
        │无
        ▼
是否傍名牌 / 他人作品字号姓名 / 业务关系人的牌子？
        │是──► H5–H9
        │否
        ▼
是否仅不同群近似、描述性、或类别过宽过窄？
        │是──► 中风险，改完或带预案再报
        │否
        ▼
官方库 + 字号 + 商店复检完毕 ──► 该类别低风险
```

## 9. 对球迹产品的决策含义

| 档位落点 | 产品动作 | 法律动作 |
|---|---|---|
| 9 与 41 均为低，42 低或中 | 锁定该名：App 名、备案名、商店名、公司字号尽量一致 | 公司名义报文字标 9/41/42；图形标分开 |
| 9 或 41 为中（M1–M3） | 不要对外锁死品牌；可同步准备 1–2 个备选名 | 代理出引证分析；评估缩项、分割、是否仍报 |
| 9 或 41 为高（H3–H5） | **停用该名做主品牌的计划** | 换名，或撤三 / 无效 / 受让（成功前不当作已清） |
| 仅 28 / 35 高 | 主品牌可保留；周边与电商另议 | 核心类照报；次要类放弃或换副品牌 |
| 「球迹」字号多、商标库尚可 | 主品牌法律风险与商号混淆风险分开写 | 第 32 / 24 条 + 反法第 6 条单独评估，不与第 30 条混成一句「能过」 |

文字标与图形标**分开申请**。只报组合标，他人单独使用文字时维权更难（2019 第 56 条 / 2026 第 71 条：保护以核准标志为限）。

申请人用**公司**，与营业执照一致（实施条例第 14 条）。执照已拿，不要再以个人名义报。

## 11. 检索局限（写进任何「低风险」结论）

1. **公告滞后**：刚提交的申请可能尚未入库。
2. **图形召回不全**：图形近似靠人眼和维也纳编码，系统会漏。
3. **未注册使用不入库**：已使用并有一定影响的未注册商标、未登记的著作权，库里没有。
4. **驰名跨类**：不会体现在「本类无近似」的查询结果里。
5. **区分表会被突破**：不同类似群在诉讼中仍可能被认定为类似。
6. **自动化检索不可用**：中国商标网存在访问阻断与验证码；AI 不能代查。结论以你本机官方页为准。

## 附录 A. 变体生成规则

对中文主名生成下列变体，纳入「读音相同 / 部分相同 / 换序」的人工对照（不必每种都在系统里单独建一次查询，但读结果时要能对上）：

| 规则 | 做法 | 例 |
|---|---|---|
| 同音 | 声调不同或声母韵母相近的常用替换 | 球迹 → 球记、球际、球计 |
| 形近 | 常见形近字 | 视具体用字 |
| 换序 / 逆序 | 二字对调 | 迹球 |
| 加缀 | 科技、网络、体育、台球、官方、Pro | 球迹科技（用「包含在其它商标中」覆盖） |
| 减字 | 三字以上去掉行业词 | 球迹训练 → 球迹 |
| 拼音 | 全拼、分写、首字母 | QIUJI、QIU JI、QJ |
| 英文 | 仅当已有英文；查其本身及与中文的音译 / 意译关系 | 未锁定则跳过 |

生成变体是为了**读结果时不漏**，不是鼓励用变体去「绕开」在先标。变体与在先标仍像同一家族的，按指南可驳。
