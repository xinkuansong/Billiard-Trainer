## 2. 法务 / 主体类（按依赖顺序）

### 2.1 商标官方检索（TOAS）— 第一闸 ⏳🧑

- **状态**：未做。候选名「球同学 / 球小练」；「球迹」若仍可能当产品名需同一套再查一遍。
- **为什么排第一**：产品名 / 公司字号 / 备案名 / 商标名是**同一个名字的四份登记**，办下来再改等于四条流程重走。市面已有多家名为「球迹」的公司（宁波、上海、长沙），9 / 41 类被占概率不低。
- **查什么**：每个候选名在 **9（软件）、41（教育 / 体育培训）、42（软件开发 / SaaS）** 必查，**28（台球器材）、35（广告 / 在线推销）** 次要。近似写法一起查（球记 / 球际 / 球迹科技 / QIUJI 等）。
- **在哪里**：TOAS <https://toas.sbj.cnipa.gov.cn>；耗时半小时，免费。
- **决策规则**：
  | 检索结果 | 动作 |
  |---|---|
  | 9 与 41 都干净 | 正常推进 |
  | 只有 28 / 35 被占 | 正常推进，次要类别届时评估副品牌 |
  | **9 或 41 被占** | **暂停，先决策产品名**（换名 / 加后缀 / 异议 / 撤三 / 洽购） |
- **硬约束（你自己定的）**：检索没做完，**不缴官费、不改 App 对外名**。
- **真源**：`docs/research/20260826-商标申请逐步操作手册.md` §1–§4、§8；`20260826-球迹候选名检索与风险判断.md`；`20260826-球迹商标类似群选择.md`。

### 2.2 商标提交 ⏳🧑

- **申请人**：公司（不用个人；个人日后转公司 450 元 / 件 + 2–4 个月）。
- **形态**：黑白**文字标**先报；Logo 图形标、英文标另件、放第二批。不要只报组合标。
- **第一批类别**：9 / 41 / 42；官费 270 元 / 类 / 件 → 810 元。第二批 28 / 35。
- **路径**：公司自行网上申请（新系统，需先注册统一身份认证）或委托代理（代理费 500–1500 元 / 件 / 类，可谈打包价；让代理先做专业近似检索并出具商品项目清单给你过目）。
- **时间线**：形式审查数周 → 实质审查法定 ≤9 个月（实务 4–7 个月）→ 初审公告 3 个月（2027 年起 2 个月）→ 发证。合计约 **9–12 个月**。提交当天起可用 ™，**核准后**才能用 ®；受理通知 ≠ 专用权。
- **真源**：`20260826-商标申请逐步操作手册.md` §2–§7、§9；`20260810-公司注册执行分工清单.md` §2.4。

### 2.3 对公账户面签 ⏳🧑

- 法定代表人**本人到场**，无法代办。
- 是后续「域名 / 云实名切公司 → 备案」「Apple 对公收款」「实缴 10 万注册资本（备注"投资款"，留回单）」的前置。
- 纪律：**对公与个人账户绝不混用**；服务器、AI 工具、Apple 年费一律走公司账户或报销。从公司拿钱只有工资 / 报销 / 分红三种姿势。
- **真源**：`20260810-公司注册执行分工清单.md` §3.1、§8。

### 2.4 域名 + 云资源实名切到公司 ⏳🧑

- `qiuji.app` 当前实名主体需你确认（推测：在个人名下，我未查到记录）。
- **真源**：`20260810` §3.2 C1 / C2。

### 2.5 App 备案（ICP）+ 网站备案 — 最长关键路径 🔄🧑

- **状态**：H-19 原文按「个人开发者主体」写，已过时；须按**企业主体**重核。若此前已按个人提交过，问接入商是撤回重报还是变更主体（变更通常等于重走）。
- **法规背景**：2023 年 8 月起，大陆 App Store 上架强制填 App 备案号；自建后端域名同样需网站备案。带订阅的经营性 App，实操上管局 / 接入商要求企业主体。
- **在哪里**：腾讯云控制台 → ICP 备案（App 备案与网站备案可合并提交）。
- **材料**：营业执照、法人身份证、域名证书、App 中文全称（**必须与 App Store 上架名一字不差**）、Bundle ID、公钥 / 签名 MD5、图标、截图。主体信息可由姐姐代填，技术字段只有你有。
- **时长**：操作约 1 小时 + 管局审核 1–4 周（清单里另一处写 5–20 个工作日）。
- **完成标志**：拿到备案号 → 填入 H-19 → 填入 App Store Connect → 在 App 内公示（见 §3.3）。
- **另需姐姐问清**：本省通信管理局对「订阅收费 App 是否需要 ICP 经营许可证」的实际执行尺度（法条字面有要求，实操大量订阅 App 只做备案）。
- **真源**：H-19；`20260703-发布前系统优化方案.md` §6.1 R3；`20260810` §2.5 第 3 问。

### 3.2 隐私政策 / 用户协议 URL 上线（H-09）⏳🤖+🧑

- **完成证据**：两个最终 HTTPS URL，无登录窗口 2xx，浏览器无证书警告，App 三处打开同一组 URL 并截图。
