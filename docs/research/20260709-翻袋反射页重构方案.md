## 1. 目标形态

### 1.1 页面状态机（两页同构）

```
求解模式 ──点「击打」──→ 回放中 ──结束自动复位──→ 求解模式（可重复击打 / 下一解）
   │
   └─切「自由」─→ 自由模式（手动瞄准/打点/力度，球真实滚动停住）
                    │
                    └─「恢复球形」→ 最近求解快照（翻袋含袋口）→ 切回求解命中缓存
```

- 求解模式击打是**演示**：击打前快照全部球位，回放结束自动复原。回放 = `TrajectoryPlayback` 播该解的 `ShotPrediction`（含母球碰后去向、障碍球被扰动等全部真实物理），配 `runCueStroke` 出杆与音效。**画面=物理=回放，单一口径**。
- 自由模式击打是**试手**：`simulateFree` 如实模拟，球停在哪是哪；「恢复球形」显式动作。
- 两模式共享场景实例与力度值；求解模式选中解在自由模式退成暗虚线参考（hint token），供用户照着练——由于解与试打同引擎口径，按解的瞄准打即真进（执行误差除外），不再有 v1 的「演示必进 / 实打未必」张力。

## 2. 真实物理反解管线（v2 核心）

### 2.1 求解语义

**翻袋（WP-B 4-a）**：反解「母球直击目标球，目标球经指定库序真实翻库进选定袋」。

- `ShotInput` 增 `bankRails: [Rail]?`（nil = 直击，与现行为完全兼容）。
- `prepareAim`（`ShotPredictor.swift` L169）bank 分支：镜像展开（现 `BankShotCalculator.solveSequence`，降级为种子生成器）出库序与初始方向 → 反推幽灵球方向种子。
- `solveAimOffset`（L663）bank 分支：放开「先吃库拒绝」（L691–693、L893 两处 guard），改为「**母球段吃库 == 0**（母球仍直击目标球）」；评分判据 = 目标球真实进袋（squirt / 两球碰撞 throw / 传旋 / 速度衰减全由引擎裁决）。
- `buildPrediction` 不变 → 产出同构 `ShotPrediction` ⇒ 回放（`TrajectoryPlayback`，`Core/Physics/TrajectoryPlayback.swift` L22）/ 出杆 / 音效 / 出片自动可用。

**反射（WP-B 4-b 语义）**：反解「母球以真实击杆状态（滑动→自然滚动过渡，非现追迹假设的出发即自然滚动）经库序碰到目标球」。射击法搜瞄准角，正向评估含目标球与障碍球真实碰撞体（「碰到」= 真实碰撞事件）。

**多解枚举**：对袋口（翻袋）/ 目标球（反射）枚举库序候选（沿用现两 Calculator 的库序枚举 + 首库角度 / 相邻库合法性预过滤），每条库序独立反解，成解后按 §3 排序取前 N（翻袋 12 / 反射 16，沿用现上限）。

### 2.2 四层性能管线（复用 B1–B3 组件，目标亚秒级）

```
第 0 层  镜像展开枚举库序种子（现有 Calculator 几何层，微秒级）
第 1 层  解析射击法：AnalyticAim（B2，母球段闭式：击杆→弹道→两球碰撞→目标球碰后
         方向/速度）+ AnalyticShotRollout（B3，目标球段单球多库闭式 rollout，库边
         解算与引擎共用 EngineNumerics.resolveCushionImpact）组成全解析目标函数，
         secant 求瞄准偏移根 —— 单次评估 µs 级，迭代成本趋近于零
第 2 层  歧义回退：解析层 needsFullSim（kiss / 级联 / 擦 jaw / 截断）的候选，
         就地换引擎 scoring-only + 兴趣球早停评估（B1 组件）
第 3 层  代表解全保真终验物化：最终上屏的每条解用同参数全引擎重建 ShotPrediction，
         不符自动试备选（B1 finalize 模式）——「画面=物理」红线由此保证
```

- 成本重估：解析层免费；引擎只花在第 2 层歧义候选 + 第 3 层终验（每解 1 次，scoring-only 早停 ~10–30ms）。**目标：翻袋典型盘面单袋 ≤500ms、最坏 ≤1s；反射 ≤300ms**——以 benchmark 实测为准，不预支承诺。
- 保真依据：B3 对拍 0–1 库停点 P95 <0.5mm（翻袋 1–3 库落在可用区间，混沌放大是 ≥4 库现象）；B2 求解层 Δoffset 对拍全量 0°。终验层兜住解析残差。
- 诚实注脚：`AnalyticShotRollout.evaluate`（L262）/`evaluateFreeShot`（L343）现服务走位反解，「按指定库序翻库并判进袋」是新消费方式，接线暴露未覆盖分支（如袋口判定口径）时如实回退引擎评估，宁慢勿假。

### 2.3 jaw 截断口径（钉死）

贴袋口路线引擎追迹失败（`railFor` purity 不足截断）时，**该候选直接淘汰，不回退几何解**——严格教学口径下不出任何未经引擎背书的解；翻袋袋口相应标不可行。宁可少解。

## 3. 好打优先排序（借鉴 E1/E2/E4/E5，代码分立）

排序 = 难度评分 + 扰动容错合成，全部落在「挑选/呈现」层（E 系列红线同款：不碰扫描与终验流水线语义）。

| 借鉴项 | E 系列原型 | 本方案落法 |
|---|---|---|
| 难度字段模式 | E2：`PositionPlaySolution.difficultyScore` L118 / `difficultyTier` L120 | 两页解模型（新，基于 `ShotPrediction` 装配）同名字段 + 档位枚举（易/中/难）；pill 文案样式与 E2 标签对齐（用户看到同一套「难度」语义） |
| 进球难度输入 | E4：切角（60° 起算 / 75° 薄球）+ 球距（1m 起算） | 翻袋直接适用——切角取**引擎碰撞口径**（非几何近似）；反射无切角，用首库入射角余量替代 |
| 扰动容错 | E5：`measureRobustness`（`PositionPlaySolver.swift` L171–190，瞄准 ±0.5° / 力度 ±8%，解析 rollout 为主、覆盖不了回退引擎，产出 `robustness` L125） | 同款方法作用于翻袋/反射解（无塞搜索故不扰打点，仅瞄准+力度 ~4 次扰动）；翻袋是出名的「悬崖解」重灾区，容错是好打优先的**主要区分量**；解析扰动近乎免费，**默认开** |
| 常量集中 | E1：`DifficultyModel`（`Core/PositionPlay/DifficultyModel.swift` L48）单一真源 | 新建 `BankKickDifficulty`（建议 `Features/AngleTraining/`）：切角/库数/路径长/首库角权重 + 容错合成比 + 档位阈值集中可调；**不与 `DifficultyModel` 共用代码**（那套是 spin/力度难度语义，两页反解不搜塞） |

不适用项（如实记录）：E1 加权 spin 范数与 0 库桶特判（本反解不搜塞）、E3 塞幅预算（同理；库数预算本页已有用户显式选择）。

排序键：`好打分 =  w1·难度评分 − w2·robustness`（升序），同分 tie-break 库数少 → 路径短。解切换的 `prevCushions` 保持逻辑（`BankShotViewModel.applySolutions` L193–195）兼容新排序。

## 4. 其余关键决策

### 4.1 解缓存（引擎化后从优化变为刚需）

- 缓存 `solve` 完整解列表（库数过滤是展示层后处理，不进 key）。
- key = `(全部球位量化到毫米, 袋口 index〔仅翻袋〕, power 量化到滑块步进)`。
- VM 内小 LRU（8 条），页面退出释放，不落盘。
- 「最近求解快照」：每次求解成功存球位+袋口，供自由模式「恢复球形」；恢复后切回求解必然命中缓存直显。
- 一致性红线：任何 key 成分变化必重算，绝不出现球形变了还展示旧解。

### 4.2 去理想模式

- `CushionReflectionSettings.realMode`（`ReflectionSolverCore.swift` L253）退役；`power`（L261）保留（力度条持久化仍两页共享）。
- `ReflectionModeControl` 组件删除（已核实仅两页引用）。
- `Solution.idealObjectPath` 对照与理想虚线绘制（`BankShotViewModel.drawSolution` L255–264）随旧管线一并退役。
- `EngineCushionTracer` 保留：种子精修（第 0/1 层之间可选加速）+ E5 式扰动的单球段复用；不再直接产出上屏解。

### 4.3 球库

- 交互复用编排台摆球（`PositionPlayComposerView` L8–9 / L48：固定序球库、拖入落位、拖回移除、在桌变暗）。
- 障碍球是反解模拟中的真实碰撞体（第 1 层解析 rollout 含障碍球检测，`evaluateFreeShot` 已有先例；歧义回退引擎）；自由模式 `simulateFree`（`ShotPredictor.swift` L314）天然多球。
- 缓存 key 含全部球位。

## 5. 红线约束

1. **上屏解必经引擎全保真复核物化**（第 3 层），画面=物理不变量沿 B1 语义。
