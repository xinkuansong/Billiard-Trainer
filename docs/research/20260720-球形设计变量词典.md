## 〇、坐标契约回显（引用真源，未重算）

以下为词典中一切几何约束依赖的坐标系与常量，逐条注明来源节，本批**不新增计算**。

- **坐标系** `[事实]`：本项目 Canvas 归一化 2D 系（真源 `.kiro/steering/table-geometry.md` + `.cursor/skills/content-engineering/SKILL.md` § 坐标系协议，两处已在 B1/B2 交叉核对一致）——原点 = 台面左上角（顶视图），X∈[0,1] 左→右，Y∈[0,0.5] 上→下，单位 = 台面内沿**长度** 2.540 m 的百分比，2:1 台面。
- **diamond 网格** `[事实·B1 §〇]`：长向 8 等分、短向 4 等分，归一化间距 `dx = dy = 0.125`（2:1 台面下等距方格）。**1 diamond = 0.125（归一化）= 0.3175 m**。
- **关键常量** `[事实·B2 §〇]`：球半径 `r = 0.028575/2.540 = 0.01125`；下中袋中心 `(0.5, 0.5268)`；「一球间隙」球心距 `= 4r = 0.045`；有效击球区 X∈[0.0197, 0.9803]、Y∈[0.0099, 0.4901]；坐标自检严区 X∈[0.05, 0.95]、Y∈[0.05, 0.45]，两球球心距 > 0.05。
- **切角双口径** `[事实·B2 §〇/§2.3]`：切角 = 击球线与进球线（目标球心→袋口中心）的夹角。
  - **行进线切角 θ（设计值，本词典 `cutAngle` 的规范口径）**：白球→ghost ball 行进方向与进球线的夹角；
  - **表观切角（字面口径）**：白球心→目标球心连线与进球线的夹角，比 θ 略小（差 1.2°–3.8°，随白球距离增大收敛）。
  - 落地 drill 时 `cutAngle` 取**行进线切角 θ**；表观切角仅作解释性派生度量，不另立字段。
- **ghost ball** `[事实·B2 §〇]`：`G = T − 2r·normalize(P − T)`（目标球心沿进球线**反向**退 2r；接触点才用 r）。
- **入袋角定义** `[事实·B2 §2.1 + `scripts/b5_audit_drills.py` 袋口轴向]`：入袋角 = 进球线（目标球心→袋口中心）与**袋口轴线（袋口法向）**的夹角；0° = 沿袋口正对方向入袋。袋口轴向真源为 `scripts/b5_audit_drills.py` 头部袋口表。
- **可行域范例** `[事实·B2 §2.2]`：中袋垂直入袋（进球线沿 Y 正向）时 `dtp + d·cosθ ≤ 0.4543`——即「小切角 + 远目标球 + 长白球距离」三者不可兼得。此不等式是**中袋主题的实例**，非全库通用；其它袋口/入袋角下的可行域须按同法（B4 脚本）逐 drill 验算，不套用本数字。

## 一、全局变量词典

> 每条给出**六项**：英文名 / 单位 / 语义 / 常用档位 / 训练意义 / 几何约束。英文名为 drill JSON / profile 的字段标识符（camelCase）。带「**种子**」标记者为 c053 profile 既有字段，逐字沿用。
> **档位口径统一**：所有归一化距离档位以「占台面内沿长度的百分比」表示，并给出 diamond 换算（1 diamond = 0.125）。角度单位统一 `deg`。

### A. 布局与瞄准几何（Aim & Layout）

#### `pocket` — 目标袋口　**（种子）**
- **单位**：枚举（无量纲）。
- **语义**：本球形目标球要进的袋口。
- **常用档位**：`topLeft` / `topCenter` / `topRight` / `bottomLeft` / `bottomCenter` / `bottomRight`（4 角袋 + 2 中袋；`top` 对应上长库 Y≈0 侧，`bottom` 对应下长库 Y≈0.5 侧）。c053 全序列钉死 `bottomCenter`。
- **训练意义**：袋口决定进球线方向与袋口容错宽度——中袋接受角窄、对入袋角敏感；角袋接受角宽、更宽容。选袋是 drill 主题的第一层钉死项。
- **几何约束** `[事实·B2 §〇]`：袋口中心坐标为固定常量（如下中袋 `(0.5, 0.5268)`），袋口轴向见 `scripts/b5_audit_drills.py`；中式紧袋容错显著小于美式，达标线不可照搬美式基准（B1 § 0.1 台种差异）。

#### `cutAngle` — 切角　**（种子）**
- **单位**：`deg`。
- **语义**：击球线与进球线的夹角，取**行进线切角 θ**口径（见 § 〇）。
- **常用档位**：`15` / `30` / `45` / `60`（厚薄教学锚点：15°≈3/4 球厚、30°=1/2 球厚、45°≈1/3 球厚、60°=极薄球，球厚≈13%）；0° = 直球；`>60°` 归 `specialShots` 薄球，不进常规角度档。
- **训练意义**：核心厚薄训练轴。薄球有效可命中窗口随 θ 增大按 `cosθ` 量级收缩，是准度类 drill 的主难度维度 `[事实·几何，Dr. Dave 90° 系列同口径]`。
- **几何约束** `[事实·B2 §2.3]`：白球被约束在过 ghost、与进球线成 θ 角的射线上（`side` 定左右分支）；行进线切角为构造设计值，表观切角为派生度量，二者差 1.2°–3.8°。

#### `side` — 切球侧别　**（种子）**
- **单位**：枚举（无量纲）。
- **语义**：白球相对进球线所在的一侧。
- **常用档位**：`L`（左切，白球 X < 进球线 X）/ `R`（右切，白球 X > 进球线 X）。
- **训练意义**：左右切的视线与送杆不对称，是两个独立训练点（不可用镜像互相替代）；BU 官方允许左右镜像摆放，PAT-S#3「可选左右侧」（B1 § 4.1）。
- **几何约束** `[事实·B2 §2.3]`：`side` 决定切角射线在进球线哪一侧；同一 `cutAngle` 的 L/R 视为同级难度（对称）。

#### `entryAngle` — 入袋角　**（种子）**
- **单位**：`deg`。
- **语义**：进球线与袋口轴线（袋口法向）的夹角；0° = 目标球沿袋口正对方向垂直入袋。
- **常用档位**：`0`（控制变量，垂直入袋）/ `10` / `20` / `30`；自检上限 30°（B2 脚本 `入袋角≤30°` 断言）。c053 钉死 `0°`。
- **训练意义**：入袋角越大，袋口有效开口越窄、越考验瞄准；中袋对入袋角远比角袋敏感。样板中固定 0° 是为把切角难度与入袋角难度**隔离**（避免归因混淆）；可作「斜线入袋」变体的目标变量。
- **几何约束** `[事实·B2 §2.1]`：与 `cutAngle` 是**两个不同物理量**——切角量的是击球线 vs 进球线，入袋角量的是进球线 vs 袋口轴线；袋口轴向真源 `scripts/b5_audit_drills.py`。

#### `dtp` — 目标球→袋口距离　**（种子）**
- **单位**：归一化（占台面内沿长度百分比）；`dtp = distance target-to-pocket`。
- **语义**：目标球心到目标袋口中心的距离。
- **常用档位**：`0.12` / `0.15` / `0.20` / `0.25`（≈0.30 / 0.38 / 0.51 / 0.64 m；≈0.96 / 1.2 / 1.6 / 2.0 diamond）；下限 0.12 保证离袋有教学意义，上限受可行域约束（中袋垂直例 0.25）。
- **训练意义**：目标球离袋越远，进球线越长、瞄准误差在袋口处放大越明显。常作**条件变量**散布。
- **几何约束** `[事实·B2 §2.2]`：与 `d`、`cutAngle` 联动受可行域约束（中袋垂直例 `dtp + d·cosθ ≤ 0.4543`）；其它袋口须按 B4 脚本重算，勿套此数。

#### `d` — 白球→ghost ball 距离　**（种子）**
- **单位**：归一化；`d = 白球心到 ghost ball 心的距离`。
- **语义**：白球到 ghost ball（接触前虚拟球位）的距离，即**击球行进距离**的设计口径。
- **常用档位**：`0.18` / `0.22` / `0.25` / `0.28` / `0.35` / `0.38`（≈1.4 / 1.8 / 2.0 / 2.2 / 2.8 / 3.0 diamond）；短/中/长全段覆盖。
- **训练意义**：同样的出杆角误差，在目标处的横向偏差随击球距离线性放大；长距离配大切角拉开难度上限。常作**条件变量**。
- **几何约束** `[事实·B2 §2.2/§2.3]`：`C = G − d·t̂`（沿切角射线反向定白球）；受可行域联动约束。**注**：白球心→目标球心距（B2 记为 `|CT|`）是派生度量，与 `d` 相差 ghost 的 2r 偏置，不另立字段（见 § 五）。

### B. 杆法与力度（Cue Action & Force）

#### `spinV` — 纵向杆法（跟/定/缩）
- **单位**：归一化撞击点纵向偏移（相对球半径，范围约 −1..+1；也可用「高杆/中杆/低杆」定性档）。
- **语义**：杆头相对母球球心的**纵向**撞击点偏移，决定母球撞击后纵向旋转——正=跟杆（follow/高杆）、0=定杆/斯登（stop/stun）、负=缩杆（draw/低杆）。
- **常用档位**：`follow`（跟，+）/ `stun`（定/斯登，0）/ `draw`（缩，−）；需分档幅度时用 `+0.5` / `0` / `−0.5` 等撞击点偏移。
- **训练意义**：杆法类 drill 的核心轴；决定母球撞击后偏离切线（90° rule）的方向与幅度——斯登沿切线走，跟/缩使离球线偏离切线（B1 § 5.4）。
- **几何约束**：本身为动力学量，无静态坐标约束；在**分离角**训练中与 `cutAngle` 共同决定母球分离方向（分离角为二者派生的输出量，见 § 五）。撞击点偏移的物理上限受球面与皮头曲率限制 `[推测]`。

#### `spinH` — 横向塞（左塞/右塞）
- **单位**：归一化撞击点横向偏移（相对球半径，范围约 −1..+1）。
- **语义**：杆头相对母球球心的**横向**撞击点偏移，产生侧旋（english）——正=右塞、0=无塞、负=左塞。与 `spinV` 正交，共同构成 2D 撞击点。
- **常用档位**：`none`（0）/ `right`（+）/ `left`（−）；需分档时用撞击点横向偏移值。
- **训练意义**：侧塞改变母球分离后走位曲线与库边反弹角（走位/解球进阶）；对准度类为干扰项，通常固定 `none` 以隔离。
- **几何约束**：动力学量；侧塞引入的「投掷效应/瞄准偏移」在几何瞄准上表现为进球线的等效偏移，本词典不量化（属引擎/物理，非静态几何）`[假设]`。

#### `speed` — 击球力度（速度）
- **单位**：**台程**（Speed 1 = 母球行进一个台长 = 内沿长 2.540 m = 归一化 X 跨度 1.0），采用 PAT-S#1 口径。
- **语义**：出杆力度，以母球（无阻挡自由行进）的行进距离度量。
- **常用档位**：`0.5` / `1` / `1.5` / `2` 台程（PAT-S#1 力度四档，B1 § 4.1）；走位类可细分。
- **训练意义**：控力/走位类 drill 的核心轴；决定母球走位落点与库数。
- **几何约束**：动力学量，无静态坐标约束；与 `positionTarget`、`cushionsCue` 强耦合（力度决定能否走到目标区/够到几库）。达标以落点区（`positionTarget`）判定。

### C. 难度因子（Difficulty Factors）

#### `nearRail` — 白球近库　**（种子）**
- **单位**：布尔（无量纲）。
- **语义**：白球是否近库（距最近库边 < 0.06 归一化，约 0.48 diamond）为附加难度因子。
- **常用档位**：`true` / `false`；不强制全覆盖，自然散布（c053 中 A4/A6 近上库，其余开阔位）。
- **训练意义**：近库限制架杆与出杆姿势，是独立难度修正项，用于难度排序的再次序。
- **几何约束** `[事实·c053 profile / B2 §2.1]`：阈值 < 0.06；**真贴库**（距库 < 2r = 0.0225，球心距库边线 < r）超出坐标自检严区，归 `frozenRail` 专项处理。

#### `frozenRail` — 目标球贴库
- **单位**：布尔（无量纲）。
- **语义**：目标球是否**贴库**（球心距最近库边 ≈ r = 0.01125，球面紧贴库边线）。与 `nearRail`（白球、近但不贴，阈值 0.06）是**不同球 + 不同阈值**的两个量。
- **常用档位**：`true`（贴库切球主题）/ `false`。
- **训练意义**：贴库球只能薄切、无法打厚，走位窗口极窄，是 `specialShots` 的贴库切球专项核心（对标 BU S2、PAT1#7、新锐 5.4/6.4）。
- **几何约束** `[事实·B1 §二 S2]`：贴库球球心 Y（或 X）落在库边线上、距库 r；超出坐标自检严区 [0.05,0.45] 属预期（专项 drill 放宽自检）。

#### `obstacle` — 障碍球
- **单位**：枚举 + 位置结构（无量纲）。
- **语义**：击球线或走位线上是否存在阻挡球，及其阻挡类型。
- **常用档位**：`none` / `onAimLine`（挡瞄准线，需 kick 解球 / jump 跳球 / massé 弧线）/ `onPositionLine`（挡走位线，需绕行走位）。
- **训练意义**：`specialShots` 的解球/跳球/弧线专项核心（对标 BU S5/S6/S8/S9、新锐 5.2）；`combined` 残局中的走位路线选择（BU S3/S4）。
- **几何约束** `[推测]`：障碍球球心到相关线（击球线/走位线）的垂距 < 2r（0.0225）视为有效阻挡；具体阻挡判定由 B4 脚本按实际坐标核算，本词典不预设坐标。

### D. 走位、序列与多球（Position / Sequence / Multi-ball）

#### `positionTarget` — 走位落点区
- **单位**：区域（中心坐标 + 容差半径/矩形，归一化或 diamond）。
- **语义**：本杆完成后母球须停到的目标区域（下一杆的走位要求）。
- **常用档位**：按容差档分——`tight`（≈ 一球范围，如 BU F3 纸靶 8.5″×11″）/ `medium`（A4 纸区，新锐口径）/ `loose`（2×1 diamond 矩形，如 BU F4 缩回区）；或按落点位置枚举多区（BU F8 五靶 / 新锐 7 区）。
- **训练意义**：走位类与控力类 drill 的判定量；`endless`（连续走位）范式下每杆的落点区即下一杆的起手位。
- **几何约束** `[事实·B1 §一 F3/F4/F8]`：落点区中心 + 容差；容差半径决定难度（越小越难）。区域坐标由用户设计时按台面摆放，本词典只定义档位语义。

#### `cushionsCue` — 母球吃库数（走位/解球）
- **单位**：库数（整数）。
- **语义**：母球从击打到停止（或碰到目标）沿途碰库的次数。
- **常用档位**：`0` / `1` / `2` / `2+`。
- **训练意义**：走位（`positioning`）与一库解球（`specialShots` kick，BU S6）、大走位区（PAT-S#7a/b）的路线维度；库数越多，角度累积误差越大。
- **几何约束**：走位线的库线反弹计算（入射角=反射角，理想库；实际受库特性修正）；本词典不算具体路线，路线可达性由 B4 脚本/引擎验证。

#### `cushionsObject` — 目标球入袋前吃库数（翻袋）
- **单位**：库数（整数）。
- **语义**：目标球在入袋前碰库的次数——0 = 直接入袋，≥1 = 翻袋（bank）。与 `cushionsCue`（母球吃库）是**不同球**的量。
- **常用档位**：`0`（直接球）/ `1`（一库翻袋，如翻中袋 cross-side、翻底袋）；`2+` 为高阶。
- **训练意义**：翻袋专项核心（对标 BU S7 翻上中袋、新锐 4.2 一库翻中袋、五级翻袋）；翻袋入射角微变构成难度分档。
- **几何约束** `[事实·B1 §二 S7]`：翻袋点由入射角=反射角（镜像法）定；具体翻袋线由用户设计、B4 脚本核算，本词典不预设坐标。

#### `ballCount` — 涉及球数
- **单位**：个（整数）。
- **语义**：本球形序列涉及的目标球/障碍球总数（1 = 单球训练，≥2 = 组合/残局）。
- **常用档位**：`1`（单球，多数准度/杆法/控力 drill）/ `3–5`（残局，如 BU S3/S4 五球残局）/ `7+`（一线球 S1、贴库球组 S2）。
- **训练意义**：多球触发顺序规划与串联走位（`combined`、`positioning` 的多杆范式）；球数越多，走位约束链越长。
- **几何约束**：多球互不重叠（球心距 > 2r）、可行摆放于有效区；具体布局由用户设计，本词典不预设。

#### `shotOrder` — 击球顺序约束
- **单位**：枚举（无量纲）。
- **语义**：多球序列的击打顺序规则。
- **常用档位**：`free`（任意顺序，如 BU S2）/ `numbered`（按号序，如 S1 一线球、9 球轮转）/ `snake`（蛇彩连打，新锐 4.3/5.3/6.1）。
- **训练意义**：顺序约束越强，走位规划自由度越小、串联难度越高（`combined` 核心维度）。
- **几何约束**：无直接几何约束；与 `positionTarget`、`ballCount` 共同定义多杆走位规划空间。

## 二、8 分类变量菜单

> 每分类给出：**本分类常用变量组合**（从 § 一取值域挑选）／**典型档位**／**对标基准项**（引 B1 基准库 § 八映射表与 B2 图集 `docs/research/20260720-权威球形基准图集.md`）。菜单是「常用套路」，非强制——用户设计时按 drill 主题在词典取值域内自行取舍。分类口径见 `docs/research/20260323-训练内容体系-动作库分类.md`。

### 1. `fundamentals` 基础功
- **常用变量组合**：`speed`（力度直线性）+ `positionTarget`（停球目标区）+ `d`（击球距离）；瞄准直线性以窄容差 `positionTarget` 表达（「球门」门宽 = 4r）。
- **典型档位**：`speed` = 0.5/1/1.5/2 台程；`positionTarget` = tight（门宽 2 球径 = 0.045）/ medium；`d` 短—中段。
- **对标基准项**：PAT-S#1（力度四档）、PAT-S#2（出杆直线性「球门」）、PAT1#1/#2；新锐 1.1/2.1；CBSA 9 级推球/直球（B1 § 八）。

### 2. `accuracy` 准度
- **常用变量组合**：`cutAngle` × `side`（目标变量，矩阵全覆盖）+ `dtp` + `d`（条件变量散布）+ `pocket` / `entryAngle`（固定）。
- **典型档位**：`cutAngle` = 15/30/45/60，`side` = L/R；`dtp` = 0.12–0.25，`d` = 0.18–0.38；`entryAngle` = 0（控制）。**这正是 c053 中袋角度球样板的变量档案**。
- **对标基准项**：BU F1（递进切角）、F6（十线组合）；PAT-S#3（角度球）；新锐 1.2/2.2/3.1/4.1/5.1；Jewett 递进瞄准（B1 § 八）；B2 图集 accuracy 页渲染图。

### 3. `cueAction` 杆法
- **常用变量组合**：`spinV`（目标变量：follow/stun/draw）+ `d`（击球距离档）+ `positionTarget`（跟进/缩回距离档，即「效果幅度」）；`spinH` 通常固定 none。
- **典型档位**：矩阵范式——`d` = {1,2,3,4} diamond × `positionTarget` 跟/缩距离 = {1,2,3,4} diamond（BU Exam VII/VIII 的 4×4 / 5×5 结构）。
- **对标基准项**：BU F2/F3/F4（递进定/跟/缩）、Exam VII（4×4 缩杆矩阵）、Exam VIII（5×5 跟杆矩阵）；PAT-S#4/#5、PAT1#3/#4；新锐 2.3/2.4（高杆/低杆，白目约 15°）（B1 § 八）。

### 4. `separation` 分离角
- **常用变量组合**：`cutAngle` + `spinV`（二者共同决定母球分离方向）+ `positionTarget`（指定要碰到的 K 球/靶方向，全扇面覆盖）。**分离角本身是 `cutAngle`+`spinV` 的派生输出量，不作独立输入字段**（见 § 五）。
- **典型档位**：`positionTarget` = 半台扇面 10 个方向档（Wagon Wheel 11 靶）；`spinV` = follow/stun/draw 切换以偏移切线；`cutAngle` 随靶方向连续变化。
- **对标基准项**：BU F5（斯登递进）、F7 Wagon Wheel；VEPP Wagon Wheel（11 靶）；新锐 3.2（K 球序列）（B1 § 八、§ 五.1/5.4）。

### 5. `positioning` 走位
- **常用变量组合**：`positionTarget`（落点区档，核心）+ `cushionsCue`（走位库数）+ `speed` + `ballCount` / `shotOrder`（串联规划）。
- **典型档位**：`positionTarget` = 落点区 5–7 档（BU F8 五靶 / 新锐 7 区）或 tight/medium/loose 容差；`cushionsCue` = 0/1/2；`shotOrder` = numbered/snake；含 `endless` 连续范式（PAT-S#6b/#7b）。
- **对标基准项**：BU F8（网格靶）、S1（一线球）、S3/S4（残局）；PAT-S#6a/b、#7a/b（小/大走位区 + endless）、PAT1#5/#6/#8；新锐 3.3/3.4/蛇彩系列（B1 § 八）。

### 6. `forceControl` 控力
- **常用变量组合**：`speed`（目标变量，核心）+ `positionTarget`（停球目标区判定）+ `cushionsCue`（弹库程数）。
- **典型档位**：`speed` = 0.5/1/1.5/2 台程（1 台程 = Speed 1）；`positionTarget` = 2-diamond 宽容差带（PAT-S#1 口径）；`cushionsCue` = 0（直接）/1（弹对面库回）。
- **对标基准项**：PAT-S#1（Speed ½/1/1½/2 四档）；BU F5（靶随档位远移）、F8；新锐二级起力度分档（B1 § 八）。**注**：`forceControl` 与 `fundamentals` 基准多为复用项，设计时按变量拆分（B1 § 八结论①）。

### 7. `specialShots` 特殊球路
- **常用变量组合**：按子主题选——贴库切球用 `frozenRail`+`cutAngle`（极薄）；解球/跳/弧线用 `obstacle`+`cushionsCue`；翻袋用 `cushionsObject`+`entryAngle`；抬杆用 `obstacle`(onAimLine)+`nearRail`。
- **典型档位**：`frozenRail` = true；`cutAngle` 偏薄（≥45°或 >60°）；`obstacle` = onAimLine；`cushionsObject` = 1（一库翻袋）；`cushionsCue` = 1（一库解球，3 角度档）；`entryAngle` 翻袋入射角微变分档。
- **对标基准项**：BU S2（贴库切球）、S5（防守）、S6（一库解球）、S7（翻袋）、S8（抬杆）、S9（跳/弧线）、S10（冲球）、Exam VI（20 防守局）；PAT1#7（贴库）；新锐 4.2（翻袋）/5.2（解球）/6.4（贴库）（B1 § 八）。

### 8. `combined` 综合
- **常用变量组合**：`ballCount`（≥3 残局）+ `shotOrder`（numbered/snake）+ `positionTarget`（多杆串联走位）+ `obstacle`（障碍路线）+ `pocket`（多袋切换）。
- **典型档位**：`ballCount` = 5–6（残局）/ 开球清台全帧；`shotOrder` = numbered（9 球轮转）/ snake（蛇彩）；`positionTarget` 逐杆链；限袋/不碰球等高约束（新锐 6.x）。
- **对标基准项**：BU S3/S4（残局×3）、Exam IV RDS（16 级清台）、Exam V PPC（18 布局连打）；PAT-S#9/#10、PAT1#9/#10；新锐各级综合/6.5 真实开球（B1 § 八）。

## 三、与 B2 六要素模板的映射说明

B2 方法论（`20260716-drill变量覆盖设计方法论.md` § 一）的「变量档案」六要素是**设计流程**；本词典是六要素的**取值域供给**。对应关系：

| B2 六要素 | 本词典如何供给 |
|---|---|
| **要素 1 固定变量** | 从 § 一挑取「本 drill 主题钉死」的变量，取其**单一档位**。示例：c053 取 `pocket=bottomCenter`、`entryAngle=0`。 |
| **要素 2 目标变量及档位** | 挑取要系统全覆盖的 1–2 个变量，用词典给出的**常用档位**作为覆盖档（如 `cutAngle`∈{15,30,45,60} × `side`∈{L,R}）；档位划分依据已写在词典「常用档位」项。 |
| **要素 3 条件变量及采样** | 挑取影响难度但非主题的变量（如 `dtp`、`d`、`nearRail`），按词典档位做**散布采样**（每档 ≥1 次），不进乘法。 |
| **要素 4 变量约束结构** | 词典「几何约束」项给出各变量的耦合关系与可行域来源（如 `dtp + d·cosθ ≤ 0.4543`），即约束链的输入。 |
| **要素 5 最小覆盖推导** | 由目标变量档位全组合定 N_min（词典档位数相乘）；条件变量按要素 3 摊入，不进乘法。 |
| **要素 6 难度递进排序** | 词典「训练意义」项给出各变量的难度方向（如切角↑难度↑、距离↑误差放大），供排序主序/次序/再次序取用。 |
| **附加栏 达标线** | 词典不定达标线（属数据回归，方案既定本轮不做）；仅在「训练意义」提示难度倾向。 |

**一句话**：模板问「这个 drill 用哪些变量、各扮什么角色、怎么覆盖」；词典答「每个变量合法取哪些值、几何上受什么约束、为什么这样分档」。任一变量可在不同 drill 里扮演固定/目标/条件不同角色，其**档位与几何约束不变**（词典是稳定真源），只有**扮演的角色**随 drill 主题变化。

## 四、命名与 c053 profile 的零冲突核对

c053 profile（`content/drill_profiles/drill_c053.profile.json`）既有字段与本词典逐字对照：

| c053 字段 | 出现位置 | 本词典 | 语义一致？ |
|---|---|---|---|
| `pocket` | fixedVariables | § 一 A `pocket` | ✅ 一致（目标袋口） |
| `entryAngle` | fixedVariables | § 一 A `entryAngle` | ✅ 一致（进球线 vs 袋口轴线夹角） |
| `cutAngle` | targetVariables | § 一 A `cutAngle` | ✅ 一致（行进线切角口径） |
| `side` | targetVariables | § 一 A `side` | ✅ 一致（L/R 侧别） |
| `dtp` | conditionVariables | § 一 B `dtp` | ✅ 一致（目标球→袋口距离） |
| `d` | conditionVariables | § 一 B `d` | ✅ 一致（白球→ghost 距离） |
| `nearRail` | conditionVariables | § 一 C `nearRail` | ✅ 一致（白球近库，阈值 0.06） |

**结论**：7 个种子字段全部逐字沿用、语义一致，**零冲突**。增补字段（`spinV`/`spinH`/`speed`/`frozenRail`/`obstacle`/`positionTarget`/`cushionsCue`/`cushionsObject`/`ballCount`/`shotOrder`）均为 c053 未涉及的新维度，与既有字段无重名。

## 五、自查：同一物理量不出现两个名字

> 逐一核对易混淆的物理量，确认「一量一名」。留档副本见 `build/b3-logs/naming-audit.md`。

| 物理量 | 规范字段名 | 易混淆/派生量 | 处理 |
|---|---|---|---|
| 击球线 vs 进球线夹角 | `cutAngle`（行进线切角 θ 口径） | 表观切角（白球心→目标球心 vs 进球线） | 表观切角仅为**派生解释量**，不立字段；`cutAngle` 唯一 |
| 进球线 vs 袋口轴线夹角 | `entryAngle` | —（与 `cutAngle` 是不同物理量，勿混） | 两者语义已在词典明确区分 |
| 目标球→袋口距离 | `dtp` | — | 唯一 |
| 白球→ghost 距离 | `d` | 白球心→目标球心距 `|CT|`（B2 派生量，差 2r 偏置） | `|CT|` 为派生度量不立字段；击球距离唯一用 `d` |
| 白球所在侧 | `side` | — | 唯一 |
| 母球纵向旋转/杆法 | `spinV` | 「跟/定/缩」「高/中/低杆」为其**档位别名**，非独立变量 | 一量一名，档位用 follow/stun/draw |
| 母球横向旋转/塞 | `spinH` | 「左塞/右塞/english」为其档位别名 | 一量一名 |
| 出杆力度/速度 | `speed` | 中文「力度」= `speed` 的语义标签，非独立字段 | 一量一名（单位台程），不另设 force |
| 白球近库（近但不贴，阈值 0.06） | `nearRail` | 与 `frozenRail` 区分：不同球 + 不同阈值 | 两者语义正交，均保留 |
| 目标球贴库（距库 = r） | `frozenRail` | 同上 | 保留 |
| 母球吃库数 | `cushionsCue` | 与 `cushionsObject` 区分：不同球 | 一量一名（母球） |
| 目标球入袋前吃库数（翻袋） | `cushionsObject` | 同上 | 一量一名（目标球） |
| 母球走位落点区 | `positionTarget` | 分离角训练里的「K 球方向」也用 `positionTarget`（母球要到达的位/方向） | 复用同一量（母球目标位），不新增 `separationTarget` |
| 分离角（母球分离方向） | —（无独立字段） | = `cutAngle` + `spinV` 的**派生输出** | 不立输入字段；训练目标用 `positionTarget` 表达 |

**核对结论**：所有「同一物理量」均只有一个规范字段名；表观切角、`|CT|`、分离角为派生量不立字段；`nearRail`/`frozenRail` 与 `cushionsCue`/`cushionsObject` 虽名近但物理量不同（球不同/阈值不同），保留合理；跟缩定、高低杆、左右塞、「力度」均为档位/语义别名而非重复变量。**无同一物理量两名的情况。**
