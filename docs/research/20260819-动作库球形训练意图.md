## 怎么填（v41 简报规格，2026-08-24）

「训练意图」是**上游简报**：喂给 drill JSON 三字段（`description` / `coachingPoints` / `tutorial`）的语义真源，用法见 `问题集合_v41.md` §四。写法按技能 `formation-training-intent` v2.2：

- **五槽**：自变量（什么固定/什么变，不写数字）、目标（袋口族：中袋 / 底袋=角袋）、主练（1–2 个，能证伪，不复述课名）、本形差（多形课必填，邻形对读分得开）、可选 `展开：<机理名>`（只点名不推导）。
- **句式分型**：阶梯课两句成段；无球形课主语「这一课」；走位/综合课第二句只留能力。不要电报体，不要开场套话，机理讲义压成展开指针。
- **两列**：训练意图 = 用户原文（⛔ 禁止改写）；完善 = AI 五槽收口。空行完善列写「跳过（待素材）」；档数/度数/杆速归序列 / 开局 / 达标，不进 `description`（D-v41-7）。
- 多形课：每形各写各的，禁止两形并成一句；单形课写这一课即可；无球形课按整课填。
