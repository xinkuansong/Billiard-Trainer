# 产品重构：从物理引擎出发的第一性原理推导

**日期**：2026-06-18
**触发**：用户指出「物理引擎是真资产，其余功能（编排台/反解器/翻袋器/拍照建球形…）只是拍脑袋想出来的」，要求**不被现有功能框住**，从第一性原理重新设计「能成爆款」的功能点/产品特性。
**方法**：按思维协议——先拆本质（引擎是什么 / 玩家要什么 / 爆款是什么），再做诚实诊断，再长出新产品。标注〔事实〕〔推测〕〔假设〕。
**关系**：本文是**产品层**重构，`docs/01` 定位与 `20260618-增长方案` 是其下游；若采纳，二者需回改。

---

## 0. TL;DR

1. **引擎的本质**：一台**「台球真相神谕机」**——能对任意球形，正向算出未来、反向解出打法、批量造局、从照片感知、渲染成画面。
2. **玩家的本质需求**：不是「训练工具」，是**变强**；而变强的唯一结构性空缺 = **即时、个性化、客观的反馈**（「我这杆到底该怎么打」「我为什么没打好——是决策错还是动作错」）。教练贵且稀缺、短视频不个性化，**这个反馈空缺只有引擎能填**。
3. **诚实诊断**：现有产品 = 一堆**给专家的计算器** ⇒ 低频 / 低传播 / 小盘 ⇒ **这就是触达命门的产品层根因**。计算器是「被人拉」（有问题才打开），爆款是「拉住人」（养成习惯、自带传播）。
4. **重构原则**：把引擎从**「工具」**重新表达为**「反馈闭环 + 游戏 + 大众玩具」**；并采用**双产品架构**——免费病毒玩具当楔子，认真训练器当深水区。
5. **最该做的一个**：**「台球答案之书 / 口袋教练」**——把所有反解器后端化，对外只呈现一件事：**任何球形，一键给你标准答案 + 你的差距 + 没打好的原因拆解**。这是教练按小时收费的核心价值，被引擎自动化。

## 1. 第一性原理拆解

### 1.1 引擎到底是什么（剥掉所有功能包装）

把 7 个功能全删掉，只看引擎暴露的**原子能力**〔事实，依据 `docs/04` §3 与求解器实现〕：

| 原子能力 | 形式化 | 现在被包装成 |
|---|---|---|
| **FORWARD 模拟真相** | 状态 + 击球输入 → 完整未来（轨迹/碰撞/进袋/终位） | 分离角演示、回放 |
| **INVERSE 反解** | 状态 + 想要的结果 → 该用的输入 | 走位反解、斯诺克反解、翻袋/颗星 |
| **GENERATE 造局** | 采样合法/有趣的球形 | 球形生成器 |
| **PERCEIVE 感知** | 照片 → 球形状态 | 拍照建球形 |
| **RENDER 渲染** | 状态/轨迹 → 广播级画面 | 教学素材管线 |

> **一句话**：引擎是**「台球真相神谕机」**——对任意局面，它知道「真相」（会怎样）和「最优」（该怎样），还能看懂照片、画成片。**这是任何台球博主、任何竞品结构上做不到的**。现有 7 个功能只是这台神谕机的 7 个**随手做的出水口**——出水口可以重设计。

### 1.2 玩家到底要什么（不是工具，是反馈）

**第一性追问**：玩家打开任何台球 App 的终极目的是什么？→ **变强 / 赢球**。
**再追问**：变强的卡点是什么？台球技能 = **决策（打哪颗、走哪条线）× 执行（身体能不能打出来）**。

关键洞察〔推测，但逻辑强〕：**其他运动都有即时反馈**——高尔夫看球落点 vs 目标、篮球进没进一目了然。台球**进球**也有反馈（进/不进），但台球真正的高阶技能——**走位与决策——几乎零反馈**：你打完一杆，母球停在某处，你**永远不知道是否存在更好的线路**。没有反馈 → 自学者在中间层无限期卡住（这正是 2026 抖音高频原话「卡 X 档太久」的物理根因）。

**结论**：玩家市场最深、最未被满足的需求 = **对「决策/走位」的即时、个性化、客观反馈**。
- 教练能给，但 ¥300/小时、稀缺、不在你打球的当下。
- 短视频给的是**通用**知识，不是**你这一局**的答案。
- **只有引擎能在你打球的当下、对你的具体球形、给出客观最优** —— 这是它的独占领地。

### 1.3 爆款到底是什么（不是"好内容"）

〔行业共识 + 推测〕一个东西能爆,靠的不是质量,是**机制**:
- **情绪峰值**：惊讶（"原来最优是这样"）/ 被证明（"判我对了"）/ 虚荣（"我的球像转播"）/ 身份（"我球商 850"）/ 冲突（争议）。
- **产物即广告**：用完产生的东西本身可分享、自带钩子。
- **低门槛参与**：3 秒能上手，不需要"想认真训练"的决心。
- **回路 / 网络效应**：用得越多、人越多，越好玩 / 越权威。

**计算器在这四条上全不及格**：算个翻袋角度——无情绪、产物不可分享、要先懂术语、无网络效应。**这从数学上注定它不爆。**

---

## 2. 诚实诊断：为什么现在触达不动

把 1.1–1.3 合起来,根因清晰〔推测,但我有把握〕:

> **现有产品把一台「神谕机」做成了「专家计算器合集」。计算器服务的是「已经想认真训练、且懂术语」的极少数人（SAM 仅 ~330 万，营收测算 §3），且低频、无传播、无网络效应。所以无论怎么投内容/地推,触达天花板都被产品形态本身锁死了。**

这不是营销不努力,是**产品架构选错了表达方式**。神谕机的正确表达不是"给专家算东西",而是:
- **给所有人即时反馈**（把"变强"的反馈空缺填上）；
- **做成游戏/体验**（把低频工具变高频习惯）；
- **产物自带传播**（把每次使用变成一次获客）。

## 3. 重构三原则

### 原则 A：双产品架构 —— 楔子玩具 + 深水训练器（解命门的架构级答案）

〔第一性原理〕严肃训练器 TAM 小、摩擦高；免费有趣的玩具 TAM 大、摩擦零。**同一台引擎能同时驱动两者**。所以:
- **楔子（免费、病毒、大众）**：解谜游戏 / 答案之书 / 脑力对决 —— 零门槛、自带传播,负责**海量触达**。
- **内核（订阅、严肃）**：系统训练 + 球商成长 —— 把楔子沉淀的认真用户导入,负责**变现**。

> 这是**从产品架构层解触达命门**,而非营销层。楔子把盘子从"330 万认真玩家"扩到"2 亿泛玩家",内核在其中收认真的那批。

### 原则 B：预测先行(Predict-before-Reveal)做成全局设计语言

〔学习科学 + 参与度〕主动预测 >> 被动观看。把「**你先判断 → 引擎揭晓真相**」刻进每一个界面(首启、解谜、内容、复盘)。这把引擎的"真相揭晓"变成**多巴胺机制**——每次揭晓都是一次"啊哈"或"打脸",既教学又上瘾又可分享。这不是一个功能,是贯穿全产品的**交互母题**。

### 原则 C：个性化优先 —— 关于"你自己"的产物

〔传播心理〕人只转发**关于自己**的东西。通用教学没人转,"**我的**赛后解析 / **我的**球商段位 / **我**差 2°就进了"才会转。引擎 + 渲染能把每次使用产出**个性化产物**,每个产物都是一条广告。

## 4. 重新设计的产品/特性（从引擎长出，按爆款潜力排序）

> 全部基于已实现的原子能力(1.1),不是新物理。多数是**重组现有能力 + 换产品形态**,工程增量可控。

### ★ P1 「台球答案之书 / 口袋教练」——填反馈空缺（旗舰，我最推荐）

- **是什么**：任何球形（拍照 F17 / 生成 F16 / 手摆）→ 引擎给**三件套**：① 这一杆的**标准答案**（最优打法,可视化）；② **你的差距**（你的选择 vs 最优,胜率差几个点）；③ **没打好的原因拆解**——「你瞄的线**本身就不进**（决策错）」vs「线对了是**力度/塞偏了**（执行错）」。
- **为什么是第一性的对**：直接填 1.2 的反馈空缺,是教练按小时卖的核心价值。**"决策错 vs 执行错"的拆分是金矿**——玩家最纠结"我到底为啥没打好",至今无人能客观分。
- **复用**：把走位反解/斯诺克/翻袋/颗星/分离角**全部后端化**,对外收敛成**一个**连贯产品(答案之书),而不是 6 个孤立计算器。
- **爆款角度**：「原来最优是这样」的反转天然可分享；「台球终于有标准答案了」是强 slogan。
- **状态**：纯软件,复用现有反解器 + 渲染,**现在就能做**。

### ★ P2 台球解谜游戏（把"工具"变"游戏"，大众楔子）

- **是什么**：引擎程序化生成**无限关卡**(保证可解、可评分),玩家预测清台顺序/走位,引擎评分通关。日常「每日球局」(同题+战绩格分享)+ 闯关模式 + 段位。
- **为什么**：游戏是**习惯 + 网络效应 + 应用商店推荐位**,传播力碾压工具。台球解谜品类**空白**,且**只有你能做**(无限造局 + 客观验证)。这是双产品架构的**楔子主体**。
- **复用**：球形生成器(出题)+ 反解器(答案/评分)+ 渲染。
- **状态**：纯软件,现在能做;可做成 App 内模式或独立轻 App。

### ★ P3 异步「脑力对决」PvP（在线竞技台球，但考脑不考手）

- **是什么**：双方拿到**同一个生成球形**,各自用打点/力度 UI 提交"我会怎么清",引擎当**绝对公平的裁判**判定谁的方案真能清/得分高。挑战好友、排位、段位、对局可生成解析片。
- **为什么是新品类**：现有在线台球(8 Ball Pool 等)考的是**划屏手感执行**;**没有任何产品考"决策/走位 IQ"**。引擎让"无需真台、无需同场、纯比脑子"的竞技成为可能——这是台球的**电竞 IQ 版**,强社交、强病毒(挑战链接/段位炫耀)。
- **复用**：球形生成 + FORWARD 判定 + 反解(算理论最优做参照)。
- **状态**：核心可做;需补对局/匹配的轻后端(自建 REST 已有)。

### P4 个性化「赛后解析 / 神球转播」一键生成（自带传播）

- **是什么**：用户输入自己的球(拍照/录入)→ 一键产出**职业转播级**解析片(上帝视角轨迹 + 走位 + 胜率 + 解说字幕)。
- **为什么**：原则 C,关于"自己"的产物转发率最高,每条带水印=一条广告。蹭观众极熟的赛事转播视觉。
- **复用**：渲染管线产品化 + 拍照建球形。

### P5 AR 瞄准镜（北极星，诚实标注依赖）

- **是什么**：手机对准真实球台 → **实时**叠加最优线路/分离角,像业余版鹰眼。
- **为什么**：这是**终极爆款**——把"口袋教练"从"拍照后看"变成"举起手机就看"。现有**拍照建球形(F17)就是它的 MVP 雏形**。
- **诚实边界**：需**实时 CV(自动识别球+号码+实时位姿)**,当前只有手动 4 角标定 + 几何单应,自动检测/号码归类是未来 DL(`docs/04` F17 阶段 2/3、AI 摄像 v2.0)。**现在做不了,但它是引擎+感知能力的必然终点,应作为北极星牵引路线图。**

## 5. 该砍 / 该收的（范围纪律 + 反取悦）

- **别再造独立计算器**：翻袋器、颗星公式、反射器作为**孤立工具**低频低传播,应**折叠进 P1 答案之书 / P2 解谜**当后端能力,不再各占一个入口。
- **诚实**：当前"瑞士军刀式计算器合集"形态,功能越加越分散,**不解决触达反而稀释焦点**。第一性原理下,**做减法(收敛成 1 个反馈产品 + 1 个游戏楔子)比做加法更对**。
- **物理已够,别再扩物理**：与 `docs/00` 2026-06-18「不再扩物理新功能」一致——爆款不在物理精度,在产品形态。

## 6. 诚实边界与依赖

| 约束 | 影响 | 对策 |
|---|---|---|
| **2D 平面物理**〔事实〕 | 跳球/扎杆腾空表达不了 | 不影响 P1–P4(走位/决策不依赖腾空);P5 AR 同样 2D 足够教学 |
| **常量未标定到真实台**〔事实,docs/04 §3〕 | 反解的"最优"可能与真实台有偏差 | P1/P3 用「相对差距/排序」比「绝对数值」稳健;标定靠真实俯拍视频(已是 backlog) |
| **无实时 CV**〔事实〕 | P5 AR 现在做不了 | P5 设北极星;先用 P1 拍照版验证需求 |
| **创意≠保成**〔假设〕 | 每个新品都可能不爆 | P1/P2 纯软件、复用已有、增量小 ⇒ **低成本快速验证**,跑不动就砍 |

## 7. 如果只能押一个：先做 P1「答案之书」

**理由**：① 直击第一性需求(反馈空缺),不是博热度的噱头;② 纯软件、复用全部现有反解器,工程增量最小;③ 同时是**留存内核**(认真玩家天天来对答案)和**传播源**("最优反转"可分享);④ 是 P2 解谜、P3 对决、P5 AR 的**公共底座**(它们都需要"给出标准答案"这一能力)。

**最小验证(MVP)**：拍照/选一个球形 → 引擎给最优走位 + "你来选,看差多少" → 一条可分享的"标准答案"卡片。用它验证两件事:玩家是否真的为"反馈"买单(付费意愿)、是否天天来(留存)——正好是营收测算 §8 最该先验的两条最软假设。

> **一句话收尾**：你拥有的不是"训练 App",是"台球真相神谕机"。过去把它做成了给专家的计算器,所以触达被锁死。第一性原理的解是——**把神谕机做成「人人都想要的反馈」和「人人都能玩的游戏」,而不是「少数人偶尔用的计算器」**。
