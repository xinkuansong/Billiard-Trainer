# 走位可视化 → 短视频引流方案（讨论整理）

**日期**：2026-06-24
**触发**：用户提出「控制白球走位的变量本质上只有少数几个，是否能画出母球可行区域图」，进而想到「把它可视化做成短视频，用于教学/引流」。
**方法**：先从第一性原理把走位的自由度讲清楚（祛魅），再设计可视化与视频内容，最后做客观评价。结论以〔事实〕〔推测〕〔假设〕标注关键判断。
**关系**：本文是**内容/增长层**草案，上承 `20260618-产品重构-从物理引擎第一性原理.md`（引擎是真资产、内容即产品）；若采纳，落地需对接 `ShotPredictor` + `SequenceVideoExporter`。

---

## 0. TL;DR

1. **走位的自由度本质很少**：固定母球/目标球/袋口后，瞄准方向被进球约束锁死，玩家真正自由的输入只有 **3 个**——力度 `V0`、左右塞 `a`、高低杆 `b`；其中吃库前**有效只有 2 个**（高低杆 × 力度）。
2. **因此「母球可行区域图」是可画的**：它是控制空间到桌面落点的二维可达集，典型形状是以鬼球位为顶点、贴切线展开的**扇形/云**。
3. **价值定位 = 走位祛魅**：把「手感/玄学」翻译成一组有限、有因果的心理模型；让玩家获得**完整走位认知**（锚点 → 两个旋钮 → 切角是能量分配器 → 库与塞 → 可达边界与余量）。
4. **可视化做成短视频**潜力大：核心爆点是「上千条母球轨迹同时绽放出一片发光可达区域」的**涌现**画面，且**内容即产品**（视频演示的就是 App 核心价值）。
5. **客观评价**：作为低成本、强差异化、内容即产品的内容打法，**值得做（B+/A-）**；但作为「大众引流神器」**偏乐观**，更现实定位是「严肃球友磁铁」。成败取决于**制作功力 + 出量 + 数据迭代**，不取决于点子本身。
6. **行动建议**：别先建大管线，**先糙做 2–3 条 pilot 发布**，用完播率/关注收藏比/下载漏斗三指标证伪后再决定是否铺图谱。

## 1. 物理基础：走位到底有几个变量

### 1.1 变量盘点

引擎 `cueStrikePT(V0, phi, theta, a, b)` 暴露的输入：

| 输入 | 含义 | 是否自由 |
|---|---|---|
| `phi` | 瞄准方向 | **被进球锁死**（母球必须撞到鬼球位） |
| `theta` | 杆身仰角 | 平杆≈0，先忽略（跳球/扎杆除外） |
| `V0` | 力度（杆头速度） | ✅ 自由 |
| `a` | 左右塞 | ✅ 自由（吃库前几乎不改变路径） |
| `b` | 高低杆 | ✅ 自由 |

- 真正自由的连续输入 = **3 个**（`V0`, `a`, `b`）。
- **吃库前有效维度 = 2 个**（`b` × `V0`）：左右塞 `a` 主要在**吃库后**才显著改变反弹角。

### 1.2 为什么接触瞬间状态被锁住一半〔事实〕

固定母球/目标球/袋口后：
- 目标球须朝袋口走 → 连心线方向固定 → **鬼球位固定 → 切角 α 固定**。
- 撞击瞬间母球球心必到鬼球位（位置固定）。
- 目标球拿走法向分量，母球留下切向分量 + 旋转影响；**切线方向固定**（垂直于连心线）→ 这就是「90° 分离角规则」的来源。

撞击后母球去向只由两件事决定：
- **离切线偏多少**：高杆前送、低杆回缩、定杆贴切线。
- **走多远**：力度 + 摩擦。

### 1.3 可行区域图的形状

把「母球最终停点」看成桌面二维点 (x,z)，映射 f:(V0,a,b)→(x,z) 的**像就是二维可达集**：
- 无库时 ≈ 以鬼球位为顶点的**扇形/月牙**：中间定杆切线，两侧满高杆/满低杆曲线，径向范围由力度 0→`maxVelocity 6.5` 决定。
- 含库时扇形**折叠**并延伸出多库分支，左右塞把每个分支撑成带宽。

### 1.4 物理边界（引擎常量，避免画出失真图）

- 打点受**打滑极限** `miscueLimitFraction = 0.5`（半个半径）约束：`a²+b²` 圆形约束，非方形。
- 力度上限 `maxVelocity = 6.5`。
- 吃库衰减 `cushionRestitution = 0.94`，远分支可达性受限。

### 1.5 必须说清的坑

- **多对一**：很多 (V0,a,b) 落到同一停点 ⇒「可达」≠「可独立精确控制」。
- **维数坍缩**：3 维输入 → 2 维落点，有 1 维冗余 ⇒ 逆问题（给定目标停点反查打法）对训练更有用。
- **`phi` 并非真固定**：加塞带来 squirt/swerve，严格时 `a` 会轻微反作用回 `phi`。
- **折叠分支**：含库后映射非单射，画图须按「吃几库」分层着色。

## 2. 产品立意：走位祛魅 = 完整走位认知

祛魅本质 = 把「手感/玄学」翻译成**有限的、有因果的几张图**。完整认知压缩为最小概念集：

1. **锚点**：撞击点固定，母球默认沿切线走（90° 法则）——整个走位的脊柱，一切都是相对切线的偏移。
2. **两个旋钮**：高低杆把线掰弯、力度定走多远 → 单独生成二维扇形。
3. **切角 = 能量分配器**：厚球→母球死在原地；薄球→母球留速、近沿原方向冲。解释「为什么有的位天然好走」。
4. **库与塞 = 延伸 + 重塑**：扩大可达范围，同时放大误差。
5. **元认知（最被低估）**：**可达边界 + 余量**。
   - 边界：有些位置物理上到不了 → 走位是**选择**不是硬凑。
   - 余量：高手瞄的是有容错的区，不是点 → 「宽容区 vs 穿针区」才是真正的祛魅。

### 现有积木盘点（已具备 ~80%）

- **正向**：`ShotSimulationViewModel`——设打点+力度看母球走线，已画 90° 垂线、切球角 α、假想球。
- **逆向**：`SiluTrainerViewModel`——摆球后画可行落区/标 K 球过点，`PositionPlaySolver` 反解塞与力度。
- **基础概念**：分离角 drills（c024–c031）、`ContactPointTableView`、`AimingPrincipleView`。
- **渲染管线**：`ShotPredictor`（正向模拟）+ `SequenceVideoExporter`（`SCNRenderer.snapshot` 抓帧、视频/GIF、顶视2D/斜视3D、HUD、竖屏）+ `TrajectoryPlayback`。

> **缺的一块新积木**：把「单条轨迹」扩成「**N 条轨迹的累积渲染层**」——上千次离线模拟 → 半透明轨迹叠加（alpha 累加）→ 热力图。纯离线、增量、不动现有架构。

## 3. 视频可视化方案

### 3.1 为什么会「牛逼」

核心爆点 = **涌现**：固定球形，扫一遍打点+力度，几百条母球轨迹同时绽放叠成发光可达区域。「从混沌长出确定形状」天生会传播，且本身就是祛魅。

### 3.2 候选镜头（按 wow 排序）

1. **可达扇形绽放（Hero）**：打点盘光点转圈，每个打点射出一条轨迹，残影累积成发光云。字幕「这一杆白球能去的地方就这么多」。
2. **因果分层（教学）**：同一杆分 4 层显形——切线 → 叠高低杆掰弯 → 叠力度伸缩 → 叠吃库反射。
3. **余量对决（最有说服力）**：宽容区 vs 穿针区，输入抖动 ±δ 跑多次看落点散布。字幕「职业不是手稳，是会挑宽容的位置」。
4. **禁区揭示**：可达云外压暗标灰。字幕「有些球到不了——不是你手不行，是物理不允许」。

### 3.3 变量收敛（避免组合爆炸）

变量空间 = {库:开/关} × {袋:中/角} × {切角:0–90 ~18 档} × {两球贴库情形:多}，全乘=上千条，做不完。

**纪律**：
- **一条短视频 = 只扫一个变量，其余全锁。**
- **做成图谱式系列，不做一条巨片**（每条 15–30s 自成一体、可连刷、对应玩家真会搜的问题）。
- 「两球不同库边」只挑 3–4 个原型：目标球贴库、母球贴库、底袋附近清球。

### 3.4 让对比看得见

- **残影叠加**（上一档压暗留底、当前档高亮）让扇形旋转/变形成为连续运动；或 **分屏对照**（α=30° vs 60°）。
- **旋转切线脊柱全程常驻**——系列视觉品牌 + 认知锚点。

## 4. 典型场景视频清单（短视频引流）

> 冷启动「情绪/揭秘钩子」比机械讲解传得远。每条锁死其余变量，只演一件事 + 一句反直觉钩子。

| # | 主题 | 钩子 | 认知点 | 定位 |
|---|---|---|---|---|
| ① | 可达边界 + 禁区 | 「下一颗总走不到位？可能真不怪你——这颗球物理上就到不了」 | 可达有边界，走位是选择 | **最强冷启动**（消除自我怀疑、高转发） |
| ② | 切角扫描 | 「为什么高手宁可打厚球，也不贪看着简单的薄球？」 | 切角是能量/控制总开关 | 反直觉揭秘，冷启动第二条 |
| ③ | 90°法则 + 高低杆 | 「九成业余不知道：白球撞完默认走这一条线」 | 锚点 + 两个旋钮 | 系列**地基课**、复用率最高 |
| ④ | 高低杆幅度 | 「什么都不变，只动一下打点，白球差出大半张台」 | 高低杆话语权 | 建立认知、转化 |
| ⑤ | 中袋 vs 角袋 | 「选错袋口，白球直接走废」 | 袋口几何重塑可达区 | 长尾、覆盖搜索词 |

**发布顺序**：第一波拉新（情绪/揭秘）① + ② → 第二波承接（建认知、转化）③ + ④ → 细分补充 ⑤。

### 统一格式（对引流关键）

- **竖屏 9:16**（`SequenceVideoExporter.portrait` 已支持）。
- **前 1.5 秒定生死**：甩谜面字幕 + 露一眼绽放。
- **时长 15–25s**，一条只讲一件事。
- **固定视觉语言**：白=瞄准线、橙=进球线、常驻旋转切线脊柱、末尾绽放可达云。
- **标题 = 玩家真会搜的问题**；结尾轻 CTA 落 App。

### 诚实红线

1. 「无库」必须字幕标明是教学简化（真台有库），否则观众误以为无库扇形=真实可达。
2. 所有轨迹必须 App 内 `ShotPredictor` **同源跑出、不手调**——保证用户能在 App 复现，否则祛魅反噬。

## 5. 客观评价

### 5.1 真正的优势

1. **边际成本极低、资产复用强**〔事实〕：已有引擎 + 导出管线，多产一条主要是配参数 + 累积渲染层。内容营销最常见死因是产不起量，此处单条成本极低 = 结构性优势。
2. **内容即产品**〔事实〕：视频演示的就是 App 核心价值，意图落差极小。
3. **视觉差异化 + 护城河**〔推测〕：台球内容多为实拍/真人；物理可视化是异类，能 scroll-stop；无忠实引擎的对手抄不动。

### 5.2 真正的风险

1. **「对你牛逼」≠「对大众牛逼」**〔推测，最大风险〕：开发者觉得绽放图惊艳是因为懂背后的问题；大众刷到抽象线扇可能「太理论/看不懂/划走」。抽象图解传播上限天然偏低。
2. **「引流」可能目标错配**〔推测〕：被钩住的多是**已有痛感的现有球友**，冷启动非球友不在乎 → 更像「严肃球友磁铁」而非「拉新机器」（这类用户 LTV 可能更高，但别用大流量当成功标准）。
3. **15 秒理解负荷是真问题**〔事实〕：讲到「小白有收获又不劝退」需大量迭代，首批大概率不太浅就太密。
4. **「引擎能渲染」≠「信息流能火」**〔事实〕：爆款物理可视化靠极致动效/节奏/配乐/排版；默认样式抓帧是「工程师做的图」。这是设计剪辑的活，最常被低估。
5. **平台算法与你为敌**〔事实〕：分发看完播+互动，教学图解完播天然低，需强钩子 + 紧剪辑 + 大量试错。
6. **转化漏斗未验证**〔假设〕：浏览→下载→留存每层都漏，「内容好就转化」是假设非事实。

### 5.3 净判断

- 作为低成本、强差异化、内容即产品的内容打法：**值得做（B+/A-）**。
- 作为大众引流机器：**偏乐观**，现实定位 = 严肃球友磁铁 / 品牌可信度资产 / 护城河展示。
- **决定成败的是制作功力 + 出量 + 数据迭代，不是点子本身**——这是内容运营赌注，赢家靠 volume 与平台 sense（与写代码不同的能力）。
- ⚠️ 警惕**创作者偏见**：当前兴奋里混了「因为我懂深度所以觉得牛逼」。

### 5.4 低成本证伪（关键纪律）

别先为 20 条视频搭累积渲染管线。**先糙做 2–3 条发布**，盯三指标：

- **完播率**（>平台均值 = 钩子+理解负荷过关）
- **关注/收藏比**（高 = 击中「想变强」的人）
- **主页点击 / 下载**（漏斗是否真通）

**让市场而非工程师审美裁决**，数据通过再铺图谱。

## 6. 下一步（待用户拍板）

1. 选定第一条 pilot：**① 可达边界**（引流爆发力最强）或 **③ 90°法则**（地基、复用率最高）。
2. 对选定镜头出**可执行镜头脚本 + 数据流方案**：摆球坐标、扫哪些打点/力度、采样密度、残影/绽放 alpha 节奏、字幕时间轴，全部挂 `ShotPredictor` + `SequenceVideoExporter`。
3. 糙版产出 2–3 条 → 发布 → 看三指标 → 决策是否铺图谱。

## 7. 落地进展

### Pilot ①「可达轨迹绽放」糙版 ✅（2026-06-29 初版 → 2026-06-30 真台改版）

按 §5.4 纪律「先糙做、别先建管线」落地第一条 pilot，**dev-only**（做成测试，零产品侵入、零架构债，验证三指标后再决定产品化/补 ADR）。

- **代码**：`QiuJiTests/ReachabilityVizTests.swift`（dev-only 测试；复用 `VideoWriter` 导出）。
- **物理同源（诚实红线 §4-2）**：固定母球/目标球/选定袋（中场目标球 + 右上角袋 + 切角 35°），扫 `(高低杆 spinY × 力度 V0)`（15×18=270 杆，`spinX=0`、`|b|≤0.5`、`V0∈[0.6,6.5]`），每杆 `ShotPredictor.predict` 真算、不手调；取「能把目标球打进且母球未刮杆」的母球轨迹（227 条）。
- **渲染范式（2026-06-30 改版）**：从初版「2D 顶视 CoreGraphics 抽象台」改为**直接在 USDZ 真台上渲染** —— 复刻 `SequenceVideoExporter.RenderContext` 的竖屏旋转顶视取景（`AngleTrainingScene` + `SCNRenderer` 离屏快照，相机 `fitRotatedTable`/`applyTopDown2DRotated`），轨迹以世界坐标喂 `addLine` 圆柱线，字幕用 CoreGraphics 叠在快照上。
- **最多三库（诚实红线 §4-1）**：每条轨迹保留到**母球第 3 次吃库**（取第 4 次吃库时刻截断，不足 3 库则到停稳），从同源 `TrajectoryPlayback` 按 120Hz 重采样后简化；字幕显式标「教学示意·最多三库」。
- **交替配色**：6 色调色板按轨迹序号循环，相邻轨迹异色以区分（用户诉求）。
- **方案微调**：真台 + 三库覆盖下母球几乎铺满台面，原「禁区凸包压暗」在真台上不诚实且失去意义 → **移除禁区叠层**，卖点收敛为「彩色多库可达轨迹绽放」。
- **画面**：竖屏 9:16（1080×1920、30fps、13s），分阶段：钩子谜面 → 逐条绽放成可达云 → 满云停留 → 收尾红线说明。
- **产物**：`build/reach_viz/{reach_still.png, reach_pilot1.mp4}`（静帧 + 三阶段抽帧已肉眼核对）。
- **运行**：`xcodebuild test -scheme QiuJi -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -only-testing:QiuJiTests/ReachabilityVizTests/test_reach_video`（静帧用 `/test_reach_still`，~44s 快调坐标/配色）。

**下一步（待用户拍板）**：① 看片定夺画面与节奏（轨迹密度/配色/绽放速度——227 条中心略糊，可降密度或加残影前沿）；② 是否补第二条凑 2–3 条发布；③ 发布后看完播/关注收藏比/下载漏斗三指标，再决定是否产品化 + 铺图谱。
