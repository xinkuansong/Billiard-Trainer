# 增长方案：解「触达/下载」命门（球迹 QiuJi）

**日期**：2026-06-18
**目的**：营收测算（`docs/research/20260618-营收测算-C端订阅营收区间.md`）反复指出——无论付费侧怎么修正，**决定营收量级的永远是「能触达并说服多少认真想涨球的人」**。本文不再论证命门，而是给出**一套结合现有全部功能、2026 台球社会环境、可由 1 人～小团队真正执行的获客方案**。
**性质**：行动方案（情景建模之上的执行层）。每条标注 〔事实/来源〕〔假设〕〔行动〕，避免把推测当承诺。
**配套**：定位见 `docs/01`，功能矩阵见 `docs/04`，营收漏斗见上引营收测算，硬件/B 端见 `docs/research/20260617-AI台球投影系统-硬件竞品.md`。

## 0. TL;DR

**一句话打法**：**把产品本身变成内容机器——用物理引擎/渲染管线近零成本量产「别人拍不出来的可视化解球内容」，借真人台球 IP 的脸建立权威，用「拍照建球形」做零摩擦钩子，把 18 万家场馆当独有线下入口，先在 iOS 用最小成本验证「内容→激活→留存→付费」单位经济，再上 Android 放量。**

**三个必须同时压上的杠杆**（缺一不可，互相复利）：
1. **内容引擎**（主引擎，唯一可能 CAC<LTV 的获客）：系列化短视频/图文 + 真人 IP。
2. **场馆线下**（台球独有、竞品做不到的优势）：连锁/无人自助合作 + 桌边二维码 + 赛事赞助。
3. **私域沉淀**（把流量变留量）：微信社群 + 品牌词心智 + 教练联名。

**90 天最小动作**（详见 §6）：用渲染管线预产 40 条底料 → 主攻抖音+小红书双号 → ASO 卡「台球 / 走位 / 台球训练」词 → 上线落地页/问卷验证付费意愿 → 谈 3–5 个腰部博主 + 3 家本地场馆试点 → 只看一个北极星指标「周新增激活」。

**诚实前提**：内容获客是慢功，3–6 个月才见稳定增长〔行业共识〕；几条爆款只够把你从「悲观」推到「保守」档（营收测算 §6.5）。本方案是「经营一条内容线 + 一张场馆网」，不是「拍中几条就起飞」。

## 1. 战略洞察：我们手里到底有什么独特牌

解命门前先盘点**结构性优势（别人难复制）**与**结构性逆风（必须正面解决）**。只有把优势对准逆风，方案才成立。

### 1.1 三个结构性优势（要 all-in 放大）

| 优势 | 为什么独特 | 直接转化为获客的方式 |
|---|---|---|
| **产品即内容工厂** | 物理引擎 + 离线渲染管线（`docs/04` §3、教学素材管线）可批量出「真实轨迹/分离角/走位」可视化动画，**边际成本趋零**。纯靠真人拍摄的博主做不出「上帝视角精确轨迹叠加」。 | 72 个 Drill × 每个出 1 条「这球怎么走位」= 起步 72 条差异化内容；选题无上限。 |
| **「拍照建球形」是零摩擦钩子**（F17） | 用户在球桌边遇到难球 → 拍一张 → App 给解。这是台球类里**摩擦最低的「立刻试一下」入口**，且天然可分享、天然发生在使用场景。 | 抖音/小红书经典「评论区出球形，我用 App 帮你解」互动栏目；场馆桌边「扫码拍这球看怎么打」。 |
| **18.6 万家场馆 = 独有线下入口** | 台球是**高密度线下聚集**运动，无人自助连锁已成网（小铁签约近 6000 家/350+ 城市，谈小娱 2500+ 家/300+ 城市，球小牛等）〔来源：艾媒/智研 2025–2026〕。线上 App 极少有这种「目标用户物理聚集」的场景。 | 桌边二维码、店内赛事赞助 Pro 兑换码、教练入驻、异业合作。 |

### 1.2 三个结构性逆风（必须工程化解决，不能绕）

| 逆风 | 后果 | 本方案的解法（见对应章节） |
|---|---|---|
| **iOS 自然流量不能直挂 App Store 下载** | 抖音/快手爆款只能靠用户「自己去搜」，跳失极高〔事实〕。 | 好记品牌名 + ASO 关键词卡位 + 评论区/主页置顶引导 + 微信视频号/小红书等可外链渠道兜底（§2.5、§2.6）。 |
| **真人/可信 IP 缺位** | 纯引擎动画难在强 KOL 的台球领域立权威、也更难起爆款〔营收测算 §6.5〕。 | B2B2C：把 App 做成博主「出片外挂」+ 自建真人养号双轨（§2.4）。 |
| **中国软件订阅习惯弱 + 训练非刚需** | 即便触达，付费/留存可能不及模型 B 假设。 | iOS 阶段最小成本先验证留存与付费（§7 三道 gate），证伪即调整，不盲目投跨端。 |

> **核心洞察**：2026 抖音台球生态里，「**想涨球 / 卡在 X 档瓶颈期太久 / 走位不够细腻经常要纠错**」是用户高频原话〔来源：抖音台球内容〕——这正是 `docs/01` 定位的「中间层瓶颈期爱好者」的**自我描述**。需求不用创造，已经在评论区喊出来了；命门是**让喊「想涨球」的人知道有这个工具、并低摩擦用起来**。

## 2. 主引擎：内容获客（最详、最优先）

营收测算已证明：本产品 ARPPU 下**付费投放几乎必亏**，自然内容是唯一可能跑正的获客方式。这一章是方案的重心。

### 2.1 内容差异化定位

2026 台球短视频两条已验证的爆款路径〔来源调研〕：
- **专业教学 IP**（王桁台球/新锐台球等）：分级教学、清台演示、"千万不要练系列"、"涨球口诀"，引流到私域/课程。
- **趣味反差/盲盒**（子涵大帝、全国青少年中式台球挑战赛切片）：业余戏剧性对局 + 一本正经解说，流量极高但精准度低。

**我们的差异化 = 第三条路：「上帝视角 + 物理真相」**。别人只能说「这球要加塞」，我们能**把母球轨迹、分离角、走位落区精确画出来并验证进不进**。把抽象球感翻译成「看得见的几何与物理」，这是引擎独占的内容形态。

### 2.2 选题库（映射功能 → 真实爆款语言）

把每个功能变成一个内容栏目，用 2026 真实流行的标题语言包装：

| 栏目 | 对应功能 | 选题示例（贴近平台爆款语言） |
|---|---|---|
| **《为什么你总走死》** | F12 分离角与走位 | "卡在 3 档？90% 是分离角没算明白"、"同一颗球，加不加塞母球差半张台" |
| **《走位脑训练》** | F14 思路训练器（反解） | "想母球停这儿，该用什么塞多大力？App 帮你反算"、"职业选手的走位思路，拆给你看" |
| **《翻袋不靠蒙》** | F18/F19 翻袋·颗星 | "翻袋到底怎么瞄？一颗星/两颗星公式"、"真实球台反射角比理想小，这样修正" |
| **《拍照解球》（钩子王）** | F17 拍照建球形 | "评论区发你的难球照片，我用 App 算给你看"、"球房遇到这种球，拍张照就知道怎么打" |
| **《今日球形挑战》** | F16 球形生成器 | "随机开球这一局，你会怎么清？"（互动留评 → 下期出解） |
| **《斯诺克做杆》** | F15 斯诺克战术 | "怎么把对手做到完全看不到球？" |
| **《一杆一课》** | 72 个 Drill | 每个 Drill 一条标准走位讲解（渲染管线批量产） |

> 黄金内容结构（借力反差/悬念）：**「真人先判断 → App 揭晓物理真相 → 反转」**。例如教练说「我觉得走中袋附近」，引擎一算其实会走库后死位——制造「连老手都算错」的钩子，同时强力展示产品价值。

### 2.3 出片流水线（让产能变成壁垒）

〔行动〕建立「**选题 → 引擎仿真 → 渲染管线出片 → 真人配音/出镜 → 多平台分发**」的标准流程：
- 引擎/渲染管线负责**视觉底料**（轨迹叠加、慢放、上帝视角），近零成本、可日更。
- 真人负责**权威与温度**（出镜或配音），解决"纯动画立不住权威"。
- 一次仿真 → 切多版本（横屏 B 站/竖屏抖音/图文小红书），一鱼多吃。

### 2.4 真人 IP：双轨

**逆风是「我们没有台球冠军的脸」。两条路并行：**

**A. B2B2C —— 把 App 做成博主的「出片外挂」（杠杆最大，最先做）**
- 〔行动〕给腰部台球博主/本地教练**免费 Pro + 专属内容工具**（编排台录制走位序列、拍照建球形、上帝视角导出），让 App 成为他们的**生产力工具**。
- 他们用我们的工具出片 → 自带「这是用某 App 做的」露出 → 借他们已有的精准粉丝触达，**我们不用从零养号**。
- 商业上可叠加联名/分成/导流分账（也是 §7 上行的「教练 IP 联名」）。
- 找谁：**腰部**（5 万–50 万粉）性价比最高——头部贵且难谈，腰部缺差异化内容、有动力用新工具。

**B. 自建养号（慢但沉淀品牌资产）**
- 创始人/团队真人出镜 + App 演示，长期经营 1–2 个官方号（对标"新锐台球官方号"的运营节奏：日更/隔日更、人格化、强 CTA "想涨球记得…"）。
- 目标不是单条爆，是**累计沉淀「想涨球就用球迹」的品牌词心智**（营收测算 §6.5：复利在账号+心智，不在单条）。

### 2.5 平台矩阵与各自的转化链路（重点解 iOS 直链断裂）

| 平台 | 角色 | 转化链路设计（关键） |
|---|---|---|
| **抖音** | 起量主场（台球流量最大） | 自然流进不了直链 ⇒ **好记品牌名「球迹」+ 简介/置顶评论引导「App Store 搜 球迹」+ ASO 卡位**；直播间挂载/小程序兜底。 |
| **小红书** | 搜索长尾 + 攻略沉淀 | 2026 小红书**搜索流量占比 >65%**〔来源〕，已是搜索引擎。按 SEO 5 步法布词（主词「台球走位」+ 长尾「中式八球翻袋怎么瞄」+ 疑问词「台球卡 3 档怎么办」），一个主题 10–20 篇形成"专家池"；外链/引导相对抖音更顺。 |
| **微信视频号 + 公众号** | 私域转化最顺 | 微信生态内可外链/小程序，是**转化率最高的兜底渠道**；把抖音/小红书粉丝沉淀到这里再推下载。 |
| **B 站** | 长内容/深度教程 | 横屏长讲解，建立"硬核专业"心智，长尾搜索价值高。 |

> **同样的播放量，链路差一倍下载就差一倍**〔营收测算 §6.5〕。链路工程化（§5）和内容本身同等重要。

### 2.6 ASO 卡位（低成本、立刻能做）

- 〔行动〕App Store 名称/副标题/关键词覆盖：**台球、台球训练、中式八球、九球、走位、解球、台球教学、瞄球**。
- 〔来源·2026 新洞察〕**苹果已用 OCR 识别截图内文字**——所以**截图必须配带关键词的文字说明**（如"反解走位 / 翻袋瞄准 / 拍照建球形"），而非"好用"等空词。
- 品牌词唯一且好搜（"球迹"），让所有内容的"自己去搜"都能精准命中。
- 把 **App Store 搜索量 + 抖音/小红书品牌词搜索量** 当作"内容是否有效"的代理指标。

### 2.7 发布节奏

- 冷启动期：**主攻 1–2 平台**（建议抖音+小红书），不要一上来铺全矩阵分散精力。
- 频率：抖音隔日更起、小红书每周 3 图文 + 2 视频〔行业基准节奏〕。
- 每 2 周复盘：哪个选题/钩子带来最多**品牌搜索与下载**（不是点赞），**对跑出来的选题 double down**。

## 3. 第二引擎：场馆 / 线下地推（台球独有，竞品做不到）

线上 App 罕有「目标用户在物理空间高密度聚集」的场景，台球有——这是必须吃下的独有红利。行业 2025 已进入**存量竞争**，门店痛点是「盈利模式单一/数字化转型滞后」〔来源：艾媒 2026〕，正是异业合作的切口。

| 打法 | 具体动作 | 为什么有效 |
|---|---|---|
| **连锁/无人自助合作** | 找小铁、谈小娱、球小牛等连锁谈**异业合作**：扫码用 App 看球形/送 Pro 体验。 | 一次谈成覆盖上千门店；他们也需要「增值内容」差异化。 |
| **桌边二维码物料** | 台尼角贴/桌边立牌："**遇到不会打的球？扫码拍张照，App 算给你看**"。 | 直接落在 F17 拍照建球形的**最佳使用场景**，转化意图最高。 |
| **店内赛事赞助** | 给门店周末赛/月赛提供 Pro 兑换码作奖品 + 现场展示。 | 借赛事流量（2026 赛事 IP 是核心驱动力），低成本曝光。 |
| **教练入驻/分成** | 本地教练用 App 给学员布置训练、复盘，App 成为教学工具。 | 教练把用户"带"进来，且强化"练脑型课前预习/课后复盘"定位。 |
| **行业展会 B 端对接** | 2026 第 20 届世界台球展（5 月·广州）：俱乐部运营系统/AI 方案集中地。 | 一站式对接连锁/投资方，也为 §7 的 B 端授权铺路。 |

〔行动·冷启动〕先不铺全国，**选创始人所在城市 3 家门店做试点**，跑通"物料→扫码→激活"转化率，再决定是否复制/谈连锁总部。

## 4. 第三引擎：私域沉淀与联名

- **微信社群**：把各平台来的"想涨球"用户沉淀进训练打卡群，用「训练记录（记）」做黏合；群内出题/答疑，复购与口碑发酵地。
- **品牌词心智**：所有渠道统一口径"想涨球就用球迹"，让品牌搜索量成为长期下载来源（第一杠杆的复利）。
- **教练/器材联名**：与球杆品牌、教练 IP 联名礼包（买杆送 Pro / 课程配套 App），互相导流。

## 5. 转化链路工程化（view → download → aha → retain → pay）

获客只解决"进来"，命门的另一半是**别让进来的人漏光**。逐级堵漏：

| 环节 | 漏点 | 对策 |
|---|---|---|
| 播放 → 主页/搜索 | 看完不行动 | 每条内容明确 CTA + 好记品牌名 + 置顶引导（§2.5/2.6） |
| 搜索 → 下载 | 商店页没说服力 | ASO 截图带关键词文字 + 首图演示拍照建球形/上帝视角（§2.6） |
| 下载 → 激活(啊哈时刻) | 打开不知道干嘛 | 〔行动·已在 `docs/04` Backlog〕**首启「啊哈」流程：拍照建球形 → 让用户先自己判断走位 → 引擎给正解对比 → 第一个"原来如此"的小胜**。这是把"练脑型"定位落到第一分钟。 |
| 激活 → 留存 | 练完即走 | 训练记录/日历/连续打卡 + 每周新内容推送召回 |
| 留存 → 付费 | 不愿掏钱 | 7 天试用 + 在"反解器/统计"等高价值功能处自然触发付费墙；定价可上探（营收测算 §5.5：年订阅不到用户台球年开销 1%） |

> 〔强约束〕**首启啊哈流程 + ASO + CTA 链路应在大规模投内容前先就位**——否则花力气引来的流量在最浅的漏斗就漏掉，等于给漏桶加水。

## 6. 冷启动 90 天最小可执行计划

按"先把漏桶补好，再开水龙头"排序。假设执行方为 1 人或 2–3 人微团队。

### 阶段一（第 0–2 周）：补漏桶 + 备弹药
- [ ] ASO 卡位：改名/副标题/关键词/截图（带文字）上线。
- [ ] App 内首启"啊哈"流程上线（拍照→你先判断→引擎正解对比）。
- [ ] 用渲染管线**预产 40 条内容底料**（覆盖 §2.2 各栏目）。
- [ ] 注册抖音+小红书+视频号官方号，统一品牌词"球迹"。
- [ ] 上线**落地页/问卷/课程预售**——**最小成本验证付费意愿**（营收测算 §8 最该先验的假设）。

### 阶段二（第 3–8 周）：开水龙头 + 找杠杆
- [ ] 抖音隔日更 + 小红书每周 5 条，跑选题 A/B。
- [ ] 启动「拍照解球」评论区互动栏目（UGC 钩子）。
- [ ] 谈 **3–5 个腰部博主**：免费 Pro + 出片外挂，试 B2B2C。
- [ ] 本地 **3 家门店**桌边二维码试点，测"扫码→激活"率。

### 阶段三（第 9–12 周）：复盘 + double down
- [ ] 找出带来最多**激活/品牌搜索**的选题与渠道，集中资源。

## 7. 指标体系与止损 / 验证 gate

**北极星指标**：**周新增激活用户**（不是播放量、不是下载量——激活才代表真触达到对的人并跑通了链路）。

**漏斗监控**（逐周看转化率，定位漏在哪一级）：
播放 → 主页点击率 → 品牌搜索量 → 下载 → 次日/7 日留存 → 试用 → 付费。

**三道验证 gate（呼应营收测算"先验证最软假设"）**：

| Gate | 验证什么 | 通过线（〔假设〕初设，按实况校准） | 不过怎么办 |
|---|---|---|---|
| **G1 内容有效性** | 单位内容能否稳定带激活/品牌搜索 | 连续 4 周周激活环比增长，且非靠单条爆款 | 换选题/换钩子/换平台；考虑加大真人 IP 比重 |
| **G2 留存** | 训练类是否"练完即走" | 7 日留存 ≥ 15%、MAU/下载 ≥ 8% | 强化打卡/内容召回/啊哈流程；留存太差则商业模型重写 |
| **G3 付费意愿** | 模型 B 是否成立 | 试用→付费 ≥ 10%、或预售验证有真实掏钱 | 调定价/价值点/付费墙位置；持续不过则下修预期、慎投 Android |

> G2、G3 是营收测算里**最软的两条假设**，也是 iOS 阶段存在的全部意义：**用最便宜的方式证实/证伪它们**。证实 → 才值得重投用户教育、IP 与 Android；证伪 → 省下跨端的大钱。

|---|---|---|

## 9. 诚实风险与「不做什么」

- **慢**：内容获客 3–6 个月才见稳定增长〔行业共识〕；预期管理好，别因为前 8 周不爆就放弃。
- **几条爆款 ≠ 生意**：营收测算 §6.5 已算清，单批病毒视频只够把你从悲观推到保守档；要的是"经营一条内容线"。
- **破圈与定位的张力**：千万下载须吃大量休闲玩家，与"练脑型严肃训练"定位冲突（营收测算 §5.6）——**iOS 阶段先服务核心人群把单位经济跑正，不要过早为流量稀释定位**。
- **不做**：付费投放（必亏）；一上来铺全平台矩阵（分散）；为了流量做社交广场/对战（分散训练专注，`docs/04` §6）；在 G2/G3 未验证前重投 Android。

## 9.5 创意升级：从「发内容」到「造增长回路」（重点）

> 自我修正：§2–§4 是**线性广播**（拍一条、曝光一次、即衰减，且谁都能抄）。本节是**增长回路**——每个机制自带「用户用 → 产生新内容/新触点 → 拉来新用户 → 又来用」的闭环，复利增长。共同内核：**把你独占的「台球真相神谕机」（1 秒算出任意球形客观最优解并渲染）武器化**。这是博主和竞品**结构上做不到**的事。

### 回路 1 · 「球形 Wordle」每日球局（旗舰，最该先做）

- **机制**：球形生成器（F16）每天**全网同一局**，所有人预测「最佳清台顺序/走位路线」，引擎当场评分，生成 **emoji 战绩格**一键分享（仿 Wordle）。
- **为什么是回路 / 为什么新颖**：①Wordle 式「同一题 + 战绩分享 + 每日一次」是被验证过的**零成本病毒循环**，台球圈**还没人做**；②**只有你能做**——需要「无限生成公平球形 + 客观验证答案」，这正是引擎独占能力，博主手工出题既慢又无法验证；③同时解决留存（每日习惯）+ 拉新（战绩格自带传播）+ 内容（无限题库零边际成本）。
- **复用功能**：F16 球形生成器（出题）+ F14 反解器（标准答案与评分）+ 渲染管线（战绩可视化）。
- **加杠杆**：每周「炸清挑战」榜单、城市/球房分榜、连续打卡段位——把单机题变成社交攀比。

### 回路 2 · 「球桌判官」争议裁决（冲突驱动，传播力最猛）

- **机制**：球房里永恒的争论——「这球到底有没有解 / 我那杆该打进的 / 我会做斯诺克」。拍张照（F17）→ 引擎给**客观判决 + 最优解演示**：「此局有解，最优走位如图；你的选择胜率 38%，最优 71%」。
- **为什么是回路 / 为什么新颖**：**冲突是最强的分享燃料**。争论双方都想用判决「证明自己对」，于是双方都转发——一次争议 = 两次传播。传统教学内容是「我讲你听」（无传播动机），判官是「帮你赢得争论」（强传播动机）。台球是高频社交对抗场景，争议供给天然无限。
- **复用功能**：F17 拍照建球形 + F14/F15 反解器（判定有解/最优/胜率）+ 渲染（判决书视频）。
- **格式**：抖音/小红书「@球桌判官，发你的争议球」固定互动栏目；判决书做成统一模板（像「鹰眼回放 + 法官敲槌」），形成可识别 IP。

### 回路 3 · 「把野球拍成 CCTV 转播」业余鹰眼（虚荣驱动）

- **机制**：用户拍自己打球的片段/球形，App 叠加**广播级上帝视角图形**——轨迹、分离角、走位落区、胜率，像职业赛事转播/鹰眼。一键导出「转播版」。
- **为什么是回路 / 为什么新颖**：**虚荣是仅次于冲突的分享燃料**。人人想让自己的野球看起来像职业转播——这是**身份炫耀**，转发率远高于教学。台球转播图形观众极熟悉（蹭赛事视觉心智），但**给业余玩家做**的还没有。每条转发都带你的水印 → 自然获客。
- **复用功能**：F17 单应矩阵 + 渲染管线（已能出上帝视角/斜视角，把它产品化成「一键转播化」）。

### 回路 4 · 引擎成为「所有台球创作者的基建」（供给侧平台，反竞争）

- **机制**：不去和 KOL 抢流量，而是做**所有台球博主都想用的「上帝视角生成器」**——一个极轻的免费工具（独立小程序/网页/App 内导出），任何创作者一键把自己的球渲染成专业图形，**自动带你水印/署名**。
- **为什么是回路 / 为什么新颖**：这是**平台打法**而非「付费找博主」。像 Hawk-Eye/某些转场特效成了行业标配——一旦你成为台球内容的「默认可视化工具」，**全行业的内容都在帮你分发**，且越多人用越是标准（网络效应）。比 §2.4 的「博主外挂」更激进：把外挂做成**独立的免费引流钩子**，门槛降到零。
- **复用功能**：渲染管线 + F14/F16 + 拍照建球形，封装成「一个动作出片」的轻工具。

### 回路 5 · 「球商段位」认知型身份（身份驱动）

- **机制**：基于**决策质量**（不是进球率）给用户一个客观「球商指数/段位」——引擎评估你在各球形下的选择离最优有多远。可分享段位卡/徽章。
- **为什么是回路 / 为什么新颖**：台球只有「水平靠口说」，没有**客观、可炫耀的身份符号**（对比王者段位/Keep 勋章）。引擎能客观给「**脑子**」打分（呼应「练脑型」定位），这是独占的。段位 = 用户主动晒 = 身份驱动获客 + 强留存（升段动机）。
- **复用功能**：F14 反解器评分体系 + 角度测试 + 训练记录。

### 创意「借势」内容（蹭已有流量，非自造）

- **复盘爆款搞笑球**：2026「子涵大帝/全国青少年挑战赛」搞笑切片正火〔调研〕——做「**引擎复盘**：这神球是运气还是有解？」蹭现成流量 + 秀神谕能力。
- **职业赛事神球解析**：蹭 500 万总决赛/WST 流量，「丁俊晖这杆走位神在哪，引擎拆给你看」——时效 + 权威 + 独占视角。
- **个性化「差一点」**：用户发失误球 → 引擎生成「你差了 2°，这样加塞就进了」——个性化 + 情绪共鸣，转发率高。

### 线下新玩法（非传单地推）

- **球房「本周谜题桌」**：与球房合作设一张「挑战桌」摆好难球形，桌边码扫码进 App 解谜，引擎验证，胜者送台费——把球房**游戏化**成线下入口，店家得活动、你得精准用户。

### 优先级与诚实边界

| 机制 | 杠杆 | 建议 |
|---|---|---|
| 回路 1 球形 Wordle | 高（习惯+病毒+零成本内容） | **第一个做**，MVP 最轻 |
| 回路 2 球桌判官 | 高（冲突传播最猛） | 与回路 1 并行，做成固定互动 IP |
| 回路 3 业余鹰眼 | 中高（虚荣传播 + 水印获客） | 把现有渲染产品化即可，性价比高 |
| 回路 4 创作者基建 | 高但慢（平台网络效应） | 中期押注，需把工具做到极轻 |
| 回路 5 球商段位 | 中（留存>拉新） | 评分体系成熟后做 |

- **诚实**：①「创意」不等于「保成」——每个回路都需小成本 A/B 验证「分享率/拉新」，跑不动就砍，别恋战；②回路 1/2/3 是**纯软件、复用已有功能**，工程量小、最该先试；③回路 4 是平台赌注，慢且重；④涉及「胜率/对赌」措辞要避开**赌博合规**红线（只做「友谊挑战/训练」框架，不碰真金对赌）；⑤这些回路是「触达」的乘数，**仍要叠加 §5 转化链路与 §7 三道 gate**——回路把人引爆式带来，链路不漏、留存付费成立，量级才真正成立。
