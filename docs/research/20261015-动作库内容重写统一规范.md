# 动作库内容重写统一规范

> 版本：v1.6 · 2026-10-16。汇总用户要求、调研结论、R5认可及全角色执行上下文约定。
> **这是本轮重写的统一写作入口。主控、作者和审稿者每轮都要先读全文。** 后续反馈优先更新此文，不再分散新增同级规则。
> 批次、清单、授权范围及验收状态见[执行方案](../../tasks/DRILL-COPY-REWRITE-20261015.md)。本规范不代表样稿已获认可，也不构成扩库或发布授权。

## 1. 目标、范围与优先级

重写首先教会学员：什么球形适合什么打法和力度，为什么这样打，能实现什么进球与走位目的。观察与纠错是辅助，不能让逐杆示范变成让学员自行试参数的说明。专业来自事实准确和讲解具体，不来自术语数量；自然来自台球教学的表达习惯，不来自随意换称呼。

覆盖动作介绍、训练要点、训练要求，以及每个球形的精讲、逐杆图注和教学参数。2026-10-16用户已认可c011／c035／c042的R5样稿标准，并授权按此修改全库动作和球形。作者仍先在隔离候选写作，交叉审和主控验收后串行集成；新稿不自动算用户已逐篇验收。

遵循以下边界：

- 当前用户指令优先；本规范汇总当前写作约定，优先于冲突的旧样板、旧技能示例和调研建议。
- 用户训练意图决定为什么练；当前录制、配图、可核验的分析决定示范发生了什么。两者不能互相代替。用户原始意图记录不改，完善列只作辅助。
- 内容数据契约决定资产归属、标识符、训练数量和数据流；当前代码与经验证的理论约束物理含义。本规范不改这些契约。
- 历史正文、旧参数、旧 profile、课程地图和概念所有权表只能帮助理解，不能证明最新球形事实。冲突须定位，不为迁就旧文字编造解释。
- 保护原序列的 before／after、最终方向、力度、打点、analysis，保护物理、瞄准、回放、图片像素、稳定 ID、球形与杆序映射、animation、shotIntent、训练配置及计分语义。
- 课名默认保留。确实误导训练对象时提出改名建议，不顺带重命名。理论页、独立功能入口卡、计划编排、视频不自动纳入本轮。
- 样稿在隔离副本写作。修改正式资源、安装、OTA、提交、发布分别以对应授权和验证为准。

## 2. 动笔前必须知道什么

每个动作先建立一份内部证据卡，至少包含：

1. 当前动作路径、球形映射、序列与图片版本、原文备份及哈希。
2. 用户原始训练意图、本动作与相邻动作的区别、课程关系；缺失或冲突明确标注。
3. 分别确认录制组织方式（独立重摆／连续接打）与教学关系（并列情况／递进／对照／连续衔接）。二者不是同一分类；不能由 repetition 推断不需要给下一颗走位。
4. 每杆目标球、目标袋、打点、杆速、瞄准角、母球路线与停位；凡有走位目的，都须核对下一颗、预期袋口及需要的角度，包括只录了首杆的独立示范。
5. 图中各球的作用：本杆目标、后续目标、障碍球还是目标区域参照球。
6. 现有训练数量、技术成功条件、计分及换位逻辑，避免文字重写暗中改了练习。

先运行文案上下文清单与事实提取工具，再**实际查看每张开局图和每杆配图**。列出图片路径、读取元数据不算读图。检查图和序列是否同一版本、球号与袋口是否对应、画面是否健康。图片用于理解画面和核实对应关系，不用于目测角度、距离或编造轨迹事实。

需要的几何与物理事实来自当前序列、经验证脚本及回放证据。没有资料就不写确定断言；局部缺失暂停对应动作或判断，继续其他已授权且不依赖它的工作。不得擅自修序列、重出图片来迁就文案。

动笔前用一句内部话明确“改变什么、主要检验什么能力、观察什么结果”。不要把这句分析话直接搬到学员页面，也不要凭摆法推断用户没表达的设计意图。

## 3. 各字段各负其责

| 字段 | 应承担的内容 | 应避免的内容 |
|---|---|---|
| 动作名称／标题 | 清楚标识训练对象；节标题对应球形和杆序 | 塞入所有变量，擅自改名或重排杆序 |
| description | 一至两句讲清任务和主要训练价值，与相邻动作有区别 | 参数堆砌、训练数量、摆球坐标、长操作清单 |
| coachingPoints | 能立即执行的动作、观察或调整；第一条脱离详情页也能用于试打／计划 | 几条换词重复，“注意稳定”“提高水平”等空话 |
| standardCriteria | 可观察的技术完成条件，忠实表达真实训练目标 | 新增次数、成功率、误差容限，悄悄改变现有通过判定 |
| 球形精讲 | 这一形怎么打、关键判断、走位目的、失误后如何调整 | 套用全库通用段落，完整复述 HUD 或逐点描图 |
| 逐杆 params | 对应 shot 的 spinX、spinY、velocity 原值 | 沿用旧文本数值，用碰前母球速度代替录制杆速 |
| caption | 杆序和必要的瞄准角，简短且名称明确 | 实际切角、长小数、重复参数栏与正文 |

信息覆盖不等于固定排版。保留可解码的数据结构、每杆节、图片和参数关联；正文可自然成段，不强制每杆都写“为什么／怎么打／自检”三个标签。只有教学信息确实重复的示范才可以少写；独立首杆如果对应不同角度和打法，就必须讲清各自适用情况及走下一颗的目的。

### 先理解教学关系，再组织逐杆讲解

| 教学关系 | 重点讲什么 | 不应写成什么 |
|---|---|---|
| 并列的不同情况 | 这类球形的进球与走位目标，适用杆法、力度及选择原因 | 上一杆不行，再换一种打点试试 |
| 单一变量递进 | 角度、距离或塞量如何逐步变化，难点和打法怎样随之变化 | 八段互不相关的通用提醒，或没有事实支持的“越来越难” |
| 对照示范 | 左右塞、高低杆、不同路线的适用区别与结果差异 | 只抄参数差别；多个变量变化却说成单变量因果 |
| 连续衔接 | 本杆为下一颗留什么位置和角度，下一颗怎样继续叫位 | 只讲本杆进球或最终停点，不交代后续目的 |

关系可以在同一球形内分组并存。先列清固定项、变化项、各示范共同目标和各自教学判断，再动笔。单变量递进要核实其他关键条件是否确实相同；正反角变化不等于角度绝对值一直增大，不看顺序就编递进。

逐杆主体应先讲清示范方案：球形条件 → 杆法和力度 → 母球路线／停位 → 进球及后续走位目的。不是固定四段模板，而是信息完整性要求。“先试打、再调整、偏了查打点”不能代替这些内容；排错集中在常见错误区，必要时才补一条本杆特有提醒。实测示范存在未达目标的地方仍须如实区分，不能把教学方案写成已达标保证。

概念课可解释必要原理，后续课只补新的判断，综合课围绕实际任务展开；不要每课都重讲完整基础理论，也不强行指定没有依据的“最难一杆”。

## 4. 统一术语：自然，但不随意

| 所指对象或过程 | 学员文案统一写法 | 不用于交替替换 |
|---|---|---|
| 承担击球与走位的球 | 母球 | 白球、本球、小白 |
| 本杆要击打的球 | 目标球；明确时直接写球号，如 2 号球 | 含糊的“那颗球”，随意改称彩球 |
| 与库边接触的动作 | 吃库、吃一库、吃两库 | 碰一下边、撞边、弹一下 |
| 接触库边的位置 | 吃库点 | 弹的地方、碰的位置 |
| 球的行进路径 | 路线、母球路线、母球吃库后的路线 | 弹出的线、想走的线、换条线 |
| 吃库后运动朝向 | 母球吃库后的方向 | 不交代主体与阶段的“弹出来往哪边” |
| 最终位置及目标范围 | 停位、停球区域、目标区域 | 单独用舒服、顺手、差不多代替目标 |

- 统一称呼是本产品的编辑约定，不是宣称其他教练说“白球”不专业。语音词表里的别名用于理解输入，不自动成为正文同义词。
- “瞄准线”“进球线”有专门含义，不改成“路线”；禁止全局替换所有“线”。
- 母球跟进、目标球进袋、球杆延伸是不同动作，不能混淆主体。球号已经清楚时不必反复写“目标球 2 号球”。
- 球的角色须有意图依据，不能仅因未录下一杆就认定为标记球。高杆一库走位的 8 号球已由用户明确为下一颗进攻球，旧稿“区域标记”判断作废；其他球形真正的标记球仍按其实际用途解释。
- 母球起点标记与目标球分开：有些编号球只标记后续各杆母球的摆放位置，逐杆换母球到该位置。仅在前面几个基础动作讲清约定，后续保留必要的摆位指令，不重复“不是目标球”等说明。只有母球直接进袋或吃库的练习，直接描述母球任务，不凭空引入“不要先碰目标球”。不能因此把实际下一颗进攻球删成标记。
- “挤偏”“弧线”“投掷”“让点”各有含义，不混为一谈；有必要时才解释，不在每课堆概念。
- “回撤”不用于描述母球低杆效果。按事实写“低杆让母球往回拉”等；球杆后摆另当别论。
- 击球后的姿势提示用“别急着起身”。“抬头”和“起身”不是同一动作，不能用“别急着抬头”代替保持击球姿势的要求。

## 5. 杆法讲准确，发力不凭空推断

写作时分清四层：**打点在哪里、怎样出杆、碰球时母球处于什么状态、最终出现什么结果**。这四层有关联，但不能直接画等号。

- 高杆／中杆／低杆、左塞／右塞是打点层；推、点、打、搓、顿等包含发力或出杆习惯。不同教练的词义并不完全一致，不强建一套统一动作分类。
- 录制数据没有记录人体出杆过程，不能单凭杆速或打点断言“这一杆必须推／点／搓”。有教学必要且有依据才写发力提示；不用术语替代说明。
- 可以用“低杆往回拉”“小力低杆一点”等自然说法，但必须符合本杆事实；“中杆斯登”不能作为所有中心打点的通称。
- 中杆不自动等于斯登或定杆；低杆出发也不保证碰球时仍有足够倒转。滑动状态本身不等于斯登，不能只见 sliding 标签就下结论。
- 杆速与碰前速度不是一个量。侧塞的浮点微小非零值不自动代表有意加塞；没有确认阈值和意图，不硬贴杆法标签。
- 左右塞与顺反塞不是同一分类。顺反塞需针对具体吃库过程判断，不写“左塞一定是顺塞”。
- 不把球杆离开母球后的延伸说成持续给母球加力。不要为了讲“送杆”写出错误因果。
- 一次示范只能证明这一杆出现了什么；多项输入同时改变时，不能断言路线变化全由某一项造成。

调研仍需辨别来源：可核实的一手正文用于支持说法，课程标题只证明有该话题，自动字幕需校对；未看过的视频不声称已经观看。英文物理资料可约束因果，不能单独证明中文球房的惯用表达。用户举例用于拓宽理解，不是限定词库。

## 6. 走位必须讲具体，不能由录制方式删掉教学目的

凡有走位目的的示范，都需要让学员理解：本杆哪颗球打哪个袋，母球走什么路线、停在哪里，下一颗打哪个袋，以及为什么要留这个位置或角度。即使只录第一杆，也不能漏掉预期接打目的。可分散在标题、正文和上下文中自然表达，不要求每句话重复全部内容。

- 先核对真实目标、吃库顺序和停位，再写走位目的。袋口、库边、半台等空间方位必须与当前文字对应的实际页面球桌一致：动作详情以横向2D球桌为准，精讲以相邻竖版配图为准，试打以该页面实际2D朝向为准。3D采用该页面固定2D参考，不随相机绕台旋转改名。不能把精讲竖图用词直接原样复用到横桌详情。
- 第一条训练要点在试打复用时，保留同一物理袋口及路线的身份，按接收页面朝向呈现；同时核介绍、其余要点、训练要求及训练记录/计划消费者。空间映射不得改左塞、右塞、高低杆、左右塞对照或相对于球/进球线的左右关系。任何转换须有明确语义范围，禁止全局替换“左/右/上/下”。
- 使用已核对的“左上角袋”“左侧中袋”等明确称呼，不用未经映射的“那边的袋”。当前竖版图的屏幕上方／右方对应关系须由渲染契约核验，不能套用普通平面图习惯。
- 不只写“给下一颗留舒服位置”。应说明下一颗及袋口，并交代需要的角度、路线或避免的障碍；没有依据就不补具体方位或距离。
- “不重复图片”限制的是无意义描图，**不禁止解释母球路线与下一杆的关系**。学员需要知道走位目的，即使图里已经画了路线，也要讲清。
- 独立练习的下一条 step 是另一个开局，不能当作本杆接续事实；但当前球形中仍可有明确的下一颗球。没有录制下一杆，不能据此把这颗球降为无进攻意义的“参照球”。先查训练意图、当前球形和母球 after，再确认后续袋口。真正纯定位标记球仍不编进袋任务。
- 初级蛇彩球形1：用户已明确八种首杆**全部是打进1号、给2号走位**。2号是下一颗进攻球，3号是评估后续衔接的球；R4“2、3号只作参照、不接着打”属于错误教学解释，后续不得沿用。每杆要讲不同角度下适用的杆法、力度、2号预期袋口及留位用途。
- 高杆一库走位：用户已明确 **8号是下一颗要打的球**，目标是给8号留下角度适中（约15°）、距离合适的位置。每杆核对母球after、8号预期袋口、角度和距离；不能称8号为停位标记，也不能把“母球未停到8号旁边”判为失败。约15°是教学目标参考，不是全部示范的实测值或新增合格阈值。
- 评估下一颗时，同时考虑进球难度和继续走位条件。用户提出约25°以内是常见的适当角度参考：有利于兼顾进球与叫下一颗；不是硬性合格线，也不是越直越好。还须看球距、袋口入射、障碍、母球贴库及需要向哪一侧走位。
- 下一颗袋口不能只按“距离最近”或“有一个袋能进”选择。要从当前 after 核对母球至假想球、目标球进袋路线是否通畅，并考虑打完下一颗怎样叫再下一颗。几何可打与课程预期需分别标注；缺证据时报告待核，不写成纯参照来回避问题。
- 不把保存的单个停点包装成唯一正确位置，不凭空规定几厘米容限、完美角度或必须停在某颗球宽内。
- 走位偏差要区分吃库点、吃库后路线与沿路线的远近，按证据说明调整方向。不笼统说“再追一点位置”。

## 7. 角度、analysis 和参数的使用边界

**本杆展示角度统一为瞄准角，来源是 `analysis.aim.aimAngleDegrees`。** 它遵循用户定义：进球线与母球中心指向假想球中心的瞄准线之间的夹角；假想球位置由引擎进球线反向延伸确定。写作层读取经过核验的值，不另造几何算法。

- 实际接触切球角留作内部核对，不进入本轮精讲正文、图注或参数提示。不得拿旧 digest 的球心夹角换个标签继续用。
- 图注明确写“瞄准角约 30.4°”，统一采用一位小数的当前展示约定；证据保留原精度。无教学必要不在正文反复报度数。
- 有效 0° 与缺失、无效值不同。自由瞄准缺少有效进球线时省略角度，不用 0、袋心夹角或实际切角补位。
- “分离角 90 度规则”等理论名、课名不是本杆实测瞄准角，不改名、不偷换概念。本轮不新增逐杆分离角指标。
- analysis 默认服务内部事实核对。只有能帮助学员决定怎么打、看什么或怎样调整的信息，才转成简短自然语言。
- 不新增物理指标区，不展示引擎版本、事件时间、速度向量、角速度、滚动比例和精确行程清单。不能用更多数字掩盖讲解不足。
- 每杆教学 params 与当前 shot 的 spinX／spinY／velocity 精确一致，不通过文字描述反推参数，不修改录制数据。

## 8. 训练数量由训练设置管理

- 介绍、要点和精讲不重复次数、组数、时长，不另设“每个位置连进 3 球，再换下一个”等门槛。即使旧文案有，也不照抄。
- 删除这类句子后，不补“按要求多练几遍”之类空话；精讲继续讲技术、观察与调整。
- 训练要求优先表达目标球进指定袋、母球留台、停入目标区域或能接打下一颗等真实技术条件。
- 旧 standardCriteria 的次数型条件要核对：是重复训练量，还是实际成功判定？不能借删除冗余文字擅自取消真实判定，也不修改 sets、计分、切换或结束逻辑。
- 区分球形结构与训练剂量。“五杆连续”“八个独立位置”“第 1–3 杆为一组示范”可解释材料；“练五组”“连进三球才换位”属于训练数量或流程。不能全局删数字。

### c065 单人练习的用户裁定（2026-10-16）

用户明确选择原始意图：按正常中式八球规则，一个人轮流扮演双方，失误后换边继续。删除旧文案“一次失误就结束”“幽灵永不失误”和“10局赢3局”等幽灵胜负门槛，训练要求改为忠实执行双方规则及观察、纠正自身问题。合法进球后的续击、犯规后的球权按正常规则处理，不把所有换边都写成自由球。课名默认保留，训练配置、计分实现和其他受保护字段不随正文裁定改动；原始意图表只读。这项裁定仅重开c065相关判断，不撤销其他已核定动作的验收。

## 9. 自然度与诊断：逐句检查，不做同义词润色

- 用清楚的主语和台球教学动词，把做法、观察、目的连起来。少用“变量、机制、容差、结果主要反映”等内部分析话。
- 不堆“本组用于”“这样设计是为了”“最后一杆检验”等课程设计说明；理由只有会影响学员做法时才保留。
- 不把自然误解为随意：删“其实、简单来说、你只需要”等填充句，也不使用“弹出的线”等生造搭配。
- 错误与纠正要有具体观察，并考虑多个可能原因。不要把“擦袋口”直接等同于打厚，把“停远”直接等同于打薄。
- 原因不唯一时，写有顺序的排查建议，不装作已确定唯一原因。无依据不加“只要”“一定”“必然”。
- 连读同组内容：遮住标题仍可互换的段落，说明缺少本课价值；连续机械同构的句子须重写。朗读后学员仍不知道怎么做，也须重写。
- 正文不出现 manual、digest、profile、内部理论编号、引擎版本、录制修复史或“本次用户修改”等工作流信息。

| 问题表达 | 编辑方向（不是可直接批量套用的句子） |
|---|---|
| 每个位置连进 3 球，再换下一个。 | 删除这条数量／流程指令，不补另一条。 |
| 看白球弹出的线能不能经过想停的位置。 | 看母球吃库后的路线是否经过目标区域。 |
| 白球每次都碰在不同地方。 | 母球每次的吃库点都不一致。 |
| 先把想走的线选好。 | 先确定母球路线和目标停球区域。 |
| 换条线去找 8 号。 | 先核8号的角色；在高杆一库走位中，说明母球吃库后的停位怎样给8号留下目标袋口、适当角度和距离。 |
| 给下一颗留舒服的位置。 | 根据已核事实说明下一颗、目标袋和留位目的。 |

例子只说明编辑方法。写入具体杆时仍须核对序列和图片，不能借修改措辞新增事实。

### 10.2 子智能体分工

- 用户已要求并行写作并使用当前模型：作者继承当前会话模型，不自行换其他模型；最多三个执行者同时写作。
- 一个完整动作的所有字段、所有球形由一个作者负责，避免不同人拆句后语义不一致。主控统一事实包和本规范版本。
- 使用独立 worktree 或已明确的不相交候选路径；正式主树不作样稿写回目标，作者不互相覆盖。
- 作者交付完整候选稿、事实依据、逐图检查记录、自查和文件哈希；三位作者交叉审读，主控独立读全文并核事实，不能只接受自报通过。
- 问题回到对应作者修订，主控串行收稿核验。三稿获用户认可后，才按执行方案推进已授权的下一阶段。
- 每次派发包含规范绝对路径/版本/SHA、事实源根与候选路径、目标动作、可改字段、保护对象、共同与专属必读清单、用户关键追加要求和分层验收。派发者不能替接收者预填“已读”；作者实际读取后报告章节范围、用途和缺口。
- 工具输出被截断、只列出路径、技能正文只剩“以前读过”摘要，均不算当前读取完成。按需补读；不能把所有无关历史材料塞入上下文，也不能因此省掉直接影响判断的原始资料。
- 作者与主控先分别形成教学判断，审稿者先读原始依据再审作者结论。读取记录、文件哈希只能证明范围和版本；教学理解须用本球形和逐杆用途证明。无证据的主控结论也应被质疑。

### 10.3 每稿验收清单

- [ ] 用户训练意图未被旧文本、研究建议或作者猜测覆盖；不同球形与相邻动作有实际区分。

- [ ] 所有有走位目的的杆（含独立首杆）说明下一颗、预期袋口和留角用途；未把进攻目标误降为参照球，未把最近袋直接当预期袋。
- [ ] 单变量递进有证据，左右塞／高低杆对照讲清适用差异；约25°参考未写成硬门槛或越直越好。
- [ ] 母球／目标球／吃库／吃库点／路线／停位用词统一；瞄准线与进球线保留技术含义。
- [ ] 打点、发力、碰球状态和结果未混淆，没有仅凭杆速命名人体动作或用单次示范证明单一因果。
- [ ] analysis 克制；逐杆数值角度只取有效瞄准角，零值与缺失分开；params 逐杆精确一致。
- [ ] 没有新增训练剂量、换位门槛、虚构容限；技术判定和训练配置保持原义。
- [ ] 句子自然、具体、可执行；没有模板标签、工作流词、无用描图或含糊走位结论。
- [ ] 允许字段之外无变更，序列／图片／物理／瞄准／回放及训练数据保护检查通过。
- [ ] JSON 可解码，结构、ID、球形、逐杆节、图片引用及参数映射正确；文案与精讲专用门禁通过。
- [ ] 主控与交叉审稿均针对最终候选哈希；修改后更新受影响的检查，不能拿旧稿报告验收。
