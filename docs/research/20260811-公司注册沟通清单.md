## 一、要讲清的背景

- [ ] App 快完成，要上中国大陆 App Store 并收会员费，必须以公司名义做，个人身份走不通
- [ ] 国内 App Store 上架必须有 App 备案号，备案实操不接受个人主体做带内购的 App
- [ ] 备案主体、域名、云服务器、开发者账号，四个名字必须完全一致；先用个人身份办，将来切公司要逐个迁，App 迁主体后还要重新备案
- [ ] 商标和软件著作权都要以公司名义申请，公司不落地这两件开不了工
- [ ] 顺序：公司先落地 → 才能办商标/软著/备案 → 才能上架；最慢的是备案（5–20 个工作日，不可控）
- [ ] 我要请对方承担的是工商财税这一段，技术和产品我自己做

## 二、前置：先说明今晚不开工

## 三、请对方负责的事（按顺序）

- [ ] 1. 公司名称预先核准（我给 3–5 个备选字号）
- [ ] 2. 公司注册：章程、股东决定、经营范围、注册资本（参数我书面给）
- [ ] 3. 刻章：公章、财务章、法人章、发票章
- [ ] 4. 税务报到：核定税种、领发票、签银税三方协议（要等我去银行开完对公户）
- [ ] 5. 商标申请：找代理、提交、跟进补正与驳回复审（全程 9–12 个月）
- [ ] 6. 软著提交：材料我出，对方提交并跟进（下证 3–4 个月）
- [ ] 7. 邓白氏编码（D-U-N-S）申请：苹果开发者组织账号要用，公司一下来就能办
- [ ] 8. 长期：代理记账、月度报税、工商年报、发票管理

补充提醒：

- [ ] 零收入也要零申报，漏报会进经营异常名录；工商年报逾期同样进异常
- [ ] 商标和软著是长周期事项，中途可能有补正通知，需要持续跟进

- [ ] 要求代理先做专业近似检索，重点是 9 类和 41 类下证概率；商品项目清单要给我过目，不要默认勾选

## 五、注册参数的三条红线（口头强调，参数表书面发）

- [ ] 法定代表人必须是我，不能挂对方名字
  - 理由（讲出来）：法代承担对外代表责任，公司被列失信被执行人时法代本人被限制高消费，行政处罚也追到法代个人；让不实际经营的人挂法代对其不公平
- [ ] 「法定代表人手机号」必须填我的手机号，不要图省事填对方的
  - 后续电子营业执照、税务实名、人脸核验、银行短信全绑这个号；经办人一栏填对方
- [ ] 注册资本按我给的数字写，不要「看着大气一点」往上加
  - 理由：新《公司法》要求认缴出资自成立之日起 5 年内缴足，写多少就是 5 年内要真掏的现金和对外责任上限；具体数字不在现场说，随参数表书面给
- [ ] 经营范围暂不写「第二类增值电信业务」（现在没证，写了会被要求补证；将来做一次变更即可）
