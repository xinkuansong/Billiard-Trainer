## 〇、审计口径（B5b 沿用）

### 0.1 坐标契约回显（geometry-spatial-reasoning 强制）

- Canvas 归一化 2D 系（真源 `.kiro/steering/table-geometry.md` + `content-engineering/SKILL.md` § 坐标系协议）：原点 = 台面左上角（顶视图），X∈[0,1] 左→右，Y∈[0,0.5] 上→下，单位 = 台面内沿长度 2.540 m 的百分比，2:1 台面。球半径 r = 0.01125（归一化）。
- 袋口中心：角袋 (∓0.0165, ∓0.0165) 系列；上中袋 (0.5, −0.0268)；下中袋 (0.5, +0.5268)。

### 0.2 几何量口径（沿用 B2 脚本口径）

- **切角**：给出两个口径，**结论以行进线切角为准**——
  - 行进线切角 = 白球→ghost ball 行进方向 与 进球线（目标球心→袋口中心）的夹角，ghost = target − 2r·normalize(pocket − target)；
  - 表观切角 = 白球心→目标球心连线 与 进球线的夹角（比行进线切角略小）。
- **入袋角** = 袋口→目标球方向与袋口台内轴向（中袋 = 垂直库边；角袋 = 45° 对角轴）的夹角，正入袋 = 0°。
- **距离**：归一化值 + 换算米值（×2.540）。**近库** = 球心距最近库边 < 0.06。
- 脚本金标准回归 `[事实]`：正对直球两切角均 0 + ghost 退距 = 2r；B2 样板 A5（45° 右切）复算 45.00°/41.92° 与 B2 输出一致；中袋正入袋 0°。

### 0.3 条目格式定义（每条 drill 一个条目，B5b 沿用）

1. **现状摘要** `[事实]`：JSON 实际内容（shotIntent 的 cue/target/pocket/spin/velocity、level/difficulty、subcategory、standardCriteria、sets、animation.source）+ 脚本计算几何量（切角、|CT| 白球→目标球距、目标球→袋口距、入袋角、近库标记）。
2. **变量档案反填**（B2 模板反向填写）：该 drill 隐含的固定变量 / 目标变量及应有档位 / 条件变量；当前球形实际覆盖了目标变量的哪些档位。
3. **覆盖缺口**：对照 B2 六要素与 B1 §八 映射表的对标基准项，缺什么档位、什么条件散布。
4. **结论**：三选一 + 优先级（见 0.4）。
5. **依据引用**：结论所依据的实际坐标/几何量数值（出自脚本输出）。
6. **B5b 口径补充**（脚本 2026-07-16 扩展，未改变既有几何口径，B5a 分类复跑经 diff 核实 37/38 条几何输出逐字一致，唯一差异为 c053——其 JSON 已被 B4 重构，见 §十一 存疑点 6）：① 现状摘要新增 **DrillBoards 已有球形数**（`QiuJi/Resources/DrillBoards/` 中该 drill 的序列文件数 + 逐杆 before 坐标几何量 + 母球 after 落点，多球形已存在的 drill 缺口相应减小）；② 多杆 shots 逐杆输出 + `obstacles` 障碍球坐标；③ positioning/forceControl 的审计除几何量外重点看 **spin/velocity 取值散布**（走位落点/力度档的实际覆盖）；④ combined 类侧重「序列是否真实存在（DrillBoards steps / 多杆 shots）还是只有单杆 shotIntent」。

### 0.4 结论口径（三选一 + 优先级）

| 结论 | 判据 |
|---|---|
| **保留** | 现有单球形作为该 drill 的合理示范/载体，无需多球形化。适用：① 姿势/动作类 drill——球形只是检验载体，训练变量在用户身体侧（握杆/站位/手架），单一标准直线球即合理；② 检验型/极限型单点测试——drill 定位本身就是「一个极限单点」（对标 BU 递进制的端点档）。 |
| **重构** | drill 自述或分类定位要求覆盖某目标变量（角度/距离/杆法幅度/方向），但现状是单点采样甚至几何与自述矛盾——需按 B2 变量覆盖方法重新设计多球形序列。 |
| **降级为示例** | 该 drill 本质是单一示范（且训练职责已由同主题的其他 drill 承担），明确其定位为「示例/自检」，不按训练序列重构。 |

- **优先级** = 分类核心度 × 缺口严重度：
  - **P1**：分类核心训练维度上的严重缺口（目标变量完全未覆盖 / 几何与训练目标直接矛盾 / 名实不符误导用户）；
  - **P2**：有明确缺口但现有球形方向正确，属「补档位」而非「推倒重来」；
  - **P3**：缺口轻微或该 drill 非分类核心，重构收益低。
- 姿势/动作类 drill（fundamentals 多数）不强行套变量覆盖，如实按其性质给结论（任务书约定）。

## 十、重构批次建议表（全库 72 条汇总，方案 v2 的 B6+ 输入）

> 聚合口径：**同分类 + 同承载方式 + 优先级**。全库重构项 59 条（B5a 30 + B5b 29，其中 c053 已由 B4 落地、在 R1 中作范式引用）+ 缺失新增 5 条 + 降级/对齐动作 2 条，聚合为 11 个执行批。
> **承载方式三类**（按 B3 决策候选 A：DrillBoards 序列 + `tutorial.formations` + sidecar 变量档案）：
> - **承载Ⅰ 静态多球形**：坐标可按 B2 方法脚本推导，示范击球仍须编排台人工录制（红线 1）——设计自动化、录制人工；
