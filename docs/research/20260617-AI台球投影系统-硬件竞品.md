# 调研：中国 AI 台球投影系统（硬件 / 门店赛道）

**日期**：2026-06-17
**目的**：摸清国内"AI 台球投影系统"格局，判断其与本产品（QiuJi，移动端几何/瞄准训练 App）的关系、可借鉴点与差异化空间。
**与既有竞品文档的关系**：`docs/03-竞品分析.md` 与 `docs/research/20260323-竞品分析-台球训练App.md` 覆盖的是**移动端训练/游戏 App**；本文覆盖的是**线下硬件投影系统（顶置摄像头 + 投影仪）**，属于不同赛道，互为补充。

> ⚠️ **资料可信度提示**：本文信息主要来自厂商官网、招商通稿、行业媒体报道与专利文本。其中**门店数量、"毫米级精度"、"职业级准度"、"遥遥领先"等多为营销/招商口径**，未经独立实测验证。下文对每条结论标注了来源性质（〔事实/可核实〕〔通稿口径〕〔推测〕）。本文不构成对任何品牌的背书或商业建议。

---

## 0. TL;DR（一句话结论）

国内"AI 台球投影系统"主要是**面向门店（To B）的重资产硬件方案**：顶置高帧率摄像头识别球位 + 高流明投影仪把瞄准线/轨迹直接打在台呢上。它们与 QiuJi（轻量、To C、随时随地的移动端几何训练）**不在同一赛道、不直接竞争**，但其"分级课程内容、分离角可视化、走位提示、数据复盘"等已被市场验证的功能值得借鉴。

## 1. 市场分层：三类容易被混为一谈的产品

| 类别 | 核心目的 | 是否实时计算物理轨迹 | 投影内容 | 代表玩家 |
|---|---|---|---|---|
| **A. AI 教练 / 瞄准辅助** | 训练涨球、姿势纠正 | 是（前馈几何，多为无塞理想线） | 瞄准线、球杆指引线、走位区域、虚拟进球点 | 小铁、易付乐小易、客满台、乔氏以利 |
| **B. 无人自助球房 SaaS** | 门店无人化运营 | 部分集成 A 类能力 | AI 教练 + AI 裁判计分 + 高光剪辑 | 小铁、谈小娱（KO 体系） |
| **C. 互动投影娱乐** | 网红特效、引流 | 否（只做触发特效，不算物理） | 水波纹、碰撞、灯光秀、互动小游戏 | 全景视通"光影桌球"、JAMMA、趣空间 FunSpace |

**与 QiuJi 最相关的是 A 类**，但 A 类是"球桌上方硬件"，QiuJi 是"手机/平板模拟"，形态根本不同。B、C 类基本与本产品无竞争关系，仅作市场背景了解。

## 2. 主要玩家详表

### 2.1 小铁自助台球（深圳小铁文娱科技）— 头部品牌

- **模式**：无人自助球房加盟，AI 是核心差异化卖点。〔通稿口径〕成立约一年半铺至 350+ 城市、3500+ 门店，被外界称为"自助台球界的瑞幸"。门店数量为招商通稿，需打折看待。
- **四大 AI 功能**：
  - **AI 教练**：投影最佳击球线 + 球杆指引线，姿势/站位纠正，基于 **CBSA（中国台球协会）标准**做段位测评与个性化训练方案。
  - **AI 裁判**：自动判定得分与违规，支持随时开赛。
  - **AI 精彩秀**：自动识别高光（清台、连杆），一键生成短视频用于社交传播/引流。
  - **AI 服务员**：自助开台、灯光空调远程控制、24h 无人值守。
- **技术参数**〔通稿可核实部分〕：球桌上方 **120 帧高速运动摄像机** + **4000 流明、HD 投影仪** + **1T 算力边缘 AI 芯片**（端边云协同）；识别坐标包括主球、目标球、叫位目标球、K 球、进袋口、虚拟进球点、分离角等。
- **2025 进展（与"芯流"合作的原生 AI 架构）**〔行业媒体报道，雷峰网〕：主打"**球内芯片 + 杆内高精度传感器 + 桌 + 光 + 音 + AI**"的**六端联动**，强调"原生 AI、非外挂改装"，区别于"传统球桌 + 外挂摄像头/投影/灯带"的家具+配件方案。并发布对标 L3 自动驾驶概念的"L3 智慧球房"（全屋智控/智能营销/AI 黑科技/大数据引擎/互联网社交五大模块）。
- **资质**〔可核实〕：获工信部工业文化发展中心数字科技中心"首批 AI 产业创新场景应用案例"。
- **点评**：目前**技术叙事最完整、数据闭环最强**的一家（数千家门店真实对局数据用于训练裁判/教练模型，这是后来者难以短期复制的护城河）。

### 2.2 易付乐 · 小易 AI 台球系统 MP-X

- **形态**：后装支架式，可加装在现有台球桌上方，给台球厅/培训中心做智能化升级，可单独售卖。
- **核心技术**：AI 视觉识别 + 动态投影。
- **功能**：精准视觉识别球位/球路 → 自动计算最佳击球路线/力度/角度 → 投影瞄准线、教学动画、游戏互动内容；分级课程（基础/进阶/专业）；实时动作（姿势）纠正。
- **宣称参数**〔通稿口径〕：识别精度"毫米级"（未见实测依据）。
- **系统组成**：视觉识别模块 + 投影交互模块 + 主控主机 + 软件系统。
- **适用场景**：商业台球厅、培训中心、高端会所、体育院校。
- **点评**：定位清晰的"升级套件"，对标海外后装方案；瞄准辅助 + 内容课程是主线。

### 2.3 客满台（葫芦岛客满台科技）智能台球投影

- **形态**：短焦投影 + 安卓触摸一体机（也可装手机 App）。
- **内容护城河**：内嵌"**新锐台球学院**"分级课程——4 级、约 50 课时、**200+ 球形**（推白球、进袋、走位、双落、蛇彩、多球进同袋等），含**王桁教练讲解视频** + 课后练习 + 考试。
- **交互流程**：扫码登录 → 选训练球形 → 调起投影仪定位（主球/目标球/叫位球/K 球/走位区域/进球点/分离角）→ 看演示视频。
- **点评**：**内容驱动型**代表，"分级课程 + 标准化球形定位"是其卖点；同时也做"台球机器人"等硬件。对 QiuJi 的 Drill 内容体系有直接参考价值。

### 2.4 乔氏以利 / 星牌等台球桌厂商（集成式智能球桌）

- **形态**：把投影、摄像头、计分、自适应桌面参数（硬度/反弹系数）做进球桌本体，向上延伸做"交互式智能台球桌 + 智能辅助训练 + 高精度计分 + 云端数据"。
- **多模式概念**〔厂商宣传〕：AR 投影切换桌游模式、甚至乒乓模式等娱乐玩法。
- **点评**：硬件大厂路线，重在"整桌集成 + 赛事计分"，训练辅助是附加值。

### 2.5 谈小娱（KO 体系）

- **模式**：物联网 SaaS + 无人台球厅加盟，〔通稿口径〕4 年约 6000 店。
- **AI 侧重**："悟空"人机交互（语音控店）、基于 **AR 增强的电子裁判**（球型/比分以动画投到电视屏）、AI 自动剪辑高光。
- **点评**：瞄准辅助不是重点，**AI 偏运营/裁判/社交**；本质是 SaaS + 加盟生意。

### 2.6 C 类娱乐投影（仅作背景）

- **全景视通"光影桌球"**（北京）：3D 拟真撞球 + 互动特效（水波纹/翻转/碰撞/擦除/避让/跟随），多种挑战模式，纯娱乐。
- **JAMMA、趣空间 FunSpace、海外 KL Multimedia**：互动投影台球套装，用 Kinect 类动作传感器追踪，叠加动画特效；**不计算真实台球物理**，定位引流娱乐。海外标准套装约 $1800–4000。

## 3. 技术路线：A 类系统的共性架构

几乎所有 AI 教练/瞄准系统是同一套范式，且并非新概念——中国早有相关专利：
- **CN202270324U《投影式台球训练系统》**（实用新型）：台球灯内置图像采集设备正对桌心，旁挂投影仪，电脑选课程并投影辅助线/瞄准点/虚拟球/轨迹，同时采集击打视频给建议。
- **CN104117202A/B《投影式台球击球智能辅助系统和方法》**（发明）：建立台球环境模型，静止时识别球坐标；用户俯身瞄准时实时捕捉球杆两端点与击打方向，以杆头指向第一个球为母球，结合预设力度/击球点/杆水平夹角计算母球与目标球轨迹并实时投影。

**通用数据流**：

```
顶置高帧率摄像头  →  识别球位 / 球杆两端点坐标
        ↓
建立台球环境模型（台面尺寸标定 + 球半径）
        ↓
输入/估计：力度、击球点、杆角
        ↓
计算：母球与目标球预判轨迹、分离角、走位落点
        ↓
高流明投影仪：把瞄准线 / 轨迹 / 虚拟球 / 走位区域叠加到台呢
```

**厂商真正的差异点**集中在：摄像头帧率、投影流明、边缘算力、是否做杆/球内置传感器、**以及课程内容库的深度**。

## 5. 局限与争议（与本产品定位最相关的部分）

1. **强依赖顶置硬件与场地**：必须吊装摄像头 + 高流明投影，受光照、桌面反光、安装高度影响，无法脱离特定球桌/场地使用。
2. **"毫米级 / 职业级准度"多为营销话术**：电商带货式文案（"±1.5mm 第三方实测"等）缺乏可验证依据，不可轻信。
3. **物理预测的根本难点**：真实轨迹受塞（旋转）、台呢摩擦、库边回弹、力度非线性影响极大。纯视觉前馈难以精确预测**带塞球**，多数系统实际只能给**理想无塞几何线**——这恰是几何瞄准教学既能教、又容易让新手被"投影线"误导之处。
4. **依赖性问题**：投影线一关就不会打，业内亦承认其定位是"辅助/趣味"，不替代真人教练的个性化深度沟通。
5. **赛道属性**：重资产、绑场地、To B 加盟，门槛高、扩张靠招商，与个人随身训练需求是两套逻辑。

## 6. 对 QiuJi（本产品）的启示

### 6.1 竞争关系判断
- **不直接竞争**：硬件投影系统是"重资产 / To B 门店 / 绑定场地"；QiuJi 是"轻量 / To C / 随时随地的移动端几何与瞄准训练"。QiuJi 反而覆盖它们触达不到的**家庭、碎片化、赛前复盘**场景。
- **潜在协同（远期）**：门店系统沉淀的"标准球形/分级课程"理念，可在移动端以更低成本、更广覆盖复刻。

### 6.2 可借鉴（已被市场验证的功能）
- **分级课程 + 标准化球形库**：客满台"200+ 球形 / 4 级"、小铁"CBSA 段位测评"证明用户为结构化训练买单 → 强化 QiuJi 的 Drill 内容体系（现有 RackGenerator、AngleTraining 方向正确，应继续做深分级与测评）。
- **分离角 / 走位区域可视化**：硬件系统的核心卖点，QiuJi 可在 2D/几何层面做得更清晰、更可教学化。
- **高光复盘 / 数据统计**：进球率、走位精度、趋势图等数据资产，是留存抓手。

### 6.3 差异化主张（QiuJi 的护城河方向）
- **诚实处理物理**：硬件系统投影的多是"理想几何线"。QiuJi 做几何/分离角训练时，可显式区分"**理想薄厚点**"与"**带塞修正**"，把"为什么这样瞄"讲清楚——比一条投影线更有教学价值（契合本项目 `geometry-spatial-reasoning` 技能与 `docs/10-解球线路原理.md`）。
- **内容深度 + 中文本土化**：结合斯诺克/中式台球，做系统化理论 + Drill，是硬件门店方案普遍偏弱的环节。
- **零硬件门槛**：随身可用，不依赖吊装/投影/场地，这是移动端天然优势。
