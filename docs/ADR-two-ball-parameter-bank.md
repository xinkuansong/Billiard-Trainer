# ADR：两球题库只存参数、当前题生成轨迹

日期：2026-10-26。决策：用户批准正式接入；验证状态见任务记录。

原完整舒适度85消费包367.80MB，主要包含552055条布局内共享轨迹。参数原型已全量核字段/顺序，并对138题578路线三次原生重放验证。采用31.45MB参数包，所有166443题及677488推荐保留。

App只读索引/参数分片；选题后台使用现有planarReference物理和保存方向生成三球结果，经进袋/母球安全/碰B/袋角/库序/舒适度准入；当前题冻结2mm事件约束折线和评分，实际击球仍保存完整回放。预期库序按事件先后而非时间戳比较，避免同时首碰/吃库边界被误判。保留原推荐顺序，不在线优化参数。

不在每次选题时校验旧离线折线；runtime replayRMSCM为nil，旧记录非nil仍能解码。漂移回归由测试bundle中的冻结578参考路线负责。物理、压缩或评分合同变化必须重新验证，不能只换版本字段。严格85边界在不同Float环境可能导致候选被移除，不能通过降低阈值隐蔽绕过；578样本及全字段审计不是全677488条物理重放。

代价：首个球杆profile准备有额外加载成本，通过设置页后台预热及只读值缓存承担；手机性能需真机另测。错误时走已有设置页提示，不能回退为未经核验的折线。旧policy练习结束保留历史，新库建立新段。回退须同时恢复旧资源与消费代码。
