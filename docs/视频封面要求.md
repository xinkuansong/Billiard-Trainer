## 制作流程与原有要求

1. 从最新成片抽取合适帧，核对视图、外观、球位及教学关系，先看系列样板再排版。
2. 大标题必须醒目，并集中于上半区域；以顶部约47%为排版起点，实际检查缩略图和目标裁切，不能只凭坐标宣称平台安全。
3. 不再使用“粉丝破万 / 抽球杆”活动文案及活动框；黄色底板用于主标题。
4. 主题、标题、版本标识按层级排版，避开球、袋口、皮头接触轮廓及必要技术标注；画面拥挤时重排。
5. 检查最终文字、球号、球位、标注位置和内容准确性。需要原帧保真时遵循用户指定的保真制作路径；生成式重排须说明，不能当作几何验证证据。
6. 保存源帧、参考图、提示词或排版参数、输出尺寸、缩略图/裁切检查结果，更新视频台账。区分候选、已确认与已发布。

- 标题可采用白色主句与黄色重点句组合，字重厚实、对比强。例如“你看到的打点 / 真的对吗？”。不再强制整块标题全部白色。

- 圆形特写不是所有选题的硬性要求：有接触、瞄准等局部教学重点时优先采用，其他题材按内容组织。

## V008 应用约束

以当前正侧面视频为内容源，新制或换新规范时采用黄底黑字主标题，不加入活动框。保持中深灰皮头，文字为“杆头所指点 / 实际接触点”。低杆时实际接触点比杆轴所指点更接近球心；不能直接照搬参考宣传图中可能错误或简化的点位。

### 接触特写保真补充（2026-09-19）

用户明确要求圆形接触特写使用真实渲染帧，保留皮头弧度、点位和球面间隙。此类教学细节不得用生成图重画或凭观感修点；使用原始画面裁切/等比缩放/遮罩合成，标记取自对应几何账本。标题与活动版式可沿用生成底图，但须区分真实局部和生成背景；不把历史高杆帧称为当前低杆帧。
