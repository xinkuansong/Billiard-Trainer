# 球迹视频封面要求

2026-09-19 更新。适用于球迹当前短视频系列；制作前同时读取视频台账、对应成片及用户最近确认的样板。以下视觉补充不取消原有流程、活动文案与裁切要求。

## 制作流程与原有要求

1. 从最新成片抽取合适帧，核对视图、外观、球位及教学关系，先看系列样板再排版。
2. 大标题与活动文案必须醒目，并集中于上半区域；以顶部约47%为排版起点，实际检查缩略图和目标裁切，不能只凭坐标宣称平台安全。
3. 当前已接受的活动系列保留黄色圆角框、黑色大字两行“粉丝破万 / 抽球杆”。它属于当前系列，不自动延续为其他活动或未来视频的永久承诺。
4. 主题、标题、版本标识、活动框按层级排版，避开球、袋口、皮头接触轮廓及必要技术标注；画面拥挤时重排，不擅自删除活动框。
5. 检查最终文字、球号、球位、标注位置和内容准确性。需要原帧保真时遵循用户指定的保真制作路径；生成式重排须说明，不能当作几何验证证据。
6. 保存源帧、参考图、提示词或排版参数、输出尺寸、缩略图/裁切检查结果，更新视频台账。区分候选、已确认与已发布。

## 新增视觉方向：白黄大标题与圆形局部特写

用户于2026-09-19表示“这种感觉更好些，放到原有的要求里去吧”。

- [用户提供的风格参考](/Users/song/projects/13.billiard_trainer/output/cue-tip-video-20260919/cover-reference/approved-style.png)。此图用于视觉风格，不作为物理几何或最终画幅的真源。
- 上部深色、简洁背景承托大字，减少杂乱装饰。
- 标题可采用白色主句与黄色重点句组合，字重厚实、对比强。例如“你看到的打点 / 真的对吗？”。不再强制整块标题全部白色。
- 主题名可放在顶部简洁细描边胶囊中，例如“皮头接触点”，字号小于主标题。
- 主场景保留真实球桌与瞄准上下文；关键细节可使用白色细边圆形放大窗，突出皮头弧度、实际接触位置。这是允许且偏好的封面处理，不要求视频内方形小窗也变圆。
- 圆形特写不是所有选题的硬性要求：有接触、瞄准等局部教学重点时优先采用，其他题材按内容组织。
- 原活动框与版本信息依然保留并融入新风格；参考图缺少活动框，不代表用户取消它。所有营销文字仍需遵守上半区和裁切检查要求。

## V008 应用约束

以当前正侧面视频为内容源，采用上述新视觉方向并融入黄色活动框。保持中深灰皮头，文字为“杆头所指点 / 实际接触点”。低杆时实际接触点比杆轴所指点更接近球心；不能直接照搬参考宣传图中可能错误或简化的点位。

### 接触特写保真补充（2026-09-19）

用户明确要求圆形接触特写使用真实渲染帧，保留皮头弧度、点位和球面间隙。此类教学细节不得用生成图重画或凭观感修点；使用原始画面裁切/等比缩放/遮罩合成，标记取自对应几何账本。标题与活动版式可沿用生成底图，但须区分真实局部和生成背景；不把历史高杆帧称为当前低杆帧。
