# ADR：场景角度与瞄准点训练规则 v2

日期：2026-10-15。决策：用户批准；本地实现及相关模拟器验证完成。

## 问题

旧场景训练的最近袋约束与远距离条件冲突，失败兜底夹位而未重算答案。瞄准点旧G1投影差无法可靠区别反向，提交后又会纠正方向、物理验证并自动切题。旧记录没有规则、辅助或复练身份。

## 决策

四个场景入口共享 `SceneTrainingConfiguration`、`SceneTrainingGenerator` 和 `SceneTrainingRun`。旧抽象角度/瞄准点题库不变。每轮先排20题配额，再按实际球位校验，失败留在设置；无夹位和跨条件替代。结果使用有效进袋瞄点。最终几何须满足0.05°误差容差，再使用已检验的整度答案统一显示与评分，避免Float尾差跨过3°等级边界。干净进袋通道调用当前几何的 `cleanPipeMargin`，不修改物理规则。

瞄准点只保留用户方向与标准方向的静态几何对照；提示为标准角度文字。毫米误差在标准假想球的共同横截面测量。反向、错侧、不接触为独立异常类型，真实误差缺失时不以0作为统计值。先前G1标记保留为题面视觉，结果毫米口径不再称G1误差。

`AngleTestResult.trainingMetadataJSON` 是可空的版本化记录包，包含规则/评分/单位、run与question UUID、配置、最终归一化几何、首答/复练、辅助事件、用户方向及异常状态。`quizType` 保持scene2D/scene3D/aimPoint2D/aimPoint3D。旧记录nil表示未知。新记录的旧数值列保留有限值兼容传输；新客户端评分和统计以metadata为准，异常没有有效毫米样本。

SwiftData升V6；V5冻结旧AngleTestResult结构，V5→V6轻量迁移。同步DTO、恢复和后端Mongoose同时支持metadata字段。服务端部署需与新客户端发布配套；本任务仅修改与验证本地代码，不代表服务器已部署。

认知会话仍使用现有TrainingSession体系，新规则按runID分轮，避免同来源30分钟窗口把不同轮及旧规则混在一起。每题只提交一次并计题与免费额度；答案展示后不能重做同题，继续下一题或总结。旧复练身份字段只用于兼容历史数据。历史趋势按来源、评分版本及辅助身份隔离；旧记录标辅助状态未知。
