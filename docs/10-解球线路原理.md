# 解球线路计算原理

> 本文档说明「球迹」App 是如何计算并绘制各条解球线路的，作为后续**独立讲解页面**的内容底稿与权威参考。
> 术语与主公式以 `.cursor/rules/45-aiming-principles.mdc` 为准；本文档在其基础上补全**完整工程算法**（含进球管道修正、反射解球、可行性判定）。

## 0. 两类解球线路

App 里所有"线"都来自两套独立的几何引擎：

| 类型 | 场景 | 引擎 | 物理模型 |
|------|------|------|----------|
| **A. 直接进球（瞄准线）** | 2D/3D 瞄准训练、角度与打点 | `AngleSceneCalculator` | 幽灵球法 + 切球角 |
| **B. 翻袋 / 反射解球** | 反射解球器（`DiamondSystemView`） | `DiamondSystemCalculator` | 纯反射镜像展开 |

两套都是**纯几何模型**：不含旋转（塞）、速度、库边吸收、碰撞偏移（throw）。这是刻意的——训练目标是先建立"几何直觉"，把变量降到最少。

## 1. 坐标系与桌面几何

所有计算都在同一个世界坐标系下（单位：米）：

- 原点在台面中心，**X = 长轴**，**Z = 短轴**，Y 为高度（计算时忽略）。
- 中式八球内框：`innerLength = 2.54`，`innerWidth = 1.27`，球半径 `R = 0.028575`（直径 57.15mm）。
- 长半轴 `halfL = 1.27`，短半轴 `halfW = 0.635`。

```
        +X (长轴, 上)
         │
  ───────┼───────  +Z (短轴, 右)
         │
   原点在台面正中心
```

**归一化坐标**（出题/存储用）：x∈[0,1] 映射长轴，y∈[0,0.5] 映射短轴，由 `normalizedToScene` / `sceneToNormalized` 双向转换。

**袋口中心**不是击球区四角，而是真实的"洞心"。在标准物理偏移（角袋 42mm、中袋 53mm）基础上，再按当前 USDZ 模型实测**减去**一个 delta（角袋 12mm、中袋 9mm），让黄色标记圆盘正好压在模型洞心上（`pocketPositions`，6 个袋按 左上/右上/左下/右下/上中/下中 排序）。

**袋口 jaw（库角鼻尖）**：每个角袋有 2 段 jaw（长边侧 + 短边侧），中袋是长边中点两侧端点（`pocketJaws` / `pocketMouths`）。jaw 是后面"进球管道"判定的关键障碍。

## 2. 直接进球瞄准线（幽灵球法）

这是最核心的一条线，整个 2D/3D 瞄准训练围绕它展开。

### 2.1 四个几何对象

1. **进球线（pocket line）**：目标球中心 → 袋口（进球点）。
2. **幽灵球中心（ghost ball）**：目标球中心沿进球线**反向**偏移 `2R` 的位置。
   它代表"白球在撞击瞬间应当到达的中心位置"。
3. **击球线（strike line）**：白球中心 → 幽灵球中心。白球只要沿这条线走，就能把目标球打进。
4. **切球角 α（cut angle）**：进球线与击球线的夹角。

```
   袋口 ●
        \  进球线
         \
          ○ 目标球
         /·  ← 接触点 (偏移 R·sinα)
        /
       ◌ 幽灵球中心 (= 目标球 − 2R·进球线方向)
      /  击球线
     ◯ 白球
```

### 2.2 公式

```
幽灵球中心 = 目标球中心 − 2R · normalize(袋口 − 目标球中心)
横移量 d   = 2R · sin(α)          ← 瞄准主公式
接触点偏移 = R · sin(α)            ← 派生量，仅用于球面可视化
```

- **横移量 d**：幽灵球中心相对目标球中心，在"垂直于击球线方向"上的位移。这是教学主公式。
- **接触点偏移**：目标球表面被击中的那一点，相对球心的横向距离（= `R·sinα`）。**不要**把它当主公式。

### 2.3 对应代码

| 函数 | 作用 |
|------|------|
| `ghostBallPosition(targetBall:pocket:ballRadius:)` | 幽灵球中心 = `T − 2R·dir` |
| `cutAngle(cueBall:targetBall:pocket:)` | 用两条单位向量点积 `acos` 求 α，截断到 [0,90] |
| `contactPointPosition(targetBall:pocket:)` | 接触点 = `T − R·dir`（在 target→ghost 方向上，与白球当前位置无关） |
| `lateralDisplacement` / `lateralDisplacementMM` | `2sinα`（无量纲）/ `2R·sinα`（毫米） |

### 2.4 屏幕上画出来的线

在 `AngleTrainingScene.updateVisualization` 里：
- 白色 = 击球线（白球 → 幽灵球）
- 红色 = 进球线（袋口 → 穿过目标球，向幽灵球后方延伸，形成切角楔形）
- 蓝色弧 + 数字 = 切球角 α
- 黄点 = 接触点；细黄线 = 进球线的垂线（标示接触点偏移方向）

### 2.5 厚薄球对照（教学常用）

| α | sin α | d/R = 2sinα | 接触点偏移% | 通称 |
|---|-------|-------------|-------------|------|
| 0° | 0.00 | 0.00 | 0% | 全球 |
| 7.5° | 0.13 | 0.26 | 13% | ≈1/4 球 |
| 10° | 0.17 | 0.35 | 17% | ≈1/3 球 |
| 30° | 0.50 | 1.00 | 50% | 半球 |
| 48.6° | 0.75 | 1.50 | 75% | 3/4 球 |
| 90° | 1.00 | 2.00 | 100% | 极薄球 |

（`thicknessName(cutAngle:)` 给出通称。）

## 3. 进球点动态修正（进球管道模型）

**问题**：瞄准并不总是对准袋口几何中心。目标球贴库时，若直愣愣瞄洞心，球会先撞到库边鼻尖（jaw）而打不进。

**思路**：把进球线看成一条有半径的**"进球管道"**，而不是一条无厚度的线——目标球球心沿管道中心线移动时，中心线两侧各有 `R + 3mm` 的扫掠半径，这条管道不能蹭到库边或非目标袋的 jaw。

### 3.1 算法（`effectivePocketAimPoint`）

1. **先试自然方向**：目标球 → 袋口中心。若整条管道安全（`aimPointIsPipeSafe`），进球点 = 袋口中心，结束。
2. **否则绕袋口中心搜索**：以 `radiusStep = 2.5mm` 向外、`angleStep = 5°` 一圈圈采样候选瞄准点，第一圈出现安全方向就停。
3. **打分选优**：在安全候选里，选"偏离自然方向最小"的那个（score = 半径 + 角度偏差·权重）。进球点 = 该候选点。

效果：离库越远 → 进球点回到洞心；越贴库 → 进球点沿库边平行偏移，自动避开 jaw。

### 3.2 管道安全判定（`aimPointIsPipeSafe`）

把管道末端延长 `clearance`，对两类障碍做线段距离检测：
- **普通障碍**（`ordinaryObstacles`）：四条库边线段 + 所有**非目标**袋口的 jaw。任意距离 < clearance → 不安全。
- **目标袋自身的 jaw**：允许贴着进（球本来就要从两片 jaw 之间穿过去），用 `boundaryTolerance = 4mm` 容差判定"擦边但仍在嘴内"。

底层几何用标准的线段-线段最近距离 / 相交判定（`segmentDistance` / `segmentsIntersect` / `closestPointOnSegment`）。

### 3.3 贴库软提示（`isPocketReachable`）

若修正后的进球点偏离洞心超过 `1.5 × 袋口半径`，标记为"贴库困难球"——**仅 UI 提示**，不影响可行性。

## 4. 可行性与自动选袋

判断某个袋口是否可行（`isFeasible`）：

1. **切球角阈值**：`α < 89°`。物理极限是 90°（动量传递归零），用 89° 回避 `acos` 边界抖动（`maxCutAngle`）。
2. **母球不挡路**（`isCueBallBlocking`）：把母球投影到进球线上，若投影落在目标球与袋口之间（`0<t<1`）且垂距 < `2.5R`，说明母球压在进球线上，挡住目标球入袋 → 不可行。

自动选袋就是对 6 个袋逐一算 `isFeasible` + 切球角，挑可行且角度最优的。

## 5. 翻袋 / 反射解球线（镜像展开法）

用于"反射解球器"页：白球、目标球可放在桌面任意位置，求出**经过 N 次库边反射后正好到达目标**的所有路线。

### 5.1 物理模型

纯反射：**入射角 = 反射角**（无塞、无速度衰减）。

### 5.2 镜像展开（mirror unfolding）

核心技巧：与其让球"折线反弹"，不如把目标球**沿要碰的库边依次做镜像**，得到一个"虚像"。从白球到虚像连一条**直线**，这条直线与各库的交点，就是真实反弹点。

对一个固定库序 `solveSequence`：
1. 从最后一库往前，把目标球依次反射，得到每一段的虚像 `images[i]`（`reflect` 对长库翻 Z、短库翻 X）。
2. 从白球出发，与 `images[0]` 连线求第一库交点；再从该点与 `images[1]` 连线求第二库交点……（`intersect`）。
3. 得到折线 `[白球, P1, …, Pk, 目标球]`。

```
   真实路径:  白 →┐      ┌→ 目标
                 └──────┘
   展开后:    白 ─────────── 目标的镜像   (一条直线)
```

### 5.3 枚举与过滤（`solveAll`）

- **枚举库序**：`railSequences` 生成长度 1…N 的所有库序，约束"相邻两库既不能相同、也不能正对"。**正对**指两条长库（左/右）或两条短库（底/顶）；连续撞正对库会让球在台面上来回"N 字"往返，不现实，故 `areOpposite` 直接剔除——实际效果是库序在长库 / 短库之间交替。
- 对每个库序解出折线后，逐项过滤：
  - 反弹点必须落在该库的**物理线段内**（`onRailSegment`）；
  - 直线参数 `t ∈ (0,1)`，拒绝退化的零长跳；
  - 反弹点不能落进**袋口嘴**（`hitsPocket`）——否则球是进袋而非翻库；
  - **首库入射角 ≥ 15°**（`firstCushionAngleOK`）——太平的擦库不现实，滤掉。
- **去重 + 排序**：按（库数升序，路径长度升序）排序并去掉几乎重合的解（`isDuplicate`）。第一条即"最少库 / 最短"解；UI 的"自动"模式就取它。

### 5.4 颗星网格（辅助参考）

`diamondLabels` / `diamondTicks` 在长库画 1…7 号颗星数字、四库画刻度点，作为肉眼对位的参照系（不参与求解）。

## 6. 出题：从答案反推球位（`AngleCalculator`）

瞄准训练的题目是**先定切球角 α，再反推球位**，保证"答案"与屏幕显示完全一致：
1. 随机选袋、随机目标球位置（满足与袋距离区间、且该袋是最近候选袋）。
2. 用 §3 的 `effectiveAimPoint` 求真实进球点 → 目标球到进球点方向 `toAim`。
3. 幽灵球 = 目标球沿 `toAim` 反向偏移 `2R`。
4. 白球 = 幽灵球沿 `approach = toAim ± α` 方向再退 `cueDist`。
   这样白球→幽灵球与进球线恰好成 α，`actualAngle == α` 与可视化吻合。
5. 200 次采样失败则用 `fallbackQuestion` 兜底（沿袋口→中心方向放置）。

## 7. 已知简化与边界

- 不建模：旋转（塞）、速度/力度、库边能量吸收、碰撞投掷偏移（throw / collision-induced throw）、球与球的连续碰撞。
- 全部是 XZ 平面纯几何；Y 仅用于把节点摆在台面上。
- 浮点判定用了一系列经验阈值（`aimMargin 3mm`、首库角 `15°`、`maxCutAngle 89°`、去重 `1cm` 等），调模型几何时需同步校准袋口 delta。

## 8. 用于讲解页面的建议（可选）

若做独立讲解页，建议按"看得见 → 算得出"分层：

1. **直接进球**：动画演示「进球线 → 幽灵球 → 击球线 → 切球角」四步，配 `d = 2R·sinα` 与厚薄球对照表；可让用户拖动目标球实时看 α 与 d 变化。
2. **贴库修正**：用一颗贴库球演示"瞄洞心打不进 / 进球管道自动偏移"的对比。
3. **翻袋反射**：用镜像展开的动画（目标球翻折出虚像、白球到虚像连直线）讲清"为什么这样瞄"，再切回真实折线路径。
4. 每节末尾给一句"几何模型不含旋转/力度"的诚实说明，避免误导。
