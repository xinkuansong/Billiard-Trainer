## 0. 产品定位提要（2026-06-18 收敛）

面向**中间层瓶颈期爱好者**（常打、想提高，但刷短视频形不成体系、又没时间/条件请教练）的**「练脑型」系统化台球训练 App**，三大支柱构成「学练记」闭环：

- **系统教学（学）**：动作库 + 官方分级计划 + 角度/解球原理。
- **交互式练习（练）— 护城河**：物理引擎驱动的「练脑」工具（线路判断 / 几何角度直觉 / 战术决策），定位为真实球台练习的「课前预习 + 课后复盘」，**不替代真实出杆手感**。
- **训练记录（记）**：日志 + 历史日历 + 统计，习惯黏合层。

### F12 — 分离角与走位（物理演示页）✅

- **故事**：作为爱好者，我想真实地看到「这一杆打下去母球和目标球各自怎么走、分离角多大」，并能调袋口/力度/上下左右塞，理解杆法对走位的影响。
- **验收**：
  - 自由摆母球 + 目标球，点选袋口；连续力度滑条 + 打点盘（真实皮头比例 + 打滑极限圈）。
  - **物理引擎实时求解**：母球轨迹（含 squirt/swerve/throw/吃库/走位）、目标球进球线、分离角、进/未进诚实显示。
  - 击球回放（原速 + 出杆运杆/跟杆动画 + 进袋入洞 + 击球音效）。
- **依赖**：物理引擎（`ShotPredictor`/`EventDrivenEngine`）。

### F13 — 走位编排台 ✅

- **故事**：作为内容创作者/进阶玩家，我想在桌上自由摆任意球，逐杆选目标+袋口、调力度打点，把多杆串成一条**走位击打序列**，用于教学制作或走位训练。
- **验收**：球库拖球摆位、连续击打状态机（击球后桌面前进、进袋离场、自动选下一杆最近目标+可进袋袋口）、重打回退、录制开关→导出序列 JSON（模拟器侧直写内容库）。
- **依赖**：F12 物理引擎 + 序列模型 + 教学素材渲染管线。

### F14 — 思路训练器（走位反解器）✅

- **故事**：作为想练「走位脑」的玩家，我不想自己试错塞和力度——我画一个母球**目标落区/落点**，让 App 反解出「该用什么塞、多大力、怎么瞄」。
- **验收**：
  - 情形 A 母球停在手画可行落区（矩形/圆）/精确落点（容差环）；情形 B 母球过指定点去 K 球。
  - 放开塞与力度作自由变量，硬约束=目标球进选定袋；输出最优解 + 「下一解」翻档，塞/力度转**只读指示器**。
  - **分水平开关**：是否允许左右塞、走位复杂度预算（基础≤1 库 / 不限），适配不同水平玩家。
- **依赖**：`PositionPlaySolver`（独立反解器）。这是「练脑」定位的代表功能。

### F15 — 斯诺克战术（做杆/安全球反解）✅

- **故事**：作为斯诺克玩家，我想选目标球 + 障碍球，让 App 算出怎么把母球做到「对手看不到目标球」的完全斯诺克。
- **验收**：点选目标球/障碍球/摆球；反解瞄准×塞×力度使母球与目标球间被障碍完全遮挡（不进袋、母球真停稳）；无完全解降级半斯诺克；终位遮挡视线可视化。
- **依赖**：`AngleSceneCalculator.snookerCoverage` + `PositionPlaySolver.solveSnooker`。

### F16 — 球形生成器（开球/少球摆法）✅

- **故事**：作为玩家，我想一键生成「中式八球开球 / 9 球（4/5/6/9）」的真实散开球形，喂给编排台或思路训练器练走位。
- **验收**：选玩法 → 摆架预览 → 调开球点/力度/打点 → **真实物理开球**散开 → 「换一局」（seed 驱动，换一局即换形）→ 路由到编排台/思路训练器。
- **依赖**：`RackLayout` + `BreakSimulator`（端上真实物理）。

### F17 — 拍照建球形 ✅

- **故事**：作为玩家，我想拍一张任意角度的球桌照片，App 自动/半自动还原所有球的号码与位置，送进训练工具。
- **验收**：拍照 → 手拖 4 角标定 → **单应矩阵**映射 → 点标每球+选号 → 2D 真台人工确认（增删改） → 产出球形送编排台/思路训练器。
- **依赖**：`Core/Geometry/Homography`。阶段 2/3（自动检测/号码归类）按需引入 DL。

### F18 — 翻袋解球器 ✅
- 目标球 1/2/3 库纯反射镜像展开进指定袋，反推母球瞄准线/接触点/切球角；袋口可行性高亮。

### F19 — 反射解球器 / 颗星公式（含真实反射模式）✅
- 母球经库反弹解球；**理想模式**（入射角=反射角）+ **真实模式**（反射角相对法线略小，缩小因子滑块 0.50–1.00 供用户拟合自家球台）。

### F20 — 击球音效 + 原速回放 🔄
- 物理回放按真实事件时刻排程**真实录音**击球音效（非游戏合成、不变调、靠多样本池），尊重静音键、可设置开关；所有回放/导出视频原速。资产待人工补齐（CC0 录音，H-18）。

## 3. 物理引擎（横向能力，支撑 F12–F17）

- 移植自 **pooltool** 的事件驱动物理引擎（`QiuJi/Core/Physics/`）：Han2005 库边模型、球-球碰撞（滑移/无滑移 + Alciatore 摩擦）、squirt/swerve/throw、漏斗袋口喉腔模型、确定性可复现。
- 配套测试网：不变量 + 系统化矩阵 + 真实球理场景（约 3800+ 被断言场景）。
- **诚实边界**：当前为 **2D 平面物理**（跳球/扎杆腾空无法表达）；3D 视频仅换相机视角，物理仍是平面。常量标定（e_b/库边摩擦/恢复系数）待真实俯拍视频拟合。

## 7. 每日清台（v52）

- 训练首页「本周训练」卡片提供独立的「每日清台」入口；入口有「每日清台 / 继续清台 / 今日已清台 ✓」三态，无激活计划时仍可使用。
- 页面复用 `FreePlayView`，但每日模式是单人挑战：当天首次进入按「我的 → 偏好设置 → 每日清台默认玩法」自动开球；未完成时恢复同一盘，用户可主动重新开球或临时换玩法。
- 支持中式八球、9 球、6 球、5 球、4 球。系统自动开球与用户重开均属于出题阶段，不计入清台杆数或犯规数。
- 每日清台记录为 `TrainingSessionKind.tool`；独立草稿/完成状态仅保存在本机，不计入周目标、今日计划完成数或真实准确率，当前不跨设备同步。

## 8. 官方主线与今日编排（v54）

- **唯一主线**：同一 owner 最多一个 active 官方计划；切换计划保留旧进度。模版不再激活，也不会替换官方计划。
- **阶段课程**：官方内容以 `stage / lesson` 表达能力顺序，不再以固定周数和训练日承诺进度；每课有稳定 ID。
- **编排今天**：官方课程、我的模版和动作库动作都可加入同一今日队列；默认追加，未完成项可排序/删除，进行中项可继续。
- **智能推进**：已学课程算复练；从当前课起连续选中的课程可逐课推进；跳过中间课程的未来课只算提前练习。所有作用在入队时冻结，只有保存完成记录后结算。
- **弹性频率**：少练不跳课，多练可多推进，一天可练多块；同日仍只计一个训练日。预计周数读取当前 owner 的每周训练目标并随剩余课程变化。
- **可回溯来源**：每个今日块和训练记录保留冻结来源。源仍存在时历史详情可返回计划/模版/动作；源删除时保留文字但停止跳转。
