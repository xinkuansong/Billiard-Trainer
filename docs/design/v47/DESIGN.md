# 球迹 v47 Design System

版本：1.0 · 2026-08-30  
用途：Stitch 母版探索与后续 SwiftUI 翻译的共同语义输入。真实业务结构以当前 App、`route-coverage.csv` 与产品文档为准；本文件不授权改变文案、数据、路由或交互。

## 1. 品牌与气质

球迹是一件“专业台球训练仪器”，不是球房海报、传统器材品牌、健身 App 或游戏 HUD。

视觉关键词：冷静、精确、数据化、可信赖、克制。前景采用专业训练仪表盘语法：指标先于容器，信息层级清晰，单屏只有一个主要动作，列表紧凑但不拥挤。

必须避免：米白、奶油、木色、黄铜、暖调摄影、霓虹赛博、AI 网络节点、电路板、分子图、世界地图、随机发光连线、玻璃拟态堆叠、大面积渐变、无意义装饰卡片。

## 2. 平台和结构约束

- 平台：iPhone，Mobile portrait，优先 6.3 英寸，同时可缩放到 6.1 与 6.9 英寸。
- 使用系统 Tab Bar、NavigationStack、Sheet、Alert 与返回手势；不设计自造网页导航。
- 五个一级 Tab 根页永久无大导航标题。根页从安全区下方直接进入内容；子页才显示正常导航标题。
- 不改变当前业务文案、数据值、区块顺序含义、路由、订阅门控、统计口径或训练剂量。
- Stitch 产物只用于布局、层级、色彩、字体与比例探索；HTML 不进入生产代码。

## 3. 色彩系统

色彩是语义参考，W1c2 Gate B 后才映射为最终 SwiftUI Asset Token。禁止为了效果图新增暖色背景。

## 4. 排版

- 中文正文使用系统无衬线；Stitch 近似字体选 `Inter`，SwiftUI 最终仍使用系统字体与 Dynamic Type。
- 标题不全大写，不使用超宽字距。圆体只用于数据、章节号和少量训练仪表读数。
- 核心数字 30–44pt Bold Rounded，卡片指标 24pt Bold Rounded，Section 20pt Bold，行标题 17pt Semibold，正文 17pt，辅助 13–15pt。
- 数字使用等宽数字；数字显著大于标签，单位靠近数字但降权。
- 根页不放“训练 / 动作库 / 练习 / 记录 / 我的”大标题；小型情境标签可以存在，但不能伪装回大标题。

## 5. 间距、形状与表层

- 4pt 基准；常用间距 8 / 12 / 16 / 20 / 24 / 32 / 48pt。
- 页面左右边距 16pt；Section 之间 24–32pt；行内 8–12pt。
- 默认圆角 12pt；按钮与输入 8–12pt；Sheet 16–20pt；胶囊只用于状态/筛选。
- 指标优先通过对齐、留白和 1px 分隔组织；禁止每个数字单独套白卡。
- 阴影只用于真正悬浮组件，不能把整个页面做成卡片墙。
- 触摸目标至少 44pt。

## 6. 球路工程图背景

只允许使用球迹自身的几何语言：母球轮廓、假想球虚线圆、碰撞点、瞄准线、目标球线、切线、分离角弧、库边刻度、钻石点、坐标校准点。

三档强度：

- `subtle`：训练、历史、个人根页，Light 可见强度约 2%–4%，只承担产品签名。
- `editorial`：长内容页顶部，约 1%–3%，正文区域迅速淡出。
- `hero`：登录/引导，约 8%–12%，可成为首屏品牌构图但不能影响文案对比。
- `none`：球桌、SceneKit、Canvas、2D/3D 工具和已有暗场主视觉页面。

背景不能随机变化，不得成为可滚动独立层，不接收触摸，不进入 VoiceOver。`subtle` 与 `editorial` 不允许持续 Timer/Timeline 动画。几何图形必须看起来像真实切球/分离角构图，不得画成通用科技网络。

## 7. 四种页面语法

### A. 仪表盘根页

训练、历史/统计、个人中心使用。首屏先给一个主要状态或数字，再给一个主 CTA；次级指标横向对齐，用细分隔而不是多层卡片。背景为 `subtle`。

### B. 紧凑列表与表单

动作库、设置、账户、订阅使用。维持 iOS 原生列表和表单感；通过行高、分隔、图标槽位和状态标签建立节奏，不改成网页卡片网格。

### C. 编辑式长内容

精讲、学页、理论页使用。强调标题、导语、首屏结论、图解、正文和练习提示的阅读层级；减少连续白卡。背景只在顶部使用 `editorial`。

### D. 暗场工具

击打、求解器、自由走位、认知场景等使用。球桌/场景是唯一重视觉；背景为 `none`。只统一顶部/底部 chrome、状态、字号、工具按钮和转场，不覆盖球桌。

认证/引导是 A 的品牌化 `hero` 变体：深石墨或冷深绿模块配冷白内容，不使用摄影底图。

## 8. 六类 Stitch 母版

1. 训练根页：无根标题；今日训练状态、核心数据、一个“继续/开始今日训练”主 CTA、计划与快捷入口。
2. 历史/统计：无根标题；日历/统计分段、周期核心指标、趋势或分布、训练记录列表。
3. 个人中心：训练档案、目标刻度、账户/Pro 状态和原生设置入口。
4. 登录/引导：Logo、品牌承诺、球路 `hero`、现有登录方式与协议，不改变流程。
5. 长内容：标题、摘要/结论、图解、正文、提示与相关入口，编辑式而非卡片墙。
6. 暗场工具：保留球桌/轨迹主视觉，只探索 chrome、控件层级、状态与可读性。

Gate A 只生成训练根页与历史/统计的 Light 变体，每类 2–3 个。用户确认视觉语言后才生成其余四类与 Dark。

## 9. 数据和交互状态

所有母版必须能扩展到：default、pressed、disabled、focused、loading、empty、error/retry、locked、success。Gate B 状态板还要覆盖键盘、Sheet、Alert、ConfirmationDialog、Viewer、滚动返回、训练最小化/恢复。

- 同一屏只有一个主 CTA。
- loading 不让布局跳动；empty 与 error 提供明确下一步；locked 不隐藏原业务含义。
- 不把示例假数据当产品事实；生成图必须沿用真实中文结构，数值仅作固定 fixture 示例。

## 10. 无障碍与动效

- 正文对比度至少 4.5:1；大字与关键图形至少 3:1。
- 支持默认字号与 Accessibility Dynamic Type；核心数字、单位和主要操作不得截断。
- Reduce Motion 下路径动效静止；Reduce Transparency 下仍有明确层级；Increase Contrast 下背景图继续降权。
- 装饰背景隐藏于 VoiceOver；阅读顺序保持业务顺序。
- 运动只表达按压、状态切换、导航或显式路径绘制，禁止持续呼吸、漂浮和霓虹扫描。

## 11. Stitch 生成禁令

- 不生成新的 Tab、路由、业务模块、商品、社交功能或数据维度。
- 不改中文文案含义，不把英文占位符带入最终候选。
- 不使用暖金背景、摄影球桌、通用科技网络、蓝色网页链接风格或游戏 HUD。
- 不恢复根页大标题，不隐藏系统 Tab Bar，不把 HTML 当 SwiftUI。
- 不把 `BTPlanCover`、训练计划卡片、练习卡片与逐卡封面作为 v47 改造对象。

## 12. 最终判断标准

用户不看 Logo，也应能从冷调球路工程图、数据层级、紧凑表层和真实球桌语言认出“球迹”。页面之间像同一套专业训练系统，但训练、数据、内容、表单和暗场工具仍保持各自正确的功能语法。
