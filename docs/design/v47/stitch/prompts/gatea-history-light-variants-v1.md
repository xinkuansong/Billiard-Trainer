# v47 Gate A — 历史/统计 Light 变体探索 v1

基于所选历史/统计母版生成 2 个 Light 变体，仅探索布局层级、冷调色彩分配和字体比例。所有真实中文数据、历史/统计分段、周/月/年、训练概况、训练时长图表、后续统计延续、无根标题与系统五 Tab 结构必须原样保留。

- 变体 A 倾向「数据报告」：减少外层卡片，使用细分隔、基线网格和编辑式留白，让 `2 天` 与 `0.1 小时/周` 成为首要扫描点。
- 变体 B 倾向「测量仪表」：保留清晰阅读流，稍加强工程刻度、轨迹采样点和冷调深绿状态带，但背景可见强度仍不得超过 4%，不能冒充统计曲线。
- 两个变体都必须专业、克制、数据优先；不新增预测、建议、排名或虚构数据。
- 不使用暖色、金融看板、通用科技网络、霓虹 HUD、大面积渐变或恢复根页标题。
- 保持图表标签可读、触摸目标至少 44pt、正文对比度合格、底部安全区完整。
