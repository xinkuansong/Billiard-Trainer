# v47 Gate A — 历史/统计 Light 母版 v1

为 iPhone 6.3 英寸竖屏设计「球迹」记录 Tab 的「统计」分段 Light 母版。它是专业台球训练数据仪表盘，不是金融看板、健身 App 或游戏 HUD。严格使用项目 Design System，界面语言为简体中文。

## 必须保留的真实结构与数据

- 一级 Tab 根页无大标题、无 navigation title；顶部是「历史 / 统计」分段，统计选中；其下是「周 / 月 / 年」范围选择，周选中。
- 首个数据区「训练概况」：主数字 `2 天`，标签「本周训练天数」；明示「球台训练 2 天 · 5 分钟」「屏内练习 0 天 · 0 分钟」「工具使用 3 天 · 3 分钟（不计训练量与成绩）」；分类摘要「杆法 2天 / 基础 1天 / 特殊 1天」和克制的小型柱图。
- 第二个数据区「训练时长」：右上 `+0.1 小时 (+0%)` / 「环比上周」；「平均训练 0.1 小时/周」；日期 `2026-08-24 ~ 2026-08-30`；保留周一至周日柱图、总量图与均值线图例。
- 下方继续进入「分类成功率」「各分类对比」「角度训练」等现有统计区，不虚构具体数值；只需在首屏底部显露下一节的延续。
- 底部保留系统五 Tab Bar：训练、动作库、练习、记录、我的；记录为选中态。
- 不新增业务、入口、排行榜、教练建议、目标预测或虚构统计；不改变统计口径。

## 视觉目标

- 冷白/银蓝灰页面底色，石墨正文，冷调深绿表达选中、正向状态与核心线条；图表辅助色使用工程蓝灰，不扩散暖金。
- 数据优先：大数字明显高于标签；同组小指标横向对齐；减少白卡套白卡，优先使用分区底色、细分隔、轴线与留白。
- 在顶部留白和页面底层加入 2%–4% 强度的 `history/subtle` 球路工程图：测量刻度、轨迹采样点、分离角弧或库边钻石点。它只能作为产品签名，不能冒充真实统计数据，也不能穿过图表和正文。
- 图表保持真实 iOS Charts 的清晰、克制和可读性；数字使用等宽数字感；正文与控件达到 WCAG AA。
- 允许把「训练概况」设计成一个主数据区，把训练时长设计成编辑式图表区；避免每个小数字单独套卡。

## 禁止项

禁止恢复「记录」大标题；禁止金融交易风格、红绿涨跌盘、通用 AI 网络、电路板、霓虹 HUD、随机装饰线；禁止暖白、米色、金色、木色与摄影背景；禁止改变 Tab、时间范围或统计语义；禁止生成英文导航或乱码。

输出一张完整、可实现、接近真实 iOS SwiftUI 的 Light 母版，包含状态栏与系统 Tab Bar，不输出说明文字。
