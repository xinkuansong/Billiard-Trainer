# v47 Gate A — 训练根页 Light 母版 v1

为 iPhone 6.3 英寸竖屏设计「球迹」训练 Tab 根页的 Light 母版。它是专业台球训练仪表盘，不是健身 App、球房宣传页或游戏 HUD。严格使用项目 Design System，界面语言为简体中文。

## 必须保留的真实结构

- 一级 Tab 根页无大标题、无 navigation title；顶部安全区右侧保留「好友」与更多菜单两个 44pt 图标按钮。
- 首屏第一个信息块是「今日安排 Chris」，右侧进度 `0 / 3`，副信息「今日清单」。
- 今日队列恰好展示三项：
  1. 专项训练 / 低杆远台缩回 / `5 × 15`，当前项有唯一主操作「GO!」。
  2. 专项训练 / 低杆加塞走位 / `12 × 15`，状态「排队」。
  3. 专项训练 / 挤偏认知 · 直球近台 / `2 球形 · 共 225 球`，状态「排队」。
- 今日队列之后保留分段「官方计划 / 我的模版」、难度筛选 Chip，以及计划卡浏览区。
- 底部保留系统五 Tab Bar：训练、动作库、练习、记录、我的；训练为选中态。
- 不新增业务、入口、徽章、成绩、连续天数、社交动态或虚构统计；不改文案含义与内容顺序。
- Drill 缩略图与计划封面是不可改的既有资产占位，不重新创作、不改逐卡映射。

## 视觉目标

- 冷白/银蓝灰页面底色，石墨正文，冷调深绿承担状态与唯一主 CTA；不使用暖白、米色、金色、木色或摄影背景。
- 让「今日安排」成为专业任务控制台：数字与状态先读，细分隔与留白代替层层白卡；当前项比排队项更明确，但三项仍属于同一队列语法。
- 在顶部留白和页面底层加入 2%–4% 强度的 `training/subtle` 球路工程图：母球轮廓、假想球虚线、碰撞点、瞄准线、切线或库边刻度。图形必须克制、几何可信、不穿过正文、不抢触控。
- 视觉密度紧凑但不拥挤；一屏只有一个主要 CTA；数字使用等宽数字感；正文与控件达到 WCAG AA。
- 卡片圆角约 12pt，阴影极少，只用于真正悬浮层；指标和队列优先用背景层级、1px 分隔、边线与留白组织。

## 禁止项

禁止恢复「训练」大标题；禁止通用 AI 网络节点、电路板、分子图、世界地图、霓虹 HUD、随机连线；禁止暖金和大面积渐变；禁止改变 Tab 架构；禁止把球路图做成可交互球桌；禁止生成英文导航或乱码。

输出一张完整、可实现、接近真实 iOS SwiftUI 的 Light 母版，包含状态栏与系统 Tab Bar，不输出说明文字。
