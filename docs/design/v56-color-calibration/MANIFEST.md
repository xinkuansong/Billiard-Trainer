## 各图增量 Prompt

### 01 / 02 — 实绿筛选

- 把顶部选中筛选从 Light 黑 / Dark 白改为对应模式的品牌绿实底 + 白字。
- 未选筛选保留中性表面；侧栏继续使用绿图标/文字 + 细侧轨。
- 普通导航不新增金色；球桌、彩球与轨迹颜色不变。

### 03 — 个人页层级

- 登录卡成为唯一高面积品牌绿主行动。
- 游客同步提醒改为低强度中性信息条，仅 warning 图标使用暖橙。
- Pro 卡保留炭黑 + 金，但降低面积和饱和度竞争。
- 普通菜单只用绿/灰；金只留订阅行；首屏不再出现第二个大号登录 CTA。

### 04 — 封面调色

- 不替换照片和构图，只统一曝光、黑位、白平衡、台呢绿与中性暗幕。
- 保留球、杆、编号、标题、字幕和 Pro badge；金色只用于 Pro。

### 05 / 06 — 弱绿筛选

- 顶部选中筛选改为低强度绿色表面 + 绿色文字/边框，不使用黑、白或实绿填充。
- 侧栏和底栏继续承担导航选中，避免同屏三个高饱和绿块。

### 07 / 08 / 09 — Pro 金色三方向

- 三张图只替换 Pro / 订阅相关金色；品牌绿、warning、布局、文案和普通菜单色保持不变。
- `07` 香槟金：基准 `#C6A15B`、高光 `#E7D3A0`、深色 `#8C6B2F`，目标是克制、精致且仍有付费识别。
- `08` 古铜金：基准 `#A8843F`、高光 `#CEB36A`、深色 `#745A2A`，测试会所/传承感是否适合本产品。
- `09` 冷淡沙金：基准 `#BFAE7A`、高光 `#DDD1AE`、深色 `#857650`，测试更安静的低饱和方向。
- 这些色值是视觉校准输入，不是直接落库的 Token；正文和按钮配色仍须通过 WCAG 对比度门禁。

### 10–14 — Pro 自定义图标探索

- 目标：替代当前 `star.fill` / `crown` 的通用会员模板感，为 Pro 建立台球专属身份。
- 第一轮分别测试“精准走线章 / 台边钻石点 / 高手章”；第二轮按 20–52pt 强轮廓要求收紧为两枚。
- 全部要求透明底、无文字、无皇冠/星星/金币/奖杯；生成结果仍出现了渐变与超出小尺寸需要的细节，因此都只算造型草图，不是可直接进 Asset Catalog 的生产资产。

### 15 / 16 — Profile 回填验证

- `15` 把精准走线章同时放进 Pro 大卡和订阅菜单行，验证“台球语义优先”。
- `16` 把台边钻石标放进相同位置，验证“高级与克制优先”。
- 两图只用于比较图标识别与页面气质；最终选中后必须确定性重绘为单色矢量，并在 20/24/32/48/52pt 验证，不从生成 PNG 直接上线。

### 17 / 18 / 19 — 保留原图标的金色材质

- 用户明确放弃自定义 Pro Mark，保留既有五角星和皇冠轮廓；三版只改变 Pro 金色的材质、亮暗与边缘。
- `17` 哑光香槟金：低反光、漫反射和极细颗粒；测试最克制的金属感。
- `18` 细拉丝香槟金：低饱和金、宽柔光、轻微斜向拉丝和边缘压暗；当前推荐方向。
- `19` 柔光象牙金：暖浅金中心、稍深边缘和轻微珐琅质感；测试更明亮柔和的方向。
- 材质只应用于星形、皇冠与其徽章表面；Pro 文字继续使用纯色前景，禁止给小字叠纹理。

### 20 — Dark 细拉丝香槟金

- 以真实 Dark Profile 为 edit target，并以 `18` 为材质参考；保持星形/皇冠轮廓、warning 橙和品牌绿不变。
- Dark 前两次生成分别把星形误做成镂空金币与切面宝石，均已淘汰；`20` 是收紧后的可比较稿。
- `20` 仍比 Light 更容易产生立体描边，证明生产实现必须用确定性 mask 锁轮廓，不能让生成器决定最终边缘。

### 21 / 22 — 独立可裁切材质母版

- 用户确认保留原图标后，使用 Codex 内置 `image_gen` 独立生成 Light / Dark 两张边到边方形材质场，不再从页面 mockup 裁材质。
- `21` 以低饱和 `#C6A15B` 附近的细拉丝香槟金为中心；`22` 以 `#E7D3A0` 附近的浅香槟金为中心，适配 `#1C1C1E` 暗表面。
- 两张都明确禁止文字、Logo、星形、皇冠、金币、珠宝、切面、厚浮雕、边框与中央对象；它们不决定图标轮廓。
- 当前原图保留为设计母版。W3 已按此派生 `btPremiumTexture.imageset`，并由 `BTPremiumMaterialSymbol` 在 24 / 32 / 48pt 使用确定性 SF Symbol mask；小于 24pt、增强对比度或降低透明度时回退纯色。固定炭黑表面使用 `btPremiumOnDark`，不让 Light 页面误取深金。

## 使用限制

1. 文生图可能重绘字体、边缘、间距和图片细节；这些变化一律不进入实现需求。
2. 只比较“第一眼焦点、颜色角色、同屏强调数量、封面整体色调”。
3. 最终实现必须回到项目 Token、SwiftUI 共享组件和真实 66 页截图矩阵。
