# 竞品分析

## 1. 竞品范围

- **直接竞品**（同为台球训练/工具类移动端）：国内暂无；国际：DrillRoom、WPB、ChalkySticks Trainer
- **间接竞品**（台球娱乐/游戏）：台球世界、天天台球、台球大师3D（国内主流）
- **跨赛道参照**（线下 AI 投影硬件，To B 门店）：小铁自助台球、易付乐小易 MP-X、客满台、乔氏以利、谈小娱
- **参照竞品**（运动训练工具通用模式）：Keep、运动类健身 App

> 详细检索笔记见 `docs/research/20260323-竞品分析-台球训练App.md`（移动端 App）与 `docs/research/20260617-AI台球投影系统-硬件竞品.md`（线下硬件投影，不同赛道、互为补充）。

## 3. 可借鉴点与差异化

### 3.1 从竞品可借鉴
- **DrillRoom**：Drill 结构化分类、训练数据可视化（热力图/趋势）、订阅制在训练工具的可行性。
- **AI 投影硬件（已被市场验证的功能）**：分级课程 + 标准化球形库（客满台 200+ 球形、小铁 CBSA 段位测评，证明用户为结构化训练买单）、分离角/走位区域可视化、高光复盘/数据统计。这些可在移动端低成本复刻。

### 3.2 本产品差异化路径（据已建成能力）
1. **交互式「练脑」是已落地的护城河**：物理引擎 + 走位反解 + 斯诺克做杆 + 球形生成 + 拍照建球形——国内 C 端 App 无同类，且短视频/硬件都给不了「自己摆球反解、即时反馈」的练判断体验。
2. **诚实处理物理**：硬件投影多给「理想无塞线」；本产品显式区分**理想薄厚点 vs 带塞修正**，讲清「为什么这么瞄」（契合 `geometry-spatial-reasoning` 技能与 `docs/10-解球线路原理.md`），教学价值高于一条投影线。
3. **中文本土化 + 系统知识库**：中式台球/斯诺克的系统理论 + Drill（理论↔内容挂接 P12），是硬件门店方案普遍偏弱的环节。
4. **零硬件门槛 + 学练记闭环**：随身可用、训练日志/复盘完整，覆盖家庭/碎片化/赛前复盘等硬件触达不到的场景。
5. **内容生产能力（潜在杠杆）**：教学素材渲染管线能近零成本量产可视化讲解，既是获客引擎也是潜在 B 端/内容工厂上行（见 `docs/01` §8）。

## 4. 风险与机会

| | 说明 |
|---|---|
| **机会1** | 国内 C 端「严肃训练工具」完全空白，无直接竞品；中文 + 中式台球/斯诺克是 DrillRoom 盲区 |
| **机会2** | AI 投影硬件是重资产/To B/绑场地赛道，与本产品（轻量/To C/随身）**不直接竞争**；其已验证的「分级课程、分离角/走位可视化、数据复盘」可在移动端低成本复刻，且本产品已有更强的端上物理引擎 |
| **机会3** | 物理/几何引擎 + 内容渲染管线可反向供给硬件/门店或当内容工厂（潜在 B 端上行） |
| **风险1** | DrillRoom 若推出中文版，直接降维打击核心 drill/记录功能 |
| **风险2** | 抖音/B站 若推出站内工具功能，削弱知识内容差异化 |
| **风险3** | 教学内容质量与权威：缺可信教练 IP 时，AI/引擎生成内容若不准会损害信任（与 `docs/01` §5「需补真人 IP」对应） |
| **风险4（最关键）** | C 端付费意愿未被真实数据验证、台球训练 C 端盘子小——商业天花板风险（见 `docs/00-讨论记录.md` 2026-06-18 商业价值评估） |
