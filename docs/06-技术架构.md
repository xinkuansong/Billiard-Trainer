# 技术架构

> v0.5（2026-03-29）描述的是「Canvas 画球台 + 纯本地几何」的轻量栈；此后为 P9–P17 的交互式练脑工具实际引入了 SceneKit + 物理引擎 + 渲染/音频管线。本版补全。实现细节以代码与 `tasks/PROGRESS.md` 为准。

## 1. 架构概览

```
┌──────────────────────────────────────────────────────────────┐
│                       iOS App（SwiftUI）                        │
│   训练 │ 动作库 │ 角度 │ 历史 │ 我的                              │
│                                                                │
│   表现层（SwiftUI + SceneKit）                                  │
│   ├── 通用页面：SwiftUI                                          │
│   ├── 球台 2D/3D：SceneKit（USDZ 真台 + 16 球 + 球杆）           │
│   └── 球台动画/缩略图：SceneKit 渲染（离线烘焙 + live 回放）     │
│                                                                │
│   领域层                                                        │
│   ├── 物理引擎 Core/Physics（pooltool Swift 移植，事件驱动）     │
│   ├── 几何/解球 AngleSceneCalculator / 反射 / 单应 Homography   │
│   ├── 走位反解 PositionPlaySolver / 球形 RackLayout+Break       │
│   ├── 音频 Core/Audio（击球音效调度）                            │
│   └── 教学素材渲染 Core/Media（SequenceVideoExporter，工具侧）   │
│                                                                │
│   本地层（SwiftData，离线主存储）                                │
│   ├── 训练记录 / 角度测试历史（离线可用，后台同步）              │
└──────────────────────────────────────────────────────────────┘
          │ 用户数据                         │ 公开内容
┌──────────────────────────────────────────────────────────────┐
│            自建 REST API（腾讯云 Node.js + MongoDB）            │
│  认证：微信 OAuth / 手机验证码 / SiWA → JWT                     │
│  私有数据：训练记录、角度测试、设置                             │
│  公开只读（OTA）：Drill JSON、官方计划（Bundle 保底）            │
│  大体积素材（视频）：走 OTA / CDN，不进 Bundle（H-14 待办）      │
└──────────────────────────────────────────────────────────────┘
```

**核心原则**：
- **离线优先**：训练记录、角度测试、动作库浏览、所有几何/物理工具均**纯端上计算**，无网（球馆）可完整使用。
- **物理在端上、视频在云上**：物理引擎/反解/球形生成全部端上实时跑；体积大的成品教学视频走 OTA（`Resources/Videos/` 一度 257MB，是 ADR-P11-10 决策起因）。
- **渲染单一真源**：App 内 2D/3D、缩略图烘焙、教学视频导出**共用同一 SceneKit 场景与物理轨迹**，保证「画面=物理」一致。
- **内容热更新**：Drill / 官方计划 Bundle 保底 + REST 增量；理论 contracts（项目16）规划中（P12）。
- **跨平台就绪**：REST API iOS/Android 共用。

## 3. 用户认证方案（自建 REST API）

> 与 v0.5 一致：微信登录 / 手机验证码 / Sign in with Apple 三选并存 → JWT（Access 1h + Refresh 30d，Keychain）。当前**仅 Sign in with Apple 已接入**；微信/短信被 H-05（微信开放平台资质）/ H-15（腾讯云短信）阻塞，待恢复。匿名用户可浏览动作库、用全部几何/物理工具与角度训练，记录仅本地。

```
POST /auth/login-wechat { code }      → 换 unionid → JWT
POST /auth/login-sms    { phone, code } → 腾讯云短信验证 → JWT
POST /auth/login-apple  { identityToken } → Apple 公钥验证 → JWT
```

## 5. 物理引擎（核心横向能力）

**来源**：完整移植自 **pooltool** 的事件驱动物理引擎（`QiuJi/Core/Physics/`，15+ 文件）。

**关键组成**：
- `EventDrivenEngine`：事件调度 + 解析运动（`EngineNumerics`/`AnalyticalMotion`），确定性有序遍历（`ballOrder`）。
- `Han2005CushionModel`：库边闭式解（O(1)，非积分循环）。
- 球-球碰撞：pooltool `_resolve_ball_ball`（滑移 + 无滑移 1/7、5/14 + Alciatore 摩擦）。
- `CueBallStrike`：z-up 求解 → SceneKit y-up 映射；杆 5 参数（V0/phi/theta/a/b）对齐教学语义（力/瞄准角/抬杆/左右塞/高低塞）。
- 袋口：**漏斗喉腔模型**（jaw 库 + 喉腔侧/后壁 + 物理落袋孔），rattle 由几何自然涌现。
- `TableGeometry.chineseEightBallQiuJi`：对齐 USDZ 实测的中式八球桌几何（袋口/库段/jaw）。
- 门面 `ShotPredictor`：摆球+袋口+力度+塞 → 两球轨迹/分离角/进袋判定；**显示层已彻底下沉、轨迹/判定全裸取引擎纯物理**（ADR-P10-06/07）。

**质量保障**：不变量测试 + 系统化组合矩阵 + 真实球理场景（约 3800+ 被断言场景）+ 性能门槛（单杆 predict 中位 ~125ms / 满台 ~663ms）。

**诚实边界**：
- **2D 平面物理**——跳球/扎杆腾空无法表达；3D 视频只换相机视角，物理仍是平面。
- 常量（e_b / 台呢库边摩擦 / 恢复系数）尚未用真实俯拍视频精标定（待办，用 `PhysicsBenchmarkTests` 钉死）。
- **工程纪律（2026-06-18）**：2D 物理已够教学用，不再扩物理新功能。

## 6. 球台渲染与教学素材管线

### 6.1 App 内渲染（SceneKit）
- `AngleTrainingScene`：USDZ 真台 + 球节点 + 球杆；顶视 2D / 2D 旋转 / 透视 3D；自适应取景 `fitRotatedTable`（按视口宽高比算正交 scale，全台可见不变量）。
- 出杆动画单一真源 `CueStroke`（回杆 `d=a+k·v` → smoothstep → 匀加速出杆触球 → 跟杆减速停留 → 收杆），App 内回放与导出同源。
- 缩略图：离屏 `SCNRenderer` 烘焙 PNG（`DrillThumbnailRenderer`），运行时 NSCache 秒加载。

### 6.2 教学素材离线渲染（工具侧，非用户运行时）
- `Core/Media/SequenceVideoExporter`：逐帧 `SCNRenderer.snapshot` → `VideoWriter`(AVAssetWriter mp4) / `GIFEncoder`(CGImageDestination)。
- 渲染矩阵：teaching(1280×720,带击球参数 HUD) / card / gif 三 preset；2D 顶视正交 + 3D 斜视角（720×1280 OTA 档 + 1440×2560 高分档）双相机模式。
- 入口仅模拟器构建可见（`#if targetEnvironment(simulator)` 编译闸即产品开关）；产物 mp4 走 OTA 不进 Bundle。

## 7. 击球音频（Core/Audio）

- `ShotSoundBank`（AVAudioEngine + 12 player 池，`AVAudioConverter` 统一格式，`.ambient + .mixWithOthers` 尊重静音键、与休息计时器后台音频共存，缺资源 no-op）。
- `ShotAudioScheduler`：消费 `ShotPrediction.events`，按真实时刻 `DispatchWorkItem` 排程、可取消；力度由 recorder 球速近似；**刻意不变调**，靠多样本池避免游戏味。
- 设置「声音·击球音效」开关；所有回放/导出原速。
- 资产：`Resources/Audio/` folder reference（drop-in `sfx_*.caf` 重新构建即生效）；**真实 CC0 录音待人工补齐（H-18）**。

## 9. 安全与隐私

- 用户训练数据存自建 MongoDB，私有，需 JWT；匿名数据仅本地 SwiftData 不上传。
- 微信仅取 OpenID + 昵称/头像；手机号后端 hash 存储不明文。
- 不收集：位置、通讯录、相机（拍照建球形为用户主动拍摄、单次使用不上传）、健康数据。
- App Store 隐私清单：账号信息（手机号）、使用数据（训练记录）、标识符（用户 ID）。
