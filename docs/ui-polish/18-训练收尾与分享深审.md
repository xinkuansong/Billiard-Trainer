## 页面概述

**TrainingNoteView**  
结束训练后的心得编辑：编号提示 + 多行 `TextEditor` + 500 字软限制提示 +「跳过 / 完成」；`onAppear` 自动聚焦键盘。

**TrainingSummaryView**  
成就总结页：2×2 统计卡 + 全宽成功率条、分 drill 明细与心得回显；底栏「保存训练 / 生成分享图 / 查看历史」，工具栏亦有分享图标。

**TrainingShareView**  
分享定制 sheet：上方 `BTShareCard` 预览，下方字体/主题/隐藏选项 + 微信/相册/返回。

**BTShareCard（分享流程用法）**  
多主题暗底导出卡：品牌头、计划名、drill 列表、三列统计、品牌脚+二维码占位；本轮只评对比度、预览一致性与主题选择反馈。

**TrainingDetailView**  
历史中的单次训练详情：横滑微统计、drill 卡组行、心得；底栏编辑/复制 + 溢出菜单（功能未接线，见 07 存疑）。

## Findings

### F-TS-01 总结页成就数据瞬时满值，无生长/仪式感进场
- **类别**：A动效 / B微交互
- **位置**：`QiuJi/Features/Training/Views/TrainingSummaryView.swift:74-81`（统计数字）；`111-120`（成功率条）；父级阶段切换 `ActiveTrainingView.swift:59`
```swift
Text(value)
    .font(.btStatNumber).fontWeight(.heavy)
// ...
Capsule()
    .fill(Color.btPrimary)
    .frame(width: geo.size.width * overallSuccessRate)
```
- **现状**：进入 `.summary` 时数字与进度条一次性以终值呈现；无 `contentTransition(.numericText)`、无条宽从 0 生长、无分区 stagger。父级仅有 `easeInOut(0.3)` 包住 phase 切换，子视图无专属进场 transition。
- **问题**：对照 **A3**（低频成就时刻允许 delight）、**A6**（突现）、**B3**（完成反馈应可感知）。这是训练收尾的高潮页，却比高频记分页（`DrillRecordView` 成功率已有 `numericText`）更「平」。
- **建议**：进场时成功率条用面板档 spring（`response: 0.34, dampingFraction: 0.86`）从 0→目标宽度（≤400ms）；四张统计数字加 `contentTransition(.numericText)` + 短 spring；可选卡片 `opacity + offset` 错峰 40–60ms。勿用 `scale(0)`。
- **语义影响**：无（只改呈现节奏，数值与保存逻辑不变）。
- **严重度**：P2

### F-TS-02 「保存训练」成功路径无完成反馈即 dismiss
- **类别**：B微交互
- **位置**：`ActiveTrainingView.swift:36-40`；`ActiveTrainingViewModel.swift:540-573`
```swift
onSave: {
    viewModel.saveTraining(context: modelContext)
    if viewModel.didSaveSuccessfully {
        dismiss()
    }
}
```
- **现状**：点「保存训练」同步 `save` 成功后立刻 `dismiss()`；`TrainingSummaryView` 按钮无 loading/禁用态；成功无 toast/短确认。失败有「保存失败」alert（B3 半边闭环），成功边沉默离场。
- **问题**：对照 **B3**——进行时与完成反馈；成就闭环在「落盘」这一刻被切断，用户不确定是否已写入历史。
- **建议**：保存中禁用主钮并显示短文案「保存中…」；成功后先非阻断 toast「已保存」（与 F-OV-04 建议的短成功形态对齐）再 dismiss，或 dismiss 后在训练首页/历史入口给一次性确认。勿再叠阻断 alert。
- **语义影响**：无（仍是保存后离开会话，只补反馈时序）。
- **严重度**：P2

### F-TS-03 主题色圈几乎同色，选择器难辨认
- **类别**：C视觉 / B微交互
- **位置**：`QiuJi/Core/Components/BTShareCard.swift:40-60`；用法 `TrainingShareView.swift:131-140`
```swift
var previewColor: Color { backgroundColor }
// defaultGreen/blackWhite/nightBlue/deepPurple 底均为近黑 #0D–#1C
Circle().fill(theme.previewColor) // 40×40
```
- **现状**：四主题 `previewColor` 直接等于暗底 `backgroundColor`，色圈在浅色/暗色面板上均呈近黑圆点，仅靠 2pt 描边与小字标签区分；「基础绿」色圈也不含绿色。
- **问题**：对照 **C2**（权重/可辨识）、**B2**（定制应即时可感知差异）。用户扫视无法预判主题差异，削弱 WYSIWYG 前期选择。
- **建议**：`previewColor` 改为主题 `accentColor`（或底色+accent 双环：外圈底、内点 accent）；选中环保持 `btPrimary`。
- **语义影响**：无（四主题与卡片渲染不变，只改选择器色样）。
- **严重度**：P2

### F-TS-04 「隐藏球台图」开关切换后预览无变化
- **类别**：B微交互
- **位置**：`TrainingShareView.swift:52`、`164`；`BTShareCard.swift:82`（属性声明后全文无引用）
```swift
BTShareCard(..., hideBallTable: hideBallTable)
togglePill("隐藏球台图", isActive: $hideBallTable)
// BTShareCard: var hideBallTable: Bool = false  // body 未消费
```
- **现状**：与 F-TR-02（隐藏备注未传入）不同：本开关**已传入**卡片，但组件 body 无球台区、亦不读该参数；pill 有动画，预览不变。
- **问题**：对照 **B3**——控件与可见结果脱节，假交互。
- **建议**：若近期无球台导出区，暂时隐藏该 pill；若要保留 API，须在卡片内渲染可隐藏的台面示意并响应参数（与 12 存疑「补台面 vs 清 API」一并裁决）。
- **语义影响**：无（对齐开关与预览，不增删分享渠道）。
- **严重度**：P2

### F-TS-05 心得页声明 interactive 键盘收起，但无 ScrollView 承载
- **类别**：B微交互
- **位置**：`TrainingNoteView.swift:14-38`
```swift
VStack(spacing: 0) { hintSection; editorSection; Spacer; … bottomBar }
.scrollDismissesKeyboard(.interactively)
.onAppear { isEditorFocused = true }
```
- **现状**：根容器是 `VStack` 而非 `ScrollView`；`.scrollDismissesKeyboard(.interactively)` 对非滚动容器基本无效。自动聚焦后，空文案时用户无法靠「拖内容」收键盘；亦无键盘工具栏「完成」、无点空白 `resignFirstResponder`。只能点「跳过/完成」离页，或依赖系统键盘键（若有）。
- **问题**：对照 **B3**（状态可恢复）、编辑场景的基本微交互闭环。
- **建议**：外层改 `ScrollView`（或 `ScrollView` + 固定底栏 `safeAreaInset`）以兑现 interactive dismiss；或加 `@FocusState` + 键盘 Toolbar「完成」收焦。底栏勿被键盘长期遮挡。
- **语义影响**：无（仍编辑同一 `note` binding）。
- **严重度**：P2

### F-TS-06 历史详情与总结页同类信息形态不一致（缺成功率）
- **类别**：D一致性 / C视觉
- **位置**：
  - 总结：`TrainingSummaryView.swift:46-57`、`90-120`（2×2 +「平均成功率」条）
  - 详情：`TrainingDetailView.swift:99-109`（横滑微统计无成功率）；`309-314`（`overallRate` 已计算但未展示）
```swift
statItem(value: "\(totalBallsMade(session))", label: "进球")
// … 组 / 分钟 / 时段 / 日期 —— 无成功率
private func overallRate(_ session: TrainingSession) -> Double { … } // 未调用
```
- **现状**：同一训练会话：总结页把成功率做成主角；详情页横滑五列却漏掉，导致回看时成就感降级。drill 行：总结有「N%」彩色成功率，详情仅 `made/target`。缩略图亦不同（`BTTrainingIcon` vs 手写毡台）。
- **问题**：对照 **D2**（同类信息同形态）、**C2**（权重匹配——成功率在总结是主角，详情消失）。
- **建议**：详情 `statsRow` 增加「成功率」列（复用已有 `overallRate`），格式与总结一致为整数百分比；drill 行右侧补成功率色（可复用总结的 `drillRateColor` 阈值）。缩略图形态收编可另开 P3。
- **语义影响**：无（展示已有计算结果，不改编辑/复制能力）。
- **严重度**：P2

### F-TS-07 分享定制主操作与主题圆缺少按压态
- **类别**：B微交互
- **位置**：`TrainingShareView.swift:146-149`（主题 `onTapGesture`）；`218-235`（分享钮 `.buttonStyle(.plain)`）
```swift
.onTapGesture {
    withAnimation(.easeInOut(duration: 0.2)) { selectedTheme = theme }
}
// ...
.buttonStyle(.plain) // shareButton：微信/相册圆钮
```
- **现状**：主题切换非 `Button`，无 scale/高亮；三个主分享圆钮显式 `.plain`，无 `BTButtonStyle` 的 0.98 scale。字体/`togglePill` 为 `Button` 默认高亮，同区手感分裂。
- **问题**：对照 **B1**（可点元素应有按下即时反馈）。
- **建议**：主题圆改为 `Button` + 轻 scale（0.96–0.98）；分享圆钮抽小型 `ButtonStyle` 或按压缩放，与库内 primary 参数对齐。
- **语义影响**：无。
- **严重度**：P2

### F-TS-08 分享页顶栏与底栏双「返回」
- **类别**：C视觉
- **位置**：`TrainingShareView.swift:25-35`（toolbar cancellation）；`206-212`（底栏文字「返回」）
```swift
ToolbarItem(placement: .cancellationAction) { … Text("返回") }
Button { dismiss() } label: { Text("返回") }
```
- **现状**：同一 `dismiss` 暴露两次；底栏右侧弱文案与左侧三个强色圆钮并列，扫描时多一个同等动词出口。
- **问题**：对照 **C4**（一屏焦点）、**C2**（次操作权重）。
- **建议**：保留顶栏取消即可；底栏去掉「返回」，或改为仅图标关闭与顶栏二选一。
- **语义影响**：无（仍可关闭 sheet）。
- **严重度**：P3

### F-TS-09 「基础绿」主题名与色样/底色不符
- **类别**：C视觉（文案）
- **位置**：`BTShareCard.swift:33`、`42`、`51`
```swift
case defaultGreen = "基础绿"
// backgroundColor → #1C1C1E（近系统深灰）
// accentColor → .btPrimary
```
- **现状**：标签承诺「绿」，色圈与卡底实为炭灰，绿色仅出现在高成功率数字的 accent。与「暗夜蓝 / 深紫」按底色命名的规则不一致。
- **问题**：对照 **C6**（叫法与所见一致）。
- **建议**：改名「基础深色 / 炭黑」等与底一致；或让 `defaultGreen` 底偏绿毡色且保证白字对比度。
- **语义影响**：无（主题枚举与渲染可保持，只改展示名或底色观感）。
- **严重度**：P3

### F-TS-10 心得字数提示显隐无过渡
- **类别**：A动效
- **位置**：`TrainingNoteView.swift:26-30`
```swift
if !note.isEmpty {
    characterCountHint
        .padding(.horizontal, Spacing.lg)
        .padding(.bottom, Spacing.xs)
}
```
- **现状**：首字输入 / 清空时字数行直接插入或移除，底栏被顶一下，无 opacity/移动过渡。
- **问题**：对照 **A6**（突现突消）。低频页可接受短过渡。
- **建议**：加 `.transition(.opacity.combined(with: .move(edge: .bottom)))` + 短 spring/`easeOut`≤200ms；或始终占位用透明字数避免布局跳变。
- **语义影响**：无。
- **严重度**：P3

### F-TS-11 短于 1 分钟的训练在总结/分享显示「0 分钟」
- **类别**：C视觉 / B微交互
- **位置**：`TrainingSummaryView.swift:17`；分享构建 `ActiveTrainingView.swift:176`
```swift
private var durationMinutes: Int { elapsedSeconds / 60 }
durationMinutes: viewModel.elapsedSeconds / 60,
```
- **现状**：整除向下取整；试打收尾或短会话总结卡/分享卡写「0 分钟」，成就数据失真感强。
- **问题**：对照 **C6**（文案诚实）、成就页数据可信度。
- **建议**：`< 60s` 显示「不足 1 分钟」或「N 秒」；≥60s 再显示分钟。分享卡 `durationMinutes` 同步同一格式化函数。
- **语义影响**：无（仍记录同一 `elapsedSeconds`，只改展示粒度）。
- **严重度**：P3
