## 2. 交叉分析：188 条聚成 8 个系统性主题

逐页看是 188 个点；横向看是 8 类根因。**修根因一次能消一簇**，这是 W2 拆批的依据。

### 主题 ① 按压态缺失（最大簇，约 25 条）

根因在组件层：`BTTextActionButton` / `BTChipRow` / `BTFloatingIndicator` / `BTExerciseRow` 等全用 `.buttonStyle(.plain)` 无按压反馈（**F-GL-02** 是根条目），页面手写胶囊继承同一缺口。`BTButton` 家族已有 0.98 scale + `easeInOut(0.1)` 标准，只是没下沉。

- 组件根因：F-GL-02、F-GL-08
- 页面成员：F-TR-03/06/10、F-DL-03/04、F-AK-01/03/04/06、F-SA-05、F-BK-03、F-PP-02、F-HI-02、F-PF-03/04、F-SC-05、F-BD-04；深审新增 F-PL-06/07、F-AT-06（会话底栏五钮同栏分裂）、F-TS-07、F-DD-06、F-TU-04

**修法**：新增轻量 `BTPressableStyle`（scale 0.96–0.98 + `easeInOut(0.1)`，token 名 `btPress`），先挂组件层，再扫页面手写胶囊。

### 主题 ② 突现突消 / 状态切换无过渡（约 20 条）

模式高度一致：`if 条件 { 视图 }` 直接插拔，无 `withAnimation` + `.transition`；或声明了 transition 但没有驱动动画（F-SA-01、F-ST-03——「写了不生效」最值得先修）。

- 前两轮：F-AK-02、F-SA-01/02/06、F-BK-02、F-PP-03/08、F-HI-01、F-DL-05、F-BD-06、F-ST-03、F-CL-03
- 深审新增：F-PL-04（激活底栏三态硬切）、F-PL-05（官方/自定义分段内容硬切）、F-PL-08（构建器列表增删跳变）、F-PL-11 / F-AT-03（chevron 符号硬换应旋转）、F-AT-02（勾选完成硬切）、F-AT-09（统计条完成态硬切）、F-TS-10、F-DD-07（收藏无过渡）、F-TU-10（媒体全屏突现）

**修法**：统一句式——状态布尔变更包 `withAnimation(.easeOut(0.2~0.25))` 或基准 spring，视图侧 `.transition(.opacity)`；chevron 用单一图标 + `rotationEffect`；进场缩放一律从 0.95 起。

### 主题 ③ 反馈诚实性：假成功 / 静默失败 / 进行时缺失（约 25 条，含 P1×5）

四条子线：
- **假反馈 / 假数据**：F-TR-01 假保存、F-TR-02 死开关、F-TS-04「隐藏球台图」死开关（传入未消费）、F-CL-05 死参数缩略位、F-DD-02 训练维度百分比由启发式编造伪装测评、F-DD-03 无视频铺三枚幽灵缩略图；
- **静默失败**：F-PF-01 购买失败、F-HI-03、F-ST-01、F-SC-03、F-TU-01 配图蒸发（P1）、F-TU-11 训练中点精讲失败无反馈、F-BD-02/F-PP-05 语义色错位；
- **完成反馈缺失**：F-PL-01 激活后首页不刷新（P1）、F-PL-03 列表激活无完成标、F-TS-02 保存训练成功静默 dismiss、F-AT-08 DrillPicker 添加行内无确认；
- **进行时缺失**：F-PF-02/05/07、F-PP-04、F-SA-03/F-SC-01、F-HI-04、F-BD-03。

**修法**：无共享代码根因，逐条修；F-OV-03 的共享 toast（tone）落地后有统一露出通道。
