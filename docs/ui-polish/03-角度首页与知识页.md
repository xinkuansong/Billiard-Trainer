# UI 打磨审阅：角度首页与知识/测验页（AK）

**范围文件**：`AngleHomeView` · `ContactPointTableView` · `AimingPrincipleView` · `AngleDynamicView` · `GeometricAngleQuizView` · `BallFeelView` · `AngleHistorySection` · `AngleSessionDetailView` · `NumericKeypadHUD`（均在 `QiuJi/Features/AngleTraining/Views/`）

**未审（范围外）**：`SceneAimingView` / `BankShotView` / `DiamondSystemView` / `ShotSimulationView` / `AimPoint*`

---

## 页面概述

- **AngleHomeView**：练习 Tab 入口枢纽——大标题 + 搜索 + 左栏「全部/学/练/打/解」+ 右双列封面卡网格；核心交互是分类筛选与点卡进子页。
- **AimingPrincipleView / ContactPointTableView / BallFeelView**：知识讲解长页——真台插图 + 公式/对照表/视角对比；ContactPoint 另有滑条驱动几何图与估角演示；无求解/击打。
- **AngleDynamicView**：暗色场景沙盘——拖球、点袋、球库加减球，顶栏实时切角/厚度/d/R 指标；核心交互是拖动与袋口选择。
- **GeometricAngleQuizView**：暗色估角测验——真台角扇题面 +「换题/参考/答题」胶囊 + `NumericKeypadHUD` 输入；结果卡给误差评级与导流。
- **NumericKeypadHUD**：应用内数字键盘覆层（读数 + 3×4 键 + 取消/提交），被测验页 `safeAreaInset` 唤起。
- **AngleHistorySection / AngleSessionDetailView**：训练统计嵌入块与单次会话明细——筛选 chips、时段分段、趋势图、题列表；只读复盘，无台面演示。

## Findings

### F-AK-01 角度预测主操作胶囊无按压态
- **类别**：B微交互
- **位置**：`QiuJi/Features/AngleTraining/Views/GeometricAngleQuizView.swift:184-198`
  ```swift
  .buttonStyle(.plain)
  ```
  （同文件 `sceneCapsuleButton` `:180` 亦为 `.plain`）
- **现状**：「换题 / 显示参考 / 答题 / 下一题 / 解锁」均为手写 Capsule + `.buttonStyle(.plain)`，按下无 scale / opacity 变化。同范围 `NumericKeypadHUD` 的 `KeypadKeyStyle`（scale 0.95）已有按压范例；设计系统 `BTButtonStyle` 亦普遍带 0.96–0.98 scale。
- **问题**：对照基准 **B1**——主要操作按钮无按压态 = P2。
- **建议**：抽一个与场景胶囊外观解耦的 `ButtonStyle`（对齐 `KeypadKeyStyle` 或 `BTButtonStyle` 的 `scaleEffect(0.96…0.98)` + ≤100ms easeOut），挂到 `actionChip` / `sceneCapsuleButton`；不改胶囊颜色与文案。
- **语义影响**：无（仅反馈层，不改变答题/换题/订阅流程）。
- **严重度**：P2

### F-AK-02 结果卡与数字键盘突现突消
- **类别**：A动效
- **位置**：`GeometricAngleQuizView.swift:28-31`（`if vm.showResult { resultSection }`）；`:145-161`（`keypadInset` 的 `if isInputting…`）；无 `.transition` / `withAnimation`
- **现状**：提交后结果卡、点「答题」后键盘均以条件视图硬切进出；无 opacity / move 过渡。对比同模块 `AngleDynamicView` 状态条已用 `.transition(.move(edge: .bottom).combined(with: .opacity))` + 0.25s 动画。
- **问题**：对照基准 **A6**——元素出现/消失无过渡造成跳变 = P2。
- **建议**：对 `resultSection` / `NumericKeypadHUD` 外包层加 `.transition(.opacity.combined(with: .move(edge: .bottom)))`，在 `showResult` / `isInputting` 变更处用 `withAnimation(.easeOut(duration: 0.22))`（或基准面板 spring `0.34/0.86`）包裹；时长 ≤300ms。
- **语义影响**：无（不改变答题判定、键盘提交/取消语义）。
- **严重度**：P2

### F-AK-03 练习首页入口卡与侧栏无按压反馈
- **类别**：B微交互
- **位置**：`AngleHomeView.swift:330-354`（`sidebarItem` → `.buttonStyle(.plain)`）；`:373-376`（`NavigationLink` → `.buttonStyle(.plain)`）；`PracticeCTA` `:541-542` 同
- **现状**：高频侧栏切换与全屏主入口网格卡、学页导流卡均为 plain，按下无即时视觉反馈（无 scale/高亮）。
- **问题**：对照基准 **B1**。
- **建议**：为侧栏与网格卡各加轻量 `ButtonStyle`（建议 scale 0.97–0.98、≤100ms）；`PracticeCTA` 复用同一风格。勿改路由与卡片内容。
- **语义影响**：无（不增删入口、不改分类模型）。
- **严重度**：P2

### F-AK-04 角度与瞄准·球库 token 点击无按压态
- **类别**：B微交互
- **位置**：`AngleDynamicView.swift:226-243`
  ```swift
  .onTapGesture {
      if onTable { vm.removeFromTable(key) } else { vm.placeFromPalette(key) }
  }
  ```
- **现状**：球库用 `onTapGesture` 而非 `Button`+`ButtonStyle`；上桌/撤下瞬间无 scale/opacity 反馈（仅靠事后 `opacity(onTable ? 0.3 : 1)` 状态色）。
- **问题**：对照基准 **B1**（可点元素应有按下即时反馈）；球库属高频操作，反馈应短促。
- **建议**：改为 `Button` + 短按压 style（scale ≈0.92–0.96、easeOut ≤80ms），或 `simultaneousGesture` 保留现逻辑并加 `isPressed` 视觉；不改 `placeFromPalette` / `removeFromTable` 语义。
- **语义影响**：无。
- **严重度**：P2

### F-AK-05 角度预测「重置统计」无确认
- **类别**：B微交互
- **位置**：`GeometricAngleQuizView.swift:46-50`
  ```swift
  Button { vm.resetStatistics() } label: {
      Image(systemName: "arrow.counterclockwise")
  }
  ```
- **现状**：导航栏一键清空次数/正确率/平均误差等会话统计，无 `confirmationDialog` / 撤销。
- **问题**：对照基准 **B4**——破坏性操作应有确认或可撤销。
- **建议**：加 `confirmationDialog`（文案如「清空本页练习统计？」）或 Toast+撤销；勿改 `resetStatistics` 清哪些字段。
- **语义影响**：无（仍是同一重置能力，仅加防误触）。
- **严重度**：P2

### F-AK-06 历史筛选 chips 手写且无按压，与 segmentedPill 未对齐
- **类别**：D一致性
- **位置**：`AngleHistorySection.swift:41-63`（手写 Capsule `Button`，无 `buttonStyle` 按压）；对比 `BTButtonStyle.segmentedPill`（`BTButton.swift:147-166`，含 `scaleEffect(0.96)`）
- **现状**：测验类型筛选视觉接近 `segmentedPill`（选中 btPrimary 实底、未选描边），但未复用该 style，按下无反馈；同文件时段筛选已用 `BTSegmentedTab`，形态分裂。
- **问题**：对照基准 **D4**（手写替身）+ **B1**。
- **建议**：筛选 chips 改挂 `BTButtonStyle.segmentedPill(isSelected:)`，或抽共享 style 与首页侧栏/测验胶囊统一按压参数；保持现有 filter 枚举与文案。
- **语义影响**：无。
- **严重度**：P3

### F-AK-07 球库底栏硬编码近黑底色
- **类别**：D一致性
- **位置**：`AngleDynamicView.swift:205`
  ```swift
  .background(Color(white: 0.11))
  ```
- **现状**：底栏球库使用 `Color(white: 0.11)`，未走 `btBG*` 语义色；同页顶栏已 `Color.black` + dark environment，底栏与全站 surface 阶梯脱节。
- **问题**：对照基准 **D3**（硬编码颜色属一致性收编；台面/球体渲染豁免——此处为 UI chrome）。
- **建议**：改为 `Color.btBG` / `btBGSecondary`（或既有 HUD 底 token），在 forced dark 环境下核对对比度；不改球库交互。
- **语义影响**：无。
- **严重度**：P3

### F-AK-08 NumericKeypadHUD 键间距与标题字号 token 逃逸
- **类别**：D一致性
- **位置**：`NumericKeypadHUD.swift:27-28`（标题 `.system(size: 13, weight: .semibold)`）；`:57` / `:61` / `:83`（`VStack`/`HStack` spacing `6`）
- **现状**：标题未用 `btFootnote`/`btCaption`；键间距 `6` 非 `Spacing.xs(4)`/`sm(8)`。按压动效本身良好（`:145-151`）。
- **问题**：对照基准 **D3**。
- **建议**：标题改 `.font(.btFootnote.weight(.semibold))`（或 btCaption + semibold）；键间距收编为 `Spacing.xs` 或 `sm`（择一并全键盘统一）；勿改 `compact` 键高语义。
- **语义影响**：无。
- **严重度**：P3

### F-AK-09 首页封面 chip 与 PracticeCTA 图标字号硬编码
- **类别**：D一致性
- **位置**：`AngleHomeView.swift:492`（chip `.font(.system(size: 10, weight: .heavy))`）；`:516` / `:530`（PracticeCTA 图标 `.system(size: 20)` / chevron `.system(size: 13)`）
- **现状**：封面角标可用 `btMicro`（token 即为 10pt）；CTA 图标/chevron 未走 `btTitle`/`btFootnote` 等 token。封面大字水印 56pt 属海报内容渲染，可豁免。
- **问题**：对照基准 **D3**。
- **建议**：chip → `.font(.btMicro.weight(.heavy))`；CTA 图标/chevron 映射到最接近的 `Font.bt*`；保持渐变封面与导流路由不变。
- **语义影响**：无。
- **严重度**：P3

### F-AK-10 对照表核心角度读数未用展示级 token
- **类别**：D一致性
- **位置**：`ContactPointTableView.swift:72-74`
  ```swift
  Text("\(Int(sliderAngle))°")
      .font(.system(size: 32, weight: .heavy, design: .rounded))
  ```
- **现状**：单屏核心角度读数手写 32pt heavy；`Typography` 已有 `btLargeTitle`（32 bold rounded）与 `btDisplaySmall`（30）。同页估角误差 `:250` 亦为 `.system(size: 22, …)`，接近 `btStatNumber`(24)。
- **问题**：对照基准 **D3**（页面 chrome/读数应用 token；非 Canvas 内标注）。
- **建议**：主角度改 `.font(.btLargeTitle)`（或 `btDisplaySmall` 若需略小）；估角 Δ 改 `.btStatNumber`；字重若需 heavy 可用 token + `.weight(.heavy)`。
- **语义影响**：无（数值与滑条绑定不变）。
- **严重度**：P3

### F-AK-11 历史「角袋/中袋」局部开关与 BTSegmentedTab 形态分裂
- **类别**：D一致性
- **位置**：`AngleHistorySection.swift:149-168`（手写双段 `pocketToggle`）；对比同文件 `:22-23` 已用 `BTSegmentedTab`
- **现状**：时段用组件库分段；图例旁角袋/中袋又手写一套圆角矩形分段，间距/选中态与 `BTSegmentedTab` 不一致，且仅外层 `withAnimation(0.2)` 无按压缩放。
- **问题**：对照基准 **D2**（同类交互同形态）+ **D4**。
- **建议**：改为两选项的 `BTSegmentedTab`，或视觉参数对齐该组件；保留 `selectedSegment` 驱动图表逻辑。
- **语义影响**：无。
- **严重度**：P3

### F-AK-12 学页导流卡与测验次要链路面板层级靠「加底+描边」堆叠
- **类别**：C视觉
- **位置**：`AngleHomeView.swift:533-539`（`PracticeCTA`：`btBGSecondary` + `btPrimary.opacity(0.35)` stroke）；知识页末复用该组件
- **现状**：导流卡在已有卡片底上再描品牌色边，一屏内强调手段偏「加框」；正文层级已够（headline + caption），描边使导流与章节卡抢权重。
- **问题**：对照基准 **C4**——优先用字重/字号/颜色深浅建层级，而非加边框加底色；强调元素宜克制。
- **建议**：去掉或弱化 stroke（改左侧 3pt `btPrimary` 条，或仅靠图标圆 + 文案层级）；保持 `NavigationLink` 目标不变。
- **语义影响**：无（仍是同一学→练导流）。
- **严重度**：P3

## 存疑项（不确定是否越红线的，单独列出待主控裁决，不算 finding）

1. **「3/4 球」跨页角度不一致**：`AimingPrincipleView` 厚薄卡写 `3/4 球 · 14.5° · overlap 0.75`（`:299`）；`BallFeelView` 锚点卡写 `3/4 球 · 48.6° · overlap 0.25`（`:99`）；`ContactPointTableView` 通称亦将 `48.6°` 标为「3/4 球」（`:29`）。可能是「打厚 3/4」vs「偏移 3/4 / 通称」两套口径。修正会动教学内容，疑似越「不改变功能语义 / 不削弱内容」红线——请产品定哪套为真源后再改。
2. **AngleHome 封面 `Color(red:…)` 渐变**：与「对齐 BTPlanCover 海报语言」注释一致，属有意品牌封面而非随意逃逸；是否纳入 D3 全站收编由主控定，本轮不记 finding。
3. **GeometricAngleQuiz 暗色页大量 `.system(size:)` 胶囊字**：注释写明对齐场景页 SPEC、禁用常规 `BTButtonStyle.primary`；与 `BTChipRow` 自身也用 system 13 一致。若强制改 bt* 可能破坏暗色场景语言——建议与场景页专项一并收编，本轮不单开 finding。
4. **AngleDynamic 顶栏 `Color.black` + forced dark**：场景页既定语言（ADR-P11-07），非本轮一致性打磨对象。
