# UI 打磨审阅：台面演示与场景组件（SC）

**范围文件**：`DrillSceneView`（含 `DrillSceneController` / `DrillShotOverlay` / `DrillPowerBar`）· `BTDrillPreviewPlayer` · `BTBakedDrillTable` · `BTAimTableView` · `BTTableFigure`（含 `FigureLine` / `BTFigureBall` / `BTGhostCircle` / `BTFigureTag`）· `BTRealisticBall` · `PoolBallFace`（含 `TrajectoryStyle`）· `BTTrajectoryDetailChip` · `ShotTableLayout` / `ShotStageProxy` · `ShotControlBar` / `ShotTryFreePlayButton` · `BreakFlowRunner` 内 UI（`BreakControlBar` / `BreakEntryTile` / `BreakGamePickerSheet`）

**内容 vs chrome 边界**：台面毛毡/木库/球体/轨迹线宽与色属**内容渲染**（字号/色 token 规则豁免；演示回放时长豁免 ≤300ms）。本卡评的是覆层按钮、加载/错误占位、力度指示器 chrome、进出场过渡，以及这些组件之间毛毡/球色/线语言是否同源。

**横向一致性结论（事实）**：生产路径已收敛——插图球走 `PoolBallFace` / `BTFigureBall`，假想球走 `BTGhostCircle` + `FigureLine`（自 `TrajectoryStyle`），轨迹色宽真源在 `TrajectoryStyle`。`BTAimTableView` / `BTRealisticBall` 在 `Features/` 无引用，属组件库遗留双轨（见存疑）。

---

## 页面概述

- **DrillSceneView**：drill 详情横幅主角——USDZ 正交顶视 + 物理/`DrillAnimation` 回放；覆层含左下播放圆钮、右下「上手试打」胶囊、击球前打点迷你盘 + 垂直力度条（`DrillShotOverlay`）。非交互摆球。
- **BTDrillPreviewPlayer / BTBakedDrillTable**：列表/卡片侧轻量预览——位图帧循环或烘焙 PNG；缺资源时台呢占位。
- **BTTableFigure / BTAimTableView / BTRealisticBall / PoolBallFace**：2D/离屏台面与球体渲染件——Figure 系与 Scene 同源坐标与线语言；Aim/Realistic 为拟真 SwiftUI 插图族。
- **BTTrajectoryDetailChip · ShotControlBar · Break\* UI · ShotTableLayout**：击打页贴桌 chrome 与布局几何——档位 chip、反解底栏读数+试打、开球底栏/入口/玩法 sheet；`ShotTableLayout` 无自绘 UI，只算球桌矩形与贴边 frame。

## Findings

### F-SC-01 回放锁定期间 chrome 无进行时反馈
- **类别**：B微交互 / A动效
- **位置**：`QiuJi/Core/Scene/DrillSceneView.swift:42`（`private var isPlaying`，非 `@Published`）；`:107-120`（`play()` 置位后仅 `guard !isPlaying`，2s 预备停顿）；`:354-366`（播放钮外观恒定）
  ```swift
  private var isPlaying = false
  // …
  guard !isPlaying, let cue = … else { return }
  isPlaying = true
  ```
- **现状**：点回放后进入最长约 2s 预备 + 物理/折线演示；按钮仍可点（静默 no-op），无变暗、无「回放中」pill、无图标切换。对照翻袋/自由击打页回放时同屏控件普遍降透明（见 `05`/`06` 审阅）。
- **问题**：对照基准 **A4**（回放锁定属功能语义不改，但锁定期间视觉反馈要到位）+ **B3**（演示中缺进行时反馈 = P2）。
- **建议**：将 `isPlaying` 升为 `@Published`（或派生 `playbackPhase`）；播放钮在预备/运动中 `.opacity(0.35–0.45)` + 可选 SF Symbol `pause.fill`/`stop.fill` 只读态，或短 pill「回放中」；结束 `resetBalls` 后恢复。不改 `preStrikePause`、不可打断语义。
- **语义影响**：无（仍禁止重入回放，仅补 chrome 状态可见性）。
- **严重度**：P2

### F-SC-02 Drill 覆层力度条高饱和渐变与击打页 `HUDStyle.powerGradient` 分裂
- **类别**：D一致性 / C视觉
- **位置**：`QiuJi/Core/Scene/DrillSceneView.swift:514`（`LinearGradient(colors: [.green, .yellow, .orange], …)`）；对照真源 `QiuJi/Core/DesignSystem/HUDStyle.swift:48-53`（`powerGradient` 暗绿→暗金→暗橙）与 `BTShotInstrumentColumn.swift:80`（填充水位走该 token）
  ```swift
  LinearGradient(colors: [.green, .yellow, .orange], startPoint: .bottom, endPoint: .top)
  ```
- **现状**：同一「力度」语义：详情台面只读条用系统高饱和绿黄橙；可编辑仪表柱用克制暗调三色。条顶 `%.1f` 白字胶囊与仪表柱金读数家族也不齐。动作库审阅曾作存疑；对照 HUD 真源后属明确 chrome 分裂（非球体/轨迹内容渲染）。
- **问题**：对照 **D2**（同类力度 chrome 同形态）+ **C1**（高饱和条在台面主角上更抢戏）。
- **建议**：`DrillPowerBar` 填充改 `HUDStyle.powerGradient`；读数字号可对齐 `HUDStyle.labelFontCompact` / 速度值用 `valueAdjustable`（金）或保持白但降对比。保留对数映射与条几何，不改 overlay 避让算法。
- **语义影响**：无（仍只读展示同一 velocity，不改为可编辑、不改量程）。
- **严重度**：P2

### F-SC-03 预览帧加载失败时永久转圈、无失败空态
- **类别**：B微交互
- **位置**：`QiuJi/Core/Components/BTDrillPreviewPlayer.swift:29-35`（`loaded && !frames.isEmpty` 才播）；`:101-105`（无论是否载入成功均 `loaded = true`）；`:66-70`（else 分支恒为 `ProgressView`）
  ```swift
  await MainActor.run {
      self.frames = loadedFrames
      self.loaded = true
  }
  ```
- **现状**：资源缺失或全部 `compactMap` 失败时 `frames` 为空但仍标记已加载 → UI 永远停在台呢 + `ProgressView`，无法区分「还在加载」与「没有预览」。对照 `BTBakedDrillTable` 缺图已有诚实图标占位（`:38-45`）。
- **问题**：对照 **B3**——失败要有诚实友好空态；进行时与失败态混淆。
- **建议**：区分 `loading` / `ready` / `failed`（或 `loaded && frames.isEmpty` → 复用烘焙缺图占位，去掉 spinner）；成功路径不变。
- **语义影响**：无（不增删预览能力，仅修正失败呈现）。
- **严重度**：P2

### F-SC-04 教学插图加载占位用纯黑，与预览/烘焙台呢占位不一致
- **类别**：D一致性
- **位置**：`QiuJi/Core/Components/BTTableFigure.swift:32-34`（`Color.black` + `ProgressView`）；对照 `BTDrillPreviewPlayer.swift:67-70`、`BTBakedDrillTable.swift:39-40`（`Color.btTableFelt`）
  ```swift
  Color.black
  ProgressView().tint(.white.opacity(0.4))
  ```
- **现状**：同属「台面尚未就绪」chrome：Figure 首渲黑场，卡片预览/缩略用 `btTableFelt`。注释写「与场景页同调」，但 SceneKit 详情兜底绿亦非纯黑（见 F-SC-06），用户从知识页插图进场先闪黑块。
- **问题**：对照 **D2**（同类加载占位同形态）+ **B3**（加载反馈材质应与内容族一致）。
- **建议**：占位改为 `Color.btTableFelt`（或与 `DrillSceneView.feltBackground` 统一后的 token），保留居中 `ProgressView`；不改 `TableFigureRenderer` 成功后的 USDZ 底图。
- **语义影响**：无（仅占位色，不改投影/摆球 API）。
- **严重度**：P2

### F-SC-05 本范围其余台面 chrome 主操作普遍无按压态
- **类别**：B微交互
- **位置**：
  - `BTDrillPreviewPlayer.swift:73-83`（重播圆钮，无 `ButtonStyle`）
  - `BTTrajectoryDetailChip.swift:29`（`.buttonStyle(.plain)`）
  - `ShotControlBar.swift:65`（`ShotTryFreePlayButton` `.plain`）
  - `BreakFlowRunner.swift:320/333/351/379/417`（开球底栏三钮、入口块、玩法选项均为 `.plain`）
  - （同根已记：`DrillSceneView` 回放/上手试打 → `02-动作库tab` F-DL-03，本条不重复打分其本体）
- **现状**：台面周边高频/主路径控件按下无 scale/opacity；设计系统 `BTButtonStyle`（`BTButton.swift:49-50`）已有 0.98 + 0.1s 范例。全局审阅 F-GL-02 覆盖更广；本条钉死 **SC 文件内**仍裸露的点。
- **问题**：对照 **B1**——主要操作无按压态 = P2。
- **建议**：抽轻量 `BTHudPressStyle`（scale 0.96–0.98，`easeInOut(0.1)`）挂到上述 Button；开球主钮可略强（0.96）。不改禁用与 `isBusy` 语义。
- **语义影响**：无（仅按下反馈）。
- **严重度**：P2

### F-SC-06 Drill 场景 SCN 兜底绿硬编码，与 `btTableFelt` 资产色不一致
- **类别**：D一致性
- **位置**：`QiuJi/Core/Scene/DrillSceneView.swift:331`（`UIColor(red: 0.11, green: 0.22, blue: 0.15)`）；对照 `QiuJi/Resources/Assets.xcassets/btTableFelt.colorset/Contents.json`（亮色约 `0.106 / 0.420 / 0.227`，暗色约 `0.078 / 0.302 / 0.165`）及预览占位对 `Color.btTableFelt` 的使用
  ```swift
  private static let feltBackground = UIColor(red: 0.11, green: 0.22, blue: 0.15, alpha: 1.0)
  ```
- **现状**：相框余量兜底绿与 token / 烘焙缺图占位可感知不同（G 通道约 0.22 vs 0.42）。属台面家族色同源检查（基准横向要求），非随意改毛毡内容材质。
- **问题**：对照 **D2 / D3**——毛毡色应走 `btTableFelt`（或 UIColor 桥接同一资产），避免列表→详情边缘闪异色。
- **建议**：`UIColor(Color.btTableFelt)`（注意 Light/Dark）替换字面量；若 SceneKit 需钉死单色，把该值写入 Colors 注释为「SCN 兜底 = dark btTableFelt」并与 asset dark 对齐。
- **语义影响**：无（仅余量/letterbox 色，不改正交取景与摆球）。
- **严重度**：P3

### F-SC-07 「回放」动作跨组件图标/形态不齐
- **类别**：D一致性
- **位置**：`DrillSceneView.swift:357`（`play.fill` 圆钮）；`BTDrillPreviewPlayer.swift:77`（`arrow.counterclockwise` 圆钮）；击打页 `BTShotPageChrome.swift:128`（文字「回放」，无图标）
- **现状**：同一「再看一遍演示」语义：详情用播放三角、卡片预览用逆时针、击打页用纯文字。圆钮尺寸同为 32 与半透明黑底，图标却分裂。
- **问题**：对照 **D2 / C6**——同类交互同形态、同一概念同一叫法。
- **建议**：台面覆层圆钮统一一种 SF Symbol（建议与详情一致 `play.fill`，或统一 `arrow.counterclockwise` 并补 accessibility「回放」）；击打页保持文字「回放」不动（贴边文字规范另案）。不改重播/物理回放逻辑。
- **语义影响**：无（只统一图标字形）。
- **严重度**：P3

### F-SC-08 开球 chrome 硬编码字号/圆角/底色未收编
- **类别**：D一致性
- **位置**：`BreakFlowRunner.swift:315-319`（`.system(size: 13…)` + `Color.white.opacity(0.10)`）；`:376`（`cornerRadius: 10`，非 `BTRadius`）；`:427`（`Color(white: 0.09)` sheet 底）；`ShotControlBar.swift:28-33`（读数 `.system(size: 12/10)`，未走 `HUDStyle.valueFontCompact` / `labelFontCompact`）
- **现状**：开球条/入口/玩法 sheet 与反解底栏读数均在暗场 HUD 语境，却绕开已有 `HUDStyle` 与 `Spacing`/`BTRadius` 阶梯；`10` 圆角落在 `BTRadius.sm(8)` 与 `md(12)` 之间。
- **问题**：对照 **D3**（chrome token 逃逸；非台面像素内容）。
- **建议**：字号映射 `HUDStyle.labelFont` / `valueFontCompact`；入口圆角改 `BTRadius.sm` 或 `md`；sheet 底收编进 F-GL-03 提案的 `btHUDPanel`（或 `Color(white: 0.09)` 命名常量）。不改开球/换局/取消流程。
- **语义影响**：无。
- **严重度**：P3

### F-SC-09 `BTRealisticBall.ghost` 与 `BTGhostCircle` 假想球视觉双轨

- **位置**：`BTRealisticBall.swift:115-129`（白半透明 + 白虚线描边）；`BTTableFigure.swift:139-157`（`FigureLine.contact` 品牌绿虚线圈 + 可选红瞄准点）

## 存疑项（不确定是否越红线的，单独列出待主控裁决，不算 finding）

1. **`BTAimTableView` / `BTRealisticBall` 是否计划下线**：`Features/` 零引用，生产插图已迁 `BTTableFigure` + `BTFigureBall`。若永久遗留，F-SC-09 类双轨会持续；若删除属「删 API」是否算改功能面，需主控拍板。
2. **详情相框 1.81 vs 烘焙/预览 2.0**：`DrillSceneController.frameAspect = 1.81`（含木边实测）与 `BTBakedDrillTable` / `BTDrillPreviewPlayer` `aspectRatio(2.0)` 不同——更像内容取景契约而非 chrome；统一是否削弱木边完整展示，待与烘焙管线对齐后再定。
3. **物理求解异步完成前轨迹「晚到」**：`DrillSceneController.setup` 后台 `ShotPredictor` 返回后才 `redrawTrajectory` + `showOverlay`（`:91-100`）。球先出现、线与打点稍后淡入——属内容就绪时序；是否要骨架/「计算中」pill 可能触及信息展示强度，未记 finding。
4. **`DrillPowerBar` 条顶仅数字无「m/s」单位**：与 `ShotControlBar`「轻力 3.1 m/s」文案密度不同；补单位是否算加强标注（不削弱）还是噪音，待体验确认。
5. **开球 `isBusy` 时次要钮仅 `disabled`、无额外降透明**：主钮已有「开球中」+ 主色变淡（`BreakFlowRunner.swift:343-352`）；取消/换一局是否需对齐 A4 变暗，轻微，未单列。
