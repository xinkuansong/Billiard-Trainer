## 七、裁决纪律备忘（执行时）

1. **ShotStageProxy**：禁止为「手感」逐页改贴边 frame；全局改动只动 `ShotTableLayout` / `ShotStageProxy`。本片区 ✅ 无一要求违此条。  
2. **HUD 玻璃**：维持 `btHudGlass` **无阴影无光效**（§9.1-⑤）；本片区无建议加阴影的 finding。  
3. **信号色封闭**（§9.1）：场景页勿借 token 收编引入第五语义通道；角色色=命名常量即可。  
4. **黑底常量**（§8.1）：页面底保持 `Color.black`；勿把场景 chrome 改成常规页 `btBG*`。  
5. **已修勿返工**：本三份审阅**未**误报 G15 尾速截断 / G13 瞄准跳变；代码已无 `perceptibleSettleTime`，无需 ❌已由Vn修复 条目。
