# UI 打磨审阅：基础组件库补审（CL）

> 范围：`QiuJi/Core/Components/` 中第一轮未逐个深审的组件 + `QiuJi/Core/DesignSystem/` 品牌/图标/HUD 真源。  
> 对照：`docs/ui-polish/00-打磨基准.md`；已记录于 `09-共享组件与全局.md` 的 F-GL-02/07/08/09/10 等**不重复收录**（按压态缺失、硬编码色抽样、BTButton text/destructive、OverflowMenu、分段时长）。

## 组件概述

### 列表 / 计划 / 空态族
- **BTDrillCard / BTDrillGridCard / BTDrillThumbnail**：动作库行卡与双列网格卡；等级徽标 + 收藏/PRO；网格卡有 Dark 描边与浅阴影。
- **BTEmptyState**：全页空态（图标圆底 + 标题副文 + 可选 `BTButtonStyle.primary` CTA）。
- **BTLevelBadge**：L0–L4 文案徽标，Light/Dark 分套色。
- **BTPlanCover**：计划「杂志封面」渐变色卡（装饰性饱和色，内容向）。
- **BTPlanWeekTimeline**：周进度节点串 + current 态呼吸脉冲。
- **BTPremiumLock**：progressive 渐隐锁 / fullMask 模糊锁 + Pro CTA。
- **BTExerciseRow**：训练中动作行（缩略位 + 组进度点 + 精讲/设置配件）。
- **BTSetInputGrid**：组数录入表（活动行左边条、完成勾选、删除菜单）。
- **BTShareCard**：训练分享导出卡（多主题底色 + 品牌头）。
- **BTShimmer / BTDrill*Skeleton**：加载闪烁与列表骨架。
- **BTFloatingIndicator**：非训练 Tab 右下「训练中」呼吸浮标（进出场在 MainTabView）。
- **BTRestTimer**：组间休息环 + 「+30S / 完成休息」；组件自洽，但生产路径另有手写实现。

### 击打仪表族
- **BTReadout**：HUD 读数胶囊（测量白 / 可调金 / 告警红），挂 `HUDStyle`。
- **BTAimWheel**：左缘竖向棘轮刻度，相对拖动微调瞄准，整度轻触感。
- **BTShotInstrumentColumn**：右缘打点迷你图 + 力度柱，拖动阻尼 + 档位触感；与瞄准轮同「尺子」家族。
- **BTSpinPad / Card / Overlay / Nudge**：打点盘 1:1 跟手；四向键按压高亮 + 长按连发 + 撞墙硬反馈；「回中」为 plain 文字钮。

### DesignSystem
- **BTBrandLogo**：生产用品牌 Mark（资产 `BrandLogoMark`）；Onboarding / Login / About / ShareCard。
- **BTLogoMark / BTWordmark / BTLogoLockup**：程序化「球+轨迹」Mark；**Features 零引用**，仅本文件 Preview。
- **BTDrillCategoryIcon / BTTrainingIcon**：分类与训练 Tab 矢量图标（btPrimary + 单点 btAccent）。
- **HUDStyle**：仪表玻璃 / 刻度 / 力度渐变真源；`btHudGlass` 修饰器。
- **IconToken（BTIcon / BTIconBadge）**：SF Symbol 语义常量 + 圆底徽标；Features 已部分迁移，Components 多数仍字面量。

## Findings

### F-CL-01 瞄准轮与力度柱同族圆角不一致（10 vs 12）
- **类别**：D一致性
- **位置**：
  - `QiuJi/Core/Components/BTAimWheel.swift:32-35`
    ```swift
    RoundedRectangle(cornerRadius: 10, style: .continuous)
        .fill(HUDStyle.glassTint)
    ```
  - `QiuJi/Core/Components/BTShotInstrumentColumn.swift:74-77`
    ```swift
    RoundedRectangle(cornerRadius: 12, style: .continuous)
        .fill(HUDStyle.glassTint)
    ```
- **现状**：两组件注释均自称同一视觉家族（左方向 / 右力度「尺子」），玻璃底与刻度语法共用 `HUDStyle`，但外壳圆角分别为硬编码 10 与 12（`BTRadius.md == 12`，无 10 的 token）。
- **问题**：对照 **D2**——同类交互同形态；并排出现在击打页时圆角差可感知为「左右尺子不是一套模具」。
- **建议**：统一为 `BTRadius.md`（12）或新增 `HUDStyle.rulerCornerRadius` 单点真源，AimWheel / InstrumentColumn / 若有的 chrome 容器一并引用。
- **语义影响**：无（仅外壳圆角，不改拖动灵敏度、量程或触感档位）
- **严重度**：P2

### F-CL-02 行卡 BTDrillCard Dark Mode 缺少描边，与网格卡/训练行分裂
- **类别**：C视觉 / D一致性
- **位置**：
  - `QiuJi/Core/Components/BTDrillCard.swift:78-80`（行卡：仅底色裁切，无 stroke）
    ```swift
    .background(.btBGSecondary)
    .clipShape(RoundedRectangle(cornerRadius: BTRadius.md))
    ```
  - 对照同文件网格卡 `:143-146`、`BTExerciseRow.swift:34-37`（Dark 下 `btSeparator` 0.5pt 描边）
- **现状**：网格卡与训练行在 Dark 用发丝描边弥补阴影失效；行卡无描边、无阴影策略，暗色下列表块与背景易糊成一片。
- **问题**：对照 **C5**（暗色 surface 层级）与 **D2**（同类卡片同形态）。
- **建议**：行卡对齐网格卡 overlay：`colorScheme == .dark ? 0.5 : 0` 的 `btSeparator` stroke；Light 可保持无阴影（行卡密度更高）或与 ExerciseRow 的轻阴影择一。
- **语义影响**：无（仅卡片边缘可见性，不改收藏/锁定/导航）
- **严重度**：P2

### F-CL-03 网格骨架宽高比与真卡不一致，加载完成布局跳变
- **类别**：A动效 / C视觉
- **位置**：
  - `QiuJi/Core/Components/BTShimmer.swift:75-77`
    ```swift
    .aspectRatio(2.0, contentMode: .fit)
    ```
  - `QiuJi/Core/Components/BTDrillCard.swift:109-110`（真卡）
    ```swift
    .aspectRatio(4.0 / 3.0, contentMode: .fit)
    ```
- **现状**：`DrillListView` 加载走 `BTDrillListSkeleton` → `BTDrillGridCardSkeleton`；真内容为 `BTDrillGridCard`。封面区比例 2.0 vs 4/3，骨架偏扁，数据到达后卡片变高。
- **问题**：对照 **A6**（突现突消/跳变）与 **C3**（同类列表节奏）；用户感知为「列表抖一下」而非平滑替换。
- **建议**：骨架 `aspectRatio(4.0/3.0)` 与真卡对齐；底部文案区 padding 已与真卡同为 `md/sm`，可保持。
- **语义影响**：无（仅加载占位几何，不改列表数据或点击）
- **严重度**：P2

### F-CL-04 BTRestTimer 已完备，ActiveTraining 另起手写休息 UI（D4）
- **类别**：D一致性
- **位置**：
  - 组件真源 `QiuJi/Core/Components/BTRestTimer.swift:29-72`（双环 + `BTButtonStyle.secondary/primary` + token 字色）
  - 生产替身 `QiuJi/Features/Training/Views/ActiveTrainingView.swift:580-628`（单环、`.system(size:)` 文案、自绘 Capsule 按钮）
- **现状**：`BTRestTimer` 提供与产品文案一致的「组间休息 / +30S / 完成休息」，但 Features 全库无 `BTRestTimer(` 引用；训练页复制了一套近似 chrome，按钮与字号脱离组件标准。
- **问题**：对照 **D4**——页面手写了组件库已有能力；长期两套休息 UI 易漂移（已出现单环 vs 双环、BTButton vs 手写胶囊）。
- **建议**：ActiveTraining 休息态改为嵌入 `BTRestTimer`（binding `restSecondsRemaining` / `onExtend` / `onComplete`）；若双环视觉过重，再收窄组件变体而非继续分叉。
- **语义影响**：无（同为延长/跳过休息，不改计时语义或 Live Activity）
- **严重度**：P2

### F-CL-05 BTExerciseRow 的 thumbnailAnimation 为死参数，缩略位永远占位图标
- **类别**：B微交互 / C视觉
- **位置**：`QiuJi/Core/Components/BTExerciseRow.swift:12` 声明、`:48-55` 渲染未使用该参数
  ```swift
  let thumbnailAnimation: DrillAnimation?
  // …
  BTTrainingIcon(size: 30, filled: true)  // 与 thumbnailAnimation 无关
  ```
  调用方仍传入真数据：`ActiveTrainingView.swift:214`、`DrillRecordView.swift:95` 的 `thumbnailAnimation: drill.animation`。
- **现状**：API 暗示「可显示动作缩略动画」，实现固定 `BTTrainingIcon`；训练中列表信息密度被占位图占满，动作辨识靠纯文字。
- **问题**：对照 **C1**（内容应为主角）——缩略位本可承载台面/动作预览却空转；亦属组件契约与呈现不一致（可感知的「假接口」）。
- **建议**：用既有 `BTDrillThumbnail` / 烘焙台面按 `drillId` 渲染，或删除参数并改调用方（二选一，避免假 API）。优先接线缩略图以加强内容，勿另发明交互。
- **语义影响**：无（不改点行进精讲/设置的模型；仅让已传入的内容真正显示）
- **严重度**：P2

### F-CL-06 BTLogoMark 生产零引用，与 BTBrandLogo 形成品牌双真源
- **类别**：D一致性
- **位置**：
  - 生产路径仅 `BTBrandLogo`：`OnboardingView.swift:173`、`LoginView.swift:91`、`AboutView.swift:38`、`BTShareCard.swift:114`
  - `BTLogoMark` / `BTLogoLockup`：`rg` 仅命中 `BTLogoMark.swift` 自身与 Preview
  - 文档仍指向旧 Mark：`IconToken.swift:9`、`:131-132` 注释写「自定义图标走 BTLogoMark / …」
- **现状**：品牌入口已统一资产版 snail-QJ（`BTBrandLogo`）；程序化「球+轨迹」`BTLogoMark` 仍留在 DesignSystem，且 IconToken 注释未更新，后续易误用第二套 Logo。
- **问题**：对照 **D2**——品牌标识应同形态；双真源是一致性债（即便当前用户看不到 LogoMark）。
- **建议**：归档/删除未用的 `BTLogoMark` 族，或明确标为「历史/实验」并改 IconToken 注释只提 `BTBrandLogo`；禁止新页面引用 LogoMark。
- **语义影响**：无（不改现网已展示的 Logo；清理死代码与注释）
- **严重度**：P2

### F-CL-07 组件库内仍散落 systemName 字面量，未接入 BTIcon
- **类别**：D一致性
- **位置**（抽样，均有对应 `BTIcon.*`）：
  - `BTDrillCard.swift:59` / `:72` — `"lock.fill"` / `"chevron.right"`
  - `BTPremiumLock.swift:94` / `:124` — `"lock.fill"`
  - `BTSetInputGrid.swift:118` — `"plus"`
  - `BTExerciseRow.swift:96` — `"ellipsis.circle"`
  - `BTFloatingIndicator.swift:23` — `"chevron.left"`
- **现状**：`IconToken.swift` 目标是集中 SF Symbol 字符串；Features 已部分用 `BTIcon`，Core/Components 补审范围内几乎全是字面量。
- **问题**：对照 **D2 / D3**——重设计换符时组件层成漏网；与 IconToken 自身约定（「新增优先 BTIcon」）不一致。
- **建议**：组件库批量替换为 `BTIcon.lock` / `chevronRight` / `plus` / `menuCircle` 等；不改图标语义，只改引用方式。
- **语义影响**：无（同名 SF Symbol 替换为命名常量）
- **严重度**：P3

### F-CL-08 多组件硬编码 cornerRadius 4，偏离 BTRadius.xs(6)
- **类别**：D一致性
- **位置**：
  - `BTSetInputGrid.swift:216` — 热身「热」徽标 `cornerRadius: 4`
  - `BTPremiumLock.swift:177` — PRO 小徽标 `cornerRadius: 4`
  - `BTShimmer.swift:48` 等 — 骨架条 `cornerRadius: 4`（多处）
- **现状**：设计系统最小圆角 token 为 `BTRadius.xs = 6`；上述 UI chrome 使用裸 4，与 LevelBadge（用 xs）等不一致。
- **问题**：对照 **D3**——圆角阶梯漂移；小徽标并排时「有的更尖」。
- **建议**：能对齐的改为 `BTRadius.xs`；若刻意更尖，在 `BTRadius` 增 `xxs = 4` 并文档化，禁止裸数字。
- **语义影响**：无
- **严重度**：P3

### F-CL-09 网格卡 PRO 徽标字号逃逸 Typography token
- **类别**：D一致性
- **位置**：`QiuJi/Core/Components/BTDrillCard.swift:195-197`
  ```swift
  .font(.system(size: 9, weight: .bold))
  Text("PRO")
      .font(.system(size: 10, weight: .heavy))
  ```
- **现状**：同卡其它文案用 `.btHeadline` / `.btCaption`；PRO 胶囊单独 `.system(size:)`。基准 §1.1：UI chrome 直接写 system size 属 D 类（台面内标注豁免，此处为卡片徽章）。
- **问题**：对照 **D3**；与 `BTLevelBadge` 的 `.btCaption2` 阶梯也不对齐。
- **建议**：锁/PRO 统一 `.btCaption2` 或 `.btMicro` + weight；保持 Capsule 与 `btAccent` 底。
- **语义影响**：无
- **严重度**：P3

## 存疑项（待主控裁决，不算 finding）

1. **`PremiumLockMode.progressive(visibleItems:)` 参数未消费**：`BTPremiumLock` 渐隐 mask 固定 stops，忽略 `visibleItems`；`PlanDetailView` / `DrillDetailView` 仍传入。修复会改变「露出多少内容」，可能触碰功能语义红线——是否单独立 bug，本轮不升 UI finding。
2. **`BTShareCard.hideBallTable`**：仅声明未使用；属死 API，清理还是补台面区？
3. **`BTDrillCardSkeleton`（行卡骨架）**：全库无引用；仅 `BTDrillListSkeleton` 用网格骨架。删除 vs 留给 PlanList？
4. **`BTSpinPadCard` 注释写「右上 ✕」**：实现无关闭钮，仅靠 Overlay 点外侧关闭。改注释还是补 ✕（补 ✕ 可能改变关闭手势习惯）？
5. **`BTSpinPad` 皮头 `Color.red`**：偏内容/物理可视化；若收 token 易与「台面渲染豁免」冲突，建议维持或挂 `HUDStyle` 明示例外。
6. **`BTPlanCover` / `BTLevelBadge` 大面积 `Color(red:)`**：09 已将封面渐变标为内容向、组件硬编码色有 F-GL-07 模式；本轮不重复记条。若要为等级色建 `btLevelL0…L4` token，另开收编任务。
7. **按压态**：本范围 `BTFloatingIndicator` / `BTExerciseRow` / `BTPremiumLock` CTA / `BTSetInputGrid` 添加钮 / Spin「回中」等 `.plain` 无 scale——证据与整改方向已由 **F-GL-02** 覆盖，此处不重复开号。
