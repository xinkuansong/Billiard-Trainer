## 页面概述

**DrillTutorialView** 是 App 最长阅读面：顶栏「精讲」+ 分类/等级/标题/简介头，下方按 `sections`（或多球形 `formations`）渲染分区卡片——原理/要领/错误/进阶，以及应用课「第N杆」的 params 胶囊 + 为什么/怎么打/自检标签行 + 可选配图。多球形时 sticky `Picker(.segmented)` 吸顶切换。配图点进 `fullScreenCover` → **TutorialMediaViewer**（TabView 翻页、捏合/双击缩放、未放大时下滑关闭、有 clip 时静音循环播）。

**入口**：动作库详情 `navigationDestination` push；训练中 `BTExerciseRow.accessory == .tutorial` 以 **sheet** 包 `NavigationStack` 呈现同一 `DrillTutorialView`。

## Findings

### F-TU-01 配图字段存在但加载失败时整块静默消失（与「缺图回退占位」注释不符）
- **类别**：B微交互
- **位置**：`QiuJi/Features/DrillLibrary/Views/DrillTutorialView.swift:5-17`；同文件 `197-225`；`319-327`
  ```swift
  /// …缺图回退占位。
  // …
  if let imageName = section.image,
     let uiImage = DrillTutorialImageStore.image(named: imageName) {
  ```
- **现状**：`image(named:)` 失败返回 `nil` 时，卡片不渲染任何占位，图注也不出现；`mediaItems(for:)` 同样 `compactMap` 掉，全屏图集里也没有该项。文件头写「缺图回退占位」，实现为零反馈。Bundle 抽查：`DrillTutorials` 仅 8 张 png，JSON 引用约 118 处，绝大多数引用在阅读页上直接「蒸发」（如 `drill_c031` 14 张图引用在缺资源时整课无图）。
- **问题**：对照 **B3**（失败要有诚实友好空态；进行时与失败不可混淆——此处连失败态都没有）。
- **建议**：当 `section.image != nil` 且 `image(named:) == nil` 时，渲染与卡片同宽的弱占位（`btBGTertiary` + `photo`/`exclamationmark.triangle` + 可选「配图暂缺」），图注仍可显示；`mediaItems` 可继续排除不可浏览项。不改 JSON schema、不假装有图。
- **语义影响**：无（不增删精讲字段，只补已声明的失败呈现）。
- **严重度**：P1

### F-TU-02 下滑关闭 / 捏合缩放把 `interactiveSpring` 绑在手势 `onChanged` 驱动值上，拖动非 1:1
- **类别**：B微交互 / A动效
- **位置**：`QiuJi/Features/DrillLibrary/Views/DrillTutorialView.swift:465-473`；同文件 `487-508`
  ```swift
  .offset(x: offset.width, y: offset.height + dismissDrag)
  .animation(.interactiveSpring(), value: scale)
  .animation(.interactiveSpring(), value: dismissDrag)
  ```
- **现状**：`dismissDrag` / `scale` 在手势 `onChanged` 中每帧写入，同时又对这两个值挂全局 `.animation(.interactiveSpring())`。松手回弹（阈值未达时 `dismissDrag = 0`、双击 `toggleZoom`）需要 spring；但拖动过程也被插值，手指与图层不同步。02/09 浅审将其标为「手势跟手例外」，深审下与 B2 冲突。
- **问题**：对照 **B2**（拖动应 1:1 实时跟随；松手后才结算 = 否则 P1）+ **A4**（跟手值被动画层改写，可打断性变差）。
- **建议**：手势进行中对 `dismissDrag`/`scale`/`offset` **禁用**隐式动画（`var transaction = Transaction(); transaction.disablesAnimations = true` 或拆「拖动无动画 / 结束用 interactiveSpring」）；仅在 `onEnded` 回弹与 `toggleZoom` 使用 `interactiveSpring`。保留现有阈值 120 与缩放上限 4。
- **语义影响**：无（仍下滑关闭 / 捏合 / 双击，不改关闭语义）。
- **严重度**：P1

### F-TU-03 下滑关闭只平移媒体层，图注留在原位造成「一拖两层」
- **类别**：A动效 / B微交互
- **位置**：`QiuJi/Features/DrillLibrary/Views/DrillTutorialView.swift:389-407`
  ```swift
  VStack(spacing: Spacing.md) {
      ZoomableContainer(swipeToDismiss: true, onDismiss: { dismiss() }) { … }
      if let caption = item.caption { Text(caption) … }
  }
  ```
- **现状**：`dismissDrag` 仅作用在 `ZoomableContainer` 内；caption 在外层 `VStack`，下滑时图走字留，跟手闭环破裂。
- **问题**：对照 **A5**（进出同路径/拖动整体应一体）+ **B2**（跟随对象应是用户抓住的那一整屏媒体单元）。
- **建议**：把 caption 移入 `ZoomableContainer` 的 content，或对整页 `VStack`（媒体+图注）统一施加 dismiss 偏移/透明度；关闭钮可继续固定在 `topBar`。
- **语义影响**：无（仍下滑关闭，不改 caption 文案来源）。
- **严重度**：P2

### F-TU-04 静态配图可点放大但无 affordance，且 `.plain` 无按压态
- **类别**：B微交互 / C视觉
- **位置**：`QiuJi/Features/DrillLibrary/Views/DrillTutorialView.swift:203-217`；对照同文件 `305-311`（仅 clip 有 `playBadge`）
  ```swift
  Button { openViewer(at: imageName) } label: {
      Image(uiImage: uiImage) … // 无放大角标
  }
  .buttonStyle(.plain)
  ```
- **现状**：有 `clip` 时居中播放角标暗示可进全屏；纯静态海报外观与不可点插图无异，`.plain` 无 scale/高亮。长文里大量「点图看大图」依赖偶然发现。
- **问题**：对照 **B1**（主要可点控件缺按压）+ **C2**（可点权重未表达）。
- **建议**：静态图右下角弱 `arrow.up.left.and.arrow.down.right` / `plus.magnifyingglass`（低于 play 角标权重）；`ButtonStyle` 按下 `scale 0.98` + 短 `easeInOut(0.1)`。不改 `openViewer` 与图集逻辑。
- **语义影响**：无（仍点进同一 Viewer，不改 clip/静态分支）。
- **严重度**：P2

### F-TU-05 精讲入口：详情 push vs 训练 sheet，导航形态分裂
- **类别**：D一致性
- **位置**：`QiuJi/Features/DrillLibrary/Views/DrillDetailView.swift:100-103`；`QiuJi/Features/Training/Views/DrillRecordView.swift:78-87`
  ```swift
  // Detail: navigationDestination → DrillTutorialView
  // Record: .sheet { NavigationStack { DrillTutorialView … +「关闭」} }
  ```

- **现状**：同一 `DrillTutorialView`：动作库为导航栈 push（系统返回）；训练中为 modal sheet + 显式「关闭」。阅读长文时，一种可侧滑返回详情上下文，一种是盖在训练页上的模态——返回手势、栈深度、工具栏都不一致。
- **问题**：对照 **D2**（同类「打开精讲」同形态）。

- **语义影响**：无（仍打开同一精讲内容；不增删入口）。
- **严重度**：P2

### F-TU-10 进全屏媒体为默认 `fullScreenCover` 突现，无与海报的空间连续
- **类别**：A动效
- **位置**：`QiuJi/Features/DrillLibrary/Views/DrillTutorialView.swift:84-86`
  ```swift
  .fullScreenCover(item: $viewer) { presentation in
      TutorialMediaViewer(items: presentation.items, startIndex: presentation.startIndex)
  }
  ```
- **现状**：海报 → 全黑 Viewer 无 `matchedGeometryEffect`、无显式 opacity/scale 过渡，系统 cover 垂直盖入；关闭同理突切回长文。相对已实现的下滑跟手关闭，进场更「跳」。
- **问题**：对照 **A6**（出现/消失无过渡易跳变）+ **A5**（理想上从触发海报扩展）。
- **建议**：最低成本——Viewer 根视图 `.opacity` + `scaleEffect(0.98)` 进场短 spring（`0.34/0.86`）或 `easeOut ≤300ms`；进阶再用 matchedGeometry 绑海报与当前页图。不改手势关闭语义。
- **语义影响**：无（仍 fullScreen 浏览同一图集）。
- **严重度**：P3

## 存疑项（不确定是否越红线的，单独列出待主控裁决，不算 finding）

1. **循环 clip 无暂停/静音控件**（`LoopingPlayerView` 静音自动 loop）：ADR-P12-02「poster_tap」是否有意做成「只能看、不能控」？补控件可能被视作增功能，故未记 finding。
2. **缺图根因是内容管线未打进 Bundle（114/118）还是路径/子目录配置错误**：F-TU-01 只要求失败 chrome；是否另开 Content 任务补资产，由主控/Content Engineer 裁决。
3. **双击放大固定 2.5× 且不以触点为中心**：常见局限；改锚点算法是否算体验必做，待裁决（未升格）。
4. **精讲头与详情简介重复**（F-DD-05）：本轮不重复；若统一入口形态（F-TU-05）后是否顺带弱化精讲头，交主控合并排期。
5. **`openTutorial` 在配件可见性上未校验 `tutorial != nil`**：若无精讲 drill 仍显示「精讲」属功能门槛，可能越「不改功能语义」红线，仅存疑。
