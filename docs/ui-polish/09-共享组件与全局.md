# UI 打磨审阅：共享组件与全局一致性（MainTabView / RootView / BT* / 全库普查）

## 页面概述

- **MainTabView + RootView**：根壳是 5 Tab + NavigationStack 路由；训练最小化时在非训练 Tab 右下角叠一层 `BTFloatingIndicator`（呼吸浮标），点按回训练 Tab。RootView 仅做 onboarding 门闩，无独立 chrome。
- **BT* 组件库（`QiuJi/Core/Components/`，约 30 个 BT* 文件）**：承载亮色列表页按钮（`BTButton`）、暗色击打页文字动作（`BTTextActionButton`）、chips/分段、浮标、空态、锁屏、仪表柱等。击打页主路径已从圆形 `BTSceneFAB` 收敛到贴边 `BTTextActionButton` / `BTShotActionColumn`（FAB 仅 Preview 残留）。
- **本范围独有职责**：全库 spring/ease 参数聚类、按压态覆盖抽样、Features 硬编码色、同类动作形态（重置/关闭/下一步）横向对比。

## Findings

### F-GL-01 试打台面进场使用 easeIn，进出场手感倒置
- **类别**：A动效
- **位置**：`QiuJi/Features/PositionPlay/Views/PositionPlayComposerView.swift:154`
  ```swift
  withAnimation(.easeIn(duration: 0.45).delay(0.1)) { stageRevealed = true }
  ```
- **现状**：试打变体首次揭示台面用 `easeIn(0.45)`；同文件说明卡出场用 `easeOut(0.25)`（:171），进场用 `easeInOut(0.35)`（:155）。
- **问题**：对照基准 **A1**——UI 进出场应「先快后慢」（ease-out / spring）；`easeIn` 用于 UI 进场 = 启动慢、收尾冲，与同页其它过渡也不一致。时长 450ms 亦超过 chrome ≤300ms 习惯（**A2**），且无内容回放理由。
- **建议**：进场改为 `.easeOut(duration: 0.28)` 或基准面板 spring `response: 0.34, dampingFraction: 0.86`；与说明卡 `easeOut(0.25)` 对齐。
- **语义影响**：无（只改缓动曲线/时长，不改变试打揭示时机、说明卡逻辑或交互模型）
- **严重度**：P1

### F-GL-02 高频共享可点控件普遍无按压态（`.plain` 无 scale/opacity）
- **类别**：B微交互
- **位置**（组件真源，抽样）：
  - `QiuJi/Core/Components/BTShotPageChrome.swift:87` — `BTTextActionButton` `.buttonStyle(.plain)`，无 `isPressed` 反馈
  - `QiuJi/Core/Components/BTChipRow.swift:38` — chips `.plain`
  - `QiuJi/Core/Components/BTSceneFAB.swift:34` — FAB `.plain`
  - `QiuJi/Core/Components/BTFloatingIndicator.swift:39` — 训练浮标 `.plain`
  - `QiuJi/Core/Components/BTExerciseRow.swift:40` — 列表行 `.plain`
  - `QiuJi/Core/Components/BTShotPageChrome.swift:59` — `BTAimModeToggleButton` `.plain`
  - 对照已达标：`QiuJi/Core/Components/BTButton.swift:49-50` — `scaleEffect(0.98)` + `easeInOut(0.1)`
- **现状**：亮色主按钮族有完整按压；暗色击打页主操作列、chips、浮标、训练行等用户每杆/每页都会点的控件用 `.plain`，按下无即时视觉变化。Features 侧大量 `Button` + `.plain` 继承同一缺口（如 BankShot `restoreButton` :200）。
- **问题**：对照 **B1**——主要操作按钮无按压态 = P2；且与 `BTButton` 已建立的 0.96–0.98 scale 规范分裂（**D2**）。
- **建议**：抽一个轻量 `BTPressableStyle`（scale 0.97 + 可选 opacity），挂到 `BTTextActionButton` / `BTChipRow` / `BTFloatingIndicator` / `BTExerciseRow` / `BTAimModeToggleButton`；按压动画沿用 `easeInOut(0.1)`（与 BTButton 一致，建议 token 名 `btPress`）。
- **语义影响**：无（仅按下视觉，不改命中区域、禁用逻辑或动作语义）
- **严重度**：P2

### F-GL-03 暗色击打页底栏 chrome 色 `Color(white: 0.11)` 全库复制未入 token
- **类别**：D一致性
- **位置**（同值多处，非台面渲染）：
  - `QiuJi/Core/Components/ShotControlBar.swift:81`
  - `QiuJi/Features/AngleTraining/Views/BankShotView.swift:426`
  - `QiuJi/Features/AngleTraining/Views/DiamondSystemView.swift:424`
  - `QiuJi/Features/PositionPlay/Views/SiluTrainerView.swift:347`
  - `QiuJi/Features/PositionPlay/Views/FreePlayView.swift:418`
  - 以及 SceneAiming / ShotSimulation / AngleDynamic / AimPointScene / PlanThree / PositionPlayComposer / SnookerTactics / BatchAuthoring / BallExtraction 等同类底栏（全库约 15+ 处）
- **现状**：击打页底栏/侧栏统一写成裸 `Color(white: 0.11)` + 常配 `Color.white.opacity(0.08)` 发丝分割，未进 `Color.bt*` / `HUDStyle`。
- **问题**：对照 **D3**——硬编码色属 token 逃逸；后续微调暗色层级需改十几处，易漂移。
- **建议**：收编为 `Color.btHUDPanel` 或 `HUDStyle.panelBackground = Color(white: 0.11)`，Features 只引用 token。
- **语义影响**：无（同色替换为命名常量，不改变对比度意图或信息架构）
- **严重度**：P2

### F-GL-04 PlanThree 角色槽武装态 spring 漂移且过弹
- **类别**：A动效 / D一致性
- **位置**：`QiuJi/Features/PositionPlay/Views/PlanThreeView.swift:325-326`
  ```swift
  .scaleEffect(armed ? 1.03 : 1)
  .animation(.spring(response: 0.3, dampingFraction: 0.7), value: armed)
  ```
- **现状**：同页 spin pad 已用基准面板 spring `0.34/0.86`（:63）；角色槽武装态单独 `0.3/0.7`。
- **问题**：对照 **D1** 相对 §1.2 漂移；**A7**——无手势动量的 UI 用 `dampingFraction < 0.75` 属过弹。
- **建议**：收编为 `spring(response: 0.34, dampingFraction: 0.86)`（`btSpringPanel`）；或若需更「点选脆感」用 `0.35/0.75`（`btSpringLayout`），勿低于 0.75。
- **语义影响**：无（仅武装态缩放手感，不改变选球/求解语义）
- **严重度**：P2

### F-GL-05 「重置 / 恢复」同类动作跨页形态与叫法不齐
- **类别**：D一致性
- **位置**（抽样对比，语义相近的「回到先前状态」动作）：
  - 求解页贴边文字钮：`BankShotView.swift:239` / `DiamondSystemView.swift:240` — `BTTextActionButton(title: "重置")`
  - 设置菜单：`SiluTrainerView.swift:447` / `PlanThreeView.swift:535` / `SnookerTacticsView.swift:366` — `Button("恢复默认", systemImage: "arrow.counterclockwise")`
  - 仅图标工具栏：`GeometricAngleQuizView.swift:46-50` — `arrow.counterclockwise`，文案在 a11y「重置统计」
  - 破坏性确认：`PositionPlayComposerView.swift:617` — `"清空并重来"` + destructive
  - 自由开球再码：`FreePlayView.swift:571-577` — settled 态图标 `arrow.counterclockwise` + 主胶囊文案切换
- **现状**：同一「逆时针箭头」图标承载重置/恢复默认/清空/再码；形态上混用贴边胶囊文字钮、系统菜单项、纯图标 toolbar、主色胶囊内嵌图标。
- **问题**：对照 **D2 / C6**——同类交互同形态、同一概念同一叫法；用户需重新学习「这页的重置长什么样」。
- **建议**（不改功能）：贴边次要重置统一 `BTTextActionButton` plain「重置」；设置内全局参数统一「恢复默认」菜单项；统计清零保持 toolbar 图标但统一 accessibilityLabel「重置统计」。勿把「恢复球形」（BankShot :193，另一语义）与「重置」合并。
- **语义影响**：无（只统一视觉形态与文案标签，不合并不同语义的动作，不增删确认流）
- **严重度**：P2

### F-GL-06 `spring(duration:)` 族与基准两套 response/damping spring 并存
- **类别**：D一致性
- **位置**：
  - `QiuJi/App/MainTabView.swift:81` — `.spring(duration: 0.3)`（训练浮标进出）
  - `QiuJi/Features/Training/Views/PlanDetailView.swift:286` — `.spring(duration: 0.3)`
  - `QiuJi/Features/Training/Views/TrainingHomeView.swift:295` — `.spring(duration: 0.2)`
  - `QiuJi/Features/Profile/Views/SubscriptionView.swift:224` — `.spring(duration: 0.2)`
- **现状**：击打系已收敛 `0.34/0.86` 与 `0.35/0.75`；亮色 Tab/训练/订阅仍用 `spring(duration:)` API，无法与 damping 基准对齐。
- **问题**：对照 **D1**——与 §1.2 语义相近但参数族漂移，长期无法收编为命名 token。
- **建议**：浮标/卡片展开 → `btSpringPanel`（0.34/0.86）；短促 chips 类 → 保持 `easeInOut(0.2)` 或 `spring(duration: 0.2)` 明确标为 `btSpringSnap` 并写进设计系统，避免第三套无名值。
- **语义影响**：无（只统一动画参数表达，不改变浮标出现条件或 Tab 行为）
- **严重度**：P2

### F-GL-07 组件库内仍硬编码 `Color(red:)`，与 bt* 色板并行
- **类别**：D一致性
- **位置**：
  - `QiuJi/Core/Components/BTButton.swift:112` — darkPill 亮色填充 `Color(red: 0x1C/255, …)`
  - `QiuJi/Core/Components/BTTogglePillGroup.swift:13` — 暗色选中 `Color(red: 0.95, 0.95, 0.97)`
  - `QiuJi/Core/Components/BTSceneFAB.swift:41` — primary 渐变尾色 `Color(red: 0.0, 0.45, 0.25)`
  - 对照 Features：`AboutView.swift:113-114` — `Color.gray` / `.gray`（非台面）
- **现状**：设计系统已有 `btBGTertiary` / `btPrimary` 等，组件仍旁路硬编码近似色。
- **问题**：对照 **D3**；Dark Mode 下 darkPill 已用 `btBGTertiary`，Light 却硬编码，两侧真源不一致。
- **建议**：Light darkPill → 已有近黑 token 或 `Color.btText`；Toggle 选中亮块 → `Color.btBG` / 显式 `btPillSelectedLight`；FAB 渐变尾 → `btPrimary` 衍生 token。
- **语义影响**：无（色值对齐现有观感即可，不改按钮角色）
- **严重度**：P3

### F-GL-08 BTButton 族内 text/destructive 无 scale，与其余变体不一致
- **类别**：B微交互 / D一致性
- **位置**：`QiuJi/Core/Components/BTButton.swift:83-99`（text 仅 opacity；destructive 仅 animation，无 scale）；对照 primary/secondary/darkPill 的 `scaleEffect(0.98)`（:49/:70/:123）
- **现状**：同属 `BTButtonStyle`，按压反馈强度不齐。
- **问题**：对照 **B1 / D2**——组件库内部标准不统一，页面选用 text/destructive 时手感变「哑」。
- **建议**：text/destructive 补 `scaleEffect(0.98)`（或 text 用 0.99），保持 `easeInOut(0.1)`。
- **语义影响**：无
- **严重度**：P3

### F-GL-09 溢出菜单弹出从 scale(0.9) 起跳，略偏「弹出」而非「淡入就近」
- **类别**：A动效
- **位置**：`QiuJi/Core/Components/BTOverflowMenu.swift:100`
  ```swift
  .transition(.opacity.combined(with: .scale(scale: 0.9, anchor: .topTrailing)))
  ```
- **现状**：自定义 popup 从 0.9 缩放 + 透明度进场；锚点在 topTrailing，空间方向合理（**A5** 部分满足）。
- **问题**：对照 **A6**——基准反对从 `scale(0)` 突现；0.9 尚未出局，但相对推荐的 `scale(0.95)+opacity` 仍偏「弹一下」。Preview 开关动画为 `easeOut(0.2)`（:125），生产 `BTOverflowMenu` 走系统 confirmationDialog，两条路径手感本就不一。
- **建议**：popup transition 改为 `scale(0.95)+opacity`；若继续双实现，文档标明 Dialog vs Popup 各自场景，避免同入口两套动效。
- **语义影响**：无
- **严重度**：P3

### F-GL-10 BTSegmentedTab / BTTogglePillGroup 切换时长未与 chips 族对齐
