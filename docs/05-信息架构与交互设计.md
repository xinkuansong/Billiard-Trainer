# 信息架构与交互设计

## 1. 产品设计参照

参照「训记」App（健身训练记录）的产品模式，将台球训练中的每个 Drill（训练项目）视同健身「动作」，建立完整的「台球动作库」。

**训记 → 台球 App 概念映射：**

| 训记概念 | 台球 App 对应 |
|---|---|
| 健身动作（如「杠铃卧推」） | 台球训练项目（如「五分点定杆练习」） |
| 动作分类（胸/背/腿） | 训练分类（准度/杆法/走位） |
| 训练计划（胸肌日） | 台球训练计划（今日专项走位训练） |
| 组数×重复次数 | 组数×每组球数（如「3组×15球」） |
| 进度（力量增长） | 进度（完成率/成功率提升） |

## 3. 各 Tab 信息架构

### Tab 1 — 训练（Training）

**定位**：日常最高频入口，引导用户完成每次练球，快速记录。

```
训练
├── 今日训练卡
│   ├── 当前计划名称（如「初级走位专项 - 第3天」）
│   ├── 今日计划内容预览（含Drill列表）
│   └── [开始训练] 按钮 → 进入训练记录流程
│
├── 训练计划
│   ├── 官方计划（按难度/目标分类）
│   │   ├── 入门阶段：「新手入门8周计划」
│   │   ├── 初级阶段：「基础杆法专项」「走位入门计划」
│   │   ├── 中级阶段：「加塞进阶计划」「分离角专项」
│   │   └── 综合提升：「全能训练计划」
│   └── 我的模版（用户自定义，从动作库选Drill组合；点卡用于今日）
│
└── 快速记录（不按计划，自由本次练了什么）
    ├── 选择球种（中式台球 / 9球）
    ├── 添加训练项目（从动作库选择）
    │   └── 每项：组数、每组球数、完成数、自评
    ├── 练习时长（自动计时或手动填写）
    ├── 心得备注（自由文本）
    └── 保存
```

**训练记录流程（核心交互）：**

```
开始训练
  → 当前训练项目卡片（全屏/半屏）
    → 显示 Drill 名称 + 球台动画（母球/目标球路线动画）+ 要点提示
    → 记录本组完成数：数字键盘输入「进了X球 / 共Y球」
    → [完成本组] → [下一组] 或 [下一个项目]
      → 完成所有项目
        → 训练完成页（总结 + 写心得入口）
```

### Tab 3 — 角度（Angle Training）⭐ 产品独创功能

**定位**：训练玩家对击球角度的视觉感知能力，配合「进球点对照表」提供角度瞄准法的完整理论工具。

角度预测页补充（2026-09-09，DR-125）：保留局部台面题图，下半区无键盘时展示本轮最近5题（最新在前，估角→实际、偏大/偏小及误差），空态使用简短答题引导。键盘展开时隐藏成绩区域并保持题面位置；换题保留成绩，重置统计清空本轮，原结果反馈与下一题入口保留。

**核心数学原理**：对于切入角 α，从母球方向看目标球，接触点偏离球心的距离 = R × sin(α)（R为球半径）。

```
角度
├── 角度测试（Angle Quiz）
│   ├── 顶视图球台
│   │   ├── 目标球（含袋口方向箭头）
│   │   ├── 母球（位置随机生成，切入角随机）
│   │   └── 题目：「这个切入角是多少度？」
│   ├── 用户输入方式
│   │   ├── 数字键盘输入角度估值
│   │   └── [确认] 按钮
│   ├── 结果反馈页
│   │   ├── 显示正确角度
│   │   ├── 动画标注：在目标球上标出对应接触点位置（高亮闪烁）
│   │   ├── 显示误差（如「你答了35°，实际是30°，误差5°」）
│   │   └── 「继续下一题」
│   ├── 测试设置（可选）
│   │   ├── 袋型偏好（全部 / 主练角袋 / 主练中袋）
│   │   └── 自适应权重开关（默认开启）
│
├── 进球点对照表（Reference Chart）
│   ├── 交互式角度滑块（0°–90°）
│   │   ├── 拖动滑块 → 目标球动态更新接触点位置
│   │   └── 数字显示：当前角度 + 接触点偏移（距球心 X%）
│   ├── 完整对照表（固定表格）
│   │   ├── 常用角度列表（5°/10°/15°/20°/25°/30°/35°/40°/45°/60°/75°/90°）
│   │   ├── 每行：角度 + 接触点示意图 + 偏移百分比 + 通称（如「1/2球」）
│   │   └── 公式说明：偏移量 = sin(α) × R
│   └── 学习说明
│       ├── 角度瞄准法原理解释
│       └── 如何将对照表用于实战瞄准
│
└── 历史记录（测试成绩追踪）
    ├── 历次测试平均误差趋势图（角袋/中袋分别展示）
    ├── 各角度区间热力图（哪些角度最容易答错）
    └── 最近N次测试记录
```

**角度测试交互细节（含自适应权重逻辑）：**

```
进入角度测试
  → 系统按自适应权重选题（见下方算法）
    → 显示俯视图：目标球（含袋口方向标记）+ 母球位置 + 袋型标注（角袋/中袋）
      → 用户目测角度，数字键盘输入估计值（整数，0–90°）
        → [确认]
          → 结果动画：
            1. 正确击球线高亮（从母球到目标球的实际击球线）
            2. 目标球面上接触点闪烁标注（偏移 = sin(α) × R）
            3. 显示幽灵球位置（可选，帮助理解）
          → 误差提示：「你答了35°，实际是32°，误差3°」
          → 判定结果（专业容差±3°）：✓ 正确 / ✗ 差X度
          → [下一题]
```

**自适应权重算法设计：**

```
出题权重 = 基础权重（30%）+ 误差权重（70%）

误差权重计算：
- 对每个角度区间（以5°为单位，0–5°/5–10°/.../85–90°）
- 记录最近10次该区间的平均误差
- 误差越大的区间，出题概率越高

角袋 vs 中袋分类：
- 角袋（底袋）：典型切入角范围 0°–75°
- 中袋：典型切入角范围 15°–60°（受台面几何约束）
- 每次出题在两种袋型间平衡（大约 60% 角袋 / 40% 中袋）
- 分开统计角袋和中袋的误差，分别做自适应

推荐每次训练题量：20题（约5–8分钟）

难度模式（仅一档，专业）：
- 容差 ±3°（答对：在正确答案±3°以内）
- 角度精度：实际题目以5°为整数精度生成（5/10/15/20...）

历史误差跟踪（对应历史记录功能）：
- 以5题为一组统计平均误差
- 历史图表显示误差随时间的下降趋势
- 分角袋/中袋分别展示（雷达图或折线）
```

**进球点对照表 — 核心数据（预计算）：**

| 切入角 | sin(α) | 接触点偏移 | 通称 |
|---|---|---|---|
| 0° | 0.00 | 球心（满球） | 全球 |
| 10° | 0.17 | 17% 半径 | — |
| 15° | 0.26 | 26% 半径 | — |
| 20° | 0.34 | 34% 半径 | — |
| 25° | 0.42 | 42% 半径 | — |

## 4. 核心用户路径

### 路径一：「今天去球馆，按计划练球」（高频场景）

```
打开 App（训练 Tab）
  → 今日训练卡（看今天练什么）
    → [开始训练]
      → Drill 1 卡片：示意图 + 要点
        → 记录每组进球数（大按钮快速点击）
          → 完成 Drill 1 → 自动进入下一个
            → ... 完成所有 Drill
              → 训练完成页
                → 可选：写今日心得
                  → 保存 ✓
```

**目标：从打开 App 到开始第一个 Drill，不超过 3 步。**

### 路径二：「想查一个技术动作」（中频场景）

```
动作库 Tab
  → 选分类（如「走位」）
    → 选子类（如「一库走位」）
      → 找到目标 Drill
        → 查看示意图 + 看教学视频 + 阅读要点
          → [加入下次训练计划] 或直接关闭
```

### 路径四：「专项训练角度感知」（中频场景）

```
角度 Tab
  → [开始测试]
    → 看球台图，目测切入角
      → 数字键盘输入估计角度
        → 确认 → 动画反馈（正确角度 + 接触点标注）
          → 误差提示 → [下一题]
（可连续练习，累积历史误差统计）

角度 Tab → 对照表
  → 拖动滑块选择角度
    → 实时更新目标球接触点动画
      → 查看完整对照表
```

```
历史 Tab → 统计视图
  → 看本月训练天数/时长概览
    → 点击某个 Drill 查成功率趋势
      → 发现薄弱项
        → 跳转到动作库查看详情
          → 加入下次计划
```

## 6. 设计原则

- **练球时手机使用场景**：球馆光线可能不足，文字应足够大；主操作按钮大而易点（44pt以上）
- **单手操作优先**：底部 Tab + 关键操作按钮置于屏幕下方，符合拇指热区
- **减少打断**：训练中记录流程不强制输入文字，进球数用数字大按钮快速点击
- **HIG 一致性**：使用系统字体、SF Symbols、标准 Sheet/NavigationStack 模式
- **离线优先**：动作库内容和训练记录功能完全可离线使用，同步在后台进行（Bundle + 自建 API，见 `docs/06` ADR-002）

## 8. 每日清台路径与状态（v52）

```text
训练 Tab → 本周训练卡片右侧「每日清台」
  → 当天无草稿：读取默认玩法 → 摆架并调整母球/方向/力度/打点 → 手动击球 → 停稳后点完成进入清台
  → 当天有草稿：「继续清台」→ 恢复同一球形、规则、杆数、犯规数与有效用时
  → 当天已完成：「今日已清台 ✓」→ 完成总结 / 再来一局（不重复累计当日完成）
```

- 右上角菜单的「击球设置」提供瞄准模式（进袋/自由）与轨迹显示（全部/双球/瞄准线）；每日清台2D/3D不再显示独立配置按钮，播放、开球和结算时禁用切换。
- 首次进入、「再来一局」、切换玩法与重开均只摆架，默认8 m/s，等待用户手动击球。旧自动开球中草稿保留原种子并迁移为待手动开球；移除旧V1终局球落袋后的自动重试。
- 「重新开球」进入手动摆架/开球流程；已有用户击球时先确认放弃本局进度。
- 「切换玩法」只改变当前新局，不写回偏好；偏好设置的变化只影响下一个无草稿新局。
- 每日清台默认横屏2D，球库、2D/3D切换与设置按钮统一顶行高度；球库按玩法显示母球及本玩法球号：母球独立放左侧，目标球行与球桌区域中线对齐。中八1～7与9～15左右对称，8号对准2D中袋；追分9/6/5/4球按实际目标球集合居中。已进球变暗并保留占位；两侧操作列等宽（DR-335）。左侧方向尺、右侧打点与力度，框内底部显示“方向”“力度”和数值；力度条松手只结束调整，只有击球按钮执行出杆。返回首页恢复竖屏。
- 3D场景铺满每日页面，HUD浮在场景上层；合法点球与2D共享目标/假想球/轨迹/袋口选择，求解后转到以该目标球为中心的第三人称，非法点球保留原目标并提示。点母球进入第一人称，不改变击球选择。第一人称眼位按实际击球点、杆轴和抬角计算（沿杆后退90cm、垂直高于杆轴13cm），运杆不带动头部；第三人称同时照顾母球与目标球构图。所有每日相机入口限制水平视野不超过56°；普通出杆从第一人称起身到以母球为中心的第三人称，第三人称或手动观察出杆保留视角，开球保留原镜头。手势接管取消自动切换；捏合起始处接近母球或当前目标球时选择对应观察中心，同一手势不反复切换，放大只改视野并降低旋转灵敏度。继续缩小到边界时恢复全桌；独立相机按钮从上至下为“全局／观察／第一人称”，第一人称采用朝左的俯身击球实心人物剪影。其他页面保持既有相机配置。
- 打点盘四向按钮位于白盘上下左右，触摸区44pt；交互红点半径缩小为原来一半，不改变物理打点值。背景底边以库鼻投影为准，任意自由视角无法安全定位时回退到可见安全区，2D/3D使用同一布局。

- 中八V2由一个用户轮流操作两方，合法进球后定组，未进本组球或犯规换手；常驻当前全色/花色/黑八阶段提示，非法选择说明正确球组，犯规说明原因、换手和自由球权限。合法打完一组及黑八完成；黑八提前进袋等规则判负结束本局。

- 未终局“重打”回滚整杆盘面、规则、轮次、计数、打点力度、瞄准与镜头。撤销历史仅本次会话保留，重启后禁用；终局不撤销已保存完成。旧V1草稿继续旧规则并显示旧规则提示，重新开球后使用V2。
- 首页入口保持独立可聚焦、可点击，无障碍标签包含当前三态和玩法；从每日页返回仍停留在训练 Tab。
