## 推荐决策

保留当前生产平面裁定方式。标准台面尺寸、球半径、坐标转换及CAD设计几何仍是规格基准；库鼻显示模型对齐这份规格，用整颗球与真实三角面验证一致性。修改接触轮廓时同时验证台呢口沿，实际捕获轮廓继续与加载后的台呢一致。

选择该路线是实施建议，尚未修改几何真源。原因：现有标准台面、教学坐标和解析库边共同依赖该规格；直接把当前显示网格的毫米误差变成新的标准边界会扩大动力学与教学消费方变化。保留当前外观风格，校正库体接触轮廓及必要连接处，不用整桌缩放代替局部校准。

本轮不切换完整三维物理，不通过缩球、扩袋、低速自动收袋或显示层挪球消除症状；摩擦/恢复系数调整不作为穿透修复手段。

## 实施顺序

### W0：固定失败输入与基线

- 把场景A/B/C、15.087ms漏根系数、近零圆弧接触及静止分离反例转为正式回归。以原始世界坐标固定输入，保留生产事件与最终球态。
- 固定当前模型和源码哈希、2250组参数清单以及历史普通球/贴库/走位对照输入；保存旧版输出。保留独立根参考与实际三角面检查，不能把实现本身当期望。
- 每批单独验证和记录，先分辨动力学改动与资产改动造成的差异，再做合并验收。

### W1：修圆弧连续碰撞检测

目标：消除毫秒级漏根及零/亚微秒合法碰撞被过滤。

- 给圆弧CCD提供有界实根隔离入口：时间区间归一化、按导数临界点分割单调区间、保界精修，并检查临界点接触。不能仅扫描固定时间点或依赖首尾变号，否则可能漏掉中途接触/转向。
- 时间窗止于当前运动方程有效的状态转换或外部事件；候选根再检查真实距离残差、逼近方向和有限弧范围，选择最早有效接触。
- 统一直库/圆弧已接触且逼近的t=0契约，保留合法正根；退离与切向球不能重复施加反弹。坐标误差按表示精度计算，不用固定时间下限代替几何校验。
- 第一批优先只替换圆弧CCD的求根入口，控制全局QuarticSolver及球球碰撞的改动范围。完整引擎与解析搜索共用该检测器。
- 验证原15.087ms有效根被检出、750组邻域无新增圆弧穿透、镜像与不同时间窗一致；检查无接触时的假碰撞、接近/退离与重复零时刻事件。记录热预测开销。

### W2：对齐模型与物理接触边界

目标：正常碰撞与正常停稳位置也不进入可见库鼻。

- 按标准几何分别校准主长库、主短库、12条袋角圆弧及必要连接段。核对资源几何与加载后的缩放/高度，先定位误差来源，再校正库体；不能给全桌统一加减1.5mm。
- 比较整球的三维接触包络，球心Y使用台呢Y+R；不能只把俯视网格边线当碰撞线，也不能将已含R的球心包络再加一次R。
- 导出后重新加载正式资源，以三角面独立验证接触位置、缝隙、弧端和镜像。核对台呢捕获口沿是否改变；如有改变，重新提取同版口沿并做六袋进/挂/弹出测试，不能沿用旧快照。
- 模型、碰撞几何与实测口沿记录相同资产/规格版本，加入资产一致性回归，防止以后换USDZ再次错位。
- 本批交付场景A/B同机位的前后截图及模型接触误差图。保留材质风格、球径、标准有效台面与教学坐标契约。

### W3：补实体约束与合法终态

目标：漏检或球球分离留下的穿透不能被当作正常停稳交付。

- 袋口通道豁免与实体穿透恢复分开；基于有限库段、有限弧和真实接触侧判断，不用袋心邻域return掩盖穿入，也不用矩形延长线堵住袋嘴。
- 球球分离联合满足球间与库边单侧约束，不能先推球再独立矩形钳回。移位后作废该球的全部受影响事件缓存。
- 小数值漂移按接触法线作有界校正；超出数值预算应拒步重算或返回明确失败，不能把厘米级推位当正常修正。
- 所有球变stationary以及开球结果分离完成后，验证球体不穿实体、球球不重叠，再允许完整终态输出；保存/回放使用同一个已提交终态。
- 恢复与拒步必须同步处理位置、速度、自旋、时钟、记录和缓存。实际冲量才记库事件，位置校正不得虚增吃库次数。

### W4：合并回归与交付

- 重跑2250组低速参数，追加滑动/侧旋、沿库擦行、弧端接缝与低速双球挤库；检查原始物理帧、解析回放和真实节点显示三层。
- 重跑近零圆弧矩阵、16组合法贴库双球、256局固定种子开球，检查实体穿透、球球重叠、捕获和终止原因。
- 普通六袋球、贴库进球、挂袋/弹出与固定有效走位解逐项前后比较；同时比较解析与完整引擎。真实接触导致的结果变化须逐项解释，不能靠总进袋率或测试绿灯声明无回退。
- 既有两库代表解丢失按历史问题单独记录：固定旧offset重放检查有效性和本轮增量影响，不把已有搜索回退混作本轮新缺陷，也不据此宣称全求解已恢复。
- 提供相同输入、相同机位的A/B/C修复前后图、最大穿透/停稳误差表和预测耗时对照。自动验证、用户视觉确认与真机复现分别记录。

## 建议验收门槛

以下为实施目标，不是已有测试结果。

| 项目 | 门槛 |
|---|---|
| 碰撞检测 | 固定漏根、近零接触均检出；退离/纯切向不误反弹；无零时刻事件风暴 |
| 引擎实体侵入 | 批量原始帧及停稳态最大不超过0.01mm；数值余量需有表示精度/算法误差依据 |
| 模型接触一致性 | 非捕获接触包络最大误差目标≤0.10mm，覆盖弧端/接缝；真实截图无可见吃库 |
| 合法终态 | 完成标志与已提交状态一致；无法恢复的实体穿透不得返回可交付终态 |
| 袋口行为 | 合法挂袋不因低速被吸走，袋嘴通道不被矩形延长库封闭 |
| 消费者一致 | 预测、实际击球、回放、开球停位消费同一几何/终态，无显示层单独挪位 |
| 回归变化 | 新增丢球/落袋/吃库变化逐项解释；合法固定解及反解覆盖单独验证 |

实施结果：W0–W4已完成。2250低速与3840侧旋/接缝全部正常停稳，786个模型接触测点最大误差0.084mm；145项覆盖经环境修正复测通过。下一步为用户看图与真机复现，历史两库搜索问题保持单列。
