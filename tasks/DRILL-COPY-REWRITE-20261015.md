## 4. 字段职责与写作质量

**统一规则入口**：执行[动作库内容重写统一规范](../docs/research/20261015-动作库内容重写统一规范.md)及共同流程。下表仅作字段摘要；R4教学定位未通过，2026-10-16已授权R5隔离样稿重写，按当前流程完成资料与理解审核后进入写作。

| 字段 | 职责 | 禁止 |
|---|---|---|
| description | 一至两句写清任务和主要能力，体现本动作与相邻动作的差别 | 把参数、剂量、摆球坐标和操作列表全塞进去 |
| coachingPoints | 最重要的动作、观察信号、下一球调整；第一条可独立用于试打和计划页 | 三条换词重复；“注意稳定”“提升水平”等空话 |
| standardCriteria | 可观察的合格判据，表达清楚既有目标 | 擅自改数量、成功率、重试规则、母球留台或走位要求 |
| 球形精讲 | 本形适用打法、原因与走位目的，必要时补纠错 | 无用描图、参数复读和可互换模板；不得借去重删掉下一颗及袋口用途 |
| 逐杆 params | 与对应序列 shot 的 spinX/spinY/velocity 精确一致 | 沿用旧教程参数；把碰前母球速度当杆头速度 |
| caption | 杆序、必要的瞄准角，简短清楚 | 实际切角、混淆角度名称、重复杆法力度与正文 |
| 标题／节标题 | 清晰对应课、球形、杆序、目标 | 改稳定 ID、删逐杆结构、为了好看重排杆序 |

逐杆角度展示建议采用一位小数（如“瞄准角约 30.4°”），保留源精度用于核验。最终格式随样稿定调，所有批次一致；不要逐课选择精度或显示不必要的长小数。

analysis 的正文准入标准：这条信息能否帮助学员决定“这一杆先做什么、看什么、错了怎么调整”？不能则留在证据卡。碰前滑动／滚动、吃库事件等可在有教学价值且有事实支持时转成自然语言；引擎版本、事件时刻、速度向量、角速度、滚动比例、精确行程等默认不上屏。不得新增“物理分析”区。实际切角始终仅作内部诊断。

同一动作要有一个明确的核心训练目标；每个球形写出自身区别。同组相邻动作做“互换测试”；三课连读检查同构句式。只保留会改变下一杆做法的信息。独立重复、连续走位、独立防守场面、规则课按实际教学语义分类，不能只凭坐标是否衔接来判为连续训练。

### 6.2 隔离、集成和漂移

- 执行时为每个活跃批次建立独立受管 worktree／分支（`codex/` 前缀），先查附着记录并复用合适工作树。按已冻结的当前工作区文件覆盖所需输入，不能直接从旧 HEAD 写作；覆盖来源与 SHA 均记录。

- 委派提示只给范围、事实包、规范链接、允许文件、交付物与验收标准；不预写答案，不将教练话改造成填空模板。

- 每批串行集成后验证，再集成下一批。共享脚本、index、台账和项目文件不得由多个写作者同时改。

## 9. 写作、复核与验收闭环

### 9.1 单动作交付物

1. 直接编辑的完整 Drill JSON 草稿与差异。
2. 一张证据卡：训练意图、主练能力、各球形差异、逐图查看记录、事实来源、疑点与采用／未采用的 analysis 信息。
3. 逐杆核对表：step ID、section、image、shot 参数、瞄准角来源与格式；规则课给出规则和页面行为来源。
4. 自检报告：技术断言、图文分工、相邻项互换、口头教练测试、参数／角度检查结果。

### 9.2 分层验收

| 层级 | 执行人 | 必验内容 | 通过证据 |
|---|---|---|---|
| 作者自检 | 子智能体 | 每动作全部字段／球形／图片；语义、参数、角度、结构和范围 | 逐图记录、差异、校验日志 |
| 交叉审稿 | 另一子智能体 | 全文读稿和相关图；因果、错法诊断、旧数据残留、无依据推断、analysis滥用 | 可定位到字段／杆的报告；无问题也说明核对范围 |
| 主控独立验收 | 主控 | 逐动作读最终文案、逐杆核对图和事实、审范围；不能只读作者摘要 | 逐项接受／返工记录和实际日志 |
| 集成验证 | 主控串行 | 本批白名单、原字段保护、JSON解码、全库门禁；确认集成版本与受审版本一致 | 基线SHA、diff、退出码、通过数量 |

### 9.3 自动检查

每批集成后：

- 原始 JSON 解码；字段白名单 diff；74 ID 无增删，稳定 token／step 关联不漂移；相关源与保护字段 SHA 不变。
- 本批所有逐杆 params 与对应 shot 精确一致；caption 数值与瞄准角格式一致。缺角不补值，不混入 actualCutAngleDegrees；保留课名／理论术语的显式例外，不用简单的“所有度数都报错”。
- 图片引用存在、source/image/step 映射正确，逐杆节数与序列一致；不能靠删除节／图片让门禁转绿。
