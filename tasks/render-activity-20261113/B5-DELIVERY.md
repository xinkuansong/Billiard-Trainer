## 最终 CPU 比较的口径

使用真实优化前提交 `f516e36b4` 构建的 A 与最终组合 App B，避免把 B1 reference 开关冒称完整前版本。A 使用独立 worktree/DerivedData；补入同源本机忽略资源，未修改跟踪源码。267 项图形资源 SHA 一致，基线/候选的实际安装二进制逐臂读回。基线构建临时目录已回收，日志、资源清单、App 指纹保留。

预定顺序 A、A、A、B、B、A：前两臂 A/A 估噪声，后四臂构成 AB 与 BA 两组。每臂同一个原生 XCTest，固定每日 closeup0 球局、green/tournamentBlue 台呢、2D/3D、方向尺按住 12 秒；记录 marker 后约 2–7 秒的整个 App 进程累计 CPU 差分，截图在采样后取得。工作计数关闭，双方都不启用 reference 参数。CPU 以单核心 100% 表示。

每个状态独立判断：两组下降均须大于 `max(5%, |A/A 相对变化|)`；未达就不宣布稳定百分比。该窗口是完整页面中的“按住瞄准、球静止”场景，**不是三分钟连续击球、纯 GPU 时间或瓦特**。没有为满足统计门槛追加采样。原协议/脚本/逐臂日志见 `output/render-activity-20261113/b5/`。

## 六轮最终结果

六轮原生 selector 全通过，24 个采样窗口有效；逐臂 App SHA 与安装包一致。完整原始数值及环境见 [B5-results.json](B5-results.json)，预定顺序见 [B5-protocol.json](B5-protocol.json)。下列 A/B CPU 是两组配对臂均值，A/A 不混入基线均值。

| 状态 | 基线进程 CPU | 候选进程 CPU | 均值相对下降 | AB / BA 相对下降 | 判定门槛 |
|---|---:|---:|---:|---:|---:|
| 绿色 2d | 17.96% | 15.26% | 15.06% | 13.68% / 16.40% | 10.97% |
| 绿色 3d | 19.11% | 14.55% | 23.89% | 19.82% / 27.52% | 10.85% |
| 蓝色 2d | 17.90% | 15.13% | 15.47% | 16.71% / 14.24% | 5.00% |
| 蓝色 3d | 19.27% | 15.01% | 22.10% | 20.99% / 23.18% | 7.58% |

四个状态两组下降均超过各自门槛，支持“本机固定按住瞄准窗口中 CPU 工作下降”的结论。两种 3D 台呢的均值下降约 22%–24%；2D 约 15%。**不能将这个比例套给分离角与走位连续击球、所有页面、整机能耗或温升**。整段训练中近景可见时长和活动组成不同，GPU 与帧尾没有在同窗量化。

实际窗口为 4.719–5.099 秒，均以各自实际墙钟秒归一化；开始距 marker 2.10–2.31 秒、结束 7.01–7.21 秒，在 12 秒按住期间。初版汇总脚本自设的 4.8 秒下界断言不匹配 0.2 秒轮询加 PID 查找延迟，报错原版已留存；按原协议“约 2–7 秒”核持有区间及实际时长后汇总，未改变收益门槛、原始数据或追加轮次。见 `output/render-activity-20261113/b5/analysis-correction.json`。

## 明确待验与后续边界

1. 手机 CPU/GPU 同一窗口、帧尾、三分钟热体验未验。不能把本机 CPU 减少换算成手机温度或能耗占比；也不能推断持续击球的主要热源已经消除。
2. 当前可用核心 iPad 验证与源码覆盖不能替代 iPhone 尺寸、最低 iOS17 和所有页面的实际 UI。未占用受保护的其他核心设备。
3. 正常 Release 仍受既有 API_BASE_URL 配置阻塞；非 DEBUG 条件编译通过和开发签名成功分开记录，不宣称可直接发布 App Store。
4. 本轮没有新常驻定时器/全局节点缓存，局部订阅生命周期与两杆进退已定向检查；没有把短生命周期检查写成无限时长 heap/RSS 无泄漏证明。
5. C1 静态低维表示、C2 输入预测去重均未触发；本轮证据不足以启动新的大改。下一步先用已封存候选在手机方便时完成短采集预检，再决定集中温升对照，不重跑旧 guard 基准。

尤其需要保留这一判断：用户描述的“操作/击球时逐渐发烫”尚未由本轮改动验证解决。B1 的明确收益集中在近景可见窗口；B2 缩减活动维护；台呢/GPU 固定着色成本本阶段没有新下降证据。不能用最有利的 HUD 窗口代替整段训练的收益。

原图复核：真实 pre-B1 A 与 B 在 3D 模式切换后的特写落位/背景可见外观存在差异，与 B1 已记录的显隐回调/迟滞重置修正有关；不能说两张最终画面逐像素相同。球桌、球局、材质资源相同，所审截图均显示 60 FPS，但单张读数不等于整个 CPU 窗口的帧尾采样。B5 只比较完整组合，纯刷新器隔离证据仍取 B1 同二进制对照。

本机采样期并非专用空闲机器：load average 在原始逐臂记录中留存，同版本 A/A 的四个状态相对波动为 10.97%、10.85%、4.54%、7.58%（取绝对值）。它只能估计此次观察到的噪声，不能消除其他进程、帧调度和设备差异；不把跨设备普遍百分比写入结论。
