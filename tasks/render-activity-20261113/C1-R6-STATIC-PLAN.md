# C1-R6 固定灯几何响应场：研究协议

2026-11-13。用户已授权持续探索台呢逐帧复用。本轮仅研究，不默认批准有损候选进入生产。

与失败路线的区别：只预计算矩形灯的**视角无关、球态无关、法线无关**几何向量积分。每个世界位置每盏灯一个float3；真实法线在消费者中点乘，高光BRDF、遮挡、AO、采样数与材质照常计算。旧18层动态可见度场随球位重建；本字段在灯/域改变时才生成。缓存键不含球位或相机；没有逐屏幕输入键或片元写入。

变量域：SceneKit世界米，位置顺序X/Z/Y。X[-1.6,1.6]、Z[-0.95,0.95]、Y[0.65,0.9]。仅在实际p位于域内，且两灯全部四角在真实纹理法线的正半空间时使用；跨地平线、域外保留原精确裁剪积分。使用真实p.y，不假定台呢平面。

候选为两张256×128×16 RGBA32F三维纹理，总显式存储16MiB，shader硬件线性插值。它是**空间插值近似**，不能继续使用此前逐位无损名称。

事前研究规则：先查字段有限值、真实消费者显示与域外回退；18个固定球态输出每通道最大误差/变化像素数、原图，基线A/A分开记录。生产资格仍为false；有任何像素差都不能称原零差合同通过。即使数值不同，也允许本研究轮记录成本，以形成可审阅的误差/收益权衡，而不是改绿旧断言。若出现可见结构性瑕疵或大差异，停止性能扩展；若性能无可靠净收益，也直接淘汰。

完整成本：实际USDZ/TaiNi、HDR/4xMSAA；单独记录一次字段生成GPU、分配字节和CPU准备；消费A/A及ABBA/BAAB六组；60帧加生成后的摊销明示。命中图验证真实路径。仅在收益与画质均值得时形成生产候选，手机不参与本轮。
