# 密集球阵碰撞时序与顺序不变性诊断（2026-10-26）

状态：诊断完成，确认当前密集球阵求解存在显著注册顺序偏置；生产代码未改，尚未修复。

## 范围与协议

用户同意固定当前摆球与10m/s，对比镜像/倒序并检查冲量时球是否接触且靠近。取此前图册固定100副（rackID11300–11399），当前生产radial_sideM60球位；正中锁定实际顶球、零塞、15球、预算8000事件/30秒。全部保留，不按开散或完成率筛选。

SceneKit XZ台面/Y向上，位置米，速度m/s，角速度rad/s。镜像为z→−z；线速度同变换，角速度作为轴向量变换为(−wx,−wy,wz)。保留球号及球的身份，镜像后slot10身份移到−Z一侧，不能仍称其“下角”。倒序仅倒转目标球注册数组，母球仍先注册；几何、球号、瞄准、杆速、实际初始速度均逐项相同。

第一轮100×4=400次：原样、倒序、镜像、镜像+倒序；12次额外原样复跑。研究引擎仅增加beforeKiss/beforeImpulse/afterImpulse三个只读观测点及辅助收集器；逐字剥离后与生产引擎完全相同。导出首次球碰球后20ms的全部球对冲量账本、1/5/20/50/100ms状态、最终落点及纯自旋尾段。

第一轮发现镜像的实际母球初速度有≤5.99181e−6m/s误差（CueBallStrike中Float atan2/旋转三角函数）；原样与倒序无该差异。最初严格初速度镜像断言失败，保留事实，未将其放宽后宣称严格通过；第一轮verification.json明确mirrorInitialVelocityExact=false。

因此第二轮补200次：正序与倒序各100副，显式使用对应原局实际初速度的严格镜像，角速度仍0。研究副本BreakSimulator仅将母球velocity允许由研究入口覆盖，生产文件未改；6次原速度覆盖对照与第一轮原局全字段一致。两轮共600个对照结果+18次复跑=618次原生模拟。

## 主要结果

能量份额为首次球接触后5ms、全部15颗目标球的平动能份额，不含母球或旋转能；先逐局求比例，再对100局平均。

| 原始球形、只改变注册顺序 | 原顺序 | 倒序 |
|---|---:|---:|
| 下角slot10平动能份额 | 74.766% | 4.311% |
| 上角slot14平动能份额 | 5.645% | 74.377% |
| 有明显自转尾段 | 74/100 | 46/100 |
| 尾段超过5秒 | 54/100 | 0/100 |
| 尾段平均（含0） | 4.405秒 | 0.676秒 |

仅倒序的100/100局均未通过早期不变性：5ms逐局最大球速差均值8.862m/s、最小5.658m/s；逐局最大位置差均值44.31mm。最终球位100/100不同，落袋集合仅27/100相同。这不是小数值抖动，而是不同碰撞链优先传力造成的宏观差异。倒序后的强能量球改为slot14；不据此选择倒序作为生产“修复”。

严格镜像200/200通过：两种注册顺序各自镜像后，5ms各球位置/线速度差均为0，包含角速度变换的早期检查100/100；最终落点在预设1mm内100/100、落袋集合100/100相同；尾段均值也分别保持4.405/0.676秒。第一轮未隔离击球三角函数误差导致的终局镜像差异不能用于指控球桌/碰撞镜像缺陷；补充对照排除了该混杂。

## 直接时序证据

原顺序100局首次接触后20ms内共3256次球对冲量，其中：
- 3163次在make-kiss修正前净距>1µm；其中3032次>0.05mm、2980次>0.10mm。
- 最大仍分离净距0.249743mm。>1µm统计包含先前make-kiss保留的10µm间隙；>0.1mm的2980次不受此解释影响。
- 每局平均31.36次连续冲量与上一冲量时间完全相同。
- 这100局/20ms窗口没有发现pre-impulse接近速度<−1e−4m/s的分离冲量。此结果不覆盖全程、其他种子，不推翻旧研究发现的分离根异常。
- 被观察球对的平动+旋转总动能均未增加；能量不增不等于时序正确。

代码链：`EngineNumerics.isBallPairOverlappingOrTouching`允许接近中的球在2R+0.25mm内返回true；EventDrivenEngine将其加入time=0/priority=−1候选；同优先级同刻候选由遍历顺序选取，解算后即时改速度，再寻找下一碰撞。makeBallBallKiss对已经超过2R+10µm的球直接返回，并不会先推进至真正接触。

因此本轮确认：当前0.02–0.38mm间隙球阵中，部分本应存在先后的接触被提前处理成零时间连锁碰撞，顺序决定了哪条链先获取能量。这解释了角球一侧长期强传力/强碰库/自转拖尾。不能把故障简单归因为所有密集接触都必须同时求解；有间隙先纠正碰撞时间，真正同时接触再单独定义联合解算。

## 修复方向（尚未实施）

1. 把实际接触/穿透几何与数值误差分开：有可分辨净距时应预测首次接触时间，不能用0.25mm窗口直接施加冲量。
2. 接触时再次核验几何、接近方向和有效根；把穿透位置修复与碰撞冲量分开，避免“修位置必碰撞”。
3. 对真正同刻多接触另立明确模型，检查排列不变性；不能靠固定球号排序或换注册顺序伪造稳定。
4. 正确性门槛先看时序/接触、排列不变、严格镜像、能量与停止；再复测原生产摆球与当前优化摆球的开散均分、1.2比例、刮杆和耗时。此前最优仅代表当前求解器下结果，修复后需重新验证；本轮不回退用户已批准的摆球或速度10。
