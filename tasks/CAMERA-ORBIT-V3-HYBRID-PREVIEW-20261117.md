## 设计修正

V1/V2 将“稳定”约束为到桌心的固定距离。长方形球桌在长库方向离桌心较近，圆形轨道会使该方向的桌边退距偏大。V3允许距离随方位有规律地变化，保留固定焦距、固定关注点与连续起停。

本轮借用当前凹面的“按方向调整观看远近”这一优点，定义独立的椭圆轨道；未直接复制整套凹面高度／距离／关注点／FOV耦合公式。

### 绕台

短库方向半径沿用V2的3.600133m。场景外沿半长1.41m、半宽0.78m，令两个正对库边方向的水平退距相同：

```
a = 3.600133
clearance = a - 1.41 = 2.190133
b = clearance + 0.78 = 2.970133
r(theta) = 1 / sqrt(cos(theta)^2/a^2 + sin(theta)^2/b^2)
```

Blender XY水平、Z向上，X为桌长。θ=0是短库方向，θ=-90°是长库方向。该等退距只针对两个轴向，不宣称任意方位到最近桌边的距离恒定。

长库边比V2靠近63cm；绕到短库边时恢复到V2原半径。椭圆半径连续光滑，两个轴向的径向导数为零，没有按角度区间跳档。原来的38mm焦距、桌心球心高度关注点和眼高保持，不靠变焦补偿。

### 抬高

高度独立更新：`r(theta,h)=r(theta)`。固定θ时保持眼点XY位置，Z从1.05升到1.758m，视线持续看向同一个桌心关注点。

在本轮约-36.87°的对角起点，V3水平半径恒为3.329865m。V2从3.600133m向内收到3.309665m；当前凹面从约2.821m向外退到3.559m。V3的三维观察距离会随升高增加，因此不宣称保持主体尺度完全不变。

此改动使绕台的远近规则与抬高的前后运动分开；未来如确需抬高时轻微后退，应作为独立参数测试。本轮未加入后退量。

### 可重放与交互范围

相机由方位、高度、椭圆长短轴、固定关注点和焦距确定。导出每帧位置、朝向、FOV与投影参数；同一状态可重复求值。自动演示沿用4秒五次平滑进度，返回复用源帧。

它是全桌观察候选，不覆盖沿杆低位、击球特写、移动目标跟随、输入增益、手势中断、原生延时和设备性能；未接入App。

## 对比与取舍

两段三栏视频从左到右为当前凹面、V2、结合V3。每格960×600，最终2880×712、30fps、12秒、360帧；1秒起点、4秒正向、2秒终点、4秒原路返回、1秒回起点。

V2和当前凹面复用上一轮484张基线帧，V3补242张。V2/V3保持相同高度、绕桌心方位、时间、关注点与焦距；抬高初始距离不同，完整方案对照不能当成只有抬高规则变化的单变量实验。

已审关键帧：V3长库边起点更近，左右两端桌边／角袋区域有裁切；抬高终点近处袋口外沿与桌裙也有裁切。绕台台呢有效矩形四角最外投影约为画宽-2.25%到102.23%，不能声称台面全范围在画内。该矩形为保守角点判据，实际口沿轮廓以成图为准。

当前版本优先检验“长库靠近、短库退远”的观察感，不兼顾全桌完整入镜。是否需要更宽固定视角或弱化椭圆幅度，待用户观看反馈后另测；本轮保持38mm以便与V2比较路径变化。
