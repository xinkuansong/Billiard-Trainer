状态：已实施并完成定向模拟器复验，待用户实看。按批准文字方案落地，生成对比图不作为视觉基线。真机、VoiceOver、分屏与全App发布验收未覆盖。

## 范围与顺序

- 角度/瞄准点 2D、3D：训练量20题/持续练习 → 角度综合0–85° → 球形条件综合 → 恢复默认；抽象训练不增加设置。
- 准度：训练量 → 自行调整高低杆/左右塞（均开）→ 角度 → 球形条件 → 系统指定高低杆/左右塞（均关）→ 恢复默认。逐轴互斥保持。
- 分离角：训练量 → 参考路线杆法（两项均开）→ 角度0–50° → 球形条件 → 演示与参考（播放开、提交后保留中杆参考关）→ 恢复默认。
- 两球：独立走位模式 → 训练量 → 轨迹模式专属参考路线杆法 → 第一杆角度/球形条件 → 演示与参考 → 恢复默认。默认轨迹；两模式分别记忆草稿与已确认设置。自由模式出题不受隐藏的路线杆法筛选限制。
- 三球：提前选下一球袋口，完成两次连续走位 → 训练量 → 第一杆角度0–50°/球形条件 → 演示与参考 → 恢复默认。前两球同组不同号，第三球黑八。
- 多球：玩法（顺序）→ 走位模式（规划）→ 球数（4）→ 中八对手球（0）→ 仅2D训练量（3题）→ 规则 → 恢复默认。
- 蛇彩：球数5 → 顺序右到左 → 最近10次默认折叠 → 恢复默认。
- 自定义：标题选择球形，保留模板、管理、新建、有效选择才能开始；无通用筛选或重置。

筛选名称：母球到目标球、目标球到袋口、目标袋类型、目标球离库；随机档改称综合，概率与多选规则保持。球形条件默认展开。2D/3D偏好独立，取消不保存，验证出题成功后才提交；历史成绩不迁改。
