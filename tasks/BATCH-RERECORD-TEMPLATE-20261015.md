# 连续重录沿用原参数

用户授权：从头重录／选杆重录后续逐杆带入原打点、杆速、瞄准设置，桌面沿上一杆新引擎停点继续；保留原序列备份，物理与瞄准算法不变；iPad 竖屏验证并交付重录。

## 实现

- PositionPlayViewModel 保留编辑会话中的原序列参数模板，完成当前杆后按新记录杆数加载下一杆输入，仅继承 shot，不读取下一杆旧 before/after。
- 重打恢复刚录的实际输入和起点，模板不多前进；选单杆、回末尾续录、回上一杆球形追加、换序列／重置时退出模板模式。
- 原目标不在台上时提示重新选择，不自动替换目标；自由／袋口模式沿用现有恢复和求解逻辑。
- 覆盖保存前，将同球形旧文件原字节复制到序列目录 `_backups/<UUID>/`，备份失败则停止保存；原子写入新文件后移除旧命名文件。没有隐式保存序列。
- 参数模板仅在当前编辑会话内保留；退出后可从旧文件备份恢复原完整序列。
