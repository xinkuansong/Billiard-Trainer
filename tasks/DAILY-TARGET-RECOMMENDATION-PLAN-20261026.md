# 中袋可行区域与每日清台目标推荐方案

日期：2026-10-26。角色：Orchestrator。状态：用户已授权实施，生产代码接入与定向验证完成；实际结果见[接入卡](DAILY-TARGET-RECOMMENDATION-IMPLEMENTATION-20261026.md)。

## 1. 目标与第一版范围

在当前盘面中，自动推荐一组“目标球＋目标袋”，优先选择当前这一杆相对好打的直进球。推荐过程为：**合法目标 → 可行性筛选 → 现有走位后评分 → 选择最高分组合**。

用户已明确：只做初步推荐；中袋过于贴库的入袋方向先用独立实验找到可行区域，并把区域判断做成可复用能力。本方案沿用这个范围。以下为已获实施授权的第一版设计；后续验证与交付状态以接入卡为准。

第一版不评价下一杆走位、不搜索清台顺序，不为每个候选跑物理模拟，不增加袋口容差、旋转、杆速等新评分项。两球走位后评分本身衡量的是停下后“下一杆好不好打”，因此可以直接用当前母球位置评价每日清台的“这一杆”。

## 2. 筛选什么

推荐单位是球—袋组合。一个球的某个中袋被排除后，仍可评估它的其他袋口。

|顺序|检查|处理|
|---|---|---|
|1|当前玩法允许首先击打的在桌目标球|沿用规则层提供的合法集合，不能因分高越过球序或球组限制|
|2|目标球对该中袋是否落在可行区域内|对当前已标定球桌的中袋使用下述区域；角袋沿用现有检查|
|3|该组合是否有可用直击瞄点|沿用有限袋口瞄点、假想球在台内、正向切球和主库检查|
|4|母球到假想球、目标球到瞄点是否被其他球挡住|沿用球体半径净空检查；不能只看球心线相交|
|5|对保留下来的候选计算W|只排序，不把低分等同于不可行|

区域内表示“允许继续找直进方向”，不是保证进球；有限瞄点未找到路线表示“本次不推荐”，不向用户宣称物理上绝无可能。区域外的排除也只用于本版直进推荐，不禁用手动选择、翻袋或其他打法。

### 中袋区域的正式口径

采用本轮原生物理实验与几何复核结果。SceneKit世界坐标水平面XZ，单位米、Y向上；横桌+X向右、+Z向下。袋4为Z负侧中袋，袋5为Z正侧中袋；竖屏只改变显示名称，不改变公式。

```text
side = -1（袋4）或 +1（袋5）
depth = innerWidth / 2 - side × target.z
boundaryDepth = 0.009263577586 + 0.299831653320 × abs(target.x)
候选区域：depth >= boundaryDepth
```

边界线与长库夹角16.6904°、与正面法线夹角73.3096°；两线交点在库线中点内侧9.2636mm。不能简化成“从袋心量角，小于73.3°就可以”，尤其近袋会产生偏差；也不能把这个入袋方向角与母球切角混用。

本版不另加人为角度余量或新惩罚。浮点误差处理只用于数值稳定，不作为玩法余量。边界上的球只进入候选，不能标为稳定可进。

参数绑定 `TableGeometry.chineseEightBallQiuJi` 及本次袋嘴/捕获轮廓；其他球桌或几何版本不套用这组参数。上层接口应区分“区域内／区域外／未标定”，未标定时跳过这项专用过滤并沿用现有筛选，不能误判为进不了。

已验证：623873次主扫描与临界实验，镜像及重放核验；标准球心矩形内、距离8–128cm、速度1/2/4m/s、零初始旋转滑动及自然滚动。几何外沿可供全桌候选公式使用，但接入前须补查更远球位及近袋/近库边缘，覆盖推荐实际会遇到的球位；这属于验证已有规则，不扩展成杆法搜索。结论针对当前App物理，不是真实球桌实测标定。

几何以 `QiuJi/Core/Physics/TableGeometry+QiuJi.swift` 与本次原生导出为准；Steering中历史长库中袋端点±0.035m不是本轮圆角切点±0.073m，禁止按旧表重建区域或袋嘴。图已采用生产数据。

## 3. 怎样评分和选球

复用已采用的两球自由走位评分：

```text
W = 0.5 × min(D, E, A) + 0.5 × (D × E × A)^(1/3)
```

|项|含义|本版处理|
|---|---|---|
|D|母球到目标球距离的舒适程度，结合该击球方向的台内纵深|复用球距v2|
|E|母球位置及出杆方向对应的出杆空间|复用方向性空间v3|
|A|切角难度，随目标球到袋口瞄点的距离收紧|复用20°袋距联动版|

A的完整口径：袋距d用厘米，切角θ为母球→假想球与目标球→瞄点的夹角；α=min(15°,900/d)，β=min(20°,20°√(60/d))，A=100exp(−[max(|θ|−α,0)/β]²)。D/E完整公式与既有实现见[评分记录](TWO-BALL-FREE-SCORE-20261026.md)。三项和W均为0–100、越高越好，不是进球概率。

评分应计算在通过检查的同一个瞄点上：袋距、切角、假想球、出杆方向和障碍检查不得各自换用袋心或另一条路线。现有两球入口使用固定anchor，不能不加适配就直接把 `evaluateFreePosition(cue,ball,pocket)` 用于每日候选。

建议提供接受显式aim的共用纯计算入口，沿用D/E/A参数与组合方式；既有两球入口继续传原anchor，保持既有结果。每日候选传其实际候选aim。复用现有有限瞄点，不扩大为密集搜索；若同袋多个瞄点通过，取W最高者并保留该aim。实施回归补充：有限瞄点须先通过现有clean pipe判定；无此类候选时，惰性取既有effectivePocketAimPoint作为唯一后备，再做基础线路检查，以保留贴库远端袋嘴入袋。直接按W挑裸袋嘴端点曾误荐近袋球形，已修正；纯捕获区射线硬过滤会误删贴库球，未采用。

选择顺序：

1. 每个球评估六个袋；每个球—袋保留其可用瞄点中W最高的一项。
2. 比较所有合法球—袋组合，推荐W最高的一组。
3. W相同则保留当前自动推荐（仍有效时）；否则按稳定的球标识、袋编号及瞄点顺序打破平局，确保同盘面结果稳定。
4. 不设置85分准入门槛，也不保留75°“舒适组”优先级。只要有通过基础检查的候选，就可从中选最高分。

例如：最近的球对所有袋都被挡住，就评估其他球；某球对上中袋在区域外，但对角袋有效，就保留其角袋组合；全桌候选分数都低，仍推荐其中最高分，不凭分数制造“无球可打”。

## 4. 每日清台里的行为

第一版接入每日清台的现有进袋模式自动选球/选袋入口，2D和3D共用同一份结果。

- 在原有需要自动选择的事件上计算：盘面就绪、击球结束且球静止、球位编辑完成等；镜头变化、2D/3D切换和静态刷新不反复改变推荐。
- 自动选球同时确定目标袋与候选aim；展示的瞄准方向和送入后续预测的方向必须与评分候选一致。如果下游重新求瞄点，应明确重新评估或弃用旧候选，不能把另一条路线的分数当本路线分数。
- 用户手动选球/选袋后沿用现有手动选择生命周期，普通刷新不抢回自动结果。手动选球后的默认选袋使用该球自身候选的W排序；手动点袋按已有交互处理。
- 没有候选时返回空结果，沿用现有临时自由模式及“未找到直进路线，暂用自由模式”提示；旧兜底路径也必须经过同一过滤，不能把已排除中袋重新选回来。
- 开球、规则要求的指定球和主动自由瞄准继续遵循原模式。合法目标集合变动后重新筛选，缓存不能保留过期目标。
- 使用现有球/袋选择与反馈样式。第一版不增加评分面板、公式弹窗、区域常驻覆盖或进球概率读数；区域图用于研究说明，后续教学展示另立需求。

无需在线批量物理模拟。最多15球×6袋，在既有有限瞄点上做几何检查和公式计算。沿用稳定盘面的候选缓存；球位、在桌集合或几何改变时失效，规则变化至少重新过滤合法集合。具体耗时在实施时测量，不预报未验证性能。

## 5. 如何复用

把两个能力分开，避免所有使用者被强制套用同一业务逻辑。

|可复用能力|输入/输出|可使用的位置|
|---|---|---|
|袋口区域判断|目标球位置、袋、几何版本 → 区域内/外/未标定|自动选袋、每日推荐、两球下一杆候选、题目生成、教学图解|
|单杆舒适度评分|母球、目标球、实际aim、几何 → D/E/A/W|每日当前杆排序、两球走位后的下一杆评分、其他练习候选排序|

合法球规则和其他球遮挡由各调用方提供；区域函数不混入玩法或评分。第一版只有每日清台启用新推荐策略。其他练习和共享宿主调用方需要显式选择是否启用，不能因修改共用函数顺带改变全部页面。

两球现有自由成绩、历史冻结成绩、题库85筛选、参考路线顺序和轨迹P2都保持原口径。特别是题库后续若采用新区域过滤，应单独生成对比并决定是否更新，不能本次自动重筛或重算旧记录。

## 8. 性能初评（10-26，非App实测）

用户要求先大概评估。M5 Pro上独立Swift -O原型，包含中袋过滤、现有线路/遮挡检查、所有有限瞄点评分与全局选择，不用候选缓存：5/9/15球均值分别0.0163/0.0278/0.0441ms；满桌P95=0.0504ms。各档400盘×20次，连同几何对照共64000次计时。说明纯算法开销很小，可先按手机端几毫秒预算；尚未测iPhone、场景/UI/物理预测端到端耗时，不作固定设备倍率换算。详[基准报告](../output/daily-recommendation-timing-20261026/REPORT.md)。推荐正确性与生产接入验收仍按上文执行。

## 9. 生产接入后的性能实测

包含新增袋口管道检查与既有求瞄后备的最终生产代码，M5 Pro本机iPad模拟器Debug，80个15球盘面，逐盘冷候选：均值32.17ms、P95 40.39ms、最大44.81ms。包含90球袋组合的筛选/评分/排序，无批量物理模拟；不含UI与选中杆预测。第8节0.044ms仅代表早期-O简化原型，不代表本版生产耗时；当前仍未测Release真机端到端。静态刷新复用候选缓存。
