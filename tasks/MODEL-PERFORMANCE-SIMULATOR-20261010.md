# 中八模型模拟器性能评估 · 2026-10-10

已完成 6 轮原版/新版交替测试（各 3 个新进程），固定 16 球散台、1.5m/s 直球、横屏、2× 像素、4× MSAA 和 60 FPS。初始球位、实际节点位置、预测时长及最终球位完全一致。

中位数：首次场景构建 8.33→2.83 秒（−66.0%）；原生解析 5.484→0.338 秒（−93.8%）；预热后进程 footprint 775→700 MiB（−9.7%）。持续击球 CPU 11.6→11.5%（单核口径）、渲染回调约 60→60 次/秒，帧间隔 P95 17.01→17.15ms；调用击球到首球移动 815→823ms，小于 25ms 轮询分辨率的差异不判收益。新候选两份资源 104.91→130.08 MB（+24%）。

新版一轮出现 241.5ms 渲染间隔（另外两轮最长 26–32ms，原版 29–35ms），原因未定位，不能把中位数接近 60 当作没有异常。

结论：加载和稳态内存有收益；未证实持续击球或响应改善。模拟器与独立 SCNView 宿主不替代完整 App 真机 GPU、峰值内存和温升测试。手机试用配置及原模型保持原状，仍待用户确认最终替换。

首轮竖屏探针及密集开球 v2 原始数据保留。密集开球在不同进程中，即使两次都用原版也出现不同回放结果，因此不纳入最终击球比较；未在本轮修改生产引擎，作为单独待查项记录。
