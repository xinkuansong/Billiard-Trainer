# 开球随机摆球策略实验（2026-10-01）

用户要求比较不同随机策略。本轮只增加测试内的实验入口，不切换生产默认，不改碰撞／旋转公式，不安装App。

## 实验设计

SceneKit X–Z水平面、Y向上，米；角速度rad/s。中八15球，球半径28.575mm，名义表面缝隙0.15mm，单球偏移半径上限0.06mm。架沿−X展开，镜像中心为Z=0。

| 策略 | 偏移规则 | 检验目的 |
|---|---|---|
| independent（现策略） | 每球独立圆盘采样，直接复用生产球位 | 基准 |
| mirrored | 同排镜像球共享dx、dz相反；中心球保留dx并令dz=0 | 左右对称微扰 |
| rowShared | 同排全部球共享该排第一球的偏移 | 保留排内距离，只变化排间关系 |
| rackShared | 全架共享顶球偏移，母球不移动 | 保留全部架内距离，只变化整架位置 |
| none | 无位置偏移 | 理想架对照 |

所有变体复用同一seed下的生产球号及随机样本，避免重新洗牌。镜像策略的中心球将二维采样投影到X轴，并非重新进行一维均匀采样。整架／同排偏移均为平移，不旋转。仅覆盖中八，不将实验策略接入其他玩法。

样本seed=1…32及用户曾复现的9030856504574103297。每个seed×5策略×原／反列表顺序，共330局完整开球，另330次0.12秒早期传力采样。各组母球点、方向(-1,0,0)、杆头速度8m/s、打点(0,0)、appDefault物理一致。固定方向用于隔离策略影响；与生产“自动瞄顶球”的微小偏向有区别，不应将本轮数字和此前自动瞄顶球诊断直接混算。

每对原／反顺序保持球位及球号不变，指标始终按原槽位／球键对应。不同seed仍会更换球号，none仅取消位置微扰，不取消球号洗牌。

几何检查覆盖201seed×5策略=1005架：确定性、球号保持、Y保持、最大偏移、边界、初始不互穿；镜像／无随机另检查逐排镜像对称。不互穿解析界为0.15−2×0.06=0.03mm。

## 指标口径

- 开散球数：目标球最终中心位移超过30cm，或已进袋；进袋计入开散，不等于视觉分布均匀。
- 最长最终纯自旋：未进袋目标球最后一次平移结束后，连续spinning到该球第一个stationary帧的时间。避免误用全局录制终点代替单球停转时刻。
- 目标球平移后录制尾段：全局recorder.duration减未进袋目标球最后平移结束时刻，不把母球平移纳入该指标。
- 峰值侧旋：目标球所有记录帧中的最大abs(ωY)，rad/s。
- 剩余球最大团簇：终态未进袋目标球间表面缝隙≤10mm视为连通，统计最大连通分量。10mm为报告指标阈值，未用于物理解算。
- 早期顺序差：0.12秒、尚未碰库时，同一槽位原／反列表速度向量差的全架最大值。

### 结论与边界

本批原序的独立／镜像／同排共享策略平均开散数相近（13.45／13.39／13.27），未显示镜像明显改善开散或缩短长自旋。镜像33/33的最长自旋球仍为slot10；独立亦33/33，同排共享与整架共享均32/33为slot10，另1局没有正时长最终纯自旋；无随机33/33为slot10。与此前同侧底角规律相符。

镜像的最长单球自旋中位数比独立更长，但目标球平移全部结束后的录制尾段中位数接近：5.31对5.38秒。两种指标意义不同，不能据9.95对8.78秒就断言用户看到的单球尾巴多1.17秒。

即使左右对称随机，各策略在未碰库的0.12秒都仍出现约7.11–7.15m/s的原／反列表速度差。本次只改变随机策略，未消除之前发现的密集接触顺序偏置；随机策略选择应与多接触解算修正分开。整架共享偏移保持所有架内缝隙，也仍有长自旋，支持“并非必须由球间独立错位才产生这条原因链”。

反序不是更合理的物理解法，反序少开散／短自旋也不是验收标准。无随机下，不同seed虽然球号洗牌不同，原序各局均开散13颗、最长纯自旋10.238162秒，反序各局均8颗、2.314306秒；提供同一几何对照的稳定参照。

这是一批正中8m/s无塞的受控实验，未覆盖偏球点、偏杆角、不同力度／加塞，也未做真实球架、真实材料或手机视觉验收。不据该批均值直接选定新的生产默认。后续可选策略接入模拟器逐局对照，或先修正解算顺序敏感后按同一矩阵复跑。
