# V011 一次击球六球：算法重建

## 问题定义

SceneKit世界坐标XZ水平、Y向上，单位米；竖屏上=+X、右=+Z。使用当前生产`TableGeometry.chineseEightBallQiuJi`和`EventDrivenEngine.appDefault`，不修改动力学系数、袋口判据或球径。六球1/2/3/4/5/8质量和几何遵循现有引擎。

控制量为u=(母球X,母球Z,出杆角,杆头速度,左右打点,高低打点,共同摆球距离d)。六颗目标球在各自袋口中心线上且距物理孔心均为d，角袋45度、中袋垂直向内。d∈[0.055,0.13]米只是当前研究范围，不是无解边界；每次完整模拟中球位固定。力度上限先9再10。方向是周期变量；打点受现有圆形失误边界约束。

一次给定u就确定整杆全部运动。后续碰撞不是新的控制决策。允许母球碰球、目标球之间传递碰撞、碰库；无指定落袋顺序，不要求8最后，也不要求六球都被母球直接碰到。目标是六个真实进袋事件同时成立、母球不落袋、模拟settled。找到可行解后再比较力度与母球吃库数的Pareto候选，并验证生产回放和参数敏感度。

## 为什么旧目标会困住搜索

1. 进球数×100的奖励使任何五球通常压过四球，可能阻止从四球且两颗接近成功的路线跨入六球。
2. 未被碰到的挂袋球，其绝对袋口间隙天然很小；缩小d能降低损失，却没有创造击球进展。
3. 只看母球到未进球距离遗漏目标球间的接力碰撞。
4. 独立扰动角度、球位、塞量很容易离开可行的窄区域；这些参数需要成组联动。
5. 不同碰撞顺序形成不同局部区域，跨越区域时响应可突变；全局单一梯度或一次局部优化不能覆盖全部。

反推只能是某些局部初值/约束的生成方法，不作为总架构的前提。

## 新可行性代理指标

每颗球分别计算：已真实进袋则残差0；否则用其记录轨迹折线距任意捕获圈的最小非负间隙g，除以初始最近捕获圈间隙g0，再加接触缺口项。

`r_i = max(1e-5, g_i / max(g0_i, 1e-6)) + 0.5 a_i / (a_i + 2R)`

其中已发生任何球球接触时a_i=0；尚未接触的球保持静止，因此可直接计算所有其它球的记录轨迹到它的最小球面间隙a_i，不只检查母球。已进球不套该公式，直接r_i=0。采样轨迹距离仅是搜索引导，不替代连续碰撞/进袋事件。

`L = max(r_i) + 0.25 mean(r_i) + 2·母球落袋 + 10·非settled`

目的：优先改善最落后的必要条件，同时保留整体改善；归一化消除只移动袋口附近初始球位的虚假收益。0.5/0.25等是优化启发权重，不是物理参数，也没有声称最优。成功仍只认真实事件，不认L近零。后续必须对权重和代理误导做消融。

## 连续求解层原型

采用多起点、全协方差的自适应高斯交叉熵搜索。对7个参数按尺度归一化，每个局部区域维护均值与7×7协方差；根据低损失样本联合更新分布，从而学习位置/角度/打点/d的相关变化。

- 每批24个合法样本，前6个更新分布；协方差保留旧分布、精英协方差与均值移动方向，并加数值正定下限。
- 最多12个不同已观测碰撞路线作初始局部区域，三种尺度；停滞16批后重启，交替使用已保存候选和新几何种子。
- 不因候选少进一颗球就淘汰它。另存实际进球最多的候选，避免代理最优被误称为任务成功。
- 完全相同的Float参数与d在本轮去重；不宣称不同参数一定是不同物理路线。
- 这是自适应全协方差交叉熵原型，**不是CMA-ES，也不是MCTS**。

## MCTS的适用位置

MCTS可作为外层预算分配方案，但不能把碰撞后出射方向作为可自由选择的新动作。两种合法建树方式：

1. 参数区域树：节点代表初始u的一个子区域；叶节点用连续求解器提出完整u，整杆模拟后回传结果。更接近连续域的分层乐观优化。
2. 事件前缀树：节点只收集真实完整初值已经实现的事件前缀；想探索其它前缀也必须重新找到满足它的一组初值，不能在节点改变球的状态。维护该约束成本较高，暂不优先。

可逐步增加分支数量，给未充分探索区域探索奖励，同时根据实际进展分配后续预算。动态内层优化使区域回报并非简单平稳随机样本，因此不直接宣称UCT置信界或HOO光滑性理论适用。完整相同初始参数的确定性模拟不应反复当作独立随机样本。

候选参考：
- HOO/X-Armed Bandits，Bubeck等，JMLR 2011：https://www.jmlr.org/beta/papers/v12/bubeck11a.html
- Continuous Upper Confidence Trees，Couetoux等，2011：https://hal.science/hal-00542673v1/file/c0mcts.pdf

当前已实现下述两层UCB区域调度原型并完成初筛；完整动态扩展MCTS尚未实现。

## 实测与验收

- 506个历史候选重新经真实引擎评估，`feasibility-audit9-r2`1项0失败：原五球候选L=1.52625；新代理更偏好的四球候选L=1.51602。四球候选8号球采样轨迹距捕获圈约0.119mm，3号球最近可能接触者是8号球，间隙0.578m；原五球候选3号球距母球轨迹约0.764m。这证明两种排名实际不同，不证明四球一定更容易补成六球。
- 全协方差优化器在已知解析极小值的旋转狭长二次函数上单测通过，最小损失约1.14e-12、学到的最大绝对相关系数0.9976。这仅验证基本数值行为，不代表台球成功。
- `adaptive9`首个台球探索试跑已完成：上限9、20,000个合法去重候选、92.89秒、68轮、27次重启；1项0失败。实际最多仍5球，最低代理损失仍1.51602（四球），两项都没有超过输入候选。尚无证据证明新版提高求解率。这不是多随机种子的受控算法对照。保存最优候选时还会诊断复算，候选计数不等于所有引擎调用数。

后续对照需相同初始候选、力度/球位范围、真实引擎调用预算、多个随机种子，分别消融新评分、协方差联动和树调度。评估指标为真实六球成功数、首次成功成本、最差单球缺口、合法采样比例、完整回放一致性；不以累计候选数或代理分数单独宣称完成。

## 两层区域树的受控试验

已实现`testRegionComparison`，不是完整HOO或带渐进扩展的通用MCTS，而是预展开的两层UCB区域树：共同d分四段，每段再按初始出杆方向分四个象限，共16叶。节点只约束初始参数，物理过程内无新控制。

比较`tree`和`round-robin`两种预算调度，保持同一16区域、输入506个候选、归一化评分、全协方差内层优化、参数边界以及每叶独立随机数流。内层25%均匀探索，其他样本来自高斯；批次没有改善时收缩协方差并回到该区域最好点，这项调整对双方完全相同，不能将它的收益归于树。

树选择：先访问所有叶，再对d父节点和方向子节点依次用平均批次奖励加探索项；每批奖励为该批最好合法样本的`1/(1+L)`，回传父/子统计。因为内层分布会更新，这里的UCB是启发式调度，不声称平稳回报条件下的理论置信保证。

验收：调度器在已知固定奖励的16叶数值测试中验证全叶探索、奖励回传和优先分配，1项0失败。真实试验用两个随机种子2026091792/2026091793，每个策略各10,000次完整物理调用（包含相同初始化）；结束后固定额外2次独立复验，明确计数。只有共同预算都到达才能作为同预算比较，若提前找到六球则记录首次成功成本。两随机种子只用于初筛，不能证明一般优越性。

四轮均完成且各1测0失败；搜索源码与物理源码hash一致。每轮10,000次搜索调用，另2次结果复验，总计40,008次调用，不宣称跨轮去重。

## 新五球传递路线与末球精修

共同d=0.07457442581653595m，初始杆速8.4250412。母球先撞3号，3号再与4、2、1号传递碰撞；母球另送进8、5号。五球真实落袋、母球不落袋、settled。3号峰值速度约6.475m/s，因此不能说它没有被打到或一开始缺乏能量。

该路线暴露了代理局限：3号全程最近袋口位置主要来自初始摆位，不能有效指导完成传递后的落袋。新增仅供局部补全的`SIX_FINISH_SCORE`，以未进球的最终静止位置到捕获圈距离作提示，仍以真实进袋事件判成功。固定共同d和原物理参数。

单独扫力度：上限9的876次候选、9–10档1,002次候选均未取得六球，各1测0失败。最终位置目标的约束精修545次合法候选，将末球缺口约9.80cm降至9.51cm，仍五球，1测0失败；保存诊断时的复算另计，不能将545称为全部引擎调用。多尺度局部搜索`relay-local9`完成12,646次候选评估、120.08秒、1测0失败，仍五球；其较低最终缺口来自改为3号进袋而1号未进，不能称为原路线末球改善。随后增加局部专用`SIX_REQUIRED_POT_MASK=59`，要求1/2/4/5/8继续真实进袋，才接受对3号的补全优化；全局搜索不受此约束。

保留五球的`relay-preserved9`完成12,837次候选评估、120.08秒、1测0失败，仍五球、白球不落袋，3号最终缺口0.092039764m。上述局部次数包含合法性拒绝且未去重，不与受控试验的精确物理调用数混用。设置保存在各输出目录`experiment-settings.json`。


### 生产入口复验失败（尚在诊断）

### 差异根因与搜索入口修正

`relay-input-audit`八组合诊断1测0失败：实际scene.surfaceY恰为0.8，方向长度恰为1；只有球体插入顺序改变结果。先目标球后母球为5球，先母球后目标球为4球。研究入口现对齐`ShotPredictor.simulateFree`：母球先加入、方向归一化、相同4000事件/90秒上限及纯自旋收尾。未修改任何生产引擎或物理参数。`relay-input-aligned`复验1测0失败，对齐后的直接引擎与生产入口均4球；这验证入口修正，不是恢复五球或六球成功。

此前树/轮转的受控比较仍是在相同旧入口下完成的历史实验，不能外推为当前生产入口的性能结论。`production-recheck9`已重新评估1,311组历史候选，1测0失败；旧分数与旧进球标签不参与验收。对齐入口下仍有五球候选，共同d=0.07457699626684189m、杆速8.425395965576172，母球不落袋；四球最低代理损失0.913235664。该候选还须单独生产回放核对。
