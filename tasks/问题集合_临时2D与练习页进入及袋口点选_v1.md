## 3. 当前代码核查结论

### 已核实事实

- `SceneAimingView` 和 `AimPointSceneTrainingView` 都使用 `DailyTableOrientation`、`entryRendered` 和 `tableFrameReady` 控制页面进入。
- 两个专用页面的手机临时 2D 入口都使用单独的临时 2D 覆盖层。
- `AngleSceneView` 存在静态临时 2D 快照路径和合并相机同步路径。
- 静态快照的现有判断条件没有直接使用 `topDownContentRevision`。
- `BTTeachingTablePage`、`FreePlayView` 和多个练习页面复用了全屏球桌入口结构。
- 袋口命中已经有 SceneKit 命中、投影回退和 44pt 的近距离回退范围，同时存在栏边前景深度判断。

### 待验证根因

- Q01 可能是静态临时 2D 快照没有随着球位、轨迹或教学覆盖层变化失效。
- Q02 和 Q03 可能涉及方向切换、SwiftUI 布局、SceneKit 尺寸和首次可见时机之间的竞态。
- Q03 可能是透明 SceneKit 背景或宿主页面背景在入口阶段暴露。
- Q04 可能是小袋口标记、倾斜投影、栏边深度判断和相邻袋口选择共同造成的命中困难。

以上内容需要通过复现和日志确认，不能直接视为最终根因。

## 5. 修复批次

### 批次 A：入口页面清单和复现基线

1. 记录当前构建版本、设备类型和系统版本。
2. 覆盖冷启动进入、返回后再次进入、2D、3D、横竖屏、浅色和深色环境。
3. 记录页面出现时间、`entryRendered`、`tableFrameReady`、方向生效、SceneKit 尺寸、第一张完整画面和背景层状态。
4. 将页面标记为正常基线、同类异常或未复现。

### 批次 B：修复临时 2D 脏影

1. 审计静态临时 2D 快照的缓存条件和生命周期。
2. 让球位、轨迹、瞄准线、球影和教学标记变化触发快照失效或同步。
3. 移动球体时清理旧快照或同步现有覆盖层。
4. 复用 `topDownContentRevision`，不增加平行状态源。
5. 保留必要的渲染节流，同时保证画面始终对应当前状态。

验收覆盖连续拖动 5 号球、移动其他球、取消移动、切换轨迹显示、2D 与 3D 往返进入，以及所有复用临时 2D 路径的页面。

### 批次 C：统一 2D 和 3D 进入时序

1. 将手机 2D 页面的首次可见时机从“竖屏已经渲染一帧”调整为“目标横屏已经生效，窗口和 SceneKit 尺寸已经稳定”。
2. 在方向切换和首次绘制期间使用稳定的不透明底色。
3. 使用方向回调、窗口尺寸和实际渲染完成状态判断，不使用固定延时。
4. 保留正常 3D 页面现有的短暂转屏过渡。
5. 统一 `SceneAimingView`、`AimPointSceneTrainingView`、`BTTeachingTablePage` 和 `FreePlayView` 的入口状态协议。
6. 审计 `backgroundColor: .clear`、全窗口 `GeometryReader`、`opacity` 和外层背景的组合，防止白色或半屏区域暴露。

验收要求如下。

- 角度练习 2D 最终稳定在正确横屏布局。
- 瞄准点练习没有白色背景闪现或残留。
- 正常 3D 页面的转屏过渡保持现有表现。
- 进入、返回和再次进入都能稳定收敛。
- iPhone 横屏以及 iPad 横屏、竖屏符合球桌页面统一规范。

### 批次 D：统一袋口点选

1. 将袋口命中计算抽成共享逻辑。
2. 以投影后的袋口中心和当前视角下的可见袋口区域建立有限扩展的触控区域。
3. 保留栏边和真实遮挡判断，改善倾斜视角下的可点击性。
4. 对相邻袋口设置最近点和歧义处理，避免扩大范围后误选。
5. 保留无障碍自定义操作，并增加清晰的选中或按下反馈。
6. 在标准视角、倾斜视角、靠近栏边、靠近球体、2D、3D 和临时 2D 中复用同一规则。

### 批次 E：跨页面回归

对最终纳入范围的每个页面执行以下矩阵。

- iPhone 横屏
- iPad 横屏和竖屏
- 冷启动和热启动
- 返回后再次进入
- 浅色和深色环境
- 临时 2D 拖球
- 六个袋口的倾斜视角点选
- 2D 与 3D 往返切换

## 6. 验收标准

### Q01

移动球后，临时 2D 中只显示当前位置对应的球、轨迹、球影和教学标记。连续拖动、释放、取消和再次进入都没有旧内容残留。

### Q02

角度练习进入后最终方向、桌面比例、控制层和教学标记稳定。异常录屏中的额外错误方向或错误尺寸画面不再出现。正常 3D 基线中的短暂转屏过渡仍然可见且能稳定完成。

### Q03

瞄准点练习进入期间没有应用拥有的白色背景闪现或残留。场景、控制层和球桌在目标尺寸稳定后再完整显示。

### Q04

六个袋口在倾斜视角下均可稳定点选。靠近栏边和相邻袋口时不发生明显误选。选中反馈和无障碍操作仍可用。

### Q05

所有纳入范围的页面使用统一入口规则，页面差异记录在页面检查表中。未纳入的页面必须写明排除理由。

## 7. 风险和待定项

- Q01 的具体残留对象需要通过同一构建复现后确认是快照、球影、轨迹还是场景节点。
- Q02 的正常 3D 视频表明短暂转屏本身属于允许过渡，验收重点是最终收敛和错误中间画面。
- Q03 需要区分应用背景暴露和系统控制中心画面。
- Q04 不能只扩大触控半径，必须同时验证相邻袋口误选和栏边遮挡。
- 当前没有真机体验证据，最终交付仍需要真机或目标模拟器复验。
