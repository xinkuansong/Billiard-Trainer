# 两球题库：第一杆指定袋纯几何筛选

2026-10-24。用户要求将筛选规则写成可执行函数，随后明确去掉入袋宽度，只考虑角度和距离，参考原782,528球形生成时的下球点。此轮为离线筛选，不修改App题库或抽题权重。

## 本轮规则

对同一C/O球位比较六袋，存在替代袋B同时满足以下条件，即将原指定袋A标为drop：

- 切角至少减少15°；
- 目标球到下球点的距离至少缩短0.30m；
- 同一距离相对于A至少缩短25%（分母为A的距离）。

三个条件均包含边界，全部AND。之前三指标方案的入袋宽度和“第三项不明显变差”规则不再执行；也不使用3°、10cm等让步阈值。参数集中在`Thresholds`，默认值为本轮讨论后的首版试筛值，尚无用户逐球审阅结论。

keep仅表示没有替代袋满足此规则，不等于原袋唯一最优或进球可行；drop表示原袋在这两个指标上被明显优于，不证明替代袋真实可进。没有袋角通道、球杆、力度、旋转、母球落袋或第二球走位筛选。

## 坐标与指标

- 世界X–Z平面、单位米、Y向上；横桌右为+X、下为+Z。Steering顶部历史上下方位文字不用于计算，以生成器和当前横桌命名规则为准。
- 使用源JSON内`geometry.length/width/radius`的原始数值，保留Swift Float导出精度。
- 角袋P为`(±(L/2-R), ±(W/2-R))`；中袋P为`(0, ±W/2)`。编号0…5不变。
- G为`O-2R*unit(P-O)`，切角为`angle(G-C, P-O)`，距离为`|P-O|`。
- 这是按用户要求复用的**生成下球点几何**，不使用正式`effectivePocketAimPoint`，不冒称运行时答案或实际碰撞测量值。
- 每个源target的P/G都与上述公式核对。全库原指定袋切角还原必须与`abs(maskIndex-85)`一致。
- 浮点比较余量：角度1e-9°、距离1e-12m，仅防算术舍入；不代表业务容差。

来源：`QiuJiTests/TrainingGridInventoryTests.swift`的`GridGeometry.generationAnchor`与生成式；`QiuJi/Core/Training/TrainingGridBank.swift`的球位恢复；[生成基线](table-page-adaptation/ACCURACY-GENERATION-BASELINE-20261021.md)。

## 函数与运行

实现：`scripts/training-question-bank/pocket_geometry_filter.py`。

```python
decision = evaluate_layout(cue, target, original_pocket, geometry, thresholds)
# decision.status: keep / drop
# decision.original: 原袋切角、OP距离
# decision.alternatives: 所有满足淘汰规则的替代袋（按袋ID排序，不冒称最佳袋）
# decision.metrics: 六袋各自的指标
```

坏输入抛错，禁止静默淘汰。函数无写入副作用。命令行导出原始稳定ID、原袋与替代袋指标，原题库只读，结果目录必须不存在，拒绝覆盖已有结果。

```bash
python3 scripts/training-question-bank/pocket_geometry_filter.py --output output/two-ball-pocket-filter-20261024
python3 -m unittest discover -s scripts/training-question-bank -p 'test_pocket_geometry_filter.py' -v
```

`--limit N`仅扫描前N条，摘要会注明是否全量。已生成的目录不能原样重跑；新一轮须使用新目录。
