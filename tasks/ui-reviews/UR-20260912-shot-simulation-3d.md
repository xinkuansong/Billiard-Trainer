# 分离角与走位：3D 试点

日期：2026-09-12。状态：本地试点，等待用户体验反馈；未发布。

## 范围与操作

入口：练习 → 打 → 分离角与走位。顶栏右侧点击 2D/3D 切换。

- 2D 保留球库摆球、拖动、选目标球与袋口及原有布局。
- 3D 隐藏球库，桌面滑动/捏合控制相机；自由模式用左侧刻度轮瞄准，仍可点选球/袋口。
- 3D 从既有击球方向进入母球后方视角；底部“回到瞄准”可重新对准。镜头操作不修改击球方向。
- 两种视角共用同一 VM、球形、参数、求解结果与播放状态；播放中允许切换视角，打点盘在切换时关闭。
- 3D 控件依视口边缘布局，避免用俯视球桌矩形定位透视控件。原有材质、物理与其他页面不变。
