# 自定义球形 · 多线与测量复验

日期：2026-10-18。范围为用户批准的 v1.3 编辑模式，既有练习的自由击球、同号球独立身份和模板副本语义保留。标准手机与 SE 小屏均通过；本记录不代表用户观感认可或真机手感验收。

## 实现与规范复用

- 左侧复用 `BTHUDCompactAction`：直线、量距离、量角度；下方撤销、重做。右侧复用 `BTReadout` 与 `BTTextActionButton`，没有新增数字输入或批量生成入口。
- 画线连续两次点击，画完可继续；新线起点和终点均可复用已有端点。单独线只包含两端点和直线；端点受台面边界约束，水平／垂直磁吸具有捕获与脱离带。
- 用户通过球栏或拖放逐颗添球。独立单球居中，两个及以上包含两端并均分；拖离解除关联。共用端点上的球由相邻线共享，避免重叠复制。
- 拖动共用端点带动相连线及两线成员。球重叠或线段过短时拒绝本次位移，保留最近有效位置；一次拖动对应一次撤销。删除线保留球。
- 右侧选中线依次显示球数、球距 cm、线长 cm；距离一位小数，球距采用相邻球心间距，少于两球显示“—”。某分支仅剩共用端点球时保留在连接点，独立单球仍居中。
- 测距选两点，测角选三点（第二点为角顶点，0–180°）；测量点支持吸附球心／线端点及拖动。只保留当前一组，完成／换工具清除，不改变球位。
- 辅助线可随模板保存／复制／恢复；旧模板可缺省该字段。练习只加载球形，不显示编辑辅助线。无产品球数上限，真实台面空间不足时拒绝重叠摆球。
- 共享 `AngleSceneView` 新能力均默认关闭，仅此编辑页启用端点优先命中、直接台面点选与精确拖动；普通球的拖动死区不变。
