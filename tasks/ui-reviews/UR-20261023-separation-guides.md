# 分离角练习：辅助线、标准动作位置与杆速诊断

日期：2026-10-23。范围为2D/3D分离角练习局部反馈；完整功能、评分的前序验证分别见首版与评分报告。

## 修改与根因

辅助线此前在安装题目时主动隐藏；现复用共享几何可视化。自动瞄准补偿仍在用户提交后执行，几何线不冒充当前打点对应的补偿瞄准结果。新题/原题重打/回放/结果/账号清理均使用各自生命周期。

左侧移除方向尺时也移除了它的布局占位，导致重打/回放上移。恢复共享标尺的自然高度（含动态字号文字），动作位置与准度页一致；不添加假的方向操作，不清除个人布局。

杆速条分析与后续建议见页面卡§11。本轮没有改共享杆速组件或物理参数。计算证据：`power-analysis.json`，截图1.44对应44.729%行程；局部刻度边距偏差并不足以解释“大段空白”，主要原因是低速非线性行程和紧凑刻度只显示0.5整数倍。
