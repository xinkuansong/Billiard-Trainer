# 每日开球/打点按钮与大白盘透明度（2026-10-05，DR-335 r4）

## 用户范围与实现
两个圆形入口44→48pt；开球图形26→30pt、小打点图34→38pt，仅每日2D/3D启用。右侧相机列按新的头部直径保持围绕力度尺居中。白盘透明度明确针对展开的大盘，小白盘不变。
BTSpinPad的discOpacity仅影响白色渐变填充；红点、十字线、虚线圈、外描边、方向键、遮罩与真实打点约束不变。默认1，普通启动/Release不改变透明度。每日DEBUG参数用于五档比较，尚未把某档设为默认。
