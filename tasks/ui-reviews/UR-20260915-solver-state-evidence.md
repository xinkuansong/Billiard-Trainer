## 影响整体方案的具体发现

1. **选中与可操作混淆。** 3D里顶部“落区/摆球”等按钮仍亮绿色，但测试与源码确认编辑已禁用。用户看到的选中样式不足以表达当前能做什么。改版应明确区分当前约束信息、可执行动作和返回编辑入口。
2. **无解的下一步不突出。** 防守无解时，移球重试建议塞在导航副标题中并截断；大量失效的参数和击球操作仍在台面周围。“回到瞄准”也以禁用项留在观察菜单。无解不能只做成普通页面的灰色版本，需要可见的恢复动作。
3. **规划推进不是普通停球。** 本次①进袋后，②变为①，②/③角色槽缺失，标题要求回2D补选。必须给角色推进与缺失配置独立布局/状态，不能让用户凭空猜测为什么“打一”不可用。
4. **视角菜单必须按任务变化。** 防守不包含目标袋观察；有解和无解的回瞄准能力不同。完整方案不能机械复制同一组五个视角到所有页面，也不能因为看起来相似而直接删掉对象观察。
5. **精细面板与主操作区重叠仍存在。** 三页3D打点展开都覆盖一部分底部左右操作区域。用例只检查面板尺寸和开合，不代表所有交叠触点安全。
6. **计算中的控件仍占位。** 三页左右动作、力度与打点变淡但没有退出，顶部编辑工具与底部信息还在。后续需按计算、看解、微调、击球、恢复分别定义显隐，而不是统一几秒后隐藏。
