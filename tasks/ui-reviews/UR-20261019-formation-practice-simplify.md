# 自定义球形练习页精简 · 2026-10-19

## 范围与约定

用户批准只精简“开始练习”后的页面，复用既有按键样式，保留已完成的球形编辑页。

- 左侧：重新开始、方向、重打；右侧：打点、杆速、击球及3D必要观察控件。
- 设置保留原有显示/瞄准偏好、操作布局；练习操作只保留回放和将当前球形另存为模板。
- 移除练习中的摆球模式、直线/清线、母球换位/选择/放回、四向微调、移除选中球/清空目标球及重复训练设置入口。
- 停稳直接拖球、拖回球库、球库取回、重复球身份、重打上一杆、恢复初始球形沿用原业务。
- 只在自定义练习分支隐藏常驻回放，按实际单键计算动作区占位；共享其他页原样。
- `FreeControlCatalog.customFormationPractice`同步移除退役按键；已保存布局数据不重写，现有按键位置继续使用。
- `FormationEditorLeft`起至文件末尾的编辑工具/参数/测量显示，与本轮修改前逐字一致；Session与绘图模型本轮未改。
