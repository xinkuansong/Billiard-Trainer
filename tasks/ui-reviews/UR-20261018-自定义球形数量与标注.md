# 自定义球形 v1.4 · 数量与标注审查

日期：2026-10-18。范围：DR-405 v1.4；用户确认25颗目标球另加1颗母球，并追加圆弧分色、无背景文字、右下角数量角标与标准标题。

## 改动与合同

- 编辑添加／保存、模板保存及开始练习遵守25目标球上限；母球独立。已有超限模板仍能读取及编辑减量，不静默截断归档。
- 练习球库只展示模板已有球号，同号合并且右下角标总数量；取回优先离台实例，保留每球独立身份。编辑球库仍为1–15号来源。
- 编辑及练习使用模板名称。此前 FreePlay 的自定义分支仍用旧单行 Text；现改用编排台同一 BTTablePageTitle 的60×34pt预算、共享单双行及奇数中间字规则，长名复用试打 fitsLongText。其他调用分支保持。
- 辅助线白色、测距青色、测角臂橙色、角度弧及角度标注粉色；线半径0.003m、端点半径0.018m，端点命中范围仍44pt。
- 角度弧取第二点为顶点的最短夹角，两条臂可水平／垂直吸附。距离和角度在台面实时显示无背景纯文字；cm与角度保留一位小数。
- 台面标注随SceneKit投影及缩放平移更新，实测文字尺寸避让圆弧；台面提示复用 info.circle 开头的 BTNoticeContent。

## 发现与修复

1. r1测距线与白色辅助线同层重叠时被盖住：测量提升到既有 aiming 层，仍遵守球桌深度遮挡。
2. r1的90°标注底板遮圆弧：按实测文字包络向圆弧外侧避让；随后依用户反馈移除底板。
3. r3首次UI复验加载了已移至模拟器 Dead 缓存的旧测试二进制（lsof确认），日志出现已删除的 testUnlimitedRepeatedBallsPersistAndScroll，未执行新标题／缩放断言。中止该轮，保留记录；在管理器租约内重新安装仅UI测试Runner后运行r4，不清除App数据。r3截图可作为过程记录，不作为最终自动化验收。
4. r4新标题断言错误地把AX文字边界等同固定预留框，短标题实际39pt却断言必须60pt。修正为可见标题在60×34pt预算内、不越界且不与球库重叠，并核对完整名称；布局实现保持共享组件。测试修订后重新构建r5，旧失败保留。
5. r5缩放位置断言差2.9pt，最初怀疑调试探针与实时标注不同步；r6新增“文字必须跟随镜头移动”的断言后仍失败，证实文字投影没有刷新。根因是TimelineView里的GeometryReader仅捕获稳定session/projector，内部投影计算被布局缓存。r7改在每个时间回调中先计算投影点，再将点值传入GeometryReader；最终同时检查标注移动、线中点横坐标误差≤2pt、数值不变和原图，保留原失败，不降低对齐阈值。
6. r6首构建结束时Xcode报告 build operation failed without specifying any errors，未给出源代码诊断；保留失败日志，原样增量重试成功。
7. 用户指出旧单行标题不符合规范：核对共享组件及编排台调用后接入统一组件，并增加标题60×34pt与名称断言。

8. r7手机并行复验在第14次加球后计数等待超时，SE同构建2UI通过；不改源代码，手机单独重跑该用例r8通过。首次超时原因未定位，保留失败记录，不宣称整轮首次通过。
