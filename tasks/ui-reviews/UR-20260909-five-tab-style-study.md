# 五个 Tab 风格对比与三套训练首页候选

日期：2026-09-09。范围：实际模拟器截图分析、视觉候选；没有修改 App 实现。

## 结论

建议以 B「深绿主场」作为训练首页方向：摄影收进本周训练卡，今日安排保持浅色，形成明确的主次。其他页面采用 A 的轻量点缀，并继续保留“我的”普通菜单灰色图标。整体统一依靠相同的绿色、圆角、文字层级、图标和间距；各页不必拥有相同面积的摄影。

三个完整五页概念板见 `output/tab-style-study-20260909/`，分别为 A、B、C。它们用于讨论表现强度，精确数据、文字和控件位置以本报告为准。

## 为什么参考图不能原样铺到全 App

参考图的优点是有真正的台球环境、光线、深绿主卡和明确的品牌记忆。但摄影头图、手写标语、卡片内鼓励句、小英文、强描边、火焰、今日白胶囊同时存在，注意力来源偏多。首页本身还有今日安排与计划货架，继续增加独立海报高度会把常用内容向下推。

现有页面的连接点很充分：森林绿、白卡、浅灰底、圆形球的意象、真实封面、边缘瞄准线。建议用这些已有元素扩展，而不是再引入一整套复古字体、金属边框或深色背景。

## 三套方案

### A · 清透摄影

首页将高清球台照片放在紧凑的品牌头区，右侧球体与左侧品牌留白相接；本周、今日均为白卡。本周突出2/3，今日用细进度线与浅色图标底。照片提供情绪，白卡承担阅读。

其他页：动作库/练习加浅绿选中底与小栏目图标底；历史仅调整星期底和选中日期；统计复用已有浅绿概况；我的只在头像卡放极淡圆弧，普通菜单保持灰色。概念图中更广泛的绿色菜单可作为强度试验，不建议作为最终默认。

理由：对当前浅色体系的改动最小，切换页面最平顺，摄影与现有练习封面天然衔接。适合重视清爽和长期耐看。代价：本周卡自身的辨识度弱于B，头图高度必须受控，否则只是在原卡上方又加一张图。

### B · 深绿主场（优先推荐）

首页保持简洁品牌栏，将真实台呢和球体摄影收进本周卡的上部，卡内数据区使用稳定深绿底保障对比度。标题/每日清台在上，2/3与连续1天在中，七日轨迹在下。今日安排继续白卡，以6/8、细进度线和两个安排条目提供操作导向。

其他页：动作库/练习可在选中项用更明确的绿色；记录只在月份标题条试用小面积深绿，日历仍白；我的头像卡可做深绿，黑金会员卡维持独立。推荐最终版再收敛记录的绿色月份条，避免两个Tab同时出现不必要的大色带。

理由：把最强的照片和明暗对比集中于一个功能模块，既满足用户喜欢的摄影海报质感，也无需另加高海报。深绿周卡与白色今日卡自然表达“长期坚持”和“现在要做的事”。代价：深卡的文字对比、照片裁切和深色模式需要单独设计；会员黑金语义必须保持区别。

### C · 运动节奏

首页使用紧凑击球摄影，周目标以3段刻度表示，完成2段；下方仍是独立七日日历。今日8个动作可用8段、完成6段表示。圆点、短刻度、精细球路成为贯穿各页的细节。

其他页：动作库/练习栏目尾部放少量短刻度；历史记录以细线连接类别点；统计继续让数据图形发声；我的头像周边加入细圆环，普通菜单不加彩色装饰。

理由：设计感来自用户的进度，更具训练反馈感，也容易与瞄准、轨迹的产品主题呼应。代价：周目标条、七日历、动作完成条三层图形容易重复；每周目标可变化、动作可能很多，固定分段并不适合所有真实状态。最终应设置分段上限，较多动作使用连续进度条。概念图的灰色未完成分段仍偏弱，需要在精确稿纠正。

## 推荐的具体组合

1. 首页采用B，限制摄影在一张周卡内；清除重复激励句与装饰英文。
2. 本周完成数字是第一层，连续天数第二层；连续火焰只作小辅助。
3. 七日保留独立等宽列：完成=勾选，今天=浅底/细框，未来=空心。未训练不能画成失败叉号；今天不等于已完成。
4. 今日安排保持白色。6/8是总动作进度，细条严格75%；预计335分钟仍然只是预计，不添加“剩余”或“已用时”的推断。
5. 两个安排仍是两个独立可展开条目。第一个的更多操作、第二个完成状态和两者的展开箭头都保留。长标题允许截断或受控换行，不能为了排版重命名用户模板。
6. 训练胶囊保留现有五态行为和入口；精确布局为其预留遮挡避让，不依据生成图中漂移位置实现。
7. 动作库、练习采用A的轻量选中态与栏目图标，不加额外头图；封面保持原语义，灰白静物也保留。
8. 记录沿用白色日历/图表，头像页点缀集中在头像。共享线稿控制在页边空白，不跨数字、图表与表格线。

建议尺寸仅作下一轮精确稿起点：周卡数字28–32pt，辅助统计18–22pt，主标题18–20pt；卡片内边距12–16pt、卡间距12–16pt，今日/完成图标视觉24–28pt但触控区域至少44pt。优先复用既有Token，最终须按真实字号/宽度验证。

## 生成图审查与交付边界

内置image_gen按五张实际Tab截图分别生成三套概念板，逐张目视并进行数字比例/日期状态/入口补充修正。图中细字、日期、进度分段、模板名和浮动按钮位置仍可能有生成偏差，不能作为可直接切图使用的产品UI。尤其C灰段辨识度、部分长标题、训练胶囊对卡片的避让，必须在选定方向后的原生精确稿中解决。

本轮没有更改Swift、正式图片资源、账号数据，没有安装/发布或声称通过设备验收。下一步是用户选定方向后再确定原生组件尺寸、状态与摄影素材裁切。
