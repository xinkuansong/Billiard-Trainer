## 看图后对产品表达的修正

| 实际画面 | 设计含义 |
|---|---|
| 动作详情有球形，精讲深入到每一杆、打点、力度及原因 | 内容价值应通过“一杆的图与解释”呈现，动作总量只做补充 |
| 学习/理论页面长文较多，瞄准点对照图局部非常直观 | 放大一个接触点或一个规则示意；整页缩图读不清 |
| 分离角与加塞吃库图谱有密集彩色线路和参数 | 选同一球形的两三种参数作对照，让用户看懂变化 |
| 2D 判断训练初始状态只有小球和提交按钮 | 应展示“先判断→揭晓参考”，不能只放空题 |
| 3D 有明确空间视角，自由走位/多杆规划有丰富操作 | 分别表达站位判断、球局思路；不能都画成泛化球桌 |
| 今日安排可组合课程/模版/动作，训练有分组录入和心得 | 展示一次完整练习的组织与记录，落到球台使用场景 |
| 历史日历呈现练习事实，统计样图为空 | 历史与统计不能混作同一 Pro 权益；统计展示需补数据态 |

## 引导：四个主题，分别有明确视觉主体

保留当前直接进入首页的启动原则。建议在首页轻入口或“我的”中提供“认识球迹”；若需要首次介绍，使用可关闭入口，不恢复强制登录或必须翻完的启动流程。

| 页 | 标题建议 | 主画面与简短文案 | 对应已有能力 |
|---|---|---|---|
| 1 | 看懂这一杆，为什么这样打 | 放大接触点/母球路线，下方一小段真实精讲。“从瞄准原理到逐杆精讲，把打点、力度和球路连起来。” | 学习、理论、动作精讲 |
| 2 | 先判断，再看参考答案 | 同一题从用户瞄准到揭晓参考；可切换俯视与 3D 视角。“练习角度与瞄准点，逐次核对自己的判断。” | 2D/3D 判断训练；涉及 Pro 的示例标记 Pro |
| 3 | 把下一杆，也想清楚 | 同一球形逐步出现目标落区及后续击球顺序。“摆出球形，尝试走位，推演后续选择。” | 思路训练、走位工具；高级示例标记 Pro |
| 4 | 今天练什么，练完留下什么 | 今日安排三行→一组录入→保存后的记录卡。“跟随计划或组合动作，记录每组结果与练习心得。” | 计划、模版、今日安排、实台记录、历史 |

第四页以免费即可完成的训练闭环收尾，不用 Pro 趋势图作为完成训练的必要终点。每日清台可做首页轻体验入口，避免把主引导加到五六页。

画面约占主要可视区域的一半，每页一个视觉主体、一句说明；提供继续/跳过，末页主按钮“开始使用”。沿用品牌绿、现有背景线稿与 Token；不同主题依靠内容构图区分。教学线路由真实渲染提供，保持物理路径/教学线各自语义；不要用生成图片捏造计算结果。静态首帧也要能解释价值。

全局介绍之后，还需要首次使用时的小提示：判断工具说明如何作答和揭晓；推演工具按摆球、目标、求解说明；实台训练说明录入及保存。这些操作说明不塞进开场四页。

## Pro：统一购买页，首屏跟随入口变化

页面顺序建议：关闭/恢复入口 → 当前能力的大幅演示 → 当前场景标题及一句收益 → 简短权益分组 → 套餐选择与购买 → 完整权益和订阅说明。套餐/按钮布局需考虑 SE 与大字号，不用固定大底栏遮住主图。

| 来源 | 首屏内容建议 |
|---|---|
| 我的 / 通用 Pro 入口 | 默认展示一张易懂的图谱对照；可切换到完整课程、走位推演、统计实例 |
| 3D 训练 | 最新真实 3D 视角及一次参考答案对照；标题“换个视角，练习瞄准判断” |
| 分离角/加塞图谱 | 同一球形切换参数后的路线对照；标题“看清打点与力度带来的变化” |
| 自由走位/多杆规划/防守 | 对应工具的已配置且有结果球形，不放尚未求解的初始状态 |
| Pro 动作/官方计划 | 当前动作的逐杆精讲或当前计划的实际课程；购买后回原内容 |
| 每日额度用尽 | 保留当前题意与题面，解释相关判断训练不限次数；不写所有工具不限次数 |
| 统计 | 有数据时用真实已记录数据说明可查看的趋势；没数据时用明确标记的演示数据 |
| 拍照建球形 | 照片→四角校准/手动标球→确认后的球桌；不宣传自动 AI 识别 |

权益按四组呈现，完整比较可展开：

1. **完整训练内容**：当前本地内容为 74 动作（44 免费、30 Pro），12 官方计划（3 免费、9 Pro）。表达“解锁更多动作与进阶计划”，不能暗示免费用户完全无法训练。
2. **进阶判断与图谱**：3D 判断训练、分离角/加塞吃库图谱、相关判断训练不限次数。
3. **进阶球局推演**：自由走位、打一走二想三、防守、拍照建球形等实际门控能力。
4. **统计与长期回顾**：统计/趋势与超出免费历史窗口的记录查看，具体描述遵循当前门控。

当前免费可用的自建模版、分享样式和登录后自主开启的云同步，不列作 Pro 独占。思路训练、自由击球、翻袋/反射等免费工具也不能整体包进 Pro。不得承诺自动评估弱项、自动推荐下一课或保证球技提升。

购买交互沿用 StoreKit 实价、月/年/终身真实产品；选中项清晰说明计费周期与总价。未登录时由购买操作进入登录并保留所选套餐及原功能，完成后继续；关闭或购买成功返回原场景。不要叠加“功能介绍页→通用 Pro 介绍页→购买页”三层跳转。

## 审查项与后续素材

### U-01 功能入口与购买页内容脱节
- 类别：产品规格 / 视觉打磨；严重程度：P2（设计改进）。
- 现状：多个不同功能截图均落到同一通用权益列表，当前 SubscriptionView 调用未传入场景。
- 建议：统一页承接来源，展示对应实际能力与结果；路由 SwiftUI Developer。

### U-02 购买权益文案与当前门控不一致
- 类别：产品规格；严重程度：P2（待实施校正）。
- 现状：当前购买页仍列自定义计划、分享全样式、云同步为卖点，而相应现行路径没有 Pro 独占门控。
- 建议：先统一真实权益，再写宣传文案；路由产品 / SwiftUI Developer。代码提示：`QiuJi/Features/Profile/Views/SubscriptionView.swift`。

### U-03 现有截图不足以直接充当营销主视觉
- 类别：视觉打磨；严重程度：P2（素材准备）。
- 现状：空统计、未求解球形、历史相机、测试名称、零记录分享混在截图集。
- 建议：生产设计前补拍当前版本的题目揭晓、图谱两三参数对照、多杆/防守结果、完整拍照建球形、真实口径的有数据统计、无测试占位字的训练闭环。
