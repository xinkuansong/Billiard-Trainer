# 绿色球训练进球线与文字（DR-133）

用户范围：仅容易与台呢混淆的颜色、进球线及瞄准线相关文字。已明确按6/14绿色系列实施，其他球号保持。

## 实现

- TrainingAssist.potColor(forNumber:)只对6/14返回白色，其余调用原球色。
- AngleTrainingScene训练样式的进球线和“进球线”文字共用取色；“瞄准线”文字原已白色，保持。
- AimPointScene训练进球线、BTAimCloseupHUD训练特写同源。
- 默认教学场景、多球轨迹与球体本身仍使用原配色。没有改几何、字号、线型、粗细和相机。
