# 每日清台球库与轻量反馈返修

## 用户最终确认
- 球库白球/全色/黑八/花色分区，本轮剩余合法球淡绿背景，瞄准球细圈，进袋暗显并保留位置；取消常驻球组文字。
- 场景统一淡绿色来自App概览深色模式现有色值，工具控件透明底且保留细框，击球主操作实底深色字。
- 无操作临时文字在上中袋下方居中，无面板、无框、无箭头。
- **所有带操作的内容均在屏幕正中**：开球确认、局中重开、开球违规处置、清台结果与再来一局、失败结果与重新开球。2D/3D共用覆盖层。
- 球桌不为消息让位，顶部球库先收紧留白。
- 一杆表示一次连续上手，不是一次击球；系统开球不计、手动开球计入当前上手。旧档未知显示击球次数，不伪造历史杆数。

## 根因与改动
旧结果直接把shotCount显示为杆，规则visitCount又会在换手时提前加一。新增playedVisitCount/lastPlayedVisit按真实上手累计，并随现有快照存档/恢复/重打。UI显示独立语义。
此前面板尺寸由满宽按钮和结果Spacer撑大。每日改用内容宽度按钮，无外层大面板；文字提示显式textOnly，共享普通页提示不受此无框入口影响。
