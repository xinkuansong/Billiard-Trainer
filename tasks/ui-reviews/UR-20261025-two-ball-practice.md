# 两球走位 · 开发与验证记录

日期：2026-10-25。用户授权轨迹走位/自由走位及2D/3D一并完成；本记录是功能专项，不是App发布或Phase人工验收。

## 实现

- 打区两正式入口，训练设置复用分离角表单，增加独立走位模式；默认轨迹走位、20题。3D与无限题数沿Pro，2D两业务模式共享本功能独立20题日额度。
- 一题固定C/A/B与A袋，按`layoutID + cellID`标识内容；同题推荐路线依次练习，默认参数为跳过，调参可提交，结果新轨迹/下一题，重打保留输入并始终可提交。自由模式整题固定第二袋、无目标推荐线，真实停点重算D，越低越好；失败null。
- 首次成绩、重试、跳过、题数/路线数分离。额度按题实例持久化后幂等记账，同题剩余路线不因额度满而被锁。三球真实物理记录、落袋事实、机位/球姿、输入、当前题快照保存；回放不重模拟。
- 同一业务VM服务两维度，使用共享TeachingTableHost/Scene/控制器/相机/布局。消费缓存最多两片，后台准备及单槽预取；无限题数在10题或512KB边界续段，单payload限1.45MB。
- 新TrainingSession kind、历史摘要、owner隔离/迁移、现有DTO传输接线；不计真实球台准确率或周目标。没有更改生成端代码、P2算法或全局物理模式。
