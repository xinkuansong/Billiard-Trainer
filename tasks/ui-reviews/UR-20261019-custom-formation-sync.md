# 自定义球形同步实现与验收

日期：2026-10-19。当前工作区代码，未提交、未部署生产。完整设计：[同步方案](../CUSTOM-FORMATION-SYNC-PLAN-20261019.md)。

## 实现

- 模板 archive v2，内容和待同步操作同文件原子保存；v1 保留备份，损坏文件不覆盖。
- 私有 REST API、版本检查、不可变重试回执、稳定分页与持久删除标记；事务失败不部分提交。
- 当前账号明确开启同步后上传/下载；游客模板另行确认合并；换号、关闭开关和迟到响应受保护。注销同步清理云端，按现有产品约定将本机内容转游客。
- 同时修改保留两个版本；远端删除且本机有修改时另存副本，原ID不复活。正在编辑的桌面保持快照。
- 列表用 btCaption/btTextSecondary 展示本机、待同步、已同步或未完成；冲突用 info.circle 辅助说明。设置与合并说明包含自定义球形，按钮继续复用原规范。
- 单次同步只遍历待上传项，已同步模板不逐个重写归档。没有新增模板数量限制，仍为25目标球另1母球。

## 失败与修正

首轮正常入口 UI 断言要求“新建模板”立即出现；该受管模拟器保留了9份游客模板，按钮位于列表下方。新增状态行进一步增加列表高度，旧测试没有滚动，75秒等待超时。原始断言保留，改为最多8次滚动查找后仍验证存在/可用；相同设备正常入口复跑通过。没有删除旧模板或修改页面以迎合测试。

该失败触发 Xcode 自动收集约3.9GB系统诊断，在磁盘不足时未能完成 xcresult，不能把该损坏包当完整附件证据。保留 `phone-ui.log`、导出失败记录、结果包其余数据及成功状态PNG，仅删除本轮未完成的 simctl_diagnostics。复跑关闭额外系统诊断采集，保留普通XCTest日志/截图/有效xcresult；成功轮未覆盖失败目录。

首轮完整gate仅报告 ProfileView 路由签名漂移，审计确认来自合并/同步说明文字；路由目的地未改。更新该文件签名、同步状态覆盖项和新测试写盘登记后完整gate通过；未批量接受其他路由漂移。

## 发布边界

本轮没有操作生产账号、发布后端、迁移线上数据库或发布隐私政策。生产默认配置不能证明MongoDB已支持事务，必须先验证副本集/分片事务及唯一索引，再部署兼容旧App的接口。详见 [后端契约与部署前提](../../backend/CUSTOM-FORMATION-SYNC.md)。目前只能确认本地隔离环境的换机数据通路可用，不能宣称线上用户已能同步新模板。真机、生产账号登录及用户体验验收仍待发布前补验。

测试资源收尾：两台模拟器租约已释放、设备保留；本轮Express与mongod进程均已退出。mongodb-memory-server关闭时自动临时目录清理报错，原错误保留在local-server.log；未扩大清理范围或删除无法确定归属的临时目录。该收尾错误发生在已完成的功能测试之后，不记为服务部署或生产数据库问题。
