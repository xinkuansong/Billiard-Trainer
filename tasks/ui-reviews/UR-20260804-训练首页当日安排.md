# UI 审查报告 — 训练首页「今日安排」（Light）
日期：2026-08-04

### U-01 当日训练信息层级分散
- **类别**：布局 / 视觉打磨
- **严重程度**：P2
- **位置**：训练 Tab > 首页 > 今日安排头部
- **现状**：周、天、完成数、栏目名、计划名与周主题分散为多行弱文本，缺少一个明确的当日训练焦点。
- **预期**：用户先识别今天练什么，再读取进度与上下文；计划名应高于周主题，周/天/时长属于辅助元信息。
- **修复方向**：合并为单一摘要卡，采用「栏目眉题 → 计划名 → 周主题 → 元信息 → 进度」层级。
- **路由至**：SwiftUI Developer
- **代码提示**：`QiuJi/Features/Training/Views/TrainingHomeView.swift`

### U-02 动作列表缺少球形辨识
- **类别**：产品规格 / 视觉打磨
- **严重程度**：P2
- **位置**：训练 Tab > 首页 > 今日动作卡
- **现状**：动作卡只有序号和文字；相似名称无法快速对应摆球与线路，重复的「第 N 项 / 共 N 项」占用副标题。
- **预期**：动作卡显示真实球形缩略图；文字区承载阶段语义与训练量。
- **修复方向**：复用离线 `BTBakedDrillTable` 缩略图与 `BTThumbnailFrame`，序号移入图上角标，副标题改为阶段标签和组球数。
- **路由至**：SwiftUI Developer
- **代码提示**：`TrainingHomeView.todayDrillCard`

### 审查总结
- 问题数量：2 项（P0: 0 / P1: 0 / P2: 2）
- 总体评价：功能链路完整，但当日训练缺乏内容预览与清晰的主次层级；本轮按现有离线缩略图能力做最小正确重构。
- **处理结果**：✅ DR-046 第四版收口——白色摘要卡严格两行、进度 2pt 底边线；90×50 专用裁口仅裁 PNG 透明留边，完整保留球桌且取消暗角；删除图上序号；阶段色降为 5pt 小色点。模拟器截图：`build/training-home-daily-redesign-v4.png`。
