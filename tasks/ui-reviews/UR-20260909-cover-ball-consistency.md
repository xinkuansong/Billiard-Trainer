# 计划与练习封面球体一致性分析

日期：2026-09-09。角色：UI Reviewer。范围：12 张官方计划、36 张练习封面；不含自定义模板、动作库教学图或运行时 3D 场景。仅分析，未修改 App 代码或正式图片。

## 证据与边界

- 用户提供四张计划卡截图；现用 Asset Catalog 48 张拼图浏览，放大核对 coverPlanAccuracy3、coverPlanPositioning2、coverPracticeSolver。
- 当前文件与 cover-felt-20260909/delivery-manifest.json 的 installed_sha256 核验 48/48 一致。
- 48 张拼图用于全局筛查，不等于全部球号逐球验收；没有凭单张图片反推真实球径。
- 代码：QiuJi/Core/Components/BTContentGridCard.swift 使用 4:3 壳；BTAtmosphereLayer.swift 对整张 UIImage scaledToFill 并叠中性曝光罩，没有逐球尺寸或球号绘制。
- 规范：docs/design/20260902-card-cover-prompt-system-v1.md §1、4、6、9。旧文档的固定 12% 暗幕说明已落后于当前按图片分档的曝光实现。

## U-01 目标球可见面缺少号码标识

- 类别：视觉打磨 / 内容一致性；严重程度：P2。
- 已确认：准度Ⅲ原图黄、蓝、红球可见面没有号码白圆；走位Ⅱ前景黄球和后方彩球没有可辨认的号码面；练习 coverPracticeSolver 黄、红球同类表现。
- 全局筛查待逐球复核：分离角、coverPracticeFlow、coverPracticePlanThree、coverPracticeAimingCorrection、coverPracticeT04/T06/T09 等。
- 单颗球号码朝背面在摄影上可能成立，不能据此断言球背面也无号码；但一组封面大量彩球无可见号码、黑8却普遍正对镜头，会产生器材体系混杂的观感。
- 修复方向：统一球面素材；前景及承担主题识别的目标球须露出完整、正确、清晰的号码面，母球不加号码。远球可以弱化，但不能借景深掩盖缺失的球体身份。
- 路由：封面资产制作；不通过界面叠文字补号码。

## U-02 主体在卡片中的比例跨度过大

- 类别：视觉打磨；严重程度：P2。
- 用户截图中准度Ⅲ母球明显小于走位Ⅰ、Ⅱ母球。现用48图同时存在微距主球、俯拍散球、局部球台等画面尺度。
- 根因：原规范允许多种镜头，只有 CAM-M1 明确主球占短边22–30%，没有跨镜头的统一缩略图可读性标准。
- 修复方向：按近景与球组/空间关系分少量模板，分别固定主体占比；同模板保持视觉尺度稳定，跨模板保留有限变化。不能把所有球强行改成相同屏幕直径。
- 路由：封面构图规范与资产制作。

## U-03 物理尺寸约束缺失，透视与人为缩小混杂

- 类别：视觉打磨；严重程度：P2。
- 原分离角提示词明确包含 two small coloured reference balls，可能引导生成器将背景球做成物理小球；未建立统一球径约束。
- 低角度照片近大远小是合理现象；本轮未进行相机标定，不能认定所有图内大小差异都是物理错误。俯拍同平面球组应优先复核，不能用透视笼统解释。
- 修复方向：固定一套同直径球模型/球面素材，尺寸变化由统一相机与深度产生；强调主角依靠位置、焦点和灯光，不独立放大球模型。
- 路由：封面资产制作。

## U-04 生成与验收规范不足以确保器材准确

- 类别：内容一致性；严重程度：P2。
- 旧规范承认 ImageGen 球号不可靠，要求具体号码时使用确定性球面素材；实例又允许远球号码不清晰、主角球放大，实际产出缺少可见号码检查。
- 原随机试装记录不等于逐图器材验收；上一轮台呢调色及哈希/构建核验也不证明球号、球径标准。
- 本轮对照上一轮原图拼图，缺号与构图尺度差异在调色前已存在；不能把它们整体归因于新台呢。
- 修复方向：先锁定球体标准，再制作候选；验收增加原图逐球检查、真实小卡可读性、整屏尺度一致性和角标遮挡。用户截图的走位Ⅰ黑8位于右上PRO附近，是安全区问题的具体例子。

## 建议顺序

1. 球体统一规范：号码圆、球色、花色、母球红点、材质及同直径；与现有项目认可素材核对。
2. 先做准度Ⅲ、分离角、走位Ⅱ、一个练习多球封面的小批对比，覆盖俯拍、低机位与球列；原图保留。
3. 缺号但构图合理的图片只修球面；比例或透视明显失真的重做球体/构图。保留已选台呢及各背景方向。
4. 候选须在完整卡片和整屏中验收，再扩展到48张；不以生成完成或构建成功替代图审。

总结：4类P2问题，未涉及功能阻断。当前证据支持“封面资产及制作规范问题为主，缩略图与角标放大问题”；不支持“运行时球号丢失”或“全部图内尺寸差异都是物理错误”。没有改图、编译或模拟器复测。
