## UI 审查报告 — 新用户引导页（Light）

日期：2026-09-03

证据边界：审查同时参考 `tmp/designer-screenshots/72-onboarding.png` 与当前 `OnboardingView.swift` / `LoginView.swift`。截图是较早状态，当前源码已换为 `ProfileBrandTrainingHero`，因此截图仅用于识别旧视觉问题，不作为当前构建验收证明。

### U-01 引导内容停留在功能罗列，没有形成用户收益链

- **类别**：产品规格
- **严重程度**：P2
- **位置**：首次启动 > 三页引导
- **现状**：页面分别讲球路、复盘和功能列表，但没有把“学、练、记”串成从理解到进步的完整路径。
- **预期**：对齐 `docs/04-功能规划.md` 的“学练记”闭环，并让每页只回答一个用户问题。
- **修复方向**：改为“先看懂 → 按计划练成 → 看见进步”。
- **路由至**：SwiftUI Developer / 产品内容设计
- **代码提示**：`QiuJi/Features/Profile/Views/OnboardingView.swift`

### U-02 前两页视觉语义相近，第三页信息过载

- **类别**：视觉打磨
- **严重程度**：P2
- **位置**：首次启动 > Hero 与第三页功能列表
- **现状**：当前源码的 route/review/identity 共用相近球路线稿；第三页又叠品牌名、标语和三条功能行，收尾焦点分散。
- **预期**：三页各有唯一视觉主题，最后一页聚焦进步与开始使用，不再重复功能清单。
- **修复方向**：三页分别使用球路理解、训练序列、进度节奏；移除第三页三条功能行。
- **路由至**：SwiftUI Developer
- **代码提示**：`OnboardingView.swift`, `LoginView.swift`

### U-03 旧截图视觉像系统占位，与当前 App 的台面素材体系脱节

- **类别**：视觉打磨
- **严重程度**：P2
- **位置**：首次启动 > 主视觉
- **现状**：旧截图使用单个通用图标和大面积空白，缺少当前 App 已形成的真实台呢、球、路径与训练卡语言。
- **预期**：主视觉能在第一眼建立“专业台球训练”识别，同时保持 iOS 页面克制。
- **修复方向**：在真实台面、轻量 3D、几何编辑式三个系列中选择一个统一方向；图片保持无字，由 SwiftUI 叠文案。
- **路由至**：SwiftUI Developer
- **代码提示**：`ProfileBrandTrainingHero`

### U-04 登录页和引导页重复讲产品定位

- **类别**：产品规格
- **严重程度**：P2
- **位置**：引导结束 > 登录 Sheet
- **现状**：登录页继续使用“看懂球路，练出结果”和同一 identity Hero，用户已经在三页引导中读过相似信息。
- **预期**：登录页只解释登录收益和游客边界。
- **修复方向**：标题聚焦“同步每一次练习”，说明换机同步、复盘数据与可先游客体验。
- **路由至**：SwiftUI Developer / 产品内容设计
- **代码提示**：`QiuJi/Features/Profile/Views/LoginView.swift`

### 审查总结

- 问题数量：4 项（P0: 0 / P1: 0 / P2: 4）
- 总体评价：功能逻辑可用，但内容叙事与视觉母题没有体现当前 App 已形成的“学练记 + 专业球路”定位，建议先选视觉系列，再逐页接入和截图验收。
