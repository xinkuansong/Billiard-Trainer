- `build-r2`：新增测试错误调用了不属于 PositionPlay 宿主的 `invalidate()`；改用现有 `suspendAuthoringActivity()`。
- `pad-r2`：前一测试的 Xcode 诊断尚占用租约，没有执行用例；保留退出状态。
- `pad-r3`：35 项逻辑／渲染检查通过；3 项 UI 因独立 pocket probe 未输出新增的反馈计数与球位字段而失败。补齐 DEBUG 诊断字段后保留原断言重跑，不修改真实选择流程来迎合测试。
