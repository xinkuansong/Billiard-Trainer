## 与「分离角与走位」的入口对照

用户更喜欢点卡片后直接出现球桌的体验。再次在同一台 iPhone 16 Pro Max、浅色模式录制。「分离角与走位」走 PositionPlayComposerView → FreePlayView，一次导航推入默认球形，桌外地毯独立于 SceneKit 保持可见。[入口原速片段](../../output/practice-first-table-20261106/stage-Composer-entry.mp4)中，列表滑出时先露出球房地毯和球库，原片约15.56秒可见台面。没有看见整屏白色或单独的纯黑底等待页。准度则由设置页内部切到共享球桌；房间地板和台面都随同一场景绘制。

独立候选让共享页按 FreePlayView 的方式在同一轮布局内取球桌区域。三项入口 UI 执行通过，但[准度候选原速片段](../../output/practice-first-table-20261106/stage-Accuracy-entry.mp4)中，原片20.89秒出现控件，21.80秒才出现台面，接着出现短暂缩小与重新铺满。提前取得布局尺寸不足以直接交付正确构图的首帧。候选未采纳；本轮无新增产品代码。后续体验目标为保留来源画面直到真实台面及相机构图就绪，再交接到练习球桌。本轮未测真机或稳定启动性能。


## 全屏球桌统一进场（准度先行）

历史上，每日清台把横屏请求推迟到导航转场完成，并在测量中的场景后铺不透明底层。该路径在 Git 提交 `1f15caf8b` 可追溯。此前共享页补黑底解决了浅色闪白；本次浅色修前片又捕获到整屏近黑和球桌缩放。用户选「分离角与走位」的球房地毯作为进场参照。

**准度试点。** 同一台 iPhone 16 Pro Max（iOS 26.3.1），从竖屏练习首页真实点击准度卡和设置页的开始。修前在 26.325 秒看到 HUD 与黑底，27.535 秒首先露出偏左的小台面，直到 27.962 秒才就位。两次独立候选虽消除了台面跳动，仍在转屏时露出半屏黑底，均退回。第三次用房间纹理平铺窗口和渲染区域，转屏期间地面覆盖完整，首次露出的台面与停稳帧四边一致，之后才放开其余入口。推广时每日清台与编排页还存在窗口旋转中提前露桌，随后由当前窗口方向控制器明确报告转场结束。六入口逐帧检查又定位到 UIKit 暂时按旧宽度裁切内容；正式方案在手机竖屏进场时把临时地面延伸到当前 UIWindow，在台面交付或离页时一并撤下。额外尝试无动画方向请求，编排页偶发台面首帧只绘出中段，撤回该尝试。首次绘制以实际 SceneKit 完成帧与稳定视口为准，进入后的单一渲染器继续工作；地毯层随后释放。

## 原实现追溯与验收纠正

用户纠正：手机先进地毯，能看到完整竖桌和操作键，再仅由台面与控件转横；地毯图案不应跟转。上方“等到横屏最终构图才露桌”的通过判定被此要求取代。

- `2cd436172`（10-08）把地毯作为独立 SwiftUI 背景常驻，透明的 SceneKit 球桌在同一个渲染视图中更新相机。源码注释明确给出原因：渲染面重排时撤掉地毯会露出宿主底色。
- `f75cbafdc`（10-11）走位编排入口复用该自由球桌。到修前的 `accc3f994` 仍走这条路径：外部 Canvas 按房间样式平铺地毯；竖、横分别选择旋转俯视／普通俯视相机；HUD 按窗口重新布局。
- `1f15caf8b`（10-21）方向控制器等页面出现、导航转场完成才向当前 UIWindowScene 请求横屏；局部坐标解出球桌绘制区。这是每日的历史修复，未发现把背景锚定物理屏幕或对地毯做反向旋转的代码。
- `6d233c3c4`（10-29）合并训练视图后，准度等项目的 2D 使用 SceneKit 内的房间。分离角与走位仍用外部地毯。常驻外部背景与“地毯每个像素在 iOS 旋转动画期间固定”是两个不同的可验证命题。
- [历史原速片段](../../output/practice-first-table-20261106/stage-Composer-entry.mp4)、[候选原片与测试](../../output/portrait-first-table-entry-20261106/)。候选准度录到竖屏桌先于旋转，不能据此给“地毯不动”判通过。原版走位路径不等候额外的首帧通知，不覆以窗口地毯。未在真机复验。

## 手机固定地毯与前景旋转

浅色 iPhone 先呈现地毯和控件，真实球桌以竖屏布局出现。系统切换方向期间保留已绘制的竖屏画面，等横屏相机和视口完成绘制后，球桌及按键在固定地毯上转动。新进场只用于手机 2D。用户明确要求 3D 使用原有入口，已撤回实验版的透视房间隐藏、竖桌等待和前景动画。iPad 继承原来的自适应方向。

准度试点先与参照对照，再推广。texture 候选可见系统黑角，native 候选有小桌跳帧，checked 候选逐帧查出一帧额外缩小。采用的 hold 试点原片显示，桌布短边在 180×390 抽帧上从竖屏约 107 像素连续调整到横屏 137 像素，停稳后维持 137 像素。露出的低饱和地毯纹路按 270×585 固定屏幕坐标逐帧作局部匹配，各帧的位移中位数在两个轴上都为零。[原片、逐帧数据与测量脚本](../../output/fixed-carpet-entry-20261106/)。

最终构建在浅色 iPhone 模拟器复录了准度、瞄准点和分离角与走位。准度从完整竖桌到横桌稳定期间，地毯特征的逐帧位移中位数为零。另在 iPhone SE 模拟器从正常入口进入角度练习 3D，测试通过，保存了[恢复后的 3D 原始录屏](../../output/fixed-carpet-entry-20261106/original-path-Angle3D.mp4)。此次未做真机复验。
