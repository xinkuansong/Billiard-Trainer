# 自由击球：3D开球试点

2026-09-12；本地实现，未发布。用户要求扩展分离角与走位试点，重点观察开球。

## 范围与使用

自由击球导航栏2D/3D切换；2D移动母球，3D滑动旋转/捏合缩放、刻度轮调方向，开球视角可重新对准。开球中允许切换，镜头不追随滚动母球。停稳后仍手动取消/重开/完成，完成后可继续击球。每日清台维持2D。

共用ShotPlayCamera和ShotPerspectiveLayout；开球仪表isPerspective默认false，其余使用者沿用原布局。未修改物理参数、开球种子、求解或规则引擎；已有v62渲染脏改保留。
