# UI 审查：每日清台专用反射／球影候选

日期：2026-09-21。依据：持续性能v2 §5.1、DR-314、设计系统及docs/05 §8。范围是渲染算法替换的视觉回归，不是页面重设计或全App无障碍验收。

## 已审证据

- `build/daily-specialized-20260921/reflection26/`、`reflection17/`：三房间×五机位/状态×六帧；A/R同机位同盘面。
- `shadow26/`、`shadow17/`：稀疏、密集、贴库、腾空，A/S/RS与运动帧；密集球堆为合法间距。
- `boundaries26/`、`boundaries17/`：台呢/木框/球贴/房间切换、六袋下方可见球体；已直接查看袋网内球体原图。
- `b6-roi-comparison.png`和`b6-roi-metrics.json`：固定矩形局部对比、MAE/峰值/差异比例。局部仍含少量台呢，数值仅帮助定位差异。
- 实际每日清台iPhone/iPad 2D/3D击球前后完整截图；实际材质标记由UI测试确认。最终补充矩阵见执行记录。

## 审查结果

| 维度 | 本轮结论 |
|---|---|
| 视觉与材质 | 保留灯板轮廓、球色/花色/号码识别、球底接触感；台呢、木框、皮袋、球杆差异仍在。密集区域存在局部高光及球影变化，未见大片黑块、洋红编译替代色或明显漂浮。 |
| 运动与状态 | 六帧运动视觉集与13帧SCNAction同帧用例；未见阴影拖尾。真实普通击球后回静止。极窄高光的真实60FPS时序观感仍须手机集中确认。 |
| 布局、Token | 原布局及字体/间距/色彩Token未改；所审完整页面未出现本次改动引入的截断、覆盖或缺失控件。3D球台透视裁切沿用既有观察相机，非本次缩放降清晰度。 |
| 产品规格 | 单人HUD、视角切换、完成后再开局遵循docs/05 §8；测试以实际状态断言验收，截图不替代规则检查。 |
| HIG/无障碍 | 本轮未更改触摸区域/字体体系。诊断AX附加值仅Debug显式开启；未重新声称已验VoiceOver全文、Dynamic Type全档或WCAG对比度。 |
| 明暗模式 | 所审实际页为深色场景；算法取自同一材质参数。本轮未做全App Light/Dark矩阵，不外推其验收。 |

当前没有确认的本轮P0/P1/P2视觉阻断项。以上属于电脑端审查，不等同用户最终接受；B7继续保护球边缘、号码、瞄准线和接触感。手机性能/温升不属于此报告通过项。
