# UI 审阅报告：全 App 色彩一致性

> 日期：2026-09-03
>
> 角色：UI Reviewer
>
> 审阅对象：当前源码 A2/iPhone 15 Pro/iOS 17.0/Light 完整巡游 66 张，以及 A1/iPhone SE（第 3 代）/iOS 17.0/Dark 完整巡游 66 张
>
> 结论：**Light 仍有中等程度的杂乱感；Dark 明显更统一，已不是“整体乱”，但选中态、金色语义和个人页首屏仍缺少统一规则。**

## 二、整体判断

App 已经有稳定的基础骨架。Light 依靠浅灰背景、白卡、深绿主色和黑色正文；Dark 依靠黑底、深灰卡、白字和亮绿交互。Dark 的模式连续性明显优于 Light，尤其是理论页进入球桌工具页时不再像切换到另一款 App。当前问题主要发生在强调层：

1. 浅色内容页使用绿、黑、灰三种不同的“选中态”。
2. 金色同时承担 Pro、警告、教学提示、轨迹和装饰强调。
3. 品牌绿、球桌绿、照片绿、薄荷绿表面和成功绿同时出现，彼此明度与饱和度跨度较大。
4. 浅色阅读模式与黑底工具模式各自成立，Light 切换仍偏突兀；Dark 已基本解决这一段割裂。
5. 计划与练习封面的摄影色温、亮度和背景差异，比 UI Token 本身更容易制造杂乱感。

主观色彩一致性评分：Light 约 7/10，Dark 约 8/10。Dark 的剩余扣分集中在状态语义，不是背景或文字对比度失控。

## 四、问题清单

### C-01 选中态颜色规则不统一

- 严重程度：P2
- 证据：`01`、`03`、`05`、`08*`、`40`、`52`、`54`。
- 现象：同为“当前选中”，Light/Dark 分别出现黑/白反相胶囊、绿底白字、绿色文字加下划线、灰底日期块和绿色侧边轨。Dark 的白色筛选胶囊尤其抢眼。
- 影响：用户需要重新学习每个页面的交互状态，视觉上也会觉得色彩在跳。
- 建议：跨模式都只保留两级：主导航用“绿色文字/指示线”，局部筛选用“品牌绿填充/白字”或低饱和绿表面；不再用 Light 黑、Dark 白作为第三套选中态。

### C-02 金色语义过载

- 严重程度：P2
- 证据：`01`、`03`、`04`、`08*`、`09e`–`10`、`19`–`28`、`50`、`53`、`54`、`55`、`57`、`72`。
- 现象：金/黄/橙同时被用于 Pro、访客警告、月达成率、提示卡、力度刻度、轨迹、装饰短线和 Onboarding 路径。
- 影响：商业权益、风险提醒与教学信息互相抢语义。
- 建议：金色只保留给 Pro；警告使用独立 Amber；教学轨迹固定为一套“白/薄荷/橙”的物理标注规则，装饰不再使用金色。

### C-03 绿色层级过多但缺少角色命名

- 严重程度：P2
- 证据：几乎全部页面，尤以 `01`、`03`、`05`、`08*`、`13`–`28`、`50`–`57` 明显。
- 现象：品牌深绿、CTA 绿、球桌高饱和绿、照片暗绿、薄荷绿底、成功绿并置。
- 影响：主操作与内容背景有时竞争，浅色页与暗场页的品牌连续性变弱。
- 建议：明确 `brand / interaction / success / felt / mint-surface` 五类角色；允许球桌绿保持内容真实，但 UI 层只使用一深一浅两个主绿层级。

### C-04 Light 内容模式与暗场工具模式缺少桥接

- 严重程度：P2
- 证据：Light 的 `12n → 13`、`08* → 14`–`28`；Dark 对照已复验。
- 现象：Light 从白卡阅读页切到黑底工具页时，背景、控件、对比度和强调色全部同时翻转；Dark 下该问题显著减弱，登录与 Onboarding 也已统一为暗色入口。
- 影响：主要影响 Light 的跨页连续性，不再视为 Dark 的全局问题。
- 建议：保留暗场工具；统一两种模式的导航标题、返回/更多按钮、状态胶囊、主 CTA 形状与绿色角色，使模式变化只发生在工作区背景。

### C-05 摄影封面缺少统一调色基线

- 严重程度：P2
- 证据：`01`、`03`、`08a2`–`08d`。
- 现象：白棚拍、高对比暗绿、明亮球桌、浅景深特写混排；相邻卡片的白平衡与黑位差异较大。
- 影响：用户首先感知到的是图片风格变化，而不是计划/练习层级。
- 建议：不重做全部封面，先统一曝光、黑位、绿桌色相、叠层强度和角标位置；白棚拍只作为一个明确系列使用，不与深绿摄影随机混排。

### C-06 个人页首屏同时出现四套强调色

- 严重程度：P2
- 证据：`50-profile-top`。
- 现象：登录绿、警告琥珀、Pro 黑金、功能图标绿/金/灰同时出现。
- 影响：用户不清楚当前第一动作是登录、升级还是继续管理训练。
- 建议：首屏只保留一个主行动色；访客警告降为中性信息条，Pro 保留金色但降低面积，普通功能图标统一为单色绿或中性灰。

## 五、保护清单

1. 不降低彩球颜色：彩球是球号与规则信息，不是装饰噪声。
2. 不把暗场工具强行改成浅色：黑底工作区能突出轨迹、瞄准点和球桌，是成熟资产。
3. 不先改全局 `btBG` 或 `btPrimary`：基础 Token 不是本轮主要根因。
4. 不用全量换图解决问题：先建立封面调色和叠层规范，再批量归一。

## 六、建议优先级

1. 先统一 Light/Dark 的选中态：解决反相黑白、绿和灰并存。
2. 再收紧金色用途：Pro、警告、教学三者拆开。
3. 减少个人页首屏的同时强调项，并统一普通功能图标。
4. 为 Light 内容与暗场工具建立共享 Chrome 规范。
5. 最后做封面调色归一。

## 七、Dark 复验结论

- **通过**：Dark 66 张主巡游、PNG 完整性、统一尺寸与联系表目视审查。
- **通过但需替换证据**：真实登录页已由登录专项用例补拍；原始主巡游 `70-login.png` 不可作为登录页视觉证据。
- **未通过（测试资产）**：`testV47BrandSample` 仍断言当前已下线的微信/手机号入口和协议文本，需另行更新测试契约；本轮只诊断，不修改测试代码。
- **颜色结论**：Dark 不存在整体失控；C-01、C-02、C-06 仍成立，C-04 在 Dark 中明显缓解。
