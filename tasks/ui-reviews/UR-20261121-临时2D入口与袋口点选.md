## 袋口命中规则

- 直接 SceneKit 命中继续优先处理球和可见袋口皮革。
- 无直接命中时，按六个袋口的投影中心计算最近候选。
- 每个候选的屏幕命中半径按投影球体半径计算，范围为 36–52pt，并保留 12pt 扩展余量至上限。
- 命中区只存在于触控解析，不创建可见球体，也不改动物理袋口。
- `-pocketSelection.probe` 诊断值新增 `hitRadius`，用于记录每个袋口的实际触控半径。
- 数值草稿见 [pocket-hit-radius-draft.json](../../output/temporary-2d-pocket-fix/pocket-hit-radius-draft.json)。

## 角度练习 3D 入口追加修订

用户新增截图显示角度练习进入 3D 后停留在小型桌面总览，和角度与瞄准点练习已经采用的玩家视角不一致。代码核对确认，角度练习题目安装后没有执行同等的第三人称相机落位。

已在 `QiuJi/Features/AngleTraining/ViewModels/AimingQuizViewModel.swift` 的题目安装路径补齐 `applyAimingPoseIfNeeded()`。3D 观察阶段会在球位完成后立即调用共享 P01 相机的第三人称入口，并重置第三人称状态。2D 路径仍不触发该调用。

验收基线改为：冷启动或返回后进入角度练习 3D，题目球位出现后应直接显示稳定的玩家瞄准视角，桌面比例和机位应与角度与瞄准点练习一致，不能停留在屏幕中央的小桌面总览。新增逻辑回归测试已编译进测试包。由于临时 iOS 27.1 模拟器容量达到上限，本轮未取得新增测试的设备执行结果，仍需在可用 iPhone 或受管 iPad 上做视觉复验。

## 临时 2D 管道透底追加修订

用户复验发现，移动球后管道内部仍能看到透视 3D 场景中的球影。原因是临时 2D 的静态快照图片和合并 SceneKit 叠层都使用透明底，管道的半透明填充在叠层合成时把底下的实时 3D 内容露出。

已在 `QiuJi/Core/Scene/AngleSceneView.swift` 为两条临时 2D 叠层路径加入不透明黑色底。静态 `UIImageView` 和合并式 `SCNView` 都会先遮住实时 3D，再显示临时 2D 球桌与半透明管道。3D 正常页面仍保持原有管道透明度。

复验标准是进入临时 2D 后拖动 5 号球或改变瞄准线，管道内只显示临时 2D 的桌面与辅助图形，不能出现透视 3D 球、球影或房间元素。设备视觉复验待可用设备。
