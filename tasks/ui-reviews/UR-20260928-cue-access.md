# UI审查与功能验证 — 近库可用打点（DR-338）

2026-09-28。用户授权将近库禁低杆与自适应避让合并；本轮实现与标准手机模拟器定向验收完成，待真机体验。

## 实现

- CueStrikeAccess 统一球位、实际台面高度、瞄准方向、侧塞、后方球与抬杆可达判断。普通击球最大抬角15°；旧60°仅保留渲染兜底，不能使交互低杆自动合法。15°为产品初值，未标定倾斜击球物理。
- 打点盘灰显不可用区域，与0.5R打滑圈共同限制。拖动沿当前侧塞列投影到可用边界；整列不可用时保留选择。方向按钮/回中不得绕过限制。
- 球位/方向变化不自动改用户打点；失效时显示受限，隐藏无法摆放的杆。出杆前在历史、杆数、动画和物理状态变更前拒绝，提示调整打点或方向。
- 可行打点的球面接触点固定，通过平移杆姿支点求最小抬角；瞄准与实时运杆一致。固定仰角可达检查复用同一几何函数，避免UI嵌套角度搜索。
- 接入共享BTProjectedSpinPadOverlay、每日BTSceneSpinPadOverlay及走位/思路/三杆/斯诺克、翻袋/颗星、开球执行入口。序列/导出保留原打点数据和只读语义；不新增扎杆/跳球物理。

## 功能验证

`build/cue-access-20260928/final.xcresult`：34项单元/场景 + 1项UI，0失败。

- CueClearanceTests 22项：原几何/回撤测试、近库与沿库方向差异、整列受限、后方球、181组可行接触点与杆身离库检查、瞄准/运杆起始姿态一致、拒绝开球不改阶段及打点。
- TableAssistDR296Tests 10项；SequenceStillCueTests只读静帧1项；BreakFlowRunnerV6Tests普通开球真实旋转传递1项。
- 每日真实页面UI：初始受限中心点点击击球显示提示；2D/3D向下拖动均停在正高杆可用边界，低杆按钮与回中均不能越界。
- `verify-gate`通过。文档体积与diff检查通过（doc-size.log / diff-check.log）。
- 早期geometry轮次31项中拒绝开球fixture两条断言失败：球被放在出杆前方库边，而杆尾位于开阔区；改为真实杆后近库侧后通过。保留旧失败日志，不计作生产缺陷修复证明。
- integration轮次33项（1个显式opt-in测试跳过）+1UI通过；最终轮明确选测试，35项均执行通过。

## 视觉审查

标准iPhone模拟器（QiuJi-CueFade-20260927，iOS 26.3）的实际每日清台2D/3D和拒绝击球提示，另有固定320pt测试宿主中的共享组件对比。已打开最终原图检查。

- 白盘、虚线圈、红点和四向键保留原尺寸/位置，禁区灰色覆盖可辨，打点文字无截断；2D/3D同一限制。
- 受限旧选择保留红点，显示“当前打点受限”。同组件无约束参照使用完全相同打点；不是改前完整App基线。
- 拒绝提示沿用无框消息，未挤压桌面。未发现本轮新增的布局阻断问题。
