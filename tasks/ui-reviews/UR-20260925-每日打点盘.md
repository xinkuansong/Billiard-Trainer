# 每日清台打点盘与力度条布局审查

## 最终实现（DR-333）

- 每日清台显式启用`BTSpinPadCard/Overlay.usesFixedLayout`：盘区160pt、透明外框264×264pt，四向键44pt，读数/回中分置下方向键两侧。
- 两模式共用`ShotTableLayout.landscapePlayingRect`，从现有2D横屏正交适配及实际外框半尺寸计算内框；面板水平居中，底边对齐内框下沿，iPad不拉伸。
- `BTShotInstrumentColumn.fixedPowerBarHeight`仅每日设144pt，力度条不再随屏高拉长；原力度范围、映射、拖动语义保持。
- 没有改变球桌尺寸、相机取景、打点物理，其他页面默认布局保持。
