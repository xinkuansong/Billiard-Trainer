# CuePhys 功能页与设置盘点 · 2026-11-20

[打开按功能排列的原生截图图册](../../output/settings-audit-20261120/index.html)。图册把练习准备页、进入后的球桌及其菜单放在同一项下。本文核对工作区 Swift 代码，整理范围和生效时机。末节是供讨论的方案。

练习目录按当前发布入口逐项核对，共 44 张公开功能卡：基础 7、准度 6、控球 7、走位 10、进阶 7、策略 7。走位目录在模拟器上另有「批量出片台」。训练首页的「每日清台」和动作详情的「试打」分别收录。[练习目录定义](../../QiuJi/Features/AngleTraining/Views/AngleHomeView.swift)

图册按 **83 项功能或页面、152 张截图** 编排，其中 25 张拍到已展开的桌边「更多」。分组是通用设置与外观 6 项、开练前设置 13 项、桌边工具与教学 13 项、目录内其他功能 20 项、训练／动作库／记录 21 项、我的与账户 10 项。同一页的展开、滚动、编辑和模式切换算同一组。

采集环境为 iPhone 17 Pro Max 模拟器、iOS 26.2，当前工作区的 1.0.0（1）Debug 构建，基础提交 `015889aea`。以浅色为启动偏好，部分页面使用自己的主题。账号、会员和示例训练记录采用模拟数据。同一模板下的动作、计划、记录取代表内容，未逐一拍摄所有球形、权限弹窗、支付流程、外部网页、尺寸或配色。本轮交付界面现状与代码盘点，App 改版待讨论。

## 从哪一页能改什么

| 我想做什么 | 现有入口 | 生效范围和时机 |
|---|---|---|
| 让相关球桌默认显示网格，或统一轨迹档位 | 我的 → 设置 → 练习显示，或训练 → 更多 → 使用帮助 → 打开设置 | 修改即应用到支持该字段的页面，清除该字段已有的页面覆盖。右上角「…」可用同一个值再次统一 |
| 只在这张球桌改显示方式 | 球桌 → 更多 → 视图、台面网格、特写、轨迹或打点盘透明度 | 按宿主提供的能力保存到当前页或合并后的训练项目。切视图和允许的辅助项目随练习不同 |
| 选择这次练什么 | 练习 → 对应训练卡 → 训练设置 | 先编辑草稿。共用表单在选题成功后保存，然后开练。返回或取消与开始分开。进行中重进设置时要区分开始新练习和继续旧局 |
| 切换球房或器材 | 我的 → 设置 → 球房风格／球桌风格／台呢颜色／球贴纸／球杆外观 | 五个独立选择页。房、桌、台呢使用当前整套搭配预览，选择即保存。球杆外观仅改变外观 |
| 改每日清台的玩法 | 我的 → 设置 → 每日清台 → 默认玩法；清台桌内另有「开球玩法」 | 通用页明确注明影响下一个新局；桌内入口处在开球流程。两处文案需要区分「下次默认」和桌内操作 |
| 调整训练习惯 | 我的 → 训练目标；训练首页 → 更多 → 训练提醒 | 训练目标页也能进入同一提醒页。前者是每周训练天数；后者是本机通知开关、时间、重复日期，点保存才生效，受系统通知授权影响 |
| 改某份训练模版里某个动作的量 | 训练 → 我的模版 → 新建或编辑 → 模版中的动作 | 「训练设置」在此指动作遍数 1–20，总量按内容剂量换算。作用范围是一份模版中的一项 |
| 管理训练数据与账号 | 我的 → 设置 → 数据管理／账号安全；「我的」还有个人信息和退出登录 | 云同步及绑定相关内容随登录状态出现。注销、清缓存和退出登录有不同后果；个人运动偏好、通知和显示偏好也各有自己的存储 |

## 「我的 → 设置」逐项核对

页面入口叫「设置」，导航标题叫「通用设置」。沿当前滚动顺序可见下表。采用登录模拟样本时可以看到账号安全；游客视图省略登录专属内容。

| 顺序 | 屏上内容 | 代码行为或阅读障碍 |
|---|---|---|
| 1　练习显示 | 默认视图 2D／3D、台面网格 4×8、瞄准特写、打点盘透明度、轨迹档位、3D 显示轨迹 | 写入全局球桌偏好。改轨迹档位还会把「3D 显示轨迹」设为开启，涉及两项显示状态 |
| 2　击球辅助 | 显示 90° 分离角辅助线、运杆演示 | 运杆演示指击球前试运一次；每项练习里的「击球过程」决定是否播放出杆后的过程，二者可独立成立 |
| 3–5　外观、球桌帧率、声音 | 跟随系统／浅色／深色；30／60／120 帧；背景音乐、击球音效 | “外观”在这里仅指应用明暗；球桌器材的外观在更下方。音乐在练习页播放 |
| 调试条件 | 开发者（模拟器）→ 解锁 Pro | 由 DEBUG 与 simulator 同时控制。图册保留原始调试画面，产品信息架构中应排除此项 |
| 6　器材卡片 | 球房风格、球桌风格、台呢颜色、球贴纸、球杆外观、显示颗星参考点 | 前五项跳转选样，末项原地开关。源码中这块叫 equipmentSection，画面里没有对应组标题。颗星参考点的用途也接近显示辅助 |
| 7　每日清台 | 默认玩法 | 单个功能的专属偏好占用全局页一整组。用户未明确选定时，代码支持根据个人偏好推断初值 |
| 8　数据管理 | 训练数据云同步、按条件显示立即同步、清除缓存、数据导出（即将推出） | 云同步范围包括训练记录、角度与瞄准成绩、自定义球形。收藏、计划、训练安排保存在本机。「数据导出」当前是占位 |
| 9　账号安全 | Apple 登录、微信登录的绑定状态；注销账号 | 已登录才显示，授权入口受渠道能力限制。截图为模拟身份状态，未进行绑定、注销或实际云端操作 |
| 右上角「…」 | 统一应用到相关页面，按字段列出当前值 | 菜单列出 8 个球桌字段。逐项选中会把该字段统一到支持页；没有“把全部选项恢复出厂”的一步操作 |

## 练习准备页逐项对照

在练习目录中，12 个项目使用标题「训练设置」，另有自定义球形使用「选择球形」。其中前六项复用同一个 SwiftUI 表单；辅助能力由宿主传入，2D／3D 不重复计作两份表单。

| 项目 | 可改的内容 | 和其他页的区别 |
|---|---|---|
| 角度练习 | 训练量、切角范围、四项球形条件 | 目标是看球形估切角。没有调球杆的出题项 |
| 瞄准点练习 | 同上 | 额外列出五档毫米误差和首答统计规则。该说明可占一段滚动空间，用户无需给它填值 |
| 准度练习 | 共用条件；自行调整高低杆／左右塞；系统指定高低杆／左右塞 | 同一轴的手动和系统指定互斥，却分处「击球设置」与「出题设置」两个区段 |
| 分离角练习 | 共用条件、目标路线是否包含高低杆／左右塞、击球过程 | 杆法开关筛选系统给的目标路线；练习中仍可自行调打点与力度 |
| 两球走位 | 轨迹走位／自由走位、训练量、第一杆角度和球形条件、击球过程；轨迹模式另有目标路线杆法 | 两种模式分别记住自己的草稿；自由走位按实际停点评分。这里的模式与「持续练习」是两回事 |
| 三球走位 | 训练量、第一杆角度和四项球形条件 | 第一杆的条件不等于后续每一杆都满足该条件；宿主没有传入击球过程或筛选目标杆法的控件 |
| 翻袋练习 | 15 题／持续练习、目标袋型、碰库 1–3 次或综合、库边颜色提示、击球过程 | 「训练模式」实际放的是题量；袋型页面称「底袋」，共用表单称「角袋」 |
| 解球练习 | 15 题／持续练习、碰库 1–4 次或综合、库边颜色提示、播放击球过程 | 这里叫「练习方式」；碰库目标是母球绕库去碰目标球 |
| K球练习 | 15 题／持续练习、观察库次、K球时机、第一球袋型、模拟容错、库边颜色提示、播放击球过程 | 「观察库次」是题库筛选，需区别于解球练习要求完成的库序 |
| 防守练习 | 轨迹／自由模式、15 题／持续练习、综合或四种双方剩球组合、击球过程 | 同屏有「练习方式」和「训练题数」，含义更容易区分；自由模式可配有限题数 |
| 多球走位 | 追分／中八残局、规划／自主走位、训练量、球数、规划球标记；中八增加对手球 | 固定训练量是 3 局。追分可选 4、5、6、9 颗；中八己方 4–8 颗，对手可选 0 或随机 1–7 颗 |
| 蛇彩练习 | 从左到右／从右到左／按号、目标球数 3–15（初始为 5） | 最近 10 次记录与开练选项在同页，默认展开；无记录时也占一组 |
| 自定义球形 | 选择内置／个人模板、创建；模板操作含复制，个人模板另有编辑、改名、删除 | 页首写「选择球形」。练习态菜单分支直接返回回放、另存模板等项；文件后段虽有「训练设置」字符串，但前面的提前返回使它不应计作当前练习态入口。编辑台另有一套模板操作 |

共用球形条件包括母球到目标球距离、目标球到袋口距离、目标袋类型和目标球离库。角度提供综合 0–85° 与五个窄区间。分离角、两球、三球的出厂选择为近直球、小角度和中角度。共用表单在恢复默认后仍要开始训练，才会保存草稿。持续练习受会员条件约束。

## 球桌上的「更多」为什么还需要单看

| 页面族 | 入口里混合了哪些事情 | 整理时要保留的差异 |
|---|---|---|
| 角度、瞄准点、准度、分离角、两球、三球及进阶题库 | 球桌显示、操作布局（支持页）、返回训练设置、结束练习等 | 题目可能禁止给出答案的辅助；例如角度练习的全局字段范围仅含视图和网格，瞄准点练习另支持特写 |
| 每日清台、多球、蛇彩、分离角与走位、动作试打 | 共享球桌按模式拼出视图、网格、特写、透明度、轨迹、瞄准方式、操作布局，以及开球或训练专属命令 | 每日、编辑、试打、残局的可用项和阶段条件不同。播放中、开球中或只读序列里有些命令会禁用 |
| 走位求解、打一走二想三、翻袋、颗星解球 | 球桌偏好与求解条件、原理说明、恢复球形或查看解混合 | 求解条件决定算法要找哪条路线；“下一解”是一次操作。颗星解球没有瞄准特写这一全局字段 |
| 扎杆与跳球 | 空间球桌上的显示、操作布局、清空／恢复、上一杆路线、详情与回放速度 | 具有专门的 3D 操作；“恢复默认”可涉及当前球桌状态，与训练表单底部的草稿重置不同 |
| 进球容错角、角度与瞄准、分离角图谱、加塞吃库图谱 | 教学内容的即时操作，以及页面提供的视图、网格等显示项 | 教学轨迹本身就是内容。全局关闭分离角辅助线时，应保留教学所需的图解 |
| 布局编辑 | “操作布局”进入另一套编辑流程，按页面族、共用／2D／3D 层处理控件位置、尺寸和排列 | 如果收拢显示设置，可保留桌上直接编辑布局的入口，用户需要看着球桌移动控件 |

球桌字段读取顺序是项目／页面覆盖值 → 通用值 → 该页初值。瞄准特写在部分页面的初始值为开。运杆演示仅读取通用值；自动推荐及目标球接触点使用独立的页面写入路径。字段表表示可接受的偏好，最终可见控件还取决于宿主和当前阶段。

下表可回答一个实际问题：在「我的」里改完一个球桌选项，哪些页面会读取它？表中只列通用设置的八项。桌上还可能提供独立的局部工具。

| 瞄准点练习 | 默认视图、网格、瞄准特写 |
| 分离角练习、两球走位、三球走位、解球练习、K球练习 | 默认视图、网格、打点盘透明度 |
| 准度练习、翻袋练习、防守练习 | 默认视图、网格、打点盘透明度、瞄准特写 |
| 扎杆与跳球 | 网格、打点盘透明度、轨迹档位、3D 显示轨迹 |
| 颗星解球 | 默认视图、网格、打点盘透明度、轨迹档位、3D 显示轨迹、运杆演示 |

## 建议先讨论的三个决定

1. **通用偏好是否应该覆盖已经调好的单页。** 这是影响最大的行为决策。建议把「修改默认值」与「把此值应用到所有支持页」写成两种明确动作。前者保留用户做过的单页选择，后者在执行前说明覆盖范围。若决定维持现行为，也应在开关旁说明会同步覆盖。
2. **训练准备页是否统一回答三个问题。** 首屏依次显示“练什么模式、练多少、抽什么题”，题量统一使用「训练量」，具体写「15 题」「3 局」或「持续练习」。准度的两组同轴开关并排表达谁来指定杆法；瞄准点评级说明和蛇彩历史都给独立展开入口。保留每门练习特有的题库条件。
3. **球桌菜单是否先按动作后果分组。** 将视图、轨迹、网格、特写、透明度收在「本页显示」，布局保留桌上入口。当前一局用到的瞄准、求解和回放紧挨操作；另列「重新开练」「结束练习」「清空桌面」，让一次性动作及作用范围一眼能辨认。

可先拿准度、翻袋、每日清台和通用设置四页对照讨论：它们分别暴露互斥字段、同义不同名、局内／下局和跨页覆盖这四类问题。

## 每日清台桌边菜单推广分析 · 2026-11-20

**范围。** 以每日清台当前五组和子菜单返回原位为参考。图册内有 25 个已展开的公开功能菜单，其中每日清台已经实施，其余 24 个公开功能列于下表。计数按功能入口，2D／3D、练习中／结算、模板练习／编辑均按状态核对。截图用于确认实际出现过的菜单行，代码用于核对其他模式下的增减。以下为待讨论建议。

**共用次序。** 先放「桌面显示」（视图、网格），再放「击球显示」（特写、接触点、轨迹、分离角辅助线），再放「瞄准辅助」（瞄准模式、自动推荐）和「操作控件」（打点盘透明度、操作布局）。某页有教学图解或求解范围时，以对应业务组安排。球形和回放操作放在相关工具之后；存在真正的玩法选择时，「玩法」放在最下。考题的「训练设置」「结束练习」归在末尾「本次练习」。按现有能力显示各组，空组省略，首层直接滚动。每组沿用每日清台的视觉层级、选中态和右对齐当前值。已有子菜单点击返回后停在原行，关闭整个菜单再打开从顶部开始。透明度面板的完成、布局编辑的保存／取消、开练或结束等有各自的后续动作。

| 功能（同配置合并列出） | 建议如何整理现有桌边选项 |

| 分离角与走位 | 桌面、击球、瞄准、控件四组按现有项排列。该宿主有特写、接触点、轨迹、瞄准模式和自动推荐；「清空桌面」「恢复默认球形」归球形操作，「开球玩法」置底。 |

| 分离角图谱、加塞吃库图谱 | 桌面（视图、网格）→ 击球显示（目标球接触点）→ 操作控件（布局）。杆法／加塞八档、库数选择继续从桌上直接操作。 |

**入口和范围。** 「训练设置」这一行可以随桌边分组调整显示位置，点开后的题量、角度、杆法、球形条件、保存与开练逻辑照原页面执行；所有进入练习前的设置页、「选择球形」和「我的 → 设置」均不纳入这次改版。普通教学阅读页及动作详情的内嵌球桌也不在此列。拍照建球形的选图、校准、标球流程沿用现状，其后分别复用分离角与走位、走位求解、打一走二想三。「自由练习」旧公开入口已退役，旧击球模拟路由映射到分离角与走位。批量出片台仅在模拟器发布，录制、重录、保存和竖屏工作台另有结构，可单列为内部工具评估。

**实施顺序建议。** 先取分离角与走位、准度练习、走位求解，分别验证自由球桌、题目中的球桌及求解专属选项。再推广至其余公开功能。渲染层复用已有分组外观；每个宿主声明自己的组和项目，按业务状态拼装，不依赖固定数组插入位置。自由球桌、共用教学球桌及角度／瞄准点两个独立宿主都要检查滚动返回。至少覆盖题目中返回原训练、试打序列／自由切换、自定义编辑／练习、多球规划／自主、3D 轨迹关闭，以及短菜单、小屏底部可达。
