# 自定义球形 v1.5 · 排序与端点防遮挡

日期：2026-10-18。范围：用户追加的白色角度标注、当前线三态球号排序、三类线端点共用球拖动规则。

## 最终行为

- 角度圆弧及角度值为白色；测角臂保持橙色、测距保持青色，文字无背景。
- 当前直线右侧新增一个56×44pt的共享BTTextActionButton，保留原三项参数、删除与保存。排序循环：球号升序从屏幕左到右、升序从右到左、恢复本轮排序前的顺序。竖线按上到下／下到上，母球在线上时按0号处理；重复号码保留独立实例。
- 全图按球身份做一一置换，因此连接点仍共用一颗球，其他槽位、球数及等距关系不变。手动增删／重排后重新建立原始顺序；拖端点不重置排序基准。撤销重做同时恢复排序状态与选中线。保存当前排列；重新编辑模板从载入的排列开始新循环。
- 三类端点保留44pt优先命中，取消立即跟手的特例和松手额外采样，与球共用52pt死区／锁定偏移／反向继续跟随。点击端点不位移、不重建测量；磁吸、桌内边界和球位重叠校验保持。
