# UI 审查报告 — 渲染代码优化集成

日期：2026-10-02。范围：角度与瞄准、分离角与走位、每日清台。审查依据为当前设计系统、实际消费者与固定画质约束，非完整产品重新设计验收。

## 证据与结果

标准手机、小屏 iOS17、iPad iOS26 各23张真实UI截图，共69张。全部原图解码/尺寸/非纯色检查通过，SHA及状态标签在 `build/render-code-optimization-20261001/s2-integration/image-manifest.json`。每单元三张联系表逐张目视，三张代表原图单独打开。联系表仅供审阅，没有覆盖或重采样替换证据原图。

S1的图解标签旧/新24状态RGBA零差另有对拍；S2有效球杆姿态/透明度的同场景A→B→A通过。原生页面中教学线、球杆、球影与材质可见，重开后球杆指向新的母球，下一杆可击出。真实手势/出杆/回放/取消确认功能与目视分别验收，未发现本批引入的新P0/P1视觉回退。不能从这组后版本截图单独认定所有动态图像与旧二进制逐帧一致。

系统外观：手机/小屏回读Light，iPad回读Dark；交互场景按产品实现固定深色，故仅为相应系统环境测试，不宣称整个App的双外观验收。字体/Token/导航没有修改，Dynamic Type/44pt所有控件/全页对比度未做全量新检查。

## U-01 iPad每日清台全屏验收缺口

- 类别：布局/测试环境；状态：待复验，尚未判定为本批产品缺陷。
- 位置：iPadOS26 > 每日清台横屏。
- 现状：App显示为系统圆角窗口，周围壁纸和Dock可见。四项UI功能通过，但测试断言针对App窗口，不等于原生全屏横屏。
- 预期：后续补真正全屏环境下相同四项流程，并保留窗口模式覆盖。
- 处理：保留原图与窗口状态。CUA检查Simulator时返回Mac已锁屏且无法自动解锁，无法操作系统最大化控件；未改Info.plist、旋转策略或伪造全屏状态。
- 路由：Test Engineer；若全屏仍有布局异常，再交SwiftUI Developer。不会以当前窗口截图宣称全屏通过。

## U-02 角度页小屏顶部统计末项截断

- 类别：布局；严重程度：P2（已有页面待办）。
- 位置：角度与瞄准 > 顶部横向统计。
- 现状：750×1334原图的偏移统计右端截断；标准手机也紧贴右侧。教学提示低对比度另有可读性问题。
- 预期：统计按可用宽度滚动或换行，教学提示具备足够对比度。
- 范围判断：本批只复用SceneKit图解UILabel布局边界，未改顶部SwiftUI统计/提示；同次旧/新布局对照一致。当前优化任务保持界面，未顺带调整统计条或提示设计。
- 路由：SwiftUI Developer；后续单独界面修复。当前不能标记为页面全优或完整无障碍通过。

## 审查结论

本批相关画面与球杆生命周期通过已覆盖状态检查；iPad每日清台窗口模式具有明确证据，全屏仍待补测。新确认并修复的动作取消P1见FL-097；本报告没有把UI测试绿色当作未覆盖系统状态的通过证明。
