# 袋口选择、推荐与反馈：系统设计方案

日期：2026-10-01。状态：r2 实施完成、模拟器验收通过。2026-10-01 用户授权执行，并将点击反馈等待明确为固定1秒；黄色持续0.6秒另计。

## 1. 这套交互的工作

用户表达“我想让这颗球去这个袋”，系统应迅速接受意图、清楚呈现当前操作能力，并让人继续瞄准击球。自动推荐提供一个直进默认方案；用户介入后，当前杆由用户决定。

由此得到五项原则：

1. 用户的意图优先。手动指定球或袋后，计算返回不得替换它，也不得改力度或打点。
2. 选中、路线可行、当前杆预测进袋是三个不同事实。黄色确认选择；几何判定是否支持直进辅助；力度/杆法预测描述这一杆的结果。
3. 推荐的代价有边界。只判断直接线路，不搜索翻袋、多库、解球或传球方案；完整模拟只服务已提交的一杆。
4. 信息要在用户能看到时呈现。状态提交迅速；袋口局部反馈与手势生命周期分开调度。
5. 当前状态持续可读。短暂黄色是事件反馈，消失后仍需从模式状态与瞄准线知道当前选择。

## 2. 已确认的现状与根因

| 当前事实 | 用户体验影响 | 源码依据 |
|---|---|---|
| 普通FreePlay不可直进时提示并return；Daily绕过这项检查 | 同一个点击在不同入口产生不同结果，均未实现用户要求的自动切自由 | `PositionPlayViewModel.swift:732` |
| Daily六袋没有几何候选时，仍传`available: true`提交旧袋/近袋 | 把“没有推荐”伪装成直进辅助，后续求解再补救 | 同文件`selectBestPocket`，约1033行 |
| 自动推荐可能调用`solveDailyDirectRecommendation`，观察到传球后逐球再次物理求解，并回写球和袋 | 初次显示的默认选择可能稍后改变；推荐实际还包含第二轮物理筛选 | `PositionPlayShotSolver.swift:15`；VM约1223、1270行 |
| 普通进袋预测失败后调用`solveBankAlternatives`，可回写spinX/spinY | 等待复杂搜索、轨迹变成翻袋，用户输入杆法被替换 | VM约1232—1294行；`DirectPotBankFallback.swift` |
| 非Daily的几何可行性调用`effectivePocketAimPoint`，其中包含袋嘴扫描及螺旋搜索 | 即便删除翻袋求解，入口仍可能做额外几何搜索 | VM约1020行；`AngleSceneCalculator.swift:193`附近 |
| Daily轻量候选将库边接触留给预测器判断 | 初选路线和后续完整求解的直进定义可能不一致 | `AngleSceneCalculator.dailyPocketCandidate` |
| aimMode的didSet立即重算；一次选择随后还会写袋口并再次recompute | 模式、球、袋可能以中间状态触发请求；缺少一次完整选择事务 | VM约122、732、982行 |
| 皮革节点切入target立即开始0.6秒；同style不重复反馈 | 反馈可能被手遮住；重复点击同一袋没有事件确认；重绘与用户点击没有独立语义 | `PocketLeatherMarker.show` |
| 点击命中先扩大球热区，再检查皮革 | 球接近袋口时，点击可见袋沿也可能先被球热区截走 | `AngleSceneView.handleTap(at:)` |

以上证明存在重计算入口与状态冲突；本轮没有测量真机耗时，不给出性能改善百分比。

规格还有漂移：docs/04及09-28报告写60°/最小切角，当前源码为75°并按切角、母球距离、袋口距离的联合分数排序。实施前须核对变更来源、统一真源；不能拿旧测试报告当作当前排序证据。本方案不擅自把现行数值改回60°。

## 3. 用户可见行为

### 自动进袋的职责

自动进袋提供直接瞄准辅助：保持用户指定的球、袋、力度和打点，帮助确定直接击球方向。任意力度或杆法不保证进袋；这一杆没有进、母球可能落袋或预测没完成，都不构成换球、换袋或改模式的授权。

这里限制选袋、推荐与预测自主改参。已有球杆可达性纠偏仍遵循其独立契约并明确反馈，不借本轮改动取消用户已认可的可达性处理。

特殊路线仅在用户明确进入对应工具或主动请求搜索时运行。正常自动进袋调用链不得触达翻袋、多库、解球、传球枚举。自由模式的真实向前模拟允许自然产生碰库或多球碰撞；这与为了推荐反向搜索特殊解不同。

### 事件与状态转移

| 事件 | 处理 | 最终状态与反馈 |
|---|---|---|
| 新杆停稳，用户偏好自动进袋，尚无手动选择 | 对合法球做轻量直进推荐；选定后锁定本杆默认组合 | 有线路→进袋；无线路→临时自由，不随意指定一个袋 |
| 缺母球/没有合法目标，或处于播放、开球、固定题等无换袋权限状态 | 不接收普通进袋选袋，不启动推荐；缺目标时在现有状态区说明先选目标球 | 不产生虚假的黄色成功确认；保留对应宿主权限 |
| 手动选球 | 锁住这颗球，只检查其六袋；不因它偏难而换球 | 有直进袋→推荐一个；无直进袋→临时自由，仍保留该球 |
| 自动进袋中点一个可直进袋 | 一次提交球、袋、模式和来源；取消旧求解 | 保持进袋，延后显示黄色确认 |
| 自动进袋中点一个确定不能直进的袋 | 接受点击意图，取消旧求解，切临时自由；保留当前可见瞄准方向，无方向才朝当前目标球初始化 | 就地提示“该袋口无法直进，已切到自由模式”；不进入翻袋搜索，不把母球突然改为直冲袋口 |
| 临时自由中主动点一个可直进袋 | 这次新点击是恢复辅助的明确意图 | 回进袋；保留用户选袋，不从后台自行回切 |
| 用户主动选择自由模式 | 本杆后续推荐不得接管自由方向 | 手动自由；下一杆继续尊重自由偏好 |
| 手动自由中点袋口 | 沿用自由点选语义，作为母球瞄准方向参考；不启动进袋反解 | 保持自由；不能把同一个“失败选袋”事件再执行一遍此逻辑 |
| 调力度、打点或预测返回 | 更新当前杆预览/风险；不重选球、袋 | 模式与用户选择保持 |
| 拖球结束或规则使目标失效 | 用户移球后只复核锁定组合；规则失效时才解除无效目标；明确显示必要的模式变化 | 不在拖动每帧反复推荐或来回切模式 |
| 2D/3D切换、主题切换、普通重绘 | 重投影同一选择和预览；不产生选袋事件 | 不重新推荐、求解或重播黄色 |
| 撤销/重打 | 恢复该杆的选择来源、辅助偏好、实际模式、方向及球袋 | 不先恢复球位再自动推荐覆盖存档 |

“临时自由”是辅助偏好仍为进袋、当前线路不支持的运行状态；“手动自由”是用户主动选择。界面继续只显示进袋/自由，内部保存来源以避免自动行为抢回控制。临时自由可以在新杆重新推荐；当前杆仅由新的明确操作恢复辅助，异步结果不回切。

轻量几何无法确认的临界情形须标记为估计/不确定，不把“有限采样没有找到”直接宣称为物理不可能；保留用户选择，不升级全量搜索。明确几何不可行才执行自动切自由。贴库相切、难度偏高和力度不足不能混作硬否定。

## 4. 推荐与计算边界

推荐读取稳定球位、合法目标和六袋几何，输出默认球袋与直接瞄准点，不能读取或回写某次模拟的进球结果。

检查范围只有：母球到接触位置、目标球到袋口的两段直接线路；其他球、有限主库段、袋口有效开口与假想球位置。使用同源球半径与几何，保留沿库相切。袋口开口使用固定的小规模候选/解析判断，不能退回袋角反弹、螺旋搜索或真实模拟来补一个推荐。边界估计保持诚实，不以推荐偏好作为手动禁用门槛。

自动选球继续近球优先，检查到满足已确定舒适档的合法直进方案就停止；未找到舒适球才在已检查的直接候选中取默认方案。手动选球只推荐本球六袋，手动选袋只判断该球该袋。距离/切角排序只在已经确认支持直进的候选里生效，排序公式和阈值单独统一，不借这次状态重构偷改既有用户选择。

推荐只在新杆、明确换目标、摆球提交或规则改变时产生。力度、打点、相机、主题、预测返回均不是重新推荐的事件。固定盘面缓存推荐；任一相关球位、规则版本或目标变化必须使缓存失效。

选择提交后立即提供便宜的几何瞄准预览，再异步预测这一杆的真实结果。旧轨迹在新意图提交时失效；预览应与完整击球指向同源，避免结果回来时瞄准线明显跳位。无法建立可信几何预览时只显示已接受的模式/选择，不能把旧杆轨迹当新杆结果。

一次离散操作至多提交一次当前杆求解请求；拖动期间只更新预览，结束后合并最终请求。后台单次当前杆预测可使用已有正常瞄准补偿，但不能遍历其他球袋或升级到特殊路线搜索。某次模拟未完成时保留选择并提示预测状态，不把它当“不能直进”切自由。取消、代次检查和迟到结果隔离继续保留。

## 5. 看得见的反馈

反馈拆成三个部分：

- 操作完成：触摸结束后迅速提交选择，遵循用户触感设置给予轻触感；模式、球袋文字立即更新。
- 位置确认：用户点击被接收后，固定等待1秒，再完整显示既有黄色皮革0.6秒，恢复原色。新触摸立即取消旧反馈；黄色0.6秒从实际开始显示计时，不能包含前置1秒。
- 当前状态：现有模式/状态区持续显示紧凑的“进袋 · 1号球 → 5号中袋”，自由模式显示自由；进袋线路始终指向该袋。复用原布局，不为了提示另加一排挤小球桌。

系统知道触摸何时结束，不能知道手是否完全离开屏幕。短等待改善被手遮住的概率；持续状态信息补足局部黄色看不见的情况。选择和模式立即提交；1秒延迟仅用于局部黄色确认反馈。

黄色表示这次袋口意图已被接收，不表示一定能进。不可直进的点击也可作一次位置确认，但必须同时明确自由状态，不显示“自动进该袋”的轨迹或持续承诺。临时自由仍以当前自由方向为准。

反馈按事件ID调度：

- 连续点A/B/C，只确认最终C，A/B待显示反馈取消；新手势取消尚未播放的反馈。
- 同一袋再点一次，明确确认这次操作；不重复求解相同输入。
- 普通重绘、异步回填、模式恢复不产生点击反馈；新杆自动推荐仅在球停稳、页面可见后提示一次，无触感。
- 清台、退页、击球、换模式及切视图撤销旧反馈；视图切换保留选择但不补播过期闪烁。
- 2D/3D共用原皮革材质与网格，保持自然透视；不改命中几何，不用旗帜、淡纹或常驻描边。
- VoiceOver直接提供选择与模式说明，不依赖颜色或等待抬手；关闭触感仍有可见状态。

手势仲裁以可见对象命中为优先，扩大热区只作容错：点击可见袋沿应能选袋；球真实盖住袋时按可见球处理；3D不穿过遮挡物选袋。球/袋区域点击用于选择，空白台面双击用于复位，拖动与双指操作不兼触发选袋。该命中约定需要真实触控回归，不能只以投影点测试代替。

选袋反馈不引发额外相机切换。相机仅消费最新提交上下文，观察操作不改变球袋；既有自动瞄准跟随行为须独立验证，不能由迟到预测重新接管手动视角。

## 6. 实施落点与顺序

第一批：统一直接路线评估与手动不可直进→自由行为；关闭正常自动进袋中的Bank fallback、逐球物理重推荐与非Daily重几何选点。保留显式翻袋/解球/复杂走位工具和自由模拟的自然碰库。

直接可行、偏好排序与预测结果分别传递。拟将球袋组合与来源、辅助偏好、实际模式、当前方向放在一个运行时选择快照中，推导显示状态；请求携带球位/规则版本和选择代次。不把这次改动扩展为物理引擎、袋口资产或数据库的重构。

第二批：把mode/target/pocket/source/direction合成一次完整选择提交。`aimMode.didSet`不再独立触发中间态求解，预测回调只交付结果；来源与偏好纳入撤销/存档。宿主的合法球规则仍由原规则层提供，禁止“统一”成绕过九球/中八权限。

第三批：把`PocketLeatherMarker`的状态应用与一次黄色反馈拆开；在共享手势/宿主层调度延后反馈，复用现有状态区说明。再接2D/3D页面并验证相机上下文、反馈取消和多次点选。

第四批：以模拟器原生点击验证状态链与2D/3D，以SCNRenderer实际像素验证1秒等待和0.6秒显示。真机触感/手遮挡效果单列待体验，不改用户指定的1秒。

范围：Daily、普通自由击球及共享PositionPlay进袋辅助路径；试打等消费者按宿主模式能力接入。固定题、只读序列、视频导出不开放额外选袋；打三①/②颜色与角色语义保留。显式复杂求解工具单列，不因删除普通模式的隐式fallback而删除其能力。

## 7. 验收条件

1. 正常自动推荐的物理模拟次数为0；手动不可直进选袋不调用Bank、多库或逐球求解；用调用计数/性能迹线证明。
2. 同一操作同时更新模式与球袋；迟到预测不得换球袋、改杆法或闪回进袋。快速连点、连续调力度、取消和撤销覆盖操作组合。
3. 全堵、薄球、贴库相切、近袋口、规则禁球、未选目标都给出明确一致的能力；几何不确定不能当作不可进事实。
4. 点不能直进袋立即获得自由方向与可操作能力，不隐藏杆后只让用户换袋；有方向时与切换前连续。
5. 黄色完整可见0.6秒，等待部分独立；重复点同袋有确认但不重复求解；重绘与相机切换不闪烁。
6. 真机分别检查手未移开、慢移手、连续选袋、单手操作、触感关闭；状态信息不挤桌面。小屏/普通手机/iPad与2D/3D分列。
7. 新杆重新推荐、用户主动自由偏好、手动锁定、回退恢复与规则失效分别测试；每种来源均与状态文字和袋口一致。

上一轮19项仅证明当时即时0.6秒皮革反馈实现；本轮以新增状态/工作计数断言、贴库回归、真实SceneKit像素及原生点击重新验收，详见本文件后续实施记录。

参考：[Apple反馈指导](https://developer.apple.com/design/human-interface-guidelines/feedback)与[手势指导](https://developer.apple.com/design/human-interface-guidelines/gestures/)支持清楚、符合操作情境的反馈；点击后等待1秒与上述业务状态是用户确认的本项目设计，不是Apple规定。


## 8. r2 实施记录

- 第一批：统一有界直接候选（最多8个开口/相切点），检查两段线路、障碍球、有限主库、假想球边界；明确不可直进才切自由，有限采样不确定保留手动球袋。现行75°舒适档与联合分数保留，docs/04同步现行源码；普通模式仍按可行候选的袋口距离排序。
- 第二批：选择事务抑制中间态重算；正常后台只预测提交杆，删除隐式Bank及物理换球/换袋/杆法回写。同袋重复点击只重启确认；整盘球位缓存六袋候选，调参不重新推荐。实际计算入口使用PredictionCancellation内线程安全DEBUG计数，可证明每次当前杆预测1次、物理重推荐0、Bank搜索0。
- 第三批：语义样式与confirmSelection分离，固定等待1秒再显示旧黄色0.6秒；新触摸、拖动、击球、清空、模式/视图切换、退页取消。黄色节点从target子节点移至marker独立子节点，因此自由 fallback也能确认点选。持续状态复用普通/试打副标题、Daily既有44pt标题区域，不另加布局行。
- 手势：真实可见球/皮革优先于扩大球热区；空白双击才复位。点击不额外启动相机切换，原有手动换目标相机约定保留。
