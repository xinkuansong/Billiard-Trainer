# 通用设置覆盖与页面记忆 · 实施记录

日期：2026-10-17。用户已批准 App 实施；依据 [r5 方案](PROFILE-SETTINGS-IMPLEMENTATION-PLAN-20261017.md)。本轮优先完成偏好与消费链路，不重做「我的」其余信息架构。**P1–P4 已实现，定向模拟器验证通过；用户体验复阅待收。**

## 已实现

- 新增 `TablePreferencesStore`：16 个双视图功能作用域、4 个固定题型作用域、逐项能力清单。页面内写自己的值；通用操作更新该项基准并移除所有适用页面的该项值。同值也发布操作，不依赖时间戳、不增加永久豁免。
- 一次性迁移旧网格、特写、轨迹、分离角、运杆，以及各页透明度、3D 隐藏和蛇彩视图。翻袋/颗星、编排/试打原共享值分别复制，之后独立。旧键保留，迁移完成后重启不再灌回；已有默认玩法和个人资料推断逻辑保留。
- 接入 FreePlay 六入口、共用教学/求解球桌、详情/训练记录预览，以及四种固定题型。只保存用户的 2D/3D 选择，不保存横竖屏、临时俯视或自动相机姿态；固定题型不受默认视图覆盖。
- 网格、特写、轨迹和运杆实际渲染读取页面快照。教学图谱专用内容、静态图和导出使用原显式配置/工具来源，未自动纳入普通练习偏好。
- 通用设置直接展开显示/辅助项；支持再次点当前视图/轨迹，以及“再次应用某项…”。打开/取消列表不写入；透明度统一操作在拖动结束时提交。通用页显示最近一次统一值，页面操作不反向修改它。
- 轨迹档位选择（含同值）同步打开适用页面的 3D 轨迹；单独关/开 3D 轨迹保留各页档位，2D 继续显示。思路训练两项独有选项单独保存。
- 默认玩法仍在通用设置，仅影响下一新局；临时换玩法保留原对局入口/确认。

## 当前球局保护

页面将偏好保存与画面消费分开。运动、求解、开球或连续演示忙碌时暂缓应用，回到安全状态再使用最新快照；不调用建局、重摆、重算业务状态或保存训练记录。轨迹刷新只重画已有结果。运杆在每杆开始读取一次有效值，导出显式参数仍优先。

测试使用真实 `PositionPlayViewModel`、`DailyClearanceController` 和球桌场景，断言统一修改八项后球节点身份、盘面坐标、runner、玩法、阶段、击球/犯规数、力度与打点不变；更改默认玩法不替换当前局。
