每行是一个页面或入口。做完「通用动作」和该行的专项动作再勾选。遇到问题，在编号后记「异常」和最后两三步；还没进入对应状态就记「未测」。所有框均留给这次真机体验。

## 通用动作

在手机横屏进入 3D。先在「分离角与走位」做一次，记住舒服的速度和距离，再用同一只手在其他页对照。

|动作|用眼睛判断|
|---|---|
|入页、慢滑、反向|静置后在空白台布上慢滑一点、停住、反向一点、松手。画面能响应第一下，小幅移动连续，手指停住后画面稳定。注意辅助线有无残影，地面与库边有无突然升降。|
|第三人称缩放与复位|双指拉近，再单指上下滑抬高，反复两轮。只捏合时仰角应稳定。侧看后点已亮的第三人称键，再切第一人称、切回第三人称，都应回到本杆默认构图。第一人称距离看母球到可见杆尾一段的纵深。|
|小眼睛往返|从一个容易辨认的侧看位置点小眼睛，俯视后直接返回。镜头应回到刚才的位置。允许编辑的页面再试一次，在俯视里实际换袋或移球，返回时应与新盘面对应。|
|横滑的含义|可自由瞄准时横滑，球杆改向且镜头跟杆。允许进袋瞄准的页面，第三人称横滑只侧看，第一人称横滑或滚动方向尺才手动改向。固定杆向题用第三人称侧看，题目杆向保持。|

跨页复验普通杆时，第三人称在球滚动中从台布横滑，核对台边随手指转动、球路照常继续。按住直到停稳再松手。有自动推荐下一球的页面，击球前先拉近、抬高并侧看，换球到位后再点已亮的第三人称按钮，画面应保持原位。

先看控件是否适合当前任务。无母球的容错角查「小眼睛临时 2D／第三人称回目标／第一人称禁用」，角度练习未作答时查第一人称禁用。测量、规划、示范期间，优先核对切镜是否误改输入或推进步骤。

## 第一站 · 参考页和首批共用页面

- [ ] **A01 分离角与走位**（练习 → 走位）。第三人称先侧看，再重选同一球；镜头应转回，球的选中放大不带镜头抖动。关闭自动推荐并选进袋模式，点一颗合法目标球，应立即看到球杆和从母球到目标球的白线，改选另一球时白线跟着换目标；袋口仍待手选，击球尚未开放。再点袋口核对杆向。自由模式点另一球再点袋，应先对准两球连线，再对准实际进袋方向。拖母球时看场景保持，松手才跟到合法落点；把母球换到长库、短库和角袋旁各试一次。
- [ ] **A02 每日清台**。用普通可击球盘和一个贴库盘分别切人称。开启推荐，先拉近、抬高并侧看，再击入当前球；自动转向下一球后，再点已亮的第三人称键，画面应保持原位。普通杆触球后，在球滚动中切镜并按住侧看跨过停稳；松手后按推荐设置接下一杆，计杆与结算各一次。已有草稿可退出再进核对。
- [ ] **A03 自定义球形 → 练习**（练习 → 走位）。选一个熟悉的模板，如 4443。移母球、选目标、击球、重打，再回模板。查拖球时画面稳定、重打恢复原杆、练习操作没有改写原模板。
- [ ] **A04 多球走位**（练习 → 走位）。从卡片进入并打开 3D；再从正式 2D 切进 3D。自主阶段横滑改杆；规划或按顺序追分时侧看、切镜，原来的球序、本杆角色和分数保持。
- [ ] **A05 蛇彩练习**（练习 → 走位）。从无遮挡台布起手横滑，再切人称和俯视。按指定顺序打一球并重试；切镜前后必须是同一颗合法目标。
- [ ] **A06 走位求解**（练习 → 走位）。先设约束，再求解、换解、试打和回放。已有解时核对第一人称沿该解出杆；切镜保留候选解、约束和落位要求。
- [ ] **A07 扎杆与跳球**（练习 → 进阶）。同盘先低杆位观察，再明显抬杆，切第一人称看实际杆轴。试打后回放，观察打点、抬杆角和原杆的恢复；遇飞台局面时另记恢复效果。

**有标准开球的页面**另测两次。一次开启自动选球和袋口，一次关闭。开球后先看跟杆，等球杆消失才开始约 1.5 秒的后退。停稳后，开启时接合法下一球，关闭时停在开球侧观察位。另在普通杆回放途中返回，重进后核对盘面。

## 第二站 · 截图中的 17 页

**先测 B01–B08。** 这八页已有逻辑测试，最缺最终版从正式界面操作的记录。后九页也保留空框，供同一台手机逐页对照。

- [ ] **B01 准度练习**（准度）。在第一、第三人称各慢调一次，再用方向尺反向微调。杆向和镜头应同步，指定目标与打点要求保持。
- [ ] **B02 解球练习**（进阶）。先在瞄准态横滑，再进入测量点库边。前者改本杆，后者设置测量点；回瞄准后按题目指定库序出杆。
- [ ] **B03 防守练习**（进阶）。自定杆向打一杆，在球滚动中侧看，再看结果或示范。防守评价应取实际停球局面，切镜不改草稿、不重复计分。
- [ ] **B04 颗星解球**（进阶）。自由试打横滑改首段方向；求解后切换候选，再沿杆观察。核对库序和目标球保持。自由回放中等球明显移动再退页，重进后应是回放前盘面。
- [ ] **B05 打一走二想三**（走位）。选球、袋和落位区域时切镜，角色和步骤保持。未解出可摆杆方案时第一人称应不可用；有解后沿该杆看。另在准备开球时横滑，应能改开球方向。
- [ ] **B06 分离角练习**（走位）。记住给定杆向，第三人称侧看后切第一人称；仍应沿题目杆向。调打点、杆速后击球，检查重试仍是同一道题。
- [ ] **B07 三球走位**（走位）。先预选下一袋，切人称并回俯视，再完成第一杆、进入第二杆。预选袋、球的角色和两杆衔接应保持。
- [ ] **B08 K球练习**（进阶）。沿给定进球方向看，再侧看要碰的第二颗球。镜头可以换，指定杆向、第二球和本题杆法保持。
- [ ] **B09 翻袋练习**（进阶）。按题面指定库序，分别用台面横滑和方向尺改杆；再测量、看示范。只有瞄准阶段写入自己的杆向。
- [ ] **B10 两球走位**（走位）。侧看两球关系，再切第一人称。镜头位置变化，给定进攻方向保持；自己的杆速、打点和落位结果仍保留。
- [ ] **B11 瞄准点练习**（准度）。横滑改变自己的答案草稿，开关俯视，最后点提交。切镜不揭示答案，提交只记一次，结果页侧看保持首答。
- [ ] **B12 翻袋**（进阶，卡片名为「翻袋」）。求解后换候选、切人称，看杆轴随当前解更新；切自由后换目标再横滑试打。回放中等球移动后停止或退页，应恢复回放前的球位和朝向。
- [ ] **B13 角度练习**（准度）。未答题时点第三人称、俯视再返回。第一人称应禁用，题号、输入和答题数保持，切镜不能提前给出答案。
- [ ] **B14 角度与瞄准**（准度）。拖母球时盯住库边，松手后再看新杆向。俯视内先重选同一袋，再另试换袋；前者回原观察位，后者对准新的教学方向。核对角度读数。
- [ ] **B15 进球容错角**（基础）。选目标球与袋口，点第三人称回到目标，再点小眼睛进入临时 2D，再点一次返回。应围绕真实目标看，袋口及两条边界保持，底部第一人称禁用。
- [ ] **B16 分离角图谱**（控球）。只留一条轨迹，从 3D 进临时俯视再回。原轨迹、杆速与观察位置应保留。另实际移除最后一颗目标球，单独记缺球提示是否出现。
- [ ] **B17 加塞吃库图谱**（控球）。第三人称只改杆高，画面应稳；随后切第一人称，应沿更新后的实体杆。临时俯视中摆一颗球再返回，核对落点及已选轨迹。

## 第三站 · 从不同入口到同一张桌

这些入口要从各自的上游进入。直接从练习卡片进桌，不能验证照片球形、模板或动作库序列有没有交接正确。

- [ ] **C01 动作库 → 动作详情 → 试打**。选带多杆序列的动作，如初级蛇彩。播放第一杆、暂停、重摆，切自由试打改向，再切回序列。原球形、第 1 杆和演示机位应恢复。
- [ ] **C02 拍照建球形 → 校准／确认**（练习 → 走位）。用真机拍一张能认清母球和球号的照片，校准并修正一个球位。先记下母球、目标球和它们相对库边的位置。
- [ ] **C03 照片确认 → 编排**。用同一布局进入，核对球号、位置后切第一、第三人称；进桌应看到刚确认的盘。
- [ ] **C04 照片确认 → 走位求解**。核对导入球位，设约束、求解、切镜；解与约束对应这张照片。
- [ ] **C05 照片确认 → 打一走二想三**。核对导入球位，选本杆和后续球再侧看；角色和规划阶段保持。
- [ ] **C06 自定义球形 → 模板编辑 → 开始练习**。在测试模板里摆球、保存、进入练习。编辑时能看清放置点，进入练习才按该盘杆向构图，返回编辑仍是保存的模板。
- [ ] **C07 理论页 → 分离角与走位**。例如从 30° 法则页尾「看分离角怎么随杆法变」进入。核对进入与 A01 同一套切镜、横滑和复位。
- [ ] **C08 动作详情内嵌 3D 演示**。在详情内播放、暂停，随序列查看下一杆；进入试打再返回，详情仍能按序列演示。
- [ ] **C09 训练记录内嵌 3D 演示**。打开一份带演示的旧记录，观看并退出；核对原记录的球序、结果与回看机位。

## 报问题

直接报「编号＋最后几步＋看到的现象」即可。例如：「B12，自由模式回放，母球刚动就返回；再进来母球停在回放中途。」手感问题可补「起手／按住微调／松手／停稳后」哪个时刻最明显。同盘同操作如果有时正常，记下大约几次出现一次。
