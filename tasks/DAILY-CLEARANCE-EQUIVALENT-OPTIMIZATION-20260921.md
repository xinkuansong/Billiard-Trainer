# 每日清台等画质性能优化

2026-09-21。用户明确：保持画质与流畅度，降低 CPU/GPU 实际开销；不以自动降帧、减少阴影采样或分辨率换性能。用户准备休息后，仅继续模拟器工作，不再操作手机。

## 最终实现范围

- GPU：`MobileReferenceLighting.directShadowShader` 在每个接收像素上生成保守球候选位掩码，光源每个采样只遍历可能影响它的球。最低有效位优先，保留原逐球相乘顺序；原有全局 `shadowPossible` 和两光源各 8×4/远处2×2采样判定不变。32球以内使用位掩码，超出容量走原算法。接收面低于原0.8m床面时保留完整可见球检查，避免误用床面投影界。
- CPU：普通进袋/自由击球预测接入已有每任务取消令牌，模拟事件/混合步之间检查取消。显式 `.cancelled` 终止不算完整桌面，取消预测不带完整轨迹、不得发布。有效任务保留原物理参数、模拟步、搜索精度和展示轨迹；不延长交互去抖。
- 已撤回前轮新增 Serious 30 FPS 及恢复期30 FPS限制、交互2D降采样。`AngleSceneView` 帧率策略恢复仓库原值；原有 Critical 紧急保护不属于此次优化。没有改设置里的用户帧率。
- 改动位于共享场景/预测入口，收益范围不只每日清台。后续收尾已检查预览节点、刷新依赖、原生PBR，见下方审计表。

## 方案否决与测试修正

- 原紧凑全球循环：2D候选49.86ms vs 原46.05ms，3D40.15ms vs 39.67ms，没有收益，否决。证据 `device-loop/` 与 `device-loop-full.log`。不得把“代码少”当作更省GPU。
- 前轮逐球布尔候选虽图像一致但更慢；8×2减少采样方案虽更快，却不符合当前等画质约束，已撤回。
- 保守投影界复用原边界并补低床面回退，标量20万随机样本、1292个可能遮挡、0漏筛。不是所有浮点几何的形式证明。脚本及结果在 `build/daily-render-ablation-20260921/check-shadow-bound-heights-fallback.*`。
- 六姿态图像首轮发现2D原算法自身前后不一致（1400像素，差异在桌边），其余五姿态一致，失败日志/原图保留 `mask-equivalence-attempt1-full.log`、`mask-attempt1/`。静态对照增加有界准备：原算法须先连续两张相同，然后原→候选→原，三者仍要求完全一致；没有放宽阈值。运动阴影仍用真实SCNAction逐帧验证，不能用静态预热代替。
- CPU接线首次编译时取消检查误放进返回Void的旧局部循环，编译拒绝；已移入返回Termination的混合预测循环。日志 `production-compile-attempt1.log`。

## 一次性收尾：剩余 CPU/GPU 路径审计

用户授权“全部做完一次”，范围为前述每日清台2D/3D的剩余优化方向，保持画质、采样、帧率、物理精度与交互去抖。仅模拟器，不安装/操作手机。当前角色 Orchestrator → SwiftUI/SceneKit → Test Engineer/UI Reviewer。

| 检查点 | 实施/结论 | 证据与边界 |
|---|---|---|
| 普通/自由预测与翻袋过期任务 | 保留前轮取消令牌与事件间检查 | 完整有效轨迹对照；不是降低求解精度 |
| 直接球影 | 保留前轮保守位掩码筛选 | 原采样、顺序和同帧球位；GPU手机短时依据见上 |
| 拖动预览节点重建 | 实线节点、虚线父/子节点及材质复用；相同输入直接复用几何 | 变化时仍执行原台呢裁剪与几何生成，不做近似阈值/降采样 |
| 理想方向先清再建 | 移除每次refresh开头的无条件清理，仅无目标/不显示时移除 | nil/极简/播放/清空仍按原生命周期隐藏；恢复时复用 |
| 重复预览几何与发布 | 用母球、方向、可见球键/位置、半径、桌尺寸、near滞回作为完整输入 | 力度/打点变化仍求物理预测，但不重复首碰与特写几何；参数同值不启动重算 |
| 无效SwiftUI刷新唤醒渲染 | 仅content活动状态/相机模式/取景策略/viewport尺寸改变时续交互窗口；实际手势唤醒保留 | SceneKit节点修改仍触发重绘，动作/物理/相机过渡仍由既有渲染循环识别；未改FPS策略 |
| 台呢原生PBR | 六场景关闭对照全部改变图像，拒绝作为无损优化 | `first-images/pbr-*`、`pbr-contribution.json`；max通道差149–229/255，不能简单删去 |

| 静态房间/桌面与标签 | 房间风格相同时不重建，2D隐藏房间；标签已有几何key；台面虚线已合并mesh | 已有机制不重复加第二套缓存；未更改模型细节、纹理、光照或MSAA |
