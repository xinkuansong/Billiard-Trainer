# Mac mini 多智能体快照与排队测试

用户授权：实现任务快照隔离和串行测试队列，验证通过后写入 mac-mini 技能。

## 设计与范围

当前角色：DevOps/Release + Test Engineer。只改工具、测试和操作文档，不改球迹产品源码。

采用 Git commit 固定快照为默认；未提交改动需调用方确认工作区暂停写入，工具双重校验漂移。执行器以哈希固定，上传校验后原子入队。远端统一文件锁串行执行 FIFO，各任务独立源码、DerivedData、证据与全新受管临时模拟器；结果绑定 job/snapshot/test selectors。中断不自动重试，未知执行状态阻止继续消费。

不安装常驻服务，不修改网络或发布设置。首版不做跨任务编译缓存/差量上传；同用户的任意写入和绕过入口的构建不受文件锁强制约束。使用契约见 `scripts/mac-mini-queue/README.md`。

- macOS 普通用户不能重命名已封成只读的目录；已改为原子发布时仅临时开放顶层目录写权限、发布后立即封存。首次上传后发布失败，两个任务均未入队；保留原失败日志，复用已上传且重新校验的归档成功入队。
