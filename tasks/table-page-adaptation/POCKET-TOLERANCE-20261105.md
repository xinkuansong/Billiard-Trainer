# 进球容错角交互页 · 2026-11-05

状态：实施与定向验证完成。用户批准本会话分析并要求开始；多球只展示选中球。

## 页面合同

学→进球容错角，紧邻角度与瞄准。顶部15球球库；无母球。点台面/球库选球，点袋选择，各球保留自己的袋；加球默认选中新球等待选袋，拖球保持袋。其他球只供比较，不作障碍。左侧仅球号、目标袋、容错全角；只绘选中球左极限管道左外缘及右极限管道右外缘，真实半径相切。

菜单只有视图与台面网格，手机横屏、iPad横竖。3D全局/目标观察，手势复用；切视图/方向保留全部球和选择。退出后重进初始化单3号球未选袋；本次导航内与后台恢复保留现场，不新增持久球形保存。

## 几何与依赖

XZ米制，Y朝上，台面2.54×1.27m，半径以AngleSceneCalculator为准（0.028575m）。查询目标位置×袋，不输入母球/障碍/杆速。DefensePipeTable仅从评分文件搬到Core/Scene，类名/查表/评分调用不变；新typed查询使用同源defenseCleanWindow回退。相切起点=目标球心±R·方向法线，延伸至当前袋真实capture入口。单连通窗口才画两条线，多区间/未闭合/无效位置明确无法评估。

当前不碰库/袋角直线模型仍有原C覆盖缺口；零窗显示“暂无直线管道；袋角附近暂无法评估”，读数—，不下进不了的结论。该缺口另行研究，本页不扩展物理模型或修改评分。

共享壳新增默认关闭的objectObservationOnly、allows3DPaletteEditing以及可选onPaletteTap；相机组件新增默认false的observationOnly与默认true的observationTargetAvailable。旧页默认行为保持。新页不启用操作布局（用户明确菜单范围）。
