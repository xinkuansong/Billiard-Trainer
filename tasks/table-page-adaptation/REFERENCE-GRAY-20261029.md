## 反馈与范围

用户认为中杆中力参考接近白色，希望采用所附特写参考圆的灰色观感。第二张整桌图左栏为“目标／参考”，确认问题是击球前中杆参考；第一张“目标／实际”的白线仍按实际轨迹保留。

根因：DR-447 r2同时提高共享 `centerReference` 的灰度与alpha（0.75/0.65→0.86/0.85），主桌较粗长虚线与特写1pt细线同色却呈现不同视觉强度。不能为降低长线亮度而继续联动用户已认可的特写。

- 中杆参考及同色图例：分离角、两球、K球，2D／3D共用 `SeparationRouteStyle.reference`。
- 三球保留的参考样式别名同步；当前不显示中杆参考的页面合同保持，不重新启用。
- 测量参考线及可拖假想球：分离角、两球、三球、多球，2D／3D共用 `GeometricReferenceTool`。
- 特写2R圆、球心连线、固定垂直虚线，以及准度台面球心细线：保留 `centerReference` 原值。
- 白色瞄准／实际、橙色目标、球色进球线、接触点、球与袋角色色不变；不改物理、评分、虚线节奏或线宽。
