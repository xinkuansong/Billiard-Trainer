# P01 每日清台能力对照与设置契约

2026-10-06，r02。用户已明确：球库放顶部，与每日清台一致；进袋等选项收入设置；每日适用项一并纳入。本文是实施目标，不是当前 App 行为。r01 底部球库 A／B 方案已被替代，不再要求用户选择。

## 源码核对范围

直接读取 `FreePlayView.dailySettings / moreMenu / dailyLandscapeBody`、`BTSolverMoreMenu` 的完整菜单组合、`ShotSimulationView` 全页、`UserPreferences` 对应字段、`PositionPlayViewModel.refreshShotAssistVisibility` 及打点组件入口。核对快照指纹见 r02 评审包；每日仍在独立调整，实施前再次检查共享接口。

每日实际菜单包含打点盘透明度、击球设置内的瞄准模式与轨迹显示、临时换玩法，以及最后的显示组（网格、特写）。没有菜单“重新开球”；开球属于每日页面操作。普通自由击球分支的结束对局／清空桌面也不能当作每日菜单项照搬。

## 顶部与页面结构

- 顶部依次为返回／标题、单排球库、2D／3D、三点设置，延续每日清台的视觉分区与对齐关系；不固定抄其屏幕坐标。顶部容量预算先扣导航、模式和设置，剩余宽度供球库局部横滑，不挤小触点。
- 2D／3D 顶部球库位置一致。2D 保留点击摆球、拖入和拖回移除；3D 首版显示球在桌／未在桌状态，摆球通过 2D 完成，不暗中新增未经验证的 3D 球库拖放。3D 既有桌上拖球能力保留；球库提供可访问说明“切到2D摆球”，不伪装为可拖入。
- 撤掉底部球库、常驻相机帮助栏、进袋／自由切换按钮和轨迹档位 chip。3D 观察／第一人称／回到瞄准保留在右侧相机操作组；不搬进设置藏起来。
- 进袋／自由和轨迹是设置选项，角度／厚薄是即时教学读数。后者保留为紧凑非交互浮层，无固定状态带挤小球桌；当前模式通过设置选中值及无障碍状态可知，切换时短提示。
- 左侧常驻方向尺、重打、回放；右侧打点、杆速、击球。2D 保持完整比例球桌，3D 场景铺底。本页无开球和对局计分。

| 瞄准特写 | 纳入，显示组 | 沿用现有全局 `showAimCloseup`；有有效 snapshot 且辅助显示允许时呈现，不强制所有模式都有特写 | 自由瞄准触发、开关、3D关闭轨迹时隐藏、面板遮挡；每日硬避让能力需验证后复用，不能因共用开关而声称已迁移 |

声音、房间风格、分离角辅助线等虽然存在于全局偏好，但不是已核到的每日三点菜单项。本轮不凭名称扩充；后续有明确需求再单列。

## 最终设置菜单顺序

```text
设置（三点入口，沿用每日外观）
  打点盘透明度 · 当前百分比 → 透明度浮层
  击球设置
    瞄准模式 · 当前值 → 进袋 / 自由
    轨迹显示 · 当前值 → [关闭，仅3D] / 瞄准线 / 双线 / 全部
  球形
    恢复默认球形
  显示（最后一组）
    台面网格 4×8
    瞄准特写
```

显示必须是最终组。当前 `BTSolverMoreMenu` 的 `onReset` 会排在显示后：首版应在 `pageExtras` 内放球形重置，传 `onReset: nil` 和 `displaySectionLast: true`；不改变所有消费者默认顺序。菜单可访问名调整为“设置”可用页面显式覆盖，避免全仓改名。

## 状态与实现边界

1. 播放／回放中禁用会改变击球输入、球形或辅助呈现的设置；透明度首版也禁用打开，避免打断播放。关闭菜单不重算球形、不出杆、不改相机。求解中切换模式走 VM 已有取消／新结果机制，旧结果不得重新点亮击球。
2. 轨迹三档、网格、特写已有全局共享语义，保留并记录跨页作用。新增 P01 透明度和 3D 隐藏建议分别用 `shotSimulation.spinDiscTransparency`、`shotSimulation.3DTrajectoryHidden`；默认值对齐每日，不能直接复用 `dailyClearance.*` 写入另一个页面偏好。此为首版工程方案，未声称用户决定了键名。
3. `BTProjectedSpinPadOverlay` 当前没有透明度参数；需要页面采用已支持 `discOpacity` 的打点承载，或给现组件增加有原行为默认值的显式参数并检验调用方。透明度菜单不允许空接、只保存值或把整盘连标记一起隐掉。
4. 左右手势、拖放帧和场景投影用当前窗口实测。顶部移动后重验球库拖回区域和 Ghost 坐标。切模式／旋转／退出期间取消进行中的球库拖放，不能用旧 frame 放球。
5. 沿用每日适用的中性 HUD、浅绿按下反馈、杆速文案与单位、稳定 2D／3D 控件位置；每日特定相机轨道、比赛规则和自动选袋策略不随布局移植。
