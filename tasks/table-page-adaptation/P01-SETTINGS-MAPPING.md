## 源码核对范围

直接读取 `FreePlayView.dailySettings / moreMenu / dailyLandscapeBody`、`BTSolverMoreMenu` 的完整菜单组合、`ShotSimulationView` 全页、`UserPreferences` 对应字段、`PositionPlayViewModel.refreshShotAssistVisibility` 及打点组件入口。核对快照指纹见 r02 评审包；每日仍在独立调整，实施前再次检查共享接口。

每日当前菜单以C51菜单r5及C56为准：显示组先列视图、打点盘透明度、网格和特写，再列击球设置。P01保留恢复默认球形，不加入每日玩法/对局选项。

## 顶部与页面结构

- 顶部依次为返回／标题、单排球库、时间电量FPS、三点设置；2D／3D收入显示组，延续每日清台的视觉分区与对齐关系；不固定抄其屏幕坐标。顶部容量预算先扣导航和状态/设置；常态横屏不双排，球面上限36pt。按2026-10-08用户最新决定，球库只显示1–15号球，与每日共同布局一致；母球不占槽，落袋后一杆停稳时使用既有空位算法自动回台，桌面仍可拖动母球。
- 2D／3D 顶部球库位置一致。2D 保留点击摆球、拖入和拖回移除；3D 首版显示球在桌／未在桌状态，摆球通过 2D 完成，不暗中新增未经验证的 3D 球库拖放。3D 既有桌上拖球能力保留；球库提供可访问说明“切到2D摆球”，不伪装为可拖入。
- 撤掉底部球库、常驻相机帮助栏、进袋／自由切换按钮和轨迹档位 chip。3D 观察／第一人称／回到瞄准保留在右侧相机操作组；不搬进设置藏起来。
- 进袋／自由和轨迹是设置选项，角度／厚薄是即时教学读数。后者保留为紧凑非交互浮层，无固定状态带挤小球桌；当前模式通过设置选中值及无障碍状态可知，切换时短提示。
- 左侧常驻方向尺、重打、回放；右侧打点、杆速、击球。2D 保持完整比例球桌，3D 场景铺底。本页无开球和对局计分。

## 状态与实现边界

1. 播放／回放中禁用会改变击球输入、球形或辅助呈现的设置；透明度首版也禁用打开，避免打断播放。关闭菜单不重算球形、不出杆、不改相机。求解中切换模式走 VM 已有取消／新结果机制，旧结果不得重新点亮击球。
2. 轨迹三档、网格、特写已有全局共享语义，保留并记录跨页作用。新增 P01 透明度和 3D 隐藏实际分别用 `shotSimulation.spinDiscTransparency`、`shotSimulation.3DTrajectoryHidden`；默认值对齐每日，不能直接复用 `dailyClearance.*` 写入另一个页面偏好。此为首版工程方案，未声称用户决定了键名。
3. P01已使用核心模板现有打点承载与`discOpacity`接线，白盘填充随透明度更新，标记和外圈保留；原`BTProjectedSpinPadOverlay`不再是本页宿主。
4. 左右手势、拖放帧和场景投影用当前窗口实测。顶部移动后重验球库拖回区域和 Ghost 坐标。切模式／旋转／退出期间取消进行中的球库拖放，不能用旧 frame 放球。
5. 沿用每日适用的中性 HUD、浅绿按下反馈、杆速文案与单位、稳定 2D／3D 控件位置；P01显式启用C56的四视角和shot-aware相机，比赛规则/每日专用选球排序不随布局移植。
