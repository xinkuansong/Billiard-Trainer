# 自定义球形 · 内置4443与L型

日期：2026-10-28。状态：用户反馈修订已实现并通过定向验证，未发布。

## 范围与行为

用户在图文调研后选定先加入4443与L型。选择页顶部「内置球形」分组提供两项，各15颗1–15号目标球和一颗母球；可直接开始练习。内置模板只读，菜单仅「复制到我的球形」，复制生成独立模板及球实例身份，之后按个人模板编辑／改名／删除／保存／同步。

内置内容不写入用户档案、不同步、无新的权益限制。内置与个人模板共用单选；内置选择存于页面Library实例，reload保留，重新创建页面时恢复原个人选择。个人档读取失败时内置仍可开始，复制遵循原档案保护而禁用。

练习副本、2D/3D、击球、重打、回放、重新开始沿用原能力；练习另存产生新的个人模板，不覆盖内置。未新增按号／袋口／碰余球裁判或成绩。

## 来源、几何与数据

- 来源与适配细节见[调研记录](../../docs/research/20261028-自定义球形内置模板图文调研.md)新增落地段。L型参考Tony Robles图文原图，4443参考已观看的于庭TQ示范开场。
- 4443按四象限4＋4＋4＋3短排；L型两臂各8颗、共用8号。具体间距、4443编号和母球起点为本应用适配，非原图精确复刻或统一比赛规则。
- 台面内长2.54m、宽1.27m，球径57.15mm；归一化x为0–1、y为0–0.5。最小球心距离4443为114.3mm、L型为76.2mm，最近边界球心距离分别152.4mm、101.6mm。数字脚本及单元断言检查唯一球号、数量、边界和全体球对分离。
- 数据位于`BuiltInCustomFormations`，固定模板UUID及确定性实例键；复用`CustomFormationTemplate`、`BoardSnapshot`、现有物理与渲染，不改Archive协议或资产。

## 用户反馈修订：贴库、台心与默认瞄准

用户明确要求L型两侧端球贴库、母球居中，并补充4443同样母球居中，标题上行「4443」下行「球形」，默认瞄准1号球中心。原r1/r2的摆位与标题截图仅保留为技术before，不能作为本次要求通过的证据。

- L型保持8号转角(0.25,0.25)，1号球贴下长库，15号球贴左短库。归一化半径r=ballRadius/innerLength≈0.01125，等距步长s=(0.25−r)/7；1–8为(0.25,0.5−r−i·s)，9–15为(0.25−j·s,0.25)。球心距库R，球面相切；最小间距约86.632mm。原留边及76.2mm间距由此覆盖。
- 4443与L型母球均为归一化(0.5,0.25)，对应世界XZ=(0,0)。4443目标球位不变；既有个人副本不自动改球位。
