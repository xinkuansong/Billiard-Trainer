# 准度落袋高度与当前瞄准特写 · 2026-10-22

用户授权：按分离角与走位修正准度落袋高度，检查2D/3D；添加只放大当前瞄准、不显示正确答案的特写。源码基于8264960b及共享工作区；已有题目提示修改保留。本轮不更换题库、进袋判据、物理参数或首杆成绩规则，不提交发布。

## 根因与实现

准度原simulateFree传surfaceY=0，普通回放补至scene.surfaceY+R，但PocketCollectionTail和袋下副本消费原始世界Y，入袋交接低了0.8m。计算前在主线程冻结实际scene.surfaceY并传入后台模拟，与分离角与走位同源。球底台面Y=0.8，球心Y=0.828575；袋内轨迹不加第二次偏移。

特写使用独立currentAim构造器，只接受当前球位、方向、球径和主画面方向线截断所需的库边终点。没有袋口答案或求解器输入，不构造假想球、接触点、瞄准点、进球线、理想方向、打空提示。主画面与小窗同用AimLineGeometry。保留共享3R/3.5R近区滞回、方向尺持触触发、台呢内框和保护区避让。2D/3D独立偏好，默认值沿用共享关闭。

共享壳通过allowsAssessmentAimCloseup显式开放考核特写，其余答案辅助仍受assessmentMode限制。BTAimCloseupOverlay的includesSceneIdealLine在考核中关闭，避免场景残留理想线注入。后台清特写缓存，返回按当前草稿重建；计算/播放/结果/临时俯视不显示。
