## 1. 已明确的需求

1. 在“打”分区新增“2D分离角”“3D分离角”两个固定维度入口，保留现有“分离角与走位”。
2. 直接复用 2D 准度的球形来源及相关训练设置，不另造一套球形几何。
3. 给出母球碰撞目标球后的完整目标轨迹；用户调整打点和杆速，系统自动补偿瞄准。
4. 调整打点和力度期间不显示“计算中”，不显示当前输入的碰后轨迹。点击击球后，先完整显示实际轨迹 **1.5 秒**，再按照正常出杆流程击球；两条轨迹保留供对照。
5. 出题先以中心打点（无高低杆、无左右塞）寻找该球形的最低可进杆速，再在该下限至 4.5 m/s 内抽样。
6. 默认允许高低杆、左右塞，也允许两者同时存在。联合抽样密度在“中心打点、约 2.5 m/s”附近最高，向外减小。
7. **每个随机打点＋杆速组合，都必须重新补偿瞄准并验证目标球实际进指定袋。中心打点能进，不能证明同杆速低杆也能进。** 不通过的组合不能成为标准答案。
8. 按现行球桌统一规范逐项接入，不能只复刻外观。
9. 3D、Pro 权益与配套能力纳入同一轮完整交付；整体对齐现有 2D／3D 瞄准训练的设置、入口、额度、恢复及结束流程，保留本题型的轨迹相似度评分与自动瞄准差异。

“显示目标轨迹”与“隐藏答案参数”并不冲突：目标线是题面；产生它的标准打点、杆速是内部答案。初版不默认把答案参数展示给用户。

## 2. 页面与训练流程

**2D、3D 同期交付，均为固定正式入口**；不在一道题的菜单里切换正式维度。两入口共用出题器与物理合同，但轮次、草稿、记录、显示偏好和操作布局身份分开。3D 复用正式相机与临时俯视，临时俯视不改变题目/输入，不记作 2D 训练，也不绕过 Pro。

正常入口：练习首页 → 打 → 2D分离角／3D分离角 → 权益检查 → 恢复当前轮次或训练设置 → 练习球桌。新轮次先设置；继续练习恢复准确题目与输入。

|阶段|台面内容|可用操作|禁止或失效处理|
|---|---|---|---|
|设置|复用训练设置表单|选条件、开始、返回；训练中进入可取消|取消不改变当前球形、输入或轮次|
|准备题目|准备状态、可返回|取消准备|不展示未经验证的临时答案；旧代次不能交付|
|作答|原始双球、指定目标袋、完整目标线、当前球杆|打点、杆速、击球、设置|不拖球、不选袋、不手动调方向；不显示当前输入的碰后预测线|
|调参后台准备|与作答完全相同，无“计算中”提示，不暴露实际线|继续调打点/杆速，仍可点击击球|后台未追上不让击球按钮来回变成不可用；只有点击才建立提交意图|
|点击后准备|冻结本次输入，保留目标线；击球键保持原文案并禁重复提交|返回/取消按生命周期撤销本次待出杆意图|若无同输入完整缓存，等待该快照求解；不能先显示旧轨迹，不占用后续1.5秒|
|揭示1.5秒|完整实际线与目标线叠加，球保持原位|查看|禁用输入、重复击球、相机过渡和布局编辑；不能改动已冻结杆|
|正常出杆及播放|1.5秒结束后走标准运杆/出杆/接触/球运动/收尾；两线保持|按共享生命周期允许取消/后台处理|不跳过球杆流程，不重新求解、不重复计题|
|结果|保留完整叠线和真实停点/进袋状态|重打、回放、下一题、设置、结束|显示本杆轨迹相似度分数；不增加通过阈值|
|回放|同一已冻结杆的数据|停止回放|结束恢复点击回放时的球形/姿态；不算新尝试|
|结束|已练题数、首杆均分、重新开始、完成|重新设置或退出|旧记录缺分不进评分分母，新提交未碰球/未进袋按0分计入，显示已评分题数|

揭示后自动出杆由同一次“击球”点击授权，不另加播放确认。**1.5秒从实际轨迹已提交显示的首帧开始计时**，不是从点击、开始计算或求解返回开始；揭示期间不得提前运杆。减少动态效果只调整装饰/相机过渡，不缩短用户明确的1.5秒观察时间。正常流程消费同一份已冻结的杆向、打点、杆速和物理记录，音效按真实接触事件播放。正常出杆流程中的可选运杆演示沿共享偏好执行，只能发生在1.5秒之后，不能提前泄露实际路线。

在点击后准备、揭示或出杆前进入后台/离页，撤销待出杆意图与计时器；回前台不能突然自动击球。保留当前题、已提交记录与可恢复状态，用户再次显式击球才建立新意图并完整揭示1.5秒；已计入首答的题不重扣额度。无解、不可出杆、模拟截断、保存失败均停在可说明/重试的状态，不能播放旧解。

重打恢复上一杆前球位、姿态与上一杆输入，保留同一题目标线；建议收起上一尝试实际线，直到再次击球再揭示，避免轨迹随拖动变成即时比对工具。回放结束恢复进入回放时的现场。下一题清除上一题的答案线、实际线和回放记录。

## 3. 出题管线

### 3.1 球形与设置

从当前 `TrainingBankStore` / `TrainingGridBank` 读取，与 2D 准度共用球形池、版本、条件筛选与有效进袋瞄点口径。复用角度范围、母球距离、目标球距袋、袋口类型、库边距离的多选规则；随机与具体选项互斥、至少保留一项、取消保留原轮次。

复用“20 题／自由练习”的轮次组织形式，并按用户要求完整接入现有瞄准训练权益模式，具体合同见§3.5。通用条件表单仍需与具体训练的权限/说明解耦，避免新页面误计入角度或准度额度。

出题杆法默认“允许高低杆＝开、允许左右塞＝开”，页内独立保存。关闭某轴只约束标准答案生成，该轴严格为 0；用户作答仍可使用正常打点盘。设置说明必须改成“影响目标轨迹的出题杆法”，不能沿用准度“指定打点不可更改”的说明。

### 3.2 中心打点最低可进杆速

对固定球形与指定袋口，设置 `spinX=0, spinY=0`，只搜索杆速；每个速度都重新补偿瞄准并跑真实物理验证。

最低杆速是**当前求解器在既定搜索精度下找到的最低有效样本**，不能把几何可进、球刚好碰到袋口或某个历史题库证明的速度当作结果。

- 搜索范围下限读取正式杆速控件的物理下限，上限为 4.5 m/s。
- 不假设“速度越大一定能进”；袋口弹出与瞄准解变化可能使可进区间不连续，不直接全区间二分。
- 实施修订：密集扫描发现0.05步长漏掉2.01 m/s的窄可进区间而误取2.23；改为全范围0.01 m/s升序扫描，首命中前邻区间以0.0025 m/s复查（FL-192）。0.005密集对照已通过，不称连续全局最小。
- 明确记录扫描精度、搜索预算、最低样本的准确杆向及进袋证据。粗网格不能证明不存在更窄的低速可进区间；若抽检发现漏检，增加分辨率/自适应细查，不能仍称精确全局最小。
- 中心打点不可出杆，或至 4.5 m/s 仍未找到进袋样本：淘汰球形。**不能自动改用高杆来代替中心基准**，也不能放宽用户条件。

基准验证包含完整有效模拟、中心打点可出杆、首次命中指定目标球及目标球进指定袋事件。母球是否进袋另外记录；标准答案的母球安全条件在下节单独处理，避免把“能进目标球”与“整杆适合出题”混成同一事实。

### 3.3 围绕中杆中力的联合抽样

建议采用**截断三维高斯分布＋拒绝采样**。令 `x/y` 为实际击点相对母球半径的偏移，`v` 为杆速：

```text
中心 μ = (0, 0, 2.5 m/s)
p(x, y, v) ∝ exp(-0.5 × [(x/σx)² + (y/σy)² + ((v-2.5)/σv)²])
```

初始调试候选：`σx=σy=0.18R，σv=0.75 m/s`，本轮按24球形实际接受分布采用的初版常量。两个击点轴使用相同尺度以保持左右、高低先验对称；力度用独立尺度，不把米每秒与半径偏移直接相加。

约束域：`v_min ≤ v ≤ 4.5`，`x²+y²` 不超共享打点物理边界，且命中实际球杆可达域；关闭的轴固定为 0。越界样本重抽，**不钳到圆周或速度边界**，避免边缘堆积。若 `v_min > 2.5`，采用原分布在合法区间上的截断，合法范围内的密度峰自然落在下限附近，不把中心硬改成区间中点。

这会产生大量小幅打点＋中等杆速，以及较少的强高低杆、强左右塞与极端力度。双轴可以同时非零；不强制九点分类配额，不用一大批完全中杆样本冒充“向中心集中的连续分布”。

### 3.4 每个组合重新验证，才生成标准轨迹

```text
已筛选球形
  → 中心打点搜索最低可进杆速
  → 随机 (水平打点, 垂直打点, 杆速)
  → 按该组合重新补偿瞄准
  → 检查补偿后杆向的精确打点可出杆
  → 完整物理模拟
  → 指定目标球进指定袋？完整终态？轨迹有效？
  → 通过：冻结题目和答案；失败：重抽组合
```

必须核对实际 `pocket(object, pocket_ID)` 事件，不能仅看 `feasible`、目标球路径经过袋口或无指定袋语义的“有球进袋”。完整模拟须自然结束，时间/事件上限截断、取消、非有限数值均拒绝。

建议首版标准答案再排除母球进袋，以及改变题意的先碰库再撞球/目标球间接进袋路线；目标袋正常袋角接触不一刀切排除。该筛选属于标准答案质量提案，须用现有直进判定逐事件核验，不把“所有碰库都禁止”套到母球碰后的走位。

同一球形内先重抽打点与杆速，有限预算耗尽才换球形。换球形仍在用户所选条件内；生成失败给出可重试/改条件的明确说明，无效题目不占题数。候选预算、中心搜索次数、失败原因须可诊断。

**分布验收分两层**：原始候选应符合中心密度递减；有效题目是该分布在“能打、能进”的可行域上的条件分布。低杆更容易因力度不足被淘汰，会改变最终分布。需报告接受前/后打点与杆速直方图、不同球形接受率；不能承诺物理筛选后仍严格高低/左右对称，也不通过偷改杆速或打点修补某个样本。

## 4. 轨迹与实际试打合同

### 4.1 两条线同一口径

- 以**母球首次碰撞指定目标球的时刻**为起点，到母球自然停稳为终点；母球进袋的用户尝试截到真实捕获时刻。
- 保留所有碰后弧线、碰库及其后续完整路径，不只画初始分离角射线或第一库前一段。
- 内部数据保存相对首次碰撞的时间标签与世界坐标。起点补齐精确接触状态，不能简单丢掉接触与首个采样点之间的一段。
- 坐标契约：SceneKit 世界 X–Z 米制，Y 向上；物理台面用实际 `scene.surfaceY`，球心高度为 `surfaceY + BallPhysics.radius`。参考半径来自领域真源，不从画面像素反推。
- 从原始物理记录提取，不使用含收球动画的播放路径当物理轨迹。呈现简化可去冗余共线点，但必须保留接触、碰库、捕获、停点及曲率；原始带时序数据保留。
- 目标线和实际线建议采用不同语义颜色并辅以不同线型，配小图例，避免只靠颜色区分。完整路径不等于必须实线；最终线宽与可读性用真实页验证。

### 4.2 当前输入与自动瞄准

用户调参时只更新打点/杆速读数与输入意图，不显示计算状态、当前碰后预测或任何“能进/不能进”的即时提示。可用单任务合并最新意图静默准备结果以缩短点击等待；后台计算状态不驱动作答页主按钮文案，也不因每次调参闪烁禁用。

点击击球是提交边界：冻结题目、双轴、杆速、球位、会话代次与原杆视角，结束调参；命中完全一致的缓存则直接使用，否则只等待该快照的完整结果。过期结果绝不能用来揭示、转镜或出杆。完成后绘制实际整线，开始1.5秒显示计时，随后标准出杆。参数未变化时可复用已验证同输入结果，不为每次回放重复求解。

3D调参时允许保持当前观察角度；后台求解不得自动抢镜或把未完成的临时杆向当精确补偿结果。点击后的最新解提交实际杆姿；如需沿杆相机准备，先按共享相机完成到本杆姿态，再开始完整的轨迹揭示窗口，不能让转镜/布局准备吃掉1.5秒。3D可见性验证包含碰库后长轨迹，不能因近景裁切就缩短或删除目标线；用户可在提交前使用全局/临时俯视检查整条线路。

**标准答案必须验证有效；用户试打允许真实失败。** 用户低杆＋低速没进袋时，不替用户加力或换杆法：使用求解器对该输入得到的当前可执行杆向展示真实轨迹和运动。无法出杆时提示原因；模拟未完成时不展示“完整轨迹”。完全未碰到目标球时说明“未碰到目标球，没有分离后轨迹”，不能拿碰前线冒充。

求解器若仅给出几何不可行而没有可执行杆向，需单独处理失败状态，不能偷用上一输入杆向。具体失败分支在 A1 核对现有 predictor 输出契约后接线。

### 5.1 草稿、记录与恢复完整接入

按同类训练体验纳入本地续练与历史，不以“暂不评分”为由省略恢复。采用独立版本化类型，冻结owner、正式维度、轮次ID、题目ID/题库与物理版本、球形、答案参数/轨迹、当前输入、首次尝试及最近一次重打。恢复同一题不能重新随机标准轨迹；重打恢复紧邻上一杆输入，不总是回到第一杆。

新题和输入草稿本地保存；首次有效提交按§3.5持久化与额度幂等提交，后续重打保存练习现场但不覆盖首答。返回/后台/进程重启恢复原题、输入与合法阶段；暂停的揭示/待击球不自动继续。击球运动已开始时采用完整记录恢复确定终态，仍允许回放；回放中断恢复回放前现场。

历史记录2D/3D类型、时间、题数与该段首杆均分；不显示排名或跨题型均差，不混入现有瞄准/准度统计。不增加历史题目详情入口，沿用同类训练边界。实际用时按活动会话累计，后台/退出不继续计时，恢复不重复累计。

沿现有owner隔离和同步队列接入，核对新kind在本地存储、历史列表、上传/下载/合并与删除链的处理；未提交草稿不上传为空历史。离线先本地保存，保存失败提供原位重试且不能假计题；账号切换取消旧任务、不向新owner写入旧题。损坏数据保留可诊断现场，题库/物理版本失配时不得静默重算改变旧题答案，保留历史并提供重新开始。

自由练习持久化分段：每10题或压缩载荷达到512 KB，在下一题边界原子保存上一段与新草稿段；界面题号和总结累计，历史按段记录真实题数/时长。失败保留原结果，未答续段不上传，原始轨迹不裁剪；单条压缩载荷1.45 MB预算守卫。
