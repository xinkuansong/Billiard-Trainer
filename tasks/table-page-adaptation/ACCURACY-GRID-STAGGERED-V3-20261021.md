# 准度球形库存 v3：15cm／2°交错采样

## 范围与合同

用户批准重新生成，先统计270组合、对比旧10cm／1°版本并渲染样例；明确不求解。本轮保留v2库存，不改Bundle，不运行中杆筛选或九打点试跑。

- 坐标：原生X–Z米制水平面、Y向上；P角袋各内收R、中袋长边中点，O目标球、G假想球、C母球。有限主库／袋角／圆弧／捕获口沿约束与v2相同。
- PG与GC采样：0.30、0.45……1.80m，共11层。
- 普通入袋方向角：PG层索引为偶数取0、2、4……；奇数取1、3、5……；0及最大值（角袋90、中袋180）额外保留。
- 切角：符号对称；绝对角度奇偶相位为`(PG层索引 + floor(入袋角/2) + GC层索引)%2`；0与±85额外保留。不同距离层与入袋角档位交错，单层仍是2°抽样，不称连续无缺口。
- 贴库另按有限主库15cm及端点补采样；其PG／入袋角可非网格。切角基相位用`round((PG-.30)/.15)+trunc(round(局部入袋角)/2)`归一到0/1，保证与普通网格重合的目标配置采用同相位；再加GC层索引。
- 精确同一目标／接触配置去重；镜像保留。原270分类仍按CO／OP距离，不按PG／GC。
- 参考进球射线仍越过P检查真实捕获；通道受阻保留候选，不能作物理无解判定。未做近似球形去重。
