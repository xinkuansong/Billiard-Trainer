版本：v2 · 2026-10-14。设计状态：用户已确认方案。工程状态：第二轮实现、构建及三设备模拟器验证完成。体验状态：本轮原生图待用户反馈。

用户要求：“先把这些页面的信息精简方案整理出来，逐项列清楚哪些删除、哪些保留、哪些改成按需显示，我确认后再改代码。”

目标：练习时优先看球形、必要标记和当前操作；减少台面常驻说明，保留目标、结果差异和异常原因。本文中的删除均指删除对应界面展示，不删除训练数据、求解信息或规则校验。

## 1. 范围与确认方式

本轮覆盖上一轮分析中的思路训练、打一走二想三、防守、翻袋、颗星、上手试打及普通编排、2D/3D角度训练、2D/3D瞄准点训练、角度与瞄准、分离角图谱、加塞吃库图谱，以及这些页面里的开球和共用反馈。

每日清台、普通对局的比分/犯规/规则裁定、内部批量编排台、图文详情与精讲、角度预测图解测验和瞄准点图解测验不随本方案批量改变。后两者属于独立教学答题页，特别是图解测验的球半径与题意说明，不因这次精简移除。分离角与走位的教学图示也不在本轮改动范围。

清单用固定编号供逐项反馈；用户已整体确认方案，本轮授权先执行第1批三规划页。用户可以整体确认，也可以指出某个编号调整。修改信息结构与新增按需入口属于本方案的确认内容；求解算法、训练评分、答案揭示时机、物理验证流程、菜单其他能力不变。

## 2. 共用展示规则

| 编号 | 内容 | 处理 | 目标行为 |
|---|---|---|---|
| G01 | 每段普通文字前的装饰性 ⓘ | 删除 | 普通状态、目标与读数不再统一加 i；帮助入口使用可点击的“说明”，无需每条文字各加一个按钮。 |
| G02 | “已就绪，点求解”“点击完成进入击打”等按钮复述 | 删除 | 由按钮文字、可用状态承担；前置条件未满足时按 G05 解释。 |
| G03 | “拖动中”“运杆中”“击球中”“演示中”等显而易见的动作播报 | 删除 | 台面不另铺文字；较长计算/验证等待在原动作位置显示进度，保留读屏状态。 |
| G04 | 基础操作与长按教程 | 按需 | 首次进入相关功能给非阻断短提示，可关闭；完成该操作即消失，记忆已完成；以后从“更多→操作说明”查看。不每次进页重播。 |
| G05 | 尚未选球、选袋或绘制约束 | 按需 | 仅在当前选择步骤或尝试受限动作时显示一个下一步，例如“选择目标袋”；步骤完成/取消即撤下。禁用动作需有可访问的原因入口，不能只变灰。 |
| G06 | 已重打、母球已回台、计划已顺延等完成反馈 | 按需 | 操作完成后出现一次，默认约 3 秒或下一次有效操作后结束；辅助功能阅读期间不因普通计时截断。不会在每次重绘后重新计时。 |
| G07 | 无解、模拟不完整、不可击球等阻碍继续的原因 | 保留（问题期间） | 简短原因与可行下一步必须可见，至条件变化或重试成功后撤下。长解释按需展开；打开打点盘也不能把全部失败状态藏掉。 |
| G08 | 未满足约束、未完全防守、翻袋备选、超出原筛选预算 | 保留（对应方案期间） | 常态保留简短标签；完整原因在方案详情。旧方案失效后同步撤下，不能把不达标解呈现为成功解。 |
| G09 | 同一字段在控件和台面重复 | 删除重复副本 | 先确认新的主要位置承接了内容及读屏值，再移除旧副本；不以台面有高亮为由直接删除唯一可读文本。 |
| G10 | 台面提示之间的竞争 | 调整展示规则 | 优先级为阻碍继续的异常→方案重要差异→当前选择步骤→普通完成反馈→首次教学；低优先级内容让位，不叠成说明墙。当前题目结果使用独立结果区。 |
| G11 | 展开说明、切换相机/2D/3D/临时2D | 保留状态一致性 | 说明跟随当前球形和方案；切相机不重播教程，不泄露未提交题目的答案。窄屏/大字号的全文只在说明面板内滚动。 |

“保留”并不表示永久显示：结果只在结果阶段显示，异常只在问题存在时显示。正常可操作状态允许完全没有台面文字。不会以“全部提示三秒消失”替代上述区别。
