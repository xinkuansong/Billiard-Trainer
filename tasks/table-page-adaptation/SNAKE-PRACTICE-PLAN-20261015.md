## 2. 入口与训练设置

### 2.1 入口

复用练习首页现有卡片，标题「蛇彩练习」，副标题建议「连续进球与走位」，内容角标使用现有「击球」，主题归入走位与准度。保留在「练」分类，不能因角标为击球而改放「打」。

现有「练」在源码注释中主要指测验，新项目需要同步调整分类描述的口径；不重排其他卡片。2026-10-16 用户决定蛇彩练习设为 Pro：复用统一 Pro 角标与入口会员校验；非会员打开订阅页，会员进入训练设置。

### 2.2 首次设置页

沿用2D角度训练的完整设置页：保持入口方向，明确点「开始练习」后才进入球桌。左上返回、右上开始，使用现有列表、分组、分段选择和文字样式。

| 项目 | 内容 | 初次默认 |
|---|---|---|
| 目标球数 | 3至15颗，下拉菜单逐个选择 | 5 |
| 清台方式 | 沿线清台 / 按号清台 | 沿线清台 |

设置项仅保留这两项，下方为「最近练习 · 10次」标准列表，最新在前；空态仅「暂无训练记录」。删除球形缩略图、规则摘要、独立球号排列开关及换一组按钮。按号清台每次开始新练习自动随机号位；沿线清台依次编号。没有预览需要锁定，点击开始才生成本局排列。

球数和方式选中即持久化，返回或重启后仍记住。局内取消设置保留当前局面，但保留新偏好供下次进入；重新开始仍保留同一排列，再来一局重新生成。旧random偏好不再读取，保存时清除。

## 3. 球形、顺序与母球摆放

### 3.1 首版摆法

采用动作库连续蛇彩的长台中线摆法。已实读c042/manual02（5球）、c069/manual02（10球）、c071/manual02（15球）的首杆before：平均球心间距分别161.07、150.61、156.72毫米，球排随球数增长。独立首杆练习的“8杆”不等于8颗球；横向围8有重复复位规则，不混入本练习。

统一按台长1/16（158.75毫米）设置球心间距，居中排列：x=0.5+(i−(N−1)/2)/16，y=0.25。3球占0.3175米，5球0.635米，10球1.42875米，15球2.2225米。每端最小球心到短库158.75毫米，扣除半径后仍有130.175毫米；母球默认放在1号球同X、y=0.375，仍可自由摆。

这是依据动作库归纳的统一产品摆法，并非声称所有球数有官方固定标准。新锐教学目录也包含十字、L形、横向等变体，当前不新增摆法选项。原“少球也铺满同一长轴范围”的方案废止。[研究与数值](../../output/snake-practice-20261015/r2/REPORT.md)。

### 3.2 顺序定义

- **沿线清台**：从模板指定起点沿排列依次清球。使用1至N号并沿线递增编号，让球号自然表达顺序。起点归属模板，在旋转屏幕或切换视角后不反转。
- **按号清台**：使用1至N号，始终按1→2→…→N击打。每局将这些球号随机分配到固定球位，不再显示顺排开关。
- 两种方式都由系统持有唯一合法目标，不能通过点击另一个球或球库改写顺序。
- 随机只改变编号与球位的映射，不改变球数、球形、物理尺寸，不在每杆后重抽。新局重新抽取，但不承诺绝不与历史排列重复。
- 随机偶然出现顺排属于正常排列，不保证每次都与历史不同。

### 3.3 母球自由摆放

进入每局后，母球先出现在一个合法默认位置，用户可直接拖动到任意合法台面位置，也可保留默认位置直接击球。无需增加「确认摆球」按钮。

合法位置不限制开球线或半台，但必须在可摆球区域内、不与目标球重叠、不落在袋口捕获区或库体内。复用已有拖球与投影反馈；无效落点回到上一个合法位置。首杆前反复调整方向、打点、杆速或切视角，均不结束摆球权限；真正执行第一杆时锁定。

开始击球后，母球及目标球都不能自由拖动，下一杆必须使用实际停点。目标球从入局起就不可拖动、增删、重编号或从球库拉回。

2D支持台面拖母球；3D首杆摆位使用现有临时俯视进入同一摆球操作，再返回原机位，不新增一套3D拖球手势。临时俯视中仍不可击球。母球落袋后的失误恢复按第5节处理，不转换成中途自由球。

## 4. 每杆规则

### 4.1 合法完成条件

以出手前的本杆目标和待打球集合为准，整杆须同时满足：

1. 母球第一次碰到的目标球是本杆指定球；允许此前吃库。
2. 指定球进入任意一个球袋。
3. 母球未落袋，也未发生引擎可判定的出台等无效状态。
4. 任何其他待打球在整杆过程中都没有被碰到，也没有进袋或出台。
5. 本杆运动完整结束，得到可信的最终台面。

本版将「不能碰其他待打球」具体化为：既禁止母球碰，也禁止本杆目标球撞到其他待打球。只要发生有效球球碰撞事件就违反约束，不以肉眼可见位移或位移阈值判断。未参与本杆的球必须保持原位。

不添加中八分组、8号决胜、指定袋、碰库次数或击球时限等额外比赛规则。球号8与其他球遵循同样的蛇彩顺序。

### 4.2 袋口选择与瞄准

复用现有进袋／自由瞄准能力，但合法目标始终由蛇彩规则决定。

- 进袋瞄准时可自主选择六袋，系统不得因预测更容易而偷偷替换用户所选袋。
- 所选袋只用于瞄准辅助。实际进了另一袋，只要其他条件全部满足，仍为合法进球；本练习没有报袋判罚。
- 自由瞄准允许用户自行调整方向。即便实际先碰错球，也应由出手后的规则判定处理，不能把方向锁死成自动命中。
- 预测会失误不等于不能出杆。只有摆位不合法、杆法不可执行、正在计算/运动等实际不可执行状态阻止击球；不把“预计进球”作为击球按钮的必需条件。

### 4.3 完成时机和提示优先级

目标球进袋时不能立即推进：母球可能随后落袋或碰到待打球。等全部运动及落袋尾段结束，统一裁定；最后一球也一样。

同时发生多个问题时只显示一条最有助于纠正的原因，建议顺序：结果不完整→母球落袋/出台→碰到其他球→未碰到指定球→目标未进。不追加犯规次数或结果明细表。

## 5. 连续练习与恢复

| 状态 | 行为与界面 | 可执行动作 |
|---|---|---|
| 首杆准备 | 标出当前目标；母球可拖，目标球固定 | 摆母球、调参、选袋、切视角、击球 |
| 击球播放 | 播放真实本杆；不显示“击球中”等重复提示 | 暂停/后台处理按共享生命周期；锁定改球、重开和重复击球 |
| 合法进球 | 沿用真实停点，更新目标高亮；无成功播报 | 继续下一杆、重打、回放 |
| 未进或违规 | 保留实际结束球形；原生弹窗一句原因 | 重打本杆/重新开始二选一；不能直接跳过继续 |
| 全部清完 | 保留空台和母球；简短显示“已清台” | 现有主动作位置变为「再来一局」，仍可回放/重打最后一杆 |
| 模拟不完整 | 保留可恢复快照，不计本杆进球 | 弹窗“本杆未完成”，重打/重开；记录只含已合法完成球数 |

### 5.1 动作语义

- **重打**：恢复最近一杆出手前的完整台面、合法目标、编号排列和击球参数，保留更早的进球。目标曾进袋、误进其他球或母球落袋，都一起还原。不再次随机；失误不终结本局，重打合法进球正常计入。已清台后重打末杆会撤回该条结果，恢复为同一局，之后只更新同一条。
- **首杆重打**：恢复首杆出手前台面，并重新开放母球摆位；第二杆及之后的重打不开放自由摆母球。
- **回放**：只观看最近一杆的实际轨迹，结束后回到观看前的局面与规则状态；不再次判罚或推进，不修改目标高亮。
- **重新开始**：先结束并保存当前局（未清完失败，已清完不重复记录），然后以新ID建立一次训练。恢复本局最初的目标球排列和首杆母球起点，再开放母球自由摆位。保留随机排列，适合重复练同一条路线。
- **再来一局**：先结束并记录当前局，使用当前设置建立新局；随机模式重新分配球号，首杆母球可自由摆。此动作在清台后由现有主按钮承接，也可从更多菜单触达。
- **修改训练设置**：选择立即保存偏好，但不改变当前局。只有明确点「开始新练习」才结束并保存旧局，再按新配置开始。
- **离页**：直接结束并保存当前局，未清完记失败、原因「提前结束」，不多加确认。重新进入先显示训练设置。

重开和换局不额外弹多层确认；使用名称明确、收在菜单内的动作表达后果。回放、重打、重新开始和再来一局必须保持不同语义。

### 5.2 状态保存边界

单次停留期间保留配置、球位、目标索引、排列、最近一杆快照及回放数据，用于规则、重打、视角切换与后台恢复。这些是运行状态，不是成绩。

本功能以UserDefaults的snakePractice.history.v1保存最多10条已结束记录，另有一条活动局检查点用于异常退出恢复。点击开始建立新ID，首次实际出杆才建立活动检查点；尚未出杆时退出、重开、换设置或中断恢复均不记录。已经出杆即使未进球，或重打首杆后退出，仍记录0/N失败；每次合法球结算更新进度，失败只更新检查点、等用户重打或结束，不预写失败历史。清台即时保存；重打末杆移回活动局；退出/重开/换配置幂等结束。中断后下次进入将活动局归档为失败，保留最后合法数量与已知原因。配置、结果独立于SwiftData训练/角度/每日记录，不写全局统计或同步，不记录用时、杆数、命中率、重打次数。首版不做退出后续局或跨设备续局；后台短暂恢复沿用现有生命周期，不因切前后台重新随机。

## 6. 页面布局与信息密度

### 6.1 标准布局

| 区域 | 蛇彩页面处理 |
|---|---|
| 返回与标题 | 现有返回触点和标题预算；标题「蛇彩练习」，不拼接球数/模式挤压球库 |
| 顶部球库 | 只显示本局1至N号球，即5/8/10/15球对应5/8/10/15个目标槽；不显示N之外的球，也不留其空占位。复用共享球库样式、居中关系和容量策略，宽度按实际内容计算，不把少量球拉伸铺满15槽宽度。当前目标突出，已进球保留暗态，不随每杆进球缩减或重排槽位。无母球槽，无中八分组线 |
| 球库交互 | 点击仅定位/短暂强调相应台面球，不切换合法目标；已进球不可拉回，未参与球没有入口。下一颗不另做常驻高亮 |

| 左侧 | 复用方向尺及重打/回放位置；原对局“开球”不适用，重开收在更多，不把无用开球按钮保留成假入口 |
| 右侧 | 复用打点盘、杆速尺和击球主按钮；清完时主按钮改为「再来一局」 |
| 3D观察 | 复用全局/第三人称/第一人称/临时俯视四入口及布局，切视角不改规则与球位 |
| 右上状态与更多 | 沿用系统状态块和标准菜单，无训练计时器；更多承担低频设置及重开动作 |

## 7. 共享能力与菜单对照

菜单分组顺序沿用现有「显示 → 击球设置」，后接本页「练习」。重开操作在运动、计算提交和回放期间禁用；临时俯视沿用共享视图切换限制。

| 参考能力 | 适用性与接入要求 | 状态/偏好范围 |
|---|---|---|
| 2D/3D视图 | 直接复用真实渲染切换与稳定场景 | 切换保留本局；初次2D，上次视图可按既有页内偏好记忆 |
| 打点盘透明度 | 复用面板、滑条和打点盘实际透明度 | 蛇彩独立页内偏好，不改每日/自由击球默认值 |
| 台面网格 | 复用选中态及场景网格开关 | 沿用现有全局网格偏好 |
| 瞄准特写 | 复用按需显示、拖动条件和遮挡规避 | 沿用现有全局特写偏好，不在静止时强制常驻 |
