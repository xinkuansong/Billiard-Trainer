# 2D瞄准拖动边界 · 2026-10-29

状态：共享实现、规范回填、15单测及6项手机/iPad原生回归完成；真机手感待用户复验。DR-453；用户明确授权跨页修复及规范回填。

## 问题与实现

准度2D桌外地毯可改变方向；源码确认瞄准回调只检查未抓到球，未判断起点边界。合并练习场景为显示真实房间地板铺满窗口，放大了此缺陷。每日等局部场景也留有桌外取景余量。

`AngleSceneView.Coordinator`记录实际touch-down，在shouldReceive/shouldBegin和began入口按相同起点检查；SCNView本地pt反投影到当前scene.surfaceY平面（SceneKit X–Z，Y向上，米），用CameraRig当前桌外框半长/半宽拒绝桌外起手。不在changed重复限界；ended/cancelled/failed清理。无相机或投影无效时拒绝2D瞄准；球/测量柄合法近邻抓取优先，保持原权限。无瞄准回调、3D及临时俯视不新增限制/能力。

画面、地板、物理、评分、球库及方向尺布局不改。技术before：`output/aim-drag-boundary-20261029/AngleSceneView.before.swift`；用户提供的截图为现象上下文，不当作动态手势证据。
