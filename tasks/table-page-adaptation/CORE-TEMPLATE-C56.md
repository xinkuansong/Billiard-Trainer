# 每日清台核心模板 · C56 有效版本与继承合同

2026-10-08。用户明确：其他有球桌的页面应把每日清台作为核心模板，所有适用内容都继承。此文件是跨页接入清单；每日活动真源仍为 `tasks/daily-adaptive/CURRENT.md` 和当前生产源码，不建立另一套每日排期。

## 1. 当前决定

其他页面采用“每日核心模板 + 业务差异”。共同外观、布局关系、交互、状态、面板与基础设施优先直接复用现有组件/计算链；不得按截图重新绘制一套近似样式、缩短行高或省掉展开状态。每日专属的玩法、合法目标、开球裁决和成绩不是所有页面的默认业务。

“最新”必须逐组件判断：C56只更新状态块，没有重新制作所有旧展开页。旧画板编号、同名节点、云端文件名都不能独立证明完整页面最新。设计源、现行代码、最新原生实图不一致时列差异，以用户最新决定为准，先修模板来源再迁移。

本轮P01初稿因来源混用撤回：菜单35pt行/简化底色/256pt宽、自绘分段、删除球库分组线均不能当模板标准。旧稿保留为失败证据，不进入实现。

## 4. 代码复用与推广顺序

1. 冻结当前每日组件来源、代码指纹和实图；Figma明确“有效组件/历史整屏/原生参考”，补齐失配项。
2. 在P01完整能力清单上接模板；共享现有样式、双尺/按钮、菜单、打点与状态组件。页面仅提供标题、球库内容、权限、参数绑定和动作回调。
3. `configureDailyClearanceRendering()`同时绑定每日渲染profile和相机策略；先拆清这两个职责的接入合同，再让P01选择所需能力。不要调用每日Controller或复制一套CameraRig。
4. 模板引入不能改变目标球上限、物理、求解、题目/成绩归属、普通用户偏好作用域。几何、相机、场景、手势命中同步验证。
5. P01按相同窗口和球形与每日对拍，再验普通自由击球作为第二消费者；随后按原页面清单继续其他场景。

本轮为模板梳理、当前状态采集与设计返工。未把所有产品页迁移完成；未修改生产`QiuJi/`代码。当前真实复用测试结论和未验边界见[P01复用核验](P01-C56-REUSE-REVIEW.md)。
