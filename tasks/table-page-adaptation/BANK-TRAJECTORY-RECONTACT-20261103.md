# 翻袋解球：击球保留轨迹与二次碰球过滤 · 2026-11-03

状态：实现完成，r4隔离快照构建、14项定向测试及2D/3D原图复核通过。用户原话：①「现在点击击球后，母球和目标球轨迹会消失，不要消失」；②「现在的解会保留母球和目标球相撞导致目标球进袋的解，这种解不需要」。第②按目标球入袋前母球与目标球再次碰撞解释，正常首次碰撞保留。

## 范围与根因

仅翻袋解球求解态。`launchPlayback` 触球时 `clearPath()` 清掉当前两球路线；`BankKickValidity.bank` 与搜索引擎评分未拒绝二次母球／目标球碰撞。现在击球、回放共用路径保留路线，只隐藏假想球／接触点；结束、停止、重打沿原快照恢复。事件过滤用于搜索引擎评分、完整终验、解目录和轻量容错验证，避免只在UI末端删解。

事件判断在目标球捕获时截止，顺序无关的球对匹配，不以折线交叉推断碰撞。不修改物理参数、题库、颗星合同、自由试打。当前并行任务已恢复自动求解，本轮保留其源码，不沿用旧手动求解文档定义。
