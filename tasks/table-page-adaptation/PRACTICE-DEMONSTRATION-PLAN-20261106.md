# 击球练习的答后示范 · v2.0

本文件是本轮需求真源。2026-11-06，用户已授权按 B1 实证通过后推进 B2、B3、B4。本文整合 v1.0–v1.4 及本轮确认的三杆规则。执行及实测记录见第 8 节。

## 1. 需求与交互

|编号|用户意见|落到页面上的行为|
|---|---|---|
|Q01|把这类页面的回放换成示范|有本题参考杆的结果页，把示范放进现有左下辅助动作位。截图里的防守轨迹页合并两处播放入口，结果态只留「重打」「示范」。|
|Q02|有测量的页面，重打前用示范，重打后用测量|同一个位置随球桌状态切换。结果态用来对照参考打法；重新瞄准时用来测量球台。|
|Q03|示范只在第一次击球后出现|按本题、当前路线统计首杆和重打。任意一杆达标，或完成第 3 杆，立即在结果页解锁。首次瞄准、跳题、计算失败均不提前揭示。|
|Q04|点示范时，右侧打点和力度条也换成示范里的|点击即切换打点圆盘、力度条填充和杆速读数；三者与动画使用同一杆参考参数，只读。|
|Q05|点重打恢复玩家之前的参数|回到该题起杆球形，恢复玩家最近一次实际出杆的打点、杆速，以及该页可由玩家控制的瞄准方向。多次重打取最近一杆，首答成绩独立保存。|
|Q06|示范打点可以点开，只读|示范播放中、播放结束或手动停止后，点右侧小打点盘均能展开大盘查看并关闭。大小盘显示同一示范落点；点按盘面、拖动、方向键微调均不能修改参数。|
|Q07|打满 3 杆还没达标也可以看示范|首杆算第 1 杆。前两杆均未达标时继续练或换题；第三杆产生结果就能看示范。六个首批入口均适用。|

**同题示例。** 分离角练习连续打出 62、71、68 分，前两次结果页提供重打和下一题，第三次结果页出现示范。如果第二杆打到 75 分，第二次结果页就出现示范。已经解锁的路线在重打瞄准时显示测量，再次出杆后可继续看示范。

|用户所处阶段|原回放／测量位|右侧仪表|下一步|
|---|---|---|---|
|新题、当前轨迹尚未击球|有测量的页面显示测量；仅有播放能力的页面留空|玩家当前设置，可按题型调整|首次击球|
|玩家击球计算或球还在动|示范不可触发|玩家本杆参数|停稳并产生结果|
|结果刚出现，尚未解锁|原位显示「测量」，灰显且不可点击|玩家刚打的参数，只读|重打或下一题|
|结果刚出现，已经解锁|有可用参考杆时显示示范|玩家刚打的参数，只读|示范、重打或下一题|
|已点击示范，准备或播放中|防止连续点击启动多次；主动作沿用「停止」|立即显示参考杆打点、杆速和力度条，只读|停止或等球停稳|
|示范结束，仍在本题结果页|示范可重复看|打点圆点和力度条保持示范值；成绩与球位仍属于玩家|重打或下一题|
|点重打，重新瞄准|原本有测量的页面恢复测量；其余留空|立即恢复玩家上一杆实际参数，可按原规则调整|再次击球|
|下一题、新轨迹、重新开始|复位为首杆前状态|使用新题自己的参数|独立解锁|

**右下主按钮**。点左侧「示范」时，右下原位由「下一题」切为「停止」，准备和播放时均可按。自然播完或点停止都停留在本题结果，右下立即恢复原来的推进动作；玩家可直接点「下一题」，无需先重打。两球走位尚有路线时恢复「新轨迹」，本组结束时恢复「查看总结」。进入新题或新轨迹时清除上一杆的示范显示。

沿用各页现有「重打／重试」命名及其判断。关闭玩家出杆动画的练习，实际完成并产生结果的杆同样计数；用户主动点「示范」仍播放参考动作。测量入口原有的首杆前使用权限继续适用。

**每一杆怎样达标**

|练习|前两杆提前解锁的条件|第 3 杆|
|---|---|---|
|防守轨迹、分离角、两球轨迹走位|本题当前路线任意一杆轨迹分 ≥75，含首杆和重打。防守效果分、首答均分独立统计。|有本杆结果即解锁|
|K球、翻袋、解球|本题任意一杆被该练习已有规则判为成功。|即使连续三杆失败也解锁|

**哪些操作算一杆。** 玩家提交一次实际击球且该题接收了本杆结果，计 1 杆。打丢、犯规、得 0 分均计入；点「重打」只回到瞄准，下一次真实出杆才计数。跳过、无可执行出杆、模拟出错且未产生答题结果、播放参考杆、停止播放均计 0 杆。重复保存同一杆只算一次。门槛只控制查看示范，玩家从第一杆结果起就可以直接进入下一题。

## 2. 页面范围与参考杆资格

下表为已确认的六项范围。覆盖每项的正式 2D、3D 视图，以当前题目保存的参考杆为准。按钮资格同时取决于当前题／路线已解锁和参考动作确实能成立。

|练习／模式|参考杆从哪里来|演示什么，怎样判断有效|
|---|---|---|
|防守练习 · 轨迹|本题已选参考解的方向、打点、杆速|复用现有参考播放及目标／玩家实际路线对照；沿用本题防守参考解入选条件。接入解锁条件，合并播放入口并同步仪表。|
|分离角练习|生成当前目标轨迹的 answer、answerDirection 和 target|在本题球位按原打点、方向、杆速复现目标路线，进入指定袋。中杆辅助线与本题答案分开。|
|两球走位 · 轨迹|当前 routeIndex 对应的已入选路线|按该路线打进第一球、展示母球落点及下一球目标袋。切换「新轨迹」后必须再次真实出杆。跳过不能解锁。|
|K球练习|所选题已存 dir、sx、sy、v，可按参考方向重建|第一球进指定袋，母球按本题要求碰到第二球，并核库序及本题入库前／出库后提示与实际接触的对应关系。首次作答前现有灰色中杆参考仍只是辅助。|
|翻袋练习|题内 source.direction 和 source.input|用当前物理模拟，按本题翻袋判定核对目标球的碰库顺序、入指定袋及犯规条件。|
|解球练习|题内 source.direction 和 source.input|用本题完整判定核对母球按序碰库、先解到指定球以及碰球后规则。已有生成库段提示的模拟只提取颜色／顺序，不能单独证明示范合格。|

**范围边界。** 防守自由模式的出题分支没有选定参考解，建议保留原有玩家回放。两球自由走位有候选路线，若后续纳入，用「一种参考打法」展示合格走位，另行确认与自由评分的关系。准度练习确有回放位，可作为下一批，前置条件是在本题允许的打点范围内生成并实测能进指定袋的一杆。三球走位需按玩家选袋及第一杆真实落点衔接第二杆。多球、蛇彩、每日清台、自定义球形需另外定义当前杆目标。角度、假想球、瞄准点题维持答后几何对照；走位求解、翻袋解球、颗星解球等摆球工具保留其试打和回放。以上均不随首批统一替换。

## 3. 参数、播放和恢复

1. **分开三份事实**。题目提供参考输入；玩家最近一杆提供重打输入；当前显示来源只决定 HUD 读哪份。参考值绝不能经仪表绑定的 setter 回写到玩家草稿。右侧力度条及数值使用该页同一杆速量程；打点横、纵坐标取同一份输入，出杆动画也取这一份。
2. **复用现有回放返回路径**。点击时保存玩家结果态、球位、相机与页面已有路线。用参考杆临时还原起杆球形播放。正常完成和主动停止都返回原结果。播放前后核对玩家最近一杆、首答、次数、分数、额度和历史。禁止以示范出杆走一次玩家提交路径。重打继续由本页 retry() 从玩家最近实际一杆恢复。
3. **临时显示的生命周期**。同题同结果保留打点盘与力度条的示范显示值；重打、下一题、下一条轨迹、重新开始清除。离页、后台中断和重新进入以玩家可恢复的存档为准，参考显示不持久化。计算期间可停止；已取消或属于旧题／旧路线的异步结果不能覆盖新题。
4. **参考不可用**。没有参考解的模式遵从上表。当前题本应有参考但重建失败或不满足规则，取消参考显示，恢复玩家结果和仪表，沿用现有提示位说明原因，保留重打／下一题能力。不得换一题假演或静默播放玩家上一杆。用当前题核验，可复用已验证预测，避免每次刷新 HUD 都求解。
5. **布局与权限**。沿用既有自由布局动作位 shot.replay 及左下重打位，保持已保存位置。按钮可见名和无障碍标签随「示范／测量」更新。播放中仪表可读，控制输入、测量拖柄与页面切换沿用相应忙态保护。防守结果页移去原先放在统计栏下方的独立示范按钮，以免重复。

**计数与续练实现。** 在玩家出杆结果被当前题正式接收时，按杆 ID 去重，并将本题已打杆数、是否已解锁与结果一并保存。已有可靠的逐杆数据时优先复用；只保存首答和最近一杆的页面需要补记解锁进度。两球轨迹以题目和当前路线共同识别。切换 2D／3D 或恢复本题时接续计数，重打只切换界面阶段；换题、新轨迹、重新开始才重置。已经解锁的题目后续打低分也可继续查看。旧存档按当前题能证实的独立出杆和成绩恢复：若只能证实一杆，则从一杆继续；能证实曾达标或打满三杆则直接恢复资格。

## 5. 验收脚本

- **打点大盘只读查看**。在播放中、自然结束后及手动停止后，从小盘实际展开大盘，核对示范圆点的位置；点按、拖动、按住微调键均不能改变示范值或玩家草稿。关闭大盘后仍在原阶段；重打后再打开，显示玩家上一杆落点，并按该题原权限编辑。复核 [小盘展开与大盘编辑接线](../../QiuJi/Core/Components/BTTeachingTablePage.swift#L857) 和 [盘面与微调控件](../../QiuJi/Core/Components/BTSpinPad.swift#L396)。
- **右下主按钮**。准备中停止、播放中停止、自然播完分别核对仍是原题；再点恢复后的按钮，验证只推进一次。另测两球「新轨迹」以及末题「查看总结」。
- **参数对照**。选择参考杆与玩家输入明显不同的题。记录玩家打点横纵坐标、杆速、瞄准方向及首答成绩；点击示范时比对参考数据、界面打点位置、力度条高度和数值。自然结束、主动停止各跑一次；两者点重打都必须精确恢复玩家值。再手动改参数打一杆，下一次重打应恢复这次的新值。
- **解锁与切槽**。进题先查示范不存在；可测量的页实际打开一次测量工具。分别验证首杆 74.9 分时隐藏、首杆或重打恰好 75 分时解锁；达标后同路线再次出杆低于 75 分仍可在结果页查看。按成功／失败判定的三项另测。重打后在原槽实际打开测量并拖动合法测量柄；下一题／新轨迹再查答案保护。仅跳过、本杆计算失败、连续点两次示范分别测试。玩家实打失败与模拟计算失败分开造例。
- **三杆边界**。在评分题连续打三杆低于 75，在成功制题连续失败三次；分别断言首杆、第二杆显示禁用的测量，第三杆结果出现即可点示范。在第二和第三杆之间切视图、退出续练并重复保存第二杆，恢复时仍应是两杆。将第二杆改成恰好 75 分或成功，确认提前解锁。两球切换路线后从零计数，同一路线重打保留计数；旧档首答和最近一杆具有相同 ID 时仅算一次。
- **数据隔离**。对比示范前后当前题目／路线、首答、最近一杆、出杆次数、分数、训练额度、保存的玩家参数；示范多次也不可增长。分别覆盖结果续练、重打中退出再进入、旧存档没有参考参数、播放中离页及快速换题。
- **原生界面**。六页分别覆盖 2D、3D 操作；紧凑 iPhone 横屏核按钮完整位于视口，标准 iPhone 核两套仪表读数切换，iPad 横竖屏核布局和旋转恢复。保留首杆前、结果、播放、播完、重打的同题对照。状态转换用连续操作或录屏证明。真机体验、全 App 回归与用户认可单列。
- **局部球桌规范**。TP07/08/09/28 继承既有辅助位、触控和布局；TP11/15 按显示来源区分只读与编辑；TP16/17/30 继承视角与退出恢复；TP22/25/26/33 按本题首杆门控、测量、重打、续练核查；TP35/36 按真实证据回填。其余沿用原页面卡。各项执行状态和验证边界见第 8 节。
