# 准度网格 v2：角袋内收基准／中袋长边中点

## 用户确认与坐标

2026-10-21用户确认：角袋生成基准P取有效台面顶点向内水平、垂直各收一个球半径；中袋P取长边中点。按此方案重新统计270个组合，再挑球形渲染审看。本轮只做几何清点与预览，不启动新物理求解或正式题库发布。

世界X–Z米制平面、Y向上；横桌屏幕右+X、下+Z。L、W、R取`TablePhysics`／`BallPhysics`：

- 四角：`P=(±(L/2−R), ±(W/2−R))`，约`(±1.241425, ±0.606425)m`。
- 两中袋：`P=(0, ±W/2)`，约`(0, ±0.635)m`。
- P是生成参考点，不移动实际袋心、捕获区、袋角或实体库边。
- 普通网格和精确贴库补充均使用同一套P；补充不再调用旧`effectivePocketAimPoint`。
- 普通PG／GC仍0.30–1.80m、10cm步长，入台方向与切角1°。角袋0°／90°边界现在能直接生成相应平行贴库球；中袋贴库仍有边界补充。
- 分类继续按CO／OP，镜像保留，固定打点／力度不增加球形数；完整平面几何检查和互斥库距约定不变。

`cleanObjectPath`沿O→P射线越过P继续检查指定袋实际捕获；搜索长度取2倍有效台面对角线，覆盖当前几何。通过P不等于进袋；参考通道受阻的候选仍保留。
