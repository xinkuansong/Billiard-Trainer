# 自定义球形删除确认与练习续接

2026-10-29；状态：实现及定向验证完成，待真机体验，未提交/发布。

## 用户反馈与合同

1. 删除确认从行菜单跳到页面上部。原因为确认修饰器挂在整张List，popover未绑定所点行；改为原生居中alert，显示具体模板名和取消/删除，删除只作用于确认的模板。
2. 每个球形未打完后，下次应进入中间状态。用户补充“不需要额外增加重新开始的入口，原来的开始练习就可以”。沿用列表“开始练习”，有进度就恢复；不增按钮、不改文字。球桌已有重新开始动作保留原功能。
3. 内置与个人球形均按owner＋template ID保存本机进度，内容为停稳球位、球身份/离桌状态、方向/选球/选袋/杆速/打点。2D/3D共享一份。模板云同步仍只同步显式保存的模板；本机进度不上传，不增加历史成绩或跨启动上一杆录像。
4. 出杆前、停稳后、静止修改后、后台和离开时存档；运动/回放临时球位不写入。中途强退恢复最近稳定检查点；退出取消旧回调，防止销毁后覆盖。
5. 改名保留进度；初始球位或球身份变化、复制新模板从头开始；清完目标球下次开始新一轮。编辑不覆盖练习进度，练习不覆盖模板。删除模板清其本机进度。坏档显式报错并保留文件，不静默覆盖。
