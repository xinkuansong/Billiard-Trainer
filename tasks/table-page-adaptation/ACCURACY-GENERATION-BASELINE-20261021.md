确认日期：2026-10-21。用户审阅当前抽题器的20题生成／实际角度对照，核对袋口编号与名称后，明确表示“现在的球形生成方案整体很好，记录下来”。本文件汇总当前采用方案；此前随机扩库、每格200／500／1000题、10cm／1°等是探索历史，不作为当前执行要求。

## 1. 整体流程

按几何参数网格生成球形 → 应用球桌和袋口几何约束 → 分类统计 → 中袋直进筛选 → 保存无解球形及组合ID → 校准组合概率 → 先抽组合、再抽组合内球形 → 恢复球位后计算正式瞄准点与实际角度。

生成覆盖和随机展示权重分开。保留各组合实际存在的球形，不为凑定额制造近似重复；组合题量不直接决定出题概率。离散网格为空只说明本次采样无候选，不证明连续几何空间不可能存在。

## 2. 生成几何与网格

世界X–Z平面，单位米，Y向上；横桌屏幕右为+X、下为+Z。有效台面2.540×1.270m，球半径0.028575m，以正式几何常量为准。

符号统一：C母球、O目标球、G生成假想球、P生成参考点。P不是真正进球瞄准点，也不移动物理袋口。

- 角袋P：有效台面顶点沿两个轴各内收一个球半径。
- 中袋P：对应长边中点。
- G在P→O反向延长线上，与O相切，球心距为2R。
- 生成变量：指定袋口、PG长度、GC长度、PG相对库边的方向、带正负号的生成切角。
- PG、GC均取0.30、0.45……1.80m，共11层，步长15cm。
- 方向角步长2°，按PG层交替取偶数／奇数角；保留方向范围端点。
- 生成切角按PG层、入袋方向档、GC层交错奇偶相位，保留0及±85°；精确公式见[网格v3记录](ACCURACY-GRID-STAGGERED-V3-20261021.md)。这不是连续穷举，也不是把两套角度在每层全部叠加。
- 贴库按有限主库每15cm及端点补采；补采目标配置与普通网格一致时采用相同切角相位。
- 校验有效球心位置、球体接触、母球到生成接触位的可达几何，以及有限主库、袋角、圆弧、捕获口沿。参考进球射线受阻不直接等同物理无解，筛选资格另记。

## 3. 分类和重复性

组合为5角度档×2袋型×3母球距离×3目标球距袋×3库距，共270格。

角度档为0–10／11–30／31–50／51–70／71–85°，使用生成角度标签；距离分类用CO和OP，区别于采样使用的PG和GC。库距按目标球表面到有限主库的最近距离，含端点，区分离库、半贴库、贴库；半贴库排除贴库，阈值10cm。用户语义为小于10cm；现有分类实现用10cm加接触浮点容差的上界，边界实现见TrainingLayoutFeatures.railClass，不能把它写成严格小于的代码断言。

精确重复的目标／接触配置去重，镜像球保留供不同视角练习；力度与打点不作为新增球形身份。当前网格库未应用早期随机生成阶段的近似去重阈值；不得声称已经按0.5°等阈值二次合并全库。

## 4. 中袋筛选与当前数量

只保留目标球直接进入指定袋的结果，排除依靠反弹或二次碰撞等间接进球。母球是否落袋不影响此阶段球形入库资格；这与练习出杆后的成绩规则是不同口径。
