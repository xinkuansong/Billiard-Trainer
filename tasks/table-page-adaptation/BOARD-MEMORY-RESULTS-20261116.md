# 七页球形记忆实施与验证

日期：2026-11-16。需求真源：[实施方案](BOARD-MEMORY-PLAN-20261116.md)。状态：B1–B4全部完成。iPad与iPhone功能、隔离及七页独立恢复验证通过；历史失败及修订单独保留。

## 实现范围

| 页面 | 恢复内容 |
|---|---|
| 分离角与走位 | 正式 composer 入口；球位、目标／袋、自动或手选来源、模式、方向、杆速／打点、开球待发输入 |
| 走位求解 | 球位、球袋、区域／落点／过点、形状、容差、求解选项及匹配路线的微调 |
| 打一走二想三 | 球位、①②③角色、逐杆袋口、未完成规划、约束及匹配路线的微调 |
| 翻袋 | 目标身份、球位与姿态、袋口、模式／库数、方向和力度／打点 |
| 颗星解球 | 真实球号与目标别名映射、球位与姿态、模式／库数、自由输入 |
| 角度与瞄准 | 多球、当前目标及袋口，重算切角与辅助图形 |
| 进球容错角 | 多球、当前球及各球独立袋口，保留未选袋；撤球沿既有映射清理规则 |

`BoardMemory` 按 owner/page 保存版本化本地 JSON，原子替换，每页最近一份；损坏和不兼容记录保留，明确恢复默认时另备份。连续修改合并提交；出杆／回放前、拖动前后及生命周期交接补保存。同页最新活实例拥有写权限，旧实例不能覆盖。显式拍照导入优先，随后成为本页草稿。合法空桌及仅母球可保存。

共享教学宿主与正式编排宿主分别接线。重进清除运行时上一杆缓存，按用户输入重新求解；只有新解匹配原路线时恢复微调，否则提示回退。准备开球保存种子及输入；普通击球中断恢复出杆前，完成交接后保存停稳状态。回放使用既有恢复机制，不持久化播放中的球位。

## 失败与复验

- B1 初始构建暴露 toast 类型适配，修复后构建通过；中途另一项任务的目标提示 API 短暂漂移导致两次编译失败，后续源状态恢复，r6通过。保留原始日志。
- Mac mini首轮构建通过，受管设备容量检查拒绝创建默认设备；没有绕过管理器。改用同覆盖角色的可用 iPhone17。
- iPhone旧快照6项功能测试通过，原生测试在导航转屏时过早点击球库，新增球等待超时。测试补充可点击且 frame 连续稳定的等待，跨页返回另等待首页恢复后继续，最终复验通过（r3功能／隔离＋r4七页原生）。失败记录见 `output/board-memory-remote-b1-r2/`；该轮不计为产品恢复通过。
- 最终补充回归发现翻袋重算入口提前清空待恢复微调；FL-272同步修复翻袋／颗星，新增真实微调恢复用例两项均通过。原生菜单关闭选择器修正为当前共享宿主label；保留本机中止轮次 `final-validation.xcresult` 及远端 `output/board-memory-remote-seven-r1/`（15通过／9失败）。最终重新构建后定向复验通过，未将旧失败改绿。
- 写盘门禁发现新增测试 fixture 未登记；补齐独立临时目录、清理及污染边界后 `verify-gate` 通过。
