# 准度重打与回放（2026-10-21）

用户反馈：准度缺少标准重打/回放组合，已有重打误用播放图标。本轮只修2D/3D准度；不继续小屏最大字号或六页完整矩阵。

## 实现

- 直接复用`BTHUDCompactAction`：`arrow.uturn.backward`＋重打、`play.rectangle`＋回放；按Foundation的`horizontalActions`排布，方向尺的位置与长度不变。左列保留已确认的四行题目信息，移除底部重复“剩余题数”，避免免费模式增加尾行挤压按钮；额度判断不变。
- 布局身份分别使用`shot.undo`、`shot.replay`；控件保留标准禁用态、标签和实际命中范围。
- 重打仍恢复本题球形、指定袋口及固定打点，首次成绩不可覆盖。
- 回放保存最近一杆的实际输入、已录制轨迹、开杆球姿态及相机；不重新求解、判分、记题或扣额度。重打之后可继续回看上一杆。
- 回放用`ShotReplayCamera`恢复原杆视角，播完或点击“停止回放”恢复点击前球位、姿态、可见性、透明度、袋中球及相机；2D保持2D。
- 后台/离页取消动画并恢复现场；换题、重新开始及切账号清除旧杆上下文。轨迹仅保留在内存，重启App后的历史成绩不伪造回放。

## 验证

- iPhone SE 3 / iOS 17 常规字号：`SixTrainingUnifiedTests` **10/10通过**；专项UI `testAccuracyStandardRetryAndRecordedPlayback` **1/1通过**，一个用例实际运行2D、3D。
- 单元覆盖：回放停止/后台恢复球位、姿态、可见性、透明度、相机、方向/力度草稿，保持首杆记录与额度；2D不切3D；切账号后旧回放失效。
- UI覆盖：初始禁用态、标准标签、实打后两按钮可用、自然播放结束、主动停止、重打后再次击球、指标不变及结束面板。两模式截图已目视核对图标与样式。

- 终轮证据：`output/accuracy-retry-replay-20261021/final.xcresult`、`final.log`，图册`重打与回放.html`。初轮证据在`output/local-test-runs/edfcb9cd53864fb1a0e6688a8333c412/evidence/`。
