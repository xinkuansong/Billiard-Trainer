# 翻袋解球 · 目标球切换 · 2026-11-03

状态：实现及固定快照定向验证完成。用户反馈“翻袋解球里，现在不支持切换目标球啊”。范围是工具 BankShotView，非翻袋练习／解球练习。

## 行为与根因

原 SolverStageHosting 默认目标为8号、selectableBalls为空、球库已上桌球只闪动；Bank沿用该固定合同，无法选其他球。Bank现在提供自身目标状态和可选球：点桌上可见号码球，或点顶部球库中已上桌号码球，立即改为目标；原目标保留原位置成为障碍。母球、未上桌球、播放中和拖动中不能作为新目标。空球库槽仍先摆球，当前目标不能被移除；原目标可移除和重新摆入。

求解态切换立即取消旧请求、清除旧结果并自动求解；自由态更新瞄准和预测。袋口、杆速、打点保持。共用球库调用宿主selectTarget，颗星仍保持固定8号合同。AngleTrainingScene.setPrimaryTarget只变角色，不重建、移动或隐藏节点。

球形快照新增targetKey；求解撤回、自由重打／回放及恢复球形使用当时目标身份恢复。自由击球物理事件匹配使用实际号码，不再硬编码8号。没有修改物理参数、求解路线准入或页面布局。
