# 分离角／加塞吃库图谱：库数显示

2026-11-01。用户确认需求并授权实施。当前：实现、三尺寸定向验证与原图审查完成；真机及用户体验待验。

## 已确认合同

两页在杆速柱下方标准击球槽提供库数入口，默认1库。单选菜单只有1/2/3/4库，复用灰框／绿勾，不含“关闭”选项；菜单右缘对齐未缩放2D桌框右缘，3D使用相同HUD参照。点外关闭且消费触摸，选中后收起观察轨迹。

可选上限取当前球形、力度、打点参数下全部八条真实母球轨迹的碰库最大值（封顶4），不随左侧显隐筛选变化。选N库表示每条轨迹显示到碰球后第N次碰库；不足N库者显示至自己的真实结束点。全部不碰库时四项全部禁用、所有轨迹完整展示。调参使当前选择超限时回落到最大可选库数；零库时保留默认1的入口标签但无选中项，恢复可碰库后仍从1开始。

分离角保留碰球后主轨迹；加塞图谱保留首库前细线、首库后主线的色序及线宽。无碰球的低速轨迹显示完整母球路径。选择1库时恰好截止首库，不额外延长出库段。球位、求解瞄准/挤偏补偿、速度范围、左侧八档及至少一档规则保持。

时间与单位：真实事件time为秒，SceneKit X–Z台面、Y向上、米；用按时间的解析回放采样及精确事件端点截断，不用空间最近点寻找多圈路径终点。界面位置是窗口pt，从Foundation桌框和标准动作槽计算。
