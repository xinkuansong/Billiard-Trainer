# 训练设置恢复默认 · 2026-10-26

状态：实现及模拟器验证完成；自定义球形模板管理页按用户要求排除。真机/VoiceOver/发布未验收。

## 范围与合同

- 共用 `SceneTrainingSettings`：2D/3D角度、瞄准点、准度、分离角、两球走位，共10入口。
- 独立 `SnakePracticeSettingsView`：蛇彩练习的首次进入和练习中重开设置。
- 自定义球形模板管理页按用户要求不增加；角度预测/平面瞄准点无独立训练设置表单。自定义计划的动作剂量编辑属于计划编排，不属于本轮练习入口设置。
- 表单最底部独立次级动作“恢复默认设置”；不弹确认，短暂提示“已恢复默认设置”。
- 仅修改当前草稿。开始/重新开始成功时沿现有路径保存；取消不影响原设置、当前题目或记录。
- 不修改历史成绩、练习额度、自定义球形模板、布局模板或全局显示偏好；生成中禁用恢复。

## 默认值真源

| 页面 | 恢复值 |
| --- | --- |
| 角度、瞄准点 | 20题；角度/母球距离/距袋/袋型/库边距离随机 |
| 准度 | 同上；击球高低杆/左右塞开启，出题高低杆/左右塞关闭 |
| 分离角、两球走位 | 20题；近直/小/中角度；其余球形条件随机；出题两轴开启；击球开启、中杆参考关闭 |

| 蛇彩 | 5颗、从右到左；开始时沿既有逻辑生成球号 |

首次加载和恢复共用路由默认值，不删除偏好键来触发重置。
