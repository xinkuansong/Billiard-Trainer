## 2 入口与模式

正式名称统一为“防守练习”，在练Tab增加独立入口；最终分组服从练Tab分组方案，卡片与翻袋、解球保持同级。动作库防守方式可提供“去练习”关联入口，返回原来源。第一版不把动作库八杆示范直接当成八道合格计分题：其中有连攻带防及教学示意，需逐题资格判断。

| 项目 | 轨迹模式 | 自由模式 |
|---|---|---|
| 任务 | 按目标路线练习一种防守的执行 | 自己决定方向、力度和杆法 |
| 题库 | 5698条精选候选中通过参考解准入的子集 | 清理后59000条开局候选，经App读取与可作答检查后使用 |
| 作答前 | 展示目标路线、相关球目标停点；不公开出杆参数 | 不展示参考解、推荐停区、实时防守分或碰后预测 |
| 作答后 | 轨迹完成度、各球误差与实际防守效果 | 同源实际防守效果与对方进攻分析 |
| 参数 | 方向、力度、打点由用户调整，不自动套答案 | 同左；球位仍固定 |
| 参考 | 可切换本题合格目标路线并单独记录首答 | 首答后可查看已有参考；无参考时不显示虚假示范 |

“自由模式”表示自主防守，不表示任意摆球，也不等于“不限题持续练习”。训练模式、训练量、正式视图是三个独立维度，避免使用同一个“自由”开关混淆。

默认建议轨迹模式、15题、球形综合、击球过程开启；前提是轨迹库达到准入要求。尚未满足时内部开发使用明确标注的试点题，不以候选总量宣称正式可用。

| 状态 | 球桌与左侧 | 右侧与主动作 | 允许的操作 |
|---|---|---|---|
| 选题 | 继续显示设置或上一题结果，忙反馈在原动作内 | 正在准备 | 返回／取消准备；不先清掉上一题 |
| 作答 | 初始球形；题目进度与模式对应统计；方向尺 | 打点、杆速、击球 | 调参、观察、允许的显示设置及测量 |
| 计算／击球 | 冻结本杆输入，展示实际运动；不提前公布结果 | 原主槽忙态 | 防止重复提交；禁止改题、改参和布局 |
| 结果 | 停稳球形与实际轨迹；左侧方向尺位置切换评分区 | 杆速／打点只读，主动作下一题 | 重打、回放、评分详情、结果分析、已有参考 |
| 重打 | 恢复本题起始球位，方向尺恢复；保留上一杆参数 | 击球 | 上杆结果保留但不伪装为本杆预测；首答不重置 |
| 回放／参考 | 独立快照播放，不修改用户出杆参数 | 停止 | 停止或播完恢复进入前现场及结果 |
| 末题结果 | 完整保留本杆终态与分项 | 查看总结 | 仍允许重打与回放，不自动跳总结 |
| 总结 | 模式对应统计与各类覆盖 | 重新开始／完成 | 重新开始经过设置及额度事务 |
| 失败 | 保留可恢复的输入或结果，解释原因 | 重试计算／重试保存 | 技术失败不计0分、不重复扣次数 |

球桌、球库、右下主动作槽及标准左下重打槽在作答／结果切换时不跳位。结果页仍是球桌页面，不增加每题一次的导航推入／返回。

左下保持“重打”；其下辅助工具根据阶段使用“测量”或“回放”。参考打法在结果分析入口内切换，避免把多个主按钮铺到台面。第一杆之前重打不可用。方向尺与杆速有效轨道端点按共享布局成对对齐；结果占用方向尺信息区，但不通过增加统计行把另一侧尺向下挤。

顶部球库按本题实际目标球显示，母球不占槽，最大容量按配置为1／2／3球预算，进袋保留原槽并淡化。当前合法首碰目标用既有天蓝角色；“我方／对方／共同黑八”用明确文字及可访问性名称解释，不把下一球金黄色直接改成“对手色”，不在台面新增常驻角色圈。三球题固定为我方1、对方9、黑八8；不能靠花色和数量临时猜球权。

新题杆速沿普通2.0默认值，打点沿共享可行域；初始方向只按合法目标的中性规则初始化，不取参考解。重打、回放和续练恢复保存值，不用默认覆盖。

## 4 详细评分页

结果区立即显示核心判定；更多说明沿现有评分详情组件展开，不依赖三秒提示保存结果，也不把全部说明挤入狭窄侧栏。

| 结果内容 | 轨迹模式 | 自由模式 |
|---|---|---|
| 本杆状态 | 合法／犯规／未完成纯防守／技术上未评出 | 相同 |
| 主要训练指标 | 轨迹完成度 | 完整直击遮挡，或对方容错角与舒适分 |
| 防守效果 | 始终独立呈现 | 始终呈现 |
| 详情 | 母球与相关目标球路线及停点误差，防守结果解释 | 对方合法目标、最有利袋口、容错角与舒适分解释 |
| 复盘图层 | 目标／实际路线对照；对方进攻分析 | 实际路线；对方进攻分析；已有参考 |

### 4.1 判定顺序

先取得完整停稳终态与真实事件，判首碰、碰后碰库／合法入袋、母球落袋及黑八终局；再判本练习的纯防守要求；最后评价对方。规则证据来自引擎事件，不从渲染折线推断碰撞先后。

合法先碰本方球后碰动其他球不自动判犯规；不能照搬旧遮挡库“对方球不能动”的内容限制。合法传进对方最后彩球后，对方下一杆改评黑八。进本方球继续进攻属于未完成本题纯防守目标，不冒称普通犯规；黑八终局单独解释，不算成功防守。

犯规和任务未完成应优先展示具体原因，不能仅显示几何上形成的100分。仍可在复盘解释轨迹，但不纳入成功防守。计算异常／未停稳／评估不完整显示“暂未评出”，不得给满分或伪装玩家失误。

### 4.2 防守效果沿原会话

- 完整直击遮挡：合法且任务完成后显示“防守效果 100分 · 完整直击遮挡”。指直接接触被完整遮挡，不表示对手解球必败，也不评价全部后续战术收益。
- 非完整遮挡：显示“对方最大容错角 ××°”“对方最高舒适分 ××”，两者均越低表示该维度进攻越困难；不能统称进球率。细数值避免四舍五入成0°，低于有效分辨率用范围或未评定表达。
- 分别取对方所有合法球、六袋中的最有利指标；两个指标若来自不同球袋，详情分别标明，不能拼成一条不存在的“最佳路线”。点击其中一项才叠加对应球袋与进攻线。
- 没找到直进路线不等于完整遮挡。搜索不足、数值异常及选袋疑点保留未评定状态；只遮住一部分直击接触域也不能给全挡100。
- 长台、角度限制、母球靠库、目标球靠库、处理袋口威胁只作为解释标签，允许同时出现，不叠加奖励。
- 开局认可的容错角≤0.008°、舒适分<10是来源筛选范围；20题参考采用过同值预览门槛，但尚不是本页正式过关线。非遮挡不自设优秀／及格阈值。

非遮挡统一百分制是后续需要标定的一个具体缺口，不影响按已确定双指标做详细结果页。首版统计不把全挡100与其他未知百分制混算“防守均分”；先统计首答全挡率、犯规率及可评估的双指标分布，并明确有效样本数与未评定数。

### 4.3 轨迹执行沿两球比较方法扩展

现有两球借用`SeparationTrajectoryScore`的等弧长RMS比较，当前映射为`100 × 2^(-RMS厘米/20)`，带“目标球必须进袋”的业务门。防守只复用路径比较能力，不能原样套进袋门。

建议第一版分别比较母球及目标路线中实际移动的各球，逐球展示完成度与终点偏差；静止障碍球显示是否被移动及偏移，不参与平均来稀释误差。防守轨迹总完成度如何汇总这些逐球值须用代表题标定，页面可先表达逐球结果，不临时发明权重。球号身份固定，不能为了相似度把两球互换配对。

与目标路线相差很远但防守有效：轨迹执行分较低，防守效果仍认可。路线接近但留下袋口球：轨迹完成度与防守效果分别揭示问题。这遵守原会话“双评价、不硬合成总分”的决定。

## 5 训练设置

使用完整原生Form：iPhone竖屏实色页面，iPad横竖均可，隐藏Tab栏。标题居中，左侧返回／取消，右侧开始训练／重新开始。训练条件用卡片外Section标题、统一紧凑行高、整行可点、综合置顶及灰框／绿勾，不额外加一层44pt内容高度。

轨迹说明建议：“观察目标路线与停点，调整方向、杆速和击球点完成防守。击球后分别查看路线完成情况和留给对方的进攻机会。”

自由说明建议：“自行选择防守打法，合法击球后观察对方还能怎样进攻。完整直击遮挡记100分，其余局面以对方的容错角和舒适分说明防守效果。”

自由模式隐藏思路及目标路线杆法筛选，并从出题请求中移除它们，不能隐藏了UI仍过滤题库。训练设置的2D／3D共用，显示偏好单独按共享Store管理。

首版不提供简单／中等／困难，因为尚无人机一致的难度标定；不提供目标袋类型、目标球到指定袋距离，因为防守没有指定进球袋；不提供第一杆切角筛选，因为用户自由选择碰撞厚薄，不能将开局进攻切角当成本杆防守切角。轨迹参考的库数、切角、简单路线要求先作生产准入，不堆成用户出题选项。

条件不足时显示“当前条件暂无可用题目”，允许保留草稿调整；不可暗中放宽或自动混入无参考题。只有题目准备成功、额度事务可提交后，才保存草稿并开始新轮。取消、恢复默认后取消、会员页取消均返回原题／原阶段／原参数。

建议本项目普通练习每天15个新球形，轨迹／自由与2D／3D共用，持续练习Pro；这是新增项目的产品提案，不宣称已有权益配置。重打、回放、同题换目标路线不重复扣新球形次数；真实新题激活的持久凭证与首答成绩分别管理，恢复不重扣。

菜单以现有显示能力为基础，显示项在前、练习管理在后。一般开关选档保持菜单；导航／播放动作按用途关闭；外点关闭消费触摸。

| 视图2D／3D | 纳入 | 读取共享偏好；切换保持题目、模式、输入、首答和结果；转镜／播放中禁止冲突操作 |
| 打点盘透明度 | 纳入 | 本页覆盖→通用→共享初值；作答打开时同步展开实际大盘，关菜单保留大盘；结果只读，不给可写盘 |
| 台面网格4×8 | 纳入 | 继承共享偏好，只改变显示；不触发重新评分 |
| 瞄准特写 | 按业务调整纳入 | 作答拖方向尺时按共享触发；只放大已有球位、杆向及固定几何基准，不露参考输入或实时结果；忙态隐藏 |
| 操作布局 | 纳入 | 注册独立页身份及正式视图模板；作答态可编辑，结果／回放／忙态禁用，不把评分文字当可拖按钮 |

## 7 题库抽题与统计

当前四类不含母球的开局候选分别为1198、10023、10023、37756；轨迹候选为1198、1500、1500、1500。自由库证明开局进攻困难，不保证每题存在容易执行的好防守。因此自由模式不要求达到某个门槛才能进入下一题；轨迹题必须存在真实可执行且说明清楚的目标路线。

综合建议先平衡四类，再在类内抽题，避免三球因数量占比主导。15题按4／4／4／3分配，轮换少一题的类别；只选部分类型时近似均分。类内不放回，并按原球形及镜像族避免相邻近似题；不把不同球权的同摆位合并成同题。战术多标签只参与覆盖，不让标签多的题获得更多抽取机会。以上抽样是本页建议策略，不改动其他练习。

轨迹一题可含多条已验路线。默认选一条作答，其他目标路线通过“目标路线1/N”选择；切换恢复初始球位，首答按题目＋路线记录，重打不覆盖。轮次先汇总每题已答路线首答，再按题平均，避免路线多的球形权重更大。若逐球完成度尚未汇成总分，则统计也按逐球指标分列，不虚构轨迹均分。

自由模式首答按题目身份冻结；本题复练与轮次首答分别存储。全挡率分母使用可判定且正式提交的首答，犯规计为未全挡，技术未评定单列；双指标统计标明非全挡有效样本量，不能将全挡的缺值直接填0混算。末题可复练，显式查看总结才离开现场。
