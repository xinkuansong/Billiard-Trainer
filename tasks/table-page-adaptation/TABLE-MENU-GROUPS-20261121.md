# 桌边「更多」菜单分组

2026-11-21。每日清台是样板。本轮推广到其余 24 个公开入口，自定义球形另核编辑态。范围从打开球桌右上「更多」开始。答题和训练开始前的设置表单、「我的」里的通用设置、照片导入流程和内部出片台沿用各自入口。

## 命名与顺序

每组有可读标题和独立卡片，只显示当前页面、当前状态实际拥有的项目。卡片内沿用原有按钮、选中值及禁用理由。下表顺序也是页面同时拥有多个组时的相对顺序。

| 组名 | 放在这里的原有项目 |
|---|---|
| 桌面显示 | 视图、台面网格。球形编辑的「恢复全桌」调整观察范围，也放在这里。 |
| 击球显示 | 瞄准特写、目标球接触点、轨迹显示、分离角辅助线。 |
| 教学图解 | 角度与瞄准的瞄准线、进球线、角度、假想球、3D 假想球和两种管道。 |
| 试打模式 | 动作试打按「击球模式 → 瞄准模式」排列，序列或自由模式会决定下一行是否可用。 |
| 瞄准辅助 | 自由／进袋瞄准模式、自动推荐。 |
| 操作控件 | 打点盘透明度、操作布局。 |
| 求解范围 | 走位求解的「允许左右塞」「仅基础走位（≤1库）」。 |
| 求解结果 | 分离角与走位有多个翻袋解时出现的「下一解」。 |
| 本次练习 | 训练设置、结束练习、当轮覆盖说明，以及本页已有的回放、上杆成绩、重打、换一局、其他防守线路等。 |
| 球形操作 | 清空、恢复、另存球形，以及编辑桌的吸附、辅助线和目标球操作。翻袋与颗星解球的自由态分别保留「恢复球形」和「恢复默认球形」。 |
| 使用说明 | 原理说明、操作说明、试打说明，沿用各页原行名。 |
| 玩法 | 始终排在最下面。每日清台为开球玩法、评分模式，已有上杆评分时随评分模式呈现。其余公开入口仅放各自已有玩法。 |

## 影响项

- **TP19**　共用组件负责组名、组序与卡片样式。页面仍负责原选项、可见条件、数据读写、禁用条件与回调。角度和瞄准点练习的本轮覆盖说明作为正文留在「本次练习」下。
- **TP20、TP21**　有返回箭头的下级选项在一级菜单上方打开，返回后沿用进入前的滚动位置。独立弹层和原有训练表单沿用原入口、关闭与取消行为。
- **TP27、TP35**　首屏、滚动后的分组、设置项的标识／名称／值／启用状态以及手机和平板代表布局分别验收。模拟器截图按设备与方向标注。

## 验证结果

- iPhone 17 Pro Max，iOS 26.2 模拟器。24 个推广入口连同自定义球形编辑态，共核对 195 条可操作行。每页按标识逐项比对显示文案、值、启用状态与控件类型。两项当轮范围说明保留原文。另核每日清台，原有标题及项目的完整顺序一致。26 个菜单状态包含 2 至 8 个可见分组，共 54 张手机原生截图。
- 分离角与走位、走位求解、每日清台的「开球玩法」，走位求解 3D 的「轨迹显示」和动作试打自由态的「瞄准模式」，逐个打开并返回，入口中心纵坐标差均为 0 pt。五个选项列表逐行核对与上一版一致。多球自主走位、动作试打自由态分别核对了条件操作项。
- 12 个原有「训练设置」入口分别打开原表单、点击取消并回到横屏球桌。XCUITest 在手机及 iPad Pro 11 英寸 M4 上各通过 2 项，覆盖短菜单、长菜单底部原位返回，以及翻袋与颗星解球自由态的两个恢复动作。iPad 在横竖屏复核分离角与走位、进球容错角，另有两张解球自由态横屏图，共 7 张可用图片，横屏整屏测试仍以通过的 XCUITest 为准。
- 当前证据来自 iOS 26.2 模拟器。条件触发的「下一解」和上杆走位评分按源码核对，未在本轮逐一制造对应球局。真机与其他字号未实测。
