# 自定义球形 · 15颗且球号唯一

日期：2026-10-28。状态：实现及定向验证完成，未发布。用户原话：“球形数量默认最多15颗吧，不允许重复，这种才符合实际的情况”。

## 当前合同与实现

- 1颗母球＋1～15颗目标球；目标球1–15号每号一颗，母球另计。无新增开关或Pro限制。
- 编辑球库已在桌的球点击选择，不新增同号实例；删除后可重新添加。添加入口防御性拒绝重复/超限，保存与开始同样校验。
- 旧重复/超限模板保留原始球位、名称、实例身份及辅助线；选择页提示原因、禁止开始，仍允许打开编辑并逐颗删除修正。不自动删球/重新编号。
- 新保存、复制、另存必须符合新规则。`validated()`保持历史解码；`validateForPractice()`执行新规则；`validateForSync()`保持旧25球协议，避免旧待同步操作或其他设备旧档阻塞读取。本轮未改服务端或发布协议。
- 自由击球、重打、回放、恢复初始球形、练习副本不覆盖原档、同账号同步同意门禁保持。

源码：`CustomFormationLibrary.swift`（规则）；`CustomFormationSession.swift`（添加/保存）；`CustomFormationPracticeView.swift`（提示/开始）；`CustomFormationStore.swift`（写入边界）；`FreePlayView.dailyPaletteBall`（仅自定义编辑分支选择已有球）。
