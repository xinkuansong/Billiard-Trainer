# 操作布局返工：最终人工验收

版本：v2.1，2026-10-19。状态：**新版正在实施，R00–R07已完成开发与可执行验证；以下真实人工项目全部待验。** 需求以 [返工方案](../TABLE-CONTROL-LAYOUT-PLAN-20261017.md) 为准；旧 B 批次证据不计入本清单。用户已明确“继续全部开发，VoiceOver 留作最终人工验收”，本清单不阻断可执行开发验证。

## VoiceOver 实机操作

覆盖每日清台/自由击球、思路训练、角度答题和瞄准点答题代表入口；分别记录 2D/3D、设备方向和字号。

1. 从页面“更多 → 操作布局”进入，朗读当前页面和固定模式；模板列表焦点正确，练习层不进入焦点循环。没有个人模板时只有本页默认，其他页面默认不出现。
2. 保存个人模板后，在另一页能找到它，名称带 2D/3D 后缀；异模式模板说明不适用原因，不自动切换练习模式。
3. 点击个人模板，可选“使用当前模板”或“在此模板基础上修改”。分别验证应用和独立草稿，不能将点选卡片直接当作应用。
4. 不依赖拖动，选择**单个按键**，调整水平位置、垂直位置和连续大小；能读出选中项和当前值，邻键不跟随。重叠控件可从列表找到，支持撤销/重做及恢复选中键。
5. 安全区外位置能保存，不宣读为“非法”或自动恢复；提示不能遮住确认/取消。编辑工具条与恢复入口可达。尺寸与触点是否适合实际握持由用户评估，系统手势限制如实记录。
6. 基于模板修改后取消，原页面/模板保持；保存新模板后原模板不变。改名不改变模式，删除模板不重排已应用页面。冲突、保存失败和恢复提示完整可读，失败不丢草稿。
7. 应用到异页面时，仅共同按键改变，目标独有按键仍保持原值；模板中的来源独有按键不会出现在当前页。另一模式和其他页面保持。
8. 保存/取消后焦点合理返回，训练状态/计时恢复；实际击球、规划动作、输入与提交执行一次。编辑过程不提交答案、不触发击球、不改变分数/题目/球形。

## 真机与用户体验

- 对照同一页面“进入前 → 编辑时收起工具 → 保存返回”：球桌/球形、球库、设置入口、帧数等读数、左上标题/返回和其他原本可见元素完整呈现，构图不被压缩；移动控件原位无残影。移动/缩放后的可见位置、大小和遮挡关系与保存结果一致，取消恢复原布局。编辑时原返回/设置按钮可见但不误触其业务动作。
- 在用户实际设备上直接拖动单键，斜向移动实时跟随；缩放实时生效，保存、退出重进、重启后位置/大小保持。
- 用户将按键放到安全区外、贴边或有意重叠，确认应用不干预设置；记录系统手势区域的实际响应，不宣称 App 可以覆盖系统保留手势。
- 核查普通操作命中、连续仪表输入、展开面板与相机按钮；缩放不能改变业务输入含义。检查手机握持、iPad 横竖、实际窗口变化及大字号。
- 完整执行“本页默认 → 自定义保存 → 另一页使用 → 基于该模板修改另存 → 返回来源页应用新模板”，复查原模板、目标独有控件和 2D/3D 隔离。
