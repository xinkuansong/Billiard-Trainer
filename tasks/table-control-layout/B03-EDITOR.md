# B03：每日清台编辑闭环

日期：2026-10-18；状态：✅ 按v1.2技术实施与可执行验收完成；真实VoiceOver保留最终实机人工验收，不代表最终体验认可。真源为[方案B03](../TABLE-CONTROL-LAYOUT-PLAN-20261017.md#b03-轻量编辑器与每日清台闭环)。

## 实现与边界

- 页面更多菜单中的“操作布局”；忙碌检查包含击球、计算、播放、相机过渡、拖球/拖尺/拖杆速、临时俯视和决策状态。
- 原页面和SceneKit实例继续存在；编辑只暂停Scene，独立展示模型持有方向、杆速、打点和无渲染场景的相机控件数据。原场景输入暂停，退出恢复先前暂停状态。编辑器使用独立UIHostingController子容器承载模态辅助功能和确认弹窗，原训练控制器不离页。
- 草稿使用独立归档快照，包含撤销/重做；共用及单模式编辑，有限移动、左右交换、组间顺序与恢复。保存通过事务落盘后才发布；另存合入当前域覆盖、原子清除已合入项，保留其他域。
- `ActiveVisitClock`在同一次前台访问累计有效秒数；布局暂停不落tool行、不重复取整。真实离页/后台仍按既有规则分段。每日计时复用幂等flush/resume，后台回编辑器不恢复训练。
- 编辑卡位于左右操作列间，最大430pt用于表单阅读；纵向容量不足滚动，按钮至少44pt。原球桌/布局Foundation不受编辑卡影响。方向改变时保留原草稿，回原方向保存，不暗中换存储域。
- 本批只开放每日清台；自由/思路正式编辑及共享选择属于B04，集中模板管理属于B05。

- r03/unit-test.log：iOS定向63项0失败，覆盖12项存储/草稿/时钟、8项排布、20项每日Controller与23项既有tool/cognitive记录。生命周期包装成功。

- r01小屏首次真实入口可见，独立预览控件的AX标识被父容器传播覆盖；测试失败并保留xcresult/连续录像。补显式container层级，避免标识覆盖。
- r02小屏可进入预览并展开打点；取消后编辑层未关闭，测试在再次打开入口处失败。发现背景原控件仍暴露于AX、模态traits使测试将整层识别为Alert并尝试中断处理。改为编辑时忽略背景子树、独立预览限定AX层级、背景单独拦截触摸，取消父级空tap与Alert语义；r03复验中。

连续录像时长：小屏121.54s、标准119.62s、Pad横121.97s、Pad竖96.01s。编码检查通过；原始录像保留设备缓冲方向，不能把方向标签作为窗口证据，窗口以JSON和截图为准。

VoiceOver来源：[Apple Performing accessibility testing](https://developer.apple.com/documentation/accessibility/performing-accessibility-testing-for-your-app)。待验流程：进入编辑器→选择组→上/下移→撤销/恢复→保存或取消→焦点返回更多；确认背景训练控件不混入、值和提示朗读正确。不用模拟器AX按钮点击替代这一流程。

恢复方法：每日清台更多→操作布局→恢复本页→“本页使用球迹默认”（解除模板并清本页覆盖）或“恢复本页跟随”（跟随本类默认）→保存→仅保存到本页。放弃未保存修改点取消并确认放弃。
