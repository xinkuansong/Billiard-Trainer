# 每日清台操作布局：Figma 单页试用

2026-10-19，用户授权：只改每日清台，工具条更小、可拖动、可收起，先用户测试，其他页面不推广。

## 设计与实现契约

- 参照 [Figma 2:2](https://www.figma.com/design/FczcEQQAdTiztoeOjJT3No?node-id=2-2) 的双行工具条；原生球桌、球库、标题返回、设置和状态信息继续呈现。
- 最新简化决定：每日清台进入即编辑当前 2D/3D 布局；列表仅本页本模式的默认和个人模板，取消共享及共有键说明。每日模板不再出现在其他页面的个人库。旧其他页面编辑器不推广，本次不删除或改写历史已应用快照。
- 初始位置贴球库可见下边沿，不使用球库扩展触摸框；用户拖动后保留其位置。背景采用 regularMaterial，读取页面外层的深浅主题，减少透明度时使用语义实底。
- 不提供菜单选键：直接手选画面按键，滑杆立即显示被选键自己的大小，切换选择不改已有位置/大小。模板/重置仍为工具条附近的小菜单，容量不足滚动，靠底向上展开。
- 个人模板右侧「⋯」只提供使用、修改、置顶/取消置顶、删除。修改保存更新原模板；取消不写。置顶持久化并排在个人列表前。删除确认后保留当前页面已应用布局。
- 工具条 480×104pt 上限，收起 196×52pt，独立 44pt 手柄拖动；窗口变化与展开后保持工具条可触及。按键自身不限制在安全区。
- 原地选中/拖动，大小滑杆、加减与精确数值；撤销、重做、恢复单键/全部、取消和另存模板保留。
- `page == .dailyClearance` 显式启用；其他页面继续原编辑器。本次不恢复 R08–R10 广泛推进，不关闭 FL-181。
