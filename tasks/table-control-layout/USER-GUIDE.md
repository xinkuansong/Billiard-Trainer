# 操作布局使用说明（旧实现历史记录）

> 2026-10-19：以下描述旧 B 批次实现，组级移动、区域限制和共用层等已被用户否定，不能作为返工后的使用说明。现行需求见 [v2.0 返工方案](../TABLE-CONTROL-LAYOUT-PLAN-20261017.md)。新版实现与使用说明尚未完成。

## 从哪里进入

- 练习中：页面右上“更多 → 操作布局”，直接调整当前页。击球、拖动、相机过渡等操作完成后可进入。
- 集中管理：“通用设置 → 练习显示 → 操作布局”，查看、复制、改名、删除模板和管理页面引用。

## 调整和保存

1. 选中控件组，用拖动或上移/下移、换侧调整；相机使用“相机换侧”。球桌、顶栏和球库不跟随移动；越界或遮挡会拒绝该次调整。
2. 选择共用或当前2D/3D层；固定2D/3D答题入口只展示本入口可用的模式。独立预览不会击球、答题或改变练习。
3. “仅保存到本页”只改这个入口；“另存为新模板”生成独立模板，可再应用到适用页面。
4. 使用已有个人模板时，“更新共享模板”先展示影响范围；其他页面自己的覆盖项继续保留。需要重新跟随时，恢复对应组/层或本页跟随。

## 恢复与边界

- “恢复本页 → 本页使用球迹默认”恢复该页内置布局；其他页面的引用和微调保持。
- 手机横屏、iPad横屏和iPad竖屏分开保存。缺少某一方向配置时使用该方向默认；缩窗临时夹紧或回退不会覆盖已保存意图。窗口过小时显示“扩大窗口继续练习”和返回入口，放大后恢复原练习与布局。
- 不适用控件保留在模板中，不在当前页强行出现；回到适用页/阶段后按能力应用。
- 模板保存在本机App数据中；本轮没有跨设备云同步、导入导出、任意控件缩放或版本历史浏览。
