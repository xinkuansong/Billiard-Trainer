# 操作布局：最终人工验收

状态：待验。用户于2026-10-18明确允许全部开发继续，真实VoiceOver留最终人工验收；这些项目不阻断B04–B12技术实施，不标记为已经通过。

## VoiceOver（实机）

至少覆盖击球、规划、角度答题/瞄准点答题代表入口；固定2D/3D的独立身份仍应核对。

1. 从页面“更多→操作布局”进入，焦点落在编辑器；训练层不进入当前焦点循环。仅用朗读导航及按钮，完成选组、上移/下移、合法左右交换、撤销、恢复。
2. 能读到当前模板、当前设备方向、共用/仅2D/仅3D范围、本页微调、空间不足反馈。必要动作及返回入口可达；非法位置不能保存。
3. 交互预览不提交答案、不击球、不改变原球形或训练参数。返回编辑后焦点恢复合理。
4. 编辑→管理模板→模板详情→独立预览→编辑，焦点仅在最前层。返回后仍为原训练，方向不改变。
5. 另存、更新共享模板、删除替换、冲突重载/草稿副本的影响说明、取消和确认均能完整朗读。取消不得静默清除微调。
6. 保存/取消回训练后焦点回“更多”；实际击球、规划动作、答题提交/下一题仍执行一次。题目、分数、训练阶段保持原值。
7. 手机横屏、平板横竖与大字号各选一轮；窗口空间不足时能找到返回操作。实际握持与触觉另由用户确认。
