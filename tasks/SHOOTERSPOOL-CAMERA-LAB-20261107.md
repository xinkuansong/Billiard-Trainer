# 球迹独立研究版｜瞄准、站立与全局观察

2026-11-07 · v2，供产品评审。本轮交付交互方案。研究入口使用每日清台的真实桌面、开球和普通杆；开球截图只用来确认按钮位置。正式 App 的相机政策仍以 TP17 为准。

## 1. 玩家首先要能做什么

拿一杆远台薄球举例：在进袋模式选球选袋，站在母球后横滑查看袋口，保留原杆线；俯身后拨动方向尺，从这条线上微调厚薄并进入临时自由模式，之后也可横滑继续调杆；点眼睛，移到目标球旁看它和袋口的关系；再点眼睛，回到刚才的姿势、倍率和真实杆向；出杆后可以观察母球跑位。下一杆从真实停点继续。整个过程由玩家决定何时改变击球方向、何时只移动视线。

ShootersPool 官方基础操作以鼠标横移调瞄、纵移调观察俯仰、左键配合前后移动调远近。观察操作单独进入，V 配合鼠标改变观察目标，然后可以转动、俯仰、缩放，S 回到击球。出杆后也能观察运动中的球。上述为公开操作合同；官方资料没有给出瞄准眼位轨迹、焦距曲线或手机手势。下面的手机按钮、复位规则和时间都是球迹研究提案。[基础操作，约10秒起](https://www.youtube.com/watch?v=RKlqDBkHF_Q&t=10s) · [改变观察目标及绕桌，约4秒起](https://www.youtube.com/watch?v=cpBGOqHQrs4&t=4s) · [归档的官方教程说明](../output/3d-scope-audit-20260912/reference-guides.json)

## 2. 三个主按钮与临时俯视

沿用截图从上到下的眼睛、站立、俯身；下方原有桌面图标负责临时俯视。常态亮一个主按钮，进入俯视时只亮俯视按钮。按钮可访问名称分别为「全局观察」「站立找线」「俯身瞄准」「临时俯视」，读出当前选中状态。点击按抬指确认，按下后滑出、系统取消或第二指打断，均撤销尚未确认的按钮操作。采用单击，不要求双击、长按或滑回手势。

| 操作 | 第一次进入 | 再点当前按钮 | 点另外一个按钮 |
|---|---|---|---|
| 俯身 | 从当前显示画面落到母球后方，以真实击球点、杆轴与合法抬杆为基准；同一杆优先恢复上次俯身倍率和俯仰 | 将水平视线对回当前杆线，并复位此姿势的观察倍率与俯仰；保留手调后的真实杆向。已经在标准姿势时静止 | 点站立，在杆线同侧抬高；点眼睛，记住当前俯身现场后进入全局 |
| 站立 | 从同一杆线后方较高处找线；同一杆恢复站立自己的倍率与俯仰。开球第一次进站姿可按球堆取一次初始构图 | 将水平视线对回当前杆线，并复位此姿势的倍率与俯仰；保留杆向。已复位时静止 | 点俯身沿当前杆线压低；点眼睛，记住当前站立现场 |
| 全局 | 记录从哪个人称进入。首次取桌心，按当前可见朝向就近选边居中，一次拟合完整桌框；横滑后允许自由看斜角 | **退出观察，返回进入前的人称**。如仍是同一杆且没有编辑，恢复进来前的视角；如杆向已改，沿最新杆向恢复姿势 | 直接点站立或俯身，去明确指定的人称；只走一次转场 |
| 临时俯视 | 暂存当前主模式、机位、观察点和未完成转场的意图，呈现现有俯视操作面 | **收起俯视，回到进入前现场**。纯查看时恢复实际画面；从转场中打开则恢复捕获帧后续接仍有效的目的地 | 俯视期间其余三个按钮禁用，收起后再选。点选球、选袋或合法摆球按页面已有权限处理 |

每次主动进入全局从整桌开始，方便再次找回桌心；在同一次全局观察中途打开菜单或临时俯视，则保留刚才看的局部。全局返回来源只有一层，从站立进全局再进俯视，退出顺序是「俯视 → 刚才的全局局部 → 原站立姿势」。无有效杆线时可看全局；依赖母球或合法眼位的人称按钮禁用，保留原因供辅助功能读取。切换后才发现目标姿态不可用时，继续显示原机位、原按钮高亮，不留下半途机位。

## 3. 手指在台面上做什么

**先看当前视角，再看本杆实际瞄准模式。** 在站立、俯身两种人称下，进袋模式的杆线由所选目标球和袋口确定，台面横滑只改变观察方向。自由模式的杆线由玩家决定，台面横滑才调杆。全局的台面手势在两种瞄准模式下都只观察；开球沿用独立的开球调向入口。显式切换模式、无合法进袋路线回退、换球和下一杆按现有业务规则处理。

**从观察接到调杆。** 进袋模式下，方向尺第一次产生有效角度增量时，以当前显示的真实进袋杆向为基准进入临时自由，首个增量只施加一次。若当时正转头看袋口，人称镜头从当前画面平滑对回新杆线；观察偏角不能算入击球角度。仅按住尺、零位移或起调前取消都保留进袋模式。拨尺结束后仍处于本杆自由模式；下一次台面横滑从刚调好的方向继续。进入或返回全局、俯视以及切换站立／俯身，只切视角，不恢复旧的瞄准模式。重新选择有效球袋或进入下一杆，由业务重新判定当前模式。

| 输入 | 俯身 / 站立 | 全局观察 |
|---|---|---|
| 进袋模式单指横滑 | 以当前眼位水平转头，保持杆线、白线、目标球、袋口及进袋模式；松手保留观察方向，再点当前人称对回杆线。横滑期间保持倍率 | 围绕观察点看球形；保持杆线及进袋模式 |
| 自由模式单指横滑（开球也可调向） | 向右滑，杆头瞄向当前杆线右侧；向左相反。按当前杆向增量计算，绕到另一桌边操作符号依然符合球员视角。站立用来找方向，俯身增益较低；方向尺用于最细调整 | 围绕当前观察点改变观察方位，初版采用拖动桌景的手感，例如把近侧的参照物向右带。观察半径、高度和镜头视野角保持。杆、选球、选袋保持 |
| 单指上下滑 | 上滑抬起视线以看远处，下滑压低视线看近处。固定眼位、倍率及杆向，滑到边界即可反向 | 上滑升高观察角，下滑贴近桌面视角；围绕观察点改变仰角，保持观察半径和镜头视野角 |
| 双指捏合 | 张开放大、合拢缩小。初版用姿势内受限的光学缩放，保持眼位与杆线；站立和俯身各记各的倍率 | 张开向观察点靠近、合拢退远，固定镜头视野角；与绕点旋转独立 |
| 双指平移 | 手指同向移动不改瞄准；识别到张合才缩放 | 桌面内容跟随双指移动，观察中心在台面平面内平移。可从桌心移到目标球与袋口之间，移动观察中心不触发业务选球 |
| 点球、点袋、拖球 | 点选与合法摆球沿用页面权限。合法拖球优先；其余有效空白区域按当前模式起手观察或调瞄。进袋模式点选走业务选球／选袋，纯横滑保留原选择 | 为避免看球被误判成换目标，研究版台面只观察；保留现有球形与标记。需要选球／袋或摆球，可点临时俯视或回到人称 |
| 左侧方向尺、右侧杆速与击球 | 进袋时拨尺切临时自由并微调；已经自由时，方向尺与台面横滑更新同一真实杆向。调速、打点不请求切镜 | 方向尺是明确调杆意图，进袋时同样切临时自由并微调，更新可见杆线，眼位仍留在观察现场；回人称沿最新杆向。杆速与打点同理。击球可用须满足正常业务条件 |

手机仲裁：按钮、尺和展开面板先接收触摸，底下的桌面不透点。单指起手先等系统识别和意图阈值，沿主轴锁到抬指；轻点、手指抖动和仅纵滑均不能把进袋模式切成自由。第二指落下时从当前状态重建双指基准；手指数减少后要求重新起手才继续单指调瞄。双指平移和缩放可组合，以两指中心位移和间距比分别计算，避免一次位移重复响应。全局移动中心遇到桌边／房间边界就停止该分量，反向立刻可动。

松手即停在最后有效位置。系统中断已开始的连续手势时，保留屏幕最后已经显示的杆向与姿势，清掉剩余触摸和速度；中断未达意图阈值的手势不改任何业务状态。暂定沿杆调瞄以投影桌框内空白起手，可连续滑出；全局观察可在未被控件占用的场景区域起手。真机重点检查小屏近库、杆速尺附近、两指变一指的误触。

## 4. 机位、切镜和中途反悔

- **沿杆**。母球与杆轴决定左右朝向，真实击球点与抬杆决定俯身基准。两个人称都用独立眼高、后距、倍率和俯仰，不经过旧凹面。横滑调杆时，允许眼位为维持沿杆对线作必要移动；禁止随方位自动补焦、缩放或重新拟合整桌。近库遮挡优先在该姿势进入时解算安全机位，用实际库体检查击球点和母球可读性；无可用姿态时给出上节的原位退路。手指调瞄穿过安全边界时连续限制姿态，不允许突然弹高，也不能阻止玩家把杆转回可用方向。
- **全局**。观察点、方位、仰角、观察半径和视野角分开存。初次全桌按屏幕可读区、桌框、房间内界一起计算；绕到斜角时允许桌面占屏自然变化。靠墙时优先限制观察点可达范围或本次绕转角度，保持最近有效位置，避免用自动推近镜头来补偿。缩放后的局部观察无需强行显示六袋。
- **切镜**。人称切换以同一杆线为轴连续升降，眼高和后距协调变化；全局切入／切出从屏幕当下的眼位、朝向和镜头视野角起步，使用最短合理转向，避免穿桌、穿库、穿墙。连续按 A→B→C 时直接从当前显示帧去 C，过时动画不得回写。按键动画中同一目标再次被点按时消费为重复请求，动画落定后才执行表中“再点”的复位或退出。这样快速连点眼睛不会在桌边折返两次。
- **手动接管**。转场开始即用新目标的按钮高亮；画面还在动时再拖，立即由新模式接管，从当前可见姿态连续交接到约束，首个有效拖动不跳到动画终点。取消旧动画后，其完成回调不能恢复旧高亮、解锁另一杆或触发出杆。切入未稳定前，“击球”临时禁用；最后真实机位与业务杆向已就绪才解锁，不缓存忙时点过的击球。
- **调校参数是试验值**。研究首轮可用同杆站起／俯身约 0.25–0.40 秒、全局往返约 0.35–0.65 秒作为起点，近目标缩短，已到目标立即结束。开启系统“减弱动态效果”时直接到位或极短过渡。小幅横滑先核实杆线与目标的关系，再调灵敏度；不得用整体降速掩盖横滑时自动变焦。

## 5. 杆与局面改变时如何恢复

| 事件 | 研究版行为 |
|---|---|
| 新开研究版 / 选练习球形 | 可直接进普通散局，也可选中八开球或贴库薄球；首入以站立显示真实杆线。开球适合较宽初始画面；普通杆直接按当前母球入位。研究样例可重置，以便同机对照 |
| 同一杆点球／点袋／换方向 | 点选建立新方向，站姿与俯姿按最新合法杆向连续对线，并保留该姿势手调倍率和俯仰。自由模式下台面横滑与方向尺共用角度增量；进袋模式下台面横滑仅写相机观察偏角。旧预测异步返回只更新对应杆与选项，不能把镜头拉回去 |
| 临时俯视内有编辑 | 仅改视图就原样返回；实际改了目标、袋或母球，人称按新球位／新杆线重新取景，保留可用的观察参数；全局恢复自己的观察点，必要时限制到合法桌面。严禁恢复旧业务球位、旧杆向或已落袋目标 |
| 击球和球在运动 | 点击球时冻结实际杆向、杆速、打点与出杆前镜头。用真实运杆、触球、碰撞、落袋和停稳流程。站立出杆留原站位；俯身出杆保留当前每日语义，指定球入袋时平滑站起，未发生相应入袋则等停稳；开球的研究默认是让玩家看完整个散球再站起。手动全局优先于自动站起。移动期间允许进全局并绕、移、缩，不开放调瞄、摆球或第二次出杆。此阶段退出全局返回冻结的出杆现场，等待停稳 |
| 开球交接 / 普通杆停稳 | 以物理结算后的每颗球的位置、朝向建立下一杆。人称按新母球和新杆向入站姿一次；全局仍由玩家掌控，下一次主动回人称时对准新杆。已消费的进袋、停稳、求解回调不得再切一次。犯规／自由球先交给页面处理，母球尚未合法落位时全局仍可看 |
| 上一步、回放、正式 2D 往返 | 上一步由业务先恢复正确的一杆，再按该杆状态恢复镜头。上一杆回放双快照：原杆视角开播，结束／取消均回到点回放时的观察现场，2D回放继续为2D。常驻2D往返与临时俯视分开；同一杆回3D恢复上次模式和机位，跨杆重算依赖球位的部分 |
| 菜单、后台、离开与重开 | 菜单覆盖时暂停输入；仅关菜单返回原画面。后台中断手势并冻结显示；回前台核对局与杆，恢复当前有效状态，重新取窗口尺寸。离开本局清理手势、过渡、观察来源和延迟回调；重开或换题不带入上一局的世界坐标。研究版重新启动后默认从场景选择进入 |

当俯身在落袋时已经自动站起，停稳只处理下一杆；如果用户正在全局观察，落袋和停稳均不能擅自退出。全局中允许按真实杆向击球，可直接从这个站位观察球路；方向尺明确修改过的杆向必须反映在随后的物理出杆中。弹窗、结算、犯规选择出现时仍由每日业务优先接管。

## 6. 实现边界与接线

研究代码和独立构建配置单列，独立名称、Bundle ID、数据容器；使用只读共享的球桌、房间、球杆、瞄准与真实击球／回放组件。研究版有单独的相机状态与输入协调，不改正式默认值、不把实验开关挂在正式设置。新模式和临时覆盖分别存储；每个快照记录局、杆、模式、观察参数和有效的返回来源。把球位、杆向、当前目标的写入留给原业务宿主。摄像机每帧只由一个呈现入口写入，渲染在手势、过渡和物理播放期间连续更新，静止后允许恢复空闲。

| 当前接线 | 研究版处理 |
|---|---|
| CameraRig 的曲面、合并模式和第一人称可用性相互关联 | 明确建模站立、俯身、全局。关掉曲面开关会影响人称入口，不能作为迁移办法 |
| AngleSceneView 负责点球、拖球、单指／双指仲裁 | 在业务命中检测之后按模式分派；自由观察和真实调瞄分别出事件；手势取消在同一处收尾 |
| 方向尺已经分开球与普通杆两条真实入口 | 先按本杆实际模式分流；进袋横滑只交给相机，禁止调用会切临时自由的 nudgeFreeAim；自由横滑和开球横滑分别复用对应角度入口和权限，使用姿势专属增益；不自己画另一根杆或预设假轨迹 |
| 每日业务有选球、重算、开球交接，以及统一的回放快照 | 旧请求按局／杆与用户意图代次作废；观察失效只更新机位，不隐式撤销本杆 |
| 教学、求解、固定题、视频导出也消费相机 | 此轮研究评估每日击球，不直接推广到这些宿主；后续单独审各页的合法操作 |

## 7. 研究版如何试，什么算通过

| 对照场景 | 必做动作 | 应看到 / 应测到 |
|---|---|---|
| 进袋 → 临时自由（站立、俯身各跑一次） | 选定同一球袋，先横滑观察，再轻触方向尺取消，再有效拨尺一次并松手，随后横滑、进全局、返回并实际击球 | 前两步对比模式、目标、袋、真实杆向均相同；首个尺增量从原进袋线生效一次；下一次横滑从新杆向累计；全局横滑前后杆向相同，回人称仍自由，最终实际出杆对准手调方向。再回进袋模式，横滑重新只观察 |
| 常规散局与远台薄球（自由模式） | 站立粗调、俯身精调、全局移到目标球侧面、点眼睛返回、击球 | 站立和俯身指同一真实落点；全局手势前后真实杆向一致；同杆纯往返恢复眼位、朝向和倍率；下一杆能继续实打 |
| 靠库、贴库和大角度切球 | 自由模式横向缓慢调杆后反向，分别在站姿、俯姿看母球、杆和远处袋口 | 观察整桌、近远库及背景的相对移动。固定姿势仅横调时记录视野角，不得自动变焦；镜头不得突然弹高、穿库或穿墙 |
| 中八开球与散球交接 | 从顶球正中调到一侧再调回，俯身击球；球在动时进全局并平移中心，停稳回站姿再打一杆 | 真实撞击和散球，对接真实停点；观察期间没有第二杆或旧镜头抢回。不能以单独的开球演示代替连续普通杆验收 |
| 输入冲突与连续切换 | 轻点球／拖母球、进袋横滑后拨尺切自由、两指缩放夹杂平移、按钮按下滑出、转到一半改点另一按钮 | 每种输入只消费一次；取消按键无跳镜，无误调杆和假切换。首个手动帧承接实际画面；忙时击球无延迟补发 |
| 现场恢复 | 全局局部→临时俯视→返回→返回；俯视里换球／袋；回放停止；2D往返、规则弹窗和后台恢复 | 纯观察还原现场，编辑后取新状态，业务快照与渲染机位可独立核对；旧动画不会再生效 |

试验按三个阶段串行：先用离线状态测试覆盖按钮转换及杆向/视图分离；再在模拟器跑真实手势和开球后至少两次可操作杆，录下杆线、球路、桌框及背景；最后交独立 iPhone 研究包，普通散局、贴库与开球都能直接选。手感评审只问三个具体问题：站着微调时像不像在找线、俯身时是否仍认得刚才那个瞄点、到目标球侧面看完能否一键回到刚才那杆。用户试用后再定增益、眼位和过渡时长，再决定是否进入正式设计评审。

## 8. 首个可安装研究包

手机上显示「球迹视角研究」，标识为 `com.xinkuan.qiuji.shotcameralab`。入口可以直接重开普通散局、贴库薄球和固定种子的中八开球。同一局的后续球位、杆速、打点、规则和落袋由每日清台宿主结算。每次从选择页进场都重新载入样例，方便在同一真机反复对比。

研究版生成器 `ruby research/shooterspool-camera-lab/generate.rb` 在 `build/shooterspool-camera-lab/` 生成独立 Xcode 工程。仅构建目录接收每日桌面的研究补丁。研究相机有单独的可见镜头；手势转头、俯仰、变焦和全局绕点分别维护。普通杆与开球的实际调向分别进入原有的 `nudgeFreeAim` 和 `nudgeAim`。立姿／俯姿各自记住观察偏角、倍率和俯仰。

真机试用时，先在「普通散局」横滑，确认杆线与目标关系，再拨左侧方向尺，接着横滑、点眼睛观察并返回，最后击球。贴库样例用于看低机位和背景的相对运动；开球样例用于看运动中转全局后的散球交接。

本次按手感原型交付。眼高、后距、增益和切换时间均为研究值。正式回放与上一步的双镜头快照、后台切入时的逐帧恢复、不同手机尺寸和连续手势边界仍需专项验证。

iPhone 16 Pro（iOS 27.2）最终版本实跑三项 UI 测试通过。普通散局核对进袋横滑保留杆向、轻点方向尺、有效拨尺切自由、横滑继续调杆、全局和俯视双层返回，再打完连续两杆；开球用例覆盖散球中进全局、停稳后回站姿再打一杆；贴库用例拍摄第一人称。真机已重新打开选择页并移除专用测试运行器。本轮直接使用 USB 真机，未占用模拟器。[测试结果](../output/shooterspool-camera-lab-20261107/phone-tests.json) · [真机入口](../output/shooterspool-camera-lab-20261107/entry-phone.png)
