# 生产回放清理旧方向兼容 · 2026-10-15

用户授权移除旧方向兼容，统一 before + 当前引擎求解；保持录制 JSON、物理和瞄准不变。

## 根因与实现

旧 legacy-directions.json 绑定初级蛇彩球形 2 的旧文件名、SHA256 与逐杆 UUID。重录同步后这些绑定失效，静态全局 registry 的 failure 经所有回放请求传播；本杆还未进入求解器便返回 nil，页面误报“当前球位无法接续”。

- SequenceReplayResolver 保留统一调用入口，直接调用当前 PositionPlayShotSolver；删除注册表、旧方向覆盖与相关物理旁路。
- 清理编排预览、视频导出对旧方向的查询／专属分支；正式详情及试打继续沿用已停稳的实际 before，显式换球形与镜头等待流程不变。
- 删除旧兼容资源与 project.yml / Xcode 资源引用；更新内容数据契约。
- 将已退役的历史方向测试替换为当前契约：全 Bundle 逐杆求解、终点消费、UUID 不影响物理、无效单杆不阻断其他球形及包内不存在旧兼容表。
- 增加正式 DrillSceneController 全球形完整回放测试，后台 SceneKit 更新，交替 2D／第三人称；保留两库／五分点三轮与延迟单球／取消回归。
