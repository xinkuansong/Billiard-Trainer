# B6：提示与规则动作（核心语义与操作通过）

来源：DailyClearanceRulesEngine.resolveBreakChoice 与 DailyClearanceController.resolveBreakChoice 的实际代码。规则引擎保持不变；只将主层整理为“重新开球 / 继续击球”，重开进一步明确原方/换方。

|用户动作|条件与引擎case|后果|草稿/成绩|
|---|---|---|---|
|重新开球→原方重新开球|存在rerackByBreaker|原方继续，记录warnedBreaker，清除lastPlayedVisit；下一次不足可能判负|控制器manualRacked、board清空、seed+1；保存草稿，不伪造新成绩|
|重新开球→换方重新开球|存在rerackByIncoming|rotateVisit换方|同上重新摆局并保存|
|继续击球|不足碰库状态存在acceptBallInHand|rotateVisit换方，cuePlacement=anywhere|保留当前球形/出杆计数，保存判罚后的草稿|
|其他有效开球处置|acceptPosition/acceptBehindHeadString|保留原位或线后自由球区别|不因双按钮设计删除防御分支和有效黑八重置|
|返回处理方式|重开子选择尚未执行|不调用引擎、不换方、不记警告|草稿/成绩不变|
