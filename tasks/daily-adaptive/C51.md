# C51 — 固定球桌，球库原位放大

2026-10-08。用户在查看设计后明确“用代码实现下吧，我看看效果”，已授权接入原生。C51已实施，最终模拟器矩阵通过，原生图册及专用模拟器已打开供体验；原Figma证据保留。

## 本轮硬约束

1. 2D／3D 切换移入更多菜单的「显示」分组，名称「视图」，直接切换，不增加一级页面。
2. 球库隐藏母球；单行取消母球及配平空翼，只保留完整目标球，目标序列对桌心居中。
3. 球桌、3D场景、两侧仪表、操作按钮、标题和更多按钮的位置、大小、样式保持不变。球库下沿固定，向上利用空隙。C50R3缩桌方案被明确否决。
4. 球径上限36pt，达到上限留白，不拉长球间距填满桌宽。
5. 正常横屏始终单行；特别窄的窗口或临时竖屏确实不足才允许两行。常规iPad竖屏不自动两行。

## 坐标与算法边界

画板局部pt，左上原点，x右/y下；没有修改物理坐标或投影。输入的安全区沿用C47/C48；3D iPad使用原设计场景，仅证明相同底图上的HUD修改，不声称本轮重新核验真实窗口安全区。

单排目标宽 `15×(d+2)+18`、高 `d+4`。固定原球库下沿、桌心，按候选球径从36向下求第一个同时满足安全区与周围控件不相交的解。本次SE实际为30，其余单排36。窄窗双排使用原分组关系；本轮420样本才进入两行。生成脚本的600pt窄窗筛选仅为此次画板分流，不是拟批准的产品设备断点；原生必须用真实容量及用户允许的窗口语义求解。横屏无可用解时报告约束冲突，不自动换行、裁球或缩桌。

球面尺寸与命中H分开：静态槽位不证明44pt命中或手感。不得通过重叠热区夸大触点。原生版还需量测真实文字、额外窗口按钮、球库与桌上触摸边界。

## 功能迁移边界

源码 `FreePlayView.dailyPaletteBall` 的母球按钮会高亮母球，`handleTargetTap`在3D会请求击球视角；移除球库入口后保留桌上母球点击和既有相机入口。新增菜单切换必须调用现有 `toggleDailyCamera`，沿用停球/临时俯视等禁用与取消交互语义，不能新建相机状态副本。

菜单示例新增44pt「视图」行；本次只展示有充分高度的iPad。手机菜单需在既有可用高度内滚动，保留所有设置，不能为了新入口缩短触点或删除原项。当前不是可交互原型。

- `DailyLayoutMetrics.FoundationReservation`保留C47/B8原布局预算，Foundation桌框、stage、侧栏计算逐字保留，仅参数类型改名。新增独立`Palette`在固定桌顶线内解析尺寸，禁止新球库高度反向推动桌体。
