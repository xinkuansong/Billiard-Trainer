## 每一杆的交互与计分

1. **开关与视图。** 建议每个新挑战从「否」开始，继续同一局恢复上次状态。开球或处理开球判罚时只做开球流程；普通击球准备阶段开启就从这一杆规划。关闭清空未出杆的选择，已记分保留。球在运动、计算、回放或终局时禁改，切换视图或临时俯视只切呈现。无计划时恢复每日原有合法球袋推荐；有计划时推荐只能提示，不能替玩家确认或改写已选球袋。自由瞄准下也按报球报袋与真实落袋事实评分，玩家照常控制方向。
2. **选球选袋。** 中八依次选第一球→第一袋→第二球→第二袋→第三球。开放局按第一球花色预排后续，实际定组后复核；已定组只看本方剩球，清完本方球后接黑八。顺序玩法（9／6／5／4 球）按剩余号码自动预排，玩家只确认实际需要的袋口。剩两颗可连续击打的球时收为四步，剩一颗收为两步；自动排号时再跳过选球步骤。球库使用现有①②③角色标识，沿用已选袋标记，第一版不加桌内工具条。点击球时提示第一个缺项，计划齐备后才允许真正出杆；包括力度释放入口。
3. **上一步与回放。** 上一步沿当前有效的可编辑步骤返回，保留返回处与此前有效选择，清除它之后的计划。例如正在选第三球时退到第二袋，再点退到第二球；顺序玩法则从第二袋直接退到第一袋。到第一步置灰，即使已有上一杆也一样。计算、运动、回放和临时俯视期间禁用。回放只播放上杆，结束回到当前球位和规划步骤。旧自定义布局中的重打位置可承接上一步，现有回放位置保留；按每日页面限定映射，其他训练保有各自的按钮。
4. **停稳与判分。** 出杆锁定本杆目标、两个袋口及后续球，停稳以同一杆的事件与真实终态结算一次。先由每日规则判定犯规、换手、终局，再按下表处理评分。每个有分的杆次（含零分）等权；分数短提示保留一位小数，点开看已有分项或零分原因，设置内可再看上杆详情。判罚提示优先。结算显示「平均走位 ××.× 分 · 计分 × 杆」，无样本时的展示见 Q04。均分代表本局所有实际参与评分的杆。

   | 情况 | 走位评分 |
   |---|---|
   | 普通计分杆，第一球进指定袋，仍可继续 | 复用 MultiBallPositionScore，评停稳后打第二球进第二袋的角度、球距、出杆空间。母球到击球点或目标球到袋线路受阻、无正向直击机会或第二球已意外落袋，记 0 并显示原因 |
   | 第二袋是中袋、第三球仍在桌 | 用现有分离方向系数修正；第二袋是底袋或第三球意外落袋时用基础分 |
   | 原有下一球可评，但本杆犯规、换手、第一球未进或进错袋 | 记 0 并说明原因，判罚与是否续打由每日玩法裁决 |
   | 评分关闭、开球、出杆前只剩最后一球、合法提前终局（如组合进 9） | 排除出均分。非法提前终局且原本有下一球可评，按犯规或本杆失败记 0 |
   | 缺失真实落袋事件或终态，无法可靠核对 | 标记本杆未评分，排除出均分，避免把数据缺失算成玩家失误 |

5. **顺延与恢复。** 同一方按计划成功续打，第二球及袋成为下一杆的第一球及袋，第三球成为第二球，只补缺项。下一杆可回到承接项改选，前一杆的已结分冻结。若错袋但仍合法续打，建议清除旧计划重新选；如仅第三球意外落袋，承接仍合法的第二球及袋。换手、定组变化导致角色无效、下一球被带进时按实际合法球序重新规划。自由球先按规则摆母球再出杆。旧草稿读为关闭、零个计分样本，老记录不补算；同局恢复开关、选择步骤与已结分，回放和恢复均防止重复记分。重新开球按现有整局流程；新挑战重置计分并沿用现有额度规则。

## Q04 · 结束时的评分

- 成功终局先显示现有清台结果、上手次数、犯规和用时，失败终局先显示结束原因。两者均在结果摘要下用一行显示「平均走位 60.0 分 · 计分 3 杆」。评分随结果停留，可在点击「再来一局」或「重新开球」前阅读。
- 不同玩法使用同一公式：累加本局每个计分杆的原始分，除以计分杆数，最终显示时保留一位小数。例如 90、0、90 的均分是 60.0。最后一球没有走位对象时只产生赛果，先前各杆的得分仍参加统计。合法提前终局、犯规等例外沿用上表，清台成功不额外加分。
- 全程关闭或旧记录无评分数据：省略评分行。曾开启但没有计分杆：显示「本局无可评分杆」，避免把零样本误读为 0 分。如果确有计分杆且全为零，正常显示「平均走位 0.0 分」。中途开关按实际计分杆汇总。
- 中途退出续局保留分数和杆数，实际终局才结算。确认放弃重开时新局另算。成功记录在清草稿前保存本局评分摘要；失败用本局终局草稿恢复。当天第二次清台展示当局结果，持久化沿用现有首次完成记录归属。
- 验收固定样例覆盖成功／失败、含零分、全零、开启后零样本、全程关闭、中途开关与退出恢复；同日两局分别用不同已知分数验证归属。小屏横屏与 iPad 检查结果、评分和终局按钮均可读可用。

## 实施与验证 · 2026-11-06

每日沿用多球走位的评分器；目标球和袋口在出杆时锁定，实际落袋事件与停稳坐标决定单杆结果。每日规则引擎继续裁决胜负。每局独立保存计分杆数、累计分数和最近一次评分；终局取该局摘要。规划上一步只回到本杆前一项，回放不触发第二次结算。

- **定向逻辑**：[iPad 测试结果](../../output/daily-scoring-20261106/final.xcresult)。每日控制器 31、每日规则 28、存档 5、多球专项 32，共 96 项通过。含实际袋号不符记零、缺失事实不计分、提前终局、普通清台最后一球、全零失败恢复、曾开启但零样本、混合分数 90／0／90 → 60.0、全程关闭与同日两局成绩归属。
- **自由瞄准**：独立 XCTest 验证编辑报球报袋时保留玩家显式选择的自由瞄准。
- **模拟器实击**：iPad mini 6（iOS 26.3.1）和 [iPhone SE 3（iOS 17.0）](../../output/daily-scoring-20261106/se-floor.xcresult) 从两球残局开始，操作菜单、报袋、退步改选、在 2D 出杆，查看评分详情、回放后切 3D 打进最后一球。两端第一杆均为 81.8 分，最终均为「平均走位 81.8 分 · 计分 1 杆」。iPad 另核对 2D／3D 竖屏终局及再次开局按钮。小屏[单杆截图](../../output/daily-scoring-20261106/se-final/daily-scoring-physical-stroke.png)／[终局截图](../../output/daily-scoring-20261106/se-final/daily-scoring-physical-completion.png)。
- **中八与布局**：[iPad 原生操作通过](../../output/daily-scoring-20261106/chinese-layout-final.xcresult)。完成第一球／袋、第二球／袋、第三球；回退后点击击球提示补选第三颗球，未出杆。布局可选并缩放原位的上一步，取消后仍可规划。关闭评分后上一步消失，回放保留。
- **边界**：定向模拟器验证，非真机、全量 UI 或发布验收。Mac mini 的独立测试包在编译 XCTest 时退出，未运行用例，不计通过；上述 SE 结果来自本机受管模拟器。
