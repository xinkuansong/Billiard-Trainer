# 首次引导年龄段与统计

年龄段在球种、球龄、性别之后。七档依次为不满 14 岁、14–17、18–24、25–34、35–44、45–54、55 岁及以上。默认无选项。点「开始训练」保存当前选择；点「跳过」忽略本题，即使刚才选过也不会保存。

- 不满 14 岁沿用本机训练流程。跳过或直接开始且未选择年龄段，可以继续游客训练，点登录时再确认是否已满 14 周岁。
- 选择合资格年龄段的游客在首次登录时复用答案。账号授权完成后才通过已认证资料接口带入。写入失败时保留对原账号的待传答案，下次可以重试。换到另一个账号不会把上一个人的年龄段带过去。
- 服务端按 CuePhys 账号去重，一人绑定微信和 Apple 不会因两种登录方式重复计数。账号注销后退出统计。报表统计自该版本服务启用以来成功登录且仍有效的账号；已填写的具体年龄段以自报时的答案为准，不从生日、设备、游客记录推测。

在配置好业务数据库连接的服务端，运行以下只读命令即可得到登录账号数、填写人数、未填写人数、填写率和各档在填写人群中的占比。没有样本时百分比为空。传入 `--beginners` 可以限定为资料中球龄不到一年的账号。

```sh
cd backend
node src/scripts/ageDistribution.js
node src/scripts/ageDistribution.js --beginners
```
