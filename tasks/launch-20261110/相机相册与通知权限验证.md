# CuePhys 相机、相册与通知权限验证

2026-11-10，北京时间。检查当前 iOS 实现、App 包内用途说明以及后端提供的中英隐私页模板。界面验证使用 iPad Pro 13 英寸模拟器、iPadOS 26.3.1、独立应用标识及游客训练数据。

| 用户操作 | 当前产品行为 |
|---|---|
| 在「个人信息」选择头像 | iOS 系统照片选择器返回用户选中的图片。取消后回到个人信息。游客头像留在设备，登录后主动确认保存的头像会上传。 |
| 在球桌照片工具导入图片 | 选择已有照片，手动标定四角并标球。取消后回到选图页。需要现场拍摄时，可先用手机相机拍照再导入。 |
| 在训练总结生成分享卡 | 生成分享卡会先保存训练记录。用户点击「保存相册」才申请添加照片权限。 |
| 保存并开启训练提醒 | 首次需要权限时显示 iOS 系统通知弹窗。拒绝后可以回到训练，提醒保持关闭。 |
| 开始组间休息 | 手动开始可触发系统通知申请。自动开始休息不申请新权限；倒计时可在前台运行。[此前的组间休息实测](组间休息计时验证.md) |

## 实现与验证

- 两个图片入口使用系统 PhotosPicker。当前版本没有 App 内调用摄像头拍照或录像的入口。项目配置与生成的 Info.plist 已删除旧的相机、读取整个相册用途说明，保留「将训练分享卡保存到相册」。球桌照片工具的引导已按实际手动标记步骤改写。[项目配置](../../project.yml) · [球桌照片导入](../../QiuJi/Features/BallExtraction/Views/BallExtractionView.swift) · [头像选择](../../QiuJi/Features/Profile/Views/PersonalInfoView.swift)
- 14:16，实际打开并取消两个系统选择器。球桌工具仍等候选图，头像选择回到个人信息。随后跳过首次引导并到达训练主页。两项界面用例通过。单独只读检查此测试 App 的系统权限库，取消选图后、首次点击保存相册前，相机、读取相册和添加照片均无授权记录。[选择器与首次启动测试](../../output/launch-20261110/permissions/deny3.xcresult) · [权限记录](../../output/launch-20261110/permissions/pickers-tcc.json)
- 本轮使用取消路径，未使用个人相册素材。此前另一次演练已用合成图片选图、标定和标球。[合成图片导入记录](../quality-diagnosis/PHOTO-004-RESULT.md)
- 14:17，在真实系统弹窗拒绝训练提醒，看到 App 的提醒设置说明，确认后提醒开关为关。用例复核了首次操作前通知状态未决定。[通知拒绝用例](../../output/launch-20261110/permissions/deny3.xcresult)
- 14:19，使用测试 HTTPS 配置构建未签名 iPhoneOS Release 成功。直接读取生成的 App 包，只含添加照片的用途说明。Debug 宿主包三个权限键断言也通过。[Release 包内字段](../../output/launch-20261110/permissions/release-permissions.json)
- 14:21，沿用已拒绝通知的游客测试安装。从基础训练计时、结束、跳过心得、生成分享卡一路操作到「保存相册」，在真实系统弹窗选择「不允许」。App 解释缺少写入权限，返回总结显示训练已保存。重新打开后，再完成一轮训练并保存成功。系统权限库中仅有添加照片的拒绝记录。[两种权限均拒绝后的训练用例](../../output/launch-20261110/permissions/photo-denied.xcresult)
- 14:23，另一独立安装在系统弹窗选择允许添加照片，Photos 写入成功后分享页关闭，回到已保存训练的总结。同一安装允许训练提醒，返回设置仍显示系统权限开启、提醒开关打开。两套安装的系统记录分别显示添加照片允许／拒绝，相机和照片库读取均无授权记录。[允许路径结果](../../output/launch-20261110/permissions/allow1.xcresult) · [系统权限对照](../../output/launch-20261110/permissions/photo-decisions-tcc.json)
- 自动化收尾两批分别为 8/8、2/2 通过，均无跳过。先前混合批次中首次引导、通知拒绝与取消选图已通过，分享用例因心得页键盘遮住「跳过」中断，补上实际收起键盘动作后在两种权限下均跑通。一次测试运行器启动繁忙的批次未作为证据。
- 中英隐私页已更新照片选择、分享卡写入、训练提醒与组间休息；法律页面的本地渲染和配置测试 3 项通过。[隐私页模板](../../backend/public/privacy/index.html)
