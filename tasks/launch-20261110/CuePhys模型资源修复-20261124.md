# CuePhys 改名后球桌消失排查（2026-11-24）

## 根因与修复

当前分支 `codex/cuephys-full-rename`，基线 HEAD `3458b498b`，保留工作区既有改名改动。

`.gitattributes` 仍绑定 `QiuJi/Resources/…`；源码改到 `CuePhys/` 后三个模型留为 Git LFS 指针。生产球桌与球杆分别只有 134/132 字节；`build/DeviceRegistration` 和 `build/DeviceFocusedTest` 的真机 App 包同样包含指针。加载器找到文件后无法按 USDZ 解码，因此桌体、球和球杆不能创建，HUD/地板仍可显示。此前构建门禁只检查文件存在，未验证内容。

已修正三个 LFS 路径，用 `git lfs checkout` 从本机缓存恢复匹配对象；球桌 119558458 字节、球杆 1239924 字节，SHA-256 与 `ModelAssetTrial.swift` 的既有生产值逐项一致。六个房间 USDZ 的 ZIP/CRC 也有效；资源目录残留 LFS 指针为零。未重做模型、修改材质或相机。

`verify_model_packaging.py` 现检查 LFS 规则、源模型和构建包模型内容，拒绝指针、无效 ZIP、无 USD 场景及 CRC 损坏。`test_verify_model_packaging.py` 修正旧工程路径并增加负例；10/10 通过。`.gitignore` 的当前资源路径同步为 CuePhys，避免母版/预览目录意外纳入提交及模型白名单失效。

生产微信/Apple 登录、StoreKit、云同步的外部联调仍按上线台账推进，球桌修复不覆盖这些项目。
