## App Store Connect 待核字段

在上传候选 build 前，由有权限的账号进入 App Store Connect → App 内购买项目，核对以下字段并保存截图或导出记录：

1. 商品 ID 是否为 `com.youbilliards.cuephys.premium.lifetime`，类型是否为“非消耗型”。
2. 中文显示名、描述、价格（当前产品文案为一次性永久会员，代码不写死价格）和中国大陆销售范围是否已准备。
3. 付费应用协议、税务和银行状态是否允许销售；未完成时不把商品标成可售。
4. 商品是否关联现有 App `6761309682`，以及当前 App 记录是否已经保存 `com.youbilliards.cuephys` Bundle ID。
5. 支付范围按整改 I22：本轮不新增后台支付通知系统；现有权益更新、启动／前台刷新和正式沙盒恢复分别验证，不把未实现的通知接收端写成已完成。

## 目前可执行的验证

- 本地 UI 只显示永久会员；`StoreKitService.loadProducts()` 只请求永久商品，`purchase()` 只接受永久非消耗型商品。
- 旧商品 ID 仍可被当前权益读取逻辑归一化，避免历史交易在改名后丢失；没有证据前不删除旧 ID。
- 正式商品查询、沙盒购买和恢复购买需在后台商品与签名配置确认后进行真机验证；本地 StoreKit 测试不能替代。
