## 依赖顺序校正

1. **先冻结备案事实**：CuePhys／iOS、`com.youbilliards.cuephys`、实际 API 域名和服务器、支持／隐私／协议页、服务范围。当前主体、域名、API 和页面已核对；属地业务分类仍待正式答复。
2. **具备表单必填字段后即可提交 App 备案**：App 备案不需要先完成 Apple 付费协议、税务／银行、IAP 商品、微信 AppID 或 TestFlight。若腾讯云表单把 iOS 发布证书 SHA-1 标为必填，则只等待该证书字段，不等待其他 Apple／微信事项。
3. **并行推进 Apple 和微信**：ASC 隐私标签、年龄分级、安全评估、AIGC 声明、商店资料、付费协议；微信企业认证后的移动应用审核和 AppID。它们分别服务于商店合规和登录接入，不是 App 备案的前置条件。
4. **最后汇合发布门槛**：App 备案号、Apple／微信生产凭据、正式签名包、购买恢复和真机登录验证齐全后，再做 TestFlight 和商店提交。

本轮已完成只读核对和备案资料预填，没有提交备案、接受协议、创建正式商品或上传 build。
