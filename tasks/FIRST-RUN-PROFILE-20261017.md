# 首次资料引导 · 2026-10-17

## 用户授权与顺序（DR-404）

用户授权实现可跳过的首次资料填写，后续从个人信息补充；不能覆盖老用户已有资料/设置。用户准备另行重做产品介绍，本轮复用现有介绍内容。

顺序：产品介绍（可跳过）→ 资料引导（可跳过）→ 首页；具体功能提示在首次实际使用时出现。仅真正新安装进入；“我的→认识球迹”仍只重看介绍，结束返回原页，不再触发资料填写。未来介绍重做只替换前一段。

## 实现约定

- 启动时先于 SwiftData 容器、游客身份和偏好单例初始化捕获安装历史；旧 app-owned 偏好、数据库、旧游客身份、旧引导完成状态或登录凭证任一存在，都按老用户保护。系统 Apple/NS 默认值不算已有资料。
- 独立 installation-level 进度记录 introduction/profile/completed；中断可续接所在步骤，跳过或完成后不重弹。已有凭证优先结束待填步骤，离线恢复失败也不要求重填；身份恢复为账号也结束引导。
- 页面内容为主打球种、当前水平、球龄、可选昵称，所有选项初始未选，可再次点击取消。头像/性别/生日从个人信息后续补齐。
- 草稿只在点击“开始使用”时提交；跳过丢弃草稿，不写任何资料字段。保存前整体校验昵称，只有当前游客、明确填写且原字段为空时才补入；不批量保存默认资料，不提交服务端。
- 新球种沿用现有默认玩法推断，不覆盖手动设置；不碰球局、轨迹、视图、网格、账号、同步开关、订阅和训练数据。
- 页面复用语义色、字号、圆角和主按钮；滚动内容、底部安全区主操作、44pt选择项；窄屏/大字号纵向排列。
