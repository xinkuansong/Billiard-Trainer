# v64 W0：球桌材质基线与诊断

日期：2026-09-24。需求真源：[问题集合 v64](../../问题集合_v64.md)。用户已授权开始实施。**本批完成诊断与可复现基线，尚未把诊断候选写入生产材质。**

## 结论

1. **皮革首先存在消费端问题。** 在当前完整生产场景中，`normal.intensity` 从 0.5 改为 0/1，以及将粗糙度贴图替换为 0.65，角袋和中袋输出都完全不变。显式按线性数据采样同一张法线/粗糙度后才出现变化。这个结论限定于本次 `.constant + satinShader` 路径，不推广为 SceneKit 的通用行为。
2. **恢复原贴图还不足以达到目标。** 正确线性采样的角袋最大 RGB 差值仅 10/255；原法线 R/G 标准差约 0.0105/0.0100，表面起伏很弱。去掉主题染色可看见原棕色斑纹，但这同时改变颜色，不能作为米色皮革的最终方案。W1 应先接通微表面，再在 Blender 制作配套细皮纹，并保留亮度层次进行染色。
3. **木材的平面感有代码根因。** 当前 Wood/BlackWood 只计算漫反射。简单切换原生 PBR 会把炭灰库边洗成明显浅灰，淘汰直接切换方案；W2 采用保留当前漫反射基调、单独增加弱漆面响应的候选，不调全场曝光。
4. **台呢已有有效法线。** 法线归零会改变画面；不是没有采样。UV 1×/2×/4×已经对照，4×使近景更平滑，不能把加密当成质感提升。W3 先保留当前 2×，针对近景细绒与掠射响应做轻量候选，最终尺度仍需运动验收。

## 单变量对照

MAE 是全幅 RGB 绝对差的均值，量纲为 0–255；包括未受影响区域，不能当成皮革区域的主观提升评分。恢复材质后角袋、中袋、台呢均与基线 PNG 完全一致，相机目标也通过屏幕中心断言。

| 对照 | 角袋/中袋结果 | 判断 |
|---|---|---|
| 原生法线强度 0、1，对基线 0.5 | 两机位均 MAE=0、最大差=0 | 当前路径不响应这个绑定 |
| 原生粗糙度改常数 0.65 | 两机位均 MAE=0、最大差=0 | 当前路径不响应这个绑定 |
| 显式线性法线 | 角袋 MAE≈0.029、最大差4；中袋≈0.018、最大差3 | 正确参与，但原细节弱 |
| 显式线性粗糙度 | 角袋 MAE≈0.077、最大差9；中袋≈0.079、最大差10 | 正确参与，变化主要为弱高光 |
| 显式线性法线＋粗糙度 | 两机位 MAE≈0.087，最大差10 | 可作为 W1 接通通道的参考 |
| 移除主题染色 | 角袋 MAE≈8.001，中袋≈4.781 | 原色纹理回归；不等于米色候选胜出 |
| 木材直接原生 PBR | 木材机位 MAE≈21.707，最大差146 | 库边洗白，淘汰直接替换 |
| 台呢法线归零 | 台呢机位出现可测变化 | 法线参与已证明；细绒质量未证明 |

显式数据通道通过 `MTKTextureLoader` 的 `.SRGB: false` 和 mipmaps 加载，再由局部诊断 shader 采样；避免把法线 R/G≈0.5 当作 sRGB 颜色解码。`r3` 曾用 UIImage 绑定自定义数据纹理，出现整体侧壁变暗，**该轮色彩空间不适合作为候选证据，已淘汰**。`r1` 有机位 roll 漂移，也不用于严格 A/B。保留失败证据；接受的原始基线为 r4。

## UV 与尺度

Blender 源为米制 Z-up，SceneKit 为 X/Z 水平、Y-up。下表为 **Blender 世界空间、面积加权中位数**；最终 App 数值须乘加载器的统一缩放，当前源外包围盒约 2.82×1.56m，缩放接近 1。未改 UV、几何或物理。所有近景直接高分辨率渲染。

| 区域 | 一次 UV 的源世界长度 | 说明 |
|---|---:|---|
| 四个角袋顶部 | 约 151 mm | 四袋一致；P90 各向异性约 1.01 |
| 四个角袋侧壁/倒角 | 约 161 mm | P90 各向异性约 1.48；可见局部拉伸，不能用统一强噪声掩盖 |
| 两个中袋顶部 | 约 200 mm | 比角袋大约 32%，同图皮纹会更大 |
| 两个中袋侧壁/倒角 | 约 206 mm | P90 各向异性约 1.37 |
| BlackWood 平面 | 约 509 mm | 不能与桌身混用固定尺度判断 |
| Wood 大片围板 | 约 1241 mm | 同一主题图纹理铺展尺度显著不同 |
| TaiNi 平面 | 约 449 mm；运行时2×后约224.5 mm | 包布中位数同量级，侧面P90约490 mm（2×前） |

以 2K 皮革图计，角袋顶部每源纹素约 0.074 mm，中袋约 0.098 mm。固定近景正交尺度 0.16、900px 高时，未计倾斜压缩的投影估算约 0.21/0.28 px 每纹素；全桌视角更小。**纹素不等于一个皮纹颗粒**，原图没有已标定的物理纹理单元，不能报“现有皮纹就是几毫米”。W1 的 Blender 新图必须记录设计粒径和铺展倍率，并考虑角袋/中袋 UV 差异；无需先增加到4K。

已检查五个离散角袋观察方向。未观察到大的贴图跳变；离散帧不足以证明连续运动无细纹闪烁。真机运动和帧时仍留在 W4，不提前关闭。

## 成本基线及未关闭项

当前普通完整场景的桌模型：2 个带几何节点、10 个几何 element、10 个材质槽/对象，source primitiveCount 合计 293,939（可能包含多边形，**不是三角形数**）。Blender 的三角化计数按对象/材质另列；两个 MG_Gold 对象分别记录，不合并假设实例或消除重复。

静态 shader 账单：皮革 satin 每像素已有 2 灯板×4×2＝16 个 GGX 采样点，加解析漫反射；木材当前仅解析漫反射、无镜面项。W1 显式法线/粗糙度诊断增加两次纹理采样与导数切线基计算，没有新增几何、灯光或渲染 pass。生产实现仍须实测，不能以公式替代 GPU 时间。

单张2048² RGBA8 数据理论基础16 MiB、全 mip约21.33 MiB；这只是统一格式估算，源 PNG 压缩字节、实际格式与驱动驻留不同。默认主题木纹1024²，多区域引用同一 UIImage；台呢 diffuse/metallic 已被常数替换，不能把USDZ所有图相加当显存。W1–W3 应记录**实际新增/替换**资源并复用缓存。

未测：实际 GPU draw calls/驻留显存、真实设备GPU时间/帧间隔/热表现、页面首次交互；每日清台既有性能任务不由本批关闭。后续W4按同设备同配置比较。
