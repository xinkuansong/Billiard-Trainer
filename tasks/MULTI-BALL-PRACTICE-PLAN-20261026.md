# 多球走位：完整讨论方案与球形生成

当前页面与权益以[第二轮合同](table-page-adaptation/MULTI-BALL-PRACTICE-20261026.md)为准：2D/3D独立入口，3D与2D自由训练需Pro，2D三题模式非Pro每天共享3题。以下原球形生成方案保持。

日期：2026-10-26。状态：离线全量球形生成运行中；用户已授权同步完成App页面、题库消费与验证。发布未授权。

## 1. 来源与决定状态

本文汇总本次连续讨论。用户明确输入优先于助手提议；“建议／试验默认／待定”不等于用户逐项确认。后续修改在本文追加版本记录，实际样本与统计独立归档。

### 已明确的用户要求

1. 多球走位包含顺序（追分形式）和中八残局两种玩法。
2. 顺序玩法可选4、5、6、9颗目标球；数字指球数，不是固定球号列表。按顺序打完。用户后续明确7、8球不做，覆盖初始4～9球范围。
3. 中八可选己方剩余4、5、6、7、8颗，包含黑八；对手球选择“0颗”或“随机1～7颗”。
4. 母球自由球上手。
5. 预先生成球形；不验证能够清台、不提供清台思路、不保存参考清台路线。
6. 顺序玩法各球数提前准备10,000个开球未进目标球的球形；中八准备10,000个完整开球基础球形。当前总目标50,000个基础球形（7、8球已取消）。
7. 中八每次新取用基础球形，临时随机双方全色／花色身份、对手保留数量和具体保留球，同一基础球形可形成不同残局。
8. 开球母球在开球线以内随机，力度9.5～10随机。
9. 按每日清台的按键与设置方式，提供进袋／自由瞄准，瞄准条上方是“重新开始”。
10. 球形散开程度只用一个统一指标，输入球坐标、输出一个可排序和过滤的数。
11. 先完整记录方案，再开始生成球形、优化指标。
12. 用户已明确全库统一采用有限桌面校准指数≥1.20；中八仅筛选完整15球基础盘面，随机删球后不评价。

### 讨论中建议，尚非单独确认的产品细则

以下保留早期建议的来历；用户后续授权全部实现后的当前合同见[页面合同](table-page-adaptation/MULTI-BALL-PRACTICE-20261026.md)。本版不实现离页恢复、成绩历史或新权益限制；正式单入口页内切2D/3D。严格顺序、黑八时机与误进对手球按页面合同的练习默认处理，不能把这些默认记为用户逐条确认。

- 定位为预设残局的一次上手连续清台训练；漏球／犯规结束本次正式尝试，重打或继续归为复练。
- 中八开局确定己方球组，自选本组顺序，黑八最后；对手球参与真实碰撞。
- 为满足己方4～8球，中八还需随机保留N−1颗己方球＋黑八。
- 对手数量先在1～7等概率选择，再等概率选择对应子集；不采用每颗球独立删除而造成数量偏向。
- 重新开始恢复本次实际残局并重新开放母球自由摆放；下一题才重新抽样。重打恢复整杆快照，回放不改成绩，重进恢复冻结盘面。
- 进袋／自由只控制瞄准辅助，不扩大移球权限；首杆后不允许随意拖球。
- 页面复用每日控件、显示设置、相机及布局；正式2D／3D入口形式和权益尚待后续页面方案确定。
- 成绩优先记录一次上手成功、连续完成球数、失败原因、尝试／重打次数；不直接平均两球舒适度作为整局分数。

## 2. 产品流程与需保留的边界

训练设置 → 从已通过离线分散筛选的基础库抽题 → 中八按条件随机减球 → 冻结本题 → 自由球摆母球 → 连续击打 → 清台／失败 → 重打、重新开始或下一题。

玩法、瞄准方式、自由球权限为三套独立状态：顺序／中八决定规则；进袋／自由决定瞄准；自由球决定母球可否移动。

| 动作 | 建议语义 |
|---|---|
| 重新开始 | 同题初始目标球／对手球全部恢复，重新自由球上手 |
| 重打 | 恢复上一杆前完整球形、输入与规则快照 |
| 回放 | 播放上一杆，不重复计分、不改变当前盘面 |
| 下一题 | 新抽基础球形及中八减球方案 |
| 切瞄准／视图 | 保持当前题与盘面 |
| 改训练设置 | 草稿确认后开启新练习；取消不改变当前局 |

现有每日清台允许合法组合进9提前完成，中八失误后换手；不能不加区分地把这些规则带入多球训练。

早期待定项现已按授权实施默认落地：顺序不允许提前或同时进后续球；中八合法首碰且己方入袋时可顺带进对手球，仅进对手球失败；末颗己方与黑八同杆入袋失败。失败提供重打与重新开始，完成提供下一局。不新增成绩历史或付费限制。详页面合同；这些约定不参与离线基础球形筛选。

## 3. 基础库与随机化

| 库 | 目标 | 来源 |
|---|---:|---|
| 顺序4／5／6／9球 | 每类10,000 | 对应球架真实开球、目标球全留台 |
| 中八15球基础库 | 10,000 | 完整15球真实开球、目标球全留台 |

目标数量是最终合格且去重后的数量，不是尝试次数。保留原始候选与过滤原因，指标迭代时可重算而无需重跑物理。

### 开球输入

- 使用生产`RackLayout`、`BreakSimulator`、`EventDrivenEngine`，同源球桌几何与默认物理模型。
- 母球在现有开球线至身后短库的合法球心区域内面积均匀抽样，避开袋口；不通过边界钳制造成边缘样本堆积。
- 杆头速度连续均匀抽取9.5～10.0 m/s；这是击杆输入，不是母球初速度。
- 试验默认中杆（spinX=spinY=0），瞄向当前球架顶球中心；随母球位置重新计算方向，不额外随机瞄准角度。
- 使用可复现的独立种子决定球架、母球位置和速度；每条保留实际输入与版本。
- 初始开球母球位置是生成条件，训练开始后的母球仍由玩家全台自由摆放。

### 7／8球已取消（历史实现背景）

`RackLayout.zhuifen(balls:)`虽接收7、8，但专门摆法仅4／5／6；7／8使用截取三角阵兜底，且球号为1…N，没有固定9号。首批研究可直接使用该生产兜底并明确标注，不能称为已确认正式7／8球规则。用户后续明确7、8球不做，不再为本轮补摆法；历史7／8试验数据保留，正式库不收录。

### 中八变体

1. 抽基础球形；随机决定己方全色或花色。
2. 根据N=4…8，保留本组N−1颗和黑八，其余己方球删除。
3. 对手为0时全部删除；随机模式先等概率抽k=1…7，再从对方7颗中随机保留k颗。
4. 坐标不移动；对手球不是静态贴图，后续参与碰撞。
5. 用户已确认：随机删球后直接使用，不计算或评价最终残局的分散指数，不按分数重抽子集或更换基础球形。指标只在离线生成时筛选开球后的基础球形。
6. 冻结基础ID、球组、保留球号／坐标、变体种子；基础盘面的指标版本与值仅作为来源元数据，不是残局评分。同题重开不重新随机。

## 4. 有效性与单一分散指标

### 基础有效性（不是第二套难度分）

完整停稳、目标球数量与身份正确、无目标球入袋／飞出、坐标有限、无异常重叠。正常贴库、挡球、无直接进袋路线不作为废局。

本轮执行默认沿用首批口径：母球落袋不淘汰目标球球形，保留cueScratched标志，并统计全部球零入袋数量；依据为训练自由球上手、用户批准在现有指标与生成流程上继续。该口径是已说明的实施默认，不另记为用户逐项明确要求。

### 统一指标：平均最近邻分散指数（基线v1）

只计开球后基础盘面的全部目标球，排除母球；中八按完整15颗计算，随机删球后的残局不再评价。每球最近邻球心距离`d_i=min_{j≠i}||p_i−p_j||`，`Dobs=mean(d_i)`。

- 理论基线：`R_theory=Dobs/(0.5*sqrt(A/N))`，A固定为有效台面面积。
- 优化候选：`R_calibrated=Dobs/E_N`。`E_N`由真实合法桌面内、同球数、不重叠的随机点集预计算；固定参考样本数、种子、采样法及版本。
- 现有参考表覆盖N=4…15；正式筛选只使用顺序4／5／6／9球和中八15球基础盘面。每副基础球形只有一个主指标，越大表示平均最近邻越疏散。
- 1是随机参考水平，不是合格线；不包装成未经标定的百分制或清台概率。
- 标准随机点过程在少球数、有限边界和有限球径下有偏差；校准针对这些影响，不对物理开球样本各自归一化，以免把差球形分布自动美化。
- 平均值仍可被孤立球拉高；需用“主体扎堆＋少数远球”等反例检验，若改公式须保留v1和同一批球形对照，不悄悄替换。
- 不叠加多个手工权重指标；需要时的诊断数据只用于解释和验证，不形成并列过滤分数。

来源：Esri Average Nearest Neighbor方法，https://pro.arcgis.com/en/pro-app/3.6/tool-reference/spatial-statistics/h-how-average-nearest-neighbor-distance-spatial-st.htm 。

### 阈值校准

先分球数展示真实样本从低到高的排序与边界样本，再确定统一阈值是否适用。可以校准参考分母，但不能为了让预想案例达标临时调权重。全量已固定mean-nearest-finite-table-v1及首批calibration.json，统一阈值≥1.20；7／8球取消。

## 5. 数据与坐标契约

- 研究源与程序：`research/multi-ball-generation-20261026/`。
- 原始输出、报告、图册：`output/multi-ball-generation-20261026/`。
- 独立生成资产，不覆盖动作库人工编排序列、既有两球题库或App资源。
- 世界坐标：SceneKit X–Z水平，Y向上，米；X沿长边正向，Z沿短边正向。横桌俯视图屏幕右为+X、屏幕下为+Z。
- 归一化：`u=(X+L/2)/L`，`v=(Z+W/2)/L`，两个轴都除以L；范围[0,1]／[0,W/L]。禁止把短边单独拉伸到[0,1]后算欧氏距离。
- 球半径、桌长宽、台面高度取当前生产常量，禁止硬编码旧文档台面高度。
- 最少记录：ID、玩法、球数、种子、完整输入、停稳状态／落袋、目标球坐标、母球状态、指标值与版本、源文件SHA、生成器版本、拒绝原因。
- 最终消费包只需基础球位和必要元数据；完整逐帧开球轨迹不要求长期进包。基准／拒绝样本保留足够复算证据。

## 9. 首批执行结果

### 用户评阅反馈（2026-10-26）

用户查看图册后反馈：“我看下来这个指标不错，中八的也是”。据此确认沿用有限桌面校准的平均最近邻分散指数，适用于顺序模式与中八模式。
