# 2D与3D角度及瞄准点训练调整方案

版本：v2。日期：2026-10-15。状态：按用户反馈删除同题重试；17项单元及9项模拟器页面测试通过。

本方案覆盖「2D角度、3D角度、2D瞄准点、3D瞄准点」四个入口。两组共用球形范围和出题校验，分别训练角度判断与瞄准方向。瞄准点提交后只做几何对照，删除自动击球验证；提示采用文字角度。界面沿用当前球桌模板。

## 用户已确定的要求

- 两组一起优化，先整理具体训练规则与调整方案。
- 瞄准点也支持选择不同训练范围。
- 删除瞄准点击球验证，不保留自动纠正方向后出杆、验证等待和验证重试。
- 瞄准点可以给提示，提示内容为文字角度。
- 结果已经展示答案，四入口均不提供同题重试；看完结果进入下一题，末题或额度用完进入总结。

以下范围、默认值、反馈档位和流程细节已获用户整体实施授权；它们属于屏幕认知练习设计，不是实战能力标准。普通「瞄准点训练」抽象拖球页与「角度预测」页不在本轮改造范围；共享代码不得误改它们。

## 训练目标与角度口径

| 入口 | 练什么 | 用户如何作答 | 结果单位 |
|---|---|---|---|
| 2D角度 | 从俯视球形判断几何瞄准角 | 输入0至90度 | 度 |
| 3D角度 | 从站位透视判断同一几何瞄准角 | 输入0至90度 | 度 |
| 2D瞄准点 | 从俯视球形确定瞄准方向 | 拖动方向与方向尺微调，提交 | 毫米与偏差方向 |
| 3D瞄准点 | 从站位透视确定瞄准方向 | 同上 | 毫米与偏差方向 |

题目中的「瞄准角」统一指母球中心→标准假想球中心的方向，与目标球→有效进袋瞄点方向之间的夹角。它不是母球→目标球中心的夹角，也不是当前用户瞄准线的角度，更不是考虑旋转、挤偏后的实际碰撞切球角。

标准假想球由有效进袋瞄点反向退一个球直径得到。答题、文字提示、结果图和保存记录使用同一最终球形重算值。2D与3D只改变观察方式，不能改变答案。

## 训练设置

四个入口先显示训练设置，再点「开始训练」。沿用角度页现有的首次设置方向规则：设置期间继承入口方向，开始后再进入球桌。训练中从「更多→训练设置」调整；编辑使用草稿，取消不改变当前训练，确认「重新开始」才生效。已提交成绩保留，未提交题不计成绩。

默认显示「练习模式、角度范围」，「球形条件」默认展开，包含两种距离与袋口类型。采用分项组合，替代现有将距离、角度和袋型混排的九种名称。不同任务和2D/3D各自记住最近设置，首次默认如下。

| 设置项 | 首次默认 | 可选项 |
|---|---|---|
| 练习模式 | 20题 | 20题、自由练习 |
| 角度范围 | 综合0至70度 | 见下表 |
| 母球距离 | 混合 | 短、中、长、混合 |
| 目标球距袋 | 混合 | 短、中、长、混合 |
| 袋口类型 | 混合 | 混合、角袋、中袋 |

### 角度范围

| 名称 | 出题角度 | 训练重点 |
|---|---|---|
| 近直球 | 0至10度 | 区分真正直球与小幅切球 |
| 小角度 | 11至30度 | 厚球到半球附近的判断 |
| 中角度 | 31至50度 | 常见切球判断 |
| 大角度 | 51至70度 | 薄球判断 |
| 极薄球 | 71至85度 | 专项挑战，首次默认和综合范围不包含 |
| 综合 | 0至70度 | 混合前四档 |

内部按整数1度目标采样，不再只出5度倍数。最终重算误差须在0.05度以内，否则重新生成；评分用重算原值，界面按整数度显示，保留±3度练习反馈容差。0度必须确实共线，不能转换成5度。

综合20题建议近直球2题、小角度6题、中角度6题、大角度6题；先排好配额，再打乱顺序。自由练习每20道新题使用同样配额。单档均衡覆盖该档整数角度，不连续重复同一角度。

不增加「全是0度」的独立角度测验，因为设置本身会给出答案。需要直球对照时从近直球范围中安排；不把预先告知角度的作答当作独立估角成绩。

### 两种距离分别定义

| 距离档 | 母球中心到目标球中心 | 目标球中心到有效进袋瞄点 |
|---|---|---|
| 短 | 0.30至0.60米 | 0.25至0.60米 |
| 中 | 大于0.60至1.20米 | 大于0.60至1.20米 |
| 长 | 大于1.20至1.80米 | 大于1.20至1.80米 |
| 混合 | 在以上三档中安排 | 在以上三档中安排 |

这些是训练编排参数，不是台球术语对近中远台的统一定义。界面使用明确的「母球距离」「目标球距袋」，同时展示米数范围；不再只写「远台」。母球距离不再使用母球到假想球的距离冒充两球心距离。

组合必须有合法球形。选择前检查可用组合；不支持的组合说明「当前角度与距离组合暂无可用球形」，由用户改条件。禁止静默缩短距离、换袋型或改角度。混合档只在可行档位中分配并显示实际覆盖，不能宣称三个距离档均已训练。

## 出题与答案正确性

1. 先安排角度、距离和袋型配额，再生成合法球形；不再要求目标袋是最近袋口。选定目标袋固定，不能由用户中途换袋或移动球。
2. 左右切在20题内各半，0度题除外；奇数余题交替分配。混合袋型为角袋10题、中袋10题，袋型内各袋出现次数尽量相差不超过1。可行性不足必须显式减少可选组合，不能靠反复拒绝抽样形成未说明的偏斜。
3. 每道题都校验两球在台内、不重叠、标准假想球可达、母球沿标准方向先接触目标球、目标球到指定袋的几何通道可行。困难的贴库、擦袋角与需要碰库的球形不进入本轮普通题库。
4. 使用真实球半径、有效进袋瞄点与当前袋口几何。不能缩球、扩大袋口或修改球桌物理。
5. 标准答案由最终球位重算。越界就重新生成；删除强行夹回台内后保留旧答案的兜底。备用题也必须通过相同校验和当前条件。
6. 生成达到预算仍失败时，保持设置并提供「重新生成／调整范围」；不生成错误题、不扣题数、不扣额度。
7. 随机球号继续保留；布局相同但球号不同不算不同球形。建立球形身份，避免把同一球形重复算成新题。

这里的通道与接触校验是几何校验，不运行击球验证，也不承诺给定力度下必然进袋。针对的是屏幕认知训练，不改动作库人工编排球形和内容资产。

## 角度训练流程与提示

流程：观察→输入角度→提交→对照结果→下一题（末题进入总结）。新题默认不显示标准瞄准线、假想球与角度答案；保留题目目标袋提示。关闭输入框回到观察，不提交答案。

保留现有图形辅助，按钮明确为「辅助」。点击后展示标准假想球和相关几何线，隐藏角度数值；从首次打开起本题标记「用过辅助」，再关闭不能恢复独立作答身份。提交后显示作答、标准角度、误差以及「估大／估小」；误差为0显示「一致」。

角度评价继续以绝对误差分档：≤3度「接近标准」、大于3至10度「有偏差」、大于10度「偏差较大」。不称为进球精度。平均误差仍按真实数值计算，显示一位小数。

## 瞄准点流程与文字提示

流程：观察球形→调整瞄准线→提交→几何对照结果→下一题（末题进入总结）。

### 文字角度提示

- 作答阶段增加「角度提示」，默认关闭。
- 点开只显示一句，例如「本题瞄准角：32°」。数值来自标准答案，与当前用户瞄准方向无关。
- 不同时显示标准假想球、标准瞄准线、角度弧、瞄准点答案或自动吸附。原有题面进球线、用户瞄准线与随用户方向变化的标记继续保留。
- 提示不计时消失，可收起；打开过即记「用过角度提示」，收起后仍保留该标记。下一道新题重新默认关闭。
- 瞄准特写仅放大用户当前瞄准关系，不在答题前额外揭示标准解；它与文字提示是不同功能。
- 提示给出了角度，学员仍需自己把角度转换成瞄准方向。可用于练习，但成绩与未看提示分开。

### 提交后只做几何对照

- 冻结用户提交方向，展示用户线与标准线、标准瞄准点、偏差数值与方向。标准线出现不得修改用户方向。
- 删除1.5秒后出杆、标准方向替换、物理预测、运杆与击球动画、验证中状态、验证失败重试以及停稳自动换题。
- 不展示进球率、进袋成功／失败、进球动画、预计进球或以动画替代验证。共享物理引擎与其他页面的正常击球保留。
- 结果一直停留，用户可看清后点「下一题」。第20道新题提交后按钮为「查看总结」，必须先能看到本题结果。
- 不提供同题重试；已展示答案的题只允许查看结果，不返回作答。

### 毫米误差与判定

建议保留毫米反馈，但统一测量到同一参考截面，替换现有两个旋转垂足的投影差，避免反向线或不同投影产生虚假的小误差。具体公式见技术约束。

显示档位建议：绝对误差≤2mm「接近标准」、大于2至6mm「有偏差」、大于6mm「偏差较大」。这是几何练习档位，不表示球会进袋。显示一位小数；显示为0.0mm时不再标「偏薄」。

先判方向和碰撞关系，再给厚薄解释：背向目标为「方向反了」；前向但从目标另一侧经过为「瞄错侧」；射线未进入两球接触范围为「未对准目标球」。这些不能记成高质量作答。正常同侧有效瞄准才显示「偏厚／偏薄」。异常题记一次未达标首答，单独计数，不伪造毫米误差或从总作答数中消失。

## 3D观察与成绩边界

保留现有站位、观察、全局与临时俯视控制，不新增相机模式。3D成绩分两层：仅用站位透视且未开提示的独立作答，以及看过辅助／全局观察／临时俯视的辅助作答。手动在允许的站位视角内观察不算使用答案提示。

本版不增加单独的考试入口，也不封锁现有观察能力；记录实际使用方式，使3D成绩可以解释。2D与3D、角度与瞄准点四种成绩分别保存。若后续需要严格考试，再设计固定观察条件的测验。

## 每轮编排与成绩记录

- 20题指20道不同球形的首次提交，辅助作答也占一道。展示答案、切视角都不新增题数；重复提交不重复记分。
- 自由练习随时结束，展示当次摘要。中途退出保存已经完成的题目；没有作答不生成空成绩。首次退出设置直接返回入口。
- 不增加限时、连续正确奖励或按速度排名。先保证理解与纠错，暂不让操作速度影响成绩。
- 保留现有每日20道免费新题、Pro权限与四个来源标识。提示不另扣额度；新题首次提交只扣一次。额度用完仍允许查看当前结果和总结，不再开启新题。
- 总结显示：已答新题数、独立／辅助题数、两组分别的平均绝对误差与达标数、异常作答数。平均误差注明有效数值样本数，不能掩盖异常作答。
- 按角度范围展示薄弱项，样本不足5道独立首答只显示题数，不判定「已掌握」。估大／估小、偏厚／偏薄倾向只由对应有效独立首答计算。
- 首版不做自动升级。选定专项不能被自适应擅自换范围；先保证均衡出题、可靠分项数据，再单独评估弱项复习算法。
- 保存规则版本、训练配置、球形身份、真实几何、首答身份（旧复练字段保留兼容）、提示与观察使用、误差单位、评分版本、异常类型。旧成绩继续展示，未知辅助状态保持未知，不能补成「未用提示」。新旧毫米口径不能混成同一趋势。
- 存储沿用既有认知训练会话与稳定quizType；实施前检查SwiftData、同步DTO与后端字段，并按数据契约记录必要ADR，不能只加本地字段而让同步丢失。

## 技术约束与边界

坐标契约：SceneKit世界系X–Z为台面，Y向上，长度单位米；归一化两轴均以台长2.54米缩放，x在0至1、y在0至0.5。半径0.028575米，实际进袋瞄点复用AngleSceneCalculator与当前几何真源，不从屏幕像素推导评分。

毫米误差提案：设母球中心C、标准假想球中心G、标准单位方向u=(G−C)/|G−C|、用户单位方向v。在台面内取过G且垂直u的截线。v·u≤0为反向／不可评分；否则用户射线与截线交点P=C+v·(|G−C|/(v·u))，偏差为P−G沿u的横向单位法线的有符号投影，乘1000转毫米。法线向标准假想球远离目标球一侧定向；直球单列左右，不强行定义薄厚。

此公式测量的是同一截面的横向偏差，不再称为旧G1垂足偏差；题面G1标记可以保留，但结果解释须说明测量含义。用户射线是否能接触目标球使用两球半径之和，不能用单个目标球半径误判合法薄球。方向异常先分类；不对近90度导致的极大值做截断后假装高精度。

标准方向、用户提交方向、题面标记与结果线必须同源。不能把文字角度提示绑定到用户方向或把3D投影角当作真实角度。

## 实施顺序与验收

| 批次 | 调整范围 | 必须验证 |
|---|---|---|
| A 出题正确性 | 共享配置与生成器，去最近袋限制与夹位兜底 | 每个开放组合都有合法题；最终实测角度和距离符合配置；左右与袋型配额；失败不扣额度 |
| B 瞄准点流程 | 训练设置、文字提示、删除击球验证、静态结果与手动下一题 | 提示数值同源；提交不运行模拟／运杆／回放；不自动换题；用户方向不被替换 |
| C 评分与记录 | 共同截面毫米误差、反向与错侧分类、提示与作答记录 | 正反向、左右镜像、0度、极薄球；单位／版本；重复提交不重复扣题；历史和同步兼容 |
| D 四入口回归 | 角度页共同设置、结果、总结和3D辅助分类 | 手机标准／SE、iPad横竖；设置取消、额度边界、20题末题、自由退出、3D俯视返回、后台返回 |

数学验收先用独立数值稿对拍，再运行实际生产入口，不能只检查题目声明字段。UI验收核实图形答案与文字答案一致、辅助分类可见、结果可以一直停留。几何单测、构建、模拟器功能与人工观感分别记录。

实施不重建已认可的球桌布局；如设置、提示或结果需要改变布局，先形成对应页面方案并核对既有页面卡。旧P10卡中的「直接开始、1.5秒后验证、停稳自动下一题」将由本次已确定要求及最终审定规则替代，旧验证只作为历史保留。
