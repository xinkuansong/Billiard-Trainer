# 台呢静态化与GPU／画面权衡 v3.0

**本文件是本轮需求真源。** 2026-11-26，用户再次明确：台呢相关能静态的尽量静态，允许预计算近似，需权衡GPU耗时收益与画面损失。状态：已授权继续；覆盖v1/v2中冲突的路线排序与画质判定，已有测试事实不改写。无需重新批准常规研究步骤。

## 需求回显与纠偏

1. 主线是固定灯光／材质／球桌下，跨相机、跨球态复用台呢静态基础，不能把公式微调或扩大LTC范围当作静态化完成。
2. 接受研究烘焙、插值、压缩等近似，并按实际收益与感知差异权衡；不要求与原图逐像素相同。静态化本身不必然损失精度，但不因担心任何像素差而只做无损小改。
3. 球影、遮挡、显隐／半透明等继续响应当前球态，视角相关高光继续响应相机。允许提前计算它们的固定输入；不将动态结果冻结进底图。
4. 帧率设置、屏幕渲染分辨率、交互响应和24Hz轨迹保持。预计算资源的分辨率／精度是研究变量，不等同于降低屏幕渲染分辨率。保持真实物理和动态关系，不以关闭效果取得成绩。
5. GPU净收益和画面差异成对交付。用户允许权衡不是对任意画质损失的预先认可，也不是把旧失败测试改成通过。

此前B2实际只做了C1有效域判定简化，B3是库边复用，C1-MAIN是重复光色运算约简，C2是LTC视域研究；均不能充当“已把能静态的都静态”的证明。既有C1固定照度字段确实已应用，其收益不能再次冒领。

## 静态化范围与路线

| 内容 | 本轮处理 |
|---|---|
| 固定灯照到台呢的基础亮度、固定库边遮蔽、库鼻柔和光照 | 以实际表面为单位预计算／复用；包含床面、库鼻和袋口折面，避免不同表面错误重叠 |
| 固定灯的方向、距离与几何权重，供动态球影／高光消费的常量输入 | 评估紧凑表面表示／系数表示，明确删掉哪些逐像素工作、付出哪些读取；不是重新烘焙已有C1 |
| 材质细节和过滤后的法线／粗糙度 | 逐项区分可烘焙部分和运行时残项；若冻结基础层法线响应会产生视图过滤差异，把实际影响作为候选画质代价测量，不预先因不完全等价否决 |
| 球影、AO、球对高光的遮挡权重 | 同帧动态合成；不能假定一张普通灰影足以等价替代所有方向响应 |
| 视角高光／掠射响应 | 当前视线仍参与；可复用固定系数，LTC作为辅助候选，不占据静态化主线 |

重点应从主循环中拿掉固定工作，而不是仅省库边几次调用。资源与消费者必须一起测；旧H2几何大表、R8候选球格子、H17逐视图缓存的无净收益或资源代价继续有效。允许不同表示／精度形成新权衡，但必须说明与旧版差别，不以用户允许像素差为由重跑本就更慢的同一版。

## 新的权衡判据

- **性能维度**：同基线完整场景GPU毫秒与降幅，主要P01及其他机位、P95/P99、CPU／准备／上传、常驻与峰值内存。继续沿用AA噪声判断和全样本记录，不把理论删式数量当收益。
- **画面维度**：真实台呢及库边ROI的差异比例、分位数、最大值与位置；正常手机显示尺度A/B和连续运动对照。区分“孤立像素差”“大面积轻微色调／质感变化”“接缝、闪烁、阴影／高光动态异常”。最大差仅是定位线索，不是单独否决条件。
- **决策维度**：稳定更快且正常使用难察觉差异的优先；明显收益伴随可见但有限的基础质感变化，展示实图／短视频供用户具体取舍。收益小且损失明显的淘汰。动态影响冻结、明显球影错误、频繁重建抵消收益等违背需求的候选仍修正或否决。
- 不设“超过2色阶就不得继续”或“7色阶自动接受”的替代硬线。既有>2等数值仍保留在报告用于分布和原因分析，不再成为开展后续研究的前置阻塞。
- 数值／状态正确性断言、同帧球态、资源身份与AA／恢复校验保留；仅改变产品画质验收政策，不删除失败断言或重写原结果。

**C2现有结果的新定位**：P01约6.8%–7.0%，四图各1个3–7色阶异常，保留为可比较候选。可做正常尺度与连续画面审查，不再为了这几个像素先停止主线去做昂贵逐片元取证；如出现可见闪烁／接缝或与动态错误相关，再提高归因优先级。它尚不是已通过用户画质认可或手机测试，也不是静态化成果。
