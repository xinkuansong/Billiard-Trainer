# S1 固定灯几何的平床面预计算原型

2026-11-26，按PLAN-v3执行。当前角色：Test Engineer／渲染研究。用户已授权连续执行；不安装手机，不改产品画质或FPS设置。

## 事前机制与覆盖

坐标为SceneKit世界系：XZ水平、Y向上、单位米。固定台面高度0.8，与当前scene及原床面遮蔽条件一致。两灯中心/半轴/样本位置逐字消费冻结基线，输入SHA ca7cae…守卫。实际表面含袋口和库边曲面，不能全部当作XZ平面。

预计算内容：原64近样本及8远样本，在床面位置的单位灯方向和距离倒数；单张RGBA16F图集，8列×9行、72个样本块。两档各块33×17／65×33，完整图集264×153／520×297；原始数据约316KiB／1207KiB，真实Metal allocation另外记录。CPU不按帧烘焙；独立GPU准备一次，镜头、球位、法线、粗糙度均不进入准备输入。

消费者删掉原逐样本灯位置／距离归一化工作，以插值方向和倒数继续原BRDF、64/8球影、法线、粗糙度、AO及LTC范围。方向和倒数插值不是精确单位方向，允许误差但须实测软影、高光及运动表现；不冒称数学等价。仅`abs(p.y-.8)<.0005`且XZ位于实际内框的片元使用，其他表面进入原函数。该高度条件沿用原床面遮蔽资格，不作为整张模型平面性的证明。

与H2区别：H2只缓存far 8样本，采用8张3D纹理；本轮覆盖主要near 64循环，压为平床面2D图集及一次采样返回方向/倒数。不是原H2同版复跑，也不预设一定更快。H2的读纹理开销教训保留，若本版没有净收益就不铺开到所有曲面。

## 原生准备与首轮控制失败

原生宿主`50424c69f5cf4fb1b1e84aaf3a1fc5d0`构建成功，准备与P01基线2测试通过，9.012秒。两档实际常驻分配425,984／1,490,944 B，含诊断纹理峰值851,968／2,981,888 B；GPU生成0.0052／0.0534ms，准备墙钟0.675／0.361ms。首次Metal库编译121.4ms，第二档缓存编译0.120ms；冷编译不能隐入小于1ms的准备结论，若晋级应离线产物化后另测进入成本。

33档首轮`d6791b8b6ca649378ad870178a531935`在实际控制纹理消费断言失败，尚未产生候选性能排名。独立PNG审计`5132656f11e34f35a7665be3f51ca9ea`确认原A与正常候选2020个像素差1色阶；控制纹理替换后没有预期大幅变化。代码核对发现同步离屏流程在替换材质纹理后漏`SCNTransaction.flush()`，不像安装shader时已有提交。补齐控制／恢复两处flush，保留原断言和失败现场，新建冻结宿主复验；未经新复验不能宣称此原因已闭环。原宿主及失败run的work已由生命周期关闭，证据保留，未修改旧签名包冒充原轮通过。

**判定**：S1预声明的这一个表示与两档精度已测完，因性能退化淘汰，不接入生产。不是因像素损失淘汰，也不说明静态化整体无空间。这里仅移出逐样本灯几何计算，仍有8／64次纹理读取及动态积分；新增读取、坐标计算与程序结构的总成本抵消了省下的算术。未取得硬件瓶颈计数，不能把全部退化精确归因为带宽。

主目标未完成，S2没有有效静态原型前置。下一表示必须直接消费已合成的静态基础或紧凑系数、保留同帧动态影响，先列明相对**已有C1合成照度字段**还删除了什么；不能再次只缓存8／64项灯几何，也不能把扩大LTC适用范围冒充静态化。当前资源／消费者拆分还需要进一步设计，现有测试并不证明“整张台呢已静态化”。
