# 台呢剩余高光与材质研究阶段记录

2026-11-14。本阶段已按[v2方案](../问题集合_3D活动期性能优化_v2.md)完成候选实现、验证及淘汰，并用分项消融修正下一阶段优先级。**没有新增可默认接入的优化；已默认接入的C1保持启用。** 未把失败候选、画面破坏性删除或Mac测试解释成手机省电/降温。

## 本轮做了什么

| 路线 | 实际结果 | 决定 |
|---|---|---|
| [PBR与constant依赖审计](H1-PIPELINE.md) | PBR直接只输出emission有10–15色阶差异；constant改变roughness/normal输入，画面明显改变 | 不直接替换 |
| [固定灯样本几何场F32](H2-R1-FIELD.md) → [F16](H2-R2-HALF.md) → [紧凑F16](H2-R3-COMPACT.md) | 新增画面差≤1色阶；F32变慢约5%，最后一版各镜头收益0.35%–2.67%，未过事前5%门槛 | 完成两次定向修订后结束该路线 |
| [far循环独立固定化](H3-SPLIT.md) | 最大新增差≤1色阶，但GPU变慢4.49%–10.14% | 淘汰 |
| [PBR逐灯入口补核](H1-DIRECT.md) | 清零零差；强紫色阳性标记也零差，入口未按预期影响当前输出 | 不误认为已删除原生光照 |
| [far短轴采样8→4](H4-SHORT-AXIS.md) | 俯视最大8色阶超标；其他镜头仅约1%–2%时间下降 | 淘汰，无理由继续资格微调 |
| [1400×800分项成本消融](H5-ABLATION.md) | 近景删整个采样循环时间下降58.85%、删所有高光18.89%、只删far7.86%；PBR末端变化不足3% | 仅作方向证据；新重点转near高密度循环 |

共9次受管原生作业，包含阳性对照和诊断；不是“9次优化成功”。候选初筛700×400、三镜头/6球态（最初管线审计每镜头2态），AA零差；6组平衡GPU对照。只对通过初筛的候选排名；H5显式作为破坏画面的诊断例外。没有为了显著性重跑同一候选。

## 与原方案的关系

- 继承B1/B2、C1、坐标/物理、HDR/4xMSAA、帧率及质量/净收益门槛。
- 本轮确实先做截图中的far高光与PBR核查，避开旧Smith分解、时间缓存、CPU基准重复验证。
- 几何预计算不等于高光完整预积分；该路线只省固定灯方向/距离项、保留实时BRDF，实际收益不足，已明确停止。没有声称已完成通用高光预积分/LTC。
- 依据新测量将下一阶段重点修正为near64中的重复遮挡/高光，更新到v2；没有改变“保留画质、不降低帧率”的需求。
- 远区高光完整预积分、near遮挡与高光分离、正式App整页对照及手机持续能耗仍未完成。新候选尚未成立，所以未追加六颜色/1400候选验收、iOS构建或手机安装；H5的1400是成本诊断。
