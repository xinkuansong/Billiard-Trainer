# H14：更换运算实现，保留逐像素光照

执行完成：[四轮交付](H14-DELIVERY.md)。本页保留事前设计与过程调整。

2026-11-14，用户要求围绕台呢、木台边和桌腿换方向，不重测失败路线。当前角色：Orchestrator → Test Engineer。

## 事前依据与范围

H13已确认低位木台边/桌腿具有可观GPU成本，近景台呢仍占主要成本。顶点插值、流式裁剪、缩纹理、减采样、球状态预计算、Smith公式拆分等历史淘汰保持关闭。本轮没有生产改动，基线仍是B1/B2/C1＋H9。

几何合同不变：SceneKit XZ水平、Y上、米；+X长边、+Z短边；台面0.8、球心0.8+0.028575。沿生产showBall并断言高度，不简化法线/粗糙度/视角/阴影，不改变球形与帧率。

## R1 两个独立候选

- 木台边＋桌腿：保持原裁剪数组、逐像素法线和光照积分，仅替换每个边的atan2。通过独立脚本对atan(sqrt(u))/sqrt(u)做9阶Chebyshev拟合，Float32 Horner FMA计算，四象限还原；实际调用y>1e-7、x有正负，不存在0/0。40万点host Float32角误差最大约2.98e-7弧度。它不等于图像或GPU验证；多项式也可能比内建函数慢。
- 台呢：仅G/F高光响应使用half，D及小分母、位置/法线/方向、遮挡资格、距离、权重与所有累加保留float。不减少采样，也不复用H2的F16缓存方案或Smith代数拆分。收益假设是局部ALU/寄存器成本降低，转换成本与精度损失由实际结果否决。

沿H13已核当前材质的Designed for iPad原生Mac夹具，1400×800、HDR/4xMSAA、近景/低位2球和俯视16球，绿色/炭灰/赛事房间；实际C1/H9 SHA与球反射函数/资源身份断言保留。每候选独立AA/AB/恢复；最大新增通道差≤1/255才运行6组交替ABBA/BAAB，每臂每组24帧，原始GPU span/CPU编码/同步墙钟全留、不裁样。目标收益>max(5%,abs AA)，非目标回退≤max(3%,abs AA)。已有CPU成本不重做排名。

若通过初筛，再做有针对性的外观/动态/尺寸扩展并接入共用生产入口；失败则记录关闭，同一候选不反复重测取最好。可继续一条有新依据的实现方向，每方向最多两次有依据修订。不会以“公式更少”代替性能结论。
