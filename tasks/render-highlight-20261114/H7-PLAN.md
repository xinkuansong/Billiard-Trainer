# H7：保留每盏灯的遮挡球集合

2026-11-14，H6分组高光路线结束后继续此前方案的重复遮挡项。实际锚点：`DailyClothSupportExperiment.guardClassification`已经对每个panel、每个shadowMask球计算`diagnosticInside`，但只保留OR到`diagnosticGlobalQuality`，原样本循环随后用全局shadowMask。

候选仅将既有逐灯/逐球结果存成两个uint掩码；对每盏灯按原球索引顺序遍历该掩码。判据、圆盘滤波半径、误差扩张、64/8样本、BRDF及累积公式均不变。域外保持全部原mask；灯与接收点的退化高度同样保持原mask。far保持原不计算遮挡语义。

保守性来自已有每球/每灯锥面排除判据：只有已能证明该球对这盏灯所有原样本无贡献时才从该灯掩码去掉；不把对一盏灯的排除推广到另一盏灯。不增纹理，不增加新的几何分类。

事前门槛：AA/AB图像零差；原生700初筛，成立后1400/六色/边界/连续球态及实际球遮挡复核。GPU沿H6近景>max(5%,AA)、其他镜头无>max(3%,AA)稳定退化。晋级前另做Float32数值反例：若任一样本可被球遮挡，该球不得被对应灯掩码排除，覆盖域内/域外、台呢实际高度范围、球半径/透明度和近/远采样。

状态：R1–R3共5候选已完成初筛并淘汰，H6试验未混入本候选。初始逐灯mask近景约4.24%仍未过门槛，相对向量/距离平方复用未形成更大收益。没有晋级，故独立几何排除反例与扩展画质/整页尚未执行，不记为通过。生产仍为C1，见[阶段交付](H6-H7-DELIVERY.md)；后续先读已捕获的GPU程序统计。
