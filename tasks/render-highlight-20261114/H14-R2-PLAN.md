# H14-R2：利用角积分的尺度不变性

2026-11-14，R1构建期间完成数值准备；实际启动及原因以R2记录为准。本页为事前设计。

保留原矩形裁剪数组、遍历顺序、原生atan2与逐像素法线，单独移除每条裁剪边上a/b的两次normalize。因为cross(a,b)与dot(a,b)同时按|a||b|缩放，atan2的角度不变；dot(c,n)/|c|的比例也不变。近共线阈值由|cross(normalize(a),normalize(b))|>1e-7等价改为|cross(a,b)|²>1e-14|a|²|b|²。不是H13的流式拓扑实现，也不叠加R1近似atan。

独立double实现核了24,084个多边形（随机位置/法线、正反轴、切过角点及地平线两侧），积分最大差4.996e-16，见H14-unscaled-numeric.json。Float32舍入、GPU寄存器及实际吞吐仍未知，必须用原生场景图像与时间判断。

仅wood＋legs，三机位、基线、画质与性能门槛、6组AA/AB原始帧及资源预算均继承H14-PLAN。若候选通过，进入外观/机位/尺寸扩展和生产接入；未过则关闭，不重跑取最好。生产仍不变。
