# H5：采样循环成本消融（2026-11-14）

目的：前四条候选路线均未成功，不能继续仅凭源码求值次数将far/PBR认定为首要目标。以下临时删除会破坏画面，只诊断实际GPU时间对各部分的敏感程度，**不是可发布方案，也不是已实现的收益或能耗占比**。

## 条件与口径

本机Apple M5 Pro / 48GB / macOS27.2，原生SCNRenderer；真实USDZ台呢、C1、法线/粗糙度、两盏灯、HDR、4xMSAA保持。1400×800，少球低位/少球近景/多球俯视各6个球位uniform状态；没有实际球模型、SwiftUI页面、房间、击球物理或手机。保留导入桌体其他材质。与前三个镜头的实际着色、几何对齐共用同一基线。

每种删除、每个镜头各6组AA及6组AB，顺序交替ABBA/BAAB；每臂每组24帧，切换后3帧预热。统计每组两臂平均GPU command span的相对变化，再取6组中位数；不是把各组最优值挑出来。全部AA画面零差。所有frame检查有效GPU时间戳、命令完成状态和Mac热状态非serious/critical；没有温度/功率/频率采样。

CPU编码/同步墙钟也已记录在[汇总JSON](results.json)及原件；它们只覆盖原生renderer调用和提交，不覆盖App的SwiftUI、物理、交互更新。没有将GPU时间差转换成UI CPU占比。

## 对优先级的修正

1. **近球影区的高密度循环是近景更值得投入的对象。** 仅移除far约8%，整个循环约59%；删除全部高光约19%。这些差值不可直接相减并宣称严格模块占比，但足以支持先研究near64中的遮挡和高光如何分别计算/复用。
2. far仍有成本，但保留画质的几何场/短轴压缩均未通过，继续同源调纹理尺寸的预期价值低。
3. PBR确实有可见贡献，当前绕过末端输出只有约0–3%的时间变化，且不是完整替换PBR。应后移替换材质管线，不能据此说整个PBR只占3%。
4. 下一候选应先保留原near64遮挡与AO，单独探索其高光响应的分离/复用，再评估是否能减少重复遮挡；必须处理球影边缘、掠射、低粗糙度和球运动连续性。没有取得这些资格前不能默认接入。
