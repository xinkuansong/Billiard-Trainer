# 渲染代码优化 S1：复用同次标签布局的视口边界（2026-10-02）

状态：本批局部实现与模拟器验收完成，Debug/Release构建及门禁通过。整体方案仍进行中，未合并main或装入手机，不代表全App加速。

## 保留的改动

`DiagramLabelOverlay.update` 对每个候选位置、后备候选位置都读取 `view.bounds` 并执行同一个6pt inset。这个方法在MainActor同步执行，过程中没有改变所属SCNView的bounds；把边界作为本次调用的局部CGRect计算一次，候选检查复用它即可。下一次调用仍从真实bounds重新计算，所以resize、旋转、相机/球变化不需要新缓存失效机制。

Release使用具体CGRect和局部函数；DEBUG增加默认false的旧路径对照开关，只用于配对测试。候选位置、文字测量、排序/迟滞、避让、选择及绘制均保持。物理、开球参数、资源、shader、灯光、反射、阴影、MSAA和请求帧率未改。

该优化只作用于启用自适应图解标签的角度页面，每日清台不启用这套标签，不能据此宣称每日3D或开球渲染加速。
