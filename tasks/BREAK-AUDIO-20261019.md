# 开球球堆瞬间音效去重 · 2026-10-19

用户授权：保留母球撞头球第一声，抑制紧密球堆内部的瞬间重复音效，球散开后的碰撞正常保留，完成后试听。

## 判断与范围

仅修改 `ShotAudioScheduler` 的声音时间线，不改物理引擎、碰撞事实、摆球、球路、已有样本及力度曲线。

1. 第一条有效球球接触必须包含 `PositionPlayBall.cueKey`；保留其时间、类型、速度。以被撞目标球为头球，从该接触时刻启动判定，而不是从出杆时刻计时。
2. 读取出杆前 t=0 的静止目标球位置。按球心距离建立紧邻关系，阈值为 `2R + RackLayout.gap + 2*RackLayout.jitterRadius + 1µm`，当前等于 0.057531m；最后 1µm 仅为 Float 比较容差。坐标为 SceneKit 世界米制，X–Z 台面、Y 向上。头球所在连通组至少含三颗目标球，否则沿用原声音。
3. 仅合并这个组中**初始紧邻球对**、且沿已受冲击球传递的接触。母球与头球间的瞬间重复接触也合并，但第一条永远保留。无关球、同组但原先不相邻的球对，以及球库、袋口、袋内声音保持原规则。
4. 对每条紧邻关系扫描引擎记录的同刻双球位置；首碰后只要球心距离曾超过上述紧邻范围，永久解除该球对本杆的抑制，即使随后在短时间内再次相撞也播放。使用记录的共同时间戳，不用 `stateAt` 的下一帧猜碰前位置。
5. 另外设首碰后 20ms 的不可续期上限。该值为第一版试听政策，依据此前密集开球记录选择，**不是实测物理接触时长**。超过上限所有接触恢复原播放政策。旧记录缺少初始球位、未形成静止紧邻组或首条并非母球碰撞时不启用去重。

本策略也适用于普通击球打散至少三颗目标球的紧密球组；不依赖页面或玩法名。分离判据的精度受现有轨迹快照及上述摆球邻域限制，不能描述为连续声学仿真。
