## 六组定义

| 标签 | 碰撞算法 |
|---|---|
| production | 当前生产算法，增加只读记录 |
| baseline | 此前mode2：实际接触时序、边界求根、对称矢量计算；原两球及Han模型 |
| coulomb | baseline上，球球滑动切向冲量上限改用μJn，Jn/m=(1+e)u/2 |
| joint | baseline上，对实际接触的连通多球共同求冲量；不扩大接触距离或合并时间窗 |
| support | baseline上，库边与台面接触共同求冲量，球球部分不变 |
| combined | 同时启用coulomb、joint、support |

`coulomb`的旧上限为μ·e·u，新上限为μ·(1+e)·u/2。在e=0.95时约增加2.63%，μ/e自身没变。它是接触律的对照，不应冒称移植错误修复：[pooltool现有frictional_inelastic源码](https://raw.githubusercontent.com/ekiefl/pooltool/master/pooltool/physics/resolve/ball_ball/frictional_inelastic/__init__.py)也使用旧式上限。

## 库边与台面共同求解的含义

SceneKit坐标XZ为台面、Y向上。N为朝向库边的水平单位向量、U为向上，R/h取现值。库鼻反力方向为

`n = -N*sqrt(1-(h/R-1)^2) - U*(h/R-1)`。

一个球同时建立两条约束：库鼻的恢复和摩擦约束；台面的法向支撑和现有滑动摩擦约束。用已有SpatialBallContact耦合冲量求解器，同时计算线速度和角速度。台面初始法向速度为0，恢复目标因此为0；这里没有新增“地面恢复系数”进行调优。使用原球惯量2mR²/5，无新刚度、碰撞时长或经验阻尼参数。

此处**物理系数固定，但接触模型确实发生了变化**。Han单接触响应与库边/台面双接触响应对平动、转动的分配不同。旧Han在本次实测轨迹里也没有总动能增加；不能把新方案尾转短等同于“已证明旧模型凭空造能”，也不能仅凭更顺眼就认定新模型真实。

库边求解后检查平动＋转动总动能不增加、竖直残差<1e−8，才清除竖直数值残差。任何求解异常都会记录并把整杆标成research_failed；诊断用回退不计作成功。此次1392杆无此回退。

## 为什么不是靠隐藏自转

- 平均峰值竖直轴角速度baseline约251.72rad/s、support约247.16rad/s，并没有把峰值截到很小。关键差异包含后续反弹路线、退旋及最后剩余的自旋。
- 全台平均平移结束时间baseline8.006秒、support7.208秒、combined7.084秒。没有通过延长其他球平移来遮住尾转。
- 跟踪baseline中114副>5秒的同一颗问题球：support和combined均有34颗改为落袋，另80颗仍在台面且全部无全台停移后的尾转。因此改善有部分来自轨迹与落袋变化，但不是全靠把问题球送入袋中。
- support仍有34/200副>1秒，combined仍27/200副>1秒；“200副无>5秒”不能写成“彻底消除自转”。

原生产最差样本之一11331、槽位10对应12号球的完整碰库账本见`case-11331.json`。它在生产的峰值252.25rad/s、尾段9.264秒；时序修正后该同名球本身已无尾段，故不能拿这个例子单独证明support收益，群体对照与同球跟踪才是主要证据。

## 对密集球阵与分散度的结论

在现有正间隙球阵中，baseline接触图记录7171次只有一条接触边、18次有两条；joint实际触发13次，combined11次。最早联合事件距首次碰撞约14.9微秒，确有少量早期多接触，但远非整个球阵一直同时接触。不能扩大碰撞时间窗或接触距离来人为造出“整阵联合传力”。

首次碰撞后5ms，两个底角占目标球平动能的均值：baseline95.28%、support95.28%、joint95.37%、combined95.39%；生产约80.31%。这个比值不含母球及转动能，不是总系统动量或能量。support在第一次碰库前没有改变球阵内部能量集中，因此它改善了碰库以后的表现，**尚未解决初期传力过于集中**。

单改切向上限或实际接触多球联合，没有解决长尾，也没有恢复生产的开散均分。当前生产还有已复现的提前接触/顺序偏置，不能通过保留这种偏置来宣称物理与分散度一起优化成功。

joint仅为研究原型：三维冲量后仍沿用平面速度投影，缺少多球与台面共同约束；接触录音/逐边事件语义也未完成生产适配。一个三球零间隙夹具通过不等于全零间隙球阵已验证。后续应先将球球接触与台面支撑联合纳入同一固定参数的约束体系，再验证传力，不引入未标定刚度或接触时间来追高分。

- 没有真球台、真机、完整App、跳球或库边形变验证；这些限制不能被模拟停稳和数值不变量替代。
