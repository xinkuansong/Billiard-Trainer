# 每日清台选球选袋修订（FL-095）

本报告覆盖 DAILY-SHOT-RANKING-20260928.md 中的首版方案。

## 现行契约

1. 自动选球：合法目标按距母球由近到远，逐个调用选袋几何。每球选可行袋中切角最小者；≤60°立即停止，不评后续球。全部>60°时才在已检查组合中取最小切角；全部无几何路线才临时自由模式。
2. 手动球：只查该球六袋，超过60°不换球。手动袋：只检查几何路线，不设60°禁用门槛。调力度/打点/微调不重新推荐。
3. 下一杆重置手动选择；当前目标规则失效时重新选择。撤销保留手动状态。
4. 几何函数不调用物理预测、球杆姿态或袋角轮廓搜索。选择球/袋之后由原预测管线计算轨迹；predictGeneration及取消令牌保留，旧结果不能改变选择。

## 几何范围

SceneKit X/Z水平、Y向上，米；六袋与点击编号共用pocketPositions/pocketJaws顺序。检查袋中心/少量有效开口点，假想球位置、切角<89°、两段球路球半径排障、直库线段排障。切角89°为原几何可击阈值，不是60°推荐阈值。

贴库相切允许，1微米仅为Float舍入保护；沿库球保留沿直库平行方向，曲面袋角不在这次简单几何中作硬否定。几何可行不承诺实际力度/旋转下必进，球杆可达性仍由原击球层单独处理。

不再包含：目标球距袋难度、容错倒数分数、抬杆惩罚、10%切换保持带、全台联合评分。
