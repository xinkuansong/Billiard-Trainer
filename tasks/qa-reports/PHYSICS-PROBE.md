## USDZ 网格实测标定（P10 Track B-1，2026-06-04）

> 探针：`QiuJiTests/TableGeometryProbeTests`（`test_probe_A1..A4` 实测、`B/C` 进球覆盖诊断）。
> 方法：`TableModelLoader.loadTable()` 取运行时同坐标/同缩放的 `TaiQiuZhuo.usdz` 网格，
> 遍历顶点（经 `worldTransform` 转世界系），按 8 个材质 element（`TaiNi` 台呢 / `Leather`

### 实测结论（出乎「17mm 错位」预设）

| 测项 | 实测 | 解读 |
|------|------|------|
| 长库库鼻 z | ±0.635（库冠内缘 ±0.641，外悬 ~6mm 正常） | 与解析 `±innerWidth/2` 一致，**库边无需校** |
| 短库库鼻 x | ±1.27（库冠内缘 ±1.252，外悬 ~18mm 正常） | 与解析 `±innerLength/2` 一致，**库边无需校** |
| 角袋皮兜 patch | bbox x[1.260,1.405] z[0.627,0.777]；内角 ≈(1.26,0.627) | 袋心/标记位置可信 |
| 中袋皮兜 | bbox x[±0.053] z[0.686,0.776]；开口半宽 ≈±0.046 | 现 jaw mouth ±0.035 偏窄（非阻塞后续） |
| 角袋 jaw 尖端距袋心 | ≈58.6mm | 真实喉口远大于旧捕获窗 13.4mm |

**根因再坐实**：rattle/进不去**不是 jaw 放错 17mm**，而是 ①旧引擎袋口只是**袋心一个圆**（捕获窗 0.042−R=13.4mm 甜点 / 后改 0.055 仍是放大的圈），无真实袋口内部结构，球要么命中甜点、要么从袋口缺口穿库飞出；②闭环瞄准求解在窄口多峰景观下偶落坏局部最优。jaw 圆弧/直线段本就与库边精确相切、自洽，几何无需重导。**用户判定「放宽捕获半径」是偷懒、非真实袋口物理**，遂改建袋口真实结构。

### 标定动作（已实施，真实袋口物理 = 喉腔模型）

1. **喉腔模型**（`TableGeometry.chineseEightBallQiuJi` + `throatCushions`）：每个袋口 = ① jaw 库（偏转切球，保留）+ ② **喉腔**——由实测 jaw 尖端（`pocketJaws`）沿喉轴 `n=单位(P−M)` 挤出**两条侧壁 + 一道后壁**（可反弹线性库，法线朝腔内）+ ③ 喉腔内**物理落袋孔** `P`（`pocketDropRadius=0.052`，球心进孔即落袋）。**rattle 由几何自然涌现**：被 jaw/侧壁偏转或过力度的球撞后壁弹回、可能从 mouth 逃出 = 未进；对准的球抵达落袋孔 = 进。喉壁把袋口「穿库飞出」从 ~8% 降到 ~2.7%。落袋孔半径仅表示物理洞口、不承担"放大强行进球"，与视觉标记半径 `*PocketRadius` 解耦。
2. **两种逻辑分清**：(A) 袋口判定（正向）＝球沿某方向来、由喉腔真实几何决定进/rattle；(B) 瞄准求解＝固定力度+塞，`solveAimOffset` 采样/寻优最优接触点（发射偏移），在 (A) 真实袋口下让目标球落袋（直接进 或 借 jaw/壁导进），打不进则如实报。
3. **闭环求解稳健化**（`solveAimOffset`）：「短模拟真进选定袋」首要评分（−10 基线压过一切未进解）；scratch 仅 mm 量级轻罚（**严禁 1.0 大值**——会压过 objMinDist 把求解逼到「不进也不刮」差解）；粗扫加密 ±16°/0.5° + 两级细化。
4. **画面=物理**（`ShotPredictor.predict`）：`objectPath` 取真实模拟折线（含穿喉腔反弹/走位/rattle）；`objectPocketed/simObjectPotted` 改**轨迹基**判定（显示轨迹最近点进落袋孔窗），与画面一致、消除穿库假阳性。`ShotSimulationViewModel` 诚实显示进/未进与提示。

## 截图驱动复盘：喉腔弹珠箱 → 漏斗袋口模型 v3（P10 Track B-2，2026-06-04）

> 探针：`QiuJiTests/ShotScenarioRenderTests`（CoreGraphics 2D 顶视**接触表 PNG**：库边/jaw 直线段/jaw 圆弧/落袋孔/标记/幽灵球/瞄准点/母球+目标球真实轨迹/进袋判定，一并渲染到 `build/shot_probe/*.png`）。
> 动机：照相级 SceneKit 渲染遮住几何，无法肉眼判断「轨迹 vs 袋口几何」是否自洽。用 2D 诊断图对**不同袋口×切角×塞×力度**矩阵出图，直接看真实情况。

### 截图暴露的真问题（喉腔模型仍有的硬伤）

1. **进袋带碎裂/非单调闪烁**：角袋 cut15 在 v2.4/v4.4/v5.8 进、**v3.3 偏不进**（objMin 135–192mm）。诊断扫描瞄准偏移发现进袋呈**斑点状**（+0.2 进、+0.3 进、+0.4 不进、+0.5 进、+0.6 不进…每 0.1° 翻转）——对 15° 中速角球这**物理上不真实**（真实袋口应有连续宽容差窗）。
2. **根因 = 喉腔「弹珠箱」**：高恢复系数（e_c=0.85）的喉腔侧/后壁把**对准的球**在腔内反复弹射，只有恰好穿过 23.4mm 小孔才落袋 → 进袋带被弹射动力学打成碎片。喉壁不是真实袋口（真实袋口是**导球漏斗**，不是弹珠台）。
3. **求解-上报双景观错位**：求解用短模拟（140ev/7s）、上报用全模拟（500ev/15s），两者进袋带**不重合**（短带≈+0.5°、全带≈0–0.3°）→ 求解器在短带寻优、结果按全带判定，必然偶发「判进画面不进」。
4. **缓行入袋被显示截断**：钳制器 `effDuration` 用 0.02m/s 速度阈值提前结束 → 球减速到 <0.02 后才滚进洞的「慢进袋」被截成「停在喉口外的未进」。

### 修复（漏斗袋口模型 v3 = 真实袋口几何）

| 改动 | 文件 | 作用 |
|------|------|------|
