# 小屏 AX5 根页可达性结果

2026-09-06。独立逐张查看 `build/quality-diagnosis/formal-extra-m2-ax5-reachability-001/screenshots/` 全部 **8 张 PNG**（750×1334）。主控报告两项 2/2、make 退出码 0、32.444 秒；本审核只读截图，不重复执行、不操作 Simulator、不读取进行中的昵称/模板产物。

## 结果

本轮补齐了两个具体缺口：正常游客训练根可以通过滚动避开浮动按钮并实际切换入门→中级；历史空态 CTA 可以滚动露出并实际回到训练根。首屏浮动按钮遮盖筛选的视觉事实仍成立，但本次没有发现因此永久不可操作；不能据通过删除原始遮挡记录。

## 断言与视觉证据的分工

主控执行通过包含 chip selected trait、预期卡出现、入门卡不再存在以及没有 activeTraining.timer 的断言；截图独立支持选中外观变化、结果首排变化与仍停留货架。单张图不能证明整个懒加载列表不存在基本功，不能用视觉首排缺失替代已执行断言。

历史旅程通过包含 CTA 全 frame 在屏内、hittable、点击后的训练根出现及原 CTA 不再 hittable；截图支持滚动可见和实际目的地。两张相近的滚动前历史图属于过程留证，不当作两次独立验证。

## 保留边界

这只是小屏 AX5 下两条正常游客/Free、内存空状态的可达性诊断。没有证明所有等级、货架底部全部卡片、其他历史月份/有记录状态、全部 Tab 控件、真实 VoiceOver 朗读、其他字号或真机通过。浮动按钮在中级结果图仍覆盖下排卡图；本次没有打开该被覆盖卡片，不推断其可操作性。本报告不修改业务，也不扩大为全页可访问性通过。
