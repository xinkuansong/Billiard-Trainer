## 坐标与公式

SceneKit世界X/Z水平、Y上、单位米；台面以中心为零，长宽取现有Geometry.source（与BTTablePhysics的Float值一致）。中袋孔心取AngleSceneCalculator.pocketPositions，与已审v2图册一致；原基础评分使用自己的库沿锚点，原遮挡/可打检查仍使用effectivePocketAimPoint，各自口径不混换。

n=normalize(P−B2)，G=B2−2R·n，u=normalize(G−C)，t=u−dot(u,n)n。瞄准直线C→G延长切分内框矩形；取垂直u、朝向t一侧的单位法向q。dot(B3−G,q)<0且t非零为反向。正向直击之外/退化输入不生成快照；同侧、线上和恰好直球K=1。

反向时d=−dot(B3−G,q)，r=第三球侧面积/全台面积（矩形半平面裁切＋鞋带公式），s=|C−B2|，θ=acos(dot(u,n))，clamp为[0,1]：

```
D = clamp(d / (0.35L))
A = 0.75 + 0.25r
C = 0.60 + 0.40 clamp(s / (0.35L))
B = 0.40 D A C
M = 0.70 + 0.30 clamp(((θ−30°)/25°)²)
K = max(0.60, 1−B M)
```

K不小于0.6，不超过1；角度只调整反向基础折减，没有加分。它是经用户选择的几何评分规则，不是下一杆成功率或多库求解器。保留图册已披露的限制：综合球形改变切角也会改变离线距离，高角度综合K不保证单调；近直球的分侧不是物理连续路线模型。
