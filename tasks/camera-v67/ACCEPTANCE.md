# v67 试点验收与体验入口

本轮只交付正式「分离角与走位」的新相机。源码与结果身份以[实施账本](IMPLEMENTATION.md)为准。本轮定向原生矩阵已完成，具体来源和未验事件分别列出。

## 体验顺序

1. 角度 → 走位 → 分离角与走位，菜单切到3D，选择第三人称。母球偏下、杆轴居中。
2. 在进袋模式沿杆瞄准时左右滑动桌面，第三人称侧看后保留机位，第一人称转头后松手回正。两种视角下，真实杆向均应保持。第三人称上下滑动调高度，双指缩放调距离。
3. 滚动方向尺，进入手动自由瞄准，镜头随真实杆向回到沿杆构图。可以连续滚动，也可以在回正途中再次滑动桌面接管。
4. 在自由模式下，分别用第一、第三人称横滑桌面。杆向随手指转动，杆轴在画面中线，松手后的新方向应保留。来回切换两个视角时，观察母球从一处偏下位置连续移到另一处。
5. 切全桌观察、临时俯视，再返回；全桌观察时滚动方向尺回到最近使用的瞄准视角。
6. 在进袋模式侧看时，先点一次当前目标，再点另一颗可进袋目标。两次机位应保持，第二次需更新目标及辅助线。再沿杆换球，观察相机是否连续对准新杆向。
7. 试靠长库、短库和角袋，再验证击球、回放、重打与 2D/3D 往返。

以上参数和松手回正手感仍是候选。用户未确认优化完成，状态保持“试点优化中”；不会自动推广。

|只改杆速、打点/抬杆、求解迟到|消费端保持现有业务路径；独立完整原生组合尚未验，不能据编译通过宣称全覆盖|
