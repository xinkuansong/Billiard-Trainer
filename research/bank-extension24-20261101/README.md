# 二库／三库线路延伸小样

继承一库反射线路，沿反射线延伸至实际首先遇到的球心边界。新的库与上一库不垂直则拒绝；落在袋口开口或端部4cm内也拒绝。在新库反射后重新摆目标球和母球。二库/三库保留同一个根ID及逐级父ID，父路线是线路种子，不表示同母球/目标球已经通过上一库数物理。

母球条件沿中远台12题：球心距≥40cm、空间≥85、六袋最小合法直打角≥45°、实际翻袋切角≤35°；距离/综合分仅展示，不淘汰远台。本次小样沿用13个目标点比例、9个切角、13个距离的有限网格；不冒充全量方案的128随机母球候选实现。

新中袋条件：种子最后一段与长库≥35°且末碰库球心在生产MiddlePocketRegion内；实际末库后至进袋前（有袋嘴接触时止于首次袋嘴接触前）采33个速度方向，最小对长库夹角≥35°。不消费捕获后的收球动画，不用袋角反弹后的方向冒充末段进球方向。原始速度样本保存供独立复算。

目标24题：2/3库×中/底袋×3直打角度档×中/远距离。保留生产求解后无塞参考解、无母球落袋、无二次球碰、实际主库数/序与垂直关系，原生独立重放事件和完整评分。类型化JSON读取保留FL-239修复。audit.py另核全路线树反射及第一边界、父子前缀、对称、球位、实际库序、分数和入袋角，并注入错误反例。
