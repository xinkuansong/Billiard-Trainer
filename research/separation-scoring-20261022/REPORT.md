# 分离角练习：真实轨迹评分示例 r1

2026-10-22。用户授权：用真实球形叠加目标与不同打点／力度下的实际轨迹，先判断评分是否符合直觉，不改 App。

本轮复用当天已经完成的逐组合自动瞄准补偿物理研究。没有重新启动模拟器，也没有修改 App、生产测试或题库。这里的“实际轨迹”指正式物理引擎的模拟输出，不是真人实测。

## 球形与数据来源

- 同一真实球形，三个目标路线：不吃库、一库、两库。不是三个不同摆法。
- 来源：`../joint-trajectory-20261022/scan-results.json`，原协议、研究 XCTest、编译研究代码和证据路径都在该目录。本轮仅取 `directionDeltaDegrees == 0` 的主实验，逐例核 `direction == solverDirection`。
- 球形源：准度布局研究 `grid-layouts-with-combinations.json` 的归档样本；母球 X/Z=(-0.1914796533,-0.2239050948)m，目标球=(-0.7515060473,0.1165060569)m，指定 pocket_2（本横图左下）。原生成标签15°不充当实测切角答案。
- 坐标：SceneKit X–Z，单位米，Y向上；横图右+X、下+Z。球桌有效长宽254×127cm，球径使用原始记录的 `2*radius`。库段、袋口、圆弧来自同一归档几何；不以无限反射线替代真实轨迹。
- 三条目标分别为 `four-0-A-1111`（0.75m/s、横-0.25R、纵0）、`four-3-A-1111`（1.6875m/s、同打点）、`two-7-A-1111`（2.9375m/s、横0、纵+0.25R）。目标均进指定袋、母球未落袋、停稳、出杆姿态可达。
- 每组8例：原样、力度±8%、横打点-0.05R、纵打点+0.05R、三参数联合变化、固定增加3档杆速、不同库序中的最近停点。最后一例是在有限已采样集合中筛出的反例，不宣称连续空间最优。
- 原始 `four` / `two` 是来源线路家族，实际库序重新读取各杆事件，低速目标按真实不吃库／一库重新命名。
- 哈希保存在 `validation.json`；本轮与原归档对拍的生产物理文件均无漂移。完整原始轨迹仍由来源记录保管；`examples.json`保存本轮选中例、接触锚点、原始折线和分数。

## 试算公式（参数先固定，不按例子反调）

采用70分路线＋30分停点；本轮将路线细分为前段30分、全程40分。

令球径D约为5.715cm，`Q(e,h)=2^(-(e/h)^2)`：误差为h时该分项得一半分，误差为0时满分。

1. **前段30分**：从各杆真实碰撞锚点起，比较相同已行进距离上的母球位置。长度取目标碰球后前30cm与实际目标路线总长的较小值；实际提前停球则停在其末位。121个等弧长点的空间均方根误差为E前，得分`30*Q(E前,D)`。不平移对齐碰撞点，因此自动补偿带来的真实接触位置变化仍保留。
2. **全程40分**：相同库序按碰球→第一库→后续库→停点分段，各段按0–100%弧长进度取121点；各段均方误差等权汇总后开方得到E全，得分`40*Q(E全,D)`。不同库序不能按事件一一对应，暂用整条碰后路线的弧长进度比较，同时明确标为“库序不同，路线未完成”。没有最近线段随意跨段匹配。
3. **停点30分**：真实停点距离E停，得分`30*Q(E停,2D)`。
4. **总分**为三项之和。进指定袋、母球不落袋、有效接触、停稳和姿态可达为基础条件；库序一致为路线条件。条件不满足时仍可展示诊断分，但不表示完成，不用一个“60分及格”规则覆盖条件。

上述半分尺度与30cm前段长度只是可评审的初始参数，未做真人标定。图中统一标“试算”，没有擅自定义优秀／及格分档。

**已知取舍**：全程按各段相对进度比较，所以路线分也会受行程长短影响，与停点分有部分重叠；这轮故意保留该具体口径供评审，不声称已将方向和力度误差完全解耦。不同库序采用另一对齐方式，库数变化边界可能存在评分不连续，正式定版前需专门扫描微扰；当前反例只证明条件标记有效，不证明所有边界平滑。

接触锚点从原始记录中独立保存的 `postContactLength` 恢复，逐例要求剩余折线长度误差<0.05mm，且母球心到初始目标球心距离与真实球径误差<0.1mm。绘图使用原始折线，不做贝塞尔拟合；仅序列化小数舍入到0.1微米，评分仍用原始数值。完整展示击球前路线与目标球路线，但评分只消费碰球后的母球轨迹和末位。捕获之后的回球架／收球动画不进入图或评分。

## 初步发现（等待用户判断）

|目标|力度-8%|力度+8%|横打点-0.05R|纵打点+0.05R|
|---|---:|---:|---:|---:|
|不吃库|82.3|80.8|94.1|95.1|
|一库|68.7|56.5|81.6|64.7|
|两库|45.0|44.0|30.3|38.8|

- 不吃库反例：实际走一库，末位仅差0.6cm，停点29.9/30，路线29.7/70，总59.6，但路线未完成。证明只看停点会丢失走法差异。
- 两库反例：实际只走一库，停点差7.3cm，总50.4，路线未完成。
- 一库组中的“不同库序最近停点”仍差20cm，不能把它说成几乎同停点；图中保持真实误差。
- 相同百分比输入扰动在三个目标中造成不同空间偏差，且可出现打点与力度变化互相抵消。评分只按效果，不按输入差距扣分。
- 两库小扰动得分下降较快，需用户判断当前尺度是否过严；尚未证明应该按题目难度放宽。
