# 一库翻袋／最佳直打对照

用户批准的24题校准样本：两种翻袋袋型 × 最佳直打角度分约20/40/60/80 × 直打距袋近中远。先判断值得翻袋的筛选阈值；不是正式大库或App资源更新。

生成起点是一中袋4、一角袋0。剔除袋口后的有限直库两端各留4cm，以长库24／短库12分层、区内固定随机；球心接触线向桌内偏移一个球半径。按最后一段来向使用effectivePocketAimPoint，理想镜面反射后在首次到达下一边界之前放目标球。沿线采用抖动分层f^1.7的近库偏置，记录球面到有限主库段（含端点）的最近净距。母球按假想球、切角和距离网格生成，原始几何只作种子，最终路线来自生产求解和精确出杆重放。

DirectAngleResearch.swift从当轮DailyShotRecommendation派生，仅将合法袋口候选的排序目标total换成共享ShotComfortScore.angle；删去未使用的legacy类型转换扩展。原生产文件不改。每袋最佳候选、六袋最大者与无有效候选情况均区别处理。空间不参与评分排序，最终两种参考解均另行检查真实出杆可达性。没有合法直袋的候选不适用于本轮分数对照矩阵，单独统计而不伪赋0分。

分数是排名量、非概率。近中远按最佳直打目标球到有效进袋点距离<0.8／0.8–1.5／≥1.5m。分档目标±8是抽样容许偏差，不是入库线。每格挑接近分档中心者，再以近库轻权重排序；不强求最终24题仍服从原候选的近库概率分布。每个母版候选只使用固定一次对称变换后版本，四种变换分配均衡，变换后重算评分和物理解，数量不乘四。

图中粉色虚线是评分几何直线，不冒称直打的完整实际轨迹；橙色线为翻袋实际轨迹。每题directProof额外存该直袋的成功物理打法；两种打法都不落母球、不发生再次球球接触，目标球分别0／1次主库碰撞后进指定袋。最优指有限采样袋口候选内的最大角度分，不宣称连续空间全局最佳。
