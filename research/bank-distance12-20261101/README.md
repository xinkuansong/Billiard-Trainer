# 中远台翻袋12题

针对用户反馈：完整舒适分中的距离衰减不能淘汰远台厚打翻袋。仅离线研究，不修改App和正式题库。

准入：两球球心距离≥0.40m、生产出杆空间分≥85、六袋最小合法直打几何切角≥45°、翻袋实际碰撞切角≤35°。取消上一轮distance≥85与total≥70门槛，完整分项保留展示与复算。目标球沿完整反射线采样，无旧中央50%/10cm区域限制。

配额：中袋/底袋×直打45–55°/55–65°/≥65°×中距离[.4,1)m/远距离≥1m，共12题。层内按距离覆盖点、翻袋切角、直打档中心和出杆空间软排序；中距离覆盖点.55/.70/.85m，远距离1.25/1.55/1.85m。排序用于选有代表性的样例，不表示进袋概率或全局最优。

bankComfort沿用生产距离、空间、角度和总分公式，翻袋角度项使用实际碰撞来向/去向与完整目标球路线长度。六袋最高直打完整分另列参考；粉线及直打实测参考解仍对应最小几何切角袋，不能混称为最高完整分袋的物理证明。

验证：12组生产公式对拍、过近/贴库反例，以及1.7m且旧距离分<85、总分<70仍可准入的正例。生成后24杆独立精确事件和评分重放；评分JSON采用JSONDecoder类型化读取，保留FL-239修复。audit.py独立复算分项、变换、距离分组与实际路线，并注入错误夹具。

```sh
python3 research/bank-distance12-20261101/audit.py

```
