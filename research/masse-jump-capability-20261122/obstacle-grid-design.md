# CB-01 障碍球二维位置设计

## 当前执行口径（2026-11-24）

用户已将范围收敛为：**每个基础球形只保留一个障碍位置和一个成功解**。下文的大网格是早期讨论稿，不再作为本轮任务量。

当前从既定的 10,000 个基础样本出发，轮转分配 `s=0.30/0.50/0.70`、`q=1.00/0.75/0.50/0.25`，检查左右侧后确定一个合法位置。`q` 仍是母球—目标球中心线的几何标签，并非目标球可见面积比例。另检查障碍球确实挡住母球到进球假想球位置的直线路径：球心到线段距离必须小于 `2R−1mm`。若预分配单元没有合法侧，依序寻找下一单元；不强制维持均匀配额。

坐标沿用项目契约：X/Z 为水平面，Y 向上，单位米；球半径 0.028575 m、内框 2.54×1.27 m。障碍球检查全部六个袋口；中袋中心使用 Z=±0.67596474 m、半径 0.043 m。

候选参数来自 E2，扎杆 9 组、跳球 8 组，跨杆法按仰角升序尝试，首个符合当前安全与进球条件的解即停止。没有扰动试验。搜索耗尽仅表示该障碍位置、该参数集合没有找到解，不证明球形不可解。执行入口、版本与结果见 [单解执行报告](one-solution-results-20261124.md)。

## 目标

在 10,000 个基础球形上展开障碍球求解条件。障碍球的位置使用两个自由度表示。

- **纵向位置 `s`**：障碍球投影在母球到目标球连线上的位置，定义为
  `s = dot(O - C, T - C) / |T - C|²`。
- **遮挡程度 `q`**：障碍球中心到母球—目标球连线的横向距离归一化，定义为
  `q = 1 - clamp(h / (2R + margin), 0, 1)`，其中 `h` 是障碍球中心到该连线的距离，`R` 是球半径，`margin = 1 mm`。

`q = 0` 表示障碍球刚好在球心通道的安全边界外，`q = 1` 表示障碍球中心落在母球—目标球连线上。`q` 是题目中的遮挡强度参数，实际输出同时保留 `h` 和 `q`，避免只存派生标签。

## 第一批二维网格

纵向位置使用 5 档。

| `s` | 含义 |
|---:|---|
| 0.20 | 靠近母球一侧 |
| 0.35 | 母球侧中近段 |
| 0.50 | 连线中点 |
| 0.65 | 目标球侧中近段 |
| 0.80 | 靠近目标球一侧 |

遮挡程度使用 5 档。

| `q` | 中心线重叠近似 |
|---:|---:|
| 0.00 | 无中心线遮挡，保留 1 mm 安全余量 |
| 0.25 | 轻遮挡 |
| 0.50 | 中遮挡 |
| 0.75 | 重遮挡 |
| 1.00 | 中心线正挡 |

每个基础球形先展开 5 × 5 = 25 个障碍条件。10,000 个基础球形对应 250,000 个连续参数组合，跳球和扎杆分别求解后为 500,000 条任务。横向正负号是离散镜像状态，不是第三个连续自由度。由于库边会破坏左右对称，求解前应检查两侧，合法时分别保留，不能只固定一侧。

若两侧都合法并都保留，最多为 500,000 个障碍几何条件，跳球和扎杆合计 1,000,000 条求解任务。

## 几何护栏

- 障碍球中心必须落在合法球心区域内。
- 母球、目标球、障碍球之间的球心距离必须大于 `2R + 1 mm`。
- `s` 必须满足 `s·|T-C|` 和 `(1-s)·|T-C|` 均大于 `2R + 1 mm`。
- 障碍球不得进入目标袋口的球体捕获区域。
- 真实求解仍需检查球杆尾部空间、库边、母球出界、目标球出界和目标路线事件。
- `q = 0` 保留为无障碍对照层，不作为“有遮挡成功”的正例。

对于当前过滤后的距离范围 1.0565–1.70715 m，`s = 0.20–0.80` 距离护栏有明显余量。最终能否保留某一网格点由真实求解结果决定，不能把静态几何通过直接当成跳球或扎杆可解。
