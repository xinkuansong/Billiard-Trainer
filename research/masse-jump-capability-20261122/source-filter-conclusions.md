# 原始准度球形全量过滤结果

日期：2026-11-22（Asia/Shanghai）

本轮从 `QiuJi/Resources/training-grid-bank.json` 的 2,520 个原始准度目标球展开全部有效组合，按每个组合生成 30%、50%、70% 三个障碍球位置，并分别复制为跳球与扎杆候选。过滤只做静态几何检查，未调用求解器，也未修改正式题库。

## 结果

- 展开候选 4,695,168 条。
- 几何通过 550,884 条。
- 几何拒绝 4,144,284 条。
- 跳球通过 275,442 条。
- 扎杆通过 275,442 条。
- 通过候选覆盖 1,082 个原始目标球。
- 通过候选的母球—目标球距离约 1.057–1.707 m。
- 通过候选包含距离位元 5–9，未包含更短距离位元。
- 三种障碍位置各有 183,628 条通过候选。

## 拒绝原因

| 原因 | 数量 |
|---|---:|
| 母球—目标球距离小于 1.00 m | 3,655,284 |
| 原始目标球未通过 clean 标记 | 1,803,144 |
| 母球越出台面合法球心区域 | 10,506 |
| 母球瞄准轴与库边发生重叠 | 6,156 |

一条候选可能同时命中多个原因，因此原因数量之和大于拒绝行数。

## 当前使用的规则

- 球半径使用项目表格常量 0.028575 m。
- 球间最小几何间距使用 `2R + 0.001 m`。
- 母球—目标球距离使用 `1.00 m` 作为第一版来源过滤线。
- 目标球和障碍球都要通过袋口区域检查。
- 母球瞄准轴必须保留正库边间距。
- 母球到最近库边的距离已经记录，但杆尾的数值最大距离尚未写成硬门槛，等待真实球杆姿态参数。

## 输出格式

- `filtered-source-shapes.json` 是通过候选的清单文件，实际记录在 `filtered-source-shapes.jsonl.gz`。
- `source-filter-audit.json` 是全量审计清单，实际记录在 `source-filter-audit.jsonl.gz`。
- `filter-summary.json` 保存计数、范围、拒绝原因和来源哈希。

下一步可以把 `filtered-source-shapes.jsonl.gz` 直接转换成求解器任务，按跳球和扎杆分别搜索一组解。求解通过后才进入候选题库。
