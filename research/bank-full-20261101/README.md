# 一至三库翻袋全量（8线路并行）

用户授权：2026-11-01，原密度全量，8个独立线路进程。该目录仅生成研究资产，不改正式App题库。

## 运行

```sh
python3 scripts/local_test_lifecycle.py run --task bank-full-20261101 -- python3 research/bank-full-20261101/run.py
```

构建一次、冻结当前生产物理和评分依赖。通过fleet借用notch-phone，单台模拟器启动8个独立Worker进程，一进程一条路线。按库数/袋型交错调度；不创建8台模拟器。每个目标点128候选，均有机会进行预筛；合格者完整物理求解后分三距离档每档择最多2题。未找到是有限预算未找到，不代表物理无解。

原长库48/短库24分区，根路线按中袋末段35°过滤，连续碰库垂直相邻；每条路线12个近库加密目标点。球心距≥40cm、空间≥85、实际翻袋切角≤35°、六袋最小合法直打角≥45°。母球3个距离档为[.4,1)、[1,1.6)、[1.6,桌面对角上限]米。没有固定目标球区域；远距离/完整总分不是硬阈值。中杆无塞，力度搜索沿已验证小样。每条保留题同时保存直打参考物理证明。

## 产物与断点

`output/bank-full-20261101/`：
- `status.json`、`active.json`：进度、活动线路与并行峰值。
- `route-tree.json`：1→2→3库的几何来源，不要求上一级有成功球形。
- `routes/NNN.json.gz`：selected rows、独立原生verification、12目标点summary。
- `routes/NNN.receipt.json`：审核通过后原子保存的SHA/源身份/数量/计数。无receipt的线路不计完成。
- `manifest.json`：全量完成后按精确镜像等价球位+库序去重，retainedIDs为最终子集。近似去重未设阈值。
- `review-sample.json`、`index.html`：全量的有限抽样图册；不是整个库存。
- `source-binding.json`、`harness-binding.json`、`generation-identity.json`：源码与产物身份。

失败时受管临时构建保留。修复/续跑必须确认源身份一致；已验路线SHA一致可跳过，源码改变不得混合旧receipt。成功后受管scratch回收，gzip原始证据保留。每个独立重放验证全部碰撞事件和完整评分；Python另外核反射树、线路、入袋角、角度、空间、配额，最后全量再核一次。

## 边界

不保证每目标点6题，也不承诺此前约9000题估算。未做实台校准、瞄准/力度扰动容错、少库替代比较或App接入。首轮仅编译失败（大异构字典导致Swift推断超时），拆分赋值后以新受管run运行，不改物理或筛选阈值；旧失败日志保留。
