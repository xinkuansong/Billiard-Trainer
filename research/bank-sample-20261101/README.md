# 翻袋八类小样 · 2026-11-01

用户授权：按已讨论方案做中袋/底袋×1–4库，每类6题、每行3题，先评阅球形和路线。仅研究，不改App。

## 复现

```sh
python3 scripts/local_test_lifecycle.py run --task bank-sample-20261101 -- python3 research/bank-sample-20261101/run.py
python3 research/bank-sample-20261101/audit.py
python3 research/bank-sample-20261101/render.py
```

再次生成应使用新输出目录，保留本轮原数据与截图。源码`main.swift`、`build.py`、`run.py`共同定义冻结入口。`build.py`沿用已验证的原生研究编译器：37个当前生产物理/几何/可出杆及入口文件重编；历史UI依赖对象复用并逐一SHA记录，不运行UI代码。不是整个App构建或全App验收。

## 构造范围

- 世界XZ米制，+Y朝上；研究图右=+X、下=+Z；台面及球径、袋口、有限主库直接导出生产几何。
- 固定PRNG种子2026110108；全桌内区10×6格每格随机1个目标球位置。小样直接全桌采样，没有将同题镜像复制凑数，也未运行正式全库的固定对称分配。
- 枚举1–4库：不连续同墙；排除相对墙A→B→A，允许A→B后转其他墙。研究入口将明确库序送入生产`ShotPredictor.predict`，不使用旧页面默认三库、最多12解和相邻相对库剪枝。
- 生产`bankSeedPath`仅提出几何种子；首库15°门槛沿用该入口。种子总路长<8.5m、碰库点落在真实有限直库段，距端点>3.5cm。这些是本轮选样值，不是真人难度界限。
- 母球相对目标首段方向，生成切角取±12/±30/±50°六个锚点，GC距离0.30–1.05m、步长15cm并固定随机选档。为小样缩减角度覆盖，未声称执行完整2°网格。
- 1库杆速候选1.8/2.5/3.2/4.0；2库2.5/3.2/4.0/4.8；3–4库3.2/4.0/4.8/5.6m/s；优先中杆无塞，补塞候选±0.15R但本轮未用到。每类至多3000次求解预算，不做扰动评分。
- 候选固定随机排序；每类同物理墙序最多2题、不同目标初始球心至少16cm；中袋每个实际袋3题，角袋每袋最多2题。质量/配额不满足则失败，不静默补复制题。

## 准入与证明

生产求解后必须从实际strikeDirection跑完整自由击球两球模拟，并检查真实出杆可达。母球直接先碰目标；目标恰好按指定主库序进指定袋；母球全程不落袋；落袋前不能再次球球碰撞。袋嘴只允许在最后一主库之后、距指定袋心18cm以内的正常进袋阶段，不计为主库，不允许中途借袋嘴翻球。

入选保存未取整参数、全部事件、按原始recorder取样并截到捕获时刻的路线。`verify`进程再逐题精确重放：事件序列JSON逐字一致。独立Python审核按事件重建事实，不依赖success字段；5个错误袋/库数/母球落袋/首碰/二次撞球构造反例必须被拒。

`generation-summary.json`的attempts是求解调用数，求解器内部有多次模拟，不等于总模拟次数。图册切角来自首次碰撞前母球速度与碰后目标初速度夹角；generationCut另存，不能混作同一个值。

## 结果

48题，8类各6题；1012次求解调用，48/48独立精确重放；全部中杆无塞。图册路径`output/bank-sample-20261101/index.html`，完整过程与证据见任务卡。
