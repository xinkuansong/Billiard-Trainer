# 两球／三球全自由题库多解生成

授权：现有自由库全部非单球球形；每个入选球形至少两解；区域型和遮挡型均保留。首轮独立候选包，不替换 App 资源。

- 原始 ID、球号、球权、坐标不变：two_black 9918、two_own 9941、three 37716，共57575。one895不在本次范围。
- 85分为区域潜力标签，不是全局淘汰线。约5cm网格（50×25）只引导搜索，75分以上连通区作为方向搜索种子；不声称离散峰值是连续最大值。低基础潜力仍搜索移动我方球形成遮挡的路线。三球额外静止8号参与评分与窗口避障。
- 每题15/30/45/60度、双侧，0.6…6.0杆速粗扫/局部细化；中杆优先，按需扩展高低杆、侧旋；不凑库数。当前仍是有界研究专用求解，不是连续方向/杆法穷举。
- 每条实际终态及四次独立扰动（方向±0.1°、速度±5%）均须满足生产v8评分≥80、合法、完全停稳、无进袋、固定球未接触/移动、母球与对方球心距≥30cm。
- 我方最佳已确认避障进球窗口为正且不下降：这是暂用保护条件，不是已校准的“稍微舒服”，没有强制送袋口，也不把窗口最大化。
- 主库0…5；禁袋角碰撞、目标球互撞、我方球吃库后再碰母球。完整回放与生产精算对拍。
- 至少2、最多保存6条。有序物理碰撞序列不同，或母球终点相差≥8cm，或我方球终点相差≥10cm，方可同时保留。找到2条即允许停止杆法扩展，不保证找到所有解；只1条单列，不收入多解包。
- 无解记录意为“在本次有界参数和保护条件下未找到”，不得说物理上无解。估算分保持分支元数据，不伪造未知角度为0，不把四探针当成功概率。

## 运行及断点

```sh
python3 scripts/local_test_lifecycle.py run --task defense-multisolution-full-20261106 -- python3 research/defense-multisolution-full-20261106/run.py
```
