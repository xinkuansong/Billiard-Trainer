# 自由球位一库翻袋12题

用户批准在近库12题基础上取消库段中央50%/10cm固定球位限制。沿有效反射线全长采样，13个比例由0.005到0.98；实际桌面/袋口/重叠合法性仍须满足。按中袋/底袋、直打三个角度档各2题。球位差异与离库深度是软排序，不设置离库档配额；有限候选不代表全局最优或全桌连续搜索。

角度口径沿上一批：六袋有限合法袋口候选中最小几何直打切角>=45°，一库成功参考解碰球实测切角<=35°。直打成功参考解也保持相同角度档。四种对称变换替换原题；生产物理全程完成、实际指定袋与库数、母球不进袋、无二次碰球、可出杆验证。每题两种打法各独立精确事件重放。

运行：python3 scripts/local_test_lifecycle.py run --task bank-open12-20261101 -- python3 research/bank-open12-20261101/run.py；随后audit.py与render.py。受管设备与临时构建自动收尾；失败现场保留。生产依赖重编译并冻结SHA，旧未运行UI对象溯源，不宣称完整App构建。JSON与网页独立研究产物，不写正式题库。
