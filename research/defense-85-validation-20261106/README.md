# 85分档十例：区域与可达路线验证

输入固定为上一轮`defense-maxscore-gallery-20261106`的85-01…85-10；均为未改坐标、未改球号的两球原题。复用已核SHA的5cm/局部加密热区，固定对方9号，移动母球与我方8号。研究输出，不改App/题库/评分。

主目标80分，诊断75/85分。初筛峰值85与终态路线得分不是同一门槛。30cm球心距离排除同时适用于区域、终态及四次扰动。本次研究沿用此暂用参数。

- 全连通高分区域作为采样目标，不用35cm分块接缝计算宽度；按区域面积选择最多12个目标。区域面积/内核宽度来自重采样网格，是估计，不是连续安全证明。
- 既有研究版`PositionPlaySolver.solveDefenseResearch`调用正式`ShotPredictor.simulateFree`和真实球杆避让；保留真实袋口、三颗球与生产规则。碰撞切角15/30/45/60度、两侧，补偿杆法偏移，杆速采用现有参数范围并局部求精。当前仍是有界研究搜索，未声称正式走位求解API已接入防守。
- 中杆→小幅高低杆→更大高低杆→侧旋，仅在80分联合目标未通过时扩展；不凑杆法或吃库数。达到80即停止继续扩展，85结果仅供诊断，不代表85分全搜索。
- 终态完整停稳、合法首碰/碰库、无球进袋、9号没有碰撞/位移、不重叠；完整回放终态和生产评分对拍。
- 我方8号暂用“最佳已确认避障进球窗口为正且不下降”。窗口不输入未来母球位置，不最大化；未知窗口不记作0。这个条件未校准为绝对舒服，特别是初始8号已很好的球形可能过严。
- 四次独立扰动：瞄准方向±0.1度、杆速±5%。四次均满足得分、合法性、30cm和8号窗口条件才记联合通过；不是实战成功率或连续误差域证明。
- 代表按执行难度、杆速、实测碰库数、区域余量排序，没有最大我方窗口奖励。名义高分但未抽样验证的候选不计通过。
