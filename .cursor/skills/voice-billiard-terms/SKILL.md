# 语音台球术语纠错

用户常用语音。ASR 会把「塞」写成「赛」、「杆」写成「刚」。本技能只做一件事：**听成正确的台球话，再执行**。

详尽词表与近音总表见 [glossary.md](glossary.md)。拿不准先查它，禁止自造术语。

## 流程

1. **判语音**：标点少、口语填充、近音错字、台球词被写成日常字 → 按语音处理。
2. **整句还原**：先猜整句在说训练 / 精讲 / 几何 / 产品哪一类，再换词。
3. **换标准术语**：只替换相关词；不改用户要做的事。
4. **回用标准词**：回复、任务理解、写进代码/文档的用词，一律用标准术语。
5. **会改任务才点明**：例如「加赛」→「加塞」。一对多先问。一对一静默换。
6. **不越权**：不纠正口吻，不讲 ASR。瞄准公式仍以 `45-aiming-principles.mdc` 为准；精讲写法仍以精讲规范为准。

## 本项目首选（冲突时用左边）

| 首选 | 口语/别称 | 不要写成 |
|------|-----------|----------|
| 母球 | 白球、本球 | 木球、母求 |
| 目标球 | 色球、对象球 | 目的球 |
| 切球角 / 切角 | 角度、厚薄角 | 切入角 |
| 加塞 | 加旋转、加 English | 加赛 |
| 挤偏 / 弧线 / 投掷 | squirt / swerve / throw | 塞偏；把挤偏写成投掷 |
| 让点 | 瞄准补偿 | 挤偏、投掷的同义词 |
| 走位 | 跑位、停位（若指母球任务） | 走味 |
| 定杆 | 停球杆法 | 定刚 |
| 斯登 | 定杆、stun | 思登、四登（杆法语境） |
| 低杆 | 打点在中心下方 | 底杆（打点语境） |
| 底袋 | 角袋（靠近底库那两个） | 底带 |
| 球形 | formation、一形 | 球星 |
| 精讲 | tutorial | 经讲 |
| 动作 / 课 | drill | 动作酷（指库时用「动作库」） |
| 分离角 | 撞后母球偏离角 | 分离脚 |
| 手架 | 桥、架口 | 手脚、手加 |

**易混对**：

- **低杆** = 打点偏低（回旋 / 拉）。**底袋** = 底侧角袋。语音「底杆进底带」→「低杆进底袋」。
- **加塞** = 左右侧旋。训练语境里的「加赛」几乎总是它，不是加时赛。
- **走位** = 母球去下一位置。训练语境里的「走味 / 周围」优先当它。
- **球形** = 一堂课里的一种摆法。不是球星、不是球型材质。
