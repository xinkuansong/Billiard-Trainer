# 球迹术语与语音近音表

技能 `voice-billiard-terms` 的详表。听不准先在本文件搜，禁止自造。
物理定义以 `.cursor/rules/45-aiming-principles.mdc`、`docs/research/20260804-瞄准理论总纲.md`、
`.kiro/steering/table-geometry.md` 与对应代码为准；本表只管「标准叫什么」，不得把不同物理效应合并成一个词。

写法：`标准术语` — 含义。其后是口语/英文，再是常见错听。

## 1. 球

| 标准术语 | 含义 | 口语 / 英文 | 常见错听 |
|----------|------|-------------|----------|
| 母球 | 用杆打的那颗，走位的主体 | 白球、本球；cue ball | 木球、母求、亩球、母秋 |
| 目标球 | 这一杆要碰/要打进的球 | 色球、对象球；object ball | 目的球、木标球、目标秋 |
| 障碍球 | 挡路或用来做安全的球 | 阻挡球；blocker | 障碍求、挡碍球 |
| 彩球 | 非母球的彩色球（中八/斯诺克语境） | 色球 | 才球、踩球 |
| 8 号球 | 中八的黑 8 | 黑八、黑球 | 巴号、八好球 |
| 9 号球 | 九球的胜负球 | 九号 | 就号球、久号 |
| 假想球 / 幽灵球 | 瞄准用的虚拟母球位置 | ghost ball | 幽铃球、有灵球、假象球 |
| 接触球 | 母球先碰到的那颗 | 第一目标球 | 接触秋 |
| 满台 | 球还很多、没怎么打 | — | 蛮台、满抬 |
| 残局 | 球所剩不多 | — | 惨局、残居 |

球号口语：1 号…15 号。语音「一号 / 幺号」都是 1 号；「幺」不要写成「妖」。

## 3. 瞄准与厚薄

| 标准术语 | 含义 | 口语 / 英文 | 常见错听 |
|----------|------|-------------|----------|
| 瞄准 | 对线、看厚薄 | aim | 秒准、瞄樽 |
| 瞄准线 | 眼睛/杆看过去的线 | — | 秒准线 |
| 进球线 | 目标球心 → 袋口 | pocket line | 进秋线、进求线 |
| 击球线 | 母球心 → 幽灵球心 | strike line | 击秋线 |
| 切球角 | 进球线与击球线的夹角 | cut angle；本项目不用「切入角」 | 切入角、切脚、窃角 |
| 切角 | 切球、打薄打厚这件事 | cut | 切脚、切叫 |
| 厚薄 | 打多厚/多薄 | fullness | 后薄、厚保 |
| 全球 / 满球 | 切球角 ≈ 0° | 直球、straight-in | 满秋 |
| 半球 | 切球角 ≈ 30° | half-ball | 半秋 |
| 厚球 | 切得较满 | thick cut | 后球、厚秋 |
| 薄球 | 切得较薄 | thin cut | 保球、博球 |
| 极薄球 | 接近 90° 的薄切 | very thin | 急薄 |
| 横移量 | 幽灵球相对目标球、垂直击球线的位移 | lateral displacement | 横移两、横移量 |
| 接触点 | 两球相碰的点 | contact point | 接触点、接处点 |
| 打点 | 皮头打在母球上的位置 | tip offset | 打点、打店 |
| 五分点 | 瞄准辅助点 | — | 五份点、五粉点 |

厚薄通称对照（与瞄准规则一致）：全球 / ≈1/4 球 / ≈1/3 球 / 半球 / 3/4 球 / 极薄球。

## 4. 杆法与打点

| 标准术语 | 含义 | 口语 / 英文 | 常见错听 |
|----------|------|-------------|----------|
| 杆法 | 打点 + 出杆方式 | stroke type | 刚法、杆发、干法 |
| 中杆 | 打点在中心附近 | stun、center | 中刚、中干 |
| 高杆 | 打点偏上，前旋、跟进 | follow、top | 高刚、高干 |
| 低杆 | 打点偏下，回旋、拉 | draw、bottom | 底杆、低刚、地杆 |
| 定杆 | 碰撞后母球少跟少缩 | stun、斯登 | 定刚、订杆、定干 |
| 斯登 | 与定杆同指这件事（stun 的常用叫法） | 定杆、stun | 思登、死灯、四登（杆法语境） |
| 跟进 | 母球碰后继续往前 | follow | 根进、跟劲、根劲 |
| 拉杆 | 母球碰后往回走 | draw | 拉刚、拿杆、啦杆 |
| 回旋 | 低杆造成的后旋 | backspin | 回悬、回玄 |
| 前旋 | 高杆造成的上旋 | topspin | 前悬 |
| 点杆 | 短促点一下 | poke | 点刚 |
| 顿杆 | 出杆有停顿 | punch / stun-ish | 顿刚、盾杆 |
| 滑杆 | 皮头打滑 | miscue | 滑刚 |
| 空杆 | 没碰到目标球 | miss、air shot | 空刚、空干 |
| 推球 | 杆头跟球粘太久（常犯规） | push | 推秋 |
| 冲球 | 大力打 | power shot | 冲秋 |
| 软打 | 很小力 | soft | 说打、睡打 |
| 中力 / 大力 | 力度档 | medium / hard | 中利、大利 |
| 力度 | 出杆快慢、能量 | speed | 力都、利度 |

打点盘口语：十二点=正高，六点=正低，三点=右塞，九点=左塞；高左 / 高右 / 低左 / 低右。

## 5. 加塞与旋转

| 标准术语 | 含义 | 口语 / 英文 | 常见错听 |
|----------|------|-------------|----------|
| 加塞 | 打左右侧旋 | english、side | 加赛、加腮、加晒 |
| 左塞 | 打点偏左 | left english | 左赛、左腮 |
| 右塞 | 打点偏右 | right english | 右赛 |
| 塞量 | 侧旋多少 | amount of side | 赛量、腮量 |
| 高塞 / 低塞 | 上下 + 左右的合成打点 | running / reverse 等 | 高赛、低赛 |
| 挤偏 | 加塞使母球出发方向偏向塞的反侧 | squirt | 挤片、挤骗、塞偏 |
| 弧线 | 母球在行进中受旋转与台呢作用而逐渐弯曲 | swerve | 弧现、弧县 |
| 投掷 | 球球碰撞时接触摩擦使目标球偏离理想进球线 | throw | 投置、头掷 |

## 12. 近音总表（按错字反查）

左边是 ASR / 口误，右边是优先还原。训练、精讲、几何语境下用本表；明显在说别的事则不要硬换。

### 赛 / 腮 → 塞

加赛→加塞；左赛/右赛→左塞/右塞；赛量→塞量；高赛/低赛→高塞/低塞；顺赛/逆赛→顺塞/逆塞。

### 刚 / 干 / 赶 / 钢 → 杆

定刚→定杆；中刚→中杆；高刚→高杆；低刚/底杆（打点）→低杆；出刚→出杆；拉刚→拉杆；架刚→架杆；点刚→点杆；顿刚→顿杆；滑刚→滑杆；空刚→空杆；扎刚→扎杆；握刚→握杆；运刚→运杆；刚法→杆法。

### 酷 / 裤 → 库

贴酷→贴库；吃酷→吃库；一酷/两酷/三酷→一库/两库/三库；长酷/短酷/顶酷/底酷→长库/短库/顶库/底库。

### 带 / 代 / 待 → 袋

底带→底袋；中带→中袋；脚带/角带→角袋；带口→袋口；翻带/反带→翻袋；叫带→叫袋。

### 味 / 为 / 未 → 位

走味/走为→走位；站味→站位；停味→停位。周围（课/练语境）→走位。

### 脚 / 叫 → 角

分离脚→分离角；切脚→切角；自然脚→自然角；正脚→正角；反脚→反角；先脚（器材）→先角。

### 秋 / 求 → 球

母求/目标秋/开秋/跳秋/清台以外的「求」→对应的「球」。开秋→开球。

### 产品词

球星/求形→球形；经讲/金讲/精降→精讲；动作酷/洞作库→动作库；货加→货架；付费强→付费墙；是打/势打→试打；编拍台→编排台；球记/球技/求迹→球迹；青苔/清抬→清台；死诺克/斯洛克→斯诺克；中巴（玩法）→中八；就球→九球。

### 其它

台泥/台尼→台呢；巧克力（擦杆）→巧克；秒准→瞄准；幽铃球→幽灵球；切入角→切球角；手脚/手加→手架；开放加/封闭加→开放架/封闭架。

## 13. 方言与发音不稳

- **n / l**：拿杆→拉杆；泥→呢（台呢）。
- **平翘舌**：走/奏都可能是走位；出/粗 + 刚 → 出杆。
- **前后鼻音**：定/订 + 刚 → 定杆；进/近 + 球 → 进球。
- **ang / an**：刚/干都当「杆」试。
- **ai / ei**：赛/塞优先塞；带/袋优先袋。

整句比单字准。例如「把那个走味精讲改一下」整句是内容任务，不是「走味」美食。

## 14. 一对多（先问再做）

| 听到 | 候选 | 怎么判 |
|------|------|--------|
| 底杆 | 低杆 / 底袋相关 | 前后是打点、回旋、拉 → 低杆；是袋口 → 底袋 |
| 加赛 | 加塞 / 加时赛 | 本项目默认加塞 |
| 周围 | 走位 / 真的周围 | 课、练、母球 → 走位 |
| 叫球 | 跳球 / 叫球叫袋 | 杆尾抬高、越过 → 跳球 |
| 跟进 | 母球前行 / 出杆送杆 | 说停点 → 走位；说胳膊、杆头 → 出杆 |
| 球型 | 球形 / 球的材质 | 摆法、第几形 → 球形 |
| 中巴 | 中八 / 其它 | 玩法、球种 → 中八 |

问的时候只给候选术语，不要展开 ASR 课。
