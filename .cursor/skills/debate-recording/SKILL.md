# Debate Recording Skill — 中立记账的通用能力

赋予使用者一套**与议题无关**的纪要能力：把一场多轮对抗辩论压缩成可回看的结构化台账，只留必要信息。议程维度以当前议题文件为准。

## 触发场景

- 结构性辩论每轮结束、需要把过程沉淀进台账时。

## 台账文件

`docs/research/<YYYYMMDD>-辩论记录-<议题简称>.md`，每轮**增量更新**。结构见 `.cursor/agents/debate-recorder.md`。

## 该留 vs 该丢

| 留 | 丢 |
|---|---|
| 当前最优方案草案（带不确定性标注） | 寒暄、客套 |
| 议程覆盖进度（按议题文件维度）| 重复的论证 |
| 被接受 / 被枪毙的结论 + 原因 | 措辞润色、过程性思考 |
| kill-test 的 A/B 类型 + 证据 / 验证计划状态 | 逐字记录 |
| 分歧的症结（卡在哪个证据） | 已被推翻的中间稿细节 |
| 每轮 2–4 句摘要、未决问题、下一步 | |

## 状态机

`进行中` → （满足共识门槛）→ `待用户签字` → （用户确认）→ `已定稿`。
记录者只如实标状态，不替用户签字、不替评判方判定共识。

## 纪律

- 不站队、不评价想法优劣、不补充自己的观点。
- 数字 / 论断照搬双方原话，不二次加工。
