# Tutorial Authoring Skill — 序列 → 图文精讲

## 你要做的事（一句话）

读一条走位序列 JSON，跑事实提取脚本，看配图，把事实**组织成中文教练话**，写回 drill JSON 的 `tutorial` 字段。你只做语言组织，**不做任何几何计算**。

写作语义以 `docs/research/20260818-v40-精讲内容规范.md`（**v2**）为准（看懂 → 理解为什么练 → 怎么打 → 打完知道哪错 → 马上调整）。规范是约束，不是填空模板。**先通读规范全文再动 JSON。** ⛔ 禁止用脚本按模块生成或回写正文（FL-032）；`tutorial_digest.py` 只供几何事实。必须逐个动作、逐个球形直接改 JSON。规范与本技能冲突时，**学员可见正文以规范为准**（中间档可留空、正文不报度数、自检不抄静帧坐标、厚薄话术不用「接触点向 X 侧调整」）。

## 为何而写（总原则，后面所有规则都从这里推出）

用户打开精讲页时，手上**已经有**：详情页动画演示、上手试打、每杆配图（图上有轨迹线、打点盘、力度读数）。

> **所以文字的唯一价值，是提供这些看不出来的东西**：为什么这么打、怎么判断自己做对了、错了是哪里错、这一杆在整体训练里占什么位置。

三条推论，构成本技能的骨架——遇到规则冲突或本文件没写到的情况，回到这三条判断，不要机械套模板：

1. **凡是已被呈现过的，文字再说一遍就是负价值。** 图上看得见母球从哪走到哪，文字重述位置轨迹只是占用注意力。→ §不重复原则
2. **要知道该写什么，先得知道图已经说了什么。** 所以读图是写作的前置条件，不是事后校验。→ 第 0 步
3. **每杆平均用力 = 没有重点。** 全组必须有一个明确的胜负手，其余相应压缩。→ §重点指认

⛔ **反面典型**：「母球在 1 号球右上方，向下中袋有自然切角；用轻高杆让母球继续前行，停到 2 号球右下方。」——三句话全是图上一眼可见的信息，读者看完不知道为什么值得练。这叫**几何转述**，是本技能最常见的失败模式，不予验收。

| 真源 | 管什么 | 缺了会怎样 |

## 第0步：意图锚定 + 读图（写作前必做）

### 0a. 读图（先做这个，它决定文字该写什么）

**逐张看**开局图与每一杆的图，用 Read 工具直接读 PNG（可以看图，不要只 `ls` 确认存在）：

```bash
ls QiuJi/Resources/DrillTutorials/ | grep <drillId>        # 已落位配图
ls build/position_play_export/ | grep <drillId>            # 未落位的原始产物（含 sNN.mp4 可看轨迹动态）
```

#### 读图的三个目的（按重要性排序）

1. **划定文字边界**——图上一眼可见的（球在哪、线怎么走、打点力度读数），文字**不再重述**。这是「不重复原则」的落地前提。
2. **图健康检查**——图坏了而文案照写，是本项目已发生的事故（见下）。
3. **发现疑点，触发回查**——图文感觉对不上时，回事实清单核对。

#### ⛔ 看图的边界（与 `geometry-spatial-reasoning` 铁律的切分，必须精确理解）

| 能做 | ⛔ 不能做 |
|---|---|
| 判断图上**有没有**某个对象（几颗球、有没有线） | 目测角度、距离、切球厚薄 |
| 判断图文**是否矛盾**（图注说三颗球、图上零颗） | 从图上读出方位词写进正文 |
| 发现疑点 → **回事实清单核对** | 发现疑点 → 按目测结论改写正文 |

一句话：**看图用于证伪，不用于取值。** 所有几何断言仍只能来自事实清单。

#### 图健康检查清单（逐项核对，别笼统「看一下」）

- [ ] **球数对不对**：图上目标球颗数与序列一致。
- [ ] **跨图连贯**：开局图的母球位置 == 第一杆图的母球位置；第 N 杆的落点 ≈ 第 N+1 杆的母球起点。
- [ ] **图注可兑现**：caption/正文提到的每个对象，图上真的存在。
- [ ] **HUD 与文字同语言**：图上 HUD 若显示「高 43% · 右 1%」而正文写「中上约一个皮头」，属已知问题（v25 E11），正文**维持档位语言**，并在交付说明中记一笔图待重出。

> **真实事故（v25 E7，写进技能以防重演）**：`drill_c042_initial.png` 上三颗彩球一颗都没渲染、只有母球，且母球位置与 `s01` 图对不上（说明可能根本不是本序列的产物）；而 JSON 图注写着「1、2、4 号球沿中线从右到左排开」。**当时写精讲的人没看图**。这一条检查若执行，事故不会发生。

#### 方位词：事实清单已是屏幕系（DR-063），照抄即可

DR-063 起，`tutorial_digest.py` 的全部方位输出（袋口中文名、区域、八方位）已统一到**用户屏幕系**（portrait 竖版，与精讲配图/击打页同向）：袋口名为 左上角袋/右上角袋/左侧中袋/右侧中袋/左下角袋/右下角袋。v25 E9 的「参照物绕行」条款废除。

- ✅ 方位词从事实清单**原样照抄**，与竖图天然对齐，不需要读者转向。
- ✅ 参照物表述仍然推荐（「停在 2 号球与底库之间约一颗球」），它比绝对方位更易执行。
- ⛔ 仍禁止自己看坐标心算方位或看图目测改写——取值只认事实清单。
- ⚠️ 若发现事实清单方位与配图不符（例如袋口名与图上袋口位置对不上），按红灯处理如实上报，禁止手工「转正」。

### 意图红线

1. ⛔ **无 profile 不得虚构设计意图。** 当前仅 11 条 drill 有 profile（`c016`/`c018`/`c020`/`c021`/`c053`/`c073`–`c078`）。其余 drill 只能从 `description` / `coachingPoints` / 实测参数能支撑的范围内写，**禁止编造「设计者当初为什么这么摆」**。写不出问 2 就在交付说明里如实说「本 drill 无变量档案，球形设计意图未溯源」。
2. ⛔ **禁止空泛意图。** 每句意图陈述必须能指回一个具体的变量 / 参数 / 元数据。「提升整体球感」「培养手感」「增强信心」这类不可证伪的话一律删除。
3. ⛔ **多球形禁止复制同一段意图。** N 个球形的「技术原理」若能互换而不违和，说明没写出球形差异——这是多球形精讲最常见的塌陷。每个球形必须点出**本球形相对其他球形变了哪个变量、因此难在哪**（如 c053 的 A1 是 15° 右切近距、A2 是 15° 左切远目标球，同切角不同 `side`/`dtp`）。
4. ⛔ **意图不得与实测矛盾。** 若元数据说「练轻力控制」而事实清单里 velocity 偏大，如实上报冲突，不硬圆（FL-027）。

## 不重复原则（总原则推论 1，三个方向都要查）

信息只在**第一次有价值的地方**说一次。三个方向的重复都算缺陷：

| 方向 | 表现 | 怎么改 |
|---|---|---|
| **跨媒介**（字 vs 图） | 文字重述图上一眼可见的球位、轨迹形状、打点百分比 | 删掉描述，改写这一杆的**意图与判据** |
| **跨杆次**（第 N 杆 vs 第 N+1 杆） | 每杆都从头解释一遍同一个原理 | 原理在**首次出现处**讲透；后续杆只写**本杆的差异与新增难点** |
| **跨 drill**（本 drill vs 同类 drill） | `c032` 中台角度球 / `c033` 远台斜线 / `c052` 极薄角度，技术原理写成同一段「角度球要判断厚薄」 | 动笔前读 `docs/research/20260818-v40-概念所有权表.md`：本条只写表里的**角色 + 本课新层** |

**判据（可自测）**：把某段文字删掉，读者是否损失了信息？没有损失 = 该删。

⚠️ 但**不重复 ≠ 惜字如金**。判据不是字数，是增量信息密度。该讲透的原理（首次出现的杆法机理、反直觉物理）要讲够。

### 跨 drill：引入课五问 / 后续课新层（v40 §四B，D-v40-1=A / D-v40-6=A）

所有权表给每个概念标了 **引入 / 后续 / 合成**。`技术原理` 按角色写，禁止 83 条同等篇幅：

| 角色 | `技术原理` 写什么 | 禁止 |
|------|-------------------|------|
| **引入**（表里「引入」列的那一课） | 把该概念机制卡的**五问写成自然段**（可合并，抽查时五问都能指认）。不要把「状态/这节只改/因为所以/观察/本课只练」标题暴露给学员 | 只贴标签和度数；只译一句定理就结束 |
| **后续** | **一句前置**（指向引入课课名，写在该形 `技术原理` 首句）+ **本课新层**（表里那一维） | 重写问 1–3（切角是什么、定杆是什么、为什么锁中杆…） |
| **合成**（走位链 / 综合 / 特殊） | 默认会先决概念。一句前置可点名先决课，然后只写本玩法新层 | 改回阶梯腔；再上一遍切角/杆法入门课 |

**引入课五问**（每问必须答到；机制只抄定理 `statement_one_liner` / `common_errors` + digest「理论参考」，⛔ 自造物理）：

| # | 问 | 必须答到 | 禁止 |
|---|----|----------|------|
| 1 | **状态** | 该现象发生时球处于什么物理状态（学员能想象的词） | 「提升球感」；只报课名 |
| 2 | **问 2** | 这节只改什么 / 变量是什么（只列与本概念相关的） | 把本课没练的量全写一遍 |
| 3 | **问 3** | 每个变量如何改变问 1 的状态；至少写到「因为…所以…」。小标题用「因为所以」，不要用分析腔词（D-v40-8） | 「用中低杆就能停」「瞄准要准」这类无机制口号 |
| 4 | **观察** | 台上怎么看出对了 / 错了（至少一对可证伪征兆） | 只有「进袋即过」 |
| 5 | **本课只练** | 钉死哪些量、只练哪一维、为什么只练这一维（一句） | 写成「本组只练一个变量」套话后就结束 |

- 后续课禁止重写五问全文。逐杆「怎么打」不再复述五问，只写本档变量怎么改。
- 所有权还管**这一杆自检盯什么**（表里「自检盯什么」列）。分离角课不得再写准度课的进袋/厚薄套话。
- 多形仍各完整，但用一句体感差 + 自带参照的数字，⛔ 不用「与球形 1 共享/变了/为何」三问答。
- ⛔ 正文禁止定理编号、公式、「法则告诉我们」（D-v40-6=A）。学员可见语域走 **D-v40-8 类型规则**（不是封闭词表，见下）。定杆概念引入是 c010，不是 c014。台面距离走 **D-v40-9**。

### 学员可见语域（D-v40-8，类型规则）

精讲读者是球房里的学员。下面是**类型**，例子只帮助认型，删掉几个词不算过：

| 类型 | 改前气味 | 改成 |
|---|---|---|
| 分析 / 验收腔 | 把内部清单当术语：窗口、旋钮、因果、切片、变量框架 | 球房能说出口的话。问 2 =「这节只改…」 |
| 半生口头语 | 没吃上、擦唇 | 切薄滑开、擦袋口、碰袋唇弹出 |
| 生造搭配 | 术语和口头语粘错对象：切角怎么吃、吃一个角度；「档」借来量厚薄/力度（略打厚半档、降半档力度） | 吃的是球的厚薄。幅度用「一点 / 明显」；力度用「加一点 / 收一点」 |
| 教材 / 实验室腔 | 法则告诉我们、T 编号、公式 | 教练话；机制写「因为…所以…」但不出现「因果」二字 |
| 机械复读腔 | 接触点向厚侧调整 / 接触点向薄侧调整（一篇里连写十几次） | 打厚一点 / 多吃一点；打薄一点 / 少吃一点。通用诊断只落「常见错误」一处 |
| 不会这么说的计量 | 袋距约 2.5 颗球、远约 10.1 颗球 | 见 D-v40-9 |

自测：把句子念给球房里的人听，他应知道台上做什么。听起来像实验报告或验收清单 = 重写。

### 学员可见距离（D-v40-9）

- **内部真源不变**：`tutorial_digest.py` 仍输出颗球。1 颗球 = **57.15 mm**（`.kiro/steering/table-geometry.md` 球直径）。禁止看图估距离。
- **上屏**：台面直线距离（袋距 / 两球距 / 落点距 / 形间差）**禁止写「颗球」**。
  - 换算后 ≤50 公分 → `约N公分`，N 为 **5 的倍数**（20、35…）。
  - 换算后 >50 公分 → `约X.X米`（一位小数，如约 0.6 米）。
- **可留「颗」的只有球厚瞄准**：半颗球厚、三分之一颗球厚。那不是台面距离。
- 公式：`mm = 颗球 × 57.15`；`cm = mm / 10`；≤50 则 `N = round(cm/5)*5`；>50 则 `米 = round(mm/1000, 1)`。

例（已用上式算过，勿重估）：2.5 颗球 → 15 公分；1.7 颗球 → 10 公分；10.1 颗球 → 约 0.6 米；12.6 颗球 → 约 0.7 米；14.3 颗球 → 约 0.8 米；22.4 颗球 → 约 1.3 米。

## 序列形态判定：走位链 vs 独立阶梯（DR-062，写逐杆节前必判）

同为多杆序列，有两种本质不同的形态，**逐杆节的写法完全不同**。写作前先按客观判据判定：

| 形态 | 客观判据（读事实清单，不靠感觉） | 逐杆节写法 |
|---|---|---|
| **走位链** | 每杆落点决定下一杆（目标球位置/距袋逐杆变化，「为下一杆创造的局面」有实义） | 每杆全文三条目（本节以下各规则的默认对象） |
| **独立阶梯** | 每杆独立重置：目标球距袋恒定 + 袋口不变 + 杆法力度锁死，只有一个变量在扫（切角/距离/塞量/力度档） | **混合式**（见下），⛔ 禁止逐杆全文解说 |

> 原理：精讲的信息量应与**变量数**成正比，不与**杆数**成正比。杆数只是采样密度；对单变量阶梯逐杆写「为什么/怎么打」，每节必然同构，全是冗余（W1 c032/c053 教训）。

### 独立阶梯的混合式结构（DR-062）

1. **`技术原理`**：若本课是该变量的**引入课**，按上一节「引入课五问」写满机制；若是**后续课**，只写前置句 + 本课新层。一次讲完，后面不再复述定义。
2. **`开局与击球顺序`**：摆位说明 + **阶梯走势**（从多少收到多少、再开到多少；「每档见配图」）。⛔ 不要把每档度数排成一串（规范第五节）。
3. **逐杆节保留**（配图与 `params` 依赖它，C4 门禁按杆数对齐），但分两档写：
   - **锚点档**（全组 2–4 杆）写完整三条目：入门档（建立基准）、教学锚点档（如半颗球厚）、上限档、以及带缺陷/特殊情况的档。三个 label 的定义见规范第六节——「为什么」写这一档在整组里的作用，禁止用度数复读顶位。
   - **中间档**：没有该档特有的新判断就**整档留空**（标题 + params + 图 + caption）。有特有信号才写一条条件诊断句。⛔ 禁止为「每档非空」凑一句（规范第六节）。
4. **多球形阶梯**：从第 2 个球形起，用一句体感差 + 自带参照的数字（如「比球形 1 远约 15 公分」），再写本形独有难点。⛔ 不用「与球形 1 共享什么 / 变了什么 / 为何按此顺序」三问答（v40 §4.2）。

**⚠️ 只写差异有个下限（多球形必读）**：多球形用 Picker 切换，用户**可能直接点到后面的球形**，不一定从第一个读起。所以——

- 差异描述必须**自带参照**：写「切角从 15° 加到 30°，球厚从 3/4 减到 1/2」，⛔ 不写「角度更大了」。
- 每个球形**至少能独立回答「本档练什么」**，不能只剩一句「同球形1，但更远」。
- 参照对象要写明是哪一档（「比球形1远约 15 公分」），⛔ 不写「比上一档远」——用户不一定知道上一档是哪个。距离单位见下节 D-v40-9。

## 语域：面向用户写作，不面向验收写作（DR-062）

精讲正文的读者是**台球学员**，不是主控/验收者。以下内部词汇 ⛔ 禁止出现在任何面向用户的字段（`description` / `coachingPoints` / `standardCriteria` / `tutorial` 全部正文）：

- **仓库工作流词**：退役/retired、profile、序列文件、manual01、digest、出片、录制、待重录、W 批次号。
- **验收自证话术**：「与已退役的旧 X 球形不同」「现行示范」这类向验收者证明你了解历史的句子——用户没有历史包袱，直接写现在是什么。
- **力度/杆法定性词汇口径（DR-063，取代 DR-062 的「纯数值」条）**：正文以**台球房定性词**为主、数值退居括号补充（首次出现或关键档写「小力（约 1.6 m/s）」，其余档只写定性词）：
  - 力度：轻推 / 小力（轻力）/ 中力 / 中大力 / 大力——分档阈值与 App `PowerDisplay.name` 同源（<1.2 / <2.2 / <3.6 / <4.8 / ≥4.8 m/s）。
  - 竖向杆法：中杆 / 中高杆 / 中低杆 / 高杆 / 低杆 / 纯高杆 / 纯低杆。
  - 横向塞：以皮头为单位——半颗皮头的左塞/右塞、一颗皮头的左塞/右塞（塞量↔digest 读数换算见提示词模板词汇表）。
  - 组合表达自然拼接：「中高杆加一颗皮头的右塞」「小力纯低杆」。⛔ 仍禁「轻力 2.1 档」式标签+数值堆叠——定性词与数值不并列混排，数值只进括号或 `params`。
- **示范缺陷的用户视角写法**：序列有 scratch 等缺陷时，只写用户需要知道的一句（「示范动画里母球也落袋了，这不是标准答案——你以母球留台为合格」）；内部的待重录/登记信息写进**交付说明**，不进正文。

## 重点指认（总原则推论 3；仅走位链适用，DR-062 限定）

⛔ **每杆平均用力 = 没有重点。** **走位链**全组必须显式指认**一个**胜负手，并让篇幅体现出来。

- **怎么找**：客观依据优先——事实清单里容差最小/落点要求最苛刻的那一杆、意图卡问 4 答出的「失败通常卡在哪一环」、`standardCriteria` 最难兑现的环节。⛔ 不靠感觉指定。
- **怎么写**：在该杆的 `为什么` 里明说它是全组关键（如 c042「这一杆是全组精度要求最高的一杆，落点对力度敏感，先求稳」），其余杆相应压缩。
- **诚实的低价值判断也是有用信息**：某杆确实只是过渡，就明写「这一杆是铺垫，难度低于第二杆，重点是别走过头」，一两句带过即可。⛔ 强行给每杆编出深意，反而稀释真正的重点。
- ⛔ **独立阶梯没有胜负手**：各档独立，最薄/最难一档只是「上限档」，不存在决定链条存亡的一杆。阶梯型正文禁用「胜负手/关键档」措辞，重点分配走混合式结构（锚点档全文、中间档一句或留空）。

### 前两节的内容要求（意图承载区，⛔ 别写成摆球说明）

样板 `drill_c042` 的这两节是达标线，写之前先读：

- **`技术原理`**：点明训练主题，并说明本组示范如何体现该主题。一段说得清就一段，⛔ 不强制「目的一句 + 空行 + 原理两句」双段式（规范第十一节）。⚠️ **`coachingPoints` 每一条都要在正文里有落点**——它是产品侧已确定的教学重点，逐条核对，遗漏视为缺陷（c042 三条全部被吸收）。多球形还须点出本球形与其他球形的差异变量（意图红线 3）。
- **`开局与击球顺序`**：先客观描述摆位与顺序，然后**必须**有一段「为什么这样排」——把顺序与袋口的选择理由讲出来（c042：「同一颗球打上袋还是下袋，取决于母球停在它的哪一侧——顺序和袋口是一起规划出来的，不是逐杆临时决定」）。只写「1、2、4 号球从右到左排开，依次进袋」就是摆球说明，不是精讲。

- 数字标题用中文：第一杆、第二杆…（对齐 drill_c042 样板）。
- `content` 支持 `\n\n` 分段和 `**加粗**`；每张图配一句话 `caption`。
- `params` = `{"spinX": …, "spinY": …, "velocity": …}`，**从事实清单「params（照抄进 JSON）」行原样抄**，不四舍五入不改写。
- 多球形 drill：`tutorial.formations: [{id:"f1", title:"球形 A：…", sections:[…]}]`，每球形一套完整骨架；单球形用 `tutorial.sections` 平铺。二选一，不能同时存在。

## 逐杆节 items 三条：写什么（⚠️ 不是「怎么造句」）

label 固定为 `为什么` / `怎么打` / `自检`（App 渲染有专属配色，一字不差）。

> ⚠️ **下面的句式是参考，不是填空模板。** 验收查的是**信息是否齐全**（内容契约），不是**句子是否长这样**（形式契约）。照着句式硬填，产出的正是那种一眼假的机械文案。允许——也鼓励——按这一杆的实际情况自然组织语言，甚至调整三条之间的信息分配（见下方 `为什么` 末条）。

### `为什么`（两层意图，缺一层即不合格）

**必须包含的信息**（形式自定）：

| 层 | 回答什么 | 来源 |
|---|---|---|
| **战术意图** | 这一杆要达成什么：用什么杆法、把母球送到哪、**为下一杆创造了什么** | 事实清单【为下一杆创造的局面】【为下一杆留出的切球角】 |
| **训练意图** | 这一杆为什么值得练：在本 drill 主题里的角色（主训点 / 铺垫 / 收尾 / 全组容错最低）、难在哪个具体维度 | 意图卡问 3 |

参考句式（可完全不用）：「用{杆法}把母球送到{落点，带参照物}，为下一杆留出{什么}——这一杆是{角色}，难在{维度}。」

- 非最后一杆**必须**写出下一杆需要什么（反向规划的落地）；最后一杆写不需要再留位置。
- ⛔ **只有战术层 = 几何转述，不予验收**——这是本技能最常见的塌陷（见 §为何而写 的反面典型）。
- ⛔ 按 §不重复原则，母球位置/轨迹形状**图上已有的不重述**；这一条的篇幅应该花在「为什么」上，不是「是什么」上。
- 两层可以合成一段自然的话，也可以分散到三条里——c042 第一杆把训练意图放在了 `怎么打`（「这一杆是全局精度要求最高的一杆」），完全可接受。**要求是这层信息存在，不是它在哪一条。**

### `怎么打`（要领，不重复数字）

- 打点用身体语言：「中上约一个皮头」「低杆加足」「中心击球」——**禁止**出现 spinX/spinY 数值或百分比读数（params 行已经展示了）。
- 力度用档位语言（轻推/轻/中/中大/大力）+ 节奏描述（「轻推出杆、送透不急收」）。
- 事实清单「理论参考」提示了反直觉物理时（如短距高杆更贴切线），在这条里用教练话点破。

### `自检`（可证伪）

> 用户唯一看不出来的就是「我怎么知道自己偏了」。必须是**条件诊断句**：看到 X = 偏 Y，往 Z 调。⛔ 禁止状态描述、预测、期望复述、鼓励句（规范第六节）。

- 独立阶梯：通用厚薄诊断（擦外侧=薄 / 弹唇=厚）只写在「常见错误」节，逐杆只写该档特有信号；没有特有信号就删这个 item，甚至整档留空。
- 走位链：写失败区怎么判（停太近 / 停太远 / 漂到中路左侧，下一杆会怎样），⛔ 不要把示范图上的正确停位再叙述一遍（「母球停在 8 号右上方约 30 公分一带」违规，规范第十节）。
- ⛔ 停位诊断只许用相对词。凡「方位词 + 公分数」的停位句一律违规——不管它戴的是哪个 label。
