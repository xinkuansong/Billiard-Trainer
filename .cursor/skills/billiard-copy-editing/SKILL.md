3. [执行流程与上下文清单](references/intent-image-workflow.md)全文：角色阅读矩阵、资料读取、理解核验、派发、恢复与验收。
4. 当前任务方案的授权范围、本人批次、保护对象、验收与最新反馈。当前重写任务是 [DRILL-COPY-REWRITE-20261015](../../../tasks/DRILL-COPY-REWRITE-20261015.md)。任务范围会变化，不能从旧样稿或历史完成记录推断授权。

## 执行顺序

范围与版本 → 实际读取 → 核清教学判断 → 写作 → 作者自查 → 独立审稿 → 主控验收 → 用户审阅。

- 原始意图回答为什么练；图片、序列和实测回答发生了什么；理论解释有条件的因果。三者不能相互覆盖。
- 独立重摆和连续接打是录制组织；并列、递进、对照和衔接是教学关系。分开判断。
- 先说明示范打法、力度与走位目的，纠错放在确有需要的位置。不要用“试打再调”填补未理解的教学内容。
- 语义要求在统一规范中维护，本技能不另定三标签、强制胜负手或机械留空规则。
- 不生成或脚本回填教学正文；直接编辑已授权候选JSON。脚本仅用于材料清单、事实计算、校验、备份和展示。
- 本轮角度、术语、analysis用量、训练数量、姿势用语等具体要求见统一规范；派发必须携带相关用户要求，不能只依赖主控记忆。

## 交付

### FL-163补充：球角色与跨页方位

2026-10-16用户复阅发现：单母球练习引入“不先碰目标球”，横桌详情沿用竖图袋名，第一要点又原样进入试打。审核必须区分未来母球起点标记与实际进攻球；标记约定只在前几个基础动作解释。正文方位按实际消费画面核验，不能只核精讲图。全部空间词逐项分类，袋名/库边/半台随页面映射，左右塞等击球参照不变。第一要点须验真实试打横竖消费者；序列多杆不等于连续走位。具体要求维护于统一规范v1.6，不能用旧门禁绿覆盖此次语义返工。

### FL-163补充：打点存档值与界面百分比

审核“高低/左右多少”或“接近极限”前，实际读取当前 `SpinDisplay.readout` 和 `CuePhysics.miscueLimitFraction`。存档spin不是界面百分比；当前读数为spin/0.5×100，例−0.4627显示低93%，不能直乘100称低46%。同时核实际图片HUD；不凭原始浮点幅度给作者下错误返工结论。2026-10-16主控已更正c064审核中的该误读，原序列未变。
