# 球形训练意图改写

把用户说的话写成表里最后一列。只改 `docs/research/20260819-动作库球形训练意图.md`。⛔ 不回写 drill JSON。

动笔前先读技能 `voice-billiard-terms`（含 `glossary.md`）。近音先还原，词表没有的先问，禁止自造术语。

## 流程

用户说：分类（可省）→ 哪一课 → 哪一形 → 训练意图。听不清或一对多先问再写。下一课以开口为准，不要按表序抢填。

1. 还原术语，对上表里那一行（课 id + 形）。说错课就改归属，不要硬写在当前行。
2. 按下面句式改写，写入该行最后一列。
3. 回用户：写了哪一课哪一形；改过的词点明半句。然后等下一课。

## 句式（定调）

两句。第一句写摆法，第二句写练什么。

1. **摆法**：什么固定、什么在变、打进哪里。
2. **意图**：`这一形主要练……，并……`。

多形课每形各写各的，禁止两形并成一句，禁止把课级意图摊到所有形上。没有并列序号就不要写「第一种 / 第二种」「一方面 / 另一方面」。

## 用词

- 意图正文里的袋口写成 **角袋**。课名里的「底袋」不动。
- 「击打点」写成 **打点**。
- 相关杆法并进同一句（高杆双下、低杆双下并进打点力度）。
- 打点 + 力度控停位就是斯登，不必再单写斯登。停位用打点 / 力度、往前停 / 往后停，不要造词。
- 用户原话里词表没有、但已确认保留的（如高杆双下 / 低杆双下、正角 / 反角）照留。正脚 / 反脚写成正角 / 反角。
- 距离口语：短台 → 近台；用户刻意纠正的距离（中远台、中长台）按纠正写，课名仍用现网。

## 删什么

- 开场套话（「非常核心的基础练习」）。
- 标签句（「这一形是中远台角度球」）。
- 同义反复（「距离变了停位也变」只留一句有信息的）。
- 口述重复的同一句，只留一遍。

过长就压，过随便就补全到两句；不要写成电报体。

## 对照

**过随便（不要）：**

> 这一形是中远台角度球。目标球位置固定，改变母球和目标球之间的角度，练中远台瞄准。

**改写后（要）：**

> 目标球位置固定，改变母球和目标球之间的角度，从不同角度把目标球打进角袋。这一形主要练中远台瞄准，并感受不同角度下目标球的瞄准点。

**另一形机制不同时，仍用两句，不要抄上一形：**

> 母球和目标球越摆越远，过程中角度也越来越小。这一形练从近台到中长台，把目标球打进角袋。
