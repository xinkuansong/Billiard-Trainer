# 球形训练意图（简报规格）

只改 `docs/research/20260819-动作库球形训练意图.md`。⛔ 不回写 drill JSON——意图是**上游简报**，由 `问题集合_v41.md` §四定义它如何喂给 `description` / `coachingPoints` / `tutorial` 三处（那是执行真源，本技能只管把表写对）。

**两列纪律（2026-08-24）**：`训练意图` = 用户原文，⛔ 禁止改写、覆盖、删字。AI 只写 `完善` 列。空行保持原文空白，在完善列标「跳过（待素材）」。

口述输入时先读技能 `voice-billiard-terms`（含 `glossary.md`）还原近音；词表没有的先问，禁止自造术语。

## 意图 = 五槽简报

每行只装五个槽，写不满就空着，⛔ 禁止拿讲义凑字：

| 槽 | 写什么 | 必填 |
|----|--------|------|
| 自变量 | 什么固定、什么在变（距离/角度/打点/力度/塞/贴库）。⛔ 不写几档、几度、米每秒——数字归序列 | ✅ |
| 目标 | 打进哪族袋（中袋 / 底袋=角袋）；有走位则母球到哪类区域 | ✅ |
| 主练 | 一个、最多两个，能证伪。⛔ 禁止复述课名、禁止「提升球感」 | ✅ |
| 本形差 | 多形课必填：和邻形差在哪（近/远、贴库/不贴库、打点阶梯/力度阶梯） | 多形课 ✅ |
| 展开指针 | 可选，`展开：<机理名>`（如 `展开：定杆=碰球时无旋转`）。只点名，⛔ 不写推导——推导归精讲 | 可选 |

## 句式分型

- **有球形、阶梯课**：两句。`摆法。这一球形主要练……，并……`。需要机理时第三句 `展开：…`。
- **无球形课**：主语改「这一课」。
- **走位 / 综合课**：第一句摆法与约束，第二句只留能力；路线怎么想（反向规划、卸力……）放展开指针。⛔ 不硬套准度腔（「感受不同角度下目标球的瞄准点」）。

多形课每形各写各的，⛔ 禁止两形并成一句、禁止把课级意图摊到所有形、禁止邻形第二句互换不违和（含**跨课**同族：蛇彩、加塞家族——各自点出本课差）。没有并列序号就不写「第一种 / 第二种」。

## 两种工作模式

**A. 口述录入**（原流程）：用户说 分类（可省）→ 哪一课 → 哪一形 → 意图。听不清或一对多先问；说错课就改归属。写完回用户：写了哪一课哪一形，改过的词点明半句。

**B. 统一完善**（v41 W1–W3）：AI 主动把已有行收成五槽。规则：
1. 每处改动必须指回真源（序列 digest / 现网 `description` `coachingPoints` 原文 / 用户原话）；指不回就保持原文并列入上报清单，⛔ 不编。
2. 改动写入 **完善** 列并前缀 **〔改〕**；整表过目通过后去掉〔改〕。⛔ 不改训练意图列。
3. 空行：训练意图列保持空白，完善列标 **「跳过（待素材）」**；c062「删除」、c059「未开放」这类状态写在完善列，不覆盖用户原文。
4. 已合格的行不为齐改腔（三问能过就不动）。
5. 意图与序列实测矛盾 → 上报，⛔ 禁止顺手改成「看起来对」（FL-027）。

## 验收三问（每行自测）

1. 不看档位数，能否说出这行钉死什么、变什么、练什么？
2. 能否从中抽出 1–3 条台上可检查的要点？
3. 精讲知不知道该展开哪一条、不该展开哪一条？

## 用词

- **袋口只分两族：中袋 / 底袋（=角袋，同义，D-v41-1）**。行内用词前后一致即可，不做全表替换；具体哪一只袋（左下/右上…）跟序列，不写进意图。课名不动。
- 「击打点」写成 **打点**。相关杆法并进同一句。
- 停位用 打点/力度、往前停/往后停；⛔ 不造词（课名本身是斯登的除外）。
- 用户原话里词表没有、但已确认保留的（高杆双下 / 低杆双下、正角 / 反角）照留。正脚 / 反脚写成正角 / 反角。
- 距离口语：短台 → 近台；用户刻意纠正的（中远台、中长台）按纠正写。

## 删什么

- 开场套话、标签句、同义反复、口述重复。
- **机理讲义**（摩擦如何抵消、反向规划步骤、容错比较）——压成 `展开：` 指针，正文最多留一句判据。
- 剂量与几何数字（几档、几度、几 m/s、台面颗球距）——归序列 / 开局 / 达标 / 精讲，**不进** `description`（D-v41-7）。

## 对照

**过随便（不要）**：

> 这一球形是中远台角度球。目标球位置固定，改变母球和目标球之间的角度，练中远台瞄准。

**合格**：

> 目标球位置固定，改变母球和目标球之间的角度，从不同角度把目标球打进底袋。这一球形主要练中远台瞄准，并感受不同角度下目标球的瞄准点。

**讲义压成指针（c010 定杆，不要整段摩擦推导）**：

> 不同距离的直线球，把目标球打进底袋，同时让母球在碰撞后原地停住。这一球形主要练按距离调打点和力度、把母球定住。展开：定杆=碰到目标球那一瞬间母球无前后旋（打点偏下抵消台呢摩擦）。

**另一形机制不同时，仍各写各的，不抄上一形**：

> 母球和目标球越摆越远，过程中角度也越来越小。这一球形练从近台到中长台，把目标球打进底袋。
