# Idea Generation Skill — 发散提想法的通用能力

赋予使用者一套**与议题无关**的发散与构想能力：在任何辩题下，系统性地把"可能性空间"打开，并产出有依据、可被检验的强想法。具体辩题 / 议程 / 证据源由当前议题文件提供。

## 触发场景

- 在结构性辩论中需要提出新想法、新方案、新机制，或迭代已有想法时。
- 任何"需要从零想出高质量选项"的场合。

## 能力清单（方法库）

### 1. 第一性原理拆解

把议题拆到不可再分的事实与约束，丢掉"行业惯例""大家都这么做"，从根本约束重新组合出方案。先问：什么是真的硬约束？什么只是习惯？

### 2. JTBD（Jobs To Be Done）

对象"雇佣"这个方案来完成什么任务？在什么情境、想达成什么、现在用什么凑合、为什么不够。围绕 job 而非功能想方案。

### 3. 跨域类比迁移

从其他成熟领域借机制（打卡 / 段位 / 每日一题 / UGC / 订阅 / 社交货币…）。**迁移不是套壳**：每个类比都要回答"它成立的前提（高频习惯 / 社交场 / 内容供给等）在本议题场景是否同样成立"，前提不成立就别硬搬。

### 4. 系统与回路思维

别只想单点动作，想**自我增强回路**：输入 → 动作 → 产出可被他人看到的东西 → 把更多输入拉回来。识别正反馈、瓶颈、杠杆点。

### 5. 选项空间扩张

对每个问题先逼自己给出 ≥3 个**本质不同**的解法（而非一个方案的微调），再比较。用"如果必须用完全不同的方式呢？"打破定式。

### 6. 约束松弛 / 极端化

逐个假设性地拿掉一个约束（预算无限 / 零技术限制 / 必须 10 倍增长），看能涌现什么新形态，再把约束加回来取可行内核。

### 7. 复用现有资产

盘点手上已有的独特能力 / 数据 / 资产，问"它们能自然长出什么别人长不出的方案"。（本议题的具体资产清单见议题文件的证据源。）

### 8. 联网取材（按需）

外部世界的事实 / 数据 / 跨行业类比真实案例与机制，**主动联网查**而非凭印象。结论标 事实 / 推测 / 假设并**附来源链接 + 日期**，优先权威来源、交叉验证。内部事实（产品自身能力 / 数据）仍以议题证据源为准。

## 纪律（与评判方对齐）

- 系统优先：先把"定位 / 对象 / 环境"想清楚，再谈具体功能与增长。覆盖议题文件列出的**全部**议程维度，别钻单点。
- 诚实：每条主张标 事实 / 推测 / 假设；凡当场可查的事实，先查证据源再下结论。
- 主动暴露自己看到的最大弱点，别等评判方挖。

## 自检（提想法前过一遍）

- [ ] 覆盖了议题文件的全部议程维度吗？还是钻进单点？
- [ ] 用了 ≥2 种上面的方法，而不是只顺着第一个念头？
- [ ] 每条主张标了 事实 / 推测 / 假设？当场可查的先查了？
- [ ] 类比的前提在本场景成立吗？
- [ ] 主动暴露了至少一个弱点？
