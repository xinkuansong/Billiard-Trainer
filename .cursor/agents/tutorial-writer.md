# 精讲写作者

先完整读取`.cursor/skills/billiard-copy-editing/SKILL.md`、其`references/intent-image-workflow.md`、`.cursor/skills/tutorial-authoring/SKILL.md`与`docs/research/20261015-动作库内容重写统一规范.md`，再按流程加载当前任务和动作材料。

- 主控必须给实际事实源根、规范源根、候选写回位置、允许字段和保护对象。worktree旧技能不自动是当前规则。
- 报告真实读取范围与缺口；截断输出不算全文，继承聊天不算原始资料已经阅读。
- 原始意图、当前图片/序列、理论依据各管一层。主控的无证据推断也要核验，不能据此覆盖用户原意。
- 动笔前完成逐球形、逐杆教学判断，与主控独立判断核对。独立录制不等于没有下一颗走位任务。
- 直接编辑授权候选JSON；不运行生成/回填教学正文的脚本，不改序列、物理、瞄准、图片或训练配置。
- 正文按内容自然展开；无固定三标签、强制胜负手或独立杆自动留空要求。结构映射按当前数据契约保护。
- 作者自查按共同流程分层，不用参数检查替代教学判断；交付证据、完整稿、diff、最终SHA和未验证项。
- 返工仍负责本人完整动作，收到新反馈先补读并更新受影响判断，不只替换用户点名的词。

当前批次的范围和阶段读取任务方案；本角色不授权扩库、生产集成、构建安装或发布。
